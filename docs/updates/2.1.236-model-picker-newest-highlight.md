## 原文（日本語訳）

`/model` ピッカーの変更点として、任意に選ばれた一部の項目ではなく、最新モデルの名前だけをハイライトするようになりました。これにより、ハイライトは新しいリリースを示すものになります。

## 原文（英語）

Changed the `/model` picker to highlight only the newest model's name, so the highlight marks the new release rather than an arbitrary subset of the list

## 概要

`/model` コマンドでモデル一覧を開くと、これまでは選択肢の一部がハイライト表示されることがありましたが、その基準が必ずしも「最新リリース」と一致していませんでした。今回の変更により、ハイライトは常に一覧の中で最も新しいモデルの名前にのみ付与されるようになり、ユーザーは一目でどれが新しいモデルなのかを判断できるようになります。

## 基本的な使い方

特別な操作は不要です。セッション内で `/model` を実行してモデル選択画面を開くと、一覧の中で最新のモデル名にのみハイライトが表示されます。

```
/model
```

表示されたピッカーの中で、ハイライトされている項目が現時点での最新モデルです。

## 実践例

### 新しいモデルがリリースされたことに気づく

Claude Codeがアップデートされて新しいモデル（例: 新バージョンのOpusやSonnet）が追加された場合、`/model` を開くと、その新しいモデル名だけがハイライトされます。これにより、changelogを確認しなくても、どのモデルが新しく追加されたのかをピッカー上で直感的に把握できます。

```
/model
# ハイライトされている項目 = 最新リリースのモデル
```

### モデルを切り替える際の判断材料にする

複数のモデルが一覧に並んでいる状況で、どれを選ぶか迷うことがあります。ハイライトが最新モデルのみを示すようになったことで、「とりあえず最新版を試したい」という場合にハイライト項目を選べばよく、判断がシンプルになります。

```
/model opus
```

## 注意点

- ハイライトはあくまで「一覧の中で最新のモデル」を示すものであり、必ずしも現在選択中のモデルを表すわけではありません
- モデルのエイリアス設定（`settings.json` の許可リストなど）によって選択できるモデルが制限されている場合、その範囲内での最新モデルがハイライト対象になります
