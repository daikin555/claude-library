# Vertex AIでファストモードが利用可能に（global・us・euリージョン）

## 原文（日本語に翻訳）

- Vertex上でglobal、us、euの各リージョンにおけるファストモードを追加。Vertexが拒否した場合は標準速度にフォールバックする

## 原文（英語）

- Added fast mode on Vertex in the global, us and eu regions, falling back to standard speed if Vertex refuses it

## 概要

Google Cloud Vertex AI経由でClaude Codeを利用している場合でも、ファストモードを使えるようになりました。対象はglobal、us、euリージョンです。Vertex側でファストモードのリクエストが拒否された場合は、自動的に標準速度で処理されます。

## 基本的な使い方

Vertexを利用する設定にした上で、セッション中に `/fast` を実行してファストモードを切り替えます。

```bash
export CLAUDE_CODE_USE_VERTEX=1
export CLOUD_ML_REGION=global
claude
```

```text
> /fast
```

## 実践例

### 対話的な開発の高速化

Vertex経由で社内ポリシーに沿って利用しているチームでも、リファクタリングや反復的な修正作業の応答速度を上げられます。

### リージョン固定の運用

データ所在地の要件でus・euを指定している場合も、リージョンを変えずにファストモードを試せます。

## 注意点

- Vertexが拒否した場合は標準速度で動作するため、エラーにはなりません。
- ファストモードは通常、標準速度より料金が高くなる場合があります。課金条件はご利用のプランで確認してください。
- 対象リージョンは global・us・eu です。
