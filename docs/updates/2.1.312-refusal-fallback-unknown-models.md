## 原文（日本語訳）

フラグ付きメッセージ後の自動モデル切り替えが、カスタムデプロイ名など未認識のモデル名にも適用されるよう変更。無効にするには `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` を設定します

## 原文（英語）

Changed automatic model switches after a flagged message to also cover model names Claude Code doesn't recognize, such as custom deployment names; set `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` to turn them off

## 概要

自動モデル切り替えの対象が広がりました。望まない場合は環境変数で無効化できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1
```

## 実践例

### モデルを固定したい場合

検証やコスト管理のため切り替えを避けたいときに無効化します。

## 注意点

- 無効化すると、フラグ付きメッセージ後も元のモデルのまま処理されます。
