## 原文（日本語訳）
- 修正：`/context` が視覚的なグリッド全体を以降のターンで毎回Claudeに送っていた問題。Claudeは表のみを読むようになりました。
- 改善：ターミナルの `/context` でClaudeが読む表を短く保ちます。各リストは最大10行に制限され、オンデマンドで読み込まれるMCPツールは、呼び出されるまでサーバーごとに1行にまとめられます。

## 原文（英語）
- Fixed `/context` sending its full visual grid to Claude on every later turn; Claude now reads only the table
- Improved `/context` at the terminal so the table Claude reads stays short: each list keeps its 10 largest rows, and MCP tools that load on demand share one row per server until they're called

## 概要
`/context` 実行後に無駄なトークンが後続ターンに載り続ける問題が解消されました。表も簡潔になり、コンテキスト消費が抑えられます。

## 基本的な使い方
```
/context
```

## 実践例

### コンテキスト逼迫の診断
大きい項目上位10件を見て、削る対象を判断できます。

### MCPツールが多い環境
サーバー単位の1行表示で、全体像を把握しやすくなります。

## 注意点
- 各リストは上位10件のみが表示されます。
