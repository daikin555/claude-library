# claude doctor に API 接続性セクションを追加

## 原文（日本語に翻訳）

`claude doctor` に API 接続性のセクションを追加しました。API に到達できるかどうかを、HTTP ステータスまたはエラーとともに報告し、テストしなかった場合はその理由を表示します。

## 原文（英語）

Added an API connectivity section to `claude doctor` that reports whether the API can be reached, with the HTTP status or the error, or says why it wasn't tested

## 概要

プロキシやファイアウォール配下で Claude Code が接続できない問題を切り分けやすくなります。

## 基本的な使い方

```bash
claude doctor
```

## 実践例

### プロキシ環境での切り分け

```bash
export HTTPS_PROXY=http://proxy.example.com:8080
claude doctor   # API connectivity の結果で到達可否とステータスを確認
```

## 注意点

- テストが行われない場合は、その理由が表示されます。
- 認証エラーとネットワークエラーはステータス／エラー内容で見分けます。
