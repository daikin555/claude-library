## 原文（日本語に翻訳）

同名のスキルが既にある場合に `--add-dir` フォルダ内のスキルへ到達できない問題を修正しました。そのスキルは `<folder>:<name>` として提示されます

## 原文（英語）

Fixed a skill in an `--add-dir` folder being unreachable when another skill already held its name; it is now offered as `<folder>:<name>`

## 概要

`--add-dir` で追加したディレクトリにスキルがあり、既存スキルと名前が重複すると、後者に隠れて使えませんでした。今後は `<フォルダ名>:<スキル名>` の形式で呼び出せます。

## 基本的な使い方

```bash
claude --add-dir ../shared-tools
# shared-tools 内の review スキルが既存の review と衝突した場合
# /shared-tools:review として利用可能
```

## 実践例

### 共有スキルリポジトリを併用する

```bash
claude --add-dir ~/work/team-skills
> /team-skills:deploy
```

### 衝突時に呼び分ける

プロジェクト側の `/review` と、追加フォルダ側の `/team-skills:review` を使い分けられます。

## 注意点

- `<folder>` は追加したフォルダ名に基づきます
- 衝突しない場合の呼び出し名は従来どおりです
