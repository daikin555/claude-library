## 原文（日本語訳）
[Claude Code on the web] セッションを既読にした直後に、それが未読状態へ戻ってしまうことがある問題を修正しました。

## 原文（英語）
[Claude Code on the web] Fixed sessions sometimes flipping back to unread right after you mark them read

## 概要
Claude Code on the webでは、セッション一覧に未読/既読の状態が表示され、新しい更新があったセッションを一目で確認できます。しかし、セッションを既読にしたにもかかわらず、直後にまた未読マークが表示されてしまう不具合がありました。これはバックエンドの状態同期処理のタイミングに起因するもので、実際には新しい更新がないにもかかわらず未読扱いになってしまうため紛らわしいものでした。今回の修正でこの誤った未読への切り替わりが解消されました。

## 基本的な使い方
特別な操作は不要です。通常通りセッション一覧でセッションを開いたり既読にしたりするだけで、正しく既読状態が維持されるようになります。

## 実践例

### セッション一覧を巡回して確認する場合
複数のクラウドセッションを次々と開いて内容を確認していく際、既読にしたはずのセッションが後で見返すと再び未読マークに戻っている、といった混乱がなくなります。

### 通知バッジの信頼性向上
未読セッション数をもとに通知バッジなどを確認している場合も、実際に新しい更新があったセッションのみが正しく未読として扱われるようになり、通知の信頼性が向上します。

## 注意点
- この修正は表示上の同期タイミングに関するものであり、実際のセッション内容やメッセージ自体には影響しません。
