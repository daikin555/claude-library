## 原文（日本語訳）

Claude Tag管理設定で1つのワークスペース用に保存された自動参加チャンネルパターンが、Enterprise Grid組織全体インストールでは無視されていた不具合を修正しました。Claudeは現在、一致する新しいチャンネルに参加するようになります。

## 原文（英語）

[Claude Tag] Fixed auto-join channel patterns saved for one workspace in Claude Tag admin settings being ignored on an Enterprise Grid org-wide install; Claude now joins matching new channels

## 概要

Claude Tag（Slackの@Claude連携）には、特定のパターンに一致する名前の新しいチャンネルに自動的に参加する設定があります。しかし、Slack Enterprise Gridで組織全体にClaude Tagをインストールしている場合、個別のワークスペース向けに保存された自動参加チャンネルパターンが正しく適用されず、無視されてしまう不具合がありました。今回の修正で、Enterprise Grid環境でもこの自動参加パターンが正しく機能し、条件に一致する新しいチャンネルにClaudeが自動的に参加するようになりました。

## 基本的な使い方

Claude Tagの管理設定画面で自動参加チャンネルパターンを設定します（例: `proj-*` のようなパターン）。Enterprise Grid環境でも、この設定に従って新しいチャンネルへの自動参加が機能するようになります。

## 実践例

### 大規模組織でのチャンネル管理の自動化

多数のワークスペースを持つEnterprise Grid組織で、プロジェクトごとに作成される新しいチャンネルに自動的にClaudeを参加させ、手動でのチャンネル追加の手間を省けます。

### 命名規則に基づいたチーム展開

「`team-*`」のような命名規則でチームチャンネルを作成する運用の組織で、新しいチームが発足するたびに自動的にClaude Tagが有効になります。

## 注意点

- 自動参加パターンは組織のClaude Tag管理設定で事前に設定しておく必要があります
- Enterprise Gridを使用していない単一ワークスペース環境では、元々この不具合の影響を受けていませんでした
