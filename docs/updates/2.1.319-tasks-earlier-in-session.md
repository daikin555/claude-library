## 原文（日本語訳）
`/tasks` に「Earlier in this session」行を追加し、完了したサブエージェントを一覧表示します。一覧から消えた後や再起動後でも、再度開いてメッセージを送れます。

## 原文（英語）
Added an "Earlier in this session" row to `/tasks` that lists finished subagents, so you can reopen one and message it even after it leaves the list or you restart

## 概要
終わったサブエージェントを後から開き直し、追加の指示や質問を送れるようになりました。調査結果の深掘りに便利です。

## 基本的な使い方
```
/tasks
```
「Earlier in this session」行から対象のサブエージェントを選びます。

## 実践例

### 調査エージェントへの追質問
調査完了後に「この結果の根拠を詳しく」と続けて聞けます。

### 再起動後の続き
Claude Codeを再起動しても、セッションを再開すれば完了済みのサブエージェントを開けます。

## 注意点
- 対象は同じセッション内で実行された完了済みサブエージェントです。
