## 原文（日本語訳）

[VSCode] claude.ai/codeの一部のセッションが、VS Codeでメッセージが一つもない空の会話として開いてしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed some claude.ai/code sessions opening in VS Code as an empty conversation with no messages

## 概要

claude.ai/code（Claude Code on the web）で開始したセッションをVS Codeから続けて開く機能がありますが、一部のセッションで会話の履歴が正しく読み込まれず、メッセージが一切表示されない空の会話として開いてしまう不具合がありました。今回の修正により、対象のセッションでも会話履歴が正しく読み込まれ、これまでのやり取りを確認しながら作業を継続できるようになりました。

## 基本的な使い方

claude.ai/codeで作成したセッションをVS Code側から開く際は、セッション一覧やリンクから該当セッションを選択します。

```
> Claude Code: Open Session from claude.ai/code
```

## 実践例

### Webで開始したセッションをローカルのVS Codeで継続する場合

claude.ai/code上でタスクを開始し、その後ローカル環境で作業を続けたい場合に、VS Code側からそのセッションを開くケースです。

```
修正前: claude.ai/codeのセッションをVS Codeで開く → メッセージが一切表示されない空の会話になる
修正後: claude.ai/codeのセッションをVS Codeで開く → これまでの会話履歴が正しく表示される
```

### チームメンバーが開始したセッションを引き継ぐ場合

特定のセッションIDやリンクを共有された際、そのセッションの文脈（過去のやり取り）を正しく確認しながら作業を引き継げるようになります。

## 注意点

- この修正は一部のセッションに限定されていた不具合の解消であり、全てのセッションで発生していたわけではありません。
- 引き続き問題が発生する場合は、セッションを再読み込みするか、claude.ai/code側でセッション状態を確認してください。
