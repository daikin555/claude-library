## 原文（日本語訳）

`/code-review` の挙動が変更されました。Bedrock、Vertex AI、Foundry上で、Claudeアプリのゲートウェイ経由で、またテレメトリや非必須トラフィックが無効化されている環境でも、Claudeが自らこのコマンドを起動できるようになりました。

## 原文（英語）

Changed `/code-review` so Claude can also start it on its own on Bedrock, Vertex AI, and Foundry, through the Claude apps gateway, and when telemetry or non-essential traffic is disabled

## 概要

`/code-review` はこれまでユーザーが明示的にスラッシュコマンドを実行することが主な起動手段でしたが、一部の環境（Bedrock、Vertex AI、Foundry経由の利用、Claudeアプリのゲートウェイ経由の利用、テレメトリや非必須トラフィックを無効化している環境）では、Claudeが自律的にコードレビューを開始する機能が制限されていました。今回の変更により、これらの環境でもClaudeが状況に応じて自らコードレビューを開始できるようになり、利用環境に関わらずコードレビュー機能の恩恵を受けやすくなりました。

## 基本的な使い方

ユーザーが明示的に呼び出す場合は従来と同じです。

```
/code-review
```

加えて、対象の環境（Bedrock/Vertex AI/Foundry、Claudeアプリゲートウェイ、テレメトリ無効化環境など）であっても、変更内容がレビューに適したタイミングだとClaudeが判断した場合、ユーザーが明示的にコマンドを打たなくても自らコードレビューを提案・開始できるようになりました。

## 実践例

### 企業のBedrock/Vertex AI環境でのコードレビュー自動化

社内ポリシーでBedrockやVertex AI経由でのみClaude Codeを利用している組織でも、大きな変更をコミットする前にClaudeが自発的にレビューを提案できるようになり、レビュー忘れを減らせます。

### テレメトリを無効化したセキュアな環境での利用

セキュリティ要件からテレメトリや非必須な外部通信を無効化している環境では、これまで自動起動系の機能が制限されがちでしたが、`/code-review` の自律起動はこうした構成でも動作するようになりました。

### Foundryやアプリゲートウェイ経由の統合環境

社内ツールやFoundry経由でClaude Codeを組み込んで使っている場合でも、コードレビューの自律的な提案が一貫して機能するようになり、統合先の違いによる体験差が減ります。

## 注意点

- ユーザーが明示的に `/code-review` を実行する使い方自体に変更はありません。今回の変更は「Claudeが自ら開始できる範囲」の拡大です
- 自律的な起動であっても、実際のレビュー内容や提示方法は通常の `/code-review` と同様です
- 環境によってはネットワーク経路やゲートウェイの設定が起動可否に影響するため、想定どおり動作しない場合は組織の管理者にゲートウェイ設定を確認してください
