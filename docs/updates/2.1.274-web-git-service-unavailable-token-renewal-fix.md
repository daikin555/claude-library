## 原文（日本語訳）
[Claude Code on the web] GitHubのトークン更新処理が一時的にエラーになった際、クラウドセッションのGit操作が「service unavailable（サービス利用不可）」エラーで失敗していた問題を修正しました。

## 原文（英語）
[Claude Code on the web] Fixed git operations in cloud sessions failing with "service unavailable" when GitHub's token renewal briefly errors

## 概要
Claude Code on the webのクラウドセッションは、GitHubへのアクセスに一時的な認証トークンを使用しており、定期的に自動更新（renewal）されます。このトークン更新処理がGitHub側の一時的な不具合で数秒〜数十秒エラーになると、その間のGit操作（clone、pull、push、commitなど）が「service unavailable」エラーで失敗してしまう問題がありました。今回の修正により、こうした一時的なトークン更新エラーが発生してもGit操作が適切にリトライ・処理されるようになりました。

## 基本的な使い方
特別な操作は不要です。クラウドセッションで通常通りGit操作（コミットやプッシュなど）を行うだけで、内部的にトークン更新の一時的な不安定さが吸収されるようになります。

## 実践例

### コミット・プッシュ中の一時的なエラー回避
これまでは、セッション実行中にGitHub側のトークン更新が一時的にエラーになるタイミングでコミットやプッシュを実行すると、「service unavailable」というエラーメッセージが表示され、作業が中断されることがありました。修正後は、こうした一過性のエラーがユーザーに影響しにくくなっています。

### 長時間稼働するクラウドセッションでの安定性向上
長時間にわたって稼働するルーティンやセッションでは、その間に複数回トークンの更新が発生します。今回の修正により、そうした長時間セッションでもGit操作の信頼性が向上します。

## 注意点
- GitHub側の障害が長時間に及ぶ場合は、引き続きGit操作が失敗する可能性があります。
- この修正はクラウドセッション（Claude Code on the web）に特有のものです。ローカルのClaude Codeには直接関係しません。
