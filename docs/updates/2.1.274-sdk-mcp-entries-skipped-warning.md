## 原文（日本語訳）
`.mcp.json`、settings、プラグイン、エージェントファイル内の `"type": "sdk"` のMCPエントリが、警告とともにスキップされるように変更されました。インプロセスサーバーを登録できるのはSDKホストアプリケーションのみです。

## 原文（英語）
Changed `"type": "sdk"` MCP entries in `.mcp.json`, settings, plugins and agent files to be skipped with a warning: only an SDK host application can register in-process servers

## 概要
MCPサーバーの設定には `"type": "sdk"` というエントリタイプがあり、これはインプロセス（同一プロセス内）でMCPサーバーを動かすためのものです。しかし通常のClaude Code CLI環境ではインプロセスサーバーを登録できず、これまでこの種のエントリが設定ファイルにあると混乱を招くことがありました。今回の変更により、`.mcp.json`、settings、プラグイン、エージェントファイルに含まれる `"type": "sdk"` エントリは、Claude Code CLI上では警告メッセージとともに安全にスキップされるようになりました。

## 基本的な使い方
通常のCLIユーザーが意識する必要はありません。もし設定ファイルに誤って `"type": "sdk"` のエントリが含まれていた場合、そのエントリは無視され、警告が表示されます。

```json
{
  "mcpServers": {
    "my-inprocess-server": {
      "type": "sdk"
    }
  }
}
```

## 実践例

### 通常のCLIでの挙動
上記のような `"type": "sdk"` エントリを含む `.mcp.json` を通常のClaude Code CLIで読み込むと、そのサーバーはロードされず、代わりに「SDKホストアプリケーションのみが登録できます」といった趣旨の警告が表示されます。

### Agent SDKを使ったホストアプリケーションでの挙動
Claude Agent SDKを使って独自のホストアプリケーションを構築している場合は、そのアプリケーション内でインプロセスサーバーとして `"type": "sdk"` のエントリを正しく登録・利用できます。

## 注意点
- `"type": "sdk"` はプラグインが配布する `.mcp.json` にも影響するため、プラグイン作者は通常のCLI環境では動作しないことを認識しておく必要があります。
- 警告が表示された場合でも、他の通常のMCPサーバーエントリの読み込みには影響しません。
- インプロセスサーバーを利用したい場合は、Claude Agent SDKでホストアプリケーションを構築する必要があります。
