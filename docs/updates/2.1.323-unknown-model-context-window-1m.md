## 原文（日本語訳）

Claude Codeが認識しないモデルIDについて想定するコンテキストウィンドウを、200Kから1Mに変更しました。早めにコンパクトするには `/autocompact` を使い、200Kのままにするには `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` を設定してください。

## 原文（英語）

Changed the context window assumed for a model ID that Claude Code doesn't recognize from 200K to 1M; use `/autocompact` to compact earlier, or `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` to keep 200K

## 概要

ゲートウェイやサードパーティ経由で、Claude Codeが知らないモデルIDを使う場合の既定のコンテキストウィンドウが200Kから1Mになりました。ウィンドウの小さいモデルを使っていると、満杯になった後は `/clear` するまで毎ターン失敗する可能性があります。

## 基本的な使い方

```bash
# 200Kのままにする
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
claude
```

セッション中に早めに圧縮したい場合は `/autocompact` を使います。

## 実践例

### 小さいウィンドウの他社モデルを使う場合

セッションが埋まる前に環境変数を設定しておきます。

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

### 自動コンパクトの調整

```text
/autocompact
```

## 注意点

- 設定せずに小さいウィンドウのモデルを使うと、満杯後に全ターンが失敗することがあります
- 認識されるモデルIDには影響しません
