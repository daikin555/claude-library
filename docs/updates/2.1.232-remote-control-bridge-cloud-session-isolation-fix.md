## 原文（日本語に翻訳）

クラウドセッション内で稼働するブリッジによってホストされるRemote Controlセッションが、そのクラウドセッション自身のトランスクリプト（会話履歴）や認証情報を誤って継承してしまっていた問題を修正しました。

## 原文（英語）

Fixed Remote Control sessions hosted by a bridge inside a cloud session inheriting that session's transcript or credentials

## 概要

Remote Controlは、ローカルで動作しているClaude Codeセッションをモバイルアプリやブラウザから閲覧・操作できるようにする機能です。クラウド上で実行されるセッション内部でブリッジ経由のRemote Controlセッションをホストするケースにおいて、これまでは新しく開始されたRemote Controlセッションが、ホスト元のクラウドセッションが持つ会話履歴（トランスクリプト）や認証情報を誤って引き継いでしまう不具合がありました。これは、本来分離されているべきセッション間で機密情報が漏洩し得るセキュリティ上の問題です。今回の修正により、クラウドセッション内のブリッジがホストするRemote Controlセッションは、ホスト元のトランスクリプトや認証情報を継承しないようになりました。

## この変更が影響する場面

これは内部的なセキュリティ修正であり、新機能ではありません。以下のような場面で影響があります。

- クラウド環境（cloud session）上でClaude Codeを実行し、その内部でRemote Control用のブリッジを起動して別のセッションをホストする構成
- 複数のRemote Controlセッションを同じクラウド環境から扱っている場合の、セッション間のデータ分離

## 実践例

### クラウドセッションから独立したRemote Controlセッションの起動

```bash
# クラウドセッション内でRemote Controlブリッジを起動するケース
# 修正前:
# 新規にホストされたRemote Controlセッションが、
# ホスト元クラウドセッションの会話履歴や認証情報を
# 意図せず引き継いでしまう可能性があった

# 修正後:
# 新規セッションはホスト元のトランスクリプトや資格情報から
# 適切に分離された状態で開始される
```

### 複数ユーザー・複数セッションが関わる運用での安全性向上

チームで共有のクラウド実行環境を使い、それぞれが別々のRemote Controlセッションを開始するような運用において、他者のセッション情報が意図せず混入するリスクが解消されます。

## 注意点

- Claude Code v2.1.232で修正されたセキュリティ修正です。
- クラウドセッション内でRemote Controlブリッジをホストする構成を使っている場合に関係する修正です。通常のローカル環境から直接Remote Controlを利用しているだけのユーザーへの影響は限定的です。
- 本修正はセッション間の情報分離に関わる重要な修正のため、該当する構成で運用している場合は最新バージョンへのアップデートを推奨します。
