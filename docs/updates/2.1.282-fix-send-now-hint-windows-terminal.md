## 原文（日本語訳）

ctrl+enterを改行として送信するターミナル（1.25より前のWindows Terminalなど）で、即時送信のヒントがctrl+enterと表示されていた不具合を修正しました。該当ターミナルではctrl+x ctrl+sと表示されるようになりました。

## 原文（英語）

Fixed the send-now hint showing ctrl+enter on terminals that send it as a newline (Windows Terminal before 1.25); it now shows ctrl+x ctrl+s there

## 概要

Claude Codeでは、複数行入力中にすぐ送信したい場合のショートカットヒントが画面に表示されます。しかし、バージョン1.25より前のWindows Terminalでは `ctrl+enter` が改行として扱われてしまうため、ヒント通りに `ctrl+enter` を押しても送信されず改行が入るだけという、混乱を招く状態になっていました。今回の修正で、そうした環境では実際に機能する `ctrl+x ctrl+s` がヒントとして表示されるようになりました。

## 基本的な使い方

古いバージョンのWindows Terminalを使用している場合、画面下部に表示されるヒントに従って `ctrl+x` の後に `ctrl+s` を押すと、複数行の入力をすぐに送信できます。

## 実践例

### 古いバージョンのWindows Terminalを使い続けている環境

社内標準環境などでWindows Terminalのアップデートがすぐにできない場合でも、正しいショートカットが案内されるため迷わず操作できます。

### 複数行プロンプトを素早く送信したい場面

長い複数行の指示を入力した後、Enterキーでの改行を続けず、すぐに送信したい場合にヒント通りのショートカットが機能します。

## 注意点

- Windows Terminal 1.25以降を使用している場合は、従来通り `ctrl+enter` がヒントとして表示され、そのまま機能します
- この修正は表示されるヒントの正確性を改善するものであり、Windows Terminal自体のキー処理を変更するものではありません
