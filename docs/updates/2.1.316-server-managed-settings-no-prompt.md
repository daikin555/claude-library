# サーバー管理設定が承認プロンプトなしで適用される

## 原文（日本語訳）

- Team および Enterprise ログインのサーバー管理設定を変更：Anthropic の API から取得した設定は承認プロンプトなしで適用され、検証に失敗する保存済みコピーは拒否される

## 原文（英語）

- Changed server-managed settings for Team and Enterprise logins: settings fetched from Anthropic's API now apply without an approval prompt, and a stored copy that doesn't verify is refused

## 概要

Anthropic の API から取得した管理設定が、確認なしで適用されます。一方、保存済みの設定コピーが検証に通らない場合は拒否されます。

## 基本的な使い方

操作は不要です。Team / Enterprise でログインすると自動で適用されます。

## 実践例

### 管理者の視点

配布したポリシーが、開発者の承認操作を待たずに有効になります。検証に失敗するコピーは使われません。

## 注意点

- 管理設定の内容は、開発者へ事前に周知しておくことを推奨します。
