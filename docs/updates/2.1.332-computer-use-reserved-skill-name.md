# computer-use が予約スキル名に変更

## 原文（日本語に翻訳）

computer use が有効な Mac では `computer-use` が予約スキル名になりました。同名の独自スキルやコマンドは読み込まれなくなり、起動時に名前を変更するよう通知されます。

## 原文（英語）

Changed `computer-use` to a reserved skill name on Macs with computer use on: your own skill or command of that name stops loading, and a start-up notice says to rename it

## 概要

computer use 機能の組み込みスキルと名前が衝突しないよう、`computer-use` が予約名になりました。該当する独自スキルを持っている場合は、リネームが必要です。

## 基本的な使い方

独自の `computer-use` スキルがある場合は、ディレクトリ名を変更します。

```bash
mv .claude/skills/computer-use .claude/skills/my-computer-use
```

## 実践例

### 起動時の通知に対応する

通知が出たら、スキルのディレクトリ名（コマンドの場合はファイル名）と、`SKILL.md` の `name` を変更します。他のスキルから参照している場合は、その参照も更新してください。

## 注意点

- 影響があるのは computer use が有効な Mac のみです。
- リネームするまで、同名のスキルは読み込まれません。
