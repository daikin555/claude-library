## 原文（日本語訳）
[VSCode] 提案された変更の差分タブにおいて、各変更の下にaccept（承認）・reject（却下）ボタンを追加し、変更を1つずつレビューできるようにしました

## 原文（英語）
[VSCode] Added accept and reject buttons under each change in the proposed-change diff tab, so an edit can be reviewed change by change

## 概要
VS Code拡張機能で提案された編集内容を確認する差分（diff）タブに、個々の変更ブロックごとにaccept/rejectボタンが追加されました。これまでは編集全体をまとめて承認・却下する必要がありましたが、この機能により、ファイル内の複数の変更箇所を1つずつ吟味しながら、必要な変更だけを取り込むといった柔軟なレビューが可能になります。

## 基本的な使い方
Claudeが複数箇所を編集する提案を行った際、差分タブで各変更ブロックの下に表示されるボタンを使って個別に判断します。

```
# Claudeが1つのファイルに複数の変更を提案
# → 差分タブで各変更ブロックの下にAccept / Rejectボタンが表示される
# → 変更Aは承認、変更Bは却下、というように個別に選べる
```

## 実践例

### リファクタリング提案の一部だけを採用する
```
# 「この関数を分割して、命名も整理して」と依頼
# → 関数分割の変更はAccept、命名変更の一部はRejectして
#   自分の意図に合う変更だけを反映する
```

### 大きなファイルの一括編集を慎重にレビューする
```
# 大規模なファイルに対する複数箇所の編集提案を、
# 上から順に1ブロックずつAccept/Rejectしながら確認
# → 意図しない変更を混入させずに済む
```

## 注意点
- 変更ブロックの粒度は、提案された編集内容の構造に依存します。
- 一部だけを承認した場合、残りの提案が意図と整合するかは別途確認が必要です。
- この機能はVS Code拡張機能の差分タブに限定されます。
