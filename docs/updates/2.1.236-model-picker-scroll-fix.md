## 原文（日本語訳）

`/model` ピッカーが端末の高さを超えて表示されてしまう問題を修正しました。ウィンドウに収まる数のモデルのみを表示し、残りはスクロールして閲覧できるようになりました。

## 原文（英語）

Fixed the `/model` picker rendering taller than the terminal: it now shows only as many models as fit the window, with the rest reachable by scrolling

## 概要

`/model` コマンドは、利用可能なモデルの一覧から使用するモデルを選択するためのピッカーUIを表示します。これまでは選択可能なモデルの数が多い環境では、ピッカー全体の高さが端末（ターミナル）の表示領域を超えてしまい、リストの一部やUIの一部が画面からはみ出して見えなくなったり、レイアウトが崩れたりすることがありました。今回の修正により、ピッカーは端末の高さに収まる件数だけを表示し、それ以上のモデルは矢印キーなどでスクロールして確認できるようになりました。

## 基本的な使い方

`/model` コマンドを実行するだけで、以前と同じ操作感でモデルを選択できます。表示しきれないモデルがある場合は、上下キーでリストをスクロールして選べます。

```
/model
```

修正前は、端末のウィンドウサイズが小さい場合や選択肢が多い場合にピッカーがウィンドウをはみ出し、一部の項目が見えない、または画面表示が乱れることがありました。修正後は常にウィンドウ内に収まるようにリストが調整され、はみ出した項目はスクロールでアクセスできます。

## 実践例

### 小さめのターミナルウィンドウで作業している場合

ノートPCの小さなターミナルペインや、tmux/iTerm2などで画面を複数分割して作業している場合、`/model` を実行してもピッカー全体が画面からはみ出さず、収まりきる範囲だけが表示されます。矢印キーでスクロールすれば残りのモデルも確認できます。

### 選択可能なモデルの数が多い環境

組織のポリシーやプラン内容によって選択できるモデルの候補が多い場合でも、ピッカーの表示が崩れることなく、必要な分だけスクロールして目的のモデルを選べます。

## 注意点

- モデルの選択操作自体（矢印キーでの移動、Enterでの確定など）に変更はなく、表示のはみ出しが解消されただけです。
- 非常に小さいターミナルサイズでは、スクロール可能であることを示すインジケーターの見え方が環境によって異なる場合があります。
