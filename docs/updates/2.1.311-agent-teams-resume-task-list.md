## 原文（日本語に翻訳）

`--resume`、`--continue`、`/resume`、`--session-id` で戻った際（`/clear` やクラッシュの後を含む）にagent teamsセッションのタスクリストが空になる問題と、`/branch` が元のセッションのリストに書き込む問題を修正しました。

## 原文（英語）

Fixed agent teams sessions showing an empty task list when coming back with `--resume`, `--continue`, `/resume` or `--session-id`, including after `/clear` or a crash, and `/branch` writing to the original session's list

## 概要

agent teamsのセッションを再開すると、タスクリストが空に見える問題がありました。この修正で再開後もタスクリストが復元されます。また `/branch` で分岐したセッションが、元のセッションのタスクリストを書き換えることもなくなりました。

## 基本的な使い方

```bash
claude --resume
claude --continue
claude --resume <session-id>
```

## 実践例

### 中断した作業の再開

```bash
claude --continue
```

前回のタスクの進捗を保ったまま続けられます。

### 分岐して別案を試す

```text
/branch
```

分岐先でタスクを変更しても、元のセッションのリストは影響を受けません。

## 注意点

- 以前のバージョンで作成したセッションの挙動は、環境により異なる場合があります。
