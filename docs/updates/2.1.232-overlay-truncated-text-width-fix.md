## 原文（日本語に翻訳）

切り詰められたテキストを含むコンテンツサイズのオーバーレイが1カラム分幅を超えて描画される問題と、先頭側が切り詰められたテキストが省略記号のみに潰れて表示される問題を修正しました。

## 原文（英語）

Fixed content-sized overlays containing truncated text rendering one column too wide, and start-truncated text collapsing to an ellipsis

## 概要

Claude CodeのターミナルUIには、内容量に応じてサイズが決まる「オーバーレイ」（ダイアログやポップアップ的な表示領域）があり、長いテキストは省略記号（…）を使って切り詰めて表示されます。今回の修正前は、このようなオーバーレイの幅が本来より1カラム分広く描画されてしまう問題と、テキストの先頭側を切り詰める表示（例: 長いファイルパスの先頭を省略する場合）が正しく機能せず、省略記号だけに潰れてしまう問題がありました。本アップデートによりこれらの表示崩れが修正され、オーバーレイの幅とテキストの切り詰め表示が正しく描画されるようになりました。

## 基本的な使い方

これはターミナルUIの描画に関する内部的な修正であり、特別な操作は不要です。長いファイルパスやテキストを表示するオーバーレイが表示される場面すべてに影響します。

```text
# 修正前:
# - オーバーレイの右端が1カラム分はみ出して表示崩れが起きる
# - 先頭を省略すべきテキストが「…」のみになり内容が読めない

# 修正後:
# - オーバーレイの幅が正しく描画される
# - 先頭省略テキストも末尾部分が正しく表示される（例: "…/src/components/Button.tsx"）
```

## 実践例

### 長いファイルパスを含む確認ダイアログを表示する場合

深い階層のディレクトリにあるファイルを編集・削除する際など、パスの先頭側を省略して末尾（ファイル名部分）を優先的に見せたい表示があります。以前はこの先頭省略の処理に不具合があり、パス全体が単に「…」とだけ表示されてしまい、どのファイルを操作しようとしているのか分からなくなることがありました。修正後は、末尾のファイル名を含む形で正しく省略表示されるため、確認ダイアログの内容を正確に把握できます。

```text
例: /home/user/projects/very-long-project-name/src/components/deeply/nested/Button.tsx

修正前: …
修正後: …/deeply/nested/Button.tsx
```

### 内容量に応じてサイズが変わるオーバーレイをナローターミナルで表示する場合

ターミナル幅が狭い環境や、内容によって幅が動的に変わるオーバーレイ（設定確認やツール実行結果のプレビューなど）を表示する際、以前は右端が1カラム分はみ出し、枠線が崩れたりテキストが折り返されて見づらくなることがありました。修正後はオーバーレイの幅計算が正しくなり、ターミナル幅に対して適切にレイアウトされるため、表示崩れなく内容を確認できます。

```text
修正前: オーバーレイの右端が1カラムはみ出し、枠線がずれる
修正後: オーバーレイが正しい幅で描画され、枠線・テキストが崩れない
```

## 注意点

- Claude Code v2.1.232での修正です。ターミナルUIの描画に関する修正であり、機能面の変更はありません。
- 利用しているターミナルエミュレータやフォントによっては、文字幅の計算に若干の差異が生じる場合があります。症状が残る場合はターミナルの設定やフォントも確認してください。
- フルスクリーンレンダリングモードを利用している場合も本修正の対象です。
