# claude mcp add/remove の設定ロック対応

## 原文（日本語訳）

- `claude mcp add` と `remove` がロックなしで設定を書き込んでいた問題を修正しました。ロックを待つか、終了コード1で終了します。ただし別ジョブの保存で保存済みサーバーが置き換わる可能性は残ります
- MCPツールのエラーを改善しました。ツールの読み込み前に呼び出した場合、入力スキーマが返されます

## 原文（英語）

- Fixed `claude mcp add` and `remove` writing the config without its lock: they now wait for it or exit 1, though another job's save can still replace a saved server
- Improved MCP tool errors: a call made before the tool is loaded now returns its input schema

## 概要

MCPサーバーの追加・削除時に設定ファイルのロックを尊重するようになり、同時実行による設定破損を減らせます。また未読み込みツールの呼び出しエラーに入力スキーマが含まれ、Claudeが正しい引数で再試行しやすくなります。

## 基本的な使い方

```bash
claude mcp add my-server -- npx -y my-mcp-server
claude mcp remove my-server
```

## 実践例

### 自動セットアップスクリプト

ロック取得に失敗すると終了コード1になるため、リトライ処理を入れると安全です。

```bash
for i in 1 2 3; do
  claude mcp add my-server -- npx -y my-mcp-server && break
  sleep 1
done
```

### ツール呼び出しエラーの改善

ツールが未読み込みの状態で呼び出しても、エラーに入力スキーマが含まれるため、Claudeが引数を修正して再実行できます。

## 注意点

- 並列実行時は終了コードを必ず確認してください。
- 完全な排他は保証されないため、並列で設定を変更する運用は避けるのが無難です。
