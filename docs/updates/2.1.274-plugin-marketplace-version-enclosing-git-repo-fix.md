## 原文（日本語訳）
それ自体のgitリポジトリを持たないプラグインやマーケットプレイスのディレクトリが、`~/.claude` のようなgit管理された外側のディレクトリからバージョン情報を取得してしまう問題を修正しました。

## 原文（英語）
Fixed a plugin or marketplace directory with no git repository of its own taking its version from an enclosing git repository, such as a git-managed `~/.claude`

## 概要
Claude Codeのプラグインやマーケットプレイスのバージョン情報は、通常そのディレクトリ自身のgitリポジトリから取得されます。しかし、プラグインやマーケットプレイスのディレクトリ自体がgitリポジトリではない場合、`~/.claude` のようにそれを内包する外側のディレクトリがgit管理されていると、誤ってその外側のリポジトリのバージョン情報を取得してしまう不具合がありました。これにより、実際のプラグインの状態と異なるバージョンが表示されることがありました。今回の修正により、プラグイン自体がgitリポジトリでない場合は、外側のリポジトリの情報を誤って使用しないようになりました。

## 基本的な使い方
プラグインやマーケットプレイスの状態は通常通りのコマンドで確認できます。

```
/plugin
```

## 実践例

### 修正前の挙動
`~/.claude` ディレクトリ全体をgitで管理している環境で、個別のgitリポジトリを持たないプラグインを導入すると、そのプラグインのバージョンとして `~/.claude` 全体のgit状態（コミットハッシュなど）が誤って表示されることがありました。

### 修正後の挙動
同じ環境でも、プラグイン自体がgitリポジトリを持たない場合は、外側のリポジトリの情報を誤って参照することなく、正しいバージョン情報（またはバージョン不明である旨）が扱われるようになりました。

## 注意点
- `~/.claude` ディレクトリ全体をgit管理している場合は、この修正の影響を受けやすい構成です。
- プラグインを配布する際は、可能であればプラグイン自体を独立したgitリポジトリとして管理することが推奨されます。
