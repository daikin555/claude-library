# claude --desktop で Claude デスクトップアプリを開く

## 原文（日本語訳）

- `claude --desktop` を追加しました。現在のディレクトリで Claude デスクトップアプリを開きます。`--continue` / `--resume <id>` と併用すると該当セッションで開きます

## 原文（英語）

- Added `claude --desktop` to open the Claude desktop app on the current directory, or on a session with `--continue` / `--resume <id>`

## 概要

ターミナルで作業中のディレクトリやセッションを、そのまま Claude デスクトップアプリで開けるようになりました。CLI から GUI へ作業を引き継ぐ際に便利です。

## 基本的な使い方

```bash
cd ~/projects/my-app
claude --desktop
```

## 実践例

### 直前のセッションをデスクトップで続ける

```bash
claude --desktop --continue
```

### 特定のセッションを指定して開く

```bash
claude --desktop --resume <session-id>
```

## 注意点

- Claude デスクトップアプリがインストールされている必要があります。
- セッション ID は `claude --resume` の一覧などで確認できます。
