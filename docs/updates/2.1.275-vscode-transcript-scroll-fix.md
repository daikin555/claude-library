## 原文（日本語訳）
[VSCode] 権限カードが表示された状態でコンテンツが届き続けている間、トランスクリプトが少しずつ下にずれていく不具合を修正しました

## 原文（英語）
[VSCode] Fixed the transcript creeping toward the bottom in small steps while a permission card waits and content keeps arriving

## 概要
VS Code拡張機能で権限確認カードが表示され、ユーザーの回答を待っている間にも、Claudeからのストリーミング出力が届き続けると、トランスクリプト（会話ログ）の表示位置が少しずつ下にずれていく不具合がありました。これにより、権限カードや直前のやり取りが見えにくくなることがありました。今回の修正でこの現象が解消され、権限確認待ちの間も表示位置が安定するようになります。

## 基本的な使い方
特別な操作は不要です。権限プロンプトが表示された状態でClaudeが出力を続けても、表示スクロール位置が意図せずずれなくなります。

```
# 例: 「このコマンドを実行してよいですか？」という権限カードが表示され、
# その間もClaudeが説明テキストなどを出力し続けている
# → 修正前: トランスクリプトが少しずつ下にずれ、
#   カードや文脈が見えにくくなることがあった
# → 修正後: 表示位置が安定し、権限カードが見やすい位置に留まる
```

## 実践例

### 長い出力と権限確認が同時に発生する場面
```
「複数のファイルを分析して、危険な操作の前には確認して」
# → 分析結果の出力が続く間も権限カードの表示位置がずれず、
#   落ち着いて確認・回答できる
```

### レビュー中にスクロール位置を見失わない
```
# 権限確認を待っている間に他の出力が流れてきても、
# 画面が勝手にスクロールしてカードを見失うことがなくなる
```

## 注意点
- これはUIの表示に関するバグ修正であり、権限確認の判断ロジックや承認/拒否の挙動自体には影響しません。
- VS Code拡張機能限定の修正です。
- 極端に長い出力が続く場合の表示挙動については、引き続き改善の余地がある可能性があります。
