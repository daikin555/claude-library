# ツール指定に不完全なルールがある場合の起動時警告

## 原文（日本語に翻訳）

`--allowedTools`、`--disallowedTools`、`--tools` の値に、完全なルールに見えない項目がある場合、起動時に警告を表示するようになりました。

## 原文（英語）

Added a startup warning when an `--allowedTools`, `--disallowedTools` or `--tools` value has an entry that doesn't look like a complete rule

## 概要

ツール指定フラグのタイプミスや書式ミスは、気づかないまま権限ルールが効かない原因になります。v2.1.326 では、不完全に見える項目があると起動時に警告が表示され、早期に誤りに気づけます。

## 基本的な使い方

```bash
claude --allowedTools "Bash(git status:*)" "Read"
```

## 実践例

### 引用符の付け忘れを検出する

```bash
# 引数が分割されて意図しないルールになる例
claude --allowedTools Bash(git diff:*)
```

シェルによって括弧が解釈されると不完全なルールになります。ルールは引用符で囲みましょう。

### CI スクリプトの見直し

`claude -p` を使う CI のスクリプトで警告が出ていないか確認し、ルールを修正します。

## 注意点

- 警告は注意喚起であり、判定は「完全なルールに見えるか」に基づきます。
- 同バージョンでは、リスト型オプションの後に置いたプロンプトが黙って捨てられる問題も修正されています。
