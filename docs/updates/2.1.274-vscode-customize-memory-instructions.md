## 原文（日本語訳）
CustomizeメニューにMemoryとInstructionsのエントリが追加されました。Memoryは自動メモリのトグル、保存されたメモリ、メモリフォルダを表示し、Instructionsは CLAUDE.md ファイルを編集します。

## 原文（英語）
[VSCode] Added Memory and Instructions entries to the Customize menu: Memory shows the auto-memory toggles, the saved memories and the memory folders, and Instructions edits the CLAUDE.md files

## 概要
VSCode拡張機能のCustomizeメニューに、新たに「Memory」と「Instructions」という2つのエントリが追加されました。「Memory」からは自動メモリ機能のオン/オフ切り替え、これまで保存されたメモリ内容、メモリが保存されているフォルダを一覧で確認できます。「Instructions」からはプロジェクトの `CLAUDE.md` ファイルを直接編集できるようになり、プロジェクトのルールやコンテキストをGUIから素早く調整できるようになりました。

## 基本的な使い方
VSCode拡張機能のCustomizeメニューを開き、「Memory」または「Instructions」を選択します。

```
VSCode: Claude Codeアイコン → Customize → Memory / Instructions
```

## 実践例

### 保存されたメモリを確認・管理したい場合
Customizeメニューの「Memory」を開くと、自動メモリのオン/オフ、これまで保存された個々のメモリ、メモリファイルが格納されているフォルダが一覧表示されます。不要なメモリの整理や自動メモリ機能の一時停止をGUIから行えます。

### CLAUDE.mdを素早く編集したい場合
Customizeメニューの「Instructions」を開くと、現在のプロジェクトの `CLAUDE.md` ファイルが編集画面に表示されます。ターミナルやエディタで別途ファイルを探す手間なく、プロジェクトルールを直接更新できます。

## 注意点
- 「Memory」で表示される内容は自動メモリ機能によって保存されたものと、ユーザーが手動で保存したものの両方を含みます。
- 「Instructions」編集はプロジェクトの `CLAUDE.md` を直接書き換えるため、変更内容はチーム全体に影響する可能性がある点に注意してください。
