## 原文（日本語に翻訳）

PowerShellで実行されるフックが、プログラムの終了コード2でブロックしない問題を修正しました。またWindowsで、Git for Windowsが未インストールの場合に `"shell": "powershell"` の `PreToolUse`・`PermissionRequest` フックがフェイルオープンする問題も修正しました

## 原文（英語）

Fixed hooks that run in PowerShell not blocking when the hook's program exits with code 2, and on Windows `PreToolUse` and `PermissionRequest` hooks with `"shell": "powershell"` failing open when Git for Windows isn't installed

## 概要

フックは終了コード2でツール実行をブロックできますが、PowerShell経由ではこれが効かない場合がありました。また、Git for Windows未導入のWindowsでは、PowerShell指定の `PreToolUse` / `PermissionRequest` フックが失敗時に通過（フェイルオープン）していました。いずれも修正され、ガードレール用途で安心して使えます。

## 基本的な使い方

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          { "type": "command", "shell": "powershell", "command": "./check.ps1" }
        ]
      }
    ]
  }
}
```

```powershell
# check.ps1
if ($env:SOMETHING_DANGEROUS) {
  [Console]::Error.WriteLine("blocked")
  exit 2   # ツール実行をブロック
}
```

## 実践例

### 危険コマンドのブロック

`exit 2` と標準エラー出力の理由で、Claudeにブロック理由を伝えられます。
