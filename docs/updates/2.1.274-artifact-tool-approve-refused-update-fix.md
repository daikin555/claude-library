## 原文（日本語訳）
Artifactツールが、セッションが最新バージョンを読み込んでいなかったために結局拒否することになる更新に対して、承認を求めてしまう問題を修正しました。

## 原文（英語）
Fixed the Artifact tool asking you to approve an update to an artifact that it then refused because the session had not read the latest version

## 概要
Artifactツールを使ってアーティファクト（生成物）を更新する際、セッションがそのアーティファクトの最新バージョンをまだ読み込んでいない状態だと、更新は本来失敗するはずです。しかし従来は、その失敗が起きるにもかかわらずユーザーに更新の承認を求めるという無駄なステップが発生していました。今回の修正により、最新バージョンを読み込んでいないことが事前にわかっている場合は、無意味な承認プロンプトを表示せずに適切に処理されるようになりました。

## 基本的な使い方
アーティファクトを更新する際は、通常のワークフロー通りに操作します。

```
Claudeにアーティファクトの更新を依頼する
→ 必要に応じて最新バージョンの読み込みが行われる
→ 更新の承認を求められる（実際に適用可能な場合のみ）
```

## 実践例

### 修正前の挙動
セッションがアーティファクトの最新バージョンを未読のまま更新を試みると、ユーザーに承認を求めるダイアログが表示されるものの、承認後に「最新版を読んでいない」という理由で更新が拒否され、ユーザーの操作が無駄になっていました。

### 修正後の挙動
同じ状況では、無意味な承認プロンプトが減り、必要に応じて最新バージョンを読み込んでから更新が進むようになりました。

## 注意点
- 複数人（チームメイト）が同じアーティファクトを編集している環境では、最新版の同期状態が特に重要です。
- 更新が反映されない場合は、セッションがアーティファクトの最新バージョンを参照しているか確認してください。
