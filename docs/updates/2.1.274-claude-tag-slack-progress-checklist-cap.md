## 原文（日本語訳）

[Claude Tag] Slack上でのClaudeのライブ進捗チェックリストを改善しました。2,000文字を上限とし、活発なスレッドでは最大15分に1回まで再投稿されるようにし、古い「Latest task list」リンクも更新されるようにしました。

## 原文（英語）

[Claude Tag] Improved Claude's live progress checklist in Slack: capped at 2,000 characters, reposted at most every 15 minutes in busy threads, with older "Latest task list" links updated

## 概要

Claude Tag（SlackでのClaude）は、タスクを実行している間、進捗状況をチェックリスト形式でSlackスレッドに投稿します。これまでこのチェックリストは文字数の制限がなく、活発なスレッドでは頻繁に再投稿されることでスレッドが読みにくくなる問題がありました。今回の改善で、チェックリストは2,000文字に制限され、再投稿の頻度も最大15分に1回までに抑えられるようになりました。また、過去の投稿にある「Latest task list」へのリンクも常に最新の状態を指すよう更新されます。

## 基本的な使い方

特別な操作は不要です。Claude Tagにタスクを依頼すると、進捗チェックリストが自動的にこのルールに従って投稿・更新されます。

```
@Claude このリポジトリのテストを全部実行して、失敗したものを修正して
```

## 実践例

### 長時間かかるタスクでの進捗確認

大規模なリファクタリングなど、多くのステップを伴うタスクを依頼した場合、チェックリストが2,000文字を超えないように要約され、読みやすさが保たれます。

```
@Claude 全モジュールのリンターエラーを修正して
```

### 活発なスレッドでの再投稿抑制

複数人が同時に会話しているスレッドでタスクを依頼した場合でも、チェックリストの再投稿は最大15分に1回に制限されるため、スレッドが進捗更新で埋め尽くされることがなくなります。

### 「Latest task list」リンクの追跡

スレッド内で複数回チェックリストが更新された場合、過去の投稿にある「Latest task list」というリンクをクリックすると、常に最新のチェックリストに移動できます。

## 注意点

- チェックリストが2,000文字を超える内容になる場合、一部が省略されることがあります
- 再投稿頻度の制限はあくまで「busy thread（活発なスレッド）」を対象としたものです
