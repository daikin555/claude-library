## 原文（日本語訳）

Ctrl+Cで消去したプロンプトの復旧機能を追加した。空のプロンプトで↑キーを押すと、貼り付けたテキストや画像を含む下書きが戻る。

## 原文（英語）

Added recovery for a prompt cleared with Ctrl+C: pressing Up on the empty prompt brings the draft back, including pasted text and images

## 概要

長いプロンプトを入力中に誤って `Ctrl+C` を押して消してしまっても、空になった入力欄で `↑` を押せば下書きを取り戻せるようになりました。貼り付けたテキストや画像も復元されます。

## 基本的な使い方

1. プロンプトを入力する
2. `Ctrl+C` でクリアする
3. 空のプロンプトで `↑` を押す

## 実践例

### 誤操作からの復帰

詳細な指示を書いている途中で `Ctrl+C` を押してしまった場合に、書き直さずに復元できます。

### 画像付きプロンプトの再利用

スクリーンショットを貼り付けたプロンプトをクリアしても、`↑` で画像ごと戻せます。

## 注意点

- 復元は「空のプロンプト」で `↑` を押した場合に行われます。
- 通常の履歴移動と同じ `↑` キーを使うため、復元対象は直前にクリアした下書きです。
