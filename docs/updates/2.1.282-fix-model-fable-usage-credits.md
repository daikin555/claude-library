## 原文（日本語訳）

プランが利用クレジットをまだ有効にしていない場合に、フルのFableモデルIDを指定した `/model` がAPIエラーで停止し、利用クレジットのプロンプトが開かなかった不具合を修正しました。

## 原文（英語）

Fixed `/model` with a full Fable model id stopping at an API error instead of opening the usage-credits prompt when the plan needs usage credits that aren't turned on yet

## 概要

`/model` コマンドでモデル名を省略形ではなくフルのモデルID（例: `claude-fable-5-1` のような完全な識別子）で指定した場合、そのプランが利用クレジットをまだ有効にしていないと、本来表示されるべき利用クレジット有効化のプロンプトが表示されず、単にAPIエラーで処理が止まってしまう不具合がありました。今回の修正で、フルモデルID指定時でも正しく利用クレジットのプロンプトが開くようになりました。

## 基本的な使い方

```
/model claude-fable-5-1
```

利用クレジットが未設定の場合、有効化を促すプロンプトが正しく表示されるようになります。

## 実践例

### スクリプトやドキュメントからのモデル指定

社内ドキュメントやスクリプトでフルモデルIDを共有・コピー&ペーストして `/model` に渡すような運用でも、利用クレジット未設定時に分かりやすい案内を受けられます。

### 新しいプランでの初回セットアップ

Fableモデルを初めて使うユーザーが `/model` にフルIDを指定した際、エラーで戸惑うことなく、利用クレジットの有効化手順に自然に誘導されます。

## 注意点

- 省略形のモデル名を指定した場合はこの不具合の影響を受けていませんでした。フルモデルID指定時特有の問題です
- 利用クレジットの有効化自体はプランの契約内容に依存します
