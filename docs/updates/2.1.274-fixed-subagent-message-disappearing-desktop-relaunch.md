## 原文（日本語訳）
サブエージェントがメインセッションに送ったメッセージが、Claude Desktopの再起動後にトランスクリプト（会話履歴）から消えてしまっていた問題を修正。

## 原文（英語）
Fixed a message a subagent sends to the main session disappearing from the Claude Desktop transcript after a relaunch

## 概要
Claude Codeではサブエージェント（Agentツールで起動した子エージェント）が処理結果をメインセッションに報告するメッセージを送ります。これまでは、Claude Desktopアプリを再起動すると、こうしたサブエージェントからの報告メッセージが会話履歴（トランスクリプト）から欠落してしまうことがありました。今回の修正により、Claude Desktopを再起動してもサブエージェントからのメッセージが正しく保持されるようになりました。

## 基本的な使い方
特別な操作は不要です。Claude Desktopでサブエージェントを使った作業を行った後にアプリを再起動しても、これまでの会話履歴がそのまま保持されます。

```bash
# サブエージェントを使うタスクの例（Claude Desktop上での操作）
"このリポジトリ全体を調査してAgentツールでレポートして"
```

## 実践例

### 長時間のサブエージェント調査後にアプリを再起動した場合
複数のサブエージェントに調査を依頼し、その結果を確認する前にClaude Desktopを再起動してしまうケースでは、以前はサブエージェントの報告内容が失われ、再度調査をやり直す必要がありました。修正後は再起動後も報告内容がトランスクリプトに残るため、作業を中断しても安心です。

### 過去のセッション履歴を後から見返す場合
過去に実行したサブエージェントタスクの結果を後日見返したいときも、Desktopアプリの再起動をまたいで履歴が保持されるようになったことで、確実に記録を追えるようになりました。

## 注意点
- 修正が適用される前のバージョンで既に失われてしまった過去のメッセージは復元されません。
- Claude Code CLI（ターミナル版）ではこの問題は該当せず、主にClaude Desktopアプリでの再起動時の挙動に関する修正です。
