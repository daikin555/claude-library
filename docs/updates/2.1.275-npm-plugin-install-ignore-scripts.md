## 原文（日本語訳）
npmソースからインストールされるプラグインの取得方法を変更：`npm pack --ignore-scripts` を使い、整合性検証（integrity verification）を行うようにしました。これにより、パッケージのインストールスクリプトが実行されなくなります

## 原文（英語）
Changed plugins installed from an npm source to be fetched with `npm pack --ignore-scripts` and integrity-verified, so a package's install scripts no longer run

## 概要
npm上で公開されているパッケージには、インストール時に自動実行される`preinstall`/`install`/`postinstall`などのライフサイクルスクリプトを含められます。悪意あるパッケージがこれを悪用すると、インストールするだけで任意のコードが実行されるサプライチェーン攻撃のリスクがあります。今回の変更により、npmソースからプラグインを取得する際は`npm pack --ignore-scripts`が使われ、加えて取得したパッケージの整合性（integrity）が検証されるようになりました。これにより、プラグインをインストールするだけでは、パッケージに含まれるインストールスクリプトが実行されなくなり、安全性が向上します。

## 基本的な使い方
プラグインのインストール操作自体は変わりません。内部的な取得方法がより安全になります。

```
/plugin install some-plugin --source npm
# → npm pack --ignore-scripts で取得され、整合性検証が行われる
# → パッケージ内のinstallスクリプトは実行されない
```

## 実践例

### サードパーティ製npmプラグインを安全にインストールする
```
/plugin install community-tool --source npm
# → プラグイン自体の機能（JavaScriptコード等）は通常どおり利用できるが、
#   パッケージのインストールスクリプトによる副作用は発生しない
```

### 整合性検証によって改ざんされたパッケージを防ぐ
```
# npmレジストリとローカルで取得した内容の整合性が検証されるため、
# 途中で内容が改ざんされたパッケージはインストール時に検知される
```

## 注意点
- プラグインの動作自体がインストールスクリプトの実行に依存している場合、そのプラグインは意図通りに動作しない可能性があります。
- これはセキュリティ強化のための変更であり、通常の正当なプラグインの利用には影響しないことが期待されます。
- npm以外のソース（ローカルパスやGitなど）からのインストール方法については、別途確認が必要です。
