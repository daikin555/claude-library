## 原文（日本語に翻訳）

`/review` を `/code-review` のエイリアスに変更した。`/code-review` は現在の差分、または `/code-review <level> <pr#>` の形式でPRをレビューできる。深いクラウドレビューを行うには `/code-review ultra` を使用する。

## 原文（英語）

Changed `/review` to be an alias of `/code-review`, which reviews the current diff or a PR (`/code-review <level> <pr#>`); use `/code-review ultra` for a deep cloud review

## 概要

これまで `/review` と `/code-review` は別々のコマンドでした。`/review`（内部的にはultrareviewとも呼ばれる）はGitHub PRに対する単発の読み取り専用レビューを行うコマンドで、`/code-review` はローカルの差分をエージェントが並列レビューするコマンドでした。v2.1.223からは `/review` が `/code-review` のエイリアスとなり、両者は統合されました。`/code-review` はブランチの上流に対する未プッシュのコミットと作業ツリーの未コミット変更をデフォルトでレビューしますが、ファイルパス・PR番号・ブランチ名・`main...my-feature` のようなref範囲を対象として指定することもできます。さらに深い分析が必要な場合は `/code-review ultra` を使うことで、Anthropicのクラウドインフラ上でマルチエージェントによる本格的なレビュー（ultrareview）を実行できます。

## 基本的な使い方

引数なしで実行すると、現在のブランチのコミットと作業ツリーの変更をレビューします。

```text
/code-review
```

PRをレビューする場合は、effortレベルとPR番号を指定します。

```text
/code-review high 1234
```

より深いクラウドレビューを行いたい場合は `ultra` を指定します。

```text
/code-review ultra
```

## 実践例

### ブランチ名やref範囲を指定してレビューする

特定のファイルやブランチ間の差分だけをレビューしたい場合は、対象を明示的に指定します。

```text
/code-review main...my-feature
```

```text
/code-review src/auth/session.ts
```

### PR番号を指定してレビューし、指摘をコメントとして投稿する

GitHub上のPRをレビューし、その結果をインラインコメントとして投稿したい場合は、PR番号と `--comment` フラグを組み合わせます。

```text
/code-review high 1234 --comment
```

### `/code-review ultra` でクラウドの深いレビューを実行する

より高い精度が求められる重要な変更では、`ultra` を指定してクラウド上のultrareviewを実行し、`--fix` で結果を自動的に作業ツリーへ適用できます。

```text
/code-review ultra --fix
```

デフォルトブランチ以外と比較したい場合は、比較対象のブランチ名を続けて指定します。

```text
/code-review ultra develop
```

CIやスクリプトから非対話的に呼び出す場合は次のようにします。

```bash
claude -p '/code-review ultra'
```

## 注意点

- `/review` は `/code-review` のエイリアスになったため、v2.1.223より前のバージョンで `/review` が行っていた「PRの単発・読み取り専用レビュー」とは挙動が異なります。旧来の `/review` の挙動に慣れている場合は、`/code-review <level> <pr#>` の形式に読み替えてください。
- `ultra` はclaude.aiアカウントでの認証が必要で、Amazon Bedrock・Google Cloud's Agent Platform・Microsoft Foundry、およびZero Data Retentionが有効な組織では利用できません。利用できない環境では、`/code-review ultra` はローカルでのレビューにフォールバックします。
- `ultra` を指定しない場合、effortレベルとフラグ以降の文字列はすべてレビュー対象として扱われます（他のコマンド名で始まっていても同様）。`ultra` を指定した場合は、単語1つならブランチ名やPR番号として、それ以外の長い文章はレビューへのメモとして扱われます。
- レビューはデフォルトでバックグラウンドのサブエージェントとして実行され、`--fix` による編集はセッションのチェックポイント（`/rewind`）の対象外になるため、元に戻す場合はgitを使用する必要があります。
- ultrareviewの課金が発生する場合、対話的なセッションでの利用確認が必要になるため、非対話モードでは `claude ultrareview` サブコマンドを使用する必要があります。
