## 原文（日本語訳）
`CLAUDE_CODE_RESUME_INTERRUPTED_TURN` を使ってローカルで起動した `claude -p --resume` が、前のプロセスが残した未完了のバックグラウンドタスクを報告しない問題を修正しました。

## 原文（英語）
Fixed a local `claude -p --resume` started with `CLAUDE_CODE_RESUME_INTERRUPTED_TURN` not reporting background tasks the previous process left unfinished

## 概要
`CLAUDE_CODE_RESUME_INTERRUPTED_TURN` 環境変数は、中断されたターンを再開する際に使われます。この環境変数を指定して `claude -p --resume` をローカルで実行した場合、前のプロセスが未完了のまま残していたバックグラウンドタスクの情報が新しいプロセスに引き継がれず、ユーザーに報告されない不具合がありました。今回の修正により、再開後のプロセスが未完了のバックグラウンドタスクを正しく検出・報告するようになりました。

## 基本的な使い方
環境変数を設定した上で、中断されたセッションを再開します。

```bash
CLAUDE_CODE_RESUME_INTERRUPTED_TURN=1 claude -p --resume <session-id>
```

## 実践例

### 修正前の挙動
バックグラウンドタスクが実行中のままプロセスが中断され、`CLAUDE_CODE_RESUME_INTERRUPTED_TURN` 付きで再開しても、そのタスクが未完了であることがユーザーに伝わりませんでした。

### 修正後の挙動
再開後のセッションで、前のプロセスが残した未完了のバックグラウンドタスクが正しく検出され、状況がユーザーに報告されるようになりました。

## 注意点
- この環境変数は非対話（`-p`）モードでの再開を扱う際に関係する内部的なフラグです。通常の対話利用では意識する必要はありません。
- バックグラウンドタスクを多用するワークフローでは、再開後にタスクの状態を確認する習慣が引き続き推奨されます。
