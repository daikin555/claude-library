# [VSCode] エクスプローラーの右クリックから Add to Chat

## 原文（日本語に翻訳）

[VSCode] エクスプローラーの右クリックメニューに「Claude Code: Add to Chat」を追加しました。選択したファイルやフォルダーをチャットで @メンションします。

## 原文（英語）

[VSCode] Added "Claude Code: Add to Chat" to the Explorer's right-click menu, which @-mentions the selected files and folders in the chat

## 概要

VS Code のエクスプローラーでファイルやフォルダーを選んで右クリックすると、「Claude Code: Add to Chat」からチャットへ @メンションとして追加できます。パスを手入力する手間が省けます。

## 基本的な使い方

1. エクスプローラーでファイル／フォルダーを選択（複数可）
2. 右クリック →「Claude Code: Add to Chat」
3. チャット入力欄に `@path/to/file` が挿入される

## 実践例

### 複数ファイルをまとめて渡す

テストと実装ファイルを Ctrl/Cmd クリックで同時に選び、「このテストが通るよう実装を直して」と依頼できます。

### フォルダー単位で渡す

`src/auth/` を選んで追加し、「この認証モジュールの構成を説明して」と質問できます。

## 注意点

- 同じ更新で、`rg` が `PATH` にある大規模ワークスペースでの @メンションのファイル検索が高速化されました。
- IDE 接続から未使用ツール（openFile、saveDocument、getOpenEditors など）が削除されています。
