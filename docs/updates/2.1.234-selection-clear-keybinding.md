## 原文（日本語訳）

アプリ内のテキスト選択を解除するキーにバインドできる `selection:clear` キーバインドアクションを追加しました。エージェントビューでも動作します。

## 原文（英語）

Added the `selection:clear` keybinding action, so a key can be bound to clear an in-app text selection; also works in the agents view

## 概要

Claude Codeのターミナル内でテキストを選択した状態のまま操作を続けると、選択範囲が意図せず残ってしまい、その後のキー入力や表示が見づらくなることがありました。今回追加された `selection:clear` アクションを使うと、任意のキーに「選択範囲を解除する」動作を割り当てられます。通常の会話ビューだけでなく、エージェントビュー（サブエージェントの実行状況を表示する画面）でも同じキーで選択解除が可能です。

## 基本的な使い方

`~/.claude/keybindings.json` を開き（`/keybindings` コマンドで開けます）、任意のキーに `selection:clear` アクションを割り当てます。

```json
{
  "bindings": [
    {
      "context": "global",
      "keys": {
        "escape": "selection:clear"
      }
    }
  ]
}
```

保存すると、Claude Codeを再起動しなくても設定が自動的に反映されます。

## 実践例

### Escapeキーで選択解除する

誤ってテキストを選択してしまった際に、素早く解除できるようにします。

```json
{
  "bindings": [
    {
      "context": "global",
      "keys": {
        "escape": "selection:clear"
      }
    }
  ]
}
```

### 既存のキーとチェイン（連続バインド）する

1つのキー入力で複数のアクションを連続実行できる場合、選択解除を他の操作と組み合わせられます。

```json
{
  "bindings": [
    {
      "context": "global",
      "keys": {
        "ctrl+l": ["selection:clear", "screen:clear"]
      }
    }
  ]
}
```

画面クリアの前に選択状態も確実にリセットされます。

### エージェントビュー専用にバインドする

サブエージェントの出力を確認している際に選択範囲が残りやすい場合、`agents` コンテキストに限定して割り当てることもできます。

```json
{
  "bindings": [
    {
      "context": "agents",
      "keys": {
        "ctrl+u": "selection:clear"
      }
    }
  ]
}
```

## 注意点

- キーバインドの設定ファイルは `~/.claude/keybindings.json` で、`/keybindings` コマンドから開けます
- 既に他のアクションが割り当てられているキーに `selection:clear` を設定すると、既存の動作を上書きする場合があります
- グローバルコンテキストに設定すればエージェントビューを含む全体で有効になりますが、特定のビューのみで有効にしたい場合はコンテキストを絞り込んでください
- 設定ファイルの変更は自動検知されて即座に反映されるため、Claude Codeの再起動は不要です
