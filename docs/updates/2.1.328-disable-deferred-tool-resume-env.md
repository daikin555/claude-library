# CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME 環境変数を追加

## 原文（日本語に翻訳）

ホストが `claude -p --resume` や `--continue` で、フックが保留（defer）したツール呼び出しを実行するのを止められる `CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME` を追加しました。

## 原文（英語）

Added `CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME`, which lets a host stop `claude -p --resume` and `--continue` from running a tool call that a hook deferred

## 概要

フックでツール呼び出しを保留した後にセッションを再開すると、その呼び出しが実行されることがあります。この環境変数を設定すると、再開時の自動実行を止められます。Claude Code を組み込むホストアプリ向けの制御です。

## 基本的な使い方

```bash
CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME=1 claude -p --resume <session-id> "続きをお願いします"
```

## 実践例

### ホスト側で承認フローを管理する

自前の承認 UI を持つホストでは、再開時にホストの判断なく保留済みの呼び出しが走らないよう、この変数を設定しておきます。

## 注意点

- 値の指定方法（`1` など）は公式ドキュメントで確認してください
- 通常の対話利用では設定不要です
