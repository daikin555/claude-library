## 原文（日本語訳）
[VSCode] 巻き戻した（rewound）会話やフォークした会話が、元の会話で選択していた権限モードを保持していなかった不具合を修正しました

## 原文（英語）
[VSCode] Fixed rewound and forked conversations not keeping the permission mode you had picked for the original conversation

## 概要
VS Code拡張機能では、会話を過去の時点に巻き戻したり、別の会話としてフォークしたりする機能があります。これまでは、この操作を行うと、元の会話で選択していた権限モード（例: 通常モード、プランモード、自動承認モードなど）が引き継がれず、意図しないモードに戻ってしまう不具合がありました。今回の修正で、巻き戻し・フォーク後も元の会話の権限モードが正しく維持されるようになります。

## 基本的な使い方
特別な操作は不要です。会話を巻き戻したり、フォークしたりすると、直前まで使っていた権限モードがそのまま引き継がれます。

```
# 「自動承認モード」で作業していた会話を、ある時点まで巻き戻す
# → 修正前: デフォルトの権限モードに戻ってしまうことがあった
# → 修正後: 「自動承認モード」のまま巻き戻される
```

## 実践例

### プランモードで検討していた会話を分岐させる
```
# プランモードで設計を検討していた会話をフォークして、
# 別のアプローチを試したい
# → フォーク後の会話もプランモードのまま開始される
```

### 誤操作を取り消すために会話を巻き戻す
```
# 意図しない変更をしてしまったため、直前の状態まで会話を巻き戻す
# → 巻き戻し前に使っていた権限モード（例: 確認必須モード）が
#   そのまま維持され、想定外の自動実行が起きない
```

## 注意点
- これはバグ修正であり、権限モードの種類や切り替え方法自体に変更はありません。
- VS Code拡張機能限定の修正です。
- 巻き戻し・フォーク機能自体を使わない通常の会話には影響しません。
