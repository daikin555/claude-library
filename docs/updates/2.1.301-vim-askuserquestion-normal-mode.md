# vimモードのAskUserQuestion自由入力でNORMALモードに対応しEscでの入力消失を修正

## 原文（日本語に翻訳）

vim モードで AskUserQuestion の入力済みの回答が Esc で破棄される問題を修正しました。自由入力フィールドが vim の NORMAL モードに対応し、Esc でキャンセルされるのは NORMAL モードのときだけになります。

## 原文（英語）

Fixed Esc discarding a typed AskUserQuestion answer in vim mode: the free-text field now supports vim NORMAL mode, and Esc cancels only from NORMAL

## 概要

vimモードでは、INSERTからNORMALに戻るつもりでEscを押すと、入力中の回答ごとキャンセルされていました。修正後は、1回目のEscでNORMALモードになり、NORMALモードでEscを押したときだけキャンセルされます。

## 基本的な使い方

1. AskUserQuestionの自由入力欄に回答を入力
2. Escで NORMAL モードへ移行（入力は保持）
3. NORMAL モードでもう一度Escを押すとキャンセル

## 実践例

### 入力の途中編集

NORMALモードで `0`、`w`、`%` などの移動や編集を行ってから、Enterで回答を確定できます。

### 同バージョンの関連修正

遅い・負荷の高いマシンでEscの後にINSERTのまま残る問題も修正されています。

## 注意点

- vimモードを有効にしている場合のみ関係します。
- キャンセルしたい場合はEscを2回押す形になります。
