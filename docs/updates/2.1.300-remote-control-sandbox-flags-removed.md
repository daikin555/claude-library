# claude remote-control の --sandbox / --no-sandbox フラグを削除

## 原文（日本語に翻訳）

`claude remote-control` から、効果のなかった `--sandbox` と `--no-sandbox` フラグを削除しました。どちらかを指定するとエラーで終了します。セッションをサンドボックス化するには、設定で `sandbox.enabled` を指定してください。

## 原文（英語）

Removed the `--sandbox` and `--no-sandbox` flags from `claude remote-control`, which had no effect; passing either now exits with an error. Set `sandbox.enabled` in settings to sandbox sessions

## 概要

これらのフラグは実際には何も変更していませんでした。サンドボックスが有効だと思い込むことを避けるため、指定するとエラーになります。

## 基本的な使い方

```json
{
  "sandbox": {
    "enabled": true
  }
}
```

## 実践例

### 既存スクリプトの修正

`claude remote-control --sandbox` を呼んでいる起動スクリプトからフラグを外し、代わりに settings.json で `sandbox.enabled` を設定します。

## 注意点

- フラグを残したスクリプトは起動に失敗します。
- 以前から効果はなかったため、挙動としての退行はありません。
