# Monitor ツールのシェルコマンドに hook の if 条件が一致するように

## 原文（日本語訳）

`Monitor(tail *)` のような hook の `if` 条件が、`Bash(tail *)` が Bash に一致するのと同様に、Monitor ツールのシェルコマンドに一致するよう変更しました。

Bash にマッチする hook が、Monitor ツールで開始されたシェルコマンドで実行されない問題を修正しました。これらの hook はブロックや確認要求はできますが、承認やコマンドの書き換えはできません。

## 原文（英語）

Changed hook `if` conditions such as `Monitor(tail *)` to match the Monitor tool's shell commands as `Bash(tail *)` matches Bash's

Fixed hooks matching Bash not running on shell commands started by the Monitor tool; such hooks can block or ask, but not approve or rewrite those commands

## 概要

Monitor ツールが実行するシェルコマンドも、hook で Bash と同じ感覚で制御できるようになりました。バックグラウンドのログ監視などにも、監査やブロックのポリシーを適用できます。

## 基本的な使い方

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Monitor",
        "hooks": [
          { "type": "command", "if": "Monitor(tail *)", "command": "./scripts/audit.sh" }
        ]
      }
    ]
  }
}
```

## 実践例

### 監視コマンドの監査

`tail -f` などの監視コマンドを記録する hook を設定できます。

### 危険なコマンドのブロック

Bash 用に作った拒否 hook が Monitor 経由のコマンドにも効くため、抜け道がなくなります。

## 注意点

- Monitor 向けの Bash 一致 hook は、ブロックと確認要求のみ可能です。承認や書き換えはできません。
- 既存の `Bash(...)` 条件の挙動は変わりません。
