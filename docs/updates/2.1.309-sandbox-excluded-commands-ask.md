## 原文（日本語に翻訳）

設定でサンドボックスから除外されたコマンドは、サンドボックスが有効だが実行できない状態のとき、その書き込み許可パスへ書く前に確認を求めるよう変更しました。サンドボックス外へのフォールバックはそこでは拒否されます

## 原文（英語）

Changed commands the settings exclude from the sandbox to ask before writing to its write-list paths while the sandbox is enabled but cannot run; the unsandboxed fallback is refused there

## 概要

設定でサンドボックス対象外にしたコマンドは、サンドボックスが有効なのに起動できない状況だと、保護なしで書き込める抜け穴になり得ました。今後はサンドボックスの書き込み許可パスへの書き込み前に確認が入り、サンドボックスなしへのフォールバックは拒否されます。

## 基本的な使い方

```json
{
  "sandbox": {
    "enabled": true,
    "excludedCommands": ["docker"]
  }
}
```

## 実践例

### 除外コマンドを最小限にする

除外はビルドツールなど本当に必要なものに限定します。サンドボックスが起動できない場合は、除外コマンドでも書き込み時に確認されます。

## 注意点

- 設定キー名は例です。正確な書式は公式ドキュメントを確認してください
- サンドボックスが起動できない原因（依存パッケージ不足など）の解消が根本対策です
