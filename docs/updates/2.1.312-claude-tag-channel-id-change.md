## 原文（日本語訳）

[Claude Tag] 古い非公開Slackチャンネルが公開になり新しいIDが付与された際、Claude Tagチャンネルのオン/オフ切替とエージェント設定がワークスペース既定値に戻る問題を修正しました

## 原文（英語）

[Claude Tag] Fixed a Claude Tag channel's on/off switch and agent settings falling back to workspace defaults when an older private Slack channel goes public and gets a new ID

## 概要

チャンネルの公開化後も、設定が失われなくなりました。

## 基本的な使い方

追加操作は不要です。公開化後も設定が引き継がれます。

## 実践例

### チャンネルの公開化

運用中のチャンネルを公開しても設定をやり直す必要がありません。

## 注意点

- 過去に既定値へ戻ってしまったチャンネルは、必要に応じて設定を確認してください。
