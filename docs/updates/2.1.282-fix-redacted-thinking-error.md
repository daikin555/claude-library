## 原文（日本語訳）

「`redacted_thinking` blockの `data` が不正」というAPIエラーで毎ターン失敗していたセッションを修正しました。Claude Codeは会話の思考ブロックを破棄し、1回だけ再試行するようになりました。

## 原文（英語）

Fixed sessions failing on every turn with an "Invalid `data` in `redacted_thinking` block" API error; Claude Code now drops the conversation's thinking blocks and retries once

## 概要

セキュリティ上の理由でClaudeの思考内容の一部が伏せられる「redacted thinking」ブロックのデータが何らかの理由で壊れると、それ以降のすべてのターンがAPIエラーで失敗し、セッションが実質的に使用不能になる不具合がありました。今回の修正により、このエラーを検知すると、Claude Codeは会話中の思考ブロックを自動的に破棄したうえで1回だけリクエストを再試行するようになり、セッションが継続できるようになりました。

## 基本的な使い方

ユーザー側の操作は不要です。該当エラーが発生した場合、Claude Codeが自動的にリカバリー処理を行います。

## 実践例

### 長時間セッションでの自動リカバリー

数時間にわたる長時間セッションで、まれに発生する `redacted_thinking` の破損によってセッションが完全に止まってしまう事態を避けられます。

### 自動化パイプラインでの継続性確保

CI上でClaude Codeを自動実行しているワークフローで、人手を介さずにこのエラーから自動復帰できるようになり、パイプライン全体の失敗を防ぎます。

## 注意点

- 自動リカバリーの過程で、破損した思考ブロックの内容自体は失われます（会話は継続できますが、直前の推論過程は再現されません）
- 再試行してもなお失敗する場合は、新しいセッションを開始することを検討してください
