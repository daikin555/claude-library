## 原文（日本語訳）

別のClaude Codeプロセスがサインインの更新中にそのプロセスが終了・強制終了された後も、「another Claude Code process is refreshing it」というログインエラーで最大1分間リクエストが失敗し続けていた不具合を修正しました。

## 原文（英語）

Fixed requests failing for up to a minute with an "another Claude Code process is refreshing it" login error after that other process was closed or killed mid-refresh

## 概要

複数のClaude Codeプロセス（複数のターミナルタブやIDEウィンドウなど）を同時に開いている場合、片方が認証トークンの更新（リフレッシュ）中にプロセスごと閉じられたり強制終了されたりすると、残りのプロセスが「他のプロセスが更新中」と誤認識し続け、最大1分間ログインエラーでリクエストが失敗する不具合がありました。今回の修正でこの状態が正しく検知・解消されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。複数のClaude Codeプロセスを同時に使用している通常のワークフローで、この修正の恩恵を自動的に受けられます。

## 実践例

### 複数ウィンドウ・複数タブでの並行作業

複数のVS Codeウィンドウや複数のターミナルタブでClaude Codeを同時に開いて作業している場合に、片方を閉じた直後にもう片方でリクエストが失敗するという事態が解消されます。

### 不安定なネットワーク環境での作業

ネットワークが不安定でプロセスが予期せず終了するような環境でも、他のプロセスがロック状態から素早く復帰できるようになります。

## 注意点

- この不具合は複数のClaude Codeプロセスを同時に起動している場合に特有のものです。単一プロセスでの利用には影響しません
- 修正後もエラーが続く場合は、認証情報の再ログイン（`/login`）を試してください
