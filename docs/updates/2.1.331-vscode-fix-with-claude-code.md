# VS Code: 「Fix with Claude Code」クイックフィックスを追加

## 原文（日本語に翻訳）

[VSCode] エラーや警告のクイックフィックス、およびテストのピークや Test Results ビューの失敗テストに「Fix with Claude Code」を追加しました。問題内容がチャット欄に入力されます。

## 原文（英語）

[VSCode] Added "Fix with Claude Code" as a quick fix for errors and warnings and to failed tests in the test peek and the Test Results view, which puts the problem into the chat box

## 概要

エディタ上の診断や失敗テストから、ワンクリックで Claude Code に修正を依頼できます。

## 基本的な使い方

エラー行で電球アイコン（Ctrl/Cmd+.）を開き、「Fix with Claude Code」を選びます。

## 実践例

### 失敗テストの修正依頼

Test Results ビューで失敗したテストを右クリックまたはピークから選ぶと、失敗内容がチャット欄に入ります。

## 注意点

- 問題内容はチャット欄に入力されるだけなので、送信前に追記や編集ができます。
