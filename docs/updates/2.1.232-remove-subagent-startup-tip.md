## 原文（日本語に翻訳）

カスタムサブエージェントの作成を提案する起動時のTip（ヒント）と、`/powerup` ツアー内の対応する案内を削除しました。

## 原文（英語）

Removed the startup tip suggesting you create custom subagents, and the matching nudge in the `/powerup` tour.

## 概要

Claude Codeは起動時にランダムなTip（活用のヒント）を表示したり、`/powerup` コマンドで機能ツアーを案内したりする仕組みを持っています。これまではその中に「カスタムサブエージェントを作成してみましょう」という趣旨の案内が含まれていましたが、v2.1.232でこのTipと `/powerup` ツアー内の対応する案内が削除されました。サブエージェント機能自体が廃止されたわけではなく、あくまで起動時の案内文言・オンボーディング導線が整理されたという変更です。

## この変更が影響する場面

これはUI/UXレベルの変更であり、機能そのものの動作には影響しません。

- Claude Code起動時にランダムに表示されるTipの一覧から、サブエージェント作成を促す文言が表示されなくなります
- `/powerup` コマンドで表示される機能紹介ツアーからも、サブエージェント作成に関する案内ステップがなくなります
- サブエージェント機能（`.claude/agents/` にカスタムエージェントを定義する機能）自体は引き続き利用可能です

## 実践例

### 起動時のTip表示

```bash
claude
# 起動時に表示されるTipの一覧から
# 「カスタムサブエージェントを作成してみましょう」といった
# 案内が表示されなくなる
```

### /powerupツアーの利用

```bash
> /powerup
# 機能紹介ツアーが表示されるが、
# サブエージェント作成を勧めるステップは含まれなくなる
```

### サブエージェント機能自体は引き続き利用可能

```bash
# .claude/agents/ 配下にカスタムエージェント定義を作成する運用は
# 従来通り可能。起動時の案内が減っただけで機能制限はない
mkdir -p .claude/agents
```

## 注意点

- Claude Code v2.1.232で導入された変更です
- サブエージェント機能自体の廃止や仕様変更ではなく、オンボーディング用の案内文言・ツアー内容の整理です
- 既にサブエージェントを利用しているユーザーへの影響はありません
- サブエージェントの作り方を知りたい場合は、公式ドキュメントの「Create custom subagents」ページを参照してください
