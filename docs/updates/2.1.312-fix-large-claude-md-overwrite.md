## 原文（日本語訳）

サブディレクトリ内の非常に大きなCLAUDE.md、ルールファイル、@インクルードされたファイルを、先頭部分しか見ないままClaudeが上書きしてしまう問題を修正。Writeは、全体を読むか、その場で編集するようClaudeに促すようになりました

## 原文（英語）

Fixed Claude overwriting a very large CLAUDE.md, rules file or @-included file in a subdirectory after seeing only its start; Write now asks Claude to read it all or edit in place

## 概要

巨大な指示ファイルは先頭しか読み込まれないことがあり、その状態でWriteすると内容が失われる恐れがありました。修正後は、Writeがファイル全体の読み込みか、Editによる部分編集をClaudeに求めます。

## 基本的な使い方

通常どおり使うだけで保護されます。大きなファイルを書き換えようとすると、Claudeは全文を読み直すか、Editで該当箇所のみ変更します。

## 実践例

### 長大なCLAUDE.mdの更新

ルールを追記するときも、全体置換ではなく該当箇所の編集に切り替わるため、既存の記述が消えにくくなります。

### @インクルードしたファイルの編集

分割した指示ファイルでも同様に保護されます。

## 注意点

- 大きなファイルでは、Claudeが追加で読み込みを行うためトークン消費が増える場合があります。
- 重要なファイルはGit管理しておくと安心です。
