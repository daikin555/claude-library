## 原文（日本語訳）

未完了のタスクが残っているセッションを再開・再起動した際に、`ctrl+t` で展開したタスクリストが常に折りたたまれた状態から始まってしまう不具合を修正しました。

## 原文（英語）

Fixed the expanded task list (`ctrl+t`) always starting collapsed when resuming or relaunching into a session that still has open tasks

## 概要

Claude Codeでは `ctrl+t` を押すことでタスクリスト（ToDoリスト）の表示を展開・折りたたみ切り替えられます。未完了のタスクが残っているセッションを `claude --resume` などで再開したり、同じセッションに再度入り直したりした場合、本来であれば直前の展開状態が引き継がれるべきところ、これまでは常に折りたたまれた状態で表示されていました。今回の修正により、開いたままのタスクが存在するセッションを再開・再起動した際に、タスクリストの展開状態が正しく扱われるようになりました。

## 基本的な使い方

タスクリストの表示切り替えには `ctrl+t` を使用します。

```
ctrl+t
```

未完了タスクのあるセッションを一度終了し、後で再開する場面を考えます。

```
claude --resume
```

修正前は、再開直後にタスクリストが常に折りたたまれた状態になっており、未完了タスクの詳細を確認するには毎回 `ctrl+t` を押し直す必要がありました。修正後は、開いたままのタスクが残っているセッションを再開・再起動した場合に、タスクリストが期待通りの状態で表示されます。

## 実践例

### 長いタスクを中断して翌日に再開する

複数ステップからなるタスクを実行中に一旦セッションを終了し、翌日 `claude --resume` で同じセッションに戻った場合、以前は毎回タスクリストが折りたたまれていましたが、修正後はスムーズに未完了タスクの状況を把握できます。

### 端末を閉じてしまい、同じセッションに再ログインする

ネットワーク切断や端末のクラッシュなどで意図せずセッションが終了した後、同じセッションIDで再度入り直した場合でも、タスクリストの展開状態が想定通りに扱われるようになり、状況把握のためのひと手間が減ります。

### `ctrl+t` でタスクリストの表示・非表示を切り替える

セッション中いつでも `ctrl+t` を押すことで、最大5件まで表示されるタスクリストの展開・折りたたみを手動で切り替えられます。この基本動作自体は今回の修正の対象ではありませんが、セッション再開時の初期状態が正しくなったことで、手動切り替えの操作感も一貫したものになります。

## 注意点

- この修正は「未完了のタスクが残っているセッションを再開・再起動する」場面に限定されます。新規セッションでの `ctrl+t` の挙動には影響しません
- `ctrl+t` がターミナル側のキー割り当てと衝突する場合は、`app:toggleTodos` アクションを別のキーに再割り当てできます
