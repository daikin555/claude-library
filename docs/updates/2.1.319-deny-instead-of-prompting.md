## 原文（日本語訳）
`permissions.denyInsteadOfPrompting` 設定を追加：権限プロンプトで待機することになるツール呼び出しを拒否し、ターンを継続します（ターミナルセッション、サブエージェント、チームメイトが対象）。

## 原文（英語）
Added `permissions.denyInsteadOfPrompting` setting: a tool call that would wait on a permission prompt is denied and the turn continues, in terminal sessions, subagents and teammates

## 概要
権限確認が必要なツール呼び出しで人の応答を待つ代わりに、自動的に拒否して処理を先へ進める設定です。無人実行やバックグラウンドのサブエージェントが承認待ちで止まる問題を避けられます。

## 基本的な使い方
`.claude/settings.json` に次を追加します。

```json
{
  "permissions": {
    "denyInsteadOfPrompting": true
  }
}
```

## 実践例

### 無人のバッチ実行
事前に `allow` で許可したツールだけを実行させ、それ以外は拒否させます。

```json
{
  "permissions": {
    "allow": ["Bash(npm test:*)", "Read"],
    "denyInsteadOfPrompting": true
  }
}
```

### サブエージェント／チームメイトの停止防止
承認待ちで固まらず、拒否結果を受けて別の方法を試せます。

## 注意点
- 許可ルールに無い操作は実行されないため、必要な操作は事前に `allow` へ追加してください。
- 拒否されたことはClaudeに伝わり、ターンは継続します。
