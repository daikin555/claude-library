## 原文（日本語に翻訳）

送信キー（ctrl+enter、または ctrl+x ctrl+s）を追加：現在のターンを中断し、キューに溜まっているすべてのメッセージを一度に送信します。送信済みおよびキュー中のメッセージは、モデルが受信するまでグレー表示になります

## 原文（英語）

Added a send-now key (ctrl+enter, or ctrl+x ctrl+s) that interrupts the current turn and sends all queued messages at once; sent and queued messages show in gray until the model receives them

## 概要

Claude Codeでは、モデルが応答を生成している最中に次のメッセージを入力してキューに溜めておくことができます。今回追加された「send-now」キーを使うと、現在のターンをすぐに中断し、キューに溜まっているメッセージをまとめて即座に送信できます。急いで方向転換したいときや、誤って入力したメッセージの実行前に追加の指示を割り込ませたいときに便利です。

## 基本的な使い方

Claude Codeが応答を生成中に、続けてメッセージを入力してEnterでキューに追加できます。すぐに送信したい場合は次のいずれかのキーを押します。

```
ctrl+enter
```

または

```
ctrl+x ctrl+s
```

## 実践例

### 誤った方向で処理が進んでいるときに割り込む

Claudeが長い処理を実行中に、途中で軌道修正が必要だと気づいた場合、メッセージを入力してからすぐに送信できます。

```
# 実行中に気づいた修正指示を入力
「そのファイルではなく src/utils.ts を編集して」

# ctrl+enter または ctrl+x ctrl+s で即座に中断・送信
```

### 複数の指示をまとめて素早く送りたいとき

複数のフォローアップ指示をキューしておき、まとめて即座に送信したい場合に利用できます。

```
# 1つ目の指示を入力してEnterでキュー
「テストを追加して」

# 2つ目の指示を入力してEnterでキュー
「READMEも更新して」

# ctrl+enter で両方を即座に送信（現在のターンは中断される）
```

## 注意点

- このキーは現在のターンを中断するため、実行中のツール呼び出しが途中で止まる可能性があります
- 送信済み・キュー中のメッセージは、モデルが実際に受信するまでグレー表示のままです
- キーバインドは環境（ターミナルやOS）によって既存のショートカットと衝突しないか確認してください
