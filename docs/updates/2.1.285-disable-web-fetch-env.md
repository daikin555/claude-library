# 環境変数 CLAUDE_CODE_DISABLE_WEB_FETCH で WebFetch ツールを無効化する

## 原文（日本語訳）

- WebFetch ツールを無効にする環境変数 `CLAUDE_CODE_DISABLE_WEB_FETCH` を追加しました

## 原文（英語）

- Added `CLAUDE_CODE_DISABLE_WEB_FETCH` environment variable to turn off the WebFetch tool

## 概要

`CLAUDE_CODE_DISABLE_WEB_FETCH` を設定すると、Claude Code が Web ページを取得する WebFetch ツールが無効になります。外部ネットワークへのアクセスを抑えたい環境や、機密性の高いリポジトリで有用です。

## 基本的な使い方

```bash
CLAUDE_CODE_DISABLE_WEB_FETCH=1 claude
```

## 実践例

### 単発の非対話実行で無効化する

```bash
CLAUDE_CODE_DISABLE_WEB_FETCH=1 claude -p "このリポジトリの構成を要約して"
```

### settings.json の env で常時無効化する

```json
{
  "env": {
    "CLAUDE_CODE_DISABLE_WEB_FETCH": "1"
  }
}
```

## 注意点

- 受理される値の詳細は changelog に記載がないため、公式ドキュメントで確認してください。
- 権限ルールで WebFetch を deny する方法もありますが、環境変数ならツール自体が無効になります。
- WebSearch など他の Web 系ツールへの影響は本項目には記載されていません。
