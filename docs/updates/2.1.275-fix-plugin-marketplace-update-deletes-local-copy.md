## 原文（日本語に翻訳）

`claude plugin marketplace update` が、フェッチに失敗し、かつマーケットプレイスがそのリポジトリ名にちなんで命名されている場合に、GitHubマーケットプレイスのローカルコピーを削除してしまっていた問題を修正

## 原文（英語）

Fixed `claude plugin marketplace update` deleting a GitHub marketplace's local copy when the fetch failed and the marketplace was named after its repository

## 概要

`claude plugin marketplace update` コマンドは、GitHub上のマーケットプレイスの最新情報を取得して更新するためのコマンドです。これまで、ネットワーク障害などでフェッチに失敗し、かつマーケットプレイスの名前がそのリポジトリ名と同じ場合に、更新処理がローカルにキャッシュされていたマーケットプレイスのコピーを誤って削除してしまう不具合がありました。この修正により、フェッチが失敗してもローカルコピーが保持されるようになりました。

## 基本的な使い方

```bash
claude plugin marketplace update <marketplace-name>
```

このコマンドを実行してマーケットプレイスの情報を最新化します。ネットワークエラーなどでフェッチに失敗しても、ローカルの既存データは保持されます。

## 実践例

### 修正前の挙動

リポジトリ名と同名のマーケットプレイス（例：`anthropics/claude-code` というリポジトリを `claude-code` という名前で追加していた場合）で、一時的なネットワーク障害によりフェッチが失敗すると、ローカルにキャッシュされていたマーケットプレイスのデータごと削除されてしまい、再度手動で追加し直す必要がありました。

### 修正後の挙動

フェッチに失敗した場合でも、ローカルコピーは削除されずそのまま保持されるようになりました。ネットワークが不安定な環境でも安心して `update` コマンドを実行できます。

```bash
# ネットワークが不安定な環境でも
claude plugin marketplace update my-marketplace
# フェッチに失敗してもローカルデータは維持される
```

## 注意点

- この不具合はGitHubマーケットプレイスかつリポジトリ名と同名の場合に発生していた特定条件下の問題でした
- フェッチ自体が失敗した場合、最新情報への更新は行われません（エラーが表示されます）
- 定期的にネットワーク状態が不安定な環境では、更新の再試行を検討してください
