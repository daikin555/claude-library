## 原文（日本語訳）
[VSCode] `environmentVariables` 設定内の `CLAUDE_CONFIG_DIR` が空の値になっていると、Claude Codeが設定ファイルをワークスペース内に保存し続けてしまう不具合を修正しました

## 原文（英語）
[VSCode] Fixed an empty `CLAUDE_CONFIG_DIR` entry in the `environmentVariables` setting making Claude Code keep its files in the workspace

## 概要
`CLAUDE_CONFIG_DIR` はClaude Codeが設定ファイルなどを保存するディレクトリを指定する環境変数です。VS Code拡張機能の `environmentVariables` 設定でこの値を空文字列のまま設定していると、意図したディレクトリではなく、ワークスペース（プロジェクトフォルダ）内に設定ファイルが保存され続けてしまう不具合がありました。今回の修正により、`CLAUDE_CONFIG_DIR` が空の場合はその設定が無視され、デフォルトの正しい保存場所が使われるようになります。

## 基本的な使い方
VS Codeの設定で `environmentVariables` に `CLAUDE_CONFIG_DIR` を空のまま残している場合、特に対処しなくても、今後はワークスペース内への誤保存が発生しなくなります。意図的に保存先を変更したい場合は、有効なパスを明示的に指定します。

```jsonc
// settings.json
{
  "claude-code.environmentVariables": {
    "CLAUDE_CONFIG_DIR": "/Users/you/.config/claude-alt"
  }
}
```

## 実践例

### 誤って空文字列を設定していた場合
```jsonc
// 修正前: 以下の設定があると、意図せずワークスペース内に
// 設定ファイルが保存され続けてしまっていた
{
  "claude-code.environmentVariables": {
    "CLAUDE_CONFIG_DIR": ""
  }
}
// 修正後: 空の値は無視され、デフォルトの保存場所が使われる
```

### 複数プロジェクトで設定ディレクトリを分けたい場合
```jsonc
// プロジェクトごとに異なる設定ディレクトリを使いたい場合は、
// 空文字列ではなく有効なパスを明示的に指定する
{
  "claude-code.environmentVariables": {
    "CLAUDE_CONFIG_DIR": "${workspaceFolder}/.claude-config"
  }
}
```

## 注意点
- ワークスペース内に誤って保存されてしまった既存の設定ファイルは、この修正では自動的に移動・削除されません。必要であれば手動で整理してください。
- `CLAUDE_CONFIG_DIR` を意図的に空にする使い方は想定されていません。設定を変更したくない場合は、このキー自体を設定から削除することを推奨します。
- この修正はVS Code拡張機能の `environmentVariables` 設定に関するものです。
