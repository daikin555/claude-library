## 原文（日本語訳）
Artifact ツールの挙動を変更：初回公開時に、絵文字のファビコンではなく一語のタブアイコン名を尋ねるようにしました

## 原文（英語）
Changed the Artifact tool to ask for a one-word tab icon on a first publish instead of an emoji favicon

## 概要
Artifactを初めて公開する際、これまではブラウザタブに表示するファビコンとして絵文字を選ぶ形式でした。今回の変更で、絵文字の代わりに一語（アイコン名）を指定する方式に変わります。これにより、より明確で一貫性のあるアイコン指定が可能になり、意図した見た目のタブアイコンを設定しやすくなります。

## 基本的な使い方
Artifactを初めて公開する際に、Claudeから一語でのアイコン指定を求められます。

```
（初めてArtifactを公開する際）
「このダッシュボードをArtifactとして公開して」
# → Claudeが「タブアイコンに使う一語（例: chart, rocket, gearなど）を教えてください」
#   のように尋ねてくる
```

## 実践例

### ダッシュボード系Artifactのアイコンを指定する
```
「タブアイコンは 'chart' でお願いします」
# → グラフを連想させるアイコンがタブに設定されて公開される
```

### ツール系Artifactのアイコンを指定する
```
「タブアイコンは 'tool' にして」
# → 一語のキーワードに基づいて適切なアイコンが選択・設定される
```

## 注意点
- 絵文字を直接ファビコンとして指定する従来の方法は使えなくなります。
- 指定できるのは一語のキーワードであり、Claude側がそのキーワードに応じたアイコンを選択します。
- 既存の公開済みArtifactの既存アイコンには影響しません。今後の初回公開時のみ対象です。
