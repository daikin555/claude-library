## 原文（日本語訳）
Claude in Chromeのautoモードの挙動を変更：bypassモードと同様に、分類器が承認した呼び出しについて拡張機能のサイトごとのチェックをスキップするようにしました。これにより、リダイレクト後に`browser_batch`で発生していた「Permission denied」エラーが修正されます

## 原文（英語）
Changed Claude in Chrome in auto mode to skip the extension's per-site check for classifier-approved calls, as bypass mode does, fixing `browser_batch` "Permission denied" after a redirect

## 概要
Claude in Chrome拡張機能のautoモードでは、ページ遷移(リダイレクト)を伴う操作を`browser_batch`で実行すると、拡張機能側のサイトごとの権限チェックに引っかかり「Permission denied」エラーが発生する不具合がありました。今回の修正で、bypassモードと同様に、Claudeの分類器がすでに承認済みと判断した呼び出しについてはサイトごとのチェックをスキップするようになり、リダイレクトを含むブラウザ操作でもエラーなく実行できるようになります。

## 基本的な使い方
autoモードでClaude in Chromeを使用し、複数のブラウザ操作をまとめて実行する際に自動的に修正が適用されます。

```
# Claude in Chrome拡張機能を「autoモード」で使用
「このログインフォームに入力して送信し、リダイレクト先のページの情報を取得して」
# → リダイレクトを挟む一連の操作がbrowser_batchでエラーなく完了する
```

## 実践例

### ログイン後にリダイレクトが発生するサイトの操作
```
# 修正前: ログイン成功後のリダイレクト先ページで
#   browser_batchが「Permission denied」で失敗することがあった
# 修正後: 分類器が承認済みの呼び出しはサイトごとのチェックをスキップし、
#   リダイレクト後も操作が継続できる
```

### 複数ページにまたがるフォーム入力の自動化
```
「このアンケートフォームに回答して、次のページに進んで送信まで完了して」
# → ページ遷移（リダイレクト）を挟んでもbrowser_batchの実行が中断されない
```

## 注意点
- この修正はautoモードに関するものです。挙動はbypassモードに近づきますが、分類器による承認判定自体は引き続き行われます。
- サイトごとのチェックが完全に無効化されるわけではなく、「分類器が承認した呼び出し」に限定されます。
- Claude in Chromeの権限モード設定については拡張機能の設定画面で確認できます。
