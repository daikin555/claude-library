## 原文（日本語訳）

`claude -p` とSDKセッションの起動を改善した。最初のターンが、HTTPおよびSSE MCPサーバーの `resources/list` への応答を待たなくなった。

## 原文（英語）

Improved startup of `claude -p` and SDK sessions: the first turn no longer waits for HTTP and SSE MCP servers to answer `resources/list`

## 概要

HTTP/SSEのMCPサーバーを設定していても、最初のターンが `resources/list` の応答を待たずに始まります。ワンショット実行やSDK利用での初動が速くなります。

## 基本的な使い方

```bash
claude -p "このリポジトリの概要を教えて"
```

## 実践例

### スクリプトからの繰り返し実行

```bash
for f in a.md b.md; do claude -p "$f を要約して"; done
```

起動のたびに生じていた待ち時間が減ります。

## 注意点

- 特別な設定は不要で、自動的に適用されます。
