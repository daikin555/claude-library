## 原文（日本語訳）

[クラウドセッション] Claudeがクラウドセッションにリポジトリを追加する際のステップを改善。開くと生のJSONではなく、結果の短い表が表示されます

## 原文（英語）

[Cloud sessions] Improved the step shown when Claude adds a repository to a cloud session: opening it now shows a short table of what happened instead of raw JSON

## 概要

リポジトリ追加の結果が、読みやすい表で確認できます。

## 基本的な使い方

セッション内の該当ステップを開くと表が表示されます。

## 実践例

### 追加結果の確認

どのリポジトリがどう追加されたかが一目で分かります。

## 注意点

- 表示の改善であり、動作は変わりません。
