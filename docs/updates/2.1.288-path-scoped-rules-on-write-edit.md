## 原文（日本語訳）

パス限定の `.claude/rules` とネストされたCLAUDE.mdが、Write/Editがその範囲のファイルを作成・変更したときに読み込まれない問題を修正した（従来はReadのみが読み込んでいた）。

## 原文（英語）

Fixed path-scoped `.claude/rules` and nested CLAUDE.md files not loading when Write or Edit creates or changes a file in their scope (previously only Read loaded them)

## 概要

特定ディレクトリ向けのルールやネストされたCLAUDE.mdは、これまでファイルを読んだときだけ読み込まれていました。そのため、新規作成や編集だけを行う場面ではルールが効かないことがありました。今回の修正でWrite/Editでも読み込まれます。

あわせて、InstructionsLoadedフックにサブエージェントの `agent_id` / `agent_type` が含まれるようになり、ファイルアクセスで読み込まれたルールは `effort` も報告します。

## 基本的な使い方

```markdown
---
paths:
  - "src/api/**/*.ts"
---
APIハンドラには必ず入力検証を入れること。
```

このルールは `.claude/rules/api.md` などに置きます。

## 実践例

### 新規ファイル作成時にルールを適用する

`src/api/` に新しいファイルを作らせると、Readなしでもルールが読み込まれます。

### サブディレクトリ固有の規約

`packages/web/CLAUDE.md` の規約が、そこでの編集時にも適用されます。

## 注意点

- 既存ファイルをReadしない編集でもルールが効くため、挙動が変わる場合があります。
- ルールが多いとコンテキストを消費します。範囲を適切に絞ってください。
