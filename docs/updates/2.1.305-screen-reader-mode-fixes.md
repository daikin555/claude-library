# スクリーンリーダーモードの検索ボックスとハイライト表示を改善

## 原文（日本語に翻訳）

- スクリーンリーダーモードを修正。検索ボックスはVoiceOverが「telephone recorder」と読んでいた記号ではなく「Search:」と表示。Ctrl+R検索の一致箇所や「ultrathink」などのハイライトされたプロンプトテキストで、単語内にスペースが入らなくなった

## 原文（英語）

- Fixed screen reader mode: search boxes now say "Search:" instead of a symbol VoiceOver read as "telephone recorder", and highlighted prompt text, such as Ctrl+R search matches and "ultrathink", no longer has spaces inside words

## 概要

スクリーンリーダー利用時の読み上げが改善されました。検索ボックスは「Search:」と読まれ、ハイライト部分も単語が分断されずに読まれます。

## 基本的な使い方

スクリーンリーダーモードを有効にした状態で、Ctrl+Rの履歴検索などを使うだけで反映されます。

## 実践例

### VoiceOverでの履歴検索

Ctrl+Rの検索で、検索欄とマッチ箇所が自然に読み上げられます。

## 注意点

- 他のスクリーンリーダーでの読み上げは環境により異なる場合があります。
