## 原文（日本語訳）

環境変数 `ANTHROPIC_DEFAULT_MODEL` が追加されました。これは新規セッションが起動時に使用するモデルを設定するもので、セッション中に `/model` でモデルを選び直した場合はその選択が優先されます。また `ANTHROPIC_MODEL` とは異なり、`/model` での選択結果は再起動をまたいで保持されます。

## 原文（英語）

Added `ANTHROPIC_DEFAULT_MODEL` environment variable: sets the model new sessions start on, while a `/model` pick still overrides it and persists across restarts (unlike `ANTHROPIC_MODEL`)

## 概要

これまで環境変数でモデルを指定する手段としては `ANTHROPIC_MODEL` がありましたが、これはセッション中ずっとその値を強制するため、`/model` でモデルを切り替えても再起動すると環境変数の値に戻ってしまう挙動でした。新設された `ANTHROPIC_DEFAULT_MODEL` は「新規セッションが開始する時点の初期モデル」を指定するだけの緩やかな指定方法で、セッション中に `/model` でモデルを選び直すとその選択が優先され、しかも再起動後もその選択が保持されます。

## 基本的な使い方

シェルの環境変数として設定してからClaude Codeを起動します。

```bash
export ANTHROPIC_DEFAULT_MODEL=claude-opus-4-6
claude
```

この状態で新規セッションを開始すると、最初は `claude-opus-4-6` で会話が始まります。セッション中に `/model` で別のモデル（例えばSonnet）に切り替えると、以後はその選択が有効になり、Claude Codeを再起動しても環境変数の値ではなく直近に選んだモデルが引き継がれます。

## 実践例

### チームやプロジェクト単位でデフォルトモデルを揃える

プロジェクトの `.claude/settings.json` の `env` フィールドや、チーム共有のシェルプロファイルに `ANTHROPIC_DEFAULT_MODEL` を設定しておくことで、メンバーが新しくセッションを始めたときの初期モデルを統一できます。個々人が `/model` で好みのモデルに切り替えることも引き続き可能です。

```json
{
  "env": {
    "ANTHROPIC_DEFAULT_MODEL": "claude-sonnet-4-6"
  }
}
```

### 一時的に高性能モデルから始めたいセッション

複雑な設計検討をする作業ディレクトリでだけ、起動直後からOpusモデルで会話を始めたい場合に利用できます。

```bash
export ANTHROPIC_DEFAULT_MODEL=claude-opus-4-6
claude
```

途中で作業内容が軽量なタスクに変わったら `/model` でSonnetやHaikuに切り替えれば、その選択が以後のセッションでも保持されます。

### `ANTHROPIC_MODEL` からの移行

これまで `ANTHROPIC_MODEL` を使って固定的にモデルを指定していた場合、`/model` での一時的な切り替えが再起動のたびにリセットされてしまい不便に感じることがありました。`ANTHROPIC_DEFAULT_MODEL` に置き換えることで、「普段はこのモデルから始めたいが、必要な時は自由に切り替えて、その切り替えを維持したい」という運用がしやすくなります。

## 注意点

- `ANTHROPIC_MODEL` は常にそのモデルを強制するのに対し、`ANTHROPIC_DEFAULT_MODEL` はあくまで新規セッション開始時点の初期値を決めるものです
- `/model` でモデルを選び直すと、その選択は環境変数の値より優先され、再起動後も保持されます
- 既に起動済みのセッションには影響しません。有効になるのは新規セッション開始時です
