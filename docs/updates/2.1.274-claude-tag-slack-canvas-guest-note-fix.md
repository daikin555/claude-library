## 原文（日本語訳）

[Claude Tag] 「Channel only」ゲスト設定を使用しているチャンネルでSlackキャンバスを編集するたびに、Claudeが繰り返し追記していたゲスト帰属の注記を削除しました。

## 原文（英語）

[Claude Tag] Removed the repeated guest-attribution note Claude appended to a Slack canvas each time it edited one in a channel using the "Channel only" guest setting

## 概要

Slackの「Channel only」ゲスト設定が有効なチャンネルでは、ゲストユーザーの閲覧範囲がそのチャンネルに限定されます。これまでClaude Tagは、このようなチャンネルでSlackキャンバスを編集するたびに、誰が編集したかを示す「ゲスト帰属」の注記をキャンバスに追記していましたが、編集の度に同じ注記が繰り返し追加されてしまい、キャンバスが冗長な注記で埋まってしまう問題がありました。今回の修正でこの繰り返し追記が行われなくなり、キャンバスがすっきりと保たれるようになりました。

## 基本的な使い方

「Channel only」ゲスト設定のチャンネルで、Claude Tagにキャンバスの編集を依頼するだけです。

```
@Claude このキャンバスに今日のミーティングメモを追加して
```

修正後は、編集のたびに不要な注記が積み重なることはありません。

## 実践例

### 複数回にわたるキャンバス編集

同じキャンバスを何度も編集依頼するワークフローでは、修正前は編集回数分だけ同じ注記が蓄積されていましたが、修正後は不要な繰り返しがなくなり、キャンバスの内容に集中できます。

```
@Claude プロジェクトステータスのキャンバスを最新情報で更新して
```

### 修正前後の比較

- 修正前: 編集のたびに「ゲスト帰属」の注記がキャンバス末尾に追加され続け、内容が肥大化する
- 修正後: 注記の重複追記が行われず、キャンバスが必要な内容のみを保持する

## 注意点

- この修正は「Channel only」ゲスト設定を使用しているチャンネルに限定されます
- 通常のチャンネル（ゲスト制限のないチャンネル）での挙動には影響しません
