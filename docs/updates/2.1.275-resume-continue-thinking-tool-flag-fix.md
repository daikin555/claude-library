## 原文（日本語訳）

セッション開始時に使われていた組み込みツールが、その後サーバー側のフラグによって無効化されていた場合、`--resume` および `--continue` が会話の以前の思考（thinking）内容を失ってしまう不具合を修正しました。

## 原文（英語）

Fixed `--resume` and `--continue` dropping a conversation's earlier thinking when a built-in tool it started with has since been switched off by a server-side flag

## 概要

Claude Codeは拡張思考（extended thinking）機能を使うと、応答の前に内部的な思考過程を生成します。会話を `--resume` や `--continue` で再開する際、セッション開始時点で有効だった組み込みツールがその後サーバー側の機能フラグによって無効化されていると、それまでの思考内容が再開時に失われてしまう不具合がありました。今回の修正により、ツールの有効・無効状態が変化していても、以前の思考内容が正しく保持されたまま会話を再開できるようになりました。

## 基本的な使い方

```bash
claude --continue
claude --resume
```

拡張思考を使った会話でも、通常どおりこれらのオプションで再開できます。

## 実践例

### ロールアウト中の機能フラグ変更をまたいだ再開

Anthropic側で組み込みツールの提供状況がサーバー側フラグによって段階的に変更されることがあります。あるツールが有効な状態で開始したセッションを、そのツールが無効化された後に `--resume` すると、修正前は以前の思考内容が欠落することがありました。修正後は思考内容がそのまま維持されます。

```bash
# セッション開始時は有効だったツールが、その後サーバー側で無効化された場合でも
claude --resume <session-id>
```

### 長期間放置したセッションの再開

数日〜数週間放置していたセッションを `--continue` で再開する場合も、その間にサーバー側の設定が変わっている可能性がありますが、この修正により思考内容の欠落を心配する必要がなくなりました。

## 注意点

- この修正は思考内容の「欠落」を防ぐものであり、無効化されたツール自体が再度使えるようになるわけではありません。
- 拡張思考の内容はモデルやAPI設定によって保持・表示のされ方が異なる場合があります。
