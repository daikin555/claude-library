# Claude apps gateway のプール型グループ予算

## 原文（日本語訳）

- Claude apps gateway にプール型グループ予算を追加：メンバー個別の上限に加えて、グループのメンバーが共有する月次予算を 1 つ設定できる。spend limits 管理 API の `pooled_budget` で設定

## 原文（英語）

- Added pooled group budgets to the Claude apps gateway: one monthly budget that a group's members share, on top of each member's own limit, set with `pooled_budget` on the spend limits admin API

## 概要

グループ単位で共有する月次予算を設定できます。各メンバーの個別上限も引き続き適用されるため、個人とチームの両方で支出を管理できます。

## 基本的な使い方

spend limits 管理 API のグループ設定で `pooled_budget` を指定します。

## 実践例

### チーム全体の月額上限を設ける

個人上限を維持したまま、チーム合計の月次支出に上限を設けられます。リクエスト形式の詳細は管理 API のドキュメントを参照してください。

## 注意点

- 個別上限とプール予算の両方が適用されます。
- 管理者向けの機能です。
