## 原文（日本語訳）

`spinnerTipsOverride` に `{id, text, cooldownSessions, priority}` 形式のエントリ、`tipsFile`、`label` が追加されました。これにより、組織は自作のTipsを組み込みのTipsと一緒にローテーション表示できるようになります。

## 原文（英語）

Added `{id, text, cooldownSessions, priority}` entries, `tipsFile`, and `label` to `spinnerTipsOverride`, so organizations can rotate their own tips alongside the built-in ones

## 概要

Claude Codeは処理中のスピナー表示に合わせて、使い方のTipsをランダムに表示する機能があります。従来 `spinnerTipsOverride` は組み込みTipsを完全に置き換えるだけの単純な仕組みでしたが、今回の拡張で各Tipに `cooldownSessions`（表示間隔のクールダウン）や `priority`（優先度）を持たせたり、`tipsFile` で外部ファイルからTips一覧を読み込んだり、`label` でTipsの出典を表示したりできるようになりました。組織が独自のオンボーディングTipsやポリシー周知を、Claude Code標準のTipsと自然に混在させて配信できます。

## 基本的な使い方

`settings.json` に `spinnerTipsOverride` としてTipsのエントリ配列を設定します。

```json
{
  "spinnerTipsOverride": [
    {
      "id": "org-onboarding-1",
      "text": "社内のCLAUDE.mdの書き方ガイドは docs/claude-md-guide.md を参照してください",
      "cooldownSessions": 5,
      "priority": 1
    }
  ]
}
```

## 実践例

### 社内オンボーディングTipsを配信する

新入社員がClaude Codeを使い始める際に知っておくべき社内ルールやよく使うコマンドを、Tipsとして自動的にローテーション表示できます。

```json
{
  "spinnerTipsOverride": [
    { "id": "onboarding-mcp", "text": "社内MCPサーバーへの接続方法は Wiki を参照", "priority": 2 }
  ]
}
```

### 外部ファイルでTipsを一元管理する

Tipsの数が多い場合や複数チームで共有したい場合は、`tipsFile` で外部ファイルを指定し、設定ファイル本体を煩雑にせずに管理できます。

```json
{
  "spinnerTipsOverride": {
    "tipsFile": ".claude/spinner-tips.json",
    "label": "社内Tips"
  }
}
```

### 表示頻度をコントロールする

告知したい情報の重要度に応じて `priority` を上げたり、`cooldownSessions` で「一定セッション数が経過するまで再表示しない」といった制御ができ、同じTipsが毎回表示されてうるさくなるのを防げます。

## 注意点

- `cooldownSessions` はセッション単位のクールダウンであり、同一セッション内での重複表示制御ではありません
- `tipsFile` で指定したファイルの形式は `spinnerTipsOverride` のエントリ配列と同様のスキーマに従う必要があります
- `label` を設定すると、Tips表示時に出典（組織名やチーム名など）が分かるようになり、組み込みTipsと見分けやすくなります
- 組み込みTipsを完全に無効化したい場合は、従来通りの置き換え指定も可能です
