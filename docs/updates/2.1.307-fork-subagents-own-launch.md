# 同時起動したフォークサブエージェントが自分の担当を認識するように改善

## 原文（日本語に翻訳）

- 同時に起動したフォークサブエージェントを改善：それぞれにどの起動が自分のものかが伝えられるようになり、互いの作業を開始しようとすることが大幅に減りました

## 原文（英語）

- Improved fork subagents launched together: each is now told which launch is its own, so forks are much less likely to try to start each other's work

## 概要

複数のフォークを並列で起動すると、フォーク同士が他方の担当タスクまで実行しようとする問題がありました。各フォークに自分の起動内容が明示されることで、役割の重複が起きにくくなります。

## 基本的な使い方

```
この3つのモジュールのレビューを、それぞれ別のフォークで並列に実行して
```

## 実践例

### 並列レビュー

モジュールごとにフォークを立てても、各フォークが担当モジュールだけを処理します。

### 並列調査

調査項目を分けて同時に起動しても、同じ調査を重複して行うことが減ります。

## 注意点

- 「ほとんど起こりにくくなる」改善であり、完全に防げる保証ではありません。
- 各フォークへの指示は、担当範囲が明確になるよう書くと効果的です。
