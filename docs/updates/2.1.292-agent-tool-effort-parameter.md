## 原文（日本語訳）

Agentツールに `effort` パラメータを追加した。Claudeは、指定された effort レベルでサブエージェントを実行する。

## 原文（英語）

Added an `effort` parameter to the Agent tool, so Claude runs a sub-agent at the effort level you ask for

## 概要

サブエージェントごとに推論の effort レベルを指定できるようになりました。重い調査には高く、単純な作業には低く、といった使い分けができます。

## 基本的な使い方

プロンプトで effort を指示すると、Claudeがその値をAgentツールの `effort` として渡します。

```text
サブエージェントを使って、このリポジトリのテスト構成を調べて。effortは低めで。
```

## 実践例

### 用途に応じた使い分け

```text
セキュリティ観点のレビューはサブエージェントを高いeffortで実行し、
ファイル一覧の整理は低いeffortで実行してください。
```

## 注意点

- 指定できる値や既定値の詳細は公式ドキュメントを確認してください。
- effort を高くすると、時間やトークン消費が増える傾向があります。
