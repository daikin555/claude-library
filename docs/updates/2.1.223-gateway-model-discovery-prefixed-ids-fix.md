## 原文（日本語に翻訳）

`vertex_ai/claude-*` や `bedrock/anthropic.claude-*` のようなプロバイダプレフィックス付きIDで登録されたClaudeモデルが、ゲートウェイのモデル検出機能で表示されなくなっていた不具合を修正しました。

## 原文（英語）

Fixed gateway model discovery hiding Claude models registered under provider-prefixed IDs such as `vertex_ai/claude-*` or `bedrock/anthropic.claude-*`

## 概要

Claude Codeは `ANTHROPIC_BASE_URL` でAnthropic Messages形式のLLMゲートウェイを利用している場合、`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` を設定することで、起動時にゲートウェイの `GET /v1/models` エンドポイントを呼び出し、返ってきたモデル一覧を `/model` ピッカーに追加できます。この判定は各モデルの `id` に `claude` または `anthropic` という文字列が含まれるかどうかで行われますが、修正前のバージョンでは `id` が `claude` または `anthropic` で「始まる」ものしか採用しておらず、`vertex_ai/claude-sonnet-4-6` や `bedrock/anthropic.claude-sonnet-4-5` のようにプロバイダ名がプレフィックスとして付いたIDは検出対象から漏れていました。v2.1.223では、`id` の文字列中に `claude` または `anthropic` が（大文字小文字を区別せず）どこかに含まれていれば拾うように判定ロジックが修正され、Google Cloud's Agent Platform（旧Vertex AI）やAmazon Bedrock経由でゲートウェイに登録されたClaudeモデルも、正しく `/model` ピッカーに「From gateway」として表示されるようになりました。

## 基本的な使い方

ゲートウェイ経由でモデル検出を有効にするには、環境変数または設定ファイルで以下を指定します。

```bash
export ANTHROPIC_BASE_URL="https://your-gateway.example.com"
export CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1
```

Claude Codeを起動して `/model` を実行すると、ゲートウェイから取得したモデルが一覧に表示されます。

```text
/model
```

## 実践例

### Google Cloud's Agent Platform（Vertex AI）経由のモデルをゲートウェイ配下で使う

ゲートウェイの `/v1/models` が `vertex_ai/claude-sonnet-4-6` のようなプレフィックス付きIDを返す構成でも、v2.1.223以降ではそのままピッカーに表示されます。

```json
{
  "data": [
    { "id": "vertex_ai/claude-sonnet-4-6", "display_name": "Claude Sonnet 4.6 (Vertex)" }
  ]
}
```

```text
/model
```

### Amazon Bedrock経由のモデルをゲートウェイ配下で使う

同様に、`bedrock/anthropic.claude-*` のようなBedrock由来のプレフィックス付きIDも検出されるようになりました。

```json
{
  "data": [
    { "id": "bedrock/anthropic.claude-opus-4-8", "display_name": "Claude Opus 4.8 (Bedrock)" }
  ]
}
```

### `managed settings` で検出対象を絞り込む

企業環境では `availableModels` を管理設定に指定することで、ゲートウェイが検出したモデルのうち利用を許可する範囲を制限できます。

```json
{
  "availableModels": ["opus", "claude-sonnet-4-6"]
}
```

## 注意点

- 本修正はClaude Code v2.1.223以降で有効です。それ以前のバージョンでは、プロバイダプレフィックス付きIDのモデルがピッカーから漏れる可能性があります。
- モデル検出は既定で無効です。共有APIキーを使うゲートウェイでは、キーがアクセスできる全モデルが全ユーザーに見えてしまうことを避けるため、`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` を明示的に設定する必要があります。
- 検出対象はAnthropic Messages形式のゲートウェイのみで、`CLAUDE_CODE_USE_BEDROCK` や `CLAUDE_CODE_USE_VERTEX` などのプロバイダ変数が設定されている場合や、`ANTHROPIC_BASE_URL` が未設定・`api.anthropic.com` を指している場合は動作しません。
- 検出結果は `~/.claude/cache/gateway-models.json` にキャッシュされ、起動のたびに再取得されます。リクエストが失敗した場合は前回のキャッシュ、それも無ければ組み込みのモデル一覧にフォールバックします。
- `id` に `claude` や `anthropic` という文字列を含まない独自エイリアスでゲートウェイがモデルを公開している場合は、この自動検出では拾えないため、`ANTHROPIC_DEFAULT_*_MODEL` 系の環境変数で手動設定する必要があります。
