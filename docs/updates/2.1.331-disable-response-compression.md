# CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION 環境変数を追加

## 原文（日本語に翻訳）

圧縮されたレスポンスを途中で切ってしまうプロキシ配下で、非圧縮のモデル応答を要求するための `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` を追加しました。セルフホストランナーや Remote Control では、まだ推奨されません。

## 原文（英語）

Added `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` to ask for uncompressed model responses behind a proxy that cuts compressed ones off; not advised yet for self-hosted runners or Remote Control

## 概要

プロキシが圧縮レスポンスを切り詰めて応答が途中で終わる場合に、この環境変数で非圧縮の応答を要求できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION=1
claude
```

## 実践例

### 社内プロキシ経由での利用

```json
{
  "env": {
    "CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION": "1"
  }
}
```
上記を `settings.json` に記載すると、毎回の export が不要になります。

## 注意点

- 通信量が増える可能性があります。
- セルフホストランナーと Remote Control では現時点で推奨されていません。
