## 原文（日本語訳）
[Claude Tag] ルーティンやスレッドからそのチャンネルに投稿し続けている最中でも、Claudeがそのチャンネルを非アクティブと判定し、タグ付けされていないメッセージをスキップしてしまう不具合を修正。

## 原文（英語）
[Claude Tag] Fixed Claude treating a channel as inactive, and skipping untagged messages there, while it was still posting in that channel from a routine or a thread

## 概要
Claude Tagは、しばらく利用がないチャンネルを「非アクティブ」と判定し、@メンションなどでタグ付けされていないメッセージへの反応を控える仕組みを持っています。しかし、実際にはルーティンやスレッドを通じてそのチャンネルに投稿を続けている最中であっても誤って非アクティブと判定され、タグ付けされていないメッセージが無視されてしまう不具合がありました。今回の修正により、ルーティンやスレッドからの投稿が継続しているチャンネルは正しくアクティブと認識され、意図しないメッセージのスキップが解消されます。

## 基本的な使い方
特別な設定は不要です。ルーティンやスレッドを介してチャンネルにClaudeが投稿している状況であれば、そのチャンネル内のタグなしメッセージも通常通り拾われるようになります。

## 実践例

### ルーティンが定期投稿しているチャンネルでの会話
毎朝ルーティンがステータスレポートを投稿しているチャンネルで、チームメンバーがそのレポートについてタグ付けせずにコメントした場合、修正前はそのコメントが無視されることがありましたが、修正後はルーティンが投稿し続けている限りチャンネルはアクティブと判定され、コメントが正しく処理されます。

```
9:00 ルーティンが日次レポートを投稿
9:05 メンバー: 「このグラフの数値が気になる」（タグなし）
→ 修正前: 非アクティブ判定でスキップされる場合があった
→ 修正後: アクティブなチャンネルとして正しく反応
```

### 進行中のスレッドがあるチャンネル
Claudeとの長いスレッドが続いているチャンネルで、他のメンバーがスレッド外にタグなしでコメントした場合も、チャンネルの投稿状況が正しく評価されるようになりました。

## 注意点
- 「非アクティブ」判定自体の仕組みは維持されており、実際に投稿がしばらくないチャンネルではタグなしメッセージがスキップされる挙動は変わりません。
- 本修正はルーティンやスレッドからの継続的な投稿がある場合の誤判定に限定した修正です。
