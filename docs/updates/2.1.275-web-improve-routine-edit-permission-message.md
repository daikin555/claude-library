## 原文（日本語訳）
[Claude Code on the web] Claudeが作成していないルーティンの編集・削除・実行を依頼された際のメッセージを改善。ルーティンのページへのリンクを表示し、ユーザー自身で操作できるようにした。

## 原文（英語）
[Claude Code on the web] Improved what Claude tells you when asked to edit, delete or run a routine it didn't create: it now links to the routine's page so you can do it yourself

## 概要
Claude Code on the webでは、Claudeに対してチャット上で「このルーティンを編集して」「削除して」「実行して」と依頼できますが、そのルーティンをClaude自身が作成したものでない場合は直接操作できません。今回の改善により、そのような場合にClaudeが単に「できません」と答えるのではなく、該当ルーティンのページへのリンクを提示し、ユーザーが自分でその場から操作できるようにガイドしてくれるようになりました。

## 基本的な使い方
チャットで他人が作成したルーティンの編集・削除・実行を依頼すると、Claudeがそのルーティンのページへのリンクを含む案内を返します。

```
ユーザー: 「〇〇ルーティンを削除して」
Claude: 「このルーティンは私が作成したものではないため直接削除できません。
          こちらのページから削除できます: [ルーティンのページへのリンク]」
```

## 実践例

### チームメンバーが作成したルーティンの編集を依頼する場合
同僚が設定したルーティンの実行タイミングを変更したい場合、Claudeにチャットで依頼すると、直接編集はできない旨とともにルーティン設定ページへのリンクが提示され、そこから自分で編集できます。

### 不要になった他人作成のルーティンを削除したい場合
Claudeにルーティンの削除を依頼すると、権限がないため代わりにルーティンページへのリンクが案内され、ワンクリックで削除画面に遷移できます。

```
ユーザー: 「古いデプロイルーティンを消して」
Claude: 「私が作成したルーティンではないため削除できません。
          [ルーティンページ] から削除してください。」
```

## 注意点
- Claudeが作成したルーティンについては、引き続きチャット上から直接編集・削除・実行を依頼できます。
- リンク先のルーティンページを操作するには、該当ルーティンへのアクセス権限が必要です。
