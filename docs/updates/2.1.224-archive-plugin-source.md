## 原文（日本語訳）

`archive` プラグインソースを追加：gitやnpmを使わずに、HTTPS経由のzipファイルからプラグインをインストールできます。オプションでSHA-256によるピン留めも可能です。

## 原文（英語）

Added `archive` plugin source: install plugins from a zip over HTTPS without git or npm, with optional SHA-256 pinning

## 概要

これまでClaude Codeのプラグインは、GitHub・gitリポジトリ・npm・ローカルパスといったソースからインストールする必要がありました。新しく追加された `archive` ソースタイプを使うと、任意の静的ファイルサーバーやアーティファクトリポジトリ（S3バケット、Artifactory、nginxなど）にホストしたzipファイルをHTTPS経由でダウンロードするだけでプラグインをインストールでき、利用者側のマシンにgitやnpmがなくても動作します。さらに `sha256` フィールドでアーカイブのダイジェストをピン留めすれば、改ざんされていない特定のファイルだけを許可する、より安全な配布も可能です。

## 基本的な使い方

`marketplace.json` のプラグインエントリで `source.source` を `"archive"` にし、zipファイルのHTTPS URLを指定します。

```json
{
  "name": "my-plugin",
  "source": {
    "source": "archive",
    "url": "https://artifacts.example.com/claude-plugins/my-plugin-2.1.0.zip"
  }
}
```

zipはプラグインの中身を直接圧縮しても、プラグインフォルダごと圧縮しても構いません。Claude Codeはアーカイブ直下、または1階層下のフォルダ内にある `.claude-plugin/` を探してインストールします。

## 実践例

### 社内アーティファクトリポジトリから配布する

CIでビルドしたプラグインのzipをS3やArtifactoryにアップロードし、そのURLをマーケットプレイスに登録して社内配布します。

```json
{
  "$schema": "https://code.claude.com/schema/marketplace.json",
  "name": "internal-plugins",
  "owner": { "name": "Platform Team" },
  "plugins": [
    {
      "name": "internal-lint",
      "source": {
        "source": "archive",
        "url": "https://artifacts.internal.example.com/plugins/internal-lint-1.2.0.zip"
      }
    }
  ]
}
```

### SHA-256でアーカイブをピン留めする

配布ファイルの改ざんやすり替えを防ぎたい場合は、`sha256` フィールドにダイジェストを指定します。ダウンロードしたファイルがこの値と一致しない場合、Claude Codeはインストールを拒否し `Plugin archive integrity check failed` を報告します。

```json
{
  "name": "my-plugin",
  "source": {
    "source": "archive",
    "url": "https://artifacts.example.com/claude-plugins/my-plugin-2.1.0.zip",
    "sha256": "6bfa50e3d2e00c052b46abe51fff89346ac803e45771f76dcf6df1ab74cca5e1"
  }
}
```

### `--plugin-url` でセッション限定で試す

マーケットプレイスに登録せず、CIビルド成果物のzipをそのセッションだけで試したい場合は `--plugin-url` フラグが使えます。

```bash
claude --plugin-url https://example.com/my-plugin.zip

# 複数指定も可能
claude --plugin-url https://example.com/a.zip --plugin-url https://example.com/b.zip
```

## 注意点

- `archive` ソースはClaude Code v2.1.224以降が必要です。v2.1.120〜v2.1.223では該当プラグインのインストールが失敗し、それより前のバージョンではマーケットプレイス自体の読み込みに失敗します。
- `http://` のURLやループバック・リンクローカル・クラウドメタデータ用ホストへのURLは拒否されます。リダイレクト先も同じ条件を満たす必要があります。
- アーカイブは256MiBを超えると拒否されます。
- Claude Codeはアーカイブの1階層より深いネストは探索しないため、プラグインをそれより深い場所に配置すると失敗します。
- `version` を明示しない場合、`sha256` ダイジェストがそのままプラグインのバージョン識別子として扱われます。ファイルを更新してダイジェストを変えたら、`version` も明示的に上げないと更新が検知されないことがあります。
- 相対パスを使うプラグインエントリはURLベースのマーケットプレイス配布には対応していないため、`archive` などの外部ソースに切り替える必要があります。
