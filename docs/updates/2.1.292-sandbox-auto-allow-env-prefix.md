## 原文（日本語訳）

サンドボックスの自動許可を改善した。ユーザー設定、管理設定、または `--settings` で厳格サンドボックスモードを設定している場合、`FOO=bar python3 app.py` のように環境変数プレフィックスが付いたインタープリタコマンドが確認なしで実行される。

## 原文（英語）

Improved sandbox auto-allow: with strict sandbox mode set in user, managed or --settings settings, an interpreter command with an env var prefix like `FOO=bar python3 app.py` runs unprompted

## 概要

厳格サンドボックスモードでは、環境変数を前置したインタープリタコマンドも許可プロンプトなしで実行されるようになりました。

## 基本的な使い方

```bash
FOO=bar python3 app.py
```

## 実践例

### 環境変数を切り替えながらのスクリプト実行

```bash
DEBUG=1 node script.js
```

サンドボックス内で実行されるため、毎回承認する手間が減ります。

## 注意点

- 厳格サンドボックスモードがユーザー、管理、`--settings` のいずれかで設定されている場合が対象です。
