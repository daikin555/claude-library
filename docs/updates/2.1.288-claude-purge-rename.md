## 原文（日本語訳）

`claude project purge` を `claude purge` に変更した。旧名称も引き続き動作し、通知が表示される。

## 原文（英語）

Changed `claude project purge` to `claude purge`; the old name still works and prints a notice

## 概要

プロジェクトの保存データを削除するコマンドが、短い `claude purge` になりました。従来の `claude project purge` もそのまま使えますが、新名称への移行を促す通知が表示されます。

## 基本的な使い方

```bash
claude purge
```

## 実践例

### スクリプトを新名称へ更新する

```bash
# 変更前
claude project purge
# 変更後
claude purge
```

### 旧名称の通知を確認する

CIなどで旧名称を使っている場合、ログに通知が出ます。出力を確認して順次置き換えてください。

## 注意点

- 旧名称は現時点で動作しますが、将来的に廃止される可能性があります。
- 削除は元に戻せない操作です。実行前に対象を必ず確認してください。
- オプションの詳細は `claude purge --help` で確認してください。
