## 原文（日本語に翻訳）

設定ファイルおよびmodの `$.env.set` における `DISABLE_COMPACT` を、compactionをオフにすることだけができ、オンに戻すことはできないように変更しました。

## 原文（英語）

Changed `DISABLE_COMPACT` in settings files and in a mod's `$.env.set` so they can only turn compaction off, not back on

## 概要

設定ファイルやmodから `DISABLE_COMPACT` を設定する場合、compactionを「無効にする」方向にしか働かなくなりました。下位の設定が、上位で無効化された状態を勝手に有効へ戻すことを防ぎます。

## 基本的な使い方

```json
{
  "env": {
    "DISABLE_COMPACT": "1"
  }
}
```

## 実践例

### 組織ポリシーでの固定

管理者が配布する設定でcompactionを無効にした場合、プロジェクト側の設定で戻されません。

### 関連する修正

同リリースでは、`DISABLE_COMPACT` 設定時にエージェントチームメイトが履歴をcompactしてしまう問題と、rewindメニューに「Summarize from here」「Summarize up to here」が表示される問題も修正されています。

## 注意点

- 設定ファイルの値で再度有効化することはできません。
- 無効化中はコンテキスト上限に注意してください。
