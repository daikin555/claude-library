## 原文（日本語訳）

Claude DesktopなどのSDKホスト型セッションで、Fableの利用クレジットに関するプロンプトに応答しなかった場合にモデルが切り替わってしまう不具合を修正しました。現在はそのターンが終了するようになり、Remote Controlクライアント側でもモデル切替の通知が表示されるようになりました。

## 原文（英語）

Fixed an unanswered Fable usage-credits prompt switching models in SDK-hosted sessions such as Claude Desktop; the turn now ends instead, and Remote Control clients now see the model-switch notice

## 概要

FableモデルはプランによってはAPI利用に「利用クレジット」の有効化が必要ですが、その確認プロンプトにユーザーが応答しないまま放置すると、Claude Desktopなど Agent SDK でホストされたセッションでは、意図せず別のモデルに自動的に切り替わってしまう問題がありました。今回の修正で、未応答の場合はモデルを切り替えずにそのターンが終了するようになりました。また、Remote Control経由で接続しているクライアント側にも、モデル切替が発生した際の通知が正しく表示されるようになりました。

## 基本的な使い方

Fableモデルの利用クレジットに関するプロンプトが表示された場合は、意図したモデルを使い続けるために明示的に応答（有効化するかどうかを選択）してください。

## 実践例

### Claude Desktopでの意図しないモデル変更の防止

Claude Desktopで作業中に利用クレジットのプロンプトを見逃しても、意図しないモデルに切り替わったまま作業が進んでしまう事態を避けられます。

### Remote Control経由でのモデル状態の把握

スマートフォンなどRemote Controlのクライアント側からセッションを見ている場合でも、モデル切替が発生したことを通知で確認できるようになり、状況を把握しやすくなります。

## 注意点

- 利用クレジットが必要なプランでFableモデルを使う場合、事前にクレジットを有効化しておくとプロンプトの発生自体を避けられます
- この修正はSDKホスト型セッション（Claude Desktopなど）に特有の挙動を対象としています
