## 原文（日本語訳）
AskUserQuestionのプレビューノートが、ハイライトされている選択肢ではなく、以前に選択した選択肢に添付されてしまう問題を修正しました。

## 原文（英語）
Fixed AskUserQuestion preview notes being attached to a previously chosen option instead of the highlighted one

## 概要
AskUserQuestionツールは、Claudeがユーザーに選択肢を提示して確認を取る際に使われる機能です。ユーザーが選択肢をハイライトしながらメモ（ノート）を入力すると、そのノートは本来ハイライト中の選択肢に紐付くべきですが、以前に選んだ別の選択肢に誤って添付されてしまう不具合がありました。今回の修正により、ノートは常に現在ハイライトされている選択肢に正しく関連付けられるようになりました。

## 基本的な使い方
AskUserQuestionのプロンプトが表示された際、矢印キーなどで選択肢を移動しながら、各選択肢に対する補足メモを入力できます。

```
選択肢1: このファイルを削除する
選択肢2: このファイルをリネームする  ← ハイライト中
  メモ: 「old_」プレフィックスを付けてリネームしてほしい
```

## 実践例

### 修正前の挙動
選択肢Aを一度選んだ後、選択肢Bにハイライトを移動してメモを入力すると、そのメモが選択肢Aに紐付いてしまうことがありました。

### 修正後の挙動
選択肢Bにハイライトを移動してメモを入力すると、メモは正しく選択肢Bに紐付きます。複数の選択肢を比較検討しながらそれぞれに異なるメモを残すワークフローが正確に動作するようになりました。

## 注意点
- この修正はAskUserQuestionのプレビュー/確認フロー内での挙動に関するものです。
- ノートを入力する前に、意図した選択肢がハイライトされていることを確認する習慣は引き続き有効です。
