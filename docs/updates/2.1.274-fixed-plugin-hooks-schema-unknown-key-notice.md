## 原文（日本語訳）
`hooks/hooks.json`のトップレベルに`$schema`を持つプラグインで「unknown key（不明なキー）」という通知が表示されていた問題を修正。

## 原文（英語）
Fixed plugins with a top-level `$schema` in `hooks/hooks.json` showing an "unknown key" notice

## 概要
JSON Schemaによるエディタ補完やバリデーションを有効にするため、`hooks/hooks.json`のトップレベルに`$schema`キーを付与するプラグイン開発者は珍しくありません。しかし、これまでClaude Codeはこのキーを認識せず、「unknown key」という誤った警告通知を表示していました。今回の修正でこの誤検知がなくなり、`$schema`を使ったプラグインでも警告なしに動作するようになりました。

## 基本的な使い方
プラグインの`hooks/hooks.json`にエディタ補完用の`$schema`キーを追加しても、余計な警告が出なくなります。

```json
{
  "$schema": "https://example.com/schemas/hooks.schema.json",
  "hooks": {
    "PreToolUse": []
  }
}
```

## 実践例

### エディタでのスキーマ補完を有効にしたいプラグイン開発者
VS CodeなどのエディタでJSONのスキーマ補完・検証を効かせるために`$schema`を追加している場合、修正前は起動のたびに「unknown key」の通知が表示されて煩わしい状態でした。修正後はこの通知が出なくなり、開発体験が改善されます。

```json
{
  "$schema": "./hooks.schema.json",
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Bash",
        "hooks": [{ "type": "command", "command": "echo done" }]
      }
    ]
  }
}
```

### 既存プラグインを配布用に整備する場合
プラグインを公開する前に`hooks.json`をスキーマ検証付きで整備するケースでも、この修正により`$schema`キーを安心して含められるようになりました。

## 注意点
- この修正は表示上の誤った警告を取り除くものであり、`$schema`の値そのものをClaude Codeが検証するわけではありません。
- 古いバージョンのClaude Codeを使っている場合は依然としてこの通知が表示される可能性があるため、最新版へのアップデートを推奨します。
