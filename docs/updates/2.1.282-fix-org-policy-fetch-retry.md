## 原文（日本語訳）

別のClaude Codeウィンドウがサインインを更新している最中に開始されたセッション（複数のVS Codeウィンドウを開いている場合によくある状況）が、組織のポリシー取得を再試行しない不具合を修正しました。

## 原文（英語）

Fixed sessions started while another Claude Code window was refreshing the sign-in (common with several VS Code windows) not retrying their organization policy fetch

## 概要

複数のVS Codeウィンドウでそれぞれ Claude Code を開いている場合、あるウィンドウがサインイン情報の更新（トークンリフレッシュ）を行っている最中に別のウィンドウで新しいセッションを開始すると、そのセッションが組織のポリシー（利用可能なモデルや機能の制限など）の取得に失敗したまま再試行されない不具合がありました。今回の修正で、こうした状況でも正しく再試行され、組織ポリシーが反映されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。複数のVS Codeウィンドウを併用する通常の使い方の中で自動的に修正が適用されます。

## 実践例

### 複数リポジトリを並行して開発する場合

複数のプロジェクトをそれぞれ別のVS Codeウィンドウで開き、同時にClaude Codeを使う開発スタイルでも、組織ポリシーが正しく適用された状態でセッションを開始できます。

### エンタープライズ環境でのポリシー適用の確実性向上

企業の管理者が設定したモデル制限やツール制限などの組織ポリシーが、タイミングの問題で反映されないまま作業が進んでしまうリスクが減ります。

## 注意点

- 単一のVS Codeウィンドウのみを使用している場合はこの不具合の影響を受けにくいです
- 組織ポリシーが正しく反映されているかは `claude doctor` などで確認できます
