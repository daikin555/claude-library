## 原文（日本語訳）

`/mcp` のサーバーのページに「Server message」行を追加しました。接続を拒否したリモートHTTP MCPサーバーのJSON-RPCエラーメッセージを表示します。

## 原文（英語）

Added a "Server message" row to a server's page in `/mcp` that shows the JSON-RPC error message of a remote HTTP MCP server that refuses the connection

## 概要

リモートHTTP MCPサーバーが接続を拒否したとき、サーバーが返したJSON-RPCエラーメッセージを `/mcp` のサーバーページで直接確認できます。これまで原因が分かりにくかった接続失敗の切り分けが楽になります。

## 基本的な使い方

```
/mcp
```

失敗しているサーバーを選び、ページ内の「Server message」行を確認します。

## 実践例

### 接続拒否の原因調査

メッセージに認証不足やバージョン不一致が示されていれば、設定やトークンの見直しに進めます。

### サーバー管理者への報告

表示された文言をそのままサーバー提供元に共有すると、調査が早く進みます。

## 注意点

- 行が表示されるのは、サーバーが接続を拒否してメッセージを返した場合です。
- メッセージの内容はサーバー実装に依存します。
