## 原文（日本語訳）

空の `!` 入力からCtrl+Dで終了した後、エージェントビューがシェルモードで再開される問題を修正しました

## 原文（英語）

Fixed agent view reopening in shell mode after exiting with Ctrl+D from an empty `!` input

## 概要

`!` でシェルモードに入り、空のままCtrl+Dで終了すると、次回もシェルモードで開いてしまっていました。通常の入力モードで開くよう修正されています。

## 基本的な使い方

1. `!` を入力してシェルモードに入る
2. 空のままCtrl+Dで終了する
3. 次回起動時は通常モードで開く

## 実践例

### 意図しないシェル実行の防止

通常のプロンプトのつもりで入力した文がシェルコマンドとして扱われる誤操作を防げます。

## 注意点

- シェルモードは `!` で明示的に入ります。
