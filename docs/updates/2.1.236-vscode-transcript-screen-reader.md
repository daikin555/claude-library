## 原文（日本語訳）

［VSCode］トランスクリプトにスクリーンリーダー対応を追加しました。返信・権限リクエスト・エラー・状態変化のライブ通知の読み上げに加え、ターンごとの見出しナビゲーションにも対応します。

## 原文（英語）

[VSCode] Added screen reader support for the transcript: live announcements for replies, permission requests, errors, and status changes, plus per-turn heading navigation

## 概要

Claude Code VS Code拡張機能では、会話のやり取りがサイドパネルのトランスクット（会話履歴）に表示されます。これまでこのトランスクリプト部分はスクリーンリーダーにとって扱いづらく、Claudeの返信や権限確認ダイアログ、エラー、状態変化に気づくためには画面を目視する必要がありました。今回の更新で、これらの出来事が発生した際にスクリーンリーダーへライブで読み上げ通知が送られるようになり、さらに各ターン（やり取りの単位）に見出しが付与されたことで、見出しジャンプ機能を使ってトランスクリプトを効率的に移動できるようになりました。

## 基本的な使い方

VS Code上でスクリーンリーダー（VoiceOverやNVDAなど）を使用している状態でClaude Code拡張機能のトランスクリプトパネルにフォーカスすると、Claudeからの返信や権限リクエストのダイアログ、エラーメッセージ、状態の変化が発生するたびに自動的に読み上げ通知が入るようになります。

```
# VS Codeの拡張機能サイドパネルでClaude Codeを開き、
# 会話を進める
# → 返信・権限リクエスト・エラー・状態変化のたびにライブ通知が読み上げられる
```

また、スクリーンリーダーの見出しジャンプ機能（例: NVDAの `H` キー）を使うと、トランスクリプト内をターン単位でジャンプしながら移動できます。

## 実践例

### 権限リクエストへの応答を待っているとき

Claudeがファイル編集やコマンド実行の許可を求めると、画面を注視していなくてもスクリーンリーダーがそのタイミングでライブ通知を読み上げるため、権限プロンプトが表示されたことにすぐ気づけます。

### 長い会話履歴の中で特定のやり取りを探すとき

会話が長くなり、トランスクリプトに多くのターンが積み重なった場合でも、ターンごとに見出しが割り当てられているため、見出しナビゲーションで目的のやり取りまで飛び移動でき、内容を1行ずつ読み進める必要がありません。

### ツール実行中にエラーが発生したとき

コマンド実行やファイル編集の途中でエラーが起きた場合も、状態変化として即座にライブ通知が読み上げられるため、処理が失敗したことに気づかないまま待ち続ける事態を防げます。

## 注意点

- この機能はVS Code拡張機能のトランスクリプトパネルを対象としたもので、CLIのターミナル上で使う `--ax-screen-reader` によるスクリーンリーダーモードとは別の実装です
- スクリーンリーダー自体（VoiceOver、NVDAなど）が有効になっている必要があり、Claude Code側が自動的にスクリーンリーダーの使用を検知して切り替えるわけではありません
- 見出しナビゲーションの具体的なキー操作は、使用しているスクリーンリーダーとOSの組み合わせによって異なります
