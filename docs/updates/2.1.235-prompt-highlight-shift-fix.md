## 原文（日本語訳）

一部の複数行プロンプトにおいて、プロンプト入力欄のハイライト（スラッシュコマンド、キーワード、メンション）が1文字以上ずれて表示される不具合を修正しました。

## 原文（英語）

Fixed prompt input highlights (slash commands, keywords, mentions) appearing shifted by one or more characters in some multi-line prompts

## 概要

Claude Codeのプロンプト入力欄では、`/`から始まるスラッシュコマンドや、`@`によるファイル・エージェントのメンション、特定のキーワードなどが色付きでハイライト表示され、入力内容を視覚的に把握しやすくなっています。しかし一部の複数行プロンプトでは、このハイライトが実際の文字位置から1文字以上ずれて表示され、色付けされる範囲が本来のトークンと一致しない不具合がありました。今回の修正により、複数行のプロンプトでもハイライト位置が正しい文字位置に一致するようになりました。

## 基本的な使い方

特別な操作は不要です。複数行のプロンプトを入力すると、スラッシュコマンドやメンションが正しい位置に色付き表示されるようになります。

```
> 以下のバグを調査してください
  @src/utils/parser.ts のパース処理と
  /test コマンドの実行結果を照らし合わせて原因を特定して
```

修正前は上記のような複数行プロンプトで `@src/utils/parser.ts` や `/test` のハイライト範囲が本来の文字位置からずれて表示されることがありましたが、修正後は正しい位置に表示されます。

## 実践例

### ファイルメンションを含む長いプロンプトを書く

複数行にわたる説明の途中で `@` によるファイルメンションを使う場合でも、メンション部分が正確な位置でハイライトされます。

```
> このコンポーネントのスタイルを直してほしい
  対象は @src/components/Header.tsx で、
  デザインは @docs/design/header-spec.md を参照して
```

### 複数行にスラッシュコマンドとキーワードが混在する場合

改行を挟んで複数のコマンドやキーワードを記述しても、それぞれが独立して正しくハイライトされるようになりました。

```
> まず /clear してから
  TODO: 認証まわりのリファクタリングを実施し
  最後に /review で確認して
```

### 貼り付けた長文にメンションを追記する

エディタなどからコピーした長い複数行テキストの末尾に `@ファイル名` を追記するようなワークフローでも、ハイライトのズレによって誤って別の単語が強調されるといった混乱がなくなります。

## 注意点

- これは表示上の見た目に関する修正であり、実際にClaude Codeへ送信されるプロンプトの内容やスラッシュコマンド・メンションの解釈自体には影響しません（修正前もハイライト表示だけがずれていました）
- 単一行のプロンプトでは元々問題が発生しにくいケースが多く、主に複数行プロンプトで顕著だった不具合です
- ターミナルのフォントや幅、絵文字・全角文字の混在などによって、ハイライトの見え方が環境依存で変わる場合があります
