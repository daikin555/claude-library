## 原文（日本語訳）

Claude Code DesktopまたはVS Codeから開始されたRemote Controlセッションは、パーミッションモードが変更されるたびにスマートフォンやclaude.ai/codeへその状態を通知するようになりました（claude.ai/codeについてはモデルの変更も通知されます）。

## 原文（英語）

Remote Control sessions started from Claude Code Desktop or VS Code now keep phones and claude.ai/code updated on the session's permission mode (and claude.ai/code on the model) as they change

## 概要

Remote Controlを使ってClaude Code DesktopやVS Code拡張機能からセッションを開始した場合、これまでローカル側でパーミッションモード（Ask / Accept Edits / Plan / Bypassなど）を切り替えても、スマートフォンアプリやclaude.ai/code側の表示にはリアルタイムで反映されないことがありました。今回のアップデートで、ローカル側でのパーミッションモードの変更が接続中のリモートクライアントに即座に同期されるようになり、claude.ai/codeではさらに使用中のモデル（Sonnet、Opusなど）の変更も同期されるようになりました。

## 基本的な使い方

この機能は自動的に動作します。ユーザー側の追加設定は不要です。

1. Claude Code DesktopまたはVS CodeでRemote Controlセッションを開始する
2. スマートフォンアプリまたはclaude.ai/codeから同じセッションに接続する
3. ローカル側（Desktop/VS Code）でパーミッションモードを切り替える（例: `Shift+Tab` でAccept Editsに変更）
4. スマホ/claude.ai/code側の表示が自動的に最新のパーミッションモードに更新される
5. claude.ai/codeの場合、使用モデルを変更すると、その情報もリアルタイムで反映される

## 実践例

### 外出先からセッション状況を正確に把握する

自宅のPCでVS Codeを使ってRemote Controlセッションを開始し、外出先でスマホアプリから接続した際、PC側でPlanモードからAccept Editsモードに切り替えた場合、以前はスマホ側の表示が古いままで混乱することがありました。修正後はスマホ画面にも即座に「Accept Edits」が反映されるため、今どの程度自動承認されているのかを正確に把握できます。

### claude.ai/codeでモデル変更を確認する

Desktopアプリ側でモデルをOpusからSonnetに切り替えた場合、claude.ai/codeのブラウザ画面でも自動的に現在のモデル名が更新されて表示されるため、ブラウザとローカルの表示がずれる心配がありません。

### チームメンバーとの共有確認

複数人でリモート接続を共有するようなワークフローでは、誰かがローカル側でパーミッションモードを変更した際に、他の閲覧者側の画面にも即座にその状態が反映されるため、現在どのモードでClaudeが動作しているか誤認するリスクが減ります。

## 注意点

- この同期はClaude Code DesktopまたはVS Codeから開始したRemote Controlセッションが対象です
- モデル情報の同期はclaude.ai/code向けであり、スマホアプリ側にはパーミッションモードのみが同期されます
- Remote Control自体の利用にはPro/Max/Team/Enterpriseプランが必要です（APIキー利用は非対応）
