## 原文（日本語訳）

メモリ使用量が危機的な状態になった際に、メモリを解放する手順や安全に再起動する手順を示す警告を表示するようになりました。

## 原文（英語）

Added a visible warning when memory usage is critical, with steps to free memory or restart safely

## 概要

長時間のセッションや大量のコンテキストを扱う作業では、Claude Codeのプロセスがメモリを大量に消費し、動作が不安定になることがあります。この変更により、メモリ使用量が危機的なレベルに達した際にターミナル上へ明示的な警告が表示され、メモリを解放する方法や安全に再起動する方法がその場で案内されるようになりました。ユーザーはクラッシュや応答停止に見舞われる前に、問題に気付いて対処できます。

## 基本的な使い方

特別な設定は不要です。通常どおりClaude Codeを使用していて、プロセスのメモリ使用量が危機的な水準に達すると、自動的に警告メッセージがCLI上に表示されます。

```
⚠ メモリ使用量が危機的な水準です。
  - 不要なファイルの読み込みやサブエージェントの起動を控えてください
  - `/compact` でコンテキストを圧縮するか、セッションを安全に再起動してください
```

## 実践例

### 大規模リポジトリを長時間探索しているとき

大量のファイルを読み込み続けるような長時間の調査タスクでは、メモリ使用量が徐々に増加します。警告が表示されたら、作業内容を保存した上で `/compact` を実行するか、セッションを再起動して安定性を回復できます。

```bash
# コンテキストを圧縮してメモリ負荷を下げる
/compact
```

### CIやバッチ処理でClaude Codeを長時間稼働させているとき

非対話的なバッチジョブなどで長時間プロセスを稼働させている場合、警告ログを監視することで、メモリ不足によるクラッシュを未然に防ぎ、安全なタイミングでプロセスを再起動する判断ができます。

## 注意点

- 警告はあくまで危機的な水準に達した際の通知であり、根本的なメモリ管理（十分なリソースを持つ環境で実行するなど)は引き続きユーザー側の責任です。
- 警告が出た状態で作業を続けると、応答が遅くなったり予期しない終了が発生する可能性があります。早めに `/compact` やセッションの再起動を検討してください。
