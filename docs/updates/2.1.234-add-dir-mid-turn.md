## 原文（日本語訳）

`/add-dir <path>` がClaudeの作業中でも使えるようになりました。また `/add-dir`、`/autocompact`、`/theme`、`/help`、`/config`、`/advisor` の各ダイアログが、フルスクリーンTUIにおいてターン実行中でも開けるようになりました。

## 原文（英語）

`/add-dir <path>` can now be used while Claude is working; `/add-dir`, `/autocompact`, `/theme`, `/help`, `/config` and `/advisor` dialogs open mid-turn in the fullscreen TUI

## 概要

これまで一部のスラッシュコマンドはClaudeが処理中（作業中）だと実行・表示できませんでした。今回の改善で `/add-dir` はClaudeの作業を中断せずにディレクトリを追加できるようになり、さらに `/autocompact`、`/theme`、`/help`、`/config`、`/advisor` といった設定・情報系ダイアログも、フルスクリーンTUIモードにおいてターン実行中に開けるようになりました。作業を止めずに設定確認や調整ができ、操作の流れが途切れにくくなります。

## 基本的な使い方

Claudeが作業中でも、以下のコマンドをそのまま入力してダイアログを開けます。

```
> /add-dir ../shared-lib
```

```
> /theme
> /help
> /config
> /autocompact
> /advisor
```

いずれも作業完了を待たずに開き、確認や変更を行った後は元の作業の続きを見守れます。

## 実践例

### 作業中に参照先ディレクトリを追加する

Claudeがモノレポ内の1つのパッケージで作業をしている最中に、共通ライブラリのディレクトリも参照させたくなった場合、作業を止めずに `/add-dir ../packages/shared` を実行すれば、そのままそのディレクトリを操作対象に加えられます。

### 長時間タスク中にテーマや設定を確認する

`/goal` などで長時間の自律タスクを走らせている間、ターミナルのテーマが見づらいと感じたら `/theme` を開いて調整したり、`/config` で現在の設定を確認したりでき、タスクの進行を妨げません。

### auto-compactの挙動を作業中に確認する

長いセッションでコンテキストが圧縮されるタイミングが気になる場合、Claudeの作業中でも `/autocompact` を開いて現在の設定や状態を確認できます。

### ヘルプやadvisorをすぐに参照する

操作方法を忘れた場合や `/advisor` の提案を確認したい場合も、Claudeの応答を待たずにその場でダイアログを開いて確認できます。

## 注意点

- この動作はフルスクリーンTUI（ターミナルUI）モードでの挙動です。非フルスクリーン環境や `-p`（print）モードでは対象外です
- ダイアログを開いている間もClaudeのバックグラウンド処理は継続しています
- `/add-dir` で追加したディレクトリの権限（読み書き可否）は通常の `/add-dir` と同様にパーミッション設定に従います
