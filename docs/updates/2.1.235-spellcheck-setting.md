## 原文（日本語訳）

プロンプト入力欄でスペルミスをタイプ中に下線表示できる、オプションの `spellcheck` 設定が追加されました。この機能は、インストール済みの `aspell`、`hunspell`、`ispell` のいずれかを利用します。

## 原文（英語）

Added an optional `spellcheck` setting that underlines misspelled words in the prompt input as you type, using your installed `aspell`, `hunspell`, or `ispell`

## 概要

Claude Codeのプロンプト入力欄に、タイプ中のスペルミスを検出して下線を引く機能が追加されました。ブラウザ内蔵のスペルチェッカーとは異なり、システムにインストールされている `aspell`・`hunspell`・`ispell` のいずれかを実行時に呼び出して判定するため、追加の辞書データやネットワーク通信は不要です。長文のプロンプトやドキュメントを書く際に、誤字脱字を早期に発見しやすくなります。

## 基本的な使い方

デフォルトでは無効になっているため、`settings.json` に `spellcheck` 設定を追加して有効化します。

```json
{
  "spellcheck": true
}
```

有効化した状態で `aspell`、`hunspell`、`ispell` のいずれかがローカル環境にインストールされていれば、プロンプト入力中にスペルミスと判定された単語へ自動的に下線が表示されます。

## 実践例

### macOS/Linuxでスペルチェッカーをインストールしてから有効化する

事前にいずれかのスペルチェックエンジンをインストールしておく必要があります。

```bash
# Debian/Ubuntu の場合
sudo apt-get install aspell

# macOS (Homebrew) の場合
brew install aspell
```

インストール後、`settings.json` で `spellcheck` を `true` にすると、Claude Codeが自動的にインストール済みのエンジンを検出して利用します。

### プロジェクト単位でスペルチェックを有効にする

チームでREADMEや設計ドキュメントの草稿をClaude Code上で書くことが多い場合、プロジェクトの `.claude/settings.json` に設定を追加しておくと、リポジトリを開いたメンバー全員に適用されます。

```json
{
  "spellcheck": true
}
```

### 個人設定としてグローバルに有効化する

特定のプロジェクトに限らず、常にスペルチェックを使いたい場合はユーザーレベルの設定ファイル（`~/.claude/settings.json`）に同じ設定を追加します。

```json
{
  "spellcheck": true
}
```

## 注意点

- `aspell`、`hunspell`、`ispell` のいずれかがシステムにインストールされていないと機能しません。事前にパッケージマネージャー等でインストールしておく必要があります
- デフォルトでは無効なオプトイン設定です。使いたい場合は明示的に `settings.json` で有効化してください
- 判定は日本語以外のロケール・辞書に依存する場合があるため、使用言語によっては誤検知が発生する可能性があります
- 下線はあくまで視覚的な補助であり、スペルミスを自動修正するものではありません
