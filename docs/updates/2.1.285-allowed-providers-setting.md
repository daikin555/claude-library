# 管理設定 allowedProviders で利用可能な API プロバイダーを制限する

## 原文（日本語訳）

- マシンが使用できる API プロバイダーを制限する管理設定 `allowedProviders` を追加しました（Anthropic API、カスタムエンドポイント、Bedrock、Mantle、Vertex AI、Foundry、Claude Platform on AWS、Cloud ゲートウェイ）

## 原文（英語）

- Added `allowedProviders` managed setting to limit which API providers a machine may use (Anthropic API, a custom endpoint, Bedrock, Mantle, Vertex AI, Foundry, Claude Platform on AWS, or a Cloud gateway)

## 概要

管理者が、組織の端末で使える API プロバイダーを限定できる管理設定です。データの送信先を Bedrock や Vertex AI などの承認済みプロバイダーに固定するガバナンス用途に向きます。

## 基本的な使い方

管理設定ファイル（managed settings）に記述します。

```json
{
  "allowedProviders": ["bedrock", "vertex"]
}
```

※ 値の正確な識別子は changelog に記載がないため、上記は例示です。公式ドキュメントで確認してください。

## 実践例

### 社内ゲートウェイのみ許可する

Cloud gateway 経由の利用に限定し、直接の Anthropic API 利用を禁止する構成が考えられます。

### クラウドベンダーを統一する

全社で Bedrock に統一している場合、他プロバイダーへの切り替えを防げます。

## 注意点

- 管理設定のため、MDM や managed-settings ファイルで配布します。
- ユーザー・プロジェクト設定で上書きできない運用を前提としています。
