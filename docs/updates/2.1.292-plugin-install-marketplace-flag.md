## 原文（日本語訳）

`claude plugin install` に `--marketplace <source>` を追加した。必要に応じてマーケットプレイスを追加し（`claude plugin marketplace add` と同じポリシーチェックを適用）、そこからプラグインをインストールする。

## 原文（英語）

Added `--marketplace <source>` to `claude plugin install`: adds the marketplace if needed, under the same policy checks as `claude plugin marketplace add`, then installs the plugin from it

## 概要

これまでマーケットプレイスの追加とプラグインのインストールは2段階の操作でした。`--marketplace` を使うと、1つのコマンドで追加とインストールをまとめて実行できます。

## 基本的な使い方

```bash
claude plugin install my-plugin --marketplace owner/repo
```

## 実践例

### セットアップスクリプトでの利用

```bash
#!/bin/bash
claude plugin install my-plugin --marketplace owner/repo
```

`marketplace add` を別途呼ぶ必要がなくなり、スクリプトが簡潔になります。

## 注意点

- マーケットプレイスの追加には `claude plugin marketplace add` と同じポリシーチェックが適用されます。
- 組織のポリシーで許可されていないマーケットプレイスは追加できません。
