## 原文（日本語訳）
CursorやVS Codeのターミナル内で実行した際、Linux Wayland環境で起動時に余分な空のエディタウィンドウが開いてしまう問題を修正しました。

## 原文（英語）
Fixed extra empty editor windows opening at startup on Linux under Wayland when running inside the Cursor or VS Code terminal

## 概要
Claude CodeをCursorやVS Codeの統合ターミナル内で起動すると、エディタとの連携機能が有効になります。しかし、LinuxのWaylandディスプレイサーバー環境に限り、起動時にこの連携処理が原因で不要な空のエディタウィンドウが余分に開いてしまう不具合がありました。今回の修正により、Wayland環境でも余分なウィンドウが開かずに済むようになりました。

## 基本的な使い方
Linux（Wayland）環境で、CursorまたはVS Codeの統合ターミナルからClaude Codeを起動します。

```bash
claude
```

## 実践例

### 修正前の挙動
Wayland環境のLinuxでCursorやVS Codeのターミナルから `claude` を起動すると、意図しない空のエディタタブ・ウィンドウが追加で開いてしまい、作業スペースが乱れることがありました。

### 修正後の挙動
同じ環境で起動しても、余分な空のエディタウィンドウは開かなくなり、クリーンな状態で作業を開始できます。

## 注意点
- この不具合はLinuxのWaylandセッションに固有のものでした。X11環境や他のOS（macOS、Windows）では影響していませんでした。
- CursorやVS Code以外のエディタ・ターミナルからの起動には直接関係しません。
