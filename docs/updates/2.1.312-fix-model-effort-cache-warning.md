## 原文（日本語訳）

`/model` と `/effort` のキャッシュ警告が「再読み込みは次のメッセージまで待つ」と表示していた問題を修正。Claudeの作業中に行った変更は、より早く再読み込みが発生することがあります

## 原文（英語）

Fixed the `/model` and `/effort` cache warning saying the re-read waits for your next message; a change made while Claude is working can trigger it sooner

## 概要

モデルや努力レベルを変更するとプロンプトキャッシュの再読み込みが発生します。作業中に変更した場合は次のメッセージを待たずに起きることがあり、警告文がそれを正しく説明するようになりました。

## 基本的な使い方

```
/model
/effort
```

## 実践例

### コストを意識した切り替え

キャッシュ再読み込みはトークン消費に影響するため、切り替えるタイミングは作業の区切りが望ましいです。

## 注意点

- 作業中の変更は、想定より早くキャッシュ再読み込みを起こす場合があります。
