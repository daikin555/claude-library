## 原文（日本語訳）

[VSCode] agent mapを改善しました。ピル表示が実行中のエージェント数をカウントし、失敗時には赤色になります。また、マップがスクロールしてもメインエージェントが常に表示範囲内に留まり、エージェントは状態、次に終了時刻の順でソートされるようになりました。

## 原文（英語）

[VSCode] Improved the agent map: the pill counts running agents and turns red after a failure, the main agent stays in view while the map scrolls, and agents sort by state then end time

## 概要

agent mapはサブエージェントの実行状況を一覧できる可視化機能です。今回のアップデートでは3つの改善が行われました。1つ目はステータスを示す「ピル」表示が実行中のエージェント数を数字で示し、失敗が発生すると赤色に変化するようになったこと。2つ目はマップをスクロールしてもメインエージェントが常に表示範囲内に留まるようになったこと。3つ目はエージェントの並び順が状態（実行中・失敗・完了など）、次に終了時刻の順にソートされるようになったことです。これにより、多数のエージェントが並行実行される複雑なワークフローでも状況を素早く把握できます。

## 基本的な使い方

agent mapはClaude Codeパネルから通常通り開くことができます。

```
> Claude Code: Show Agent Map
```

## 実践例

### 多数のサブエージェントが並行実行されているワークフローの監視

複数のサブエージェントを並行起動するようなタスクでは、ピル表示を見るだけで現在何個のエージェントが実行中かを即座に把握できます。

```
ピル表示例: "3 running" → 実行中のエージェントが3つあることを示す
失敗発生時: ピルが赤色に変化 → 何らかのエージェントが失敗したことに即座に気付ける
```

### 大量のエージェントをスクロールして確認する場合

エージェント数が多くマップをスクロールする必要がある場合でも、メインエージェントは常に画面内に固定表示されるため、全体の文脈を見失いません。

```
スクロール中でもメインエージェントのカードは表示エリア内に留まる
```

### 状態別にエージェントを素早く見つけたい場合

エージェントは状態（例: 失敗 → 実行中 → 完了）、同じ状態内では終了時刻順にソートされるため、問題のあるエージェントを素早く見つけられます。

## 注意点

- これはUI/UXの改善であり、エージェントの実行ロジック自体に変更はありません。
- ソート順は今後のバージョンで調整される可能性があります。
