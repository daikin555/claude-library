# セルフホストランナーでTERM設定時の Resource temporarily unavailable を修正

## 原文（日本語に翻訳）

- セルフホストランナー: stdoutのみをランナーやオーケストレーターと共有する起動スクリプトが、`TERM` 設定時に `Resource temporarily unavailable` で失敗する問題を修正（2.1.300のリグレッション）

## 原文（英語）

- Self-hosted runner: Fixed a start script that shares only its stdout with the runner or orchestrator failing with `Resource temporarily unavailable` when `TERM` is set (a 2.1.300 regression)

## 概要

2.1.300で発生したリグレッションの修正です。stdoutだけを共有する起動スクリプトが `TERM` 設定時にエラーになる問題が解消されます。

## 基本的な使い方

セルフホストランナーを2.1.305以降に更新するだけで反映されます。

## 実践例

### 起動スクリプトの運用

回避策として `TERM` を外していた場合は、不要になっている可能性があります。

## 注意点

- 2.1.300〜2.1.304で該当症状が出ていた環境が対象です。
