## 原文（日本語訳）

Claude APIおよびEnterpriseユーザー向け、またBedrock、Vertex、Foundry、ゲートウェイ利用時のauto modeを、分類器のオーバーヘッドに課金されないサーバーサイド分類器をデフォルトで使用するように変更（Bedrock、Vertex、Foundry、ゲートウェイでは `CLAUDE_CODE_AUTO_MODE_SERVER=0` でオプトアウト可能）。課金対象のフォールバックが発生した場合は警告を表示。詳細は https://code.claude.com/docs/en/auto-mode-classifier-billing を参照。

## 原文（英語）

Changed auto mode for Claude API and Enterprise users, and on Bedrock, Vertex, Foundry and gateways, to default to the server-side classifier, which does not charge for classifier overhead (`CLAUDE_CODE_AUTO_MODE_SERVER=0` opts out on Bedrock, Vertex, Foundry and gateways); warns on billed fallback. See https://code.claude.com/docs/en/auto-mode-classifier-billing

## 概要

Auto mode（自動実行モード）では、シェルコマンドやネットワークリクエストなどのアクションを実行する前に「分類器（classifier）」と呼ばれる別モデルが安全性チェックを行っています。これまでこの分類器の呼び出しはトークン使用量として課金されていましたが、v2.1.278以降ではClaude API・Enterpriseプラン、およびAmazon Bedrock・Google Vertex（Agent Platform）・Microsoft Foundry・各種ゲートウェイ経由の利用において、この安全チェックをサーバー側で実行することで、分類器のオーバーヘウンド分の課金が発生しなくなりました。Pro/Max/Teamプランではこの通知自体が表示されません。

## 基本的な使い方

対象プラットフォームでauto modeを使っていれば、特別な設定なしにサーバーサイド分類器が自動的に有効になります。現在のセッションの状態は `/status` コマンドで確認できます。

```bash
/status
```

出力に含まれる `Auto mode server` の行が `Enabled` であれば、サーバー側の安全チェックが有効な状態でauto modeが動作しています。

## 実践例

### Bedrock/Vertex/Foundryでサーバーサイド分類器を明示的に無効化する

社内ゲートウェイがリクエストヘッダーやレスポンスのフィールドを書き換えてしまい、サーバー側チェックが正しく機能しない場合は、環境変数でオプトアウトできます。

```bash
export CLAUDE_CODE_AUTO_MODE_SERVER=0
```

この設定を行うと、分類器のリクエストは常にClaude Code自身が行う従来方式になり（課金は従来通り）、フォールバック通知も表示されなくなります。

### CI/非対話環境でのフォールバック通知を検知する

`-p` を使った非対話モードでは、フォールバックが発生した際に通知がstderrに出力されます。`stream-json` 出力形式を使っている場合は `system` タイプの警告メッセージとしてストリームに現れるため、Agent SDKなどでメッセージストリームを監視しているアプリケーションはこれを検知して記録できます。

### 社内ゲートウェイをサーバーサイド分類器に対応させる

ゲートウェイやプロキシが原因でサーバー側チェックに到達できていない場合、ゲートウェイ管理者にリクエスト/レスポンスをそのまま（ヘッダーや `safeguards` フィールドなどを含めて）パススルーするよう依頼することで、新しいセッションから再びサーバー側チェックが有効になります。

## 注意点

- Pro、Max、Teamプランではこの通知は表示されず、常に非課金のサーバーサイド分類器（対応プラットフォームの場合）が使われます。
- サーバー側チェックがセッションに到達できない場合、Claude Codeは自動的に従来の（課金対象の）自前の分類器にフォールバックし、セッション中に一度だけ通知を表示します。以降そのセッションでは再表示されません。
- `CLAUDE_CODE_AUTO_MODE_SERVER` はAnthropic APIへの直接接続では読み込まれません。
- `CLAUDE_CODE_AUTO_MODE_SERVER` は暫定的な設定であり、将来のリリースで削除される可能性があります。
- Bedrock、Vertex（Agent Platform）、Foundry、およびサインイン済みClaudeアプリのゲートウェイセッションでは、auto mode自体がClaude Sonnet 5、Opus 4.7以降、Fableモデルでのみサポートされます。
