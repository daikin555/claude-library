## 原文（日本語に翻訳）

セルフホストランナー: GitHub CLI がインストールされていない macOS および Linux マシンで、Anthropic 管理の git を使うセッション向けに、組み込みの `gh api`（REST のみ）を追加しました。

## 原文（英語）

Self-hosted runner: Added a built-in `gh api` (REST only) for sessions that use Anthropic-managed git on macOS and Linux machines where the GitHub CLI is not installed

## 概要

セルフホストランナー上で Anthropic 管理の git を使うセッションに、組み込みの `gh api` が追加されました。GitHub CLI が未インストールの macOS / Linux マシンでも、GitHub の REST API を呼び出せます。

## 基本的な使い方

Claude に GitHub 操作を依頼すると、内部で `gh api` が使われます。形式は GitHub CLI と同じです。

```bash
gh api repos/OWNER/REPO/pulls
```

## 実践例

### PR 情報の取得

```bash
gh api repos/OWNER/REPO/pulls/123
```

### Issue へのコメント

```bash
gh api repos/OWNER/REPO/issues/45/comments -f body="確認しました"
```

## 注意点

- **REST のみ**対応です。GraphQL（`gh api graphql`）は対象外です。
- 対象は macOS と Linux で、GitHub CLI 未インストールかつ Anthropic 管理の git を使うセッションです。
- GitHub CLI がインストール済みの環境では、通常どおりそちらを使います。
