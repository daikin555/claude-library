# vimモードに % モーション（対応する括弧へジャンプ）を追加

## 原文（日本語に翻訳）

vim モードに `%` モーションを追加しました。対応する括弧へジャンプでき、単独でも d/c/y と組み合わせても使えます。

## 原文（英語）

Added the `%` motion to vim mode: jump to the matching bracket, alone or with d/c/y

## 概要

プロンプト入力のvimモードで、カーソル位置の括弧に対応する括弧へ `%` で移動できるようになりました。`d%`、`c%`、`y%` のようにオペレーターと組み合わせて、括弧で囲まれた範囲を削除・変更・ヤンクできます。

## 基本的な使い方

NORMALモードで括弧の上にカーソルを置き、`%` を押します。

```text
foo(bar, baz)
   ^ここで % → 閉じ括弧へジャンプ
```

## 実践例

### 括弧内を含めて削除する

開き括弧の上で `d%` を実行すると、対応する閉じ括弧までを削除できます。

### 括弧の範囲をコピーする

`y%` で括弧で囲まれた範囲をヤンクし、別の場所へ貼り付けられます。

### 括弧の中身を書き換える

`c%` で範囲を削除してINSERTモードに入り、書き直せます。

## 注意点

- vimモードが有効な場合のみ使えます（`/config` などで切り替え）。
- カーソルが括弧上にないときの挙動はvimの標準動作に準じます。
