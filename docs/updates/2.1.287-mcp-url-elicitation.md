## 原文（日本語に翻訳）

2025-11-25 プロトコルの MCP サーバーからの URL プロンプト（サインインなど）に対応しました。今回の更新後にサーバーへ接続できなくなった場合は、その MCP 設定エントリーに `"bareElicitationCapability": true` を追加してください。

## 原文（英語）

Added URL prompts from MCP servers on the 2025-11-25 protocol, for example to sign in. If a server no longer connects after this update, add "bareElicitationCapability": true to its MCP config entry

## 概要

MCP の 2025-11-25 プロトコルで定義された URL 形式のプロンプトを受け取れるようになりました。サーバー側が、サインインなどのためにユーザーを特定の URL へ誘導できます。一方で、更新後に接続できなくなるサーバーがある場合の回避設定が用意されています。

## 基本的な使い方

接続できなくなったサーバーの設定に `bareElicitationCapability` を追加します。

```json
{
  "mcpServers": {
    "my-server": {
      "type": "http",
      "url": "https://example.com/mcp",
      "bareElicitationCapability": true
    }
  }
}
```

## 実践例

### サインインが必要な MCP サーバー

サーバーが認証用 URL を提示すると、Claude Code 上でそのプロンプトが表示されます。

### 更新後に接続できなくなった場合

`claude mcp list` や `/mcp` で状態を確認し、該当サーバーの設定に上記フラグを追加して再接続してください。

## 注意点

- フラグが必要になるのは、更新後に接続できなくなったサーバーのみです。
- URL を開く前に、提示元が信頼できるサーバーであることを確認してください。
