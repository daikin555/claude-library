## 原文（日本語訳）

[クラウドセッション] クラウド環境設定のセットアップスクリプト欄に、色分け・行番号・コピーボタン付きのBashエディタを追加しました

## 原文（英語）

[Cloud sessions] Added a Bash editor with colors, line numbers and a Copy button to the setup script box in cloud environment settings

## 概要

セットアップスクリプトの編集が、シンタックスハイライトと行番号つきのエディタで行えます。

## 基本的な使い方

クラウド環境設定のセットアップスクリプト欄で、そのままBashを記述します。

```bash
npm ci
```

## 実践例

### エラー行の特定

行番号で問題箇所を伝えやすくなります。

### スクリプトの共有

Copyボタンでチームに共有できます。

## 注意点

- 追加されたのはエディタ部分のUIです。
