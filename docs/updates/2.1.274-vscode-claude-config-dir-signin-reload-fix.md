## 原文（日本語訳）
「Environment Variables」設定で `CLAUDE_CONFIG_DIR` を変更した後、ターミナルで行ったサインイン・サインアウトがリロードするまで反映されなかった不具合が修正されました。

## 原文（英語）
[VSCode] Fixed sign-ins and sign-outs made in a terminal not showing until a reload after `CLAUDE_CONFIG_DIR` changed in the Environment Variables setting

## 概要
VSCode拡張機能の「Environment Variables」設定で `CLAUDE_CONFIG_DIR`（Claude Codeの設定ディレクトリの場所）を変更した後、ターミナルから行ったサインインやサインアウトの状態が拡張機能側に反映されず、手動でウィンドウをリロードするまで古い認証状態が表示され続ける不具合がありました。今回の修正により、`CLAUDE_CONFIG_DIR` 変更後でもターミナルでのサインイン・サインアウトが即座に拡張機能側に反映されるようになりました。

## 基本的な使い方
`CLAUDE_CONFIG_DIR` は環境変数として設定でき、VSCode拡張機能のEnvironment Variables設定からも変更可能です。

```json
{
  "claudeCode.environmentVariables": {
    "CLAUDE_CONFIG_DIR": "/path/to/custom/config"
  }
}
```

## 実践例

### 修正前の挙動
VSCodeのEnvironment Variables設定で `CLAUDE_CONFIG_DIR` を別のディレクトリに変更した後、ターミナルで `claude login` や `claude logout` を実行しても、拡張機能側の認証状態表示はウィンドウをリロードするまで更新されませんでした。

### 修正後の挙動
同じ手順でターミナルからサインイン・サインアウトを行うと、拡張機能側の認証状態がリロードなしで即座に更新されるようになりました。

## 注意点
- 複数のClaude Code設定ディレクトリを使い分けている開発者にとって特に有用な修正です。
- `CLAUDE_CONFIG_DIR` の変更自体は引き続きVSCodeのEnvironment Variables設定から行います。
