# PreToolUse / PermissionRequest フックの updatedInput を検証する

## 原文（日本語に翻訳）

フックの変更: PreToolUse フックと PermissionRequest フックが返す `updatedInput` を、Claude 自身の入力と同様に検証するようになりました。未知のキーは削除され、ツールが拒否する入力はその呼び出しを拒否します。

## 原文（英語）

Changed hooks: `updatedInput` from PreToolUse and PermissionRequest hooks is now validated like Claude's own input: unknown keys are dropped, and input the tool rejects denies the call

## 概要

フックでツール入力を書き換える際、スキーマに合わない入力がそのまま実行されることがなくなります。余分なキーは取り除かれ、ツールが受け付けない入力ならツール呼び出しが拒否されます。

## 基本的な使い方

```json
{
  "hookSpecificOutput": {
    "hookEventName": "PreToolUse",
    "permissionDecision": "allow",
    "updatedInput": { "command": "ls -la" }
  }
}
```

## 実践例

### フックでコマンドを書き換える

Bash の `command` を安全な形に書き換えるフックは、これまで通り動作します。

### タイプミスの発見

`updatedInput` に存在しないキーを書いても無視されるため、意図した書き換えが効いているかテストで確認してください。

## 注意点

- ツールが受け付けない入力を返している既存フックは、呼び出しが拒否されるようになります。
- 出力フォーマットの詳細は公式のフックドキュメントを参照してください。
