## 原文（日本語訳）

/code-reviewに `--max-findings <n>|all` を追加した。通常の上限より多く、または少ない件数の指摘を報告できる。この選択は `--max-findings default` を指定するまで再利用される。

## 原文（英語）

Added `--max-findings <n>|all` to /code-review to report more or fewer findings than the usual limit; the choice is reused until you pass `--max-findings default`

## 概要

`/code-review` が報告する指摘の件数には通常の上限があります。`--max-findings` を使うと、この上限を任意の件数、または `all`（すべて）に変更できます。一度指定した値は以降のレビューでも使い回され、`--max-findings default` で初期状態に戻ります。

## 基本的な使い方

```text
/code-review --max-findings 5
/code-review --max-findings all
/code-review --max-findings default
```

## 実践例

### 重要な指摘だけに絞る

大きな差分でも上位の指摘だけを確認したい場合は、件数を少なくします。

```text
/code-review high --max-findings 3
```

### マージ前にすべての指摘を洗い出す

リリース前など網羅性を重視する場面では `all` を指定します。

```text
/code-review high --max-findings all
```

### 設定を元に戻す

指定した値は保持されるため、不要になったらデフォルトへ戻します。

```text
/code-review --max-findings default
```

## 注意点

- 指定値は次回以降も再利用されます。意図せず `all` のままにならないよう注意してください。
- 件数を増やすと、確度の低い指摘が含まれる可能性があります。
- `ultra` の PR レビューなど他のオプションとも併用できます。
