## 原文（日本語訳）

`claude_code.llm_request` のOpenTelemetryトレーススパンに `effort` 属性を追加しました。これは `api_request` イベントに合わせたものです。

## 原文（英語）

Added `effort` attribute to the `claude_code.llm_request` OpenTelemetry trace span, matching the `api_request` event

## 概要

Claude CodeはOpenTelemetry経由でLLMリクエストのトレース情報をエクスポートでき、組織はこれを使ってコストやレイテンシを監視できます。今回の変更で、モデルの思考努力度（reasoning effort）を表す `effort` 属性が `claude_code.llm_request` スパンにも付与されるようになり、既存の `api_request` イベントと同様にeffortレベル別の分析が可能になりました。

## 基本的な使い方

OpenTelemetryを有効化してClaude Codeを実行すると、エクスポートされる `claude_code.llm_request` スパンの属性に `effort` が含まれるようになります。

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_METRICS_EXPORTER=otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
claude
```

## 実践例

### effortレベル別のレイテンシ分析

トレースバックエンド（Jaeger、Honeycombなど）で `claude_code.llm_request` スパンを `effort` 属性でグルーピングすることで、effortレベル（例: low/medium/high）ごとのレイテンシやトークン消費の傾向を可視化できます。

### コスト配分の精緻化

`api_request` イベントと `claude_code.llm_request` スパンの両方に `effort` が付与されたことで、メトリクスとトレースを横断してeffort別のコストを突き合わせ、ダッシュボード上での整合性を高めることができます。

## 注意点

- この属性を利用するには、OpenTelemetryのトレースエクスポートを有効にしている必要があります。
- effortの概念に対応していないモデルやリクエストでは、属性が空または該当なしとして記録される場合があります。
