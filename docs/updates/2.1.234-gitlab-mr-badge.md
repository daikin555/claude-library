## 原文（日本語訳）

フッターとステータスラインにGitLabマージリクエストのバッジを追加しました。GitLabのリモートが設定されていて、`glab` CLIで認証済みのリポジトリでは、`MR !N` のようにドラフト／保留中／グリーン（承認済み・パイプライン成功）といった状態を表示します。

## 原文（英語）

Added a GitLab merge request badge to the footer and statusline: repos with a GitLab remote and an authenticated glab CLI show MR !N with draft/pending/green states

## 概要

これまでGitHubのプルリクエストに対応する簡易ステータス表示はありましたが、GitLabを使っているリポジトリでは同様の情報を確認するのに `glab mr view` などを別途実行する必要がありました。今回の更新で、GitLabリモートを持つリポジトリで `glab` CLIが認証済みであれば、現在のブランチに紐づくマージリクエスト番号とその状態（ドラフト・パイプライン保留中・グリーン）がフッターおよびステータスラインに自動的に表示されるようになりました。

## 基本的な使い方

事前に `glab` CLIをインストールして認証しておくだけで、追加設定なしにバッジが表示されます。

```bash
# glab CLIのインストールと認証（未設定の場合）
glab auth login

# GitLabリポジトリでClaude Codeを起動
cd my-gitlab-project
claude
```

対象ブランチにマージリクエストが存在すれば、フッターに `MR !42` のようなバッジが表示されます。

## 実践例

### 作業中のブランチのMR状態を一目で確認

コーディング中に別ターミナルへ切り替えなくても、パイプラインが失敗していないか、レビュー待ちかをフッターで確認できます。

```bash
git checkout -b feature/add-caching
# ... 変更してMRを作成 ...
glab mr create --draft
claude
# フッターに "MR !128 (draft)" のように表示される
```

### パイプライン成功後にグリーン表示へ切り替わる様子を確認

CIパイプラインが完走してマージ可能になると、バッジの状態が自動的に更新されます。

```bash
claude
# パイプライン実行中: "MR !128 (pending)"
# パイプライン成功後: "MR !128 (green)"
```

### カスタムステータスラインに組み込む

`/statusline` で生成したカスタムステータスラインでも、MRバッジの情報を利用できます。

```bash
/statusline GitLabのMR番号と状態、現在のブランチ名を表示して
```

## 注意点

- この機能はリポジトリのリモートがGitLab（`gitlab.com` または自ホストのGitLabインスタンス）である場合にのみ有効です
- `glab` CLIがインストールされていない、または認証されていない場合、バッジは表示されません
- GitHubリポジトリの場合は従来通りGitHub向けのプルリクエストバッジが表示されます
- パイプラインの状態取得にはGitLab側へのAPIアクセスが発生するため、ネットワーク環境やレート制限によって表示更新に遅延が生じることがあります
