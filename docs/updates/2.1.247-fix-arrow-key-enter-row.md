## 原文（日本語訳）

履歴検索、`/config`、`/mcp`、`/skills`、バックグラウンドタスク、`/model` において、矢印キーとEnterキーを素早く連続して押した際に、実際に移動した行ではなく1つ上の行に対して操作が実行されてしまう不具合を修正しました。

## 原文（英語）

Fixed fast arrow-key + Enter sequences acting on the row above the one you navigated to in history search, `/config`, `/mcp`, `/skills`, background tasks, and `/model`

## 概要

一覧から項目を選ぶUI（履歴検索、`/config`、`/mcp`、`/skills`、バックグラウンドタスク一覧、`/model` など）で、矢印キーで目的の行に移動した直後にすぐEnterキーを押すと、選択がまだ描画に反映される前にEnterが処理され、意図した行ではなく1つ上の行が選択されてしまうことがありました。素早く操作する習慣のあるユーザーほど発生しやすい不具合でした。本修正により、矢印キーとEnterキーを素早く連続入力しても、実際にカーソルが移動した行が正しく選択されるようになりました。

## 基本的な使い方

修正後は、対象のどの一覧UIでも、矢印キーで移動してすぐにEnterを押した場合に、カーソルが表示されている行が確実に選択されます。

```
/model
（↓を2回押した直後にEnterを押す）
→ 修正前: 1つ上のモデルが選択されてしまうことがあった
→ 修正後: ↓で移動した行のモデルが正しく選択される
```

## 実践例

### 履歴検索で目的のコマンドを素早く選ぶ

Ctrl+Rなどで履歴検索を開き、矢印キーで目的のコマンドまで移動して即座にEnterを押しても、表示されている行のコマンドが正しく実行されるようになりました。

### `/model` でモデルを切り替える

モデル一覧を矢印キーで素早くスクロールし、目的のモデル名が表示された瞬間にEnterを押しても、誤って別のモデルに切り替わることがなくなりました。

### `/mcp` や `/skills` でMCPサーバーやスキルを選択する

多数のMCPサーバーやスキルが並ぶ一覧から、素早いキー操作で目的の項目を選んでも、正しい項目に対して操作が実行されます。

### バックグラウンドタスク一覧の操作

複数のバックグラウンドタスクが並ぶ一覧でも、同様に矢印キー+Enterの高速操作が正しい行に反映されるようになりました。

## 注意点

- この不具合はキー入力を非常に速く連続して行った場合に発生しやすいものでした。ゆっくり操作していた場合は影響を受けにくいものでした
- 修正はUI描画とキー入力処理のタイミング調整によるもので、ユーザー側の設定変更は不要です
