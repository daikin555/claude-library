## 原文（日本語訳）

クラウド環境（cloud environments）の一覧の取得結果が空、または不正な形式で返ってきた際に表示されるわかりにくいエラーを修正しました。

## 原文（英語）

Fixed an unclear error when the cloud environments list came back empty or malformed

## 概要

Claude Codeには、Anthropicが管理するクラウド上のセッション実行環境や、組織が用意した自己ホスト型の環境（self-hosted environments）を一覧表示する機能があります。これまでは、この一覧を取得しようとした際にサーバー側から空のレスポンスや想定外の形式のデータが返ってきた場合、原因の分かりにくい汎用的なエラーが表示され、何が問題なのか利用者が判断しづらい状態でした。今回の修正により、このようなケースでもエラー処理が改善され、状況が把握しやすくなりました。

## 基本的な使い方

この修正は、クラウド環境の一覧を扱う操作（クラウドセッションの起動先を選ぶ場面など）で発生するエラーメッセージの質を改善するものです。ユーザー側で特別な操作は必要ありません。

```
/cloud
```

修正前は、環境一覧の取得結果が空だったり形式が壊れていたりすると、原因が読み取れないエラーがそのまま表示され、設定ミスなのかサーバー側の問題なのか判断がつきませんでした。修正後は、こうした異常なレスポンスに対してより明確な形でエラーが扱われるようになっています。

## 実践例

### 組織のクラウド環境がまだ何も登録されていない場合

管理者がクラウド環境やセルフホスト環境をまだ1つも作成していない組織でメンバーが環境一覧を開こうとすると、一覧が空で返ってくることがあります。修正前はここで意味の取りにくいエラーが表示されていましたが、修正後はより適切に処理されるようになりました。

### ネットワークや権限の問題で一覧データが壊れて返ってきた場合

プロキシやネットワークの不調、権限設定の問題などにより、クラウド環境一覧のレスポンスが不完全・不正な形式で返ってくるケースでも、修正前は原因不明のエラーで処理が止まっていました。修正後はこうした異常系がより丁寧に扱われ、問題の切り分けがしやすくなります。

## 注意点

- この修正はエラー発生時の表示・処理の改善であり、環境一覧が空になる根本原因（未作成、権限不足、ネットワーク問題など）自体を解決するものではありません。
- クラウド環境が実際に1つも存在しない場合は、引き続き環境を作成する必要があります。
