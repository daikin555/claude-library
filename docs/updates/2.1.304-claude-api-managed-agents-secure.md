## 原文（日本語に翻訳）

`/claude-api managed-agents-secure` を追加しました。Managed Agents のエージェント設定を Anthropic が公開しているセキュリティガイドと比較します。何も変更しません。

## 原文（英語）

Added `/claude-api managed-agents-secure`, which compares a Managed Agents agent's settings with Anthropic's published security guide, without changing anything

## 概要

`/claude-api` スキルのサブコマンドで、Managed Agents のエージェント設定を Anthropic 公開のセキュリティガイドと突き合わせて確認できます。読み取り専用の比較であり、設定は変更されません。

## 基本的な使い方

```text
/claude-api managed-agents-secure
```

## 実践例

### 本番投入前のセキュリティチェック

エージェントを本番環境へ公開する前に実行し、ガイドとの差異を洗い出します。結果を見て、修正が必要な項目は自分で設定を更新します。

### 定期的な設定の見直し

設定を変更した後に再実行して、ガイドから外れていないか確認できます。

## 注意点

- 比較のみを行い、設定の自動修正は行われません。
- 判断の基準は Anthropic が公開しているセキュリティガイドです。
