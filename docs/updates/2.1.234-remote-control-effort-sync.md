## 原文（日本語訳）

Remote Control: スマートフォンやclaude.ai/code上で選択したEffort（思考の労力）設定が、ターミナルおよびDesktop/VS Codeでホストされているセッションにも適用されるようになりました。また、セッション自身も自分のEffortレベルを接続中のクライアントへ公開（通知）するようになりました。

## 原文（英語）

Remote Control: effort picks made on a phone or on claude.ai/code now apply to terminal- and Desktop/VS Code-hosted sessions, and the session publishes its effort level to connected clients

## 概要

Claude Codeには応答の「Effort（労力・思考の深さ）」レベルを調整する設定がありますが、これまでRemote Control経由でスマートフォンアプリやclaude.ai/codeからEffortを変更しても、ターミナルやDesktop/VS Code側で実際に動いているセッションには反映されないことがありました。今回のアップデートで、リモートクライアント側で選んだEffort設定がホスト側のセッションに正しく適用されるようになり、さらにセッション自身も現在のEffortレベルを接続中の全クライアントに公開するため、どのデバイスから見ても一貫した状態を確認できます。

## 基本的な使い方

1. ターミナル、Claude Code Desktop、またはVS CodeでRemote Controlセッションを開始する
2. スマートフォンアプリまたはclaude.ai/codeから同じセッションに接続する
3. スマホ/claude.ai/code側でEffortレベル（例: 低・中・高など）を変更する
4. ホスト側（ターミナル/Desktop/VS Code）のセッションにその設定が反映される
5. 逆に、ホスト側の現在のEffortレベルも接続中のクライアントに公開され、表示が同期される

## 実践例

### 移動中にEffortを上げて重い処理を依頼する

自宅のターミナルでセッションを開始し、移動中にスマホアプリから接続してEffortを「高」に切り替えた場合、これまではターミナル側のセッションに反映されずギャップがありましたが、修正後は即座にターミナル側のセッションもより高いEffortで応答するようになります。

### VS CodeとclaudeAiCodeを行き来する開発フロー

VS Code上でRemote Controlセッションを起動し、外出先のブラウザ（claude.ai/code）からEffortを調整して軽量なタスクだけ素早く処理させる、といった使い分けが可能になります。設定はセッション全体で共有されるため、どちらの画面からでも現在のEffortが一致して見えます。

### 現在の設定状況を接続先で確認する

複数のクライアントから同じセッションを覗いている場合でも、セッションが自らEffortレベルを公開するため、各クライアントの表示が古い情報のままにならず、常に最新の設定状況を把握できます。

## 注意点

- Effortの同期はRemote Controlで接続されたセッション間でのみ有効です
- Effort設定はモデルやタスクの複雑さによって処理速度・コストに影響する場合があります
- Remote Controlの利用にはPro/Max/Team/Enterpriseプランが必要です
