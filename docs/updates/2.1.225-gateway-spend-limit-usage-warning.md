## 原文（日本語訳）

Claude Code の使用警告にゲートウェイの支出制限サポートを追加しました。制限に達した場合のメッセージに、上限額、リセット時刻、および運用者のメッセージが明示されるようになります（ゲートウェイが 2.1.225 以上である必要があります）

## 原文（英語）

Added gateway spend-limit support to Claude Code's usage warning; the limit-reached message now names the cap, its reset time, and the operator's message (requires the gateway on 2.1.225)

## 概要

Claude Code がエンタープライズ環境の Claude apps ゲートウェイと統合する際、ゲートウェイで設定された開発者ごとの支出制限に達すると、より詳細な情報がユーザーに表示されるようになりました。制限額、リセット時刻、および管理者が設定したカスタムメッセージが一度に確認できるため、制限に達した場合の対応がスムーズになります。この機能は、組織全体の使用量を効果的に管理し、予期しない支出超過を防ぐことができます。

## 基本的な使い方

開発者は Claude Code を通常通り使用していますが、ゲートウェイで設定された支出制限に達すると、自動的に詳細なエラーメッセージが表示されます。メッセージには以下の情報が含まれます：

- **制限額**: 管理者が設定した1日、1週間、または1ヶ月単位の支出上限
- **リセット時刻**: 制限がリセットされるUTC時刻（毎日 00:00 UTC、毎週月曜日 00:00 UTC、毎月1日 00:00 UTC）
- **運用者メッセージ**: 管理者が `admin.blocked_message` で設定したカスタムメッセージ

この通知により、開発者は制限の詳細と次に実行できる時期を即座に把握できます。

## 実践例

### 日次予算制限と制限到達時の通知

組織の管理者が、各開発者の日次支出制限を $100 に設定した場合：

```
Error: spend limit reached
Your daily spending cap is $100.00. Limit resets at 00:00 UTC (in 4 hours 30 minutes).
Contact your administrator if you need to increase your limit.
```

開発者はこのメッセージから、現在の制限額、次のリセット時刻、および対応方法を同時に確認できます。

### グループレベルでの制限と管理者メッセージ

契約開発チーム向けに、週間制限 $500 と カスタムメッセージが設定されている場合：

```
Error: spend limit reached
Your weekly spending cap is $500.00. Limit resets at 00:00 UTC on Monday (in 2 days 10 hours).
Message from your organization: "Please reach out to finance@company.com for budget increase requests"
```

管理者のカスタムメッセージにより、制限に達した場合の具体的な対応方法が明確に伝わります。

### 月次組織規模の制限

組織全体の月次支出制限が $10,000 の場合：

```
Error: spend limit reached
Your organization's monthly spending cap is $10,000.00. Limit resets at 00:00 UTC on the 1st of next month (in 18 days).
Please coordinate with your team to manage usage within this limit.
```

開発者は組織全体の制限状況を理解し、他のチームメンバーとの利用調整が可能になります。

## 注意点

- **ゲートウェイのバージョン要件**: この機能を利用するには、Claude apps ゲートウェイが 2.1.225 以上である必要があります。それより古いバージョンではメッセージが詳細化されません
- **エンタープライズ環境専用**: この機能は Claude apps ゲートウェイを使用するエンタープライズ組織に限定されます。通常の Claude.ai サブスクリプションやコンソール API では利用できません
- **複数の制限が存在する場合**: ユーザーが複数の制限（日次、週次、月次など）の対象になっている場合、最初に達した制限が報告されます
- **UTC タイムゾーン**: リセット時刻は常に UTC で表示されるため、組織内で統一した理解が必要です
- **管理者メッセージは任意**: `admin.blocked_message` はゲートウェイ設定で任意フィールドです。設定されていない場合は、管理者メッセージ部分は表示されません
