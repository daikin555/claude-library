## 原文（日本語訳）

サブエージェントの `autoCompactWindow` が `CLAUDE_CODE_AUTO_COMPACT_WINDOW` で設定された窓を下げるようになりました（以前は効果なし）。窓を引き上げることはありません

## 原文（英語）

Changed a subagent's `autoCompactWindow` to lower the window set by `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, where it had no effect before; it still never raises that window

## 概要

サブエージェント側で自動コンパクトの窓をより小さくできるようになりました。全体の窓を超えて大きくはできません。

## 基本的な使い方

```bash
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=200000
```

サブエージェント定義で `autoCompactWindow` に小さい値を指定すると、その値が使われます。

## 実践例

### 軽量サブエージェント

短命なサブエージェントを早めにコンパクトして文脈を軽く保ちます。

## 注意点

- 環境変数より大きい値を指定しても引き上げられません。
