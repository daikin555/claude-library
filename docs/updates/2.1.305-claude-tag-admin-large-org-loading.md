# [Claude Tag] 大規模組織の管理ページでチャンネル読み込み中も編集可能に

## 原文（日本語に翻訳）

- [Claude Tag] 大規模組織の管理ページで、チャンネル一覧の読み込み中でも、プラグイン・スキル・バンドルの編集ができるように改善

## 原文（英語）

- [Claude Tag] Improved Claude Tag admin pages in large organizations so plugin, skill and bundle edits work while the channel list is still loading

## 概要

チャンネル一覧が読み込み中でも、プラグイン、スキル、バンドルの編集ができるようになりました。

## 基本的な使い方

管理ページを開いたら、一覧の完了を待たずに編集を始められます。

## 実践例

### 大規模Slackワークスペースの管理

チャンネル数が多い組織でも待たずに設定できます。

## 注意点

- チャンネルに依存する項目は、読み込み完了後に利用可能になります。
