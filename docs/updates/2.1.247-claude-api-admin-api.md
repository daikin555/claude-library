## 原文（日本語訳）

`/claude-api` スキルが更新され、Admin APIのカバー範囲が拡大しました。組織メンバー、招待、ワークスペース、APIキー、レート制限レポート、workload identity federation、CMEK（顧客管理暗号鍵）に関する内容が追加されています。

## 原文（英語）

Updated the `/claude-api` skill with Admin API coverage (organization members, invites, workspaces, API keys, rate limit reports, workload identity federation, CMEK)

## 概要

Claude APIを組織として運用する場合、モデル呼び出しそのものだけでなく、組織メンバーの管理、APIキーの発行・管理、ワークスペースの分割、レート制限の把握、セキュリティ要件（workload identity federationやCMEKなど）への対応が必要になります。今回の更新で `/claude-api` スキルがAdmin API周りの操作についても案内できるようになり、組織運用に関する質問や実装作業をこのスキル経由でサポートできるようになりました。

## 基本的な使い方

`/claude-api` スキルを呼び出し、Admin APIに関する質問やタスクを伝えます。

```
/claude-api 組織のAPIキーをローテーションする方法を教えて
```

該当するAdmin APIのエンドポイントや必要な権限、実装例を踏まえた案内が得られます。

## 実践例

### 組織メンバーとワークスペースの管理

新しいメンバーの招待、ワークスペースへの割り当て、権限管理をAdmin API経由でどのように行うかを確認できます。

```
/claude-api 新しいメンバーをワークスペースBに招待するAPI呼び出しを教えて
```

### APIキーのライフサイクル管理

APIキーの発行、無効化、ローテーションといった運用作業をAdmin APIでどう実装するかをサポートします。

### レート制限状況の可視化

組織全体・ワークスペース単位でのレート制限レポートを取得し、利用状況の監視や制限緩和の申請判断に活用する方法を確認できます。

### エンタープライズ向けセキュリティ要件への対応

workload identity federationによるクラウド環境からのAPIキー不要な認証や、CMEK（顧客管理暗号鍵）を用いたデータ保護要件への対応方法についても案内を得られます。

## 注意点

- Admin API関連の操作の多くは組織の管理者権限を持つAPIキーやロールが必要です
- workload identity federationやCMEKは主にエンタープライズ向けの機能であり、利用可能かどうかは契約プランに依存します
- Admin APIの操作は組織全体に影響する変更を含むため、実行前に対象範囲（ワークスペース単位か組織全体か）を確認することが重要です
