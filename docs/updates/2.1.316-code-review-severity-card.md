# Code Review 分析ページに重大度別の指摘カードを追加

## 原文（日本語訳）

- [Code Review] Code Review 分析ページに、期間中の指摘総数、重大度別の積み上げ日次グラフ、各重大度の件数を示す重大度別指摘カードを追加

## 原文（英語）

- [Code Review] Added a findings-by-severity card to the Code Review analytics page, showing the period's total findings, a daily chart stacked by severity, and each severity's count

## 概要

Code Review の分析ページで、指摘の傾向を重大度別に確認できるようになりました。

## 基本的な使い方

分析ページを開くと、新しいカードが表示されます。

## 実践例

### 品質傾向のモニタリング

重大度の高い指摘が増えていないかを、日次グラフで追跡できます。

## 注意点

- Code Review 機能を利用している組織向けの表示です。
