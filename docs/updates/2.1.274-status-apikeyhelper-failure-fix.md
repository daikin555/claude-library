## 原文（日本語訳）
自身のエラーバナーで確認するよう案内していたにもかかわらず、`/status` が `apiKeyHelper` の失敗を表示していなかった問題を修正しました。

## 原文（英語）
Fixed `/status` not showing the `apiKeyHelper` failure that its own error banner told you to check

## 概要
`apiKeyHelper` はAPIキーを動的に取得するためのカスタムスクリプトを設定する機能です。このスクリプトの実行が失敗した場合、Claude Codeはエラーバナーを表示して「`/status` で確認してください」と案内していましたが、実際には `/status` の出力に該当する失敗情報が表示されておらず、案内が機能していない矛盾した状態でした。今回の修正により、`apiKeyHelper` の失敗が `/status` に正しく表示されるようになりました。

## 基本的な使い方
`apiKeyHelper` に関するエラーが発生した場合、案内に従って `/status` を実行します。

```
/status
```

## 実践例

### 修正前の挙動
`apiKeyHelper` スクリプトの実行に失敗すると、エラーバナーが「`/status` を確認してください」と表示するものの、実際に `/status` を実行しても失敗の詳細が確認できず、原因調査が行き詰まっていました。

### 修正後の挙動
同じ状況で `/status` を実行すると、`apiKeyHelper` の失敗内容（エラーメッセージなど）が表示され、設定の問題を特定しやすくなりました。

## 注意点
- `apiKeyHelper` を利用している場合、スクリプトが正常終了コードを返し、期待する形式でキーを出力しているか確認してください。
- 失敗が続く場合は `/status` の出力とあわせてスクリプトのログも確認すると原因特定がしやすくなります。
