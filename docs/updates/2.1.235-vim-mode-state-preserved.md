## 原文（日本語訳）

Vimモードにおいて、詳細なトランスクリプト表示の切り替え（ctrl+o）やパネルを閉じた際に、NORMALモードとカーソル位置が保持されるようになりました。

## 原文（英語）

Vim mode: NORMAL mode and cursor position are now preserved when toggling the detailed transcript (ctrl+o) or closing a panel

## 概要

Claude CodeのVimモードでは、入力欄でEscキーを押すとINSERTモードからNORMALモードに切り替わり、`hjkl` などのVimキーバインドでテキストを編集できます。これまでは `ctrl+o` で詳細なトランスクリプト表示を切り替えたり、開いていたパネルを閉じたりすると、入力していたモード（NORMAL/INSERT）やカーソル位置がリセットされてしまうことがありました。今回の改善により、こうした画面操作を挟んでもVimの編集状態がそのまま維持されるようになり、編集作業を中断せずに続けられます。

## 基本的な使い方

Vimモードを有効にした状態で入力中にNORMALモードへ切り替え、そのまま `ctrl+o` でトランスクリプト表示を開閉しても、入力欄に戻った際に元のモードとカーソル位置が保たれます。

```bash
# Vimモードを有効化（未設定の場合）
> /vim

# 入力欄で編集中にEscでNORMALモードへ
# ctrl+o でトランスクリプトを開閉してもNORMALモード・カーソル位置は維持される
```

## 実践例

### 編集途中でトランスクリプトを確認したい場合

長いプロンプトをVimのNORMALモードで編集している最中に、これまでのやり取りを確認したくなることがあります。`ctrl+o` でトランスクリプトを開いて内容を確認し、閉じて入力欄に戻っても、以前は編集していたカーソル位置やNORMALモードの状態が失われ、INSERTモードに戻ってしまったり、カーソルが先頭や末尾に移動してしまったりすることがありました。今回の改善で、確認作業を挟んでも編集を中断した箇所からそのまま続けられます。

### パネルを開閉しながら細かい修正を繰り返す

ファイル差分などのパネルを開いて内容を確認し、閉じてから入力中のコマンドやプロンプトを `hjkl` や `dd`、`cw` などのVimコマンドで細かく修正する、という操作を繰り返すワークフローでも、パネルの開閉のたびにモードやカーソル位置がリセットされなくなったことで、テンポよく編集を続けられます。

### 長いマルチライン入力をNORMALモードで整形する

複数行にわたる指示文をVimのNORMALモードで整形している途中で誤って `ctrl+o` を押してしまっても、状態が保持されるため、意図せずINSERTモードに戻って編集内容を崩してしまう心配が減ります。

## 注意点

- この改善はVimモードを有効化している場合にのみ関係します。Vimモードは `/vim` コマンドまたは `/config` から有効化できます
- 保持されるのはNORMALモードの状態とカーソル位置であり、トランスクリプトやパネル自体の表示内容には影響しません
