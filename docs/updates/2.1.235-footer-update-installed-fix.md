## 原文（日本語訳）

バックグラウンドで自動更新が行われた後、プロンプトのフッターに「Update installed（更新がインストールされました）」という再起動を促す通知が表示されない不具合を修正しました。

## 原文（英語）

Fixed the prompt footer not showing the "Update installed" restart notice after a background auto-update

## 概要

Claude Codeはネイティブインストールや `npm@latest` でのインストールの場合、起動時や実行中に定期的に更新を確認し、新しいバージョンをバックグラウンドでダウンロード・インストールします。インストール自体はバックグラウンドで完了しますが、実際に新しいバージョンが有効になるのは次回起動時です。本来はこのタイミングでフッターに「Update installed」といった再起動を促す通知が表示される想定でしたが、通知が表示されないケースがあり、ユーザーは更新が完了していることに気づかないままセッションを使い続けてしまうことがありました。今回の修正でこの通知が正しく表示されるようになりました。

## 基本的な使い方

特別な操作は不要です。Claude Codeを通常どおり使用していると、バックグラウンドで自動更新が行われます。

```
claude
# 作業を続けていると、バックグラウンドで新バージョンがダウンロード・インストールされる
```

修正前は、更新が完了していてもフッターに何も表示されず、ユーザーは `claude doctor` を実行するなどしない限り更新が完了したことに気づけませんでした。修正後は、自動更新が完了すると、プロンプトのフッターに「Update installed」といった趣旨の通知が表示され、セッションを再起動すれば新しいバージョンが使えることが分かるようになります。

## 実践例

### 長時間の作業セッション中に自動更新が完了した場合

長時間Claude Codeを起動したままにしていると、その間にバックグラウンドで新バージョンがインストールされることがあります。修正後は、インストールが完了した時点でフッターに再起動を促す通知が表示されるため、キリの良いタイミングでセッションを再起動して最新版に切り替えられます。

### `claude doctor` で更新状況を確認する

フッターの通知に気づかなかった場合でも、`claude doctor` を実行すると直近の更新試行の結果を確認できます。

```
claude doctor
```

### パッケージマネージャー経由のインストールとの違いを理解する

Homebrew、WinGet、apt、dnf、apkなどパッケージマネージャー経由でインストールした場合はデフォルトで自動更新されないため、今回の修正の対象となる「バックグラウンド自動更新後の通知」自体が発生しません。この場合は `brew upgrade claude-code` のように手動で更新する必要があります。

## 注意点

- この修正はネイティブインストールおよび `npm@latest` インストールなど、自動更新が有効な環境が対象です
- パッケージマネージャー経由でインストールし、自動更新が無効な環境では、この通知は表示されません（そもそも自動更新が行われないため）
- 更新の反映には、通知が出た後にセッションを再起動する必要があります
