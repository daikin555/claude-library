## 原文（日本語訳）

2.1.326で追加された、`max_tokens` エラーで示された上限での自動リトライを削除しました。モデルの出力トークン上限が小さいゲートウェイ経由では、`CLAUDE_CODE_MAX_OUTPUT_TOKENS` をその上限に設定してください。

## 原文（英語）

Removed 2.1.326's automatic retry at the limit named in a `max_tokens` error; behind a gateway whose model takes fewer output tokens, set `CLAUDE_CODE_MAX_OUTPUT_TOKENS` to that limit

## 概要

ゲートウェイ越しに出力上限の小さいモデルを使っている場合、自動調整に頼らず環境変数で明示します。

## 基本的な使い方

```bash
export CLAUDE_CODE_MAX_OUTPUT_TOKENS=8192
claude
```

## 実践例

### ゲートウェイ環境

`max_tokens` 関連のエラーが出たら、モデルの上限値を設定します（8192は例です）。

## 注意点

- 値はお使いのモデルの実際の上限に合わせてください。
