# 管理対象マーケットプレイスの自動更新が既定に（2026年11月30日以降）

## 原文（日本語に翻訳）

2026 年 11 月 30 日以降のリリースで、管理設定の `extraKnownMarketplaces` に含まれるプラグインマーケットプレイスが既定で自動更新されるようになります。除外するには、そのエントリに `"autoUpdate": false` を設定します。

## 原文（英語）

Changed in a future release, on or after November 30, 2026: plugin marketplaces in managed `extraKnownMarketplaces` will auto-update by default. To opt one out, set `"autoUpdate": false` on its entry

## 概要

管理者が配布するマーケットプレイスは、今後は既定で自動更新されます。固定したい場合は事前にオプトアウトが必要です。

## 基本的な使い方

```json
{
  "extraKnownMarketplaces": {
    "internal-tools": {
      "source": { "source": "github", "repo": "example/plugins" },
      "autoUpdate": false
    }
  }
}
```

## 実践例

### バージョンを固定したい場合

上記のように `autoUpdate: false` を指定すると、現行の手動更新の挙動を維持できます。

## 注意点

- 変更は 2026-11-30 以降のリリースが対象です。
- 設定スキーマの詳細は公式ドキュメントを確認してください。
