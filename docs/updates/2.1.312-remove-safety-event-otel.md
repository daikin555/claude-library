## 原文（日本語訳）

Claude Codeが `claude_code.safety_event` のOpenTelemetryイベントを送信しなくなりました

## 原文（英語）

Changed Claude Code to stop sending the `claude_code.safety_event` OpenTelemetry event

## 概要

このイベントは送信されなくなりました。

## 基本的な使い方

追加の操作は不要です。

## 実践例

### ダッシュボードの確認

このイベントに依存するアラートや集計があれば、見直しが必要です。

## 注意点

- 監視ルールにこのイベントを使っている場合は影響を受けます。
