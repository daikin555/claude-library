## 原文（日本語訳）

`Skill(anthropic-skills:*)` および `Skill(claude-ai:*)` の許可ルールを変更し、claude.aiから同期されたスキルのみを対象とし、その名前を単に使用しているだけのプラグインや他のスキルは対象外にしました。

## 原文（英語）

Changed `Skill(anthropic-skills:*)` and `Skill(claude-ai:*)` allow rules to cover only skills synced from claude.ai, not plugins or other skills that merely use such a name

## 概要

これはセキュリティに関わる変更です。`Skill(anthropic-skills:*)` や `Skill(claude-ai:*)` といった許可ルールは、本来claude.aiから同期された正規のスキル群に対する権限付与を意図したものですが、これまでは同じ名前空間（`anthropic-skills` や `claude-ai`）を単に名乗っているだけの、無関係なプラグインやスキルにもこの許可が適用されてしまう可能性がありました。今回の変更で、これらの許可ルールはclaude.aiから実際に同期された正規のスキルにのみ適用されるようになり、名前を騙った第三者のスキル・プラグインに意図せず権限が付与されるリスクがなくなりました。

## 基本的な使い方

エンドユーザー側の対応は不要です。`Skill(anthropic-skills:*)` や `Skill(claude-ai:*)` の許可ルールを設定ファイルで使用している場合、この変更後はより厳格にスコープが限定されます。

## 実践例

### 権限ルールのなりすまし対策

第三者が意図的に `anthropic-skills` や `claude-ai` に似た名前でプラグインを配布しても、既存の許可ルールによって不当に権限を得ることができなくなります。

### エンタープライズでの正規スキルへの権限付与の厳格化

組織が正規のclaude.ai同期スキルにのみ広い権限を与えたい場合、この変更によってその意図がより確実に実現されます。

## 注意点

- 関連する変更として、`anthropic-skills` や `claude-ai` の名前空間を使ったスキルフォルダ・コマンドファイル自体が読み込まれなくなる変更もあります（[名前空間の読み込み停止に関する変更](./2.1.282-change-skill-namespace-no-load.md)を参照）
- 正規のclaude.ai同期スキルを利用している場合は、この変更による動作の変化はありません
