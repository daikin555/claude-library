## 原文（日本語訳）
安全チェックを利用できず操作が拒否された場合に、オートモードの `claude -p` が終了コード0で終了する問題を修正しました。テキスト出力とJSON出力では終了コード1になります。

## 原文（英語）
Fixed `claude -p` exiting 0 in auto mode when its actions were refused because no safety check was available: text and JSON output now exit 1

## 概要
CIなどで `claude -p` を使う際、安全チェック不可による拒否が成功と誤判定されないよう、失敗として終了コード1を返します。

## 基本的な使い方
```bash
claude -p "テストを修正して" --permission-mode auto
echo $?
```

## 実践例

### CIでの失敗検知
```bash
claude -p "lintエラーを直して" --permission-mode auto || exit 1
```

### JSON出力の利用
`--output-format json` でも同様に終了コード1になります。

## 注意点
- 既存スクリプトが終了コード0を前提にしている場合は、失敗を扱う処理を確認してください。
