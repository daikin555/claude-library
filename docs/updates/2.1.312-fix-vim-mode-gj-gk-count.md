## 原文（日本語訳）

Vimモードで、残り行数より大きいカウントの `gj`/`gk` に `d`・`c`・`y` を組み合わせると、テキストを削除・コピーしていた問題を修正。Vim同様、カーソル移動のみ行います

## 原文（英語）

Fixed vim mode `d`, `c` and `y` with a `gj` or `gk` count larger than the lines left deleting or copying text; like Vim, they now only move the cursor

## 概要

範囲を超えるカウント付きの `dgj` などで、本来動かないはずのテキスト操作が行われていました。Vimと同じ挙動に揃いました。

## 基本的な使い方

```
10dgj   # 残りが10行未満なら、削除せずカーソル移動のみ
```

## 実践例

### 安全な編集

カウントを多めに指定しても、意図しない削除が起きません。

## 注意点

- Vimモードを有効にしている場合に関係する修正です。
