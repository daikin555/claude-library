## 原文（日本語訳）

クラウドセッションでのWebFetchエラーを改善。解決できないホストは「許可されたネットワークドメイン外の可能性がある」と説明され、Claudeが許可すべきホストを示せるようになりました

## 原文（英語）

Improved WebFetch errors in cloud sessions: a host that does not resolve is now explained as possibly outside the allowed network domains, so Claude names the host to allow

## 概要

名前解決に失敗した場合、許可ドメイン外の可能性がエラーで説明されます。Claudeが許可すべきホスト名を案内しやすくなります。

## 基本的な使い方

クラウド環境でWebFetchが失敗した場合、案内されたホストをネットワーク設定の許可リストに追加して再試行します。

## 実践例

### 外部ドキュメント取得の失敗対処

案内されたホストを環境の許可ドメインに追加します。

## 注意点

- 許可ドメインの追加は、セキュリティ上の影響を確認したうえで行ってください。
