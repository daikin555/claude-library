## 原文（日本語訳）

[Code Review] 組織の上限が原因でレビューがスキップされた際のチェックランカードとPRコメントを改善しました。それぞれの原因ごとに、解決するための管理者ページへのリンクが表示されるようになりました。

## 原文（英語）

[Code Review] Improved the check-run card and PR comment when a review is skipped because of an organization limit: each cause now links the admin page that fixes it

## 概要

組織で設定された利用上限（レビュー回数の上限やシート数の上限など）に達すると、Code Reviewがスキップされることがあります。これまではスキップされた理由が分かっても、それを解決するために管理者がどこを操作すればよいのかが分かりにくいという課題がありました。今回の改善により、GitHubのチェックランカードやPRコメントに表示されるスキップ理由ごとに、該当する管理者設定ページへの直接リンクが表示されるようになり、問題解決までの手間が大幅に減りました。

## 基本的な使い方

組織の上限に達している状態でPRを作成すると、チェックランカードとPRコメントにスキップ理由とリンクが自動的に表示されます。

```
# 上限に達した状態でPRを作成すると、
# チェックランに "Code Review skipped: organization limit reached" のようなメッセージと
# 管理者ページへのリンクが表示される
```

## 実践例

### レビュー実行回数の上限に達した場合

月間のレビュー実行回数上限に達すると、チェックランカードに「利用上限に達しました」という趣旨のメッセージとともに、上限を確認・変更できる管理者ページへのリンクが表示され、管理者への連携がスムーズになります。

### シート数の上限に達した場合

契約シート数を超えたユーザーがレビュー対象になった場合も同様に、シート管理ページへの直接リンクが表示されるため、管理者はすぐに対応できます。

## 注意点

- リンク先の管理者ページにアクセスできるのは、該当する権限を持つ管理者のみです
- 上限の種類によって表示されるリンク先は異なります
