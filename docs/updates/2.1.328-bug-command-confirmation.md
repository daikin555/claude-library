# /bug が送信前に Yes / No を確認するように変更

## 原文（日本語に翻訳）

`/bug` は送信前に Yes か No を尋ねるようになり、Enter の連打でレポートが送信されたり GitHub が開いたりしなくなりました。

## 原文（英語）

Changed `/bug` to ask Yes or No before sending, so repeated Enters no longer send a report or open GitHub

## 概要

`/bug` で意図せずレポートを送ってしまう事故を防ぐため、確認ステップが入りました。あわせて、送信後に "cancelled" と表示される不具合も修正されています。

## 基本的な使い方

```bash
/bug
```

表示される確認で Yes / No を選びます。

## 実践例

### 誤送信の防止

Enter を連打しても確認で止まるため、意図しない送信を避けられます。

## 注意点

- 送信する場合は明示的に Yes を選択してください
