# claude remote-control が終了ステータス 4 / 69 を返すように改善

## 原文（日本語に翻訳）

`claude remote-control` は、自ら停止した場合にステータス 4（単一セッション実行の場合は従来どおり 0）、登録できなかった場合に 69 で終了するようになりました。これにより、サービスマネージャーが再起動できます。

## 原文（英語）

Improved `claude remote-control`: it now exits with status 4 when it stops by itself (single-session runs still exit 0) and 69 when it can't register, so a service manager can start it again

## 概要

終了コードで停止理由を区別できるようになり、systemd などのサービスマネージャーによる再起動判断がしやすくなりました。

| 状況 | 終了コード |
|------|-----------|
| 自ら停止した場合 | 4 |
| 単一セッション実行の終了 | 0 |
| 登録できなかった場合 | 69 |

## 基本的な使い方

```bash
claude remote-control
echo $?
```

## 実践例

### systemd で自動再起動する

```ini
[Service]
ExecStart=/usr/local/bin/claude remote-control
Restart=on-failure
```

0以外で終了した場合に再起動されます。登録失敗（69）の場合も再起動対象になるため、必要に応じて `RestartPreventExitStatus=69` で除外してください。

### シェルスクリプトで分岐する

```bash
claude remote-control
case $? in
  0)  echo "正常終了" ;;
  4)  echo "自己停止: 再起動します" ;;
  69) echo "登録失敗: 設定を確認してください" ;;
esac
```

## 注意点

- 単一セッション実行は従来どおり 0 で終了します。
