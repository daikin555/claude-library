## 原文（日本語に翻訳）

Gateway: `desktop:` オーバーレイが、リリース済みのDesktop設定すべてを受け付けるようになりました（従来は手動でリストアップされた11個のキーのみでした）。設定はDesktop自身のスキーマに対して起動時に検証され、未知のキーや不正な値があると起動が失敗するようになりました。

## 原文（英語）

Gateway: the `desktop:` overlay now accepts every released Desktop setting (was 11 hand-listed keys), validated at boot against Desktop's own schema; unknown or invalid keys fail boot

## 概要

Claude Code Gatewayが管理者向けに提供している `desktop:` オーバーレイ設定は、Claude Desktopアプリの挙動を組織全体で統一的に制御するための仕組みです。これまでは対応するキーが11個に固定されており、Desktop側で新しい設定項目が追加されてもGateway経由では反映できませんでした。今回の変更により、Desktopがリリース済みのすべての設定項目をオーバーレイ経由で指定できるようになり、さらに起動時にDesktop自身が持つスキーマ定義と照合するバリデーションが導入されました。これにより、キー名のタイプミスや不正な値を含んだ設定ファイルでGatewayを起動しようとした場合、サイレントに無視されるのではなく、起動そのものが失敗するようになります。

## 基本的な使い方

この変更は主にGatewayを運用する管理者に影響します。Gatewayの設定ファイル（managed設定）内の `desktop:` セクションに、Desktopアプリの設定キーを記述します。

```yaml
# gateway managed 設定ファイルの例
desktop:
  # Desktop側で定義されている設定キーであれば
  # 以前は使えなかったキーも含めて指定可能に
  autoUpdate: false
  theme: "dark"
  telemetryEnabled: false
  # ... Desktopのリリース済み設定キーすべてが対象
```

設定ファイルを反映してGatewayを再起動すると、起動処理の中でDesktopのスキーマに対する検証が行われます。

```bash
# Gatewayの再起動（設定検証が走る）
gateway restart

# 未知のキーや不正な値がある場合:
# Error: invalid desktop overlay setting "unknownKey"
# Boot failed
```

## 実践例

### 新しいDesktop設定項目を組織全体に展開する

Desktopの新バージョンで追加された設定項目を、Gateway経由で全社的に強制したい場合。

```yaml
desktop:
  # 以前のバージョンでは対応キー外だったため無視されていた項目も
  # 今回のアップデート以降は正しく検証・適用される
  newlyReleasedSetting: true
```

```bash
gateway restart
# ✓ Boot successful — 新設定が全クライアントに配布される
```

### 設定ミスを起動時に検知する

タイプミスしたキーをうっかり設定ファイルに含めてしまった場合。

```yaml
desktop:
  autoUpdaet: false  # タイポ（正しくは autoUpdate）
```

```bash
gateway restart
# Error: unknown desktop overlay key "autoUpdaet"
# Boot failed

# 修正前は誤ったキーがサイレントに無視され、
# 意図した設定が反映されないまま起動していた
```

### CI/CDでのデプロイ前検証

設定変更をデプロイする前に、CIパイプラインでGatewayの起動テストを行うことで、不正な設定が本番環境に反映される前に検出できます。

```bash
# CIステップの例
gateway validate-config --file ./managed-config.yaml
# desktop オーバーレイのスキーマ不整合があればここで失敗する
```

## 注意点

- Claude Code v2.1.232で導入された変更です。
- 対応キーが11個から「Desktopがリリース済みの全設定」に拡張されたため、これまで意図せず無視されていた設定が急に適用される可能性があります。デプロイ前に設定内容を再確認してください。
- 未知または不正な値を含む設定はGatewayの**起動失敗**を引き起こします。以前のように「サイレントに無視される」動作は期待できません。設定変更後は必ず起動確認を行ってください。
- Desktop側の設定スキーマはDesktopアプリのバージョンに追従するため、Desktopのバージョンアップ時にオーバーレイ設定の互換性も確認することを推奨します。
