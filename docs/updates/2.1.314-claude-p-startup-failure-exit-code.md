# claude -p が起動失敗時にエラーを出力し終了コード 1 を返すよう修正

## 原文（日本語訳）

起動に失敗した際、`claude -p` が終了コード 0 で何も出力せずに終了する問題を修正しました。エラーを出力し、終了コード 1 で終了します。

## 原文（英語）

Fixed `claude -p` exiting with code 0 and no output when startup failed; it now prints the error and exits 1

## 概要

以前は起動に失敗しても `claude -p` が成功したように見えたため、CI やスクリプトが失敗を検知できませんでした。修正後はエラー内容が出力され、終了コード 1 を返すので、通常のシェルのエラー処理で扱えます。

## 基本的な使い方

```bash
claude -p "このリポジトリの概要を説明して"
echo $?   # 起動失敗時は 1
```

## 実践例

### CI パイプラインでの失敗検知

```bash
set -e
claude -p "変更差分をレビューして" > review.md
```

起動失敗時にステップが失敗扱いになり、空の review.md が成功として扱われることを防げます。

### リトライ・通知処理

```bash
if ! claude -p "テストを修正して"; then
  echo "Claude Code の起動に失敗しました" >&2
  exit 1
fi
```

## 注意点

- 終了コードに依存した既存スクリプトでは、これまで見逃されていた失敗が表面化する可能性があります。
- 認証切れや設定不備が主な原因です。出力されたエラーメッセージを確認してください。
