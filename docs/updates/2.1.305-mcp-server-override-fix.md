# クラウドセッション／SDK指定のMCPサーバーが同名の設定で上書きされる問題を修正

## 原文（日本語に翻訳）

- クラウドセッションやSDKの `setMcpServers` で渡されたMCPサーバーが、セッション後半で自分の設定にある同名サーバーに置き換えられる問題を修正

## 原文（英語）

- Fixed an MCP server passed by a cloud session or by the SDK's `setMcpServers` being replaced later in the session by a same-named server from your own settings

## 概要

クラウドセッションやSDKの `setMcpServers` で注入したMCPサーバーが、ユーザー設定の同名サーバーに途中で差し替わってしまう不具合が修正されました。

## 基本的な使い方

SDK利用時の例（概念）:

```ts
await query.setMcpServers({
  docs: { command: "node", args: ["./docs-server.js"] },
});
```

## 実践例

### SDKアプリに固有のMCPを組み込む

利用者の個人設定に同名サーバーがあっても、アプリ側が指定したサーバーが使われ続けます。

## 注意点

- 意図しない差替えを避けるため、サーバー名は用途が分かる固有の名前にしておくと安心です。
