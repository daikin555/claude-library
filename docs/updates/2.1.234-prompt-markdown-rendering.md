## 原文（日本語訳）

トランスクリプトを改善しました。自分の入力したプロンプトも、Claudeの返信と同じようにMarkdownとしてレンダリングされるようになりました（シンタックスハイライト付きコードブロック、インラインコード、リストなど）。

## 原文（英語）

Improved the transcript: your own prompts now render markdown (highlighted code blocks, inline code, lists) the same way replies do

## 概要

これまでClaude Codeのトランスクリプトでは、Claudeからの返信はMarkdownとして整形表示される一方、ユーザー自身が入力したプロンプトはプレーンテキストのまま表示されていました。今回の改善により、ユーザーの入力もコードブロックのシンタックスハイライト、インラインコード、箇条書きリストなどが返信と同様にレンダリングされるようになり、会話全体の見た目の一貫性が向上しました。

## 基本的な使い方

特別な操作は不要です。プロンプトにMarkdown記法（コードブロック、リスト、インラインコードなど）を使って入力すると、送信後のトランスクリプト上でそのまま整形表示されます。

```
これはコードの一部です:

​```python
def hello():
    print("Hello, Claude Code!")
​```

- 修正してほしい点1
- 修正してほしい点2
```

上記のように入力すると、コードブロックはシンタックスハイライトされ、リストは箇条書きとして表示されます。

## 実践例

### コードスニペットを含む質問をする

バグの原因になっているコードをコードブロックで貼り付けて質問すると、トランスクリプト上でも読みやすくハイライト表示されます。

```
このコードでNullPointerExceptionが出ます。原因を教えてください。

​```java
public String getName(User user) {
    return user.getProfile().getName();
}
​```
```

### 複数の要望をリストで整理して伝える

やってほしいことを箇条書きで整理して渡すと、返信と同様に見やすいリスト表示になります。

```
以下を対応してください:

1. ログイン画面のバリデーションを追加
2. エラーメッセージを日本語化
3. テストコードを追加
```

### インラインコードで対象を明示する

`config.yaml` のようにファイル名や変数名をバッククォートで囲んで入力すると、インラインコードとして強調表示され、後からトランスクリプトを読み返す際に対象が一目でわかります。

## 注意点

- 表示上の改善であり、Claudeへの入力内容や解釈自体が変わるわけではありません
- 見た目が変わるのはトランスクリプト（会話履歴）の表示のみです
- 既存のセッションを再度開いた場合も、保存されているプロンプトはMarkdownとして再レンダリングされます
