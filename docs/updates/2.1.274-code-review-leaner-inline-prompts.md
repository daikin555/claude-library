## 原文（日本語訳）
`/code-review` が、チューニング済み設定を持たないすべてのモデルに対して、多数のレビューサブエージェントを起動する代わりに、より軽量なインラインレビュープロンプトを使用するように変更されました。

## 原文（英語）
Changed `/code-review` to use leaner inline review prompts for every model that has no tuned settings of its own, instead of spawning many review subagents

## 概要
`/code-review` コマンドは、特定のモデル向けにチューニングされた設定がある場合はその専用フローを使いますが、そうでないモデルではこれまで多数のレビューサブエージェントを並行起動して分析していました。今回の変更で、チューニング済み設定を持たないモデルについては、サブエージェントを多数起動する代わりに、より軽量なインラインプロンプトでレビューを行うようになりました。これによりレビュー実行のオーバーヘッドが減り、応答が速くなることが期待されます。

## 基本的な使い方
使い方自体に変更はなく、通常通り `/code-review` を実行するだけです。

```
/code-review
```

## 実践例

### 変更前の挙動
チューニング済み設定を持たないモデルで `/code-review` を実行すると、内部的に複数のレビューサブエージェントが並行して起動され、それぞれの結果を統合する形でレビューが行われていました。処理は徹底的でしたが、その分オーバーヘッドが大きくなりがちでした。

### 変更後の挙動
同じ条件で `/code-review` を実行すると、サブエージェントを多数起動せず、軽量なインラインプロンプト一つでレビューが実行されます。

```
/code-review --level medium
```

## 注意点
- チューニング済み設定を持つモデル（Anthropicが個別最適化しているモデル）では、従来通りの挙動が維持されます。
- レビューの網羅性よりも実行効率を優先した変更のため、非常に大規模な差分では詳細度に差が出る可能性があります。
- レビューの深さは引き続き `code-review` スキルのレベル指定（low/medium/high/xhigh/max/ultra）で調整できます。
