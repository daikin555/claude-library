## 原文（日本語訳）

Bashツールが `pyright` を実行する前に承認を求めるようになった（読み取り専用扱いを廃止）。また、より多くの形式の `ps` コマンドが、承認なしで実行されず承認を求めるようになった。

## 原文（英語）

Changed the Bash tool to ask for permission before running `pyright`, which is no longer treated as a read-only command
Changed Bash permission checks so that more forms of the `ps` command ask for approval instead of running without asking

## 概要

`pyright` と一部の `ps` は読み取り専用とみなされなくなり、自動承認の対象から外れました。

## 基本的な使い方

頻繁に使う場合は、許可ルールを追加すると承認を省略できます。

```json
{ "permissions": { "allow": ["Bash(pyright:*)"] } }
```

## 実践例

### 型チェックを頻繁に実行する場合

上記の許可ルールを `.claude/settings.json` に追加します。

### プロセス確認

`ps` は形式によって承認が必要です。必要なら許可ルールを追加してください。

## 注意点

- 許可ルールは信頼できるコマンドに限定してください。
