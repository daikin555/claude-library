## 原文（日本語訳）

[クラウドセッション] ルーチンページのメニューから Edit を選ぶと、編集ダイアログが開かずルーチンの詳細ページに移動するだけだった問題を修正しました

## 原文（英語）

[Cloud sessions] Fixed Edit in a routine's menu on the Routines page going to the routine's page without opening its edit dialog

## 概要

Editを選ぶと編集ダイアログが開くようになりました。

## 基本的な使い方

Routinesページで対象ルーチンのメニューからEditを選びます。

## 実践例

### スケジュールやプロンプトの変更

一覧から直接編集ダイアログに入れます。

## 注意点

- 他の項目の動作は変わりません。
