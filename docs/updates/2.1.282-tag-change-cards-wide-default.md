## 原文（日本語訳）

Claudeが計画、表、詳細のためにSlackの返信で使用する枠付きカードを、狭い幅ではなく既定でワイド表示するように変更しました。

## 原文（英語）

[Claude Tag] Changed the bordered cards Claude uses in Slack replies for plans, tables and details to render wide by default instead of a narrow width

## 概要

Claude TagがSlack上で計画（プラン）や表、詳細情報を表示する際に使用する枠付きのカードUIについて、これまでは狭い幅で表示されるのが既定でしたが、今回の変更で既定でワイド（幅広）表示されるようになりました。これにより、特に表形式のデータや詳細な計画内容など、情報量の多いコンテンツがより読みやすく表示されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。Claude TagがSlackで計画や表、詳細情報を含む返信を行う際、自動的にワイド表示のカードが使われます。

## 実践例

### 複数列の比較表を含むタスクの依頼

複数の選択肢を比較する表を含む調査結果をSlackで受け取る際、ワイド表示によって列が窮屈にならず、内容を把握しやすくなります。

### 詳細な実行計画の確認

複雑なタスクを依頼した際にClaudeが提示する実行計画（プラン）が、ワイドカードによってより見やすく整理された形で表示されます。

## 注意点

- これは表示スタイルの変更であり、カードに表示される情報の内容自体は変わりません
- Slackのウィンドウ幅やモバイルアプリなど、閲覧環境によって実際の見え方は多少異なります
