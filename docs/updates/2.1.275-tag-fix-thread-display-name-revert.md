## 原文（日本語訳）
[Claude Tag] スレッドの「Claude [タスク]」という表示名が、そのスレッドを支えるセッションが更新または再起動された後に、単なる「Claude」に戻ってしまう不具合を修正。

## 原文（英語）
[Claude Tag] Fixed a thread's "Claude [task]" display name reverting to plain "Claude" after the session behind that thread was refreshed or restarted

## 概要
Claude Tagでは、Slackスレッド内でClaudeが取り組んでいるタスクの内容に応じて「Claude [タスク名]」のような分かりやすい表示名が設定されます。しかし、そのスレッドの裏側にあるセッションが更新・再起動されると、この表示名が単なる「Claude」に戻ってしまい、スレッドを見ただけではどのタスクを扱っているスレッドか分かりにくくなる不具合がありました。今回の修正で、セッションが更新・再起動された後もタスクに応じた表示名が維持されるようになりました。

## 基本的な使い方
特別な操作は不要です。スレッド内でClaudeにタスクを依頼すると、そのタスク内容を反映した表示名が自動的に設定され、セッションの更新・再起動後もその表示名が保持されます。

## 実践例

### 長時間実行中のタスクでセッションが再起動された場合
「Claude [PRレビュー中]」のような表示名がついたスレッドで、セッションが何らかの理由で再起動されても、修正後は表示名がそのまま維持され、チームメンバーはスレッド一覧を見ただけでどのタスクの続きかを把握できます。

```
Before: 再起動後 "Claude [PRレビュー中]" → "Claude" に戻ってしまう
After:  再起動後も "Claude [PRレビュー中]" のまま維持される
```

### 複数のスレッドを並行して追っている場合
チャンネル内で複数のタスクスレッドを同時に進めている際、それぞれのスレッドの表示名がタスク内容を保ったままになるため、一覧性が保たれ、目的のスレッドを探しやすくなります。

## 注意点
- 表示名はタスクの進行状況に応じて自動的に更新される場合があります。
- 本修正はセッションの更新・再起動が発生した場合の表示名の巻き戻りに関するものであり、通常のタスク進行中の表示名更新ロジック自体は変更されていません。
