# VS Code: claudeCode.attachSelection で選択テキストの自動添付を止める

## 原文（日本語に翻訳）

[VSCode] エディタで選択したテキストがメッセージに追加されないようにする `claudeCode.attachSelection` 設定を追加しました。

## 原文（英語）

[VSCode] Added the `claudeCode.attachSelection` setting to stop text selected in the editor from being added to your messages

## 概要

VS Code 拡張では、エディタで選択した範囲がメッセージに加わります。この設定で、その自動追加を止められます。意図しないコードを送りたくない場合に便利です。

## 基本的な使い方

```json
{
  "claudeCode.attachSelection": false
}
```

## 実践例

### 機密コードの誤送信を避ける

別の用件を質問するときに、たまたま選択していたコードが含まれることを防げます。

## 注意点

- 既定値や詳細は拡張機能の設定画面で確認してください。
- 無効にした場合、必要なコードは `@` メンションなどで明示的に渡します。
