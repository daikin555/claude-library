# Self-hosted runner: --repository-folder オプションを追加

## 原文（日本語に翻訳）

`--capacity 1` のとき、セッションがリポジトリに使うフォルダー名を指定する `--repository-folder` を追加しました。従来のベースフォルダー配下のパスの代わりに使え、シンボリックリンクにはできません。

## 原文（英語）

Self-hosted runner: Added `--repository-folder` to name the folder that sessions use for a repository at `--capacity 1`, in place of its path under the base folder, which can't be a symbolic link

## 概要

Self-hosted runner で、リポジトリ用フォルダーの名前を明示できるようになりました。既存ディレクトリ構成に合わせたい場合に便利です。

## 基本的な使い方

```bash
claude self-hosted-runner --capacity 1 --repository-folder my-repo
```

## 実践例

### 固定のフォルダー名でリポジトリを扱う

後続のスクリプトやフックが決まったフォルダー名を前提にしている場合に指定します。

## 注意点

- `--capacity 1` の場合の機能です
- フォルダーはシンボリックリンクにできません。同バージョンでは、push 先リポジトリのパスがシンボリックリンクだと `--capacity 1` でより早い段階でセッションを拒否するようになりました
- コマンドの正確な構文は `--help` で確認してください
