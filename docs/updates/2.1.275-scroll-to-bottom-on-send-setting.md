## 原文（日本語訳）

[VSCode] 返信がストリーミング中に上へスクロールしても会話が自動的に一番下に引き戻されてしまう問題を修正し、送信時のジャンプを無効化できる`claudeCode.scrollToBottomOnSend`設定を追加しました。

## 原文（英語）

[VSCode] Fixed the conversation pulling you back to the bottom while a reply streams after you scroll up, and added a `claudeCode.scrollToBottomOnSend` setting to turn off the jump on send

## 概要

Claudeの返信がストリーミング中、過去のメッセージを確認するために会話を上にスクロールしても、強制的に一番下に引き戻されてしまい、内容をじっくり確認できないという問題がありました。この修正により、ユーザーが明示的に上にスクロールした場合はその位置が尊重されるようになります。さらに、メッセージ送信時に自動で一番下へジャンプする挙動自体をオフにできる新設定`claudeCode.scrollToBottomOnSend`が追加され、ユーザーはスクロール挙動をより細かく制御できるようになりました。

## 基本的な使い方

VS Codeの設定（`settings.json`）に以下を追加すると、メッセージ送信時の自動スクロールを無効化できます。

```json
{
  "claudeCode.scrollToBottomOnSend": false
}
```

デフォルトは `true`（従来通り送信時に一番下へスクロール）です。

## 実践例

### 返信を読みながら過去の文脈を参照したい場合

Claudeの返信がストリーミング中でも、上にスクロールして過去の会話を確認したい場合、修正後は意図せず一番下に引き戻されることがなくなります。

```
1. 返信がストリーミング中に会話を上にスクロール
2. ストリーミングが続いても、スクロール位置がそのまま保たれる
```

### メッセージ送信時の自動スクロールを無効にしたい場合

長い会話で送信するたびに画面が一番下へジャンプするのを避けたいユーザーは、設定でこの挙動をオフにできます。

```json
// settings.json
{
  "claudeCode.scrollToBottomOnSend": false
}
```

これにより、メッセージを送信しても現在のスクロール位置が維持されます。

## 注意点

- `claudeCode.scrollToBottomOnSend`を`false`にした場合、新しい返信を確認するには手動でスクロールする必要があります。
- 上にスクロールした状態を尊重する挙動の修正は設定に関わらず常に適用されます。
