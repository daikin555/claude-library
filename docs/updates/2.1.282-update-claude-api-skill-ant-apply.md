## 原文（日本語訳）

`claude-api` スキルを更新し、Managed Agentsのリソースをバージョン管理されたファイルとして維持するために `ant apply` を推奨するようにしました。

## 原文（英語）

Updated the `claude-api` skill to recommend `ant apply` for keeping Managed Agents resources as version-controlled files

## 概要

Managed Agents（Anthropicがホストするサーバー型エージェント）のリソース定義を管理する際、これまでは手動での設定変更が中心でしたが、`claude-api` スキルが更新され、`ant apply` コマンドを使ってリソースをバージョン管理されたファイルとして維持する方法が推奨されるようになりました。これにより、Infrastructure as Code的な手法でManaged Agentsの設定を管理できるようになります。

## 基本的な使い方

Managed Agentsのリソース定義をファイルとして用意し、以下のように適用します。

```bash
ant apply -f managed-agent-config.yaml
```

設定ファイルはGitなどでバージョン管理し、変更履歴を追跡できます。

## 実践例

### 複数環境でのManaged Agents設定の一貫性確保

開発・ステージング・本番といった複数環境で同じManaged Agentsの構成をバージョン管理されたファイルから適用することで、環境間の設定差異を防げます。

### レビュープロセスを伴う設定変更

Managed Agentsの設定変更をPull Requestとしてレビューしてから `ant apply` で適用する運用にすることで、意図しない設定変更のリスクを減らせます。

## 注意点

- `ant apply` コマンドの詳細なオプションや対応リソースの範囲については、公式のClaude API / Agent SDKドキュメントを参照してください
- 既存の手動設定からの移行時は、現在の設定内容を事前にエクスポート・確認することをおすすめします
