## 原文（日本語訳）
[Claude Code on the web] ルーティンを編集すると、たまにそのルーティンが2回発火したり、一時停止したばかりのルーティンが再有効化されてしまったりする問題を修正しました。

## 原文（英語）
[Claude Code on the web] Fixed editing a routine occasionally making it fire twice or re-enabling a routine that had just been paused

## 概要
Claude Code on the webの「ルーティン」機能（決められたスケジュールやトリガーで自動実行されるセッション）で、設定を編集して保存した際に、意図せずそのルーティンが二重に実行されてしまったり、直前に一時停止したはずのルーティンが編集操作によって再び有効化されてしまう不具合がありました。今回の修正により、ルーティンの編集操作が実行状態や有効/無効の状態に予期しない影響を与えないようになりました。

## 基本的な使い方
特別な操作は不要です。通常通りルーティンの設定（トリガー条件やプロンプトなど）を編集して保存するだけで、意図しない二重実行や再有効化は発生しなくなります。

## 実践例

### 一時停止中のルーティンを編集する場合
ルーティンを一時停止（Pause）した直後にプロンプト文言などの軽微な修正を加えて保存しても、ルーティンは一時停止状態のままとなり、意図せず有効化されることはありません。

### スケジュール直前にルーティンを編集する場合
定期実行のタイミングが近いルーティンの設定を編集・保存しても、そのタイミングでルーティンが2回続けて実行されるようなことはなくなりました。

## 注意点
- 編集後に意図的にルーティンを有効化したい場合は、明示的にトグルを操作する必要があります。
- この修正はClaude Code on the webのルーティン機能に関するものです。
