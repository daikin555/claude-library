## 原文（日本語訳）

`keybindings.json` で全エージェント停止のショートカットが未割り当ての場合、`/tasks` ダイアログのフッターに ` · ` の区切り文字が二重に表示されてしまう不具合を修正しました。

## 原文（英語）

Fixed a doubled ` · ` separator in the `/tasks` dialog footer when the stop-all-agents shortcut is unbound in `keybindings.json`

## 概要

`/tasks` ダイアログのフッターには、利用可能な操作のヒントが ` · ` （中点）で区切られて並べて表示されます。しかし、`keybindings.json` で「全エージェント停止」のショートカットキーの割り当てを解除（unbind）していると、そのショートカットに対応するヒント項目が空になり、結果として区切り文字の ` · ` だけが2つ連続して表示されてしまう、見た目上不自然な不具合がありました。今回の修正でこの表示崩れが解消されました。

## 基本的な使い方

ユーザー側の対応は不要です。`keybindings.json` で全エージェント停止のショートカットを未割り当てにしている場合でも、`/tasks` ダイアログのフッター表示が正しく整形されます。

```
/tasks
```

## 実践例

### 特定のショートカットを意図的に無効化している環境

誤操作防止のために「全エージェント停止」のショートカットをあえて未割り当てにしている開発者でも、フッター表示が崩れずに済みます。

### キーバインドのカスタマイズ全般における表示の一貫性

複数のショートカットを自分好みにカスタマイズ・無効化している環境でも、`/tasks` を含む各種ダイアログのフッター表示が一貫して正しく表示されます。

## 注意点

- デフォルトのキーバインド（ショートカットが割り当てられている状態）を使用している場合は、この不具合の影響を受けていませんでした
- これは表示上の修正であり、`/tasks` ダイアログの機能自体には影響しません
