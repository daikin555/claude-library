## 原文（日本語訳）

フィードバックサーベイのトランスクリプト共有の仕様を変更しました。ユーザーの同意がある場合、直近のリクエストのモデル設定 ―― システムプロンプト（あなたの`CLAUDE.md`の指示内容を含む）、ツール定義、モデルパラメータ ―― も併せてアップロードするようになりました。機密情報（シークレット）は従来どおり削除（redact）され、共有内容が大きすぎる場合はこれらのフィールドが最初に削除されます。

## 原文（英語）

Changed the feedback-survey transcript share: with your consent it now also uploads the last request's model settings — the system prompt (which includes your `CLAUDE.md` instructions), tool definitions, and model parameters. Secrets are redacted as before, and these fields are dropped first if the share is too large

## 概要

Claude Codeには「このセッションの調子はどうですか？」というセッション品質サーベイが表示されることがあります。評価だけを送る場合は会話内容は一切送信されませんが、その後に表示される「セッションのトランスクリプトをAnthropicが確認してもよいか」という追加の同意ステップで「Yes」を選ぶと、これまでも会話トランスクリプトやサブエージェントのトランスクリプト、セッションログがアップロードされていました。今回の変更では、この「Yes」を選んだ場合に限り、アップロード内容に直近リクエストの「モデル設定」――システムプロンプト（`CLAUDE.md`の指示を含む）、利用可能なツールの定義、モデルパラメータ――が新たに追加されます。これはClaude Codeの改善のために、実際にどのような設定でモデルが動作していたかをAnthropicが把握できるようにするためのものです。

## 基本的な使い方

サーベイが表示された際、評価を送った後に表示される追加の確認ダイアログで選択するだけです。

```text
"Can Anthropic look at your session transcript to help us improve Claude Code?"

Yes    → トランスクリプト・サブエージェントのログ・モデル設定(システムプロンプト/ツール定義/モデルパラメータ)がアップロードされる
No     → 何も送信せず辞退
Don't ask again → 今後このダイアログを表示しない
```

## 実践例

### フィードバックに協力しつつ社内向けCLAUDE.mdの扱いを理解しておきたい場合

システムプロンプトには、プロジェクトの`CLAUDE.md`に書いた指示内容がそのまま含まれます。社内ルールやプロジェクト固有の指示を`CLAUDE.md`に書いている場合、「Yes」を選ぶとその内容も送信対象に含まれることを理解したうえで判断してください。

```text
# CLAUDE.md にプロジェクト独自のルールを書いている場合
# → トランスクリプト共有に同意すると、そのCLAUDE.mdの内容を含む
#   システムプロンプトもアップロードされる
```

### 送信を明示的に拒否・恒久的に無効化したい場合

この追加ステップはオプトイン（明示的な同意が必須）であり、「No」または「Don't ask again」を選べば何も送信されません。組織単位でこのサーベイ自体を無効化することもできます。

```bash
# サーベイ自体を無効化(環境変数)
export CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1

# 非本質的な通信全体を無効化する場合も、この同意ステップは表示されなくなる
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

### Zero Data Retention(ZDR)契約の組織で運用している場合

Zero Data Retentionの契約がある組織や、組織ポリシーで製品フィードバックが無効化されている場合、この追加ステップ自体が表示されません。

## 注意点

これはプライバシー・データ共有に直結する変更のため、内容を正確に理解しておくことが重要です。

- **アップロードはオプトイン**です。評価（レーティング）だけを送った段階では会話内容は一切送信されません。会話トランスクリプトやモデル設定が送信されるのは、レーティング後に表示される追加の確認で明示的に「Yes」を選んだ場合のみです。
- **今回新たに追加されたアップロード対象**は、直近リクエストの「モデル設定」です。具体的には、(1) システムプロンプト（プロジェクトの`CLAUDE.md`に書いた指示内容を含む）、(2) 利用可能なツールの定義、(3) モデルパラメータ、の3種類です。
- **既知のAPIキー・トークンのパターンは従来どおり削除（redact）されます。** ただしソースコードやファイル内容など、それ以外の会話内容は基本的にそのままアップロードされる点は変わりません。`CLAUDE.md`に機密情報や個人情報を直接書き込んでいる場合、パターンとして検出されない限り送信対象に含まれうるため、機密性の高い指示は別の方法（環境変数や外部の秘密管理サービスなど）で管理することを推奨します。
- **共有データが大きすぎる場合、まずモデル設定（システムプロンプト・ツール定義・モデルパラメータ）が優先的に削除**されてから送信されます。つまり、サイズ超過時にはこれらの新規追加フィールドが真っ先に間引かれる設計です。
- 共有されたトランスクリプトは最大6か月保持され、モデルの学習には使用されません。
- Amazon Bedrock・Google Cloud's Agent Platform・Microsoft Foundryや、Anthropicの資格情報が設定されていない環境では、送信の代わりに`~/.claude/feedback-bundles/`配下にローカル保存されるだけで、明示的に共有するまで外部には送信されません。
