## 原文（日本語訳）

claude.aiでのログインが優先されるべき状況で、期限切れになったAnthropicプロファイルの資格情報が表示された場合に、`/login`へ誘導するようになりました。

## 原文（英語）

Expired Anthropic profile credential now points you at `/login` when a claude.ai login would take precedence

## 概要

Claude Codeでは、Anthropicプロファイル（APIコンソール経由の認証情報など）とclaude.aiアカウントによるログインの両方が絡む認証の優先順位が存在します。これまで、Anthropicプロファイル側の資格情報が期限切れになっている場合、本来はclaude.aiログインが優先されるべき状況であっても、ユーザーに適切な対処法（`/login`の実行）が案内されないケースがありました。今回の修正で、そのような状況では明確に`/login`を実行するよう案内されるようになり、認証エラーで詰まってしまう状況が改善されました。

## 基本的な使い方

この修正はエラーメッセージ・案内文の改善であり、ユーザー側の操作フローはシンプルになります。

1. Anthropicプロファイルの資格情報が期限切れの状態でClaude Codeを使用しようとする
2. claude.aiログインが優先されるべき状況だと判定されると、`/login`を実行するよう促すメッセージが表示される
3. 表示された案内に従って `/login` を実行し、再認証する

```
$ claude
Your Anthropic profile credential has expired.
Please run /login to sign in with your claude.ai account.
```

## 実践例

### APIコンソール認証からclaude.aiサブスクリプションに切り替えて使っている場合

以前AnthropicのAPIコンソール経由で認証していたが、現在はclaude.aiのPro/Maxプランでログインして使っているようなユーザーの場合、古いAnthropicプロファイルの資格情報が期限切れのまま残っていると、以前はどう対処すべきか分かりにくいエラーが出ることがありました。修正後は`/login`を実行すべきことが明確に案内されます。

### 認証エラーに遭遇した際の切り分け

Claude Code起動時や実行中に認証関連のエラーメッセージが出た場合、そのメッセージが「`/login`を実行してください」という具体的な案内であれば、この修正で改善された導線に沿って再ログインするだけで解決できます。

## 注意点

- この修正はAnthropicプロファイルの資格情報が期限切れかつclaude.aiログインが優先されるべき、という特定の状況に関するものです
- `/login`を実行すると、claude.aiアカウントでの再認証フローが開始されます
- 認証方式（APIキー、Anthropicコンソール、claude.aiサブスクリプション）によって案内内容は異なる場合があります
