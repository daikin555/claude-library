# plugin install --config で同梱 MCP サーバーの設定をインストール時に指定する

## 原文（日本語訳）

- `claude plugin install --config` に `<server>.<key>=<value>` を指定できるようにしました。同梱の `.mcpb` MCP サーバー自身の設定をインストール時に設定でき、`/plugin` → Configure を開かなくても起動します

## 原文（英語）

- Added `<server>.<key>=<value>` to `claude plugin install --config`, so a bundled `.mcpb` MCP server's own settings can be set at install time and it starts without visiting `/plugin` → Configure

## 概要

`.mcpb` 形式の MCP サーバーを同梱するプラグインで、サーバー固有の設定をインストールと同時に渡せます。設定が必要なサーバーが未設定のままスキップされる問題（同バージョンで通知されるよう改善）も、この方法で回避できます。

## 基本的な使い方

```bash
claude plugin install my-plugin@my-marketplace --config my-server.api_url=https://example.com
```

## 実践例

### 複数の設定を渡す

```bash
claude plugin install my-plugin@my-marketplace \
  --config my-server.api_url=https://example.com \
  --config my-server.region=ap-northeast-1
```

### CI やセットアップ自動化

対話操作なしでプラグインと MCP サーバーの設定を完了できます。

## 注意点

- `--config` を複数回指定できるかは、実際のヘルプで確認してください。
- 設定が必要なのに未設定の `.mcpb` サーバーは、`/plugin` やインストール時のメッセージで通知されます。
