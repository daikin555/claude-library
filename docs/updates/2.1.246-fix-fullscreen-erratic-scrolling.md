## 原文（日本語訳）

トランスクリプト内で以前のメッセージ位置にいるときに、フルスクリーンのスクロールが不安定になる不具合（最下部へのジャンプがトランスクリプトの途中で止まってしまう現象を含む）を修正しました。

## 原文（英語）

Fixed erratic fullscreen scrolling when positioned at an earlier message, including jump-to-bottom getting stuck mid-transcript

## 概要

フルスクリーンモードでトランスクリプトをスクロールして過去のメッセージを見ている際、スクロール操作が予測しづらい動きをする不具合がありました。特に、最下部（最新メッセージ）へジャンプする操作を行っても、途中で止まってしまい最新メッセージまで到達できないケースが報告されていました。今回のアップデートでこの問題が修正され、過去のメッセージを閲覧中でもスクロールが安定して動作し、最下部へのジャンプも確実に機能するようになりました。

## 基本的な使い方

フルスクリーンモードで長いトランスクリプトを上にスクロールして過去のメッセージを表示させた状態から、最下部へジャンプする操作（例: `End` キーや対応するショートカット）を行うと、修正後の挙動を確認できます。

```
# 過去のメッセージまでスクロールした状態で
# 最下部へジャンプするキー操作を行う
```

修正後は途中で止まることなく、確実に最新メッセージの位置までスクロールします。

## 実践例

### 長い会話履歴を遡って過去の指示を確認する場合

長時間にわたるセッションで過去の指示や出力を確認するためにスクロールバックした後、最新の状態に戻ろうとした際、以前は途中で止まってしまうことがありましたが、修正後は問題なく最下部まで戻れます。

### コードレビューのため以前のdiffを見返す場合

過去に生成されたdiffやコード提案を確認するために画面を遡った後、作業を再開するために最新メッセージへスムーズに戻れるようになりました。

### 複数の変更点を順番に確認していく場合

トランスクリプトの中盤にとどまりながら細かくスクロール操作を繰り返すようなワークフローでも、スクロールの挙動が安定し、意図しない位置に飛ばされることがなくなりました。

## 注意点

- この修正は表示・操作性に関するものであり、会話データ自体には影響しません
- 通常表示（フルスクリーンモード以外）ではこの不具合の影響を受けません
- ターミナルの種類やサイズによって、スクロール操作の細かな挙動が異なる場合があります
