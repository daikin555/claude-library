## 原文（日本語訳）

macOS の Keychain 読み込みがタイムアウトした後、MCP OAuth サーバーが 401 エラーの連続で間欠的に失敗する問題（認証されていないかのように見える）が修正されました。

## 原文（英語）

Fixed MCP OAuth servers on macOS intermittently failing with a burst of 401 errors, as if never authenticated, after a keychain read timed out

## 概要

Claude Code は macOS の Keychain に MCP サーバーの OAuth 認証情報を安全に保存します。以前は Keychain への読み込みタイムアウトが発生すると、有効な認証情報が存在しているにもかかわらず、MCP サーバーが未認証として扱われ、401 エラーが連続して発生することがありました。このバージョンでは、この間欠的な認証エラーの問題が修正され、Keychain タイムアウト後の復帰動作が改善されました。

## 基本的な使い方

MCP OAuth 認証は通常、以下のフローで動作します。

**OAuth ベースの MCP サーバーを追加する：**

```bash
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
```

**認証状態を確認する：**

Claude Code セッション内で `/mcp` コマンドを実行してサーバーのリストを表示します。

```text
/mcp
```

サーバーが `! Needs authentication` と表示される場合は、認証が必要です。

**認証フロー：**

1. `/mcp` パネルでサーバー名を選択して Enter キーを押します
2. `Authenticate` を選択します
3. ブラウザが自動的に開き、サーバーの認証ページが表示されます
4. 認証を許可すると、認証情報が macOS Keychain に暗号化されて保存されます
5. Claude Code に戻るとサーバーのステータスが接続状態に変わります

## 実践例

### OAuth 認証が必要な MCP サーバーをセットアップする

Sentry のような OAuth ベースのサーバーをセットアップする例：

```bash
# ターミナルでサーバーを追加
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp

# サーバーの状態を確認
claude mcp list
```

出力例：
```
sentry: ! Needs authentication
```

セッションを開始：

```bash
claude
```

セッション内で認証：

```text
/mcp
```

サーバーを選択して Authenticate を実行します。ブラウザで Sentry にサインインすると、認証情報が Keychain に保存されます。以降は自動的に認証情報が使用されます。

### 401 エラーが再度発生した場合の対処方法

万が一、修正後も 401 エラーが発生する場合の確認手順：

```bash
# セッション内で認証状態を確認
/mcp
```

**チェック項目：**

1. サーバーのステータスが `✔ Connected` か確認
2. `! Needs authentication` と表示される場合は再度認証を実行
3. エラーメッセージに Keychain へのアクセス許可を求めるプロンプトがないか確認

**再認証手順：**

```text
/mcp
```

リストからサーバーを選択し、`Authenticate` を選択して再度ブラウザ認証を実行します。

## 注意点

- **macOS 固有の問題**：このバージョンの修正は macOS での Keychain 読み込みタイムアウトに対応したものです。Linux や Windows ではこの問題は発生しません。

- **間欠的な性質**：Keychain タイムアウトは通常、macOS の Keychain システムが応答遅延を起こす場合に発生します。ネットワークの遅延や Keychain のロック状態が原因となることがあります。

- **Keychain アクセス許可**：SSH セッションや UI なしの環境では、Keychain がロックされていないことを確認してください。

- **認証情報の再入力**：`/mcp` パネルから再度 `Authenticate` を実行すれば、最新の認証情報を Keychain に保存できます。

- **デバッグ情報**：401 エラーが続く場合は、`claude mcp get <server-name>` コマンドで設定内容を確認してください。
