# /usage の警告をソース名付き1行の修正案にし f キーで適用

## 原文（日本語に翻訳）

- `/usage` を改善：各警告がソースを示す1行の修正案になり、`f` キーで修正を適用できる。同じ修正はVS Codeと `/doctor` にも表示される

## 原文（英語）

- Improved `/usage`: each warning is now a one-line fix that names its source, and `f` applies the fixes; the same fixes appear in VS Code and `/doctor`

## 概要

`/usage` の警告が、原因の出どころを示す1行の修正案として表示されます。`f` を押すとまとめて適用でき、VS Codeや `/doctor` でも同じ修正が提示されます。

## 基本的な使い方

```
/usage
```

警告の行を確認し、`f` を押して修正を適用します。

## 実践例

### 使用量の最適化

トークンを消費している設定の出どころが分かり、ワンキーで改善できます。

### /doctor での診断

`/doctor` でも同じ修正案を確認できます。

## 注意点

- 適用前に、各修正案の内容を確認してください。
