## 原文（日本語訳）

[クラウドセッション] 送信失敗後に同じメッセージを再送すると、二重に実行されることがある問題を修正しました

## 原文（英語）

[Cloud sessions] Fixed resending an unchanged message after a failed send in a cloud session sometimes running it twice

## 概要

再送時にメッセージが2回実行される可能性がなくなりました。

## 基本的な使い方

追加操作は不要です。再送しても1回だけ実行されます。

## 実践例

### 不安定な回線での利用

再送しても二重の作業が起きにくくなります。

## 注意点

- 念のため、失敗直後は状態を確認してから再送すると安心です。
