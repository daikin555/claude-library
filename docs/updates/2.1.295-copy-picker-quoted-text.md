# /copy ピッカーで引用テキストを > なしでコピー

## 原文（日本語に翻訳）

`/copy` ピッカーに引用テキストを追加しました。下書きしたメッセージを `>` マーカーなしでコピーできます。

## 原文（英語）

Added quoted text to the `/copy` picker, so a drafted message copies without its `>` markers

## 概要

`/copy` のピッカーから、引用ブロックとして表示されているテキストを `>` 記号抜きでコピーできるようになりました。メールやチャットの下書きを Claude に作らせた場合、貼り付け後に `>` を手で消す手間が省けます。

## 基本的な使い方

```
/copy
```

表示されたピッカーから引用テキストの項目を選択します。

## 実践例

### Slack や PR コメントの下書き

Claude に下書きを書かせ、`/copy` で `>` を取り除いた状態のまま貼り付けられます。

### メール文面の作成

引用形式で提示された文面をそのままコピーして、メーラーに貼り付けられます。

## 注意点

- 選択できる項目はピッカーに表示される内容に従います。
