# Claude Fable 5.2が追加され、Fableモデルのデフォルトに

## 原文（日本語に翻訳）

- Claude Fable 5.2（`claude-fable-5-2`）を追加。Fableモデルのデフォルトになりました。1Mコンテキスト、$8/$40 per Mtok、キャッシュ読み取りは$0.20/Mtok
- 保存されているFable 5.1のモデル選択を `fable` に移行。ProおよびMaxプランでは即時、TeamおよびEnterpriseプランでは組織が許可した時点で移行される。元に戻すには `/model claude-fable-5-1` を使用

## 原文（英語）

- Added Claude Fable 5.2 (`claude-fable-5-2`), now the default Fable model — 1M context, $8/$40 per Mtok with $0.20/Mtok cache reads
- Changed saved Fable 5.1 model picks to move to `fable`: on Pro and Max plans at once, on Team and Enterprise plans once your organization allows it; use `/model claude-fable-5-1` to switch back

## 概要

最新のFableモデル「Claude Fable 5.2」が利用できるようになり、`fable` エイリアスの指す先になりました。1Mトークンのコンテキストを持ち、料金は入力$8・出力$40（100万トークンあたり）、キャッシュ読み取りは$0.20です。

## 基本的な使い方

```text
> /model fable
```

起動時に指定することもできます。

```bash
claude --model claude-fable-5-2
```

## 実践例

### 以前のFable 5.1に戻す

挙動を固定したい場合は、明示的にバージョンを指定します。

```text
> /model claude-fable-5-1
```

### 長大なコードベースの調査

1Mコンテキストを活かし、大規模リポジトリを横断した調査や設計レビューに使えます。キャッシュ読み取りが安価なため、同じ文脈での反復作業に向いています。

## 注意点

- Fable 5.1を選択していた場合、プランに応じて自動的に `fable`（5.2）へ移行します。TeamとEnterpriseは組織の許可が必要です。
- 料金は入力$8／出力$40（per Mtok）、キャッシュ読み取り$0.20（per Mtok）です。
