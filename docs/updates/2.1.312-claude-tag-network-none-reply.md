## 原文（日本語訳）

[Claude Tag] 環境のネットワークアクセスがNoneに設定されたチャンネルで、Slack上のClaudeが返信しない問題を修正しました

## 原文（英語）

[Claude Tag] Fixed Claude in Slack not replying in channels whose environment has network access set to None

## 概要

ネットワークアクセスをNoneにした環境でも、Slackで返信が届くようになりました。

## 基本的な使い方

追加操作は不要です。

## 実践例

### 制限環境での利用

外部通信を禁止した環境でもSlackで応答を受け取れます。

## 注意点

- Claude自身の外部アクセスは設定どおり制限されたままです。
