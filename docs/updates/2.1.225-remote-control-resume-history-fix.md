## 原文（日本語訳）

大規模会話がコンパクション後、Remote Control セッション再開時に会話履歴が破損する問題を修正しました。

## 原文（英語）

Fixed conversation history breaking on Remote Control session resume after very large conversations were compacted

## 概要

Claude Code の Remote Control 機能を使用して別のデバイスからセッションを再開する際に、コンテキストがコンパクション（圧縮）された大規模会話の場合、会話履歴が破損して表示されない問題がありました。このアップデートでコンパクション後のセッション再開時にも会話履歴が正しく表示されるようになりました。長時間のセッションを複数のデバイスから継続して利用する方に特に重要な修正です。

## 基本的な使い方

Remote Control は、デスクトップ or VS Code で実行中のローカルセッションを、phone・tablet・ブラウザから接続・操作できる機能です。セッションはマシン上で実行され、ファイルシステムへのアクセスはすべてローカルで行われます。非常に大規模な会話では、コンテキスト ウィンドウが満杯になるとコンパクション（会話履歴の自動要約圧縮）が動作します。以前は、このコンパクション後に Remote Control で別デバイスからセッションを再開するときに会話履歴の表示が破損することがありました。

## 実践例

### 長時間セッションを複数回コンパクション後、phone から再開する場合

デスクトップで数時間かけて大規模なコード修正プロジェクトを進めており、コンテキストが満杯になり複数回コンパクションが発生しました。その後、phone の Claude アプリから同じセッションを`claude.ai/code`で開いて再開した場合、以前はコンパクション後の会話履歴が正しく表示されませんでしたが、このバージョン以降は正常に表示されます。

```bash
# デスクトップで Remote Control セッションを開始
claude remote-control --name "LargeProjectUpdate"

# phone や tablet で claude.ai/code を開き、セッション一覧から再開
# 会話履歴が正常に表示されます
```

### Desktop と Remote Control 間で長時間会話を切り替える場合

ローカル VS Code でセッションを開いていて、途中で phone に切り替えて操作継続し、また Desktop に戻ってくるというフロー。特に会話が非常に大規模でコンパクションが複数回発生しているケースでも、すべてのデバイス間で会話履歴の一貫性が保たれます。

```bash
# Desktop で Remote Control を有効化
claude --remote-control "MySession"

# VS Code から操作開始
# /remote-control コマンドで Remote Control を起動

# phone で claude.ai/code または Claude アプリからアクセス
# 会話の続きを見続けられます

# Desktop に戻ってセッションを再開
claude --resume MySession
# コンパクション後でも会話履歴は破損しません
```

## 注意点

- このバージョンはクライアント側（Claude Code 2.1.225+）の修正です。アップグレードすることで修正が有効になります
- 非常に大規模な会話特に複数回のコンパクションが発生したセッションで効果があります
- Remote Control は Pro、Max、Team、Enterprise プランで利用可能です（Team・Enterprise ではアドミンが有効化する必要があります）
- セッション再開前に Claude Code が最新バージョンに更新されていることを確認してください
- `/resume` や `claude --resume` でセッションを再開する際に有効です
