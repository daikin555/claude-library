## 原文（日本語に翻訳）

[VSCode] チャット入力のCtrl+Jが常に改行を挿入していた問題を修正しました。~/.claude/keybindings.json のChatコンテキストで "ctrl+j" を null に設定すると、VS CodeとOSに処理が委ねられます

## 原文（英語）

[VSCode] Fixed Ctrl+J in the chat input always inserting a newline: it is now left to VS Code and the OS when "ctrl+j" is set to null in the Chat context of ~/.claude/keybindings.json

## 概要

VS Code拡張のチャット入力ではCtrl+Jが常に改行になっていました。Ctrl+JをVS Codeのコマンド（パネル切替など）に使っていると衝突します。keybindings.json で `null` を指定すれば、Claude側のバインドが外れます。

## 基本的な使い方

`~/.claude/keybindings.json`（構造は一例です。既存ファイルの形式に合わせてください）:

```json
{
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+j": null
      }
    }
  ]
}
```

## 実践例

### VS Codeのパネル切替と共存させる

Ctrl+J をパネル表示の切替に使っている場合、上記設定でチャット入力中もVS Code側が処理します。

## 注意点

- 無効化後の改行入力は別のキー（Shift+Enterなど）を使います
- 正確な設定書式は公式ドキュメントで確認してください
