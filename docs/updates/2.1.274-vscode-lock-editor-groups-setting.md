## 原文（日本語訳）
Claudeが開いたエディタグループをロックしないようにするための `claudeCode.lockEditorGroups` 設定が追加されました。

## 原文（英語）
[VSCode] Added a `claudeCode.lockEditorGroups` setting to stop Claude from locking the editor groups it opens in

## 概要
VSCode拡張機能は、Claudeが差分表示やファイルを開く際にエディタグループをロックし、他のタブに置き換わらないようにする挙動を持っています。しかし、この挙動が使い方によっては邪魔に感じられることもありました。今回追加された `claudeCode.lockEditorGroups` 設定により、この自動ロック機能を無効化できるようになりました。

## 基本的な使い方
VSCodeの `settings.json` に以下を追加すると、Claudeが開いたエディタグループが自動的にロックされなくなります。

```json
{
  "claudeCode.lockEditorGroups": false
}
```

## 実践例

### エディタグループの自動ロックを無効にしたい場合
複数のファイルを自由に切り替えながら作業したいユーザーは、この設定をオフにすることでエディタグループのロックによる制約を受けなくなります。

```json
{
  "claudeCode.lockEditorGroups": false
}
```

### デフォルトの挙動を維持したい場合
特に設定を変更しなければ、これまで通りClaudeが開いたエディタグループはロックされたままになります。

```json
{
  "claudeCode.lockEditorGroups": true
}
```

## 注意点
- 設定名は `claudeCode.lockEditorGroups` です。VSCodeの設定UIまたは `settings.json` から変更できます。
- ロックを無効にすると、Claudeが新しいファイルを開いた際に既存のタブが意図せず置き換わってしまう可能性がある点に注意してください。
