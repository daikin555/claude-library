## 原文（日本語訳）
[Claude Code on the web] 個人アカウントでのクラウドセッションがGitHubアクセスを拒否された際のClaudeの案内を修正。管理者向け設定ページへのリンクではなく、claude.ai/connect-githubへリンクするようになった。

## 原文（英語）
[Claude Code on the web] Fixed Claude's guidance when a cloud session on a personal account is denied GitHub access: it now links to claude.ai/connect-github instead of an admin settings page

## 概要
個人アカウントでClaude Code on the webのクラウドセッションを使用している際、GitHubへのアクセスが拒否されるとClaudeがエラーガイダンスを表示します。これまではこのガイダンスが組織向けの管理者設定ページへのリンクを案内しており、個人アカウントのユーザーにとっては操作できない・意味のないリンクになっていました。今回の修正で、個人アカウントのユーザーには正しく `claude.ai/connect-github` へのリンクが案内されるようになり、自分自身でGitHub連携を設定できるようになりました。

## 基本的な使い方
個人アカウントでクラウドセッションを開始し、GitHubリポジトリへのアクセスが必要な操作を行った際にアクセスが拒否されると、案内メッセージに従って `claude.ai/connect-github` にアクセスし、GitHub連携を設定します。

```
1. クラウドセッションでGitHub操作を実行
2. アクセス拒否メッセージが表示される
3. 案内された claude.ai/connect-github リンクをクリック
4. GitHubアカウントを連携
```

## 実践例

### 個人アカウントで初めてクラウドセッションを使う場合
GitHub連携が未設定の状態でリポジトリ操作を伴うタスクを実行すると、拒否メッセージとともに `claude.ai/connect-github` へのリンクが表示されるため、そのまま連携設定に進めます。

```
エラー例:
"GitHubへのアクセスが許可されていません。
 claude.ai/connect-github で連携を設定してください。"
```

### 修正前に管理者ページへ誤誘導されていた場合
修正前は個人アカウントのユーザーが管理者向け設定ページへ案内されてしまい、権限がなく設定を完了できないという行き詰まりが発生していました。修正後は個人アカウント向けの正しい案内に変わります。

## 注意点
- 組織（Enterprise/Team）アカウントの場合は、引き続き管理者による設定が必要なケースがあります。
- GitHub連携の設定にはGitHubアカウントへのログインが必要です。
