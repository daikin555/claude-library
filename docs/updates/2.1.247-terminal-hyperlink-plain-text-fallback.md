## 原文（日本語訳）

レンダリングされたMarkdown内のターミナルハイパーリンクの挙動が変更されました。ネットワークパスやオートマウンターのパスを指しているリンク、制御文字を含むリンク、あるいは不可視文字で始まるリンクは、クリック可能なハイパーリンクではなく、プレーンテキストとして表示されるようになりました。

## 原文（英語）

Changed terminal hyperlinks in rendered markdown: link targets that point at a network or automounter path, contain a control character, or lead with an invisible character now render as plain text

## 概要

Claude CodeはMarkdown内のリンクをターミナルのクリック可能なハイパーリンクとして表示しますが、リンク先の文字列を悪用してユーザーを誤誘導したり、意図しない挙動を引き起こしたりするリスクが指摘されていました。今回の変更により、`\\\\server\\share` のようなネットワーク/オートマウンターパス、制御文字を含むリンク、不可視文字で先頭を偽装したリンクは、クリック可能なリンクとしてレンダリングされず、素のテキストとしてそのまま表示されるようになりました。見た目やクリック時の挙動に関するリスクを軽減するセキュリティ向けの改善です。

## 基本的な使い方

ユーザー側で何かを設定する必要はありません。Claudeが出力したMarkdownに通常のHTTP(S)リンクなどが含まれる場合は、これまでと同様にクリック可能なハイパーリンクとして表示されます。

```markdown
詳細は [公式ドキュメント](https://code.claude.com/docs/en) を参照してください
```

一方、次のような疑わしいリンク先は、リンクとしてではなくプレーンテキストとして表示されます。

```markdown
[共有フォルダ](\\suspicious-server\share)
```

## 実践例

### 社内ネットワークパスを含むドキュメントを扱う場合

Claudeが生成・引用するドキュメントに `\\server\share` のようなネットワークパスが含まれていても、誤ってクリック可能なリンクとして表示されず、テキストとして安全に表示されます。

### 制御文字を使った表示偽装への対策

リンクのテキストと実際の遷移先を制御文字や不可視文字でずらして、ユーザーに誤ったURLをクリックさせるような手法に対して、該当リンクをプレーンテキスト化することで見た目の偽装によるリスクを減らします。

### 信頼できないMCPサーバーやツール出力を扱う場合

外部ツールやMCPサーバーからの出力にリンクが含まれる場合でも、危険なパターンに合致するリンクは自動的にプレーンテキスト化されるため、意図しないクリックによるリスクが下がります。

## 注意点

- 通常のHTTP(S)リンクなど安全なリンクの表示・クリック挙動には影響しません
- この判定はリンク先の文字列パターン（ネットワークパス、制御文字、不可視文字の先頭付与）に基づくものであり、すべての悪意あるリンクを網羅的に検出するものではありません
- ターミナルのハイパーリンク機能自体（OSC 8）に対応していない端末では、元々プレーンテキスト表示になるため影響はありません
