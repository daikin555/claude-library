## 原文（日本語訳）

フルスクリーンモードでコピーした際に、`/login` のOAuth URLなどのモーダルテキストの文字が欠落する問題を修正しました。

## 原文（英語）

Fixed modal text such as the `/login` OAuth URL losing characters when copied in fullscreen

## 概要

Claude Codeをフルスクリーンモードで使用している際、`/login` コマンド実行時に表示されるOAuth認証URLなどのモーダル内テキストをコピーすると、一部の文字が欠落してしまう不具合がありました。今回の修正により、フルスクリーン表示中でもモーダル内のテキストを正確にコピーできるようになりました。

## 基本的な使い方

`/login` を実行すると認証用のURLがモーダルに表示されます。このURLをターミナルからコピー＆ペーストしてブラウザで開く、という通常の操作が、フルスクリーンモードでも文字欠落なく行えるようになりました。

```
$ claude
> /login
```

表示されたOAuth URLをマウスで選択してコピーし、ブラウザのアドレスバーに貼り付けます。

## 実践例

### フルスクリーンモードでログインURLをコピーする

```
$ claude
> /login
# モーダルにOAuth URLが表示される
# 表示されたURL全体を選択してコピー
# ブラウザに貼り付けて認証を完了
```

修正前は末尾や途中の文字が欠落し、URLが不正な形式になってしまい、認証に失敗するケースがありました。修正後はURL全体が正確にコピーされ、そのまま認証ページへアクセスできます。

### その他のモーダル表示テキストのコピー

`/login` のURL以外にも、フルスクリーンモードで表示される各種モーダル（設定確認ダイアログなど）のテキストコピー全般で、同様の文字欠落リスクが解消されています。

## 注意点

- この修正はフルスクリーンレンダラーを使用している場合に関係する不具合です
- 通常モード（非フルスクリーン）では元々問題は発生していませんでした
- 認証URLのコピーがうまくいかない場合は、Claude Codeを最新バージョンに更新してください
