## 原文（日本語訳）
トランスクリプトが自分自身のメッセージ内の番号付きリストを振り直していた問題を修正（「3. 2. 1.」と入力すると「3. 4. 5.」と表示されていた）。番号や「N)」形式のマーカーは、入力した通りに表示されるようになりました。

## 原文（英語）
Fixed the transcript renumbering ordered lists in your own messages (typing "3. 2. 1." displayed "3. 4. 5."); numbers and "N)" markers now show as typed

## 概要
Claude Codeのトランスクリプト（会話履歴）表示は、Markdownの番号付きリストを解釈する際にリストの規則に従って番号を自動的に振り直していました。そのため、ユーザーが意図的に「3. 2. 1.」のような降順や非連続の番号を入力しても、「3. 4. 5.」のように表示が変わってしまう不具合がありました。今回の修正により、ユーザーが入力した番号やマーカー（「N)」形式を含む）がそのまま表示されるようになりました。

## 基本的な使い方
特別な操作は不要です。通常通りチャット入力欄にメッセージを入力するだけで、番号付きリストの表記がそのまま保持されます。

```
3. 最初に確認する項目
2. 次に確認する項目
1. 最後に確認する項目
```

## 実践例

### 修正前の挙動
以下のように独自の順序で番号を振ったメッセージを送信すると、表示上は連番に自動修正されてしまっていました。

```
入力: 3. 2. 1.
表示: 3. 4. 5.  （意図しない振り直し）
```

### 修正後の挙動
入力した番号・マーカーがそのまま表示されるようになりました。

```
入力: 3. 2. 1.
表示: 3. 2. 1.  （入力通り）
```

「N)」形式のマーカーを使った場合も同様に、入力通りの表記が維持されます。

```
1) 項目A
3) 項目B
2) 項目C
```

## 注意点
- この修正はトランスクリプト（自分が送信したメッセージ）の表示に関するものであり、Claudeが生成する応答のMarkdownレンダリング全般を変更するものではありません。
- 番号付きリストの意味的な順序を厳密に扱いたい場合は、依然として自然な連番で記述することが推奨されます。
