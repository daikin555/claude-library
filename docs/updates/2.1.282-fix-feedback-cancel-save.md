## 原文（日本語訳）

Bedrock、Vertex、その他のサードパーティプロバイダで、保存中にキャンセルしても `/feedback`、`/bug`、`/share` がレポートファイルを保存してしまっていた不具合を修正しました。

## 原文（英語）

Fixed /feedback, /bug and /share on Bedrock, Vertex and other third-party providers still saving the report file after you cancelled during the save

## 概要

`/feedback`、`/bug`、`/share` の各コマンドは、レポート内容をファイルとして保存する処理を行いますが、Amazon BedrockやGoogle Vertex AIなどサードパーティプロバイダ経由で利用している場合、保存処理の最中にキャンセルしても、実際にはレポートファイルが保存されてしまう不具合がありました。今回の修正で、キャンセル操作が正しく保存処理を中断するようになりました。

## 基本的な使い方

```
/feedback
/bug
/share
```

保存中にキャンセルした場合、意図通りファイルは保存されなくなります。

## 実践例

### 機密情報を含むセッションでのキャンセル操作の信頼性向上

`/bug` や `/share` でレポートを作成中に、機密情報が含まれていることに気づいてキャンセルした場合でも、意図せずレポートファイルがディスクに残ってしまう心配が減ります。

### Bedrock/Vertex環境での安全な利用

企業のセキュリティポリシー上、意図しないファイル保存を避けたいBedrockやVertex AI経由の利用環境でも、キャンセル操作が確実に機能するようになります。

## 注意点

- 直接Anthropic APIを利用している場合はこの不具合の影響を受けていませんでした。サードパーティプロバイダ特有の問題です
- 過去にこの不具合の影響で意図せず保存されたレポートファイルが残っている場合は、該当ファイルを手動で確認・削除することを検討してください
