# [クラウドセッション] セルフホスト環境の削除ダイアログとエラーを改善

## 原文（日本語に翻訳）

- [Cloud sessions] セルフホスト環境の削除で、ダイアログとエラーメッセージが、削除を妨げているものと影響範囲を示すようになった

## 原文（英語）

- [Cloud sessions] Improved deleting a self-hosted environment so the dialog and error messages say what blocks the delete and what it will affect

## 概要

セルフホスト環境の削除時に、何が削除を妨げているか、削除でどこに影響が出るかが分かるようになりました。

## 基本的な使い方

管理ページで環境の削除を実行すると、確認ダイアログで影響範囲が示されます。

## 実践例

### 環境の整理

削除できない場合も、原因を解消する手がかりが得られます。

## 注意点

- 削除前に影響範囲の表示を確認してください。
