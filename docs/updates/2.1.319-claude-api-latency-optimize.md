## 原文（日本語訳）
`/claude-api latency-optimize` を追加：Claude APIコードで利用者が待たされる箇所を見つけ、評価（eval）に対してより高速な設定を試します。

## 原文（英語）
Added `/claude-api latency-optimize` to find where your Claude API code makes people wait and try faster settings against your eval

## 概要
`/claude-api` スキルのサブコマンドで、アプリ内のClaude API呼び出しのうち遅延の原因になっている箇所を特定し、より速い設定を既存のevalで検証しながら試せます。

## 基本的な使い方
```
/claude-api latency-optimize
```

## 実践例

### チャットUIの初回応答を速くする
ストリーミングの有無、モデル選択、出力長など、体感待ち時間に効く箇所を洗い出せます。

### 品質を保ったまま設定を変える
evalに対して試すため、速度改善で品質が落ちていないか確認できます。

## 注意点
- 改善の検証にはeval（評価セット）が用意されていると効果的です。
- 変更案は自分のワークロードで必ず確認してください。
