# Program Status Protocol (OSC 7501) 対応

## 原文（日本語に翻訳）

Program Status Protocol (OSC 7501) に対応しました。このプロトコルを実装したターミナルは、Claude Code が作業中か、あなたの入力待ちか、完了したかを表示できます。

## 原文（英語）

Added Program Status Protocol (OSC 7501) support: terminals that implement it can show whether Claude Code is working, waiting on you, or done

## 概要

Claude Code が OSC 7501 のエスケープシーケンスで現在の状態をターミナルへ通知するようになりました。対応ターミナルでは、タブやウィンドウ上で「作業中」「入力待ち」「完了」を確認できます。

## 基本的な使い方

特別な設定は不要です。OSC 7501 を実装したターミナルで `claude` を起動すると、状態がターミナル側に伝わります。

```bash
claude
```

## 実践例

### 複数タブでの並行作業

複数のタブで Claude Code を動かしている場合、タブの表示から入力待ちのセッションを見つけて素早く対応できます。

### 長時間タスクの完了確認

別の作業をしながら、ターミナルの状態表示で完了を把握できます。

## 注意点

- 表示の可否や見た目はターミナル側の実装に依存します。
- 未対応のターミナルでは従来どおりの表示のままです。
