# MCPサーバーからのスキル提供（ベータ）

## 原文（日本語に翻訳）

MCPサーバーからスキルを追加できるようになりました（ベータ）。`/` メニューでは `server:skill` の形式で表示され、それ以外のスキルは従来の名前のままです。

## 原文（英語）

Added skills from MCP servers (beta). They show as `server:skill` in the `/` menu; other skills keep their names

## 概要

Claude Code v2.1.332 では、MCPサーバーがスキルを配布できるようになりました（ベータ）。チームで共有するワークフローを、ファイルを配らずにMCPサーバー経由で提供できます。サーバー由来のスキルは名前が `サーバー名:スキル名` となるため、既存スキルと衝突しません。

## 基本的な使い方

MCPサーバーを接続した状態で、プロンプト欄に `/` を入力するとメニューにスキルが表示されます。

```text
/
  review                 （通常のスキル）
  my-server:deploy-check （MCPサーバー由来のスキル）
```

## 実践例

### 社内ツールのMCPサーバーでワークフローを配布する

```bash
claude mcp add --transport http my-server https://mcp.example.com/mcp
claude
> /my-server:deploy-check
```

### 名前の衝突を避ける

プロジェクト内の `deploy-check` スキルとMCPサーバー由来の `my-server:deploy-check` は別物として扱われます。

## 注意点

- ベータ機能のため、挙動や表示は今後変わる可能性があります。
- 信頼できるMCPサーバーのみを接続してください。サーバーが提供するスキルはClaudeへの指示になります。
