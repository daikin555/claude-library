## 原文（日本語訳）

[クラウドセッション] クラウド環境の作成に失敗した際、エラーが開いているダイアログの外のトーストにのみ表示されていた問題を修正。ダイアログ内に表示されます

## 原文（英語）

[Cloud sessions] Fixed a failed cloud environment creation showing its error only as a toast outside the open dialog; it now appears inside the dialog

## 概要

エラーが入力中のダイアログ内で確認できます。

## 基本的な使い方

環境作成に失敗したらダイアログ内のエラーを読み、設定を直して再試行します。

## 実践例

### 設定ミスの修正

エラーを見ながら、ダイアログ上で設定を修正できます。

## 注意点

- エラーの内容は状況により異なります。
