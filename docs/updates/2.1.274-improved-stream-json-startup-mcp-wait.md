## 原文（日本語訳）
`--input-format stream-json`セッションの起動を改善：最初のターンでは、接続中でツール検索が遅延しているMCPサーバーのツールを最大2秒待つことがなくなった。これらのツールは後のターンで利用可能になる。

## 原文（英語）
Improved startup in `--input-format stream-json` sessions: the first turn no longer waits up to 2s for still-connecting MCP servers whose tools tool search defers; they arrive on a later turn

## 概要
`--input-format stream-json`はClaude Codeを他のプログラムと連携させるためのストリーミング入力形式です。これまでは、このモードでセッションを開始する際、まだ接続処理中でツール一覧の取得が遅延しているMCPサーバーがあると、最初のターンの応答が最大2秒待たされることがありました。今回の改善により、そうしたMCPサーバーのツールは最初のターンを待たずに後続のターンで利用可能になり、起動直後のレスポンスが速くなりました。

## 基本的な使い方
```bash
# stream-json形式で標準入力からセッションを開始する例
echo '{"type":"user","message":{"role":"user","content":"こんにちは"}}' | \
  claude --input-format stream-json --output-format stream-json
```

## 実践例

### 外部プログラムからClaude Codeをストリーミング連携させる場合
自作のオーケストレーションツールやCIパイプラインから`stream-json`形式でClaude Codeを起動し、複数のMCPサーバーを設定している場合、以前は起動直後の最初の応答が接続の遅いMCPサーバーによって最大2秒遅延することがありました。改善後は最初のターンがブロックされず、MCPサーバーの接続が完了次第、後のターンでそのツールが使えるようになります。

```bash
# 複数のMCPサーバーを設定した状態でstream-jsonセッションを開始
claude mcp add slow-server -- npx some-slow-mcp-server
claude --input-format stream-json --output-format stream-json
```

### レイテンシに敏感なリアルタイム連携
チャットボットやリアルタイムアシスタントのバックエンドとしてClaude Codeをstream-json経由で利用する場合、この改善により初回応答までの待ち時間が短縮され、ユーザー体験が向上します。

## 注意点
- 接続に時間がかかるMCPサーバーのツールは、最初のターンではまだ利用できない可能性があります。必要な場合は後続のターンで利用可能になることを踏まえてフローを設計してください。
- 通常のインタラクティブモード（`--input-format stream-json`を使わない場合）には直接関係しない改善です。
