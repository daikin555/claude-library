## 原文（日本語訳）

[Remote Control] アーカイブを解除したRemote Controlセッションが、コンピュータが再接続するまで「作業中」と表示される問題を修正。idleと表示されます

## 原文（英語）

[Remote Control] Fixed an unarchived Remote Control session showing as working until a computer reconnected; it now shows as idle

## 概要

状態表示が実態に合うようになりました。

## 基本的な使い方

アーカイブ解除後、再接続前はidleと表示されます。

## 実践例

### セッション状態の把握

作業中と誤認して待つ必要がなくなります。

## 注意点

- 実際の作業再開にはコンピュータの再接続が必要です。
