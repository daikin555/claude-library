# CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS で無人リトライの待機時間を制限

## 原文（日本語に翻訳）

無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が 429 や 529 エラーを待つ最大時間を制限する `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` を追加しました。

## 原文（英語）

Added `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` to limit how long unattended retry mode (`CLAUDE_CODE_RETRY_WATCHDOG`) waits out 429 and 529 errors

## 概要

CI や夜間バッチなどの無人実行で、レート制限（429）や過負荷（529）エラーを待ち続けて終わらない事態を避けるため、待機の上限をミリ秒で指定できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_RETRY_WATCHDOG=1
export CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS=600000  # 最大10分
claude -p "依存関係を更新してテストを通して"
```

## 実践例

### CI ジョブのタイムアウトと揃える

ジョブ全体の制限時間より短い値を設定し、リトライ待機でジョブ枠を使い切らないようにします。

### 夜間バッチの上限設定

```bash
export CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS=1800000  # 30分
```

## 注意点

- 値の単位はミリ秒です。
- `CLAUDE_CODE_RETRY_WATCHDOG` を有効にしている場合に意味を持ちます。
