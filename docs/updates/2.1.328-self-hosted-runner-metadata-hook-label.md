# Self-hosted runner: --metadata と --hook-label で spawn-runner フックにラベルを渡す

## 原文（日本語に翻訳）

`claude --environment` に `--metadata key=value` を追加し、`spawn-runner` フック向けにセッションへラベルを付けられるようにしました。また `claude self-hosted-runner orchestrator` に `--hook-label` を追加し、選んだセッションラベルを `spawn-runner` フックに渡せます。

## 原文（英語）

Self-hosted runner: Added `--hook-label` to `claude self-hosted-runner orchestrator`, to hand chosen session labels to the `spawn-runner` hook
Self-hosted runner: Added `--metadata key=value` to `claude --environment`, to label a session for the `spawn-runner` hook

## 概要

セッションに任意のメタデータを付け、runner を起動する `spawn-runner` フックで参照できるようになりました。ラベルに応じて起動先やリソースを振り分ける運用に使えます。

## 基本的な使い方

```bash
claude --environment <env> --metadata team=platform
claude self-hosted-runner orchestrator --hook-label team
```

## 実践例

### チーム別に runner を振り分ける

\`team=platform\` のようなラベルをフックで受け取り、専用ホストで runner を起動します。

## 注意点

- 例のコマンド引数は説明用です。実際の構文は `--help` で確認してください
- 同バージョンでは `--correlation-id` が `spawn-runner` フックに届かない問題も修正されています
