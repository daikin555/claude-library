## 原文（日本語訳）

ローカル（stdio）MCPサーバー接続が、Bedrock・Vertex・Foundryを含むすべてのインストールで、デフォルトでプロトコルバージョン2026-07-28をネゴシエートするよう変更した。`MCP_PROTOCOL_NEGOTIATION=legacy` でオプトアウトできる。

## 原文（英語）

Changed local (stdio) MCP server connections to negotiate protocol version 2026-07-28 by default on every install, including Bedrock, Vertex and Foundry; `MCP_PROTOCOL_NEGOTIATION=legacy` opts out

## 概要

ローカルMCPサーバーとの接続で、新しいプロトコルバージョンが標準で使われるようになりました。互換性の問題がある場合は環境変数で従来方式に戻せます。

## 基本的な使い方

```bash
export MCP_PROTOCOL_NEGOTIATION=legacy
claude
```

## 実践例

### 古いMCPサーバーで接続に問題がある場合

新プロトコルのチェックを無視するstdioサーバーでは、接続が遅くなることがあります。その場合は `legacy` を指定してください。

## 注意点

- 同リリースでは、新しいチェックを無視するstdioサーバーが1回遅い接続になった後、7日間記憶され、待機なしで従来方式で接続されるようになりました。
- Bedrock・Vertex・Foundryでも同様に適用されます。
