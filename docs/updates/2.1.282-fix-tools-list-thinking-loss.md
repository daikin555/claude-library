## 原文（日本語訳）

会話の途中で提示されていた組み込みツールを除外した `--tools` リストを指定して再起動した場合に、継続・再開した会話の以前のextended thinkingが失われていた不具合を修正しました。

## 原文（英語）

Fixed continued or resumed conversations losing earlier extended thinking when relaunched with a `--tools` list that leaves out a built-in tool offered earlier in the conversation

## 概要

`--tools` オプションで利用可能なツールを制限してClaude Codeを起動する際、以前の会話で使われていた組み込みツール（Bash、Read、Editなど）がそのリストから漏れていると、`--continue` や `--resume` で会話を再開したときにそれ以前のextended thinkingが破棄されてしまう不具合がありました。今回の修正により、ツールリストの構成が変わっても過去の思考内容が保持されるようになりました。

## 基本的な使い方

```bash
claude --resume --tools Read,Grep,Glob
```

以前の会話でBashやEditなどが使われていても、上記のように限定したツールリストで再開してextended thinkingが失われないようになりました。

## 実践例

### 読み取り専用モードでの安全な再開

コードを変更せずにレビューだけしたい場面で、`--tools Read,Grep,Glob` のように書き込み系ツールを外して会話を再開しても、以前の検討内容（推論過程）を踏まえた応答が得られます。

### ツール権限を段階的に絞り込む運用

最初は広いツール権限で調査を行い、後続のフェーズでは必要なツールだけに絞って再開するといった運用でも、思考の連続性が失われません。

## 注意点

- `--tools` で明示的にツールを絞り込んでいない通常の再開フローには影響しません
- extended thinkingを有効にしていない場合はこの不具合の影響を受けません
