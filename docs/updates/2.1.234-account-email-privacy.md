## 原文（日本語訳）

Claudeは、ユーザーのアカウントメールアドレスを本人確認のためだけに使用し、ユーザーが明示的に依頼しない限り、無関係なサービスへ送信しないよう指示されるようになりました。

## 原文（英語）

Claude is now told to use your account email only to identify you, and not to send it to unrelated services unless you ask

## 概要

Claude Codeはユーザーのアカウント情報の一部としてメールアドレスを扱う場面があります（例えばコミットの作者情報の推定や、ユーザー本人を識別する目的など）。今回の更新は、Claude自身に対して「メールアドレスは本人識別のためだけに使い、ユーザーが明示的に依頼していない限り、外部の無関係なサービスへ送信しない」という指示を明確化したものです。これはコードや動作の変更というより、Claudeの振る舞いに関するガードレールの強化にあたります。

## 基本的な使い方

ユーザー側で特別な操作は不要です。Claudeが外部サービス連携や通知処理などを行う際、アカウントメールアドレスを不必要に第三者サービスへ渡さないよう、内部的な振る舞いが調整されています。

```bash
claude

> このバグをSlackのチームに通知して

# Claudeはメールアドレスをむやみに送信せず、
# 明示的に必要な場合や依頼された場合のみ使用する
```

## 実践例

### 外部連携ツールを使う際の安心材料になる

Webhookやサードパーティ連携ツールを呼び出すタスクをClaudeに依頼したときに、意図せずアカウントメールアドレスが無関係な送信先に含まれるリスクが減ります。

```bash
claude

> このエラーレポートを外部の監視サービスAPIに送信して

# Claudeはエラーレポートの内容は送信するが、
# 依頼されていないアカウントメールアドレスは含めない
```

### 明示的にメールアドレスの利用を依頼する

必要な場合はユーザー自身が明示的に依頼すれば、これまで通りメールアドレスを使った処理も可能です。

```bash
claude

> 私のアカウントのメールアドレスを使って、この通知メールの宛先を設定して
```

このように明示的な指示があれば、Claudeはメールアドレスを目的の処理に使用します。

## 注意点

- これはコード上の機能追加というより、Claudeへのシステム指示（振る舞いのガードレール）の強化です
- 「本人識別」目的（例えばユーザーが誰であるかを確認する用途）では引き続きメールアドレスが使われる場合があります
- ユーザーが明示的に依頼すれば、外部サービスへの送信を含めメールアドレスを使った処理は可能です
- 完全に情報漏洩を防ぐ仕組みではなく、あくまでClaudeの振る舞いに対するガイドラインの強化である点に留意してください
