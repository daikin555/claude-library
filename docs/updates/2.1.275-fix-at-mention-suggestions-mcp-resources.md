## 原文（日本語に翻訳）

カスタムの `fileSuggestion` コマンドを使用している場合、または `@.`/`@./` と入力した場合に、@メンションのファイル候補がMCPリソースの下に埋もれてしまっていた問題を修正

## 原文（英語）

Fixed @-mention file suggestions being buried below MCP resources when using a custom `fileSuggestion` command or typing `@.`/`@./`

## 概要

Claude Codeでは `@` を入力するとファイルやMCPリソースの候補一覧が表示されます。カスタムの `fileSuggestion` コマンドを設定している場合や、`@.` や `@./` のように入力した場合に、本来優先的に表示されるべきファイル候補がMCPリソースの候補の下に埋もれてしまい、見つけにくくなる不具合がありました。今回の修正でファイル候補の表示順が改善されています。

## 基本的な使い方

```
@./src/
```

と入力すると、カレントディレクトリ配下のファイル候補が表示されます。カスタムの `fileSuggestion` コマンドを設定している場合も同様です。

```json
{
  "fileSuggestion": "my-custom-file-finder.sh"
}
```

## 実践例

### `@./` でファイルを素早く探す

プロジェクト内のファイルを素早く参照したい場合、`@./` と入力して候補一覧からファイルを選びます。

```
@./comp
# → components/ 配下のファイル候補が
#   MCPリソースより上に見やすく表示されるようになった
```

### カスタムfileSuggestionコマンドを使っている場合

独自のファイル検索スクリプトを `fileSuggestion` に設定しているプロジェクトでも、その候補が優先的に表示されます。

```json
// .claude/settings.json
{
  "fileSuggestion": "./scripts/find-files.sh"
}
```

```
@
# → カスタムスクリプトによるファイル候補が
#   MCPリソース候補の下に埋もれず表示される
```

## 注意点

- MCPサーバーを複数接続している環境ほど、この不具合の影響を受けやすい状況でした
- 標準の `@` メンション（カスタムコマンドなし）でも改善の対象となる場合があります
- MCPリソース自体の候補表示機能は変わらず利用できます
