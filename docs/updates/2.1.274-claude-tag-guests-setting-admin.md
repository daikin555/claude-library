## 原文（日本語訳）
[Claude Tag] Claude Tag管理設定の「チャンネルを追加」および「ワークスペースを追加」フォームに「ゲスト（Guests）」設定を追加しました。オーナーはInherit（継承）、Allow（許可）、Channel only（チャンネルのみ）、Restrict（制限）を事前に選択できるようになります。

## 原文（英語）
[Claude Tag] Added a Guests setting to the Add channel and Add workspace forms in Claude Tag admin settings, so owners can pick Inherit, Allow, Channel only or Restrict up front

## 概要
Claude Tag（SlackでのClaude連携機能）の管理設定において、これまでゲストユーザー（Slackのゲストアカウント）に対するClaudeの利用可否を、チャンネルやワークスペースを追加した後で別途設定する必要がありました。今回の変更により、「チャンネルを追加」「ワークスペースを追加」フォームの時点で、ゲストに対する扱いを Inherit（親設定を継承）・Allow（許可）・Channel only（そのチャンネル内のみ許可）・Restrict（制限）の4種類から事前に選択できるようになりました。管理者はセットアップの最初の段階でアクセス制御方針を決定でき、運用の手間が減ります。

## 基本的な使い方
1. Slack管理者としてClaude Tagの管理設定を開く
2. 「Add channel（チャンネルを追加）」または「Add workspace（ワークスペースを追加）」フォームを開く
3. 「Guests」設定で Inherit / Allow / Channel only / Restrict のいずれかを選択して保存する

## 実践例

### 社内ワークスペース全体でゲストアクセスを制限する場合
外部パートナーをゲストとして招待しているワークスペースでは、「ワークスペースを追加」時にGuests設定を「Restrict」に設定することで、ゲストユーザーがClaude Tagを利用できないようにできます。

### 特定チャンネルのみゲストの利用を許可する場合
特定のプロジェクトチャンネルでのみゲストにもClaudeとのやり取りを許可したい場合は、そのチャンネルの追加時にGuests設定を「Channel only」に設定します。これにより、そのチャンネル内に限定してゲストがClaude Tagを利用できるようになります。

### 上位設定を引き継ぐ場合
特に個別の制御が不要な場合は「Inherit」を選択することで、ワークスペース全体やSlack組織側の既存設定をそのまま引き継げます。

## 注意点
- 既存のチャンネル・ワークスペースに対する設定変更は、追加時だけでなく後から管理設定画面で変更することも可能です。
- 「Restrict」を選択すると、そのスコープ内のゲストは一切Claude Tagを利用できなくなるため、必要なゲストユーザーがいないか事前に確認することをお勧めします。
