## 原文（日本語訳）

インストール済みプラグインに対して `claude plugin update` を省略名（bare name）で実行すると失敗する不具合を修正しました。これまでは完全修飾名（fully-qualified name）でしか動作しませんでした。

## 原文（英語）

Fixed `claude plugin update` failing for an installed plugin given its bare name (only the fully-qualified name worked)

## 概要

プラグインは通常 `<marketplace>/<plugin-name>` のような完全修飾名で管理されますが、インストール済みのプラグインであれば単純な名前（省略名）だけでも操作できるのが自然な挙動です。これまでの `claude plugin update` コマンドは、この省略名を渡すと対象プラグインを見つけられずに失敗し、完全修飾名を毎回指定しなければなりませんでした。今回の修正により、インストール済みプラグインであれば省略名を指定するだけで更新できるようになりました。

## 基本的な使い方

インストール済みのプラグイン名だけを指定して更新できます。

```bash
claude plugin update my-plugin
```

修正前はこのコマンドが失敗し、以下のように完全修飾名を指定する必要がありました。

```bash
claude plugin update my-marketplace/my-plugin
```

修正後はどちらの指定方法でも正しく更新が実行されます。

## 実践例

### 日常的なプラグイン更新作業の簡略化

複数のプラグインを管理している場合、いちいちマーケットプレイス名を確認しなくても、覚えている省略名だけで更新コマンドを実行できます。

```bash
claude plugin update code-review-helper
```

### スクリプトやCI内での自動更新

自動化スクリプトでプラグインの更新を行う際、プラグイン名のみを保持しておけば十分になり、完全修飾名を別途管理する手間が減ります。

### `claude plugin list` からの名前の使い回し

`claude plugin list` で表示されたプラグイン名をそのまま `plugin update` にコピーして使えるようになり、表記の不一致によるエラーを避けられます。

## 注意点

- 同名のプラグインが複数のマーケットプレイスからインストールされている場合は、あいまいさを解消するために完全修飾名を指定する必要があります
- この修正は `claude plugin update` に関するものであり、`claude plugin install` など他のサブコマンドの名前解決仕様は別途確認してください
