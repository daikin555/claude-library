## 原文（日本語訳）
Manage Pluginsの有効化トグルとMCPサーバーダイアログの行が、キーボードから操作できなかった不具合が修正されました。

## 原文（英語）
[VSCode] Fixed the Manage Plugins enable toggle and MCP servers dialog rows being unreachable from the keyboard

## 概要
VSCode拡張機能のManage Pluginsパネルにあるプラグイン有効化トグルと、MCPサーバー管理ダイアログの各行は、これまでマウス操作でしかアクセスできず、キーボードだけでの操作（Tabキーでのフォーカス移動など）ができない状態でした。今回の修正により、これらのUI要素もキーボードから正しくフォーカス・操作できるようになり、アクセシビリティが向上しました。

## 基本的な使い方
キーボードのTabキーなどでManage PluginsパネルやMCPサーバーダイアログ内を移動し、Enter/Spaceキーでトグルや行を操作できます。

## 実践例

### プラグインの有効/無効をキーボードだけで切り替えたい場合
Manage Pluginsパネルを開き、Tabキーで有効化トグルにフォーカスを移動し、Space/Enterキーで有効・無効を切り替えられるようになりました。

### MCPサーバーダイアログをキーボードだけで操作したい場合
MCPサーバー管理ダイアログを開き、Tabキーで各サーバーの行にフォーカスを移動し、キーボード操作だけで設定を確認・変更できるようになりました。

## 注意点
- マウスを使わないユーザーやスクリーンリーダーを利用するユーザーにとって特に重要な修正です。
- この修正はUI操作性に関するものであり、プラグインやMCPサーバー自体の機能には影響しません。
