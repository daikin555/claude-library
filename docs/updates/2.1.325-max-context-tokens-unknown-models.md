# CLAUDE_CODE_MAX_CONTEXT_TOKENS が未知のclaude-モデルIDにも適用

## 原文（日本語に翻訳）

`CLAUDE_CODE_MAX_CONTEXT_TOKENS` が、ゲートウェイの `claude-sonnet-latest` のような、`claude-` で始まる未認識のモデルIDのコンテキストウィンドウにも適用されるようになりました。

## 原文（英語）

Changed `CLAUDE_CODE_MAX_CONTEXT_TOKENS` to also set the context window of unrecognized model IDs that start with `claude-`, such as a gateway's `claude-sonnet-latest`

## 概要

サードパーティのゲートウェイが独自のエイリアス（例: `claude-sonnet-latest`）を使う場合、Claude Code がコンテキスト長を判断できないことがありました。この環境変数で明示的に指定できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_MAX_CONTEXT_TOKENS=200000
claude --model claude-sonnet-latest
```

## 実践例

### ゲートウェイ経由で利用する

```bash
export ANTHROPIC_BASE_URL=https://gateway.example.com
export CLAUDE_CODE_MAX_CONTEXT_TOKENS=200000
claude
```

### 1Mコンテキストのモデルを使う

実際のモデルの上限に合わせた値を設定してください。

## 注意点

- 実際のモデルの上限より大きい値を設定すると、コンテキスト長エラーの原因になります。
- 対象は `claude-` で始まる未認識のモデルIDです。
