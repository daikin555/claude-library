## 原文（日本語に翻訳）

Code Review にレビューレベルを追加しました。オーナーは組織全体に対して Quick、Standard（デフォルト）、Deep のいずれかを選択でき、リポジトリごとに個別のレベルを設定することもできます。

## 原文（英語）

[Code Review] Added review levels to Code Review: Owners choose Quick, Standard (the default), or Deep for the organization, and can give individual repositories their own level

## 概要

Code Review の深さを 3 段階から選べるようになりました。組織のデフォルトを決めたうえで、重要なリポジトリだけ Deep にするといった使い分けが可能です。

あわせて、GitHub 組織内のすべてのリポジトリ（後から追加されたものを含む）を個別選択なしでレビュー対象にするオプションが追加されました。また、管理者が Code Review を有効にした直後の 1〜2 分以内に開かれた PR が黙ってスキップされる問題も修正され、再試行されるようになりました。

## 基本的な使い方

Code Review の管理者設定画面で、組織のレベルと、必要に応じてリポジトリごとのレベルを選択します。

## 実践例

### 重要なリポジトリだけ Deep にする

組織は Standard のままにし、決済や認証を扱うリポジトリのみ Deep に設定します。

### 小規模リポジトリは Quick

軽量なレビューで十分なリポジトリは Quick にして、レビュー時間を抑えます。

## 注意点

- 設定できるのはオーナーです。
- 各レベルの具体的な動作や料金への影響は公式ドキュメントを確認してください。
