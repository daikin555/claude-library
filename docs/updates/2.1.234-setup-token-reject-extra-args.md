## 原文（日本語訳）

`claude setup-token` が、想定外の余分な引数を黙って無視するのではなく、拒否するようになりました

## 原文（英語）

`claude setup-token` now rejects unexpected extra arguments instead of silently ignoring them

## 概要

`claude setup-token` コマンドは、CI/CDやAPIキーを持たない環境向けの長期利用可能なトークンを発行するためのコマンドです。これまでは、コマンドにタイプミスや誤った引数を渡しても、そのまま黙って無視されて実行されてしまい、意図しない挙動に気づきにくいという問題がありました。今回の修正により、想定外の余分な引数が渡されるとエラーとして拒否されるようになり、コマンドの誤用にすぐ気づけるようになりました。

## 基本的な使い方

`claude setup-token` は引数なしで実行するコマンドです。

```bash
claude setup-token
```

修正前は、たとえば以下のように誤ったオプションやタイプミスを含む引数を渡しても、そのオプションは無視されてトークン発行が実行されてしまいました。

```bash
# 修正前: 誤字があっても黙って無視され、トークンが発行されてしまう
claude setup-token --verbos
```

修正後は、このような余分な引数を渡すとエラーになり、コマンドが失敗します。

## 実践例

### CIスクリプトでのタイプミス検知

```bash
# CIパイプライン内のスクリプト
claude setup-token --output token.txt
```

`--output` のようなサポートされていないオプションを誤って渡した場合、以前は静かに無視されていましたが、修正後はエラーになりCIがすぐに失敗を検知できます。

### 正しい使い方の確認

```bash
claude setup-token
```

引数を渡さずに実行するのが正しい使い方です。ヘルプで利用可能なオプションを確認できます。

```bash
claude setup-token --help
```

## 注意点

- 既存の正しい呼び出し方（引数なしでの実行）には影響ありません
- CIスクリプトなどで誤った引数を渡していた場合、今後はコマンドがエラーで停止するようになります。該当箇所がないか事前に確認しておくと安全です
- このコマンドで発行されるトークンは長期利用向けのため、取り扱いには注意してください
