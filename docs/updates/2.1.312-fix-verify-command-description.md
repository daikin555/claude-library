## 原文（日本語訳）

`/verify` が `/help` と `/` コマンドメニューで、Claude向けの長い説明を表示していた問題を修正し、短い説明が表示されるようになりました

## 原文（英語）

Fixed `/verify` showing a long description meant for Claude in `/help` and the `/` command menu instead of a short one

## 概要

`/verify` の説明がユーザー向けの短いものに改善されました。

## 基本的な使い方

```
/help
```

または `/` を入力してメニューで確認できます。

## 実践例

### コマンドの探索

メニューが見やすくなり、目的のコマンドを選びやすくなります。

## 注意点

- コマンドの動作自体は変わりません。
