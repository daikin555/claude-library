## 原文（日本語訳）

スラッシュコマンドのドロップダウンが開いている状態で高速にタイプしたりキーを押し続けたりすると、フルスクリーンセッションが「Claude Code exited after an unrecoverable interface error」というメッセージとともに終了することがある不具合を修正しました。

## 原文（英語）

Fixed fullscreen sessions sometimes exiting with "Claude Code exited after an unrecoverable interface error" when typing fast or holding a key with the slash-command dropdown open

## 概要

Claude Codeのフルスクリーンモードでは、`/` を入力するとスラッシュコマンドの候補一覧がドロップダウン表示されます。このドロップダウンが表示された状態で高速にタイピングしたり、キーを押しっぱなしにしたりすると、インターフェースの内部状態が壊れ、「Claude Code exited after an unrecoverable interface error」というエラーでセッションごと終了してしまう不具合がありました。今回の修正により、こうした高速入力があってもフルスクリーンセッションがクラッシュしなくなりました。

## 基本的な使い方

特別な操作は不要です。スラッシュコマンドの入力は通常どおり行えます。

```
/rew
```

のようにスラッシュコマンド名を素早く入力しても、ドロップダウンが安定して表示されるようになりました。

## 実践例

### スラッシュコマンド名を素早く入力する

`/review` のような長めのコマンド名をタイプ音がするほどの速さで入力すると、修正前はドロップダウンの状態更新が追いつかずクラッシュすることがありました。修正後はどれだけ速く入力してもクラッシュしません。

```
/revi<Enterを押す前に高速で追加入力>
```

### キーを押し続けた場合

矢印キーなどを押しっぱなしにしてドロップダウンの候補を素早くスクロールする操作でも、同様にクラッシュが発生することがありましたが、この修正で解消されています。

## 注意点

- この不具合はフルスクリーンモード固有のものです。通常モードでは影響を受けていませんでした。
- 万一同様のエラーに遭遇した場合は、Claude Codeを最新バージョンに更新してください。
