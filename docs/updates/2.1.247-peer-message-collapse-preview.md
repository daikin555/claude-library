## 原文（日本語訳）

クロスセッションのピアメッセージが、デフォルトで `Message from @<送信者>: <先頭行>` という1行のプレビュー表示に折りたたまれるように変更されました。Ctrl+O を押すと本文全体が展開表示されます。

## 原文（英語）

Changed cross-session peer messages to collapse by default to a one-line `Message from @<sender>: <first line>` preview; Ctrl+O expands the full body

## 概要

`SendMessage` を使って他のClaude Codeセッションからメッセージを受け取ると、以前は本文全体がそのまま画面に表示されていました。長いメッセージが届くと画面が占有されてしまう問題がありましたが、今回の変更でデフォルトでは送信者名と本文の先頭行だけを1行で表示するようになりました。詳細を確認したい場合は Ctrl+O で全文を展開できます。

## 基本的な使い方

他のセッションからメッセージが届くと、まず次のような1行のプレビューが表示されます。

```
Message from @worker-1: リファクタリングが完了しました。テスト結果は...
```

全文を読みたい場合は、そのまま Ctrl+O を押します。

```
Ctrl+O
```

すると、メッセージ本文全体が展開されて表示されます。

## 実践例

### 複数セッションを並行運用しているときの画面を見やすく保つ

複数のworktreeやターミナルでセッションを並行させ、`SendMessage` で頻繁に連絡を取り合っている場合、以前は長い本文がその都度画面いっぱいに表示され、直前の作業内容が流れてしまうことがありました。1行プレビューにより、画面を占有せずに通知の有無だけをさっと確認できます。

### 重要なメッセージだけ詳細を確認する

複数のピアから届く通知のうち、先頭行を見て重要だと判断したメッセージだけ Ctrl+O で展開して全文を確認する、という選択的な読み方ができます。

### バックグラウンドで進行中のタスクの完了通知を受け取る

`notify_when_idle` などと組み合わせて他セッションから完了通知を受け取る場合も、まず1行で概要を把握し、必要なら展開して詳細な結果やログを確認する、という流れがスムーズになります。

## 注意点

- この折りたたみ表示はデフォルトの挙動であり、無効化する設定は明記されていません
- 展開操作は Ctrl+O のキー操作で行います
- プレビューに表示されるのは本文の先頭行のみのため、重要な情報が2行目以降にある場合は展開して確認する必要があります
