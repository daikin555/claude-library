## 原文（日本語に翻訳）

`/plugin install plugin@marketplace` が、インストール前にマーケットプレイスを自動的に更新するようになりました。これにより、新しく公開されたプラグインも手動でマーケットプレイスを更新することなくインストールできるようになりました

## 原文（英語）

`/plugin install plugin@marketplace` now refreshes the marketplace first, so newly published plugins install without a manual marketplace update

## 概要

`/plugin install plugin@marketplace` コマンドは、指定したマーケットプレイスから特定のプラグインをインストールするコマンドです。これまでは、マーケットプレイスに新しく公開されたばかりのプラグインをインストールしようとすると、ローカルにキャッシュされたマーケットプレイス情報が古いため「プラグインが見つからない」といったエラーになり、事前に手動で `/plugin marketplace update` を実行する必要がありました。v2.1.232では、`/plugin install` の実行時にマーケットプレイス情報が自動的に更新されるようになり、この手動更新の手間が不要になりました。

## 基本的な使い方

```bash
# マーケットプレイスから直接プラグインをインストール
> /plugin install my-plugin@my-marketplace

# 修正前: マーケットプレイスに新しく公開されたプラグインは
#         事前に /plugin marketplace update を実行しないと見つからないことがあった
# 修正後: インストールコマンド実行時に自動でマーケットプレイス情報が更新される
```

## 実践例

### 公開されたばかりのプラグインをすぐにインストールする

```bash
# 開発者がマーケットプレイスに新しいプラグインを公開した直後
> /plugin install brand-new-plugin@team-marketplace

# 修正前: 手動更新が必要だった
> /plugin marketplace update team-marketplace
> /plugin install brand-new-plugin@team-marketplace

# 修正後: 1コマンドで完結
> /plugin install brand-new-plugin@team-marketplace
```

### チーム内で共有しているマーケットプレイスの最新プラグインを取得する

```bash
# チームの共有マーケットプレイスに新バージョンや新プラグインが追加された場合
> /plugin install team-tool@shared-marketplace

# 常に最新のマーケットプレイス情報を参照した上でインストールが行われる
```

### CI環境でのプラグインセットアップを簡略化する

```bash
# CIスクリプト内でプラグインをインストールする際、
# 事前のmarketplace update手順を省略できる
claude --print "/plugin install ci-helper@org-marketplace"
```

## 注意点

- Claude Code v2.1.232で導入された改善です。
- インストールのたびにマーケットプレイス情報の更新処理が挟まるため、ネットワーク環境によっては若干の遅延が発生する可能性があります。
- 手動でのマーケットプレイス更新（`/plugin marketplace update`）は引き続き利用可能で、プラグインをインストールせずに一覧を最新化したい場合などに使えます。
