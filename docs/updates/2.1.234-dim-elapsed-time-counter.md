## 原文（日本語訳）

実行中のツールヘッダーにある経過時間カウンターを暗く（ディム）表示するようにし、太字のカウント表示と視覚的に競合しないようにしました

## 原文（英語）

Dimmed the elapsed-time counter on the running tool header so it no longer competes with the bold counts

## 概要

ツールが実行されている間、ヘッダー部分には経過時間のカウンターと、処理件数などの太字のカウント表示が並んで表示されます。これまでは経過時間カウンターも通常の明るさで表示されていたため、本来注目すべき太字のカウント情報と視覚的に競合し、どちらが重要な情報か分かりにくいことがありました。今回の変更で経過時間カウンターの表示が薄く（ディム）なり、太字のカウントの方が自然と目立つようになりました。

## 基本的な使い方

特別な操作は不要です。ツールが実行されている間、ヘッダーに表示される経過時間（例: `12s` など）が、周囲のテキストより薄い色で表示されるようになります。

```bash
claude
# 何らかのツール（Bash、Read、Grepなど）を実行中
```

## 実践例

### 大量のファイル処理中の視認性向上

大量のファイルを処理するツール呼び出しでは、ヘッダーに「処理件数（太字）」と「経過時間（ディム表示）」が並びます。経過時間が薄く表示されることで、進捗を示す件数の方に自然と目が行くようになります。

### 長時間実行されるBashコマンドの監視

長時間かかるビルドやテストの実行中、経過時間の表示がディムになったことで、コマンドの出力そのものやエラーの有無に注意が向きやすくなります。

## 注意点

- あくまで表示上の変更で、経過時間カウンターの機能自体（更新頻度や計測内容）に変更はありません
- ターミナルのカラーテーマによってはディム表示の見え方が異なる場合があります
