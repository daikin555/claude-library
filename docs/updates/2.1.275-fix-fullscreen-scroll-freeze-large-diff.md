## 原文（日本語に翻訳）

大きなファイル差分を通り過ぎて上にスクロールした際に、フルスクリーンモードが数秒間フリーズまたは画面が真っ白になっていた問題を修正

## 原文（英語）

Fixed fullscreen mode freezing or blanking for several seconds when scrolling up past a large file diff

## 概要

Claude Codeのフルスクリーンモードでは、会話履歴やツール出力（ファイル差分など）を遡ってスクロールできます。これまで、大きなファイル差分（大量の変更行を含む差分）を通過して上方向にスクロールすると、レンダリング処理の負荷により画面が数秒間フリーズしたり、一時的に真っ白になってしまう不具合がありました。今回の修正により、大きな差分を含む履歴をスクロールしてもスムーズに表示されるようになりました。

## 基本的な使い方

フルスクリーンモードは通常通り起動し、スクロール操作を行います。

```bash
claude
# フルスクリーンモードに入り、上スクロールで履歴を遡る
```

## 実践例

### 修正前の挙動

大規模なリファクタリングなどで生成された大きなファイル差分を含むターンを上スクロールで通過すると、画面が数秒間反応しなくなったり、真っ白になってしまい、作業が中断されていました。

### 修正後の挙動

大きなファイル差分を含む履歴でも、スクロール時のフリーズや画面のブランクが発生せず、スムーズに閲覧できるようになりました。

```bash
# 大きな差分（数百〜数千行の変更）を含むセッションでも
# フルスクリーンモードでのスクロールが快適になった
claude
```

## 注意点

- この修正はフルスクリーンモードにおける表示パフォーマンスの改善です
- 非常に大きな差分（極端に大きいファイルなど）では、依然として表示に多少時間がかかる場合があります
- 通常モード（非フルスクリーン）では元々この問題は発生していなかった可能性があります
