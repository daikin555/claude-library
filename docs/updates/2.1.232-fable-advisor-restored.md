## 原文（日本語に翻訳）

Fable 5アクセス権を持つ組織向けに、`/advisor` のアドバイザーとしてFable 5が再び提供されるようになりました。利用クレジット（usage-credits）に関する同意は `/model fable` を通じて設定します。

## 原文（英語）

Fable 5 is offered as an advisor in `/advisor` again for organizations with Fable access, with usage-credits consent set up through `/model fable`

## 概要

`/advisor` は、メインで使用しているモデルよりも高い能力を持つモデルに、重要な判断だけを助言してもらう機能です。今回のアップデートで、Fable 5アクセス権を持つ組織であれば、Fable 5を再び `/advisor` のアドバイザーとして選択できるようになりました。Fable 5をアドバイザーとして使うには利用クレジット（usage-credits）に関する同意が必要で、この同意設定は `/model fable` コマンドを通じて行います。

## 基本的な使い方

```bash
# Fable 5の利用同意（usage-credits）を設定
> /model fable

# アドバイザーとしてFable 5を設定
> /advisor fable
```

`/advisor` にモデルエイリアスを指定すると、そのモデルがメインモデルの判断をレビューするアドバイザーとして機能するようになります。

## 実践例

### 通常はSonnetで作業し、重要な判断だけFable 5に相談する

コストを抑えつつ、難しい設計判断や大きな変更の前だけ強いモデルの意見を求めたい場合。

```bash
# メインモデルはSonnetのまま
> /model sonnet

# Fable 5の利用同意を設定
> /model fable

# アドバイザーとしてFable 5を登録
> /advisor fable

# 通常のタスク実行はSonnetが担当し、
# 重要な意思決定ポイントでFable 5に助言を求める
```

### 組織でFable 5アクセスが有効かどうかを確認する

```bash
> /advisor
# Fable 5アクセスがある組織では選択肢にfableが表示される
# アクセスがない組織では表示されない
```

## 注意点

- Claude Code v2.1.232で導入された変更です。Fable 5がアドバイザーとして利用できるのは、組織がFable 5アクセスを持っている場合に限られます。
- Fable 5をアドバイザーとして使うには、`/model fable` を通じた利用クレジット（usage-credits）に関する同意設定が必要です。
- アドバイザーには、メインモデル以上の能力を持つモデルを設定する必要があります。メインモデルより能力が低いモデルをアドバイザーに設定しても、トリガーされず無視されます。
- advisorツールはAnthropic APIでのみ提供されるサーバー実行型のツールであり、Amazon Bedrock、Claude Platform on AWS、Google CloudのAgent Platform、Microsoft Foundryでは利用できません。
