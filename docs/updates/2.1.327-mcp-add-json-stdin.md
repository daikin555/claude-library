# claude mcp add-json で標準入力から JSON を読み込めるように

## 原文（日本語に翻訳）

`claude mcp add-json <name> -` を追加しました。サーバーの JSON を標準入力から読み込むため、トークンをコマンドラインに残さずに済みます。Claude Code セッション内では利用できません。

## 原文（英語）

Added `claude mcp add-json <name> -` to read the server's JSON from stdin, so tokens can stay off the command line; not available inside a Claude Code session

## 概要

`claude mcp add-json` の JSON 引数に `-` を指定すると、サーバー設定の JSON を標準入力から読み込めます。API トークンを含む設定をコマンドライン引数に書かずに済むため、シェル履歴やプロセス一覧（`ps`）への漏洩を防げます。

## 基本的な使い方

```bash
echo '{"type":"http","url":"https://mcp.example.com","headers":{"Authorization":"Bearer xxx"}}' \
  | claude mcp add-json my-server -
```

## 実践例

### シークレットマネージャーから設定を渡す

```bash
# 環境変数から JSON を組み立てて渡す（履歴にトークンが残らない）
jq -n --arg t "$MY_TOKEN" \
  '{type:"http",url:"https://mcp.example.com",headers:{Authorization:("Bearer "+$t)}}' \
  | claude mcp add-json my-server -
```

### ファイルからリダイレクトする

```bash
claude mcp add-json my-server - < ./server.json
```

## 注意点

- Claude Code セッション内（`!` コマンド等）では利用できません。通常のシェルから実行してください。
- 引数に直接 JSON を書く従来の形式も引き続き使えます。
- `echo` でトークンを直接書くとシェル履歴に残るため、変数や `jq` 経由での受け渡しを推奨します。
