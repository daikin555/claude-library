# CLAUDE_CODE_FULL_SIGN_IN_LINK でサインインリンク全体を出力

## 原文（日本語に翻訳）

短いリンクでエラーが表示される場合や、スクリプトがリンクから値を読み取る場合のために、サインインリンク全体を出力する `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` を追加しました。

## 原文（英語）

Added `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` to print the full sign-in link, if the short one shows an error or a script reads values from it

## 概要

環境変数 `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` を設定すると、短縮されたリンクではなく完全なサインインリンクが表示されます。同リリースでは通常のサインインリンク自体もかなり短くなっています。

## 基本的な使い方

```bash
CLAUDE_CODE_FULL_SIGN_IN_LINK=1 claude auth login
```

## 実践例

### 短いリンクでエラーが出る場合

上記のように環境変数を付けてサインインをやり直します。

### スクリプトでリンクの値を解析する

```bash
CLAUDE_CODE_FULL_SIGN_IN_LINK=1 claude auth login 2>&1 | tee login.log
```

完全なリンクにはクエリ値が含まれるため、スクリプトから読み取れます。

## 注意点

- 完全なリンクには認証に関わる値が含まれるため、ログの取り扱いに注意してください
- 通常は設定不要です
