# CLAUDE_CODE_DISABLE_1M_CONTEXT 設定時の opus[1m] モデル未検出エラーを修正

## 原文（日本語に翻訳）

- `CLAUDE_CODE_DISABLE_1M_CONTEXT` が設定されていて、モデルが `opus[1m]` のように `[1m]` サフィックス付きのエイリアスである場合に、モデル未検出エラーでリクエストが失敗する問題を修正

## 原文（英語）

- Fixed requests failing with a model-not-found error when `CLAUDE_CODE_DISABLE_1M_CONTEXT` is set and the model is an alias with the `[1m]` suffix, such as `opus[1m]`

## 概要

1M コンテキストを無効化する環境変数を設定しつつ、`opus[1m]` のようなエイリアスを指定していると、モデルが見つからないエラーになっていました。この組み合わせでも正常にリクエストできるようになります。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
claude --model 'opus[1m]'
```

## 実践例

### 共有設定で1Mを無効化している環境

組織の管理設定で `CLAUDE_CODE_DISABLE_1M_CONTEXT` を設定していても、個人の設定やスクリプトに残る `[1m]` エイリアスでエラーになりません。

## 注意点

- 1M コンテキストが無効なため、実際のコンテキストウィンドウは拡張されません。
