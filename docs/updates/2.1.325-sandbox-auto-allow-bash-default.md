# サンドボックス内Bashコマンドが通常の権限フローに従うよう変更

## 原文（日本語に翻訳）

サンドボックス内のBashコマンドは、デフォルトで通常の権限フローに従うよう変更されました。プロンプトなしで実行し続けるには `sandbox.autoAllowBashIfSandboxed: true` を設定してください。また、サンドボックスを有効にする管理設定については、最上位の管理ソースで `sandbox.autoAllowBashIfSandboxed: true` を設定すると、プロンプトなしで実行できます。

## 原文（英語）

Changed sandboxed Bash commands to follow the normal permission flow by default; set `sandbox.autoAllowBashIfSandboxed: true` to keep running them without prompts
Changed managed settings that turn the sandbox on: to keep commands running without prompts, set `sandbox.autoAllowBashIfSandboxed: true` in your highest-ranking managed source

## 概要

これまでサンドボックス有効時のBashコマンドは自動で許可されていましたが、v2.1.325からは他のコマンドと同じ通常の権限フロー（許可ルール・確認プロンプト）に従います。従来の挙動を維持したい場合は明示的に設定を追加します。

## 基本的な使い方

`.claude/settings.json` に次のように記述します。

```json
{
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true
  }
}
```

## 実践例

### 個人開発で従来どおりプロンプトなしで使う

ローカルのプロジェクト設定（`.claude/settings.local.json`）に `autoAllowBashIfSandboxed: true` を入れておけば、サンドボックス内のコマンドは確認なしで実行されます。

### 組織で管理設定を配布している場合

管理設定でサンドボックスを有効にしている組織は、確認なしの実行を維持するために、最上位の管理ソースへ同じキーを追加します。

```json
{
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true
  }
}
```

### 慎重に運用したい場合

何も設定しなければ、サンドボックス内でも通常の権限ルールが適用されます。`permissions.allow` で必要なコマンドだけを許可する運用に向いています。

## 注意点

- アップデート後、これまで確認なしで動いていたコマンドが確認を求めるようになる可能性があります。
- 自動化（`claude -p` やCIなど）で待ちが発生しないか、アップデート後に確認してください。
