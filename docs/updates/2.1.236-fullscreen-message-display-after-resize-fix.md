## 原文（日本語訳）

フルスクリーンモードで、ターミナルをリサイズした直後に新しく送信したメッセージが次の更新まで表示されないことがある問題を修正しました。

## 原文（英語）

Fixed fullscreen mode sometimes not showing a newly sent message until the next update after the terminal was resized

## 概要

Claude Codeのフルスクリーン表示モードでは、ターミナルウィンドウのサイズ変更に合わせて画面レイアウトが再計算されます。これまでは、ターミナルをリサイズした直後にメッセージを送信すると、そのメッセージがすぐには画面に反映されず、次に何らかの更新（Claudeからの応答やさらなる操作など）が発生するまで表示されないことがありました。今回の修正により、リサイズ直後に送信したメッセージも即座に画面へ反映されるようになりました。

## 基本的な使い方

特別な操作は不要です。フルスクリーンモードでターミナルの幅や高さを変更した直後にメッセージを送信しても、これまでのように表示が遅れることなく、すぐに画面に反映されます。

```bash
claude
# フルスクリーンモード中にターミナルウィンドウをリサイズ
# → 直後にメッセージを送信
# 修正前: 送信したメッセージが画面に表示されず、次の更新まで見えないことがあった
# 修正後: リサイズ直後の送信でも即座に画面へ反映される
```

## 実践例

### ウィンドウを分割・調整しながら作業する場合

tmuxやウィンドウマネージャーでペインの大きさを調整した直後にClaude Codeへ指示を送ると、以前は送ったメッセージが一時的に画面から消えたように見え、本当に送信されたのか不安になることがありました。修正後はリサイズ直後でもメッセージがすぐに表示されるため、送信結果を即座に確認できます。

### 外部モニターの接続・切断でウィンドウサイズが変わる場合

ノートPCを外部モニターに接続・切断した際にターミナルのウィンドウサイズが自動的に変わることがありますが、そうしたタイミングで送信したメッセージも取りこぼされることなく画面に表示されるようになりました。

## 注意点

- 表示が遅れて見えるだけで、メッセージの送信自体は修正前から正常に行われていました。今回の修正はあくまで画面描画のタイミングに関するものです。
- インラインモード（フルスクリーンではない通常表示）ではこの問題は該当しません。
