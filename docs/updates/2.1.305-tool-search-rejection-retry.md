# ToolSearchを拒否するエンドポイントでのリクエスト失敗を修正

## 原文（日本語に翻訳）

- エンドポイントやゲートウェイがツール検索を拒否する場合、またはゲートウェイでToolSearchが無効／`--tools` から除外されている場合に、Vertex・Bedrockなどのプロバイダーで全リクエストが失敗する問題を修正（2.1.304のリグレッション）。Claude Codeはツール検索なしで再試行するようになった

## 原文（英語）

- Fixed every request failing on Vertex, Bedrock and other providers when the endpoint or a gateway rejects tool search, and behind gateways with ToolSearch disallowed or left out of `--tools` (a 2.1.304 regression): Claude Code now retries without it

## 概要

2.1.304で発生したリグレッションの修正です。ツール検索を受け付けないエンドポイントやゲートウェイ経由だと全リクエストが失敗していましたが、2.1.305ではツール検索なしで自動的に再試行します。

## 基本的な使い方

設定変更は不要です。2.1.304で該当症状が出ていた場合は、2.1.305へアップデートしてください。

```bash
claude update
claude --version
```

## 実践例

### 社内LLMゲートウェイ経由でBedrock／Vertexを利用している場合

ゲートウェイがツール検索関連のパラメータを拒否しても、再試行により通常どおり動作します。

### `--tools` でツールを絞っている場合

ToolSearchを含めない構成でも失敗しなくなります。

## 注意点

- ツール検索なしで再試行されるため、ツール数が多い環境ではコンテキスト消費が増える可能性があります。
