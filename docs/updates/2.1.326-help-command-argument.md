# /help <command> でコマンド別の使い方を表示

## 原文（日本語に翻訳）

`/clear --help` などの組み込みコマンドが、使い方を表示せずにアイドル状態のプロンプトで実行されてしまう問題を修正しました。あわせて `/help <command>` を追加しました。

## 原文（英語）

Fixed `/clear --help` and other built-in commands running at an idle prompt instead of showing usage; added `/help <command>`

## 概要

v2.1.326 で `/help <command>` が追加されました。また、`/clear --help` のように組み込みコマンドへ `--help` を付けたとき、コマンドが実行されてしまう不具合が修正され、使い方が表示されるようになりました。

## 基本的な使い方

```text
/help clear
/clear --help
```

## 実践例

### 破壊的なコマンドを安全に確認する

`/clear` のように会話を消すコマンドは、以前は `--help` を付けても実行される場合がありました。修正後は使い方が表示されます。

```text
/clear --help
```

### 知らないコマンドのオプションを調べる

```text
/help compact
/help resume
```

## 注意点

- 表示内容はコマンドごとに異なります。
- 以前のバージョンでは `--help` で実行される可能性があるため、古い環境では注意してください。
