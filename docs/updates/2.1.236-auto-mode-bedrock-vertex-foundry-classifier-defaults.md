## 原文（日本語訳）

Bedrock、Vertex AI、Foundry上で、およびテレメトリが無効な場合のauto modeを改善しました: classifierが、重大度スコアによる分類を含め、Claude APIと同じデフォルト設定を使うようになりました。

## 原文（英語）

Improved auto mode on Bedrock, Vertex AI, and Foundry, and when telemetry is disabled: the classifier now uses the same defaults as on the Claude API, including severity-scored classification

## 概要

auto modeは、ツール呼び出しの前に別モデルである「classifier」が内容を審査し、破壊的・不可逆的・環境外への操作をブロックする仕組みで、Anthropic API、Amazon Bedrock、Google CloudのAgent Platform（旧Vertex AI）、Microsoft Foundryなど、すべての提供経路で利用できます。しかしこれまでは、BedrockやVertex AI、Foundry経由で利用している場合や、テレメトリを無効化している環境では、classifierがClaude API利用時とは異なるデフォルト設定で動作しており、各アクションを内部の重大度スケールでスコアリングする「重大度スコアによる分類（severity-scored classification）」が適用されないなど、審査の挙動に差異がありました。今回の改善で、こうした環境でもClaude API利用時とまったく同じデフォルト設定・同じ分類ロジックがclassifierに適用されるようになり、利用経路やテレメトリ設定にかかわらず一貫したauto modeの安全性が得られるようになりました。

## 基本的な使い方

ユーザー側で追加の設定は不要です。Bedrock・Vertex AI・Foundry経由でClaude Codeを利用している場合や、組織のポリシーでテレメトリを無効化している場合でも、auto modeを有効にすれば、Claude API利用時と同じ基準でclassifierが動作します。

```bash
# 例: Bedrock経由でauto modeを使う場合も特別な設定は不要
export CLAUDE_CODE_USE_BEDROCK=1
claude
```

効果的な範囲を確認したい場合は、`claude auto-mode config` で実際に適用されているルールを確認できます。

```bash
claude auto-mode config
```

## 実践例

### Bedrock/Vertex AI/Foundryで社内利用しているチーム

エンタープライズの調達方針でAmazon Bedrock、Google CloudのAgent Platform、Microsoft Foundry経由でClaude Codeを配布しているチームでは、これまでclassifierの挙動がClaude API利用時と微妙に異なるケースがありました。今回の改善で、どの経路から使っていてもauto modeの安全基準が統一され、社内向けドキュメントやトレーニングを提供元ごとに書き分ける必要がなくなります。

### テレメトリを無効化しているセキュリティ重視の環境

コンプライアンス上の理由でテレメトリ送信を無効にしている組織でも、これまではclassifierのデフォルトが弱まる可能性がありましたが、今回の変更でテレメトリの有無にかかわらずClaude APIと同じ重大度スコアリングを含むデフォルト設定が使われるようになり、安全性を犠牲にせずテレメトリを無効化できます。

## 注意点

- `autoMode` 設定（`environment` / `allow` / `soft_deny` / `hard_deny`）でカスタマイズしている内容には影響せず、あくまでベースとなるデフォルトが統一されます
- auto modeの利用可否自体は、モデルやプランなど別の要件にも依存するため、詳細は公式ドキュメントの要件を確認してください
- `claude auto-mode defaults` でclassifierの組み込みルールを、`claude auto-mode config` で実際に適用される設定を確認できます
