# 最初の Bash コマンドを高速化（シェル起動ファイルの先行実行）

## 原文（日本語に翻訳）

セッション最初の Bash コマンドの速度を改善しました。承認前、拒否される場合でも、シェルの起動ファイルが先に実行されることがあります。無効にするには `CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1` を設定してください。

## 原文（英語）

Improved the speed of a session's first Bash command: shell start-up files may now run before it's approved, even if it's refused; set `CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1` to turn this off

## 概要

`.bashrc` や `.zshrc` などの読み込みを、コマンドの承認を待たずに先行して始めることで、最初の Bash 実行までの待ち時間を短縮します。ただし、コマンドが拒否されても起動ファイルは実行される点に注意が必要です。

## 基本的な使い方

無効化する場合:

```bash
export CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1
claude
```

## 実践例

### 起動ファイルに副作用がある環境

起動ファイルがネットワークアクセスや認証プロンプトなどを行う場合は、承認前に実行されたくないため無効化します。

```json
// .claude/settings.json
{
  "env": { "CLAUDE_CODE_DISABLE_SHELL_HEAD_START": "1" }
}
```

### 通常の開発環境

副作用の無い起動ファイルであれば、既定のままで体感速度が向上します。

## 注意点

- 起動ファイルは「ユーザー自身が書いたもの」で、Claude が生成したコマンドではありません。
- 厳格な承認フローを求める環境では無効化を検討してください。
