## 原文（日本語訳）

バックグラウンドコマンドの時間制限を、無人セッション（`-p`、Agent SDK、CI、クラウド）にのみ適用するよう変更した。ターミナル、デスクトップアプリ、VS Codeのセッションには制限がない。

## 原文（英語）

Changed the background command time limit to apply only in unattended sessions (`-p`, Agent SDK, CI, cloud); terminal, desktop app and VS Code sessions have no limit

## 概要

バックグラウンドで実行するコマンドの時間制限が、人が見ていない無人セッションだけに適用されます。対話的に使う環境では、開発サーバーやビルド監視などを時間切れなしで動かし続けられます。

## 基本的な使い方

対話セッションでは設定不要です。Claudeにバックグラウンドで実行させるだけです。

```text
開発サーバーをバックグラウンドで起動して
```

## 実践例

### 長時間のdevサーバーを動かし続ける

ターミナルやVS Codeでは、`npm run dev` のようなプロセスが時間制限で止められなくなります。

### CIでの暴走防止

`claude -p` やCIでは制限が残るため、終了しないバックグラウンドコマンドが残り続けません。

## 注意点

- 無人セッションでは従来どおり制限があるため、長時間処理は設計に注意してください。
- 対話セッションで起動したプロセスは自分で停止する必要があります。
