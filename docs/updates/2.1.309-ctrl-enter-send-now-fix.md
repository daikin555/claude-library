## 原文（日本語に翻訳）

ctrl+enter（今すぐ送信）が、応答開始前に押した場合のみメッセージをキューに入れるだけだった問題と、プロンプトのフック実行中に押すとフックを再起動しつつメッセージがキューに残る問題を修正しました

## 原文（英語）

Fixed ctrl+enter (send now) only queuing a message when pressed before the response had started, and restarting a prompt's hooks while leaving the message queued when pressed while those hooks were running

## 概要

ctrl+enter は、Claudeの処理中に入力したメッセージを待たせず送るためのショートカットです。応答開始前はキューに入るだけ、フック実行中はフックが再実行されるのにメッセージが残る、という不具合が修正されました。

## 基本的な使い方

```text
Claudeが処理中にメッセージを入力 → ctrl+enter で今すぐ送信
```

## 実践例

### 方向修正をすぐ伝える

長い処理の途中で「テストは書かなくていい」と追記したいとき、ctrl+enter で即座に反映できます。

### プロンプトにフックがある環境

フック実行中に押しても、メッセージがキューに残り続ける問題は起きなくなります。

## 注意点

- 通常のenterはキュー投入、ctrl+enterは即時送信という使い分けです
- キーバインドは `~/.claude/keybindings.json` で変更可能です
