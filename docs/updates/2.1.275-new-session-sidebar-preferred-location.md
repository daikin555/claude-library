## 原文（日本語訳）

[VSCode] Preferred Locationが「Sidebar」に設定されている場合、Claudeエディタタブ内で新規セッションを開始すると、常に新しいタブが開かれるのではなく、サイドバーに開くように変更しました。

## 原文（英語）

[VSCode] Changed New session in a Claude editor tab to open in the sidebar when Preferred Location is set to Sidebar, instead of always opening another tab

## 概要

Claude Codeには、パネルの表示場所を設定する「Preferred Location」という設定があります。これまで、Claudeのエディタタブ内から「New session」を実行すると、Preferred Locationの設定に関わらず常に新しいエディタタブとしてセッションが開かれていました。今回の変更により、Preferred Locationが「Sidebar」に設定されている場合は、新規セッションもその設定に従ってサイドバーに開くようになり、ユーザーの表示設定との一貫性が保たれるようになりました。

## 基本的な使い方

VS Codeの設定でPreferred Locationを「Sidebar」に設定します。

```json
// settings.json
{
  "claudeCode.preferredLocation": "sidebar"
}
```

この状態でエディタタブ内のClaudeパネルから「New session」を実行すると、サイドバーに新規セッションが開きます。

## 実践例

### サイドバー中心のワークフローで新規セッションを開始する場合

エディタ領域を広く使いたいユーザーが、Claudeパネルを常にサイドバーに表示する設定にしている場合、新規セッションもエディタタブを圧迫せずサイドバーに開くようになります。

```
設定: claudeCode.preferredLocation = "sidebar"
操作: エディタタブ内のClaudeパネルから "New session" を実行
結果: 新規セッションがサイドバーに開く（従来はエディタタブとして開いていた）
```

### 複数ファイルを並べて編集しながらClaudeを利用する場合

複数のコードファイルをエディタタブで並べて開いて作業しているユーザーにとって、新規セッションがタブを増やさずサイドバーに開くことで、エディタのタブ管理がシンプルに保たれます。

## 注意点

- Preferred Locationが「Editor（デフォルトのタブ表示）」に設定されている場合は、従来通り新しいタブとしてセッションが開きます。
- この変更はPreferred Locationの設定値に応じた挙動の一貫性を高めるためのものです。
