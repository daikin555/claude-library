# Remote Controlのspawnモード関連メッセージを改善

## 原文（日本語に翻訳）

- Remote Control: spawnモードのメッセージを改善。`w` を押すと新しいモードがフォルダに保存されると表示され、保存済みモードを使った後続の `claude remote-control` 起動では、その出所が表示される

## 原文（英語）

- Remote Control: Improved the spawn-mode messages: pressing `w` now says the new mode is saved for the folder, and a later `claude remote-control` start that uses the saved mode says where it came from

## 概要

spawnモードの保存と再利用の挙動がメッセージで分かりやすくなりました。

## 基本的な使い方

```bash
claude remote-control
```

起動後に `w` を押すと、モードがフォルダ単位で保存される旨が表示されます。

## 実践例

### プロジェクトごとのモード固定

次回以降の起動時に、保存済みモードが使われていること、およびその出所が表示されます。

## 注意点

- 保存はフォルダ単位です。別フォルダでは別のモードになる場合があります。
