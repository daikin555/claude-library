## 原文（日本語に翻訳）

`/config` に「Dialog expiry（ダイアログの有効期限）」と「Messages from your other sessions（他セッションからのメッセージ）」の行が追加されました（クロスセッションの受信メッセージに対するaccept/hold/refuseの制御）。

## 原文（英語）

Added `/config` rows for "Dialog expiry" and "Messages from your other sessions" (cross-session inbound accept/hold/refuse)

## 概要

他のClaudeセッションから `SendMessage` でメッセージが届くと、確認ダイアログが表示されます。v2.1.232では `/config` 画面に、このダイアログが応答なく放置された場合に自動的に閉じるまでの時間を設定する「Dialog expiry」と、他セッションからの受信メッセージをどう扱うか（自動で受け入れる/保留する/拒否する）を設定する「Messages from your other sessions」の項目が新たに追加されました。GUIから直感的に設定できるようになったことで、通知の煩わしさやセキュリティ上の懸念を細かく調整できます。

## 基本的な使い方

```
/config
```

`/config` を実行し、設定一覧の中から「Dialog expiry」「Messages from your other sessions」の行を選んで値を変更します。

## 実践例

### ダイアログの自動クローズ時間を調整する

```
/config
# Dialog expiry の行を選択
# 例: 5分（デフォルト）から10分に延長
```

応答するまでに時間がかかりそうな場合は、有効期限を延ばすことでダイアログが自動的に閉じてメッセージが破棄されるのを防げます。

### 他セッションからのメッセージを自動で保留(hold)にする

```
/config
# Messages from your other sessions を "hold" に設定
```

作業に集中したい間は受信メッセージを自動的に保留し、あとでまとめて確認する運用にできます。

### すべて拒否(refuse)して集中モードにする

```
/config
# Messages from your other sessions を "refuse" に設定
```

他セッションからの割り込みを完全に遮断したい場合は、拒否設定にすることで送信元にも拒否が通知されます。

## 注意点

- Claude Code v2.1.232での変更（`/config` にUIとして追加）です。
- Dialog expiryのデフォルトは5分で、`dialogExpiry` 設定として調整・無効化ができます（この設定自体はv2.1.224以降で利用可能）。
- ターミナルがアタッチされていないバックグラウンドセッションでは、ダイアログは期限を過ぎても閉じられず、アタッチ後に一定時間応答がなければ閉じられてメッセージが破棄されます。
- 権限モードが変更されると受信ルールが再適用され、保留中のメッセージが配信されたり、拒否設定になった場合はまとめて破棄・通知されたりします。
