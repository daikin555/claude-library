## 原文（日本語に翻訳）

Pro および Max プランで、非アクティブな会話を再開すると 5 時間の使用量上限のかなりの割合を消費する場合に警告を表示するようにしました。そのまま再開するか、新しい会話を始めることができます。新しい会話でも、前の会話に言及すれば Claude が参照できます。

## 原文（英語）

Added a warning on Pro and Max plans when resuming an inactive conversation would use a noticeable share of your 5-hour usage limit: resume anyway, or start a new conversation and Claude can look up the previous one if you refer to it

## 概要

長時間放置した会話を再開すると、コンテキストを再読み込みするため使用量を多く消費することがあります。Pro / Max プランでは、その消費が 5 時間の使用量上限に対して無視できない割合になる場合、再開前に警告が表示されます。

## 基本的な使い方

```bash
claude --resume
```

警告が表示されたら、次のどちらかを選びます。

- そのまま再開する
- 新しい会話を始める（前の会話に言及すれば、Claude が参照できます）

## 実践例

### 上限が近いときに大きな会話を再開しない

警告が出たら新しい会話を始め、「先日の○○の件の続き」のように前の会話に触れて依頼します。

### 使用量に余裕があるとき

十分余裕があるなら、そのまま再開して文脈を完全に引き継げます。

## 注意点

- 対象は Pro と Max プランです。
- 警告が出る具体的なしきい値は公開されていません。
