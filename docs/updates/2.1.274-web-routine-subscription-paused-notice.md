## 原文（日本語訳）
[Claude Code on the web] ルーティンの一時停止通知の文言を変更しました。サブスクリプションが一時停止している場合、これまでの「自動的に再開する」という案内ではなく、ユーザー自身でルーティンを再度オンにするよう案内するようになりました。

## 原文（英語）
[Claude Code on the web] Changed a routine's on-hold notice: when your subscription is paused it now tells you to turn the routine back on yourself instead of promising an automatic resume

## 概要
Claude Code on the webでは、サブスクリプションが一時停止（pause）状態になると、それに紐づくルーティンも実行が保留（on hold）になります。これまでの通知文言では、サブスクリプションが再開すればルーティンも自動的に再開すると案内されていましたが、実際にはこの自動再開が保証されないケースがあったため、誤解を招く表現でした。今回の変更で、サブスクリプション再開後はユーザー自身がルーティンを手動でオンに戻す必要があることが明確に案内されるようになりました。

## 基本的な使い方
1. サブスクリプションが一時停止すると、対象のルーティンに保留中（on hold）の通知が表示される
2. サブスクリプションを再開した後、ルーティン一覧から該当のルーティンを手動でオンに切り替える

## 実践例

### サブスクリプション再開後の対応
サブスクリプションの支払いが復旧してプランが再開された場合、ルーティン一覧を確認し、保留中と表示されているルーティンのトグルを手動でオンにする必要があります。自動的には再開されない点に注意してください。

### 複数ルーティンを運用している場合
複数のルーティンを設定しているユーザーは、サブスクリプション再開後にどのルーティンが保留中になっているかを一覧で確認し、必要なものだけを選んで再度有効化できます。

## 注意点
- サブスクリプションが一時停止している間、ルーティンは自動実行されません。
- サブスクリプション再開後も、ルーティンは自動的には再開されないため、忘れずに手動でオンにする必要があります。
