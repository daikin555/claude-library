## 原文（日本語訳）
Claude appsゲートウェイのサインインレート制限エラーを改善：`/login`が拒否理由を説明するようになり、ゲートウェイのログにはどの制限に達したか、どの設定を変更すべきかが記録されるようになった。

## 原文（英語）
Improved Claude apps gateway sign-in rate limit errors: `/login` now explains the refusal, and the gateway log says which limit was hit and which setting to change

## 概要
Claude appsゲートウェイには、不正利用防止のためサインイン試行に対するレート制限が設けられています。これまでは、レート制限に達してサインインが拒否されても、ユーザーには理由がよく分からないエラーしか表示されず、管理者もログからどの制限に引っかかったのかを特定しにくい状態でした。今回の改善により、`/login`のエラーメッセージが拒否理由を具体的に説明するようになり、ゲートウェイのログにも「どの制限に達したか」「どの設定を変更すればよいか」が明記されるようになりました。

## 基本的な使い方
特別な操作は不要です。レート制限によってサインインが拒否された場合、以前より分かりやすいメッセージが表示されます。

```bash
# サインインを試みる
claude /login
```

## 実践例

### ユーザーがサインインを何度も試みてレート制限に達した場合
パスワードやOTPの入力ミスなどでサインインを何度も試みてレート制限に達すると、以前は単に「拒否されました」としか表示されず、ユーザーはどれくらい待てばよいのか分かりませんでした。改善後は、`/login`のエラーメッセージに拒否理由（例：一定時間内の試行回数超過など）が明示されます。

```text
$ claude /login
エラー: サインイン試行のレート制限に達しました。しばらく待ってから再試行してください。
```

### 管理者がゲートウェイのレート制限設定を調整する場合
組織内で正当なユーザーがレート制限に頻繁に引っかかってしまう場合、管理者はゲートウェイのログを確認することで、どの制限（例：IPごとの試行回数上限など）に達しているか、どの設定項目を調整すればよいかを直接把握できるようになりました。

```bash
# ゲートウェイのログを確認する例
grep "rate limit" /var/log/claude-apps-gateway/gateway.log
```

## 注意点
- レート制限自体の閾値やポリシーが変更されたわけではなく、あくまでエラーメッセージとログの分かりやすさが改善された点に注意してください。
- 実際に制限を緩和したい場合は、ログに示された設定項目をもとにゲートウェイの管理者設定を変更する必要があります。
