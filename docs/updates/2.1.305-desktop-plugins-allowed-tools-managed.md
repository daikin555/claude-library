# Claude Desktopがパスでマウントするプラグインの allowed-tools を管理設定で無効化

## 原文（日本語に翻訳）

- 組織の管理設定で `allowManagedPermissionRulesOnly` が設定されている場合、Claude Desktopがパスでマウントするプラグインは `allowed-tools` を保持しなくなった

## 原文（英語）

- Changed plugins that Claude Desktop mounts by path to no longer keep their `allowed-tools` when your organization's managed settings set `allowManagedPermissionRulesOnly`

## 概要

管理設定で `allowManagedPermissionRulesOnly` が有効な組織では、Claude Desktopがパスでマウントするプラグインの `allowed-tools` が適用されなくなります。権限ルールを管理設定だけに限定する方針と整合します。

## 基本的な使い方

```json
{ "allowManagedPermissionRulesOnly": true }
```

## 実践例

### 組織のポリシー統制

プラグイン側の `allowed-tools` による権限拡張を防げます。

## 注意点

- 該当プラグインが必要とするツールは、管理設定の権限ルールで許可する必要があります。
