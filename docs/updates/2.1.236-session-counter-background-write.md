## 原文（日本語訳）

起動パフォーマンスを改善しました: セッションカウンタがバックグラウンドで書き込まれるようになりました。

## 原文（英語）

Improved startup performance: the session counter is now written in the background

## 概要

Claude Codeは起動時にセッション数を記録するカウンタをディスクに書き込んでいますが、これまではこの書き込み処理が起動シーケンスの一部として同期的に行われており、わずかながら起動を遅らせる要因になっていました。今回の改善により、セッションカウンタの書き込みがバックグラウンドで非同期に行われるようになり、CLIの起動が速くなりました。

## 基本的な使い方

ユーザー側で行う操作は特にありません。Claude Codeを起動するだけで、体感できる程度に起動が速くなります。

```bash
claude
```

## 実践例

### CLIを頻繁に起動・終了するワークフロー

シェルスクリプトやエイリアスなどからClaude Codeを何度も繰り返し起動するようなワークフローでは、1回あたりの起動時間短縮の積み重ねが体感速度の向上につながります。

### CIやサンドボックス環境での短命セッション

自動化パイプラインの中で短時間だけClaude Codeを起動して終了するような使い方をしている場合も、起動時のディスクI/Oが減ることで全体のスループットがわずかに改善します。

## 注意点

- カウンタの値自体や統計の内容は変わらず、書き込みのタイミングが非同期になっただけです
- 体感できる差はごくわずかですが、特に起動を繰り返すユースケースで効果が積み重なります
