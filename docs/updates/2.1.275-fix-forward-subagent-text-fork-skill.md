## 原文（日本語に翻訳）

`--forward-subagent-text` のstream-json出力およびSDK出力で、`context: fork` スキルによって生成されたサブエージェントのメッセージや、サブエージェントまたは他のforkされたスキルによって呼び出されたforkスキルのメッセージが欠落していた問題を修正

## 原文（英語）

Fixed `--forward-subagent-text` stream-json and SDK output dropping the messages of subagents spawned by a `context: fork` skill, and of forked skills invoked by a subagent or another forked skill

## 概要

`--forward-subagent-text` フラグは、stream-json出力やSDK連携時にサブエージェントのテキスト出力を転送するための機能です。これまで、`context: fork` として定義されたスキルから生成されたサブエージェントのメッセージ、およびサブエージェントや他のforkスキルから呼び出されたforkスキルのメッセージが、この転送処理から漏れてしまう不具合がありました。今回の修正により、ネストしたfork構成でもすべてのサブエージェント出力が正しく転送されるようになりました。

## 基本的な使い方

```bash
claude --output-format stream-json --forward-subagent-text -p "タスクを実行して"
```

このフラグを有効にすると、メインエージェントだけでなくサブエージェントのテキスト出力もstream-jsonイベントとして流れてきます。

## 実践例

### 修正前の挙動

`context: fork` として設定されたスキルがサブエージェントを生成した場合、そのサブエージェントのテキスト出力が `--forward-subagent-text` を指定していても stream-json 出力やSDK出力に現れず、監視ツールやログ収集パイプラインで一部のメッセージが欠落していました。

### 修正後の挙動

forkスキルから生成されたサブエージェント、およびサブエージェントや他のforkスキルから呼び出されたforkスキルのメッセージも含め、すべてのサブエージェント出力が正しく転送されるようになりました。

```bash
# forkスキルを利用するワークフローでも
# サブエージェントの出力が漏れなくstream-jsonに流れる
claude --output-format stream-json --forward-subagent-text -p "複雑な多段タスクを実行"
```

## 注意点

- この修正はCLIの `--forward-subagent-text` フラグおよびSDKの相当機能を利用している場合に影響します
- `context: fork` スキルを使わない通常のワークフローでは、これまでも問題なく動作していました
- ネストが深い（forkスキルがforkスキルを呼び出す）構成ほど、この修正の恩恵を受けやすくなります
