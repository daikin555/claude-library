## 原文（日本語に翻訳）

`/add-dir` コマンド、またはSDKの `register_repo_root` コントロールリクエストによってセッションの途中で新しい作業ディレクトリが登録された直後に発火する `DirectoryAdded` フックを追加しました。

## 原文（英語）

Added `DirectoryAdded` hook that fires after `/add-dir` or the SDK `register_repo_root` control request registers a new working directory mid-session

## 概要

Claude Codeでは、セッションの開始後でも `/add-dir` コマンドを使うことで作業対象のディレクトリを追加できます。しかし従来は、そのタイミングでフックを介した処理（追加ディレクトリのルール読み込みやログ記録など）を挟むことができませんでした。`DirectoryAdded` フックは、`/add-dir` またはAgent SDKの `register_repo_root` コントロールリクエストによって新しいディレクトリがセッションに登録された直後に発火し、そのディレクトリ情報を受け取って任意のコマンドを実行できるようにします。

## 基本的な使い方

`.claude/settings.json` の `hooks` セクションに `DirectoryAdded` イベントを追加します。

```json
{
  "hooks": {
    "DirectoryAdded": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "echo \"[DirectoryAdded] $(date): new directory registered\" >> ~/.claude/logs/directory-added.log"
          }
        ]
      }
    ]
  }
}
```

フックはイベント発火時にJSON形式のデータを標準入力（stdin）で受け取ります。ここには追加されたディレクトリの絶対パスなどが含まれるため、`jq` 等でパースしてコマンド内で利用できます。

```json
{
  "hook_event_name": "DirectoryAdded",
  "session_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "directory": "/home/user/projects/another-repo"
}
```

## 実践例

### 追加ディレクトリのCLAUDE.mdを自動的に読み込ませる

`/add-dir` で追加されたディレクトリに `CLAUDE.md` が存在する場合、その内容をそのままセッションに追加コンテキストとして流し込みます。

```json
{
  "hooks": {
    "DirectoryAdded": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "dir=$(jq -r '.directory'); if [ -f \"$dir/CLAUDE.md\" ]; then cat \"$dir/CLAUDE.md\"; fi"
          }
        ]
      }
    ]
  }
}
```

### 監査ログとして追加ディレクトリを記録する

セキュリティ監査のため、セッション中にどのディレクトリがいつ追加されたかを記録しておきます。

```json
{
  "hooks": {
    "DirectoryAdded": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "jq -c '{time: now, session: .session_id, directory: .directory}' >> ~/.claude/logs/directory-audit.jsonl"
          }
        ]
      }
    ]
  }
}
```

### 許可されていないディレクトリの追加をブロックする

社内ポリシーで許可された特定のパス配下以外のディレクトリ追加を拒否したい場合、フックが非ゼロの終了コードを返すことでブロックできます。

```json
{
  "hooks": {
    "DirectoryAdded": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "dir=$(jq -r '.directory'); case \"$dir\" in /home/user/allowed-projects/*) exit 0 ;; *) echo \"許可されていないディレクトリです: $dir\" >&2; exit 1 ;; esac"
          }
        ]
      }
    ]
  }
}
```

## 注意点

- `DirectoryAdded` は `/add-dir` コマンド実行時と、Agent SDKを利用したアプリケーションが `register_repo_root` コントロールリクエストを送信したときの両方で発火します。SDKベースの統合でも同じフック設定が有効です。
- フックはプロジェクトの `.claude/settings.json` のほか、`~/.claude/settings.json`（ユーザー設定）や `.claude/settings.local.json` にも設定できます。設定範囲に応じて使い分けてください。
- フック内のコマンドは信頼できる内容にしてください。任意のシェルコマンドが実行されるため、外部から渡される `directory` の値をそのまま危険な形でシェル展開しないよう注意が必要です。
- 他のフックイベント（`PreToolUse` や `SessionStart` など）と同様、複数のコマンドを配列で登録でき、実行順は登録順になります。
