## 原文（日本語に翻訳）

`CLAUDE_CODE_DISABLE_1M_CONTEXT` を変更し、固定リストに含まれるモデルだけでなく、ネイティブに1Mトークンウィンドウを持つすべてのClaudeモデルを、オートコンパクションによって200Kに抑えるようにした。オートコンパクションがセッションを200Kに抑えられていない場合、起動時に警告が表示されるようになった。

## 原文（英語）

Changed `CLAUDE_CODE_DISABLE_1M_CONTEXT` to hold every Claude model with a native 1M window to 200K via auto-compaction, not just a fixed list; a startup warning now appears when auto-compaction isn't holding the session to 200K

## 概要

`CLAUDE_CODE_DISABLE_1M_CONTEXT` は、コンプライアンス要件などでコンテキストウィンドウを200Kに制限したい企業環境向けの環境変数です。これまでは対象となるモデルが固定リストで管理されていたため、リストに載っていない新しい1M対応モデル（例えばSonnet 5など、ネイティブに1Mトークンウィンドウを持つモデル）ではこの変数が効かず、意図せず200Kを超えてコンテキストが伸びてしまう可能性がありました。今回の変更により、ネイティブに1Mウィンドウを持つすべてのClaudeモデルが対象になり、オートコンパクション（自動要約・圧縮）によって確実に200Kへ抑えられるようになりました。さらに、何らかの理由でオートコンパクションがセッションを200Kに抑えられていない場合には、起動時に警告が表示されるようになり、意図しないコンテキスト超過に気づきやすくなりました。

## 基本的な使い方

環境変数として設定し、Claude Codeを起動します。

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
claude
```

この設定により、1Mコンテキストウィンドウのモデルバリアントは `/model` ピッカーから除外され、対象モデルのセッションはオートコンパクションによって200Kトークン相当に抑えられます。

## 実践例

### コンプライアンス要件のある企業環境での一律制限

社内のセキュリティポリシー上、コンテキストウィンドウを200Kに統一したい場合は、全社配布のシェル初期化ファイルや管理設定でこの環境変数を有効にします。

```bash
# ~/.bashrc や /etc/profile.d 経由で配布
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

以前はこの変数が固定リストのモデルにしか効かなかったため、新しく1M対応となったモデルではポリシーが漏れる可能性がありましたが、今回の変更でモデルの種類にかかわらず一律に200Kへ抑制されます。

### 起動時警告で抑制の失敗に気づく

`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` を設定した状態でセッションを開始した際、何らかの理由でオートコンパクションが200Kにセッションを抑えられていない場合、起動時に警告メッセージが表示されます。

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
claude
# → 抑制が機能していない場合、起動時に警告が出力される
```

警告が出た場合は、`ANTHROPIC_BASE_URL` でLLMゲートウェイを経由している構成など、モデル判定に影響する設定を見直すきっかけになります。

### LLMゲートウェイ経由での動作確認

`ANTHROPIC_BASE_URL` がゲートウェイを指している構成では、Claude Codeが1M対応かどうかを直接検証できないため、`CLAUDE_CODE_DISABLE_1M_CONTEXT` の効き方に注意が必要です。設定後は実際に起動して警告が出ないかを確認するとよいでしょう。

```bash
export ANTHROPIC_BASE_URL="https://your-llm-gateway.example.com"
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
claude --debug
```

## 注意点

- この変数を設定すると、1Mコンテキストモデルのバリアントが `/model` ピッカーから見えなくなります。
- 対象は「ネイティブに1Mトークンウィンドウを持つモデル」であり、今後リリースされるモデルも自動的に対象へ含まれるようになった点が今回の変更のポイントです。
- 起動時警告はオートコンパクションが実際に200Kへ抑えられていない場合にのみ表示されます。警告が出た場合は設定やモデル構成の見直しが必要です。
