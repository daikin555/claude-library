## 原文（日本語に翻訳）

`claude ultrareview` はワークスペースの信頼が必要になりました。ターミナルでは確認を求め、それ以外では拒否します。スクリプトでは `--trust-workspace`（値は取りません。PR番号やベースブランチはその前に置きます）を渡すか、`CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1` を設定してください

## 原文（英語）

Changed `claude ultrareview` to require workspace trust: it asks on a terminal, else refuses; scripts pass `--trust-workspace`, which takes no value (put a PR number or base branch before it), or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`

## 概要

`claude ultrareview` を実行する際、対象ワークスペースを信頼するかの確認が必須になりました。対話ターミナルでは確認プロンプトが表示され、非対話環境では信頼が明示されない限り拒否されます。CIなどのスクリプトでは `--trust-workspace` フラグか環境変数で明示的に許可します。

## 基本的な使い方

```bash
# 対話ターミナル: 信頼確認が表示される
claude ultrareview

# スクリプト/CI: --trust-workspace を付ける
claude ultrareview 123 --trust-workspace
```

## 実践例

### PR番号やベースブランチと併用する

`--trust-workspace` は値を取らないフラグです。PR番号やベースブランチは**その前**に置きます。

```bash
claude ultrareview 123 --trust-workspace
claude ultrareview main --trust-workspace
```

### 信頼チェック自体を無効化する

信頼できる隔離環境に限り、環境変数でチェックを無効化できます。

```bash
export CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1
claude ultrareview 123
```

## 注意点

- `--trust-workspace` の直後に値を書かないでください（値を取りません）
- 環境変数による無効化は、コードが信頼できる環境に限定してください
- 非対話環境でフラグも環境変数もない場合は拒否されます
