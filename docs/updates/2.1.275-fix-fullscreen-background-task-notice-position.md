## 原文（日本語に翻訳）

フルスクリーンモードにおいて、バックグラウンドタスクの完了通知が、長いターンの折りたたまれたツール行の下ではなく、本来届いた場所の下に表示されてしまっていた問題を修正。各通知は開いている行を閉じるようになりました

## 原文（英語）

Fixed fullscreen mode placing background-task completion notices beneath a long turn's collapsed tool row instead of where they arrived; each notice now closes the open row

## 概要

Claude Codeのフルスクリーンモードでは、バックグラウンドで実行しているタスクが完了すると通知が表示されます。これまでは、長いターン（多数のツール呼び出しを含むターン）の折りたたまれたツール行の下に通知が表示されてしまい、実際にタスクが完了したタイミングの文脈から離れた位置に表示されるという不具合がありました。今回の修正により、通知は本来届いた場所に表示され、さらに開いたままになっているツール行を自動的に閉じるようになりました。

## 基本的な使い方

フルスクリーンモードでバックグラウンドタスクを実行すると、完了時に通知が表示されます。

```
/background
# バックグラウンドタスクを開始

# フルスクリーンモードで作業を続ける
# タスク完了時、通知が正しい位置に表示される
```

## 実践例

### 修正前の挙動

長いターン（多くのツール呼び出しが折りたたまれて表示されているターン）の最中にバックグラウンドタスクが完了すると、通知がその折りたたまれたツール行の下に表示されてしまい、実際に完了した文脈がどこにあるのか分かりにくくなっていました。

### 修正後の挙動

バックグラウンドタスクの完了通知が本来届いたタイミング・位置に正しく表示されるようになり、さらに開いたままのツール行があれば通知が自動的に閉じるようになりました。

```
# 長いツール呼び出しの実行中でも
# バックグラウンドタスクの完了通知が
# 適切な位置に表示され、視認性が向上する
```

## 注意点

- この修正はフルスクリーンモード特有の表示問題に対するものです
- 通常モード（非フルスクリーン）では影響がない場合があります
- バックグラウンドタスクを複数同時に実行している場合、通知の表示順にも注意してください
