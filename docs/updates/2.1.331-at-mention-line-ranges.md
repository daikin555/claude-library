# @file#10-12 形式の行範囲指定が正しく動作するよう修正

## 原文（日本語に翻訳）

`@file#10-12` と書いた @メンションが、指定行ではなくファイル全体を添付していた問題を修正しました。

## 原文（英語）

Fixed @-mentions written as `@file#10-12` attaching the whole file instead of those lines

## 概要

行範囲付きの @メンションが期待どおり、指定行のみを添付するようになりました。コンテキストの節約に役立ちます。

## 基本的な使い方

```text
@src/app.ts#10-12 この部分の挙動を説明して
```

## 実践例

### 大きなファイルの一部だけを参照

```text
@src/server.ts#120-180 このハンドラのエラー処理を改善して
```

## 注意点

- 行番号は 1 始まりで、`開始-終了` の形式で指定します。
- VS Code 拡張の Alt+K による行範囲指定も同様に修正されています。
