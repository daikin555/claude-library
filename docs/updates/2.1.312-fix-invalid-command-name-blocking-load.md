## 原文（日本語訳）

無効な名前のコマンドが1つあると全コマンドの読み込みが止まり、`claude -p` の出力が空になることがある問題を修正しました

## 原文（英語）

Fixed a command with an invalid name stopping all commands from loading, which could leave `claude -p` with no output

## 概要

カスタムコマンドに無効な名前のものが混ざると、他のコマンドも読み込まれなくなっていました。この問題が修正されています。

## 基本的な使い方

```bash
claude -p "このリポジトリを要約して"
```

非対話モードでも、出力が得られない事態が解消されます。

## 実践例

### CI/スクリプトでの安定化

`claude -p` をCIで使っている場合、コマンド名の不備による無出力を避けられます。

## 注意点

- 無効な名前のコマンド自体は使えないため、ファイル名を見直してください。
