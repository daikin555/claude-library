## 原文（日本語訳）
マルチバイト文字を含むファイルで、Edit権限プロンプトのプレビューが、実際に承認される編集箇所とは異なる位置を表示することがあった問題を修正。

## 原文（英語）
Fixed the Edit permission prompt preview sometimes showing a different location than the approved edit in files with multi-byte characters

## 概要
Claude CodeがEditツールでファイルを変更する際、実際の変更前に権限確認のプレビューが表示されます。しかし、日本語や絵文字などのマルチバイト文字を含むファイルでは、文字位置（オフセット）の計算方法の違いにより、プレビューに表示される編集箇所と実際に承認される編集箇所がずれてしまうことがありました。今回の修正でこの位置ずれが解消され、日本語を含むファイルでも正確な位置がプレビューに表示されるようになりました。

## 基本的な使い方
特別な操作は不要です。日本語などのマルチバイト文字を含むファイルを編集する際、Editツールの許可プレビューが常に正しい位置を示すようになります。

```bash
# 日本語を含むファイルの編集例
claude "README.mdの『概要』セクションの説明文を修正して"
```

## 実践例

### 日本語ドキュメントを編集する場合
日本語のREADMEやドキュメントファイルをClaude Codeで編集する際、以前はプレビューに表示される変更箇所と、実際に承認して適用される変更箇所が微妙にずれていることがありました。修正後はプレビュー表示が実際の編集内容と一致するため、承認前に変更内容を正確に確認できます。

```markdown
## 概要
このプロジェクトは日本語ドキュメントを多く含みます。
```

### 絵文字を含むコードコメントの編集
コメントに絵文字を含むコードファイルを編集する場合も、同様に文字位置のずれが解消され、意図しない箇所を承認してしまうリスクが減ります。

```javascript
// 🎉 リリース準備完了
function release() { /* ... */ }
```

## 注意点
- ASCII文字のみのファイルではこの問題は発生していなかったため、影響があるのは主に日本語・中国語・絵文字などのマルチバイト文字を含むファイルです。
- 古いバージョンのClaude Codeでは依然としてプレビューの位置ずれが発生する可能性があるため、最新版へのアップデートを推奨します。
