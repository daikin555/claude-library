## 原文（日本語訳）

[Claude Tag] 同じチャンネルの別スレッドで回答している際に、Slack上のClaudeがファイルを誤ったスレッドへ投稿することがある問題を修正しました

## 原文（英語）

[Claude Tag] Fixed Claude in Slack sometimes posting a file in the wrong thread when it was answering in another thread of the same channel

## 概要

ファイルが正しいスレッドに投稿されるようになりました。

## 基本的な使い方

追加操作は不要です。

## 実践例

### 複数スレッドの並行利用

同一チャンネルで複数の依頼を並行しても、成果物が混ざりにくくなります。

## 注意点

- 過去に誤投稿されたファイルは自動では移動されません。
