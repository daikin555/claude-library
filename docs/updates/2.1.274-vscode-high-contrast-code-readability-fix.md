## 原文（日本語訳）
[VSCode] ハイコントラストテーマ使用時に、チャット返信内のインラインコードとコードブロックが読みにくくなっていた問題を修正しました。

## 原文（英語）
[VSCode] Fixed inline code and code blocks in chat replies being unreadable under the High Contrast themes

## 概要
VSCodeの「High Contrast」テーマ（ハイコントラストテーマ）を使用している環境で、Claude Codeのチャット返信に含まれるインラインコードやコードブロックの配色が背景色と衝突し、文字が読み取りにくくなる不具合がありました。今回の修正により、ハイコントラストテーマでもコード部分の視認性が確保されるようになりました。視覚的なアクセシビリティを重視するユーザーにとって重要な改善です。

## 基本的な使い方
特別な操作は不要です。VSCodeで High Contrast テーマ（`Preferences: Color Theme` から選択可能）を使用している状態でClaude Codeとチャットするだけで、修正済みの配色が適用されます。

1. VSCodeのコマンドパレットから `Preferences: Color Theme` を開く
2. `Default High Contrast` などのハイコントラストテーマを選択
3. Claude Code拡張機能でチャットし、コード付きの返信を受け取る

## 実践例

### 修正前の挙動
ハイコントラストテーマ使用時、インラインコードやコードブロックの文字色・背景色のコントラストが不十分で、コード片の内容が判読しづらい状態になっていました。

### 修正後の挙動
インラインコードとコードブロックの配色がハイコントラストテーマに合わせて調整され、他のテーマと同様にはっきりと読める表示になりました。

## 注意点
- 通常のダーク/ライトテーマには影響しない、ハイコントラストテーマ特有の修正です。
- 視覚的なアクセシビリティ設定を利用しているユーザーは拡張機能を最新版に更新することを推奨します。
