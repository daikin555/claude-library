## 原文（日本語に翻訳）

Windowsにおいて、`CLAUDE_CODE_GIT_BASH_PATH` に指定されたパスがbash/shバイナリでない場合に、Claude Codeが異常終了したり、そのパスをそのままbashとして使用しようとしていた不具合を修正しました。現在はそのようなパス指定は無視され、警告が表示されるようになります。

## 原文（英語）

Fixed `CLAUDE_CODE_GIT_BASH_PATH` on Windows exiting or being used as bash when the path isn't a bash/sh binary; it's now ignored with a warning

## 概要

Claude CodeはWindows上でBashツールなどを実行する際、内部的にGit for Windowsに同梱されているbash（`Git\bin\bash.exe` など）を利用しています。`CLAUDE_CODE_GIT_BASH_PATH` 環境変数を設定すると、このbash実行ファイルのパスを明示的に指定できますが、従来はこのパスが誤っていた場合（bash/shバイナリではない実行ファイルを指していた場合など）に、Claude Codeが異常終了したり、そのファイルをそのままbashとして扱おうとして予期しない動作をすることがありました。今回の修正により、指定されたパスがbash/shバイナリでないと検出された場合はそのパス指定を無視し、警告を表示したうえで通常のフォールバック（デフォルトのGit Bash探索など）で動作を継続するようになりました。

## 基本的な使い方

`CLAUDE_CODE_GIT_BASH_PATH` は、Git for Windowsのbashが標準的な場所にインストールされていない場合や、複数のbashが存在してどれを使うか明示したい場合に設定する環境変数です。

PowerShellの場合:

```powershell
$env:CLAUDE_CODE_GIT_BASH_PATH = "C:\Program Files\Git\bin\bash.exe"
claude
```

コマンドプロンプト（cmd.exe）の場合:

```cmd
set CLAUDE_CODE_GIT_BASH_PATH=C:\Program Files\Git\bin\bash.exe
claude
```

恒久的に設定したい場合は、Windowsの「システム環境変数の編集」からユーザー環境変数として `CLAUDE_CODE_GIT_BASH_PATH` を追加してください。

## 実践例

### 正しいGit Bashのパスを指定する

Git for Windowsを標準以外の場所（例えばカスタムインストールディレクトリ）に入れている場合、正しいbash実行ファイルを明示的に指定します。

```powershell
# インストール先を確認
Get-Command bash -ErrorAction SilentlyContinue

# 正しいパスを環境変数にセット
$env:CLAUDE_CODE_GIT_BASH_PATH = "D:\Tools\Git\bin\bash.exe"
claude
```

指定したファイルが実際にbash/shバイナリであれば、Claude Codeはそのまま正常に動作します。

### 誤ったパスを指定してしまった場合の挙動確認

例えば誤って別の実行ファイル（bash/shバイナリではないもの）を指定してしまうケースです。

```powershell
# 誤って別のexeを指定してしまった例
$env:CLAUDE_CODE_GIT_BASH_PATH = "C:\Program Files\Git\bin\git.exe"
claude
```

この修正が適用されたバージョンでは、以下のように警告が表示され、Claude Codeは異常終了せずにデフォルトのGit Bash探索処理へフォールバックして起動を継続します。

```
Warning: CLAUDE_CODE_GIT_BASH_PATH does not point to a valid bash/sh binary and will be ignored.
Falling back to default Git Bash detection.
```

（実際のメッセージ文言はバージョンにより異なる場合があります）

### 環境変数の設定状況を確認・クリアする

意図しないパスが残っていないか確認し、不要であれば削除する例です。

```powershell
# 現在設定されている値を確認
$env:CLAUDE_CODE_GIT_BASH_PATH

# 不要な場合は環境変数を削除してデフォルト探索に任せる
Remove-Item Env:\CLAUDE_CODE_GIT_BASH_PATH
claude
```

Claude Codeを削除後に再起動すると、システムにインストールされているGit for Windowsのbashを自動的に検出して使用します。

## 注意点

- この修正はあくまで「異常終了を防ぎ、警告を出したうえでフォールバックする」ものであり、`CLAUDE_CODE_GIT_BASH_PATH` に誤ったパスを設定したこと自体が解決されるわけではありません。警告が表示された場合は、パスを見直すか環境変数を削除することを推奨します。
- 警告が表示されてフォールバックが発生した場合、実際に使用されるbashは `CLAUDE_CODE_GIT_BASH_PATH` で意図していたものとは異なる（システムにインストールされた別のGit Bash、あるいは検出できなければBashツール自体が使用不可）になる可能性があります。Bashツールの挙動が想定と違う場合は、まず環境変数の値を確認してください。
- Git for Windowsがインストールされていない、またはbashが全く検出できない環境では、パスの指定を無視した後もBashツールが利用できない場合があります。その場合はGit for Windowsのインストール、またはWSL環境の利用を検討してください。
- 企業環境などで `CLAUDE_CODE_GIT_BASH_PATH` をポリシーで一括設定している場合、この修正によって不正な値が「エラーで気付く」のではなく「警告付きで黙って迂回される」ようになるため、設定ミスに気づきにくくなる可能性があります。CI/CDやプロビジョニングスクリプトでこの環境変数を設定している場合は、値が正しいbash/shバイナリを指しているか改めて確認することをお勧めします。
