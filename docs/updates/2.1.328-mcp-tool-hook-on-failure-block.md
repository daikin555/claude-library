# mcp_tool フックに "onFailure": "block" を追加

## 原文（日本語に翻訳）

`mcp_tool` フックに `"onFailure": "block"` を追加しました。command フックや HTTP フックと同様に、フックの呼び出しが失敗するとそのアクションをブロックします。

## 原文（英語）

Added `"onFailure": "block"` for `mcp_tool` hooks, as for command and HTTP hooks: a hook whose call fails blocks the action

## 概要

MCP ツールを呼び出す `mcp_tool` フックで、フックの実行自体が失敗した場合にアクションを止める fail-closed な運用ができるようになりました。監査・ポリシーチェック用の MCP サーバーが落ちているときに、チェックなしで処理が進んでしまうのを防げます。

## 基本的な使い方

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "mcp_tool",
            "server": "policy-checker",
            "tool": "check_command",
            "onFailure": "block"
          }
        ]
      }
    ]
  }
}
```

## 実践例

### ポリシーサーバーが停止したら操作を止める

社内ポリシー判定を MCP サーバーで行っている場合、サーバー障害時に判定がスキップされるのを避けるため \`"onFailure": "block"\` を指定します。

## 注意点

- 上記の設定例はフィールド名を含め説明用です。正確なスキーマは公式の hooks ドキュメントを確認してください
- フックが失敗するとアクションがブロックされるため、MCP サーバーの可用性に注意してください
