## 原文（日本語訳）
[Claude Code on the web] ルーティンの「paused」および「on hold」通知が文の途中で切れて表示される不具合を修正。一時停止されたサブスクリプションの通知は、ユーザー自身でルーティンを再開するよう案内する文言に変更。

## 原文（英語）
[Claude Code on the web] Fixed routine "paused" and "on hold" notifications being cut off mid-sentence; the paused-subscription notice now says to turn the routine back on yourself

## 概要
Claude Code on the webのルーティン機能では、支払い停止などの理由でルーティンが一時停止（paused）または保留（on hold）状態になった際に通知が表示されますが、これまでその文言が途中で切れてしまい、ユーザーに何をすべきか正しく伝わらないことがありました。今回の修正で通知文が最後まで正しく表示されるようになり、特にサブスクリプション停止によるルーティン一時停止の場合は、ユーザー自身の操作でルーティンを再開する必要がある旨が明確に案内されるようになりました。

## 基本的な使い方
特別な操作は不要です。ルーティンが一時停止・保留状態になると、Claude Code on the webのUI上に通知が表示されます。通知内容を確認し、必要に応じてルーティンを再開してください。

```
ルーティン一覧 > 対象のルーティン > 「再開」ボタン
```

## 実践例

### サブスクリプションの支払いが止まりルーティンが一時停止した場合
修正前は通知メッセージが途中で切れており、ユーザーは何をすべきか分かりにくい状態でした。修正後は「ルーティンを再開するにはご自身で操作してください」という趣旨のメッセージが最後まで表示されます。

```
Before: "Your routine has been paused because your subscription..."（文が途切れる）
After:  "サブスクリプションが一時停止されたため、ルーティンを一時停止しました。
         再開するにはルーティンをご自身でオンに戻してください。"
```

### 保留（on hold）状態のルーティンを確認する場合
「on hold」通知も同様に全文が表示されるようになり、なぜ保留になっているのかをユーザーが正確に把握できます。

## 注意点
- これは表示上のバグ修正であり、ルーティンの一時停止・保留の挙動自体は変更されていません。
- サブスクリプションが原因で一時停止した場合、自動的には再開されないため、ユーザー自身での再開操作が必要です。
