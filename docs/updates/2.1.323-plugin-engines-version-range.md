## 原文（日本語訳）

`plugin.json` に `engines["claude-code"]` を追加しました。記載されたClaude Codeのバージョン範囲外にあるプラグインは、インストール・更新・読み込みが行われません。また、インストールと更新では、範囲に適合する最新バージョンが選ばれます。

## 原文（英語）

Added `engines["claude-code"]` to `plugin.json`: plugins outside their stated Claude Code version range are not installed, updated or loaded, and install and update pick the newest version that fits

## 概要

プラグイン作者は `plugin.json` の `engines["claude-code"]` で、プラグインが対応するClaude Codeのバージョン範囲を宣言できるようになりました。範囲外の環境ではインストール・更新・読み込みが行われないため、非互換なプラグインによる不具合を防げます。複数バージョンがある場合は、範囲に適合する最新版が選択されます。

## 基本的な使い方

```json
{
  "name": "my-plugin",
  "version": "1.2.0",
  "engines": {
    "claude-code": ">=2.1.323"
  }
}
```

バージョン範囲の書式の詳細は公式のプラグインドキュメントを確認してください。

## 実践例

### 新しいhook APIに依存するプラグイン

特定バージョン以降でのみ使える機能に依存する場合、下限を指定して古いClaude Codeでの誤動作を防ぎます。

```json
{ "engines": { "claude-code": ">=2.1.323" } }
```

### 検証で確認する

```bash
claude plugin validate .
```

## 注意点

- 範囲外のプラグインは読み込まれないだけでなく、インストールや更新も拒否されます
- 古いClaude Codeを使っている利用者には、範囲に適合する旧バージョンが選ばれます
- 範囲を狭くしすぎると利用できる環境が減るため、必要最小限の指定にしましょう
