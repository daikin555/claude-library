## 原文（日本語訳）

[VSCode] Claudeが応答している最中に入力したスラッシュコマンドが、応答完了後に実行されるのではなく、そのままテキストとしてモデルに送信されてしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed slash commands typed while Claude is responding being sent to the model as text instead of running once the response finishes

## 概要

スラッシュコマンド（`/help`や`/clear`など）は、Claude Codeの特別な操作を呼び出すための機能です。これまで、Claudeが応答中にスラッシュコマンドを入力すると、そのコマンドが実際には実行されず、単なるテキストとしてそのままモデルに送信されてしまう不具合がありました。今回の修正により、応答中に入力されたスラッシュコマンドは、応答が完了した後に正しくコマンドとして実行されるようになりました。

## 基本的な使い方

入力欄にスラッシュコマンドを入力してEnterを押すと、対応する操作が実行されます。

```
/clear
/help
/compact
```

## 実践例

### Claudeが応答中に次のスラッシュコマンドを先に入力しておく場合

長い応答を待っている間に、次に実行したい`/compact`のようなコマンドを先に入力してEnterを押すケースです。

```
修正前:
  1. Claudeが応答中に "/compact" と入力してEnter
  2. 応答完了後、"/compact" というテキストがそのままモデルに送られてしまう（コマンドとして実行されない）

修正後:
  1. Claudeが応答中に "/compact" と入力してEnter
  2. 応答完了後、"/compact" が正しくコマンドとして実行される
```

### 応答待ち時間を有効活用したいワークフロー

長時間の処理を待つ間に次の操作を予約的に入力しておく使い方をするユーザーにとって、コマンドが意図通りに実行されることは作業の連続性を保つ上で重要です。

## 注意点

- スラッシュコマンドは応答完了後にキューされて実行される形になるため、即座には実行されない点に注意してください。
- 通常のテキストメッセージについては、この修正の影響を受けません。
