## 原文（日本語訳）

そのGitHub組織が切断された後、Claude Tag管理設定のアクセスバンドルのRepositoriesタブから、あるGitHub組織のグラントを削除しようとしても保存に失敗していた不具合を修正しました。

## 原文（英語）

[Claude Tag] Fixed removing a GitHub organization's grant from an access bundle's Repositories tab in Claude Tag admin settings failing to save after that GitHub organization was disconnected

## 概要

Claude Tagの管理設定では、「アクセスバンドル」という単位でGitHub組織へのアクセス権限（グラント）を管理できます。すでに切断（disconnect）されたGitHub組織については、そのグラントをアクセスバンドルから削除しようとしても、保存処理が失敗してしまう不具合がありました。これにより、既に使われていない組織のグラントが管理画面上に残り続け、設定の整理ができないという問題がありました。今回の修正でこの削除操作が正しく保存されるようになりました。

## 基本的な使い方

Claude Tag管理設定画面のアクセスバンドルにあるRepositoriesタブを開き、切断済みのGitHub組織のグラントを選択して削除します。

## 実践例

### 組織再編に伴うアクセス権限の整理

GitHub組織の統合や切断が発生した際、不要になったグラントをアクセスバンドルから確実に削除し、権限設定をクリーンに保てます。

### セキュリティ監査での不要権限の棚卸し

定期的なセキュリティ監査で、既に使われていないGitHub組織へのアクセス権限が誤って残っていないかを確認・削除する作業がスムーズに行えます。

## 注意点

- この修正は既に切断されたGitHub組織のグラント削除に関するものです。接続中の組織のグラント管理には影響しません
- 削除操作を行う前に、本当に不要なグラントかどうかを確認することを推奨します
