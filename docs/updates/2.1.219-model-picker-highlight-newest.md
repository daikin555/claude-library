## 原文（日本語に翻訳）

`/model` のモデル選択画面において、ハイライト表示が「最新モデルの名前」だけにかかるように変更されました。これにより、ハイライトはリスト内の任意の一部（複数モデルや従来のルールに基づく範囲）を示すのではなく、常に新しくリリースされたモデルを示すようになりました。

## 原文（英語）

Changed the `/model` picker to highlight only the newest model's name, so the highlight marks the new release rather than an arbitrary subset of the list

## 概要

Claude Codeのモデル選択メニュー（`/model`）には、注目してほしいモデルをハイライト表示する機能があります。これまではハイライトの対象範囲が曖昧で、複数のモデルにまたがったり、必ずしも「最新モデル」を指していなかったりすることがありました。今回のバージョン2.1.219では、この挙動が整理され、ハイライトは常にリスト内で最も新しくリリースされたモデルの名前1つだけにかかるようになりました。これにより、ユーザーは一目でどれが最新モデルかを判断できます。

## 基本的な使い方

ターミナルでClaude Codeを起動した状態で、以下のコマンドを実行するだけです。

```
/model
```

モデル選択メニューが表示され、利用可能なモデル一覧の中で最新モデルの名前だけがハイライトされます。矢印キーでカーソルを移動し、Enterで選択すれば、そのセッション（またはプロジェクト）で使用するモデルを切り替えられます。

```
❯ /model

  Select a model:

    Claude Haiku 4.5
    Claude Sonnet 4.5
  ▸ Claude Opus 5        ← ハイライト（最新モデル）
```

## 実践例

### 最新モデルへの切り替え判断に使う

新しいモデル（例: Claude Opus 5）がリリースされた直後、どのモデルが「新しく追加されたものか」をリストの見た目だけで判断するのは意外と難しいものです。今回の変更により、`/model` を開いた瞬間にハイライトされている項目を見るだけで「これが最新リリース」と確信を持って選択できます。

```
/model
# ハイライトされているモデル名を確認し、そのまま選択するだけで
# 最新モデルに切り替えられる
```

複雑なタスク（大規模なリファクタリングや設計方針の検討など）に着手する前に `/model` を開き、ハイライトされた最新モデルへ切り替えてから作業を始める、という運用がしやすくなります。

### CLAUDE.mdやチームの運用ルールと組み合わせる

チームでモデル運用ルールを定めている場合、「新しいモデルがリリースされたら `/model` のハイライトを確認し、必要に応じて切り替える」という手順をドキュメント化しやすくなりました。ハイライト対象が一意になったことで、手順書やオンボーディング資料に「ハイライトされているモデルが最新版です」と迷いなく書けます。

```
# チームのオンボーディングメモの一例
1. 週次で /model を実行する
2. ハイライトされているモデル名（= 最新モデル）を確認する
3. 現在使用中のモデルと異なる場合は切り替えを検討する
```

### スクリプトやドキュメント作成時の確認用途

ガイド記事やスクリーンショットを作成する際、「どれが最新モデルか」を説明するのにハイライトをそのまま根拠として使えるようになりました。以前は複数モデルがハイライトされる可能性があったため、説明文で補足が必要でしたが、今後は「ハイライトされているモデルが最新です」と一言で説明できます。

## 注意点

- ハイライトはあくまで「リスト内で最も新しくリリースされたモデル」を示すものであり、そのモデルが必ずしもユーザーの用途に最適とは限りません。用途に応じてSonnet/Haiku/Opusなど適切なモデルを選択してください。
- 組織やプランによっては、最新モデルが利用可能なモデル一覧に表示されない場合があります。その場合はハイライト自体が表示されないことがあります。
- 本変更はあくまでUI表示上の改善であり、モデルの性能や料金体系には影響しません。
