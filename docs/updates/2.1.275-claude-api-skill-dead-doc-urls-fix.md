## 原文（日本語訳）

バンドルされているclaude-apiスキルの「ライブソース」テーブルにあった、Pricing、Computer Use、Skills、CLIに関する4つの無効なドキュメントURLを修正しました。

## 原文（英語）

Fixed four dead documentation URLs (Pricing, Computer Use, Skills, CLI) in the bundled claude-api skill's live-sources table

## 概要

Claude Codeには `claude-api` という、Claude APIやAnthropic SDKに関する最新情報（料金、モデルID、機能など）を参照するためのバンドル済みスキルが同梱されています。このスキルは内部に「ライブソース」と呼ばれる参照先URLのテーブルを持ち、必要に応じて最新のドキュメントを取得します。このテーブルのうち、Pricing（料金）、Computer Use、Skills、CLIに関する4つのURLがリンク切れになっており、正しく最新情報を取得できない状態でした。今回の修正でこれらのURLが有効なものに更新されました。

## 基本的な使い方

特別な操作は不要です。`claude-api` スキルを利用するとき（Claude APIの料金やモデル、機能について質問したときなど）に、内部的に修正済みの正しいURLが参照されるようになります。

## 実践例

### Claude APIの料金について質問する

「Claudeの最新モデルの料金を教えて」といった質問をした際、`claude-api` スキルが参照するPricingページのURLが修正前はリンク切れになっており、最新情報を正しく取得できないことがありました。修正後は正しいURLから最新の料金情報を参照できます。

### Computer UseやSkills機能について調べる

Computer UseやSkills機能の仕様について尋ねた場合も、同様にリンク切れが解消されたことで、より正確な最新ドキュメントを参照した回答が得られるようになります。

## 注意点

- これはドキュメント参照用の内部データ修正であり、ユーザーが直接操作するものではありません。
- ドキュメントのURLは将来的に変更される可能性があるため、常に最新情報については公式ドキュメントサイトを直接確認することも有効です。
