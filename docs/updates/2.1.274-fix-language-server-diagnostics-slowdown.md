## 原文（日本語訳）

言語サーバーが数千ファイル分のプロジェクト全体の診断情報（diagnostics）を発行した際に、ターンごとに発生していた処理の遅延を修正しました。

## 原文（英語）

Fixed a per-turn slowdown when a language server publishes project-wide diagnostics for thousands of files

## 概要

Claude CodeはIDE統合機能を通じて言語サーバー（LSP）からの診断情報を利用し、コードの問題箇所などを把握します。大規模なプロジェクトでは言語サーバーがプロジェクト全体に対して数千ファイル分の診断情報を一度に発行することがあり、これまではその情報量の多さが原因で、会話のターンごとに目に見える処理の遅延が発生していました。今回の修正でこの処理が効率化され、大規模プロジェクトでもターンごとの遅延が軽減されました。

## 基本的な使い方

この修正は内部的なパフォーマンス改善であり、ユーザー側の操作は不要です。IDE統合（VS Code拡張など)を有効にして大規模なプロジェクトを開いているだけで、改善の恩恵を受けられます。

## 実践例

### モノレポなど非常に大きなコードベースでの作業

数千ファイルを含むモノレポや大規模なプロジェクトをIDEで開き、言語サーバーがプロジェクト全体の診断を発行するような環境でも、修正後は各ターンの応答がスムーズになります。

### 型チェックが厳格な大規模TypeScript/Javaプロジェクト

型エラーや警告が多数出やすい厳格な設定の大規模プロジェクトでは、診断情報の量が特に多くなりがちですが、修正後はそうした環境でも快適に対話を続けられます。

## 注意点

- 改善の度合いはプロジェクトの規模や使用している言語サーバーの実装によって異なります。
- 依然として非常に大規模なプロジェクトでは、多少の遅延が発生する可能性があります。
