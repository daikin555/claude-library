## 原文（日本語訳）
`/status` のGitHub行の表記が「Cloud sessions」に変更され、`/web-setup`、`/ultrareview`、テレポートメッセージも「Claude Code on the web」ではなく「cloud session」と表記されるようになりました。

## 原文（英語）
Changed the `/status` GitHub line to read "Cloud sessions", and `/web-setup`, `/ultrareview`, and teleport messages to say "cloud session" instead of "Claude Code on the web"

## 概要
これはUI表記の統一に関する変更です。これまで「Claude Code on the web」と表記されていた機能名が「cloud session」という呼び方に統一され、`/status` コマンドのGitHub関連行や `/web-setup`、`/ultrareview`、テレポートメッセージなど複数の箇所で新しい表記が使われるようになりました。機能自体の挙動に変わりはなく、ユーザーにとって一貫した用語でクラウド上のセッションを理解しやすくすることが目的です。

## 基本的な使い方
特別な操作は不要です。`/status` を実行すると新しい表記を確認できます。

```
/status
```

## 実践例

### /status コマンドでの表示
```
/status
```
GitHub関連の行が「Cloud sessions」という表記で表示されます。

### /web-setup や /ultrareview 実行時のメッセージ
```
/web-setup
```
このコマンドやテレポート関連のメッセージ内でも、「Claude Code on the web」ではなく「cloud session」という表記に統一されています。

## 注意点
- これは表記のみの変更であり、機能自体の挙動には影響しません。
- ドキュメントやスクリプトなどで旧表記「Claude Code on the web」を前提にしたテキストマッチングを行っている場合は、新しい表記に合わせて更新が必要になることがあります。
