## 原文（日本語訳）

Claudeがバージョンに60文字を超えるラベルを付けた場合にアーティファクトの公開が失敗していた不具合を修正しました。現在はラベルが自動的に短縮されます。

## 原文（英語）

Fixed artifact publishes failing when Claude gave the version a label longer than 60 characters; the label is now shortened

## 概要

Claude Codeの `/artifacts` 機能では、公開したアーティファクトの各バージョンにラベルが付与されます。しかし、Claudeが生成したラベルが60文字を超える長いものだった場合、公開処理自体がエラーで失敗してしまう不具合がありました。今回の修正で、長すぎるラベルは自動的に短縮されるようになり、公開が失敗しなくなりました。

## 基本的な使い方

ユーザー側の対応は不要です。通常どおりアーティファクトを作成・公開する操作の中で、ラベルの長さは自動的に調整されます。

```
/artifacts
```

## 実践例

### 詳細な説明を含むダッシュボードやレポートの公開

複雑な内容を表すために長い説明的なバージョンラベルが生成されやすいダッシュボードやレポート系のアーティファクトでも、公開が失敗せずに済みます。

### 頻繁にバージョンを更新するアーティファクトの運用

何度も更新を重ねるアーティファクトで、更新内容を説明する長めのラベルが生成された場合でも、公開プロセスが中断されることなく続けられます。

## 注意点

- ラベルは自動的に短縮されるため、公開後に表示されるラベルの文言が元の生成内容と多少異なる場合があります
- この修正はラベルの長さに起因する失敗のみを対象としており、他の理由による公開失敗には別途対応が必要です
