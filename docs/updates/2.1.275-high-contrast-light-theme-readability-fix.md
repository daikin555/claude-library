## 原文（日本語訳）

[VSCode] High Contrast Lightテーマにおいて、プランプレビューおよびHooksとPermission rulesダイアログ内のコードが読めなくなっていた問題を修正しました。

## 原文（英語）

[VSCode] Fixed unreadable code in the plan preview and the Hooks and Permission rules dialogs with the High Contrast Light theme

## 概要

VS CodeのアクセシビリティテーマであるHigh Contrast Lightを使用しているユーザーに向けて、Claude Codeの一部UI（プランプレビュー、Hooksダイアログ、Permission rulesダイアログ）で表示されるコード部分の配色が不適切で、テキストが読めない状態になっていた不具合を修正しました。この修正により、High Contrast Lightテーマ利用時でもこれらのコード表示が視認できるようになります。

## 基本的な使い方

VS Codeの設定からテーマを「High Contrast Light」に切り替えるだけで、修正後のコントラストが適用されます。

```
> Preferences: Color Theme > High Contrast Light
```

## 実践例

### プランプレビューでコード変更内容を確認する場合

Claudeが提案する実装プランのプレビューにコードスニペットが含まれる際、High Contrast Lightテーマ利用時でも文字色と背景色のコントラストが確保され、内容を正しく読み取れるようになります。

```
修正前: High Contrast Lightテーマでプランプレビューのコードが背景色に埋もれて読めない
修正後: High Contrast Lightテーマでもコードが十分なコントラストで表示される
```

### HooksやPermission rulesダイアログの設定内容を確認する場合

HooksやPermission rulesのダイアログに表示されるJSON設定やコマンド例も、同様に視認性が改善されます。

```
> Claude Code: Manage Hooks
> Claude Code: Manage Permission Rules
```

## 注意点

- この修正はHigh Contrast Lightテーマ利用時に限定された表示上の不具合対応です。
- 視認性向上のための修正であり、機能自体の動作には影響しません。
