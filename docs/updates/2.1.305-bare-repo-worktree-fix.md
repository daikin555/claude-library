# bareリポジトリのworktree起点とサブエージェントworktree削除の修正

## 原文（日本語に翻訳）

- bareリポジトリで新しいworktreeがデフォルトブランチではなくローカルHEADから開始されることがある問題、および変更のないサブエージェントのworktreeがクリーンアップされないことがある問題を修正

## 原文（英語）

- Fixed new worktrees in a bare repository sometimes starting from local HEAD instead of the default branch, and unchanged subagent worktrees sometimes not being cleaned up

## 概要

worktreeまわりの2つの不具合修正です。bareリポジトリで新規worktreeがデフォルトブランチから作成されるようになり、変更のないサブエージェント用worktreeも確実に片付けられます。

## 基本的な使い方

```bash
claude --worktree feature-x
git worktree list
```

## 実践例

### bareリポジトリ運用

bare＋worktree構成のチームでも、新しい作業が最新のデフォルトブランチを起点に始まります。

### 並列サブエージェント

何も変更しなかったサブエージェントのworktreeが残らず、ディスクとブランチ一覧が散らかりません。

## 注意点

- 過去に残ったworktreeは `git worktree prune` や `git worktree remove` で手動整理できます。
