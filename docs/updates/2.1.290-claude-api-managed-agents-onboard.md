## 原文（日本語訳）

`/claude-api managed-agents-onboard <url>` を追加した。ページが説明するManaged Agentsのパターンを `ant apply` 用ファイルとして構築する。`<quickstart-name>`（例: `deep-researcher`）を指定すると、Consoleのクイックスタートテンプレートを `ant` CLIで構築する。

## 原文（英語）

Added `/claude-api managed-agents-onboard <url>` to set up the Managed Agents pattern a page describes as `ant apply` files
Added `/claude-api managed-agents-onboard <quickstart-name>` to build a Console quickstart template, such as `deep-researcher`, with the `ant` CLI

## 概要

ドキュメントページのURLまたはクイックスタート名から、Managed Agentsのセットアップを自動生成するサブコマンドです。

## 基本的な使い方

```text
/claude-api managed-agents-onboard deep-researcher
```

## 実践例

### URLからパターンを再現

```text
/claude-api managed-agents-onboard https://example.com/agent-pattern
```

### Consoleクイックスタートの構築

`deep-researcher` のようなテンプレート名を指定します。

## 注意点

- `ant` CLIが必要です。
- 同バージョンで、`claude-api` スキルのManaged Agentsの例は、Webツールを必要なときだけ有効にし、`auto` 権限ポリシーを使うよう変更されています。
