## 原文（日本語訳）

スラッシュコマンドの入力ミス、またはそのセッションで利用できないコマンドに対してEnterキーを押すと、最も近いあいまい一致のコマンドを実行するのではなく、その旨をエラーとして報告するようになりました。プレフィックス入力やエイリアスは引き続き実行されます。

## 原文（英語）

Pressing Enter on a slash-command typo or a command unavailable in this session now reports it instead of running the closest fuzzy match; prefixes and aliases still run

## 概要

これまでClaude Codeでは、スラッシュコマンドを入力した際に、綴りを間違えたり、そのセッションでは使えないコマンド名を入力してしまったりした場合でも、名前が近い別のコマンドが「あいまい一致」によって実行されてしまうことがありました。これは意図しないコマンドが実行される原因になり得ました。今回の修正により、そうしたタイプミスや利用不可なコマンド名を入力してEnterキーを押すと、あいまい一致で別のコマンドを実行するのではなく、「そのコマンドは見つかりません」といった形で明確にエラー報告されるようになりました。なお、コマンド名の先頭部分（プレフィックス）だけを入力した場合や、正式なエイリアスを入力した場合は、これまでどおり正しく実行されます。

## 基本的な使い方

特別な操作は不要です。スラッシュコマンドを入力する際、存在しないコマンド名や、現在のセッションで無効になっているコマンド名を入力してEnterキーを押すと、そのコマンドが見つからない旨がエラーとして表示されます。

```
/revie
```

上記のように `/review` の入力ミス（末尾の `w` が抜けている）でEnterを押しても、以前のように近いコマンドが誤って実行されることはなく、コマンドが見つからない旨が報告されます。

## 実践例

### コマンド名を打ち間違えたときに誤実行を防ぐ

```
/comit "fix bug"
```

`/commit` のつもりで `/comit` と入力してしまった場合、以前は名前が似た別のコマンドがあいまい一致で実行されてしまう可能性がありましたが、今回の変更後は「そのようなコマンドは見つかりません」という報告が表示されるだけで、意図しないコマンドが実行されることはありません。

### そのセッションで無効なコマンドを入力した場合

プラグインやMCPサーバーが無効化されている、あるいはそのセッションの権限では使えないスラッシュコマンドを入力した場合も、あいまい一致による代替実行は行われず、「このセッションでは利用できません」という趣旨のエラーが報告されます。これにより、無効なはずのコマンドが別のコマンドとして意図せず実行される事故を防げます。

### プレフィックス入力やエイリアスは引き続き便利に使える

```
/rev
```

一方で、コマンド名の先頭部分だけを入力した場合（プレフィックスマッチ）や、コマンドに設定された正式なエイリアスを入力した場合は、これまでどおり正しく対応するコマンドが実行されます。あいまい一致だけが廃止された点に注意してください。

## 注意点

- 廃止されたのは「あいまい一致（fuzzy match）」による実行であり、プレフィックス入力やエイリアスによる実行は引き続きサポートされます
- カスタムスラッシュコマンド（`.claude/commands/` 配下のMarkdownファイル）でも同様の挙動になります
- コマンドが見つからない場合は、利用可能なコマンド一覧を `/` だけ入力して確認するとよいでしょう
