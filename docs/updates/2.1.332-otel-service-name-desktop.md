# デスクトップ Code タブの OpenTelemetry service.name を変更

## 原文（日本語に翻訳）

デスクトップ Code タブのセッションにおける OpenTelemetry の既定の `service.name` が `claude-code-desktop` になりました。`claude-code` で絞り込んでいるフィルタは更新するか、`OTEL_SERVICE_NAME` で従来の名前を指定してください。

## 原文（英語）

Changed the default OpenTelemetry `service.name` of desktop Code tab sessions to `claude-code-desktop`; update filters keyed on `claude-code`, or set `OTEL_SERVICE_NAME` to keep the old name

## 概要

CLI とデスクトップアプリを区別して監視できるよう、既定のサービス名が分けられました。ダッシュボードやアラートが `service.name = claude-code` に依存している場合は対応が必要です。

## 基本的な使い方

従来の名前を維持するには環境変数を設定します。

```bash
export OTEL_SERVICE_NAME=claude-code
```

## 実践例

### フィルタを両方に対応させる

クエリを `service.name IN ("claude-code", "claude-code-desktop")` のように変更すれば、CLI とデスクトップの両方を集計できます。

### 応答テキストのログ

同リリースでは `assistant_response` イベントが追加され、`OTEL_LOG_ASSISTANT_RESPONSES=1` のときに SendUserMessage 等で送られたテキストが記録されます。それ以外では `tool_input` には長さのみが表示されます。

## 注意点

- ダッシュボードやアラートが無効になる可能性があります。
- 応答ログには機微な内容が含まれうるため、有効化は慎重に行ってください。
