## 原文（日本語訳）
[VSCode] セッションピッカーで検索クエリを入力している最中に、セッション名が横方向にずれてしまう問題を修正しました。

## 原文（英語）
[VSCode] Fixed session names shifting sideways in the session picker while typing a search query

## 概要
VSCode拡張機能のセッションピッカー（過去のセッション一覧から選択するUI）で、検索ボックスに文字を入力するたびにセッション名のテキストが横方向にガタガタとずれて表示される不具合が修正されました。これは見た目上の問題ですが、目的のセッションを素早く探す際に視認性を損ねていました。今回の修正により、検索中もセッション名の表示位置が安定します。

## 基本的な使い方
特別な操作は不要です。VSCode拡張機能を最新版に更新すれば、自動的に修正が適用されます。

1. VSCode の拡張機能タブから Claude Code 拡張機能を最新版に更新
2. Claude Code パネルを開き、セッションピッカーを表示
3. 検索ボックスにキーワードを入力してセッションを絞り込む

## 実践例

### 修正前の挙動
検索ボックスに `refactor` のように文字を1文字ずつ入力するたびに、一覧に表示されているセッション名のテキストが左右にずれてちらつくように表示されていました。長いセッション名や日本語混じりのセッション名では特に目立ちやすい問題でした。

### 修正後の挙動
検索クエリを入力してもセッション名の表示位置は固定されたままとなり、フィルタリング結果だけが滑らかに更新されます。多数のセッションを抱えるプロジェクトで、目的のセッションを検索して素早く切り替える際の視認性が向上します。

## 注意点
- この修正はVSCode拡張機能のUIに関するものであり、ターミナル版のClaude Codeには影響しません。
- 効果を得るには拡張機能を最新版に更新する必要があります。
