## 原文（日本語訳）

Bedrock、Vertex、Foundry、Mantleで、Claude Codeが認識しないモデル名（カスタムデプロイ名や推論プロファイルARNなど）には、SonnetやHaikuを背後に持つ場合でも短いシステムプロンプトを使うよう変更。完全版を維持するには `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` を設定します

## 原文（英語）

Changed Bedrock, Vertex, Foundry and Mantle to use the shorter system prompt for model names Claude Code doesn't recognize, such as custom deployment names and inference profile ARNs, even when they front Sonnet or Haiku; set `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` to keep the full prompt

## 概要

未認識のモデル名では短いシステムプロンプトが使われるようになりました。従来の完全版を使いたい場合は環境変数で指定します。

## 基本的な使い方

```bash
export CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0
claude
```
