## 原文（日本語に翻訳）

エージェントパネルを更新しました。完了したサブエージェントは即座に非表示になり、フッターに `/tasks` を案内するヒントが表示されるようになりました。また、「↓ あとN件」というオーバーフロー表示（見きれている項目数の表示）が視認性向上のため左側に移動しました。

## 原文（英語）

Updated agent panel: completed subagents hide immediately with a `/tasks` footer hint, and the "↓ N more" overflow indicator moved left for visibility

## 概要

これはエージェントパネル（実行中のサブエージェントを一覧表示するUI）のUX改善です。従来は完了したサブエージェントがパネル上にしばらく残り続けることがあり、実行中のタスクとの区別がつきにくいことがありました。今回の更新で、完了したサブエージェントは即座にパネルから消えるようになり、代わりにフッターへ `/tasks` コマンドで完了済みタスクも含めて確認できることを案内するヒントが表示されます。また、表示しきれないタスクがある場合の「↓ N more」オーバーフロー表示が、見やすさのためにパネル左側へ移動しました。

## 基本的な使い方

エージェントパネルの見え方の変更であり、特別な操作は不要です。完了したタスクの詳細を確認したい場合は `/tasks` を使います。

```
/tasks
```

パネルのフッターに表示されるヒントからも、この `/tasks` コマンドの存在に気づけるようになっています。

## 実践例

### 複数のサブエージェントを並行して走らせている場合

複数の調査タスクや修正タスクをサブエージェントとして同時に走らせているとき、完了したものが即座にパネルから消えるため、現在実行中のタスクだけがひと目でわかるようになります。

```bash
# 複数のサブエージェントを起動して並行作業
```

完了したエージェントの結果を後から振り返りたい場合は、フッターのヒントに従って `/tasks` を実行します。

```
/tasks
```

### 多数のバックグラウンドタスクが同時に走っている場合

タスクの数が画面に収まりきらない場合、以前は右側に表示されていた「↓ N more」の表示が左側に移動したことで、パネル内の他の情報と重ならず視認しやすくなりました。

### 完了済みタスクの結果を後から確認したい場合

パネルからはすぐに消えてしまっても、`/tasks` を実行すればこれまでに完了したタスクの一覧や結果を確認できます。

```
/tasks
```

## 注意点

- 完了したサブエージェントの情報自体が失われるわけではなく、パネル上の表示から即座に消えるだけです。詳細は `/tasks` から確認できます。
- 「↓ N more」の位置変更は表示上のレイアウト改善であり、機能面での変更はありません。
- エージェントパネルの表示内容やレイアウトは今後のバージョンでも継続的に調整される可能性があります。
