## 原文（日本語訳）
1回限りのスケジュールルーチンが前回のセッション以降に実行されたことを知らせる起動時通知を削除しました

## 原文（英語）
Removed the startup notice that told you a one-off scheduled routine had run since your last session

## 概要
これまでClaude Codeを起動すると、前回のセッション以降に1回限り（one-off）のスケジュールルーチンが実行されていた場合、その旨を知らせる通知が表示されていました。今回のアップデートでこの起動時通知は削除されました。実行結果自体を確認する方法（ルーチンの履歴や実行結果の確認機能）は引き続き利用できます。

## 基本的な使い方
特にユーザー側で行う操作はありません。今後Claude Codeを起動した際に、この種の通知は表示されなくなります。

```
claude
# → 以前: 「1回限りのスケジュールルーチンが実行されました」という
#   起動時の通知が表示されることがあった
# → 今後: この通知は表示されない
```

## 実践例

### 起動時の体験がシンプルになる
```
claude
# 以前は前回セッション以降に実行された1回限りのルーチンについて
# 通知が表示されていたが、今後は表示されず、すぐに作業を開始できる
```

### ルーチンの実行結果を確認したい場合
```
# 起動時通知に頼らず、ルーチンの管理・履歴確認機能から
# 直接実行結果を確認する
```

## 注意点
- この変更は通知の削除のみであり、ルーチン自体の実行やスケジューリング機能には影響しません。
- 実行結果を確認したい場合は、ルーチンの管理画面や履歴機能を別途参照する必要があります。
- 繰り返し実行されるルーチン（1回限りでないもの）の通知挙動については、この変更の対象外です。
