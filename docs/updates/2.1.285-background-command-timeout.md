# バックグラウンド Bash/PowerShell コマンドに時間制限が追加

## 原文（日本語訳）

- バックグラウンドの Bash および PowerShell コマンドは、制限時間（`run_in_background` 使用時の `timeout`。既定 30 分、最大 2 時間）で停止するようになりました。停止時は Claude に通知されます

## 原文（英語）

- Changed background Bash and PowerShell commands to stop after a time limit (their `timeout` with `run_in_background`, default 30 min, max 2 h); Claude is notified when one is stopped

## 概要

バックグラウンド実行されるコマンドに、既定30分・最大2時間の時間制限が設けられました。放置された開発サーバーやウォッチ処理が残り続けるのを防ぎます。停止されると Claude に通知されます。

## 基本的な使い方

Claude が `run_in_background` でコマンドを起動する際に `timeout` を指定します。未指定の場合は30分で停止します。

## 実践例

### 長時間ビルドを走らせる

長いビルドやテストは、`timeout` を最大の2時間まで伸ばすよう Claude に指示します。

```text
> ビルドをバックグラウンドで実行して。timeout は 2 時間にして
```

### 常駐プロセスが必要な場合

2時間を超える常駐プロセス（開発サーバー等）は、Claude Code の外（別ターミナルなど）で起動してください。

## 注意点

- 従来2時間超で動かしていたバックグラウンドコマンドは停止されます。
- 停止は Claude に通知されるため、必要に応じて再実行を指示できます。
