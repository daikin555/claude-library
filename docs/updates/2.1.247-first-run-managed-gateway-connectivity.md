## 原文（日本語訳）

管理設定でClaude appsゲートウェイのサインインが構成されており、Anthropicのエンドポイントに到達できない場合に、初回セットアップが「Anthropicサービスに接続できません」というエラーで終了してしまう問題を修正しました。

## 原文（英語）

Fixed first-run setup exiting with "Unable to connect to Anthropic services" when managed settings configure Claude apps gateway sign-in and Anthropic endpoints are unreachable

## 概要

組織によっては管理設定（managed settings）を通じてClaude appsゲートウェイ経由のサインインを構成し、社内ネットワークなどを介してClaude Codeを利用させる運用を行っています。この構成では、Anthropicの通常のエンドポイントに直接到達できないことが前提となる場合がありますが、これまでは初回セットアップ時にAnthropicのエンドポイントへの到達性を確認しようとして失敗し、「Anthropicサービスに接続できません」というエラーでセットアップ自体が中断してしまう問題がありました。今回の修正で、ゲートウェイ経由のサインインが構成されている場合はこの誤ったチェックによる失敗が発生しなくなりました。

## 基本的な使い方

管理者が `managed-settings.json` などでClaude appsゲートウェイのサインインを構成した環境で、エンドユーザーが初めてClaude Codeを起動します。

```
claude
```

修正後は、Anthropicの直接エンドポイントに到達できない環境であっても、ゲートウェイ経由の認証が正しく構成されていれば初回セットアップが正常に完了します。

## 実践例

### 社内ネットワーク経由でClaude Codeを配布する企業

セキュリティ上の理由からAnthropicのエンドポイントへの直接アクセスを禁止し、ゲートウェイ経由でのみアクセスを許可している企業では、従業員が初めてClaude Codeを起動した際にセットアップが失敗せず、そのままゲートウェイ経由で利用開始できます。

### プロキシ環境での展開

社内プロキシ配下の端末に管理設定を配布してClaude Codeを導入する場合、プロキシがAnthropicの通常エンドポイントへの直接通信をブロックしていても、ゲートウェイ設定があれば初回セットアップがブロックされません。

### IT部門による一括展開

MDMなどを使って多数の端末に管理設定を一括配布する運用でも、ネットワーク構成に起因する初回起動エラーがなくなり、サポート対応の負荷が減ります。

## 注意点

- この修正はゲートウェイ経由のサインインが管理設定で構成されているケースが対象です。ゲートウェイ設定がない環境でAnthropicのエンドポイントに到達できない場合は、引き続き接続エラーとなります
- 管理設定の適用範囲や優先順位は既存の管理設定の仕組みに従います
