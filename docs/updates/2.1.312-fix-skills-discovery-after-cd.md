## 原文（日本語訳）

Gitリポジトリ内でBashにより深い階層へ `cd` した後、ディレクトリ別スキルや `paths:` スキルが見つからなくなる問題を修正しました

## 原文（英語）

Fixed per-directory and `paths:` skills not being found after a Bash `cd` deeper into a git repository

## 概要

サブディレクトリに置いたスキルや、`paths:` で適用範囲を指定したスキルが、Bashで深い階層へ移動した後に認識されない不具合が修正されました。

## 基本的な使い方

スキルのfrontmatterで対象パスを指定している場合の例です（書式は説明用の例です）。

```markdown
---
name: api-guidelines
description: APIコードの規約
paths: src/api/**
---
```

## 実践例

### モノレポでのパッケージ別スキル

パッケージごとのスキルを置いていても、Claudeが `cd` で移動した後に正しく見つかります。

### 深い階層での作業

`cd src/api/v2` のように移動した後でも、該当スキルが利用できます。

## 注意点

- スキルの書式は例示です。最新の仕様は公式ドキュメントを確認してください。
