## 原文（日本語訳）

Remote Control使用時に、Fable 5を初めて利用する際の利用クレジット確認プロンプトが、60秒間応答がないと自動的にフォールバックモデルを選択してしまう問題を修正しました。

## 原文（英語）

Fixed the Fable 5 first-time usage-credits prompt auto-selecting the fallback model after 60 seconds with no answer when using Remote Control

## 概要

Fable 5を初めて使用する際、Claude Codeは利用クレジットに関する確認プロンプトを表示し、そのまま利用を続けるかどうかをユーザーに尋ねます。これまでは、Remote Control経由でセッションを操作している場合、このプロンプトに60秒以内で応答しないと自動的にフォールバックモデルへ切り替わってしまい、モバイルアプリやブラウザ側で確認する前に意図しないモデルで処理が進んでしまうことがありました。今回の修正により、Remote Control使用時にはこのタイムアウトによる自動選択が発生しなくなりました。

## 基本的な使い方

Remote Controlでローカルセッションをスマートフォンやブラウザから操作している状態で、Fable 5を初めて使う場面に遭遇すると、利用クレジットに関する確認プロンプトが表示されます。

```
（ローカル端末とスマートフォン/ブラウザをRemote Controlで接続した状態でFable 5を初めて実行）
```

修正前は、通知に気づいてスマートフォンを開くまでの間に60秒が経過すると、意図せずフォールバックモデルが自動選択されてしまい、Fable 5を試すつもりが別のモデルで処理が進んでしまうことがありました。修正後は、Remote Control経由の場合はこの自動フォールバックが発生しないため、実際に確認して選択するまでプロンプトが待機します。

## 実践例

### 外出先でスマートフォンからRemote Control経由で確認する場合

PCで起動したセッションをスマートフォンのClaudeアプリでRemote Control接続して見ているユーザーが、通知に気づくまでに1分以上かかった場合、修正前は気づいた頃にはすでにフォールバックモデルへ切り替わっており、Fable 5を試す機会を逃していました。修正後はユーザーが実際に応答するまでプロンプトが維持されます。

### 複数デバイス間でセッションを行き来している場合

ブラウザのclaude.ai/codeとローカル端末を行き来しながら作業しているユーザーが、初回のFable 5利用クレジット確認をすぐに見られなかった場合でも、修正後は勝手にモデルが切り替わることなく、後から改めて確認・選択できます。

## 注意点

- この修正はRemote Control経由でセッションを操作している場合の挙動に関するものです。ローカル端末で直接プロンプトに応答する通常の利用フローには影響しません。
- タイムアウト自体が撤廃されたわけではなく、Remote Control使用時に60秒での自動フォールバック選択が起きないよう修正されたものです。プロンプトへの応答自体は引き続き必要です。
