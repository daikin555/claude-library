# attributionProject 設定でセッションの課金グループを指定

## 原文（日本語に翻訳）

`attributionProject` 設定で、セッションの課金グループ名を指定できるようになりました。`admin.billing_group_tag` を設定している Claude apps ゲートウェイ向けです。

## 原文（英語）

Added support for naming a session's billing group with the `attributionProject` setting, for Claude apps gateways that set `admin.billing_group_tag`

## 概要

組織が Claude apps ゲートウェイを使い、管理側で `admin.billing_group_tag` を設定している場合、セッションごとに課金先のグループ（プロジェクト）を `attributionProject` で指定できます。コスト配賦をプロジェクト単位で管理したいチームに有用です。

## 基本的な使い方

```json
// .claude/settings.json
{
  "attributionProject": "mobile-app"
}
```

## 実践例

### リポジトリごとに課金先を分ける

各リポジトリの `.claude/settings.json` に別々の値を設定すると、利用料金をプロジェクト別に集計できます。

### 個人用の上書き

```json
// .claude/settings.local.json
{
  "attributionProject": "experiments"
}
```

## 注意点

- ゲートウェイ側で `admin.billing_group_tag` が設定されている場合のみ意味を持ちます。
- 同じ更新で、管理設定が `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` の場合に `x-claude-code-managed-settings-checksum` ヘッダーも送信されるようになりました。
