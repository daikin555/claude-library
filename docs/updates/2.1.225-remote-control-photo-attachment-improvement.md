## 原文（日本語訳）

Remote Control の改善: Claude appから添付された写真が、ディスクから別のツール呼び出しで読み込むのではなく、Claude に直接表示されるようになりました

## 原文（英語）

Improved Remote Control: photos attached from the Claude app are now shown to Claude directly instead of being read from disk with a separate tool call

## 概要

Claude のモバイルアプリから Remote Control セッションに添付した写真が、これまでのようにディスクから読み込むための追加のツール呼び出しを必要とせず、メッセージコンテンツの一部として Claude に直接渡されるようになりました。この改善により、レスポンス速度が向上し、よりシームレスな操作体験が実現されます。

## 基本的な使い方

Claude モバイルアプリから Remote Control セッションに写真を添付するには、以下の手順を実行します：

1. Claude モバイルアプリで Remote Control セッションに接続します（セッションURL またはQRコードをスキャン）
2. メッセージボックスの添付ボタンをタップします
3. デバイスのカメラロールから写真を選択して添付します
4. メッセージを送信すると、写真は自動的に Claude に表示されます

以前は写真がディスクに保存されてから読み込まれていましたが、現在は直接メッセージコンテンツに含まれるため、処理がより速くなります。

## 実践例

### スマートフォンで撮影したエラー画面をデスクトップのセッションで即座に共有

デスクトップで実行している Claude Code セッション中に、スマートフォンでエラーメッセージのスクリーンショットを撮影した場合、Claude アプリから Remote Control セッションに写真を添付するだけで、すぐに Claude がその画像を見てデバッグを支援できます。これまでは写真の読み込みに遅延が発生していましたが、今は瞬時に処理されます。

### ホワイトボードやダイアグラムの写真をリアルタイムで参照しながらコーディング

チーム会議で描いたダイアグラムやホワイトボードの内容を、スマートフォンで撮影して Claude アプリから添付すると、デスクトップのセッションで実装を進める際に、Claude がその内容をダイレクトに参照できます。設計図の細部を確認しながらコードを書く作業が、より効率的になります。

## 注意点

- **高速化のメリット**: 従来は写真を読み込むための個別のツール呼び出しが発生していましたが、今は不要になるため、リクエスト処理が高速化されています
- **Remote Control の可用性**: Team および Enterprise プランでは、管理者が Claude Code 管理設定で Remote Control トグルを有効にする必要があります
- **対応形式**: メジャーな写真形式（JPEG、PNG など）が対応しています。ファイルサイズが大きい場合は、自動的に最適化される場合があります
- **プラットフォーム対応**: iOS および Android の Claude モバイルアプリで利用可能です
