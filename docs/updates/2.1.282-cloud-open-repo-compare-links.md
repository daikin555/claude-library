## 原文（日本語訳）

リポジトリがGitHub以外でホストされているクラウドセッションのリポジトリメニューに、「Open repository」と「Open compare page」のリンクを追加しました。

## 原文（英語）

[Cloud sessions] Added "Open repository" and "Open compare page" links to the repository menu of a cloud session whose repository is hosted on a Git server other than GitHub

## 概要

クラウドセッションはGitHub以外のGitサーバー（GitLabやセルフホストのGitサーバーなど）にホストされているリポジトリでも利用できますが、これまではそうしたリポジトリに対して、Webブラウザでリポジトリ本体や変更差分の比較ページに素早くアクセスする手段がありませんでした。今回の変更で、クラウドセッションのリポジトリメニューに「Open repository」（リポジトリを開く）と「Open compare page」（比較ページを開く）のリンクが追加され、GitHub以外のホスティング環境でもワンクリックで該当ページにアクセスできるようになりました。

## 基本的な使い方

クラウドセッションの画面でリポジトリメニューを開き、「Open repository」または「Open compare page」をクリックします。

## 実践例

### セルフホストGitLabでの変更内容の確認

社内のセルフホストGitLabにあるリポジトリでクラウドセッションを実行した後、生成された変更内容を「Open compare page」からすぐにブラウザで確認できます。

### 複数のGitホスティングサービスを併用する組織での利便性向上

GitHubとGitLabなど複数のGitホスティングサービスを併用している組織でも、どちらのリポジトリでも同じような操作感でリポジトリや差分ページにアクセスできます。

## 注意点

- 表示されるリンクの内容は、実際にリポジトリがホストされているGitサーバーの種類や設定によって異なります
- この機能はクラウドセッションに関するものです
