## 原文（日本語訳）

[VSCode] Manage pluginsダイアログが、マーケットプレイスのURLに入力されたパスワードやトークンをそのまま表示してしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed the Manage plugins dialog showing a password or token that was typed into a marketplace URL

## 概要

プラグインのマーケットプレイスをプライベートリポジトリなどに設定する場合、認証情報を含むURL（例: `https://user:token@example.com/marketplace`）を入力することがあります。これまで、Manage pluginsダイアログはこのURLをそのまま平文で表示してしまい、画面共有時やスクリーンショットなどを通じて認証情報が漏えいするリスクがありました。今回の修正により、URLに含まれるパスワードやトークンはマスクされ、安全に表示されるようになりました。

## 基本的な使い方

マーケットプレイスの追加時にURLを入力する操作自体に変更はありません。

```
> Claude Code: Manage Plugins
```

## 実践例

### 認証情報付きのプライベートマーケットプレイスURLを登録する場合

企業内のプライベートなプラグインマーケットプレイスに、ユーザー名とトークンを含むURLでアクセスするケースです。

```
修正前: https://myuser:ghp_xxxxxxxxxxxx@internal.example.com/marketplace
  → ダイアログにトークンがそのまま平文で表示される

修正後: https://myuser:****@internal.example.com/marketplace
  → トークン部分がマスクされて表示される
```

### 画面共有中にプラグイン管理画面を開く場合

ペアプログラミングやデモなどで画面を共有している際にManage pluginsダイアログを開いても、認証情報が第三者に見えてしまうリスクが軽減されます。

## 注意点

- これはセキュリティ関連の修正のため、拡張機能を最新版に更新することを推奨します。
- 過去に認証情報付きURLを使用していた場合、該当のトークンやパスワードは念のためローテーション（再発行）することを検討してください。
