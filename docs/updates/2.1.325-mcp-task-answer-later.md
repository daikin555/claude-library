# バックグラウンドMCPタスクの質問でEscを押すと「後で回答」になる

## 原文（日本語に翻訳）

バックグラウンドMCPタスクの質問でEscを押すと「後で回答」として扱われるようになりました。サーバーには何も送信されず、質問は `/tasks` に残ります。また、タスクがあなたの回答を待っているときは Claude に通知され、`/tasks` を案内できるようになりました。

## 原文（英語）

Changed Esc on a background MCP task's question to "answer later": nothing is sent to the server, and the question stays in `/tasks`
Improved MCP tasks: Claude is now told when a task is waiting for your answer, and can point you to `/tasks`

## 概要

MCPサーバーのバックグラウンドタスクが質問（elicitation）を出したとき、Escで閉じても質問が失われなくなりました。後から `/tasks` で再表示して回答できます。

## 基本的な使い方

1. タスクが質問を表示したら、今すぐ答えられない場合は Esc を押します。
2. 準備ができたら `/tasks` を開き、Enter で質問を再表示して回答します。

## 実践例

### 作業中に質問が来た場合

入力中のメッセージを邪魔しないよう、質問は下書きを送信または消去するまで待機します。Escで後回しにして作業を続けられます。

### 回答待ちを Claude に気づかせる

タスクが回答待ちのとき、Claude はそれを把握しており、`/tasks` を案内してくれます。

## 注意点

- Escではサーバーに何も送信されません。タスクは回答を待ち続けます。
