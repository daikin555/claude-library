## 原文（日本語訳）

[Claude Tag] Slack上のClaude Tagのリトライ通知を改善。汎用的なAPIエラーではなく、使用中のモデル名またはレート制限に達したことを表示します

## 原文（英語）

[Claude Tag] Improved Claude Tag's retry notice in Slack to name the model in use, or say rate limits were hit, instead of a generic API error

## 概要

リトライ通知から原因が分かりやすくなりました。

## 基本的な使い方

Slackで通知が出たら、モデル名やレート制限の表示で状況を判断します。

## 実践例

### 原因の切り分け

レート制限なら時間を置いて再試行、といった判断ができます。

## 注意点

- 通知内容は状況により異なります。
