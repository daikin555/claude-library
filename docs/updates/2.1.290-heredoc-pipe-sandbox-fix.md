## 原文（日本語訳）

`cat <<EOF | python3` のようにheredocを別のコマンドへパイプするサンドボックス内のコマンドが、実行のたびに承認を求めていた問題を修正した。

## 原文（英語）

Fixed sandboxed commands that pipe a heredoc into another command (`cat <<EOF | python3`) asking for approval on every run

## 概要

サンドボックス有効時に、heredocをパイプする書き方で毎回プロンプトが出ていた問題が解消され、通常どおり動くようになりました。

## 基本的な使い方

```bash
cat <<EOF | python3
print("hello")
EOF
```

## 実践例

### 短いスクリプトの実行

Pythonの短いスクリプトをheredocで流すパターンが、中断なく実行されます。

### データ加工

`cat <<EOF | jq .` のような整形処理にも同様に有効です。

## 注意点

- サンドボックスの制限自体は維持されます。
