# permissions.blockWritesOutsideWorkingDirectories で作業ディレクトリ外への書き込みを禁止する

## 原文（日本語訳）

`permissions.blockWritesOutsideWorkingDirectories` を追加しました。Write、Edit、NotebookEdit は、あらゆる権限モードで作業ディレクトリ外のパスを拒否します。

## 原文（英語）

Added `permissions.blockWritesOutsideWorkingDirectories`: Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode

## 概要

この設定を有効にすると、Write・Edit・NotebookEdit ツールは作業ディレクトリ外のパスへの書き込みを拒否します。権限モードに関わらず常に効くため、意図しない場所へのファイル変更を確実に防げます。

## 基本的な使い方

`settings.json` に次のように記述します。

```json
{
  "permissions": {
    "blockWritesOutsideWorkingDirectories": true
  }
}
```

## 実践例

### 自動承認モードでの安全策

確認の少ないモード（auto mode など）で長時間タスクを走らせる際に有効化すると、プロジェクト外（例: `~/.ssh` や `/etc`）への書き込みを防げます。

### チーム共通ポリシーとして配布

プロジェクトの `.claude/settings.json` にコミットすれば、全員に同じ制限を適用できます。

```json
{
  "permissions": {
    "blockWritesOutsideWorkingDirectories": true,
    "allow": ["Edit(src/**)"]
  }
}
```

### 追加ディレクトリが必要な場合

`--add-dir` や `/add-dir` で追加したディレクトリは作業ディレクトリとして扱われます。必要な場所だけ明示的に追加してください。

## 注意点

- 対象は Write / Edit / NotebookEdit のファイルツールです。Bash 経由のファイル操作はサンドボックス設定など別の仕組みで制御してください。
- 作業ディレクトリ外を編集する必要がある場合は、先にそのディレクトリを追加してください。
