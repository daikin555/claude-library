## 原文（日本語に翻訳）

Bedrock、Mantle、Vertex、Foundry上のClaude Codeが、downloads.claude.ai の署名付きファイルからモデル設定を読み込むように変更しました。無効にするには `CLAUDE_CODE_MODEL_CATALOG=off` を設定します。

## 原文（英語）

Changed Claude Code on Bedrock, Mantle, Vertex, and Foundry to load model settings from a signed file on downloads.claude.ai; set CLAUDE_CODE_MODEL_CATALOG=off to turn this off

## 概要

クラウドプロバイダー経由で利用する場合、モデルに関する設定が downloads.claude.ai の署名付きファイルから取得されるようになりました。新しいモデルへの対応をClaude Codeのアップデートなしで反映しやすくなります。

## 基本的な使い方

```bash
# 無効化する場合
export CLAUDE_CODE_MODEL_CATALOG=off
claude
```

## 実践例

### 閉域ネットワークでの利用

downloads.claude.ai へ到達できない環境や外部通信を制限したい環境では、無効化します。

```bash
CLAUDE_CODE_MODEL_CATALOG=off claude
```

### プロキシ許可リストの更新

有効のまま使う場合は、`downloads.claude.ai` への通信を許可してください。

## 注意点

- ファイルは署名付きです。
- 無効化した場合、モデル設定は同梱の内容が使われると考えられます。詳細は公式ドキュメントを確認してください。
