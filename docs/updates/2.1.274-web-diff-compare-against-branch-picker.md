## 原文（日本語訳）
[Claude Code on the web] クラウドセッションの差分ビューに「Compare against（比較対象）」ブランチピッカーを追加し、変更内容をベースブランチだけでなく任意のブランチと比較できるようになりました。

## 原文（英語）
[Claude Code on the web] Added a "Compare against" branch picker to a cloud session's diff view, so you can diff its changes against any branch instead of only the base branch

## 概要
Claude Code on the web（クラウド版Claude Code）のセッションでは、これまで差分ビューはセッション開始時のベースブランチとの比較しかできませんでした。今回追加された「Compare against」ブランチピッカーにより、任意の別ブランチを選んでその変更内容と比較できるようになりました。これにより、例えば最新のmainブランチとの差分や、別の作業ブランチとの差分を柔軟に確認できるようになります。

## 基本的な使い方
1. Claude Code on the webでクラウドセッションを開く
2. 差分（Diff）ビューを表示する
3. 画面上部の「Compare against」ブランチピッカーをクリックし、比較したいブランチを選択する

## 実践例

### mainブランチが進んだ後の差分確認
長時間実行しているクラウドセッションの間にmainブランチへ他のPRがマージされた場合、「Compare against」で最新のmainを選び直すことで、実際にマージ時に発生する差分をより正確に把握できます。

### 特定の作業ブランチとの比較
チームメンバーが作業している別ブランチ（例: `feature/api-v2`）を比較対象に指定し、自分のセッションの変更がそのブランチとどう異なるかを確認できます。これにより、複数ブランチにまたがる作業の整合性チェックが容易になります。

## 注意点
- 比較対象に選べるのはリポジトリ内に存在するブランチに限られます。
- ベースブランチとの比較がデフォルトの挙動である点は変わりません。必要に応じて明示的に比較対象を切り替えてください。
