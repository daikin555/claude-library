## 原文（日本語訳）
貼り付け・添付された画像を改善：Claude が権限プロンプトなしでファイルとして開ける場所に保存されるようになりました（Desktop や VS Code を含む）

## 原文（英語）
Improved pasted and attached images: they are now saved where Claude can open them as files without a permission prompt, including in Desktop and VS Code

## 概要
これまで、チャットに貼り付けたり添付したりした画像を Claude が改めてファイルとして開こうとすると、権限プロンプトが表示されることがありました。この変更により、画像は Claude があらかじめアクセスを許可された場所に保存されるようになり、Desktop アプリや VS Code 拡張機能を使っている場合でも、余計な確認なしにスムーズに画像を扱えるようになります。

## 基本的な使い方
特別な操作は不要です。通常どおり画像をチャットに貼り付ける、またはファイルとして添付するだけで、Claude が必要に応じてその画像をファイルとして参照・分析できます。

```
# 画像をクリップボードからペースト、またはドラッグ&ドロップ
# → Claude が画像ファイルを直接開いて分析できる
```

## 実践例

### スクリーンショットをそのまま貼り付けて分析させる
```
# スクリーンショットをコピーしてチャットにペースト
「このエラー画面の原因を教えて」
# → 以前は「ファイルを開く権限」の確認が挟まることがあったが、
#   今回の改善でその確認なしに Claude が画像を参照できる
```

### VS Code 拡張機能からデザインカンプを添付する
```
# VS Code の Claude Code パネルに画像をドラッグ&ドロップ
「このデザインに合わせて CSS を実装して」
# → Desktop / VS Code のどちらでも同様にスムーズに動作
```

## 注意点
- 保存場所が変わるだけで、画像の内容や扱い方自体が変わるわけではありません。
- 環境によっては、初回のみ別の許可が必要になる場合があります。
- 大きな画像ファイルを多数貼り付けると、コンテキスト消費が増える点は従来どおりです。
