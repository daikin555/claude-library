## 原文（日本語訳）

プラグインマーケットプレイスのセキュリティを強化しました。制御文字や不可視文字を含む名前は拒否されるようになり、`/plugin` および `claude plugin` の出力に含まれるマーケットプレイス提供のテキストはエスケープ処理されて安全に表示されるようになりました。

## 原文（英語）

Improved plugin marketplace hardening: names containing control or invisible characters are rejected, and marketplace-supplied text in `/plugin` and `claude plugin` output is escape-safe

## 概要

プラグインマーケットプレイスは、プラグイン名や説明文といったサードパーティ提供のテキストを扱います。このようなテキストに制御文字や不可視文字（ゼロ幅文字など）が混入していると、ターミナル上での表示が偽装されたり、意図しない挙動を引き起こしたりするリスクがあります。今回の改善により、名前に制御文字や不可視文字が含まれるプラグイン/マーケットプレイスは登録・インストール時に拒否されるようになり、`/plugin` や `claude plugin` コマンドの出力に表示されるマーケットプレイス提供のテキストもエスケープ処理された安全な形で表示されるようになりました。

## 基本的な使い方

通常通りプラグインマーケットプレイスを追加・利用します。

```
/plugin marketplace add <marketplace-url-or-repo>
/plugin install <plugin-name>@<marketplace-name>
```

もし追加しようとしたマーケットプレイスやプラグインの名前に制御文字や不可視文字が含まれている場合、これらの操作は拒否されます。

## 実践例

### 社外・第三者提供のマーケットプレイスを利用する場合

社外の開発者やコミュニティが公開しているマーケットプレイスを利用する際、悪意を持って不可視文字でターミナル表示を偽装するような名前が使われていても、そのようなマーケットプレイスやプラグインは登録段階で拒否されます。

### `/plugin` コマンドで一覧表示・操作する場合

`/plugin` コマンドでインストール済みプラグインやマーケットプレイスの一覧を表示する際、プラグイン説明文などにエスケープシーケンスが含まれていても、それがそのまま実行されたり表示が乱されたりすることなく、安全にテキストとして表示されます。

### CLIから `claude plugin` サブコマンドを使う場合

スクリプトやCI上で `claude plugin` サブコマンドの出力を扱う場合も、マーケットプレイス提供のテキストがエスケープ処理されているため、出力を解析・表示する際の安全性が高まります。

## 注意点

- 既存の正当なプラグイン名・マーケットプレイス名（通常のASCII文字や一般的なUnicode文字を使ったもの)には影響しません
- この強化はプラグインの内容自体の安全性を保証するものではなく、名前やメタデータの表示・取り扱いに関する防御です。プラグインのコードは依然として信頼できる提供元からのみ導入することが推奨されます
