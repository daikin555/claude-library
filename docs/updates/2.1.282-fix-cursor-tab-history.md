## 原文（日本語訳）

タブを含むプロンプトを履歴から呼び出した際、カーソルがプロンプトの末尾より手前に位置してしまう不具合を修正しました。

## 原文（英語）

Fixed the cursor landing before the end of a prompt recalled from history when the prompt contains a tab

## 概要

上矢印キーなどで過去に入力したプロンプトを履歴から呼び出す際、そのプロンプトにタブ文字が含まれていると、カーソルが本来あるべき末尾ではなく、それより手前の位置に置かれてしまう不具合がありました。今回の修正でこの問題が解消され、タブを含むプロンプトでも正しくカーソルが末尾に配置されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。タブ文字を含むプロンプトを履歴から呼び出す通常の操作の中で、この修正が自動的に適用されます。

## 実践例

### インデント付きコードスニペットの再利用

タブでインデントされたコードスニペットを含むプロンプトを再度呼び出して編集する際、カーソルが末尾に正しく配置されるため、続きをスムーズに入力できます。

### 複雑なテンプレートプロンプトの微調整

タブを使って整形した長いプロンプトテンプレートを履歴から呼び出し、末尾に追記して再送信するような使い方がしやすくなります。

## 注意点

- タブ文字を含まないプロンプトにはこの不具合は影響していませんでした
- vimモードでのカーソル位置の不具合は別の修正で対応されています（[vimモードのカーソル位置に関する修正](./2.1.282-fix-vim-mode-cursor-placement.md)を参照）
