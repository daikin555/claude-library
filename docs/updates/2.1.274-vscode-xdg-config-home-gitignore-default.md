## 原文（日本語訳）
[VSCode] `XDG_CONFIG_HOME` が絶対パスの場合、デフォルトのグローバルgitignoreファイルを `$XDG_CONFIG_HOME/git/ignore` に変更しました。

## 原文（英語）
[VSCode] Changed the default global gitignore file to `$XDG_CONFIG_HOME/git/ignore` when `XDG_CONFIG_HOME` is an absolute path

## 概要
LinuxやmacOSでXDG Base Directory仕様に従って環境変数 `XDG_CONFIG_HOME` を設定しているユーザーの場合、VSCode拡張機能がこれまで参照していたデフォルトのグローバルgitignoreファイルのパスが、Gitの標準的な挙動と一致していませんでした。今回の変更により、`XDG_CONFIG_HOME` が絶対パスとして設定されている場合、Gitの慣例通り `$XDG_CONFIG_HOME/git/ignore` をデフォルトのグローバルgitignoreとして参照するようになりました。これにより、Git本体の設定との整合性が取れます。

## 基本的な使い方
`XDG_CONFIG_HOME` を設定している場合、追加の設定は不要です。以下のような環境変数設定があれば、自動的に該当パスのgitignoreが使われます。

```bash
export XDG_CONFIG_HOME="$HOME/.config"
# この場合、$HOME/.config/git/ignore が参照される
```

## 実践例

### XDG準拠環境でのグローバルgitignore管理
XDG Base Directory仕様に沿って設定ファイルを `~/.config` 配下にまとめて管理しているユーザーは、以下のパスにグローバルなgitignoreルールを記述できます。

```bash
mkdir -p "$XDG_CONFIG_HOME/git"
echo "node_modules/" >> "$XDG_CONFIG_HOME/git/ignore"
echo ".DS_Store" >> "$XDG_CONFIG_HOME/git/ignore"
```

### Git本体の挙動との整合性確認
Gitコマンド自体も `core.excludesFile` が未設定の場合、XDG準拠環境では `$XDG_CONFIG_HOME/git/ignore` をデフォルトのグローバルexcludesファイルとして参照します。今回の修正でVSCode拡張機能もこれに合わせられたため、ターミナルから `git` コマンドを実行した場合と、VSCode拡張機能上での挙動が一致するようになりました。

## 注意点
- `XDG_CONFIG_HOME` が絶対パスとして設定されていない場合はこの変更の対象外です。
- 既に `core.excludesFile` をGit設定で明示的に指定している場合は、そちらの設定が優先されます。
