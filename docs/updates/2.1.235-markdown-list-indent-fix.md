## 原文（日本語訳）

ネストされたMarkdownのリスト項目が深さ3以上で位置ずれする不具合を修正し、ターミナルUI上で折り返されたリスト項目にぶら下げインデント（hanging indent）を追加しました。

## 原文（英語）

Fixed nested markdown list items misaligning at depth 3+ and added a hanging indent to wrapped list items in the terminal UI

## 概要

Claude Codeはレスポンス内のMarkdownをターミナル上で整形して表示しますが、これまでは箇条書きリストを3階層以上ネストすると、インデント幅が崩れて見た目が揃わなくなる不具合がありました。また、1つのリスト項目が長くターミナル幅で折り返される際、2行目以降が箇条書きの記号位置に揃わず読みにくくなる問題もありました。今回の修正で、深いネストのインデント計算が正しくなり、折り返し行にもぶら下げインデントが適用されて、リストのテキスト部分と自然に縦位置が揃うようになりました。

## 基本的な使い方

特別な設定は不要です。Claude Codeが深くネストされたリストや長いリスト項目を含むMarkdownを出力すると、自動的に正しいインデントで表示されます。

```
- レベル1の項目
  - レベル2の項目
    - レベル3の項目（修正前はここでずれていた）
      - レベル4の項目
```

## 実践例

### 詳細な手順書やタスク一覧を出力させる

複雑な作業手順をClaude Codeにネストした箇条書きでまとめてもらう場合、深い階層でも視覚的に整った状態で表示されます。

```
> このリファクタリング計画を段階的なチェックリストにまとめて

- フェーズ1: 準備
  - 依存関係の棚卸し
    - 未使用パッケージの洗い出し
      - package.json の重複チェック
- フェーズ2: 実装
  - モジュール分割
    - 循環参照の解消
```

### 長い説明文を含むリスト項目を確認する

1項目のテキストが長く、ターミナル幅で自動的に折り返される場合でも、2行目以降が箇条書き記号ではなくテキスト部分の開始位置に揃って表示されます。

```
- この項目は非常に長い説明を含んでおり、ターミナルの幅を超えるため
  自動的に折り返されますが、折り返し後の行も適切にインデントされます
```

### コードレビュー結果を箇条書きで受け取る

`/code-review` などでネストした指摘事項リストが返される場合も、階層構造がずれずに表示されるため、どの指摘がどの親項目に属するかを一目で把握できます。

## 注意点

- あくまで表示上の整形に関する修正であり、Markdownの内容自体（テキストやリンク）には影響しません
- 非常に狭いターミナル幅では、深いネストと組み合わさるとリスト記号とテキストの間隔が詰まって見える場合があります
- この修正はターミナルUI（CLI）での表示に関するものです。VS Code拡張やDesktopアプリなど、別レンダラーを使う環境では表示方法が異なる場合があります
