# 解析できないツール呼び出しからの回復を改善（最大2回再試行）

## 原文（日本語に翻訳）

- 解析できないツール呼び出しからの回復を改善：ターンをエラーで終了する前に、Claude Code が呼び出しを最大2回再試行するようになりました

## 原文（英語）

- Improved recovery from unparseable tool calls: Claude Code now retries the call up to twice before ending the turn with an error

## 概要

モデルが出力したツール呼び出しが壊れていて解析できない場合、従来はすぐにエラーで終了することがありました。今回から最大2回まで再試行し、成功すればそのまま作業が続きます。

## 基本的な使い方

設定は不要で、更新のみで有効になります。

## 実践例

### 長時間の自動実行

`claude -p` による CI やバッチ処理で、一時的なツール呼び出しの乱れによる中断が減ります。

## 注意点

- 3回続けて失敗した場合は、従来どおりエラーでターンが終了します。
