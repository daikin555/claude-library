## 原文（日本語訳）

[VSCode] Claudeがツールを実行している最中に完了したバックグラウンドエージェントについて、ウィンドウのリロード後にその完了通知とagent map上の結果が失われてしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed a background agent that finished while Claude was running a tool losing its completion notice, and its result on the agent map, after a window reload

## 概要

バックグラウンドエージェントが完了すると、通知とagent map上に結果が表示されます。しかし、メインのClaudeが別のツールを実行している最中にバックグラウンドエージェントが完了した場合、その状態がうまく保存されず、ウィンドウをリロードすると完了通知とagent map上の結果の両方が失われてしまう不具合がありました。この修正により、リロード後も完了通知と結果が正しく保持されるようになります。

## 基本的な使い方

バックグラウンドエージェントの起動と完了確認は通常通り行えます。完了時には自動的に通知とagent map上の結果が表示されます。

```
> Claude Code: Show Agent Map
```

## 実践例

### メインエージェントがツール実行中にバックグラウンドエージェントが完了する場合

複数のサブエージェントを並行して走らせているとき、メインの処理がツール実行中にバックグラウンドエージェントの一つが先に完了するタイミングです。

```
修正前:
  1. バックグラウンドエージェントが完了（メインはツール実行中）
  2. ウィンドウをリロード
  3. 完了通知・agent map上の結果が消えている

修正後:
  1. バックグラウンドエージェントが完了（メインはツール実行中）
  2. ウィンドウをリロード
  3. 完了通知・agent map上の結果が保持されたまま表示される
```

### 長時間タスクの結果を後から確認する場合

数分〜数十分かかるバックグラウンドタスクの結果を、リロードを挟んで後から確認したいケースでも、正確な結果が失われず参照できます。

## 注意点

- この修正はUIの状態保存・復元ロジックに関するものです。
- 実際のバックグラウンドエージェントの処理結果自体（ファイル変更など）は元々失われていませんが、UI上の可視性が損なわれていました。
