## 原文（日本語訳）
プラグインポリシーがリモートの管理設定から提供される場合に、`installed_plugins.json` がほぼ毎回の起動で書き換えられてしまい、Claude Desktopが開いているすべてのセッションのプラグインを再読み込みしてしまう問題を修正しました。

## 原文（英語）
Fixed `installed_plugins.json` being rewritten on nearly every start-up when plugin policy comes from remote managed settings, which made Claude Desktop reload every open session's plugins

## 概要
`installed_plugins.json` はインストール済みプラグインの状態を管理するファイルです。プラグインのポリシーが組織のリモート管理設定から配信される環境では、このファイルが実際には変更がないにもかかわらずほぼ毎回の起動時に書き換えられてしまう不具合がありました。その結果、Claude Desktopで開いているすべてのセッションのプラグインが不要に再読み込みされ、パフォーマンスやユーザー体験に悪影響を及ぼしていました。今回の修正により、実質的な変更がない場合は `installed_plugins.json` が不要に書き換えられなくなりました。

## 基本的な使い方
リモート管理設定でプラグインポリシーを配信している組織環境で、通常通りClaude Desktopやセッションを起動するだけで修正の恩恵を受けられます。

```
Claude Desktopを起動
→ installed_plugins.json が不要に書き換えられない
→ 既存セッションのプラグインが不要に再読み込みされない
```

## 実践例

### 修正前の挙動
リモート管理下のプラグインポリシーを使う組織では、Claude Desktopを起動するたびに `installed_plugins.json` が実質的な変更なしに書き換えられ、その影響で既存の開いているセッションのプラグインがすべて再読み込みされてしまい、作業が中断されることがありました。

### 修正後の挙動
同じ環境で起動しても、実際にプラグイン構成に変更がない限りファイルは書き換えられず、既存セッションのプラグインが不要に再読み込みされることもなくなりました。

## 注意点
- この修正はリモートの管理設定（マネージドポリシー）でプラグインを配信している組織環境に特有のものです。個人利用では影響が少ない可能性があります。
- 実際にプラグイン構成へ変更があった場合は、引き続き `installed_plugins.json` が更新され、変更が反映されます。
