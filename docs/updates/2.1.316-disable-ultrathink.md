# CLAUDE_CODE_DISABLE_ULTRATHINK で ultrathink キーワードを無効化する

## 原文（日本語訳）

- `ultrathink` キーワードを無効にする `CLAUDE_CODE_DISABLE_ULTRATHINK` を追加

## 原文（英語）

- Added `CLAUDE_CODE_DISABLE_ULTRATHINK`, which turns the `ultrathink` keyword off

## 概要

環境変数 `CLAUDE_CODE_DISABLE_ULTRATHINK` を設定すると、プロンプト中の `ultrathink` キーワードによる思考の強化が行われなくなります。意図せず高い思考量で実行されるのを避けたい場合に有効です。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_ULTRATHINK=1
claude
```

## 実践例

### 文章中に ultrathink という単語が登場する場合

「ultrathink」という語を含む文章を扱うときも、意図しない効果を防げます。

```bash
CLAUDE_CODE_DISABLE_ULTRATHINK=1 claude -p "ultrathink という機能の説明文を校正して"
```

### チーム全体で無効化する

`.claude/settings.json` の `env` に `CLAUDE_CODE_DISABLE_ULTRATHINK` を設定すると、チームで共有できます。

## 注意点

- 設定値の厳密な解釈（`1` 以外の値の扱い）は公式ドキュメントで確認してください。
- 思考量そのものは `/effort` など別の設定で調整します。
