## 原文（日本語訳）

対話セッションのWebSearch上限を、200回で終了する方式から、時間とともに回復する方式（100回/時間）に変更した。`CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR` で回復レートを設定でき、0にすると無効になる。

## 原文（英語）

Changed the interactive session's WebSearch budget to refill over time (100 calls/hour; `CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR` sets the rate, 0 turns it off) instead of ending after 200 calls

## 概要

これまでは1セッションで200回のWebSearchを使い切るとそれ以上検索できませんでした。今回から上限が時間経過で回復するようになり、長時間セッションでも検索を続けられます。

## 基本的な使い方

```bash
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=50
claude
```

## 実践例

### 長時間の調査セッション

デフォルト（100回/時間）のままで、調査を継続できます。

### 回復を無効にする

```bash
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=0
```

## 注意点

- 0を指定すると回復がオフになります。
- 対象は対話セッションです。
