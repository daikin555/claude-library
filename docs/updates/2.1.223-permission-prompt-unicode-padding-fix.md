## 原文（日本語に翻訳）

タブや不可視のUnicode文字でパディングされたコマンドが、承認ダイアログの中でコマンドの一部を隠せてしまう問題を修正し、権限プロンプトを改善しました。

## 原文（英語）

Fixed permission prompts so commands padded with tabs or invisible Unicode can no longer hide part of the command from the approval dialog

## 概要

Claude Codeは、権限が必要なBashコマンドなどを実行する前に、実際に実行される文字列を承認ダイアログに表示してユーザーに確認を求めます。今回修正された問題は、コマンド文字列にタブ文字や、幅を持たない・表示上見えないUnicode文字（ゼロ幅スペースなど）を混ぜ込むことで、承認ダイアログ上でコマンドの一部が見切れたり隠れたりしてしまうというものでした。これにより、ユーザーが表示された内容だけを見て承認した場合、実際には表示されていない別の処理が一緒に実行されてしまう可能性がありました。v2.1.223では、こうした不可視文字やパディングを含むコマンドでも、実行内容がダイアログ上に正しく・省略なく表示されるように修正されています。

## 基本的な使い方

この修正はダイアログの表示ロジックに関するものであり、ユーザー側での設定変更は不要です。アップデート後、権限プロンプトが表示された際にコマンド全文が正確に表示されることを前提に、通常どおり内容を確認してから承認してください。

```bash
# 最新バージョンに更新
claude update
claude --version
```

## 実践例

### 権限プロンプトの内容を必ず目視確認する習慣

修正後も、プロンプトに表示されたコマンドは実行前に必ず読むことが重要です。特に長いコマンドや見慣れない引数が含まれる場合は注意深く確認します。

```bash
# 例：Claudeが提案したコマンドに対する確認プロンプトが表示された場合
# → コマンド全文が省略されずに表示されることを確認したうえで承認する
```

### 疑わしい入力を含むファイルやスクリプトを扱う場合

外部から取得したスクリプトや、コピー＆ペーストしたコマンドをClaudeに実行させる場合、不可視文字が混入している可能性があるため、事前にテキストエディタなどで文字種を確認するとより安全です。

```bash
# 不可視文字の有無を確認する一例（od でバイト列を確認）
echo "$SUSPICIOUS_COMMAND" | od -c | grep -E '\\t|302|342'
```

### 組織内でのセキュリティ運用ルールの見直し

チームで権限プロンプトの承認をポリシーとして運用している場合、今回の修正内容を周知し、引き続き「表示された内容を全て確認してから承認する」運用を徹底することが推奨されます。

```json
{
  "permissions": {
    "ask": ["Bash(curl:*)", "Bash(wget:*)"]
  }
}
```

## 注意点

- 本修正はセキュリティ上重要な変更のため、v2.1.223以降への速やかなアップデートを推奨します。
- どのような不可視Unicode文字・パディングパターンが問題を引き起こしていたかの詳細はchangelogに明記されておらず、本記事でも具体的な再現手順は扱いません。
- 修正後もダイアログの表示を流し読みせず、コマンド全体を確認してから承認する運用は引き続き推奨されます。
- ターミナルやフォントによっては、一部の不可視文字が視覚的に判別しにくい場合があるため、疑わしいコマンドは実行前にテキストとして精査することが望ましいです。
