## 原文（日本語訳）

メッセージを送信した直後に権限モードを切り替えると、クラウドセッション（Claude Code on the web、デスクトップアプリ、モバイルアプリ）で以前の権限モードが表示されてしまうことがある問題を修正しました。

## 原文（英語）

Fixed cloud sessions (Claude Code on the web, desktop and mobile apps) sometimes showing the previous permission mode when you switch modes right after sending a message

## 概要

Claude Codeには、通常モードや計画モードなど複数の権限モードがあり、ユーザーはいつでも切り替えることができます。しかし、Claude Code on the webやデスクトップ/モバイルアプリのようなクラウドセッションでは、メッセージを送信した直後というタイミングで権限モードを切り替えると、切り替え処理とメッセージ送信処理の間で競合が発生し、実際には新しいモードに切り替わっているにもかかわらず画面には古いモードが表示されたままになることがありました。今回の修正でこの表示上の不整合が解消されました。

## 基本的な使い方

クラウドセッションでメッセージを送信した直後に、権限モードの切り替えUIから別のモード（例: 計画モード）を選択します。

修正後は、切り替え直後の表示にも正しく新しい権限モードが反映されます。

## 実践例

### メッセージ送信後すぐに計画モードへ切り替える

タスクを依頼するメッセージを送った直後に「計画モードに切り替えたい」と考えて素早く操作した場合でも、UI上に表示されるモードが実際の状態と一致するようになります。

### モバイルアプリでの操作

モバイル端末からの操作はタップの間隔が短くなりがちですが、送信とモード切り替えを連続して行っても表示のズレが発生しなくなります。

### 複数クラウドセッションを並行管理している場合

Claude Code on the webで複数セッションを切り替えながら操作している際、各セッションの権限モード表示を信頼して次の操作を判断できるようになります。

## 注意点

- この問題は表示上の不整合であり、実際に適用されていた権限モード自体が誤って動作していたわけではありませんが、ユーザーが誤った表示を信じて誤操作するリスクがありました
- 対象はクラウドセッション（Claude Code on the web、デスクトップアプリ、モバイルアプリ）です。ローカルのCLIセッションには元々この問題はありません
