## 原文（日本語に翻訳）
プランにFableが含まれているにもかかわらず、古いキャッシュにラベルが焼き込まれていたことが原因で、Fableモデルの行に「使用クレジットが必要です（Requires usage credits）」と表示されてしまう不具合を修正しました。

## 原文（英語）
Fixed the Fable model row showing "Requires usage credits" for plans that include it, when a stale cache had baked the label in

## 概要
Claude Codeの `/model` コマンドで開くモデル選択メニューには、Claude Fable（`claude-fable-5` など）を含む各モデルの行に、プランに応じて追加の使用クレジットが必要かどうかを示すラベルが表示されます。今回の修正前は、クライアント側に保持されているプラン情報のキャッシュが古いまま残ってしまうケースがあり、実際にはプランにFableが含まれていて追加クレジットが不要なユーザーに対しても「Requires usage credits」という誤ったラベルが表示されてしまう問題がありました。v2.1.219ではキャッシュの扱いが改善され、常に最新のプラン情報に基づいてラベルが表示されるようになりました。

## 基本的な使い方
修正の適用を確認するには、Claude Codeを最新バージョンに更新した上で `/model` コマンドを実行し、モデル選択メニューでFableの行を確認します。

```
/model
```

メニューが開いたら、`claude-fable-5` などFableの行にカーソルを合わせ、契約プランに応じたラベルが正しく表示されているかを確認します。

## 実践例

### バージョンを確認してから `/model` で表示を確認する
まずインストールされているClaude Codeのバージョンが2.1.219以降であることを確認します。

```bash
claude --version
```

バージョンが古い場合はアップデートします。

```bash
claude update
```

更新後に `/model` を実行し、Fableの行に表示されるラベルを確認します。プランにFableが含まれている場合、「Requires usage credits」ラベルは表示されず、そのまま選択可能な状態になっているはずです。

### 表示がおかしいと感じたときにキャッシュをリフレッシュする
バージョンアップ後も古いラベルが表示され続ける場合は、一度ログアウトしてから再ログインすることで、プラン情報のキャッシュを強制的に再取得できます。

```
/logout
/login
```

再ログイン後にもう一度 `/model` を開き、ラベルが更新されているかを確認してください。

### スクリプトやCIでFableモデルの利用可否を検証する
自動化スクリプトの中でFableモデルが問題なく利用できるかを確認したい場合は、`--model` フラグで明示的に指定して起動し、想定外のエラーや警告が出ないことを確認します。

```bash
claude --model claude-fable-5 -p "動作確認用の簡単な質問"
```

「Requires usage credits」に関連するエラーメッセージが表示される場合は、契約プランの内容とClaude Codeのバージョンをあわせて確認してください。

## 注意点
- 本修正はあくまで表示上のラベルに関する不具合修正であり、Fableの利用条件そのもの（プランごとに追加クレジットが必要かどうか）を変更するものではありません。
- 修正の適用にはClaude Codeのアップデートが必要です。古いバージョンを使い続けている場合、同じ表示バグが再発する可能性があります。
- アップデート後もラベルが更新されない場合は、ローカルに保存されているプラン情報のキャッシュが古いままになっている可能性が高いため、再ログインを試してください。
- 画面上のラベルはあくまで参考情報です。実際の請求内容やクレジット消費については、契約しているプランの詳細ページで最終確認することをおすすめします。
