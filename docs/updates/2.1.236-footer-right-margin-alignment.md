## 原文（日本語訳）

右寄せで表示されるフッター項目（ゴールインジケーター、セッション状態、バックグラウンドエージェントの状態）と、切り詰められた通知の右マージンが、プロンプト領域の他の要素と統一された値になりました。

## 原文（英語）

Right-aligned footer items (goal indicator, session state, background agent status) and truncated notices now share a consistent right margin with the rest of the prompt area

## 概要

Claude Codeのフッターには、現在のゴール（目標）の進捗を示すインジケーターや、セッションの状態、バックグラウンドで動いているエージェントの状態などが右寄せで表示されます。また、表示しきれない通知が省略記号で切り詰められて表示されることもあります。これまではこうした右寄せ要素や切り詰め通知の右端の余白（マージン)が、プロンプト枠など他の表示領域の右マージンと微妙に異なっていました。今回の修正でこれらの右マージンが統一され、画面全体の余白にずれのない、一貫した見た目になりました。

## 基本的な使い方

これは表示上の調整であり、特別な操作は不要です。通常どおりClaude Codeを使用していると、ゴールインジケーターやセッション状態、バックグラウンドエージェントの状態、あるいは長い通知が省略されて表示される際に、右端の余白がプロンプト枠や他のフッター要素と揃って表示されます。

```
claude
```

## 実践例

### ゴールを設定して作業を進めている場合

ゴールを設定してタスクを進めていると、フッター右側にゴールの進捗インジケーターが表示されます。修正後はこの表示の右端が、プロンプト領域全体の右端と同じマージンで揃うようになります。

### バックグラウンドでサブエージェントが動いている場合

バックグラウンドエージェントが稼働中は、その状態を示す表示がフッターの右側に現れます。長い通知文が省略記号で切り詰められる場合も含め、右端の余白が他の要素と統一されているため、画面全体がより整然として見えます。

## 注意点

- 機能面での変更はなく、右マージンの見た目を統一するだけの修正です
- ゴールインジケーターやセッション状態、バックグラウンドエージェント状態そのものの表示ロジックや情報量は変わりません
