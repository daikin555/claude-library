## 原文（日本語訳）

Mantle: メインループで使用するモデルがすでに確定している場合、起動時のadmin-pin（管理者ピン）可用性チェックをスキップするようになりました

## 原文（英語）

Mantle: skip the admin-pin availability probe at startup when a main-loop model is already picked

## 概要

Amazon Bedrock powered by Mantleを利用する構成（`CLAUDE_CODE_USE_MANTLE=1`）では、起動時にメインループで使うモデルの可用性を確認するための処理が走ります。これまでは、使用するモデルがすでに確定している場合でも、admin-pin（管理者による固定モデル指定）が利用可能かどうかを探索するための余分な起動時チェックが毎回実行されていました。今回の修正により、メインループのモデルがすでに決まっているケースではこの探索処理がスキップされ、起動がより高速になります。

## 基本的な使い方

Mantle経由でClaude Codeを利用しているユーザーに自動的に適用される内部的な最適化です。特別な設定変更は不要です。

```bash
export CLAUDE_CODE_USE_MANTLE=1
claude
```

モデルが明示的に指定されている、または環境設定からすでに一意に確定している場合、起動時の不要なadmin-pin探索処理がスキップされます。

## 実践例

### モデルを明示指定して起動する場合の高速化

```bash
export CLAUDE_CODE_USE_MANTLE=1
claude --model claude-sonnet-5
```

モデルが明示的に指定されているため、起動時に不要なadmin-pinの可用性確認をスキップし、より速く対話を開始できます。

### 頻繁に起動・再起動するCI/バッチ用途での恩恵

Mantle環境でClaude Codeを繰り返し起動するようなCIパイプラインやバッチ処理では、1回あたりの起動時間短縮が積み重なり、全体の実行時間短縮につながります。

## 注意点

- この最適化はMantle（`CLAUDE_CODE_USE_MANTLE=1`）を利用している場合にのみ関係します
- メインループのモデルが確定していない設定（admin-pinによる動的なモデル選択に依存している構成）では、従来どおり探索処理が行われます
- 挙動自体（最終的に使用されるモデル）は変わらず、あくまで起動時間の短縮です
