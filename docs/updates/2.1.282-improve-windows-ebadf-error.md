## 原文（日本語訳）

トランスクリプトファイルが読み込めない（EBADF）ためにセッションを再開できない場合にWindowsで表示されるエラーを改善しました。考えられる原因と試すべき対処法が明示されるようになりました。

## 原文（英語）

Improved the error shown on Windows when a session can't be resumed because its transcript file could not be read (EBADF): it now names possible causes and what to try

## 概要

Windows環境で、セッションのトランスクリプト（会話記録）ファイルが何らかの理由で読み込めなくなり、`EBADF`（不正なファイルディスクリプタ）エラーによってセッションを再開できない場合がありました。これまではエラーメッセージが技術的すぎて、ユーザーが次に何をすべきか分かりにくい状態でした。今回の改善で、考えられる原因（ファイルの破損、権限の問題、他プロセスによるロックなど）と、それぞれに対して試すべき対処法がエラーメッセージ内に明示されるようになりました。

## 基本的な使い方

セッション再開時にこのエラーが表示された場合、メッセージに記載された対処法（ファイルの再確認、権限の見直し、別プロセスの終了など）を順に試してください。

```bash
claude --resume
```

## 実践例

### クラウド同期ツールを使うWindows環境でのトラブルシューティング

OneDriveなどのクラウド同期ツールがトランスクリプトファイルをロックしてしまう環境でも、エラーメッセージから原因を推測しやすくなり、自己解決がしやすくなります。

### ウイルス対策ソフトによるファイルロックの切り分け

セキュリティソフトが一時的にファイルをスキャン・ロックしている場合など、Windows特有の要因によるエラーの原因究明にかかる時間を短縮できます。

## 注意点

- この改善はエラーメッセージの分かりやすさを向上させるものであり、根本的なファイルアクセスの問題自体を解決するものではありません
- Windows以外のOSでは元々異なるエラーハンドリングが行われています
