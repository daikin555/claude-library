# /model ピッカーの「More models」を番号なし行に変更

## 原文（日本語に翻訳）

- `/model` ピッカーを改善：「More models」を他のすべての行の下に表示される番号なしの行にし、古いモデルはその下で開くようになった。他の番号は振り直されない

## 原文（英語）

- Improved the `/model` picker: "More models" is now an unnumbered row below every other, and older models open under it without renumbering the rest

## 概要

`/model` ピッカーで、古いモデルを開いても主要なモデルの番号が変わらなくなりました。番号キーで選ぶ操作が安定します。

## 基本的な使い方

```text
> /model
```

一覧の番号キーで選択できます。古いモデルは最下部の「More models」を開いて選びます。

## 実践例

### 番号でのすばやい切り替え

主要モデルの番号が固定されるため、毎回同じキーで切り替えられます。

### 古いモデルの選択

```text
> /model
（「More models」を開き、古いモデルを選択）
```

## 注意点

- 「More models」自体には番号がないため、矢印キーで選択してください。
- モデルを直接指定するなら `/model <モデル名>` も使えます。
