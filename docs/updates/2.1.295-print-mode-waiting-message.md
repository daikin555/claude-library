# claude -p の待機理由を stderr に表示

## 原文（日本語に翻訳）

stderr が端末の場合、`claude -p` の実行が最後のターンの後も開いたままのときに、何を待っているかを示す行を stderr に表示するようにしました。

## 原文（英語）

Added a line on stderr, when it is a terminal, that says what a `claude -p` run is waiting for when it stays open after its last turn

## 概要

バックグラウンドタスクが残っているなどの理由で `claude -p` がすぐ終了しない場合、原因が分からず固まったように見える問題がありました。今回の変更で、待機の理由が stderr に表示されるようになります。

## 基本的な使い方

```bash
claude -p "テストを実行して結果を要約して"
```

終了しない場合、stderr に待機理由が表示されます。

## 実践例

### 手元での原因調査

スクリプトを組む前に `claude -p` を試す際、終了しない理由をすぐ把握できます。

### バックグラウンド処理を含むプロンプトの確認

バックグラウンドの作業が完了するのを待っている場合、その旨が分かります。

## 注意点

- stderr が端末でない場合（パイプやファイルへのリダイレクト時）は表示されません。
