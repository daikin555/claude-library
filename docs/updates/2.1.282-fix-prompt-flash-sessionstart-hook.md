## 原文（日本語訳）

`SessionStart` フックを持つプロジェクトで、起動時にプロンプトのサンプルテキストがちらついて消える不具合を修正しました。

## 原文（英語）

Fixed the prompt's example text flashing and disappearing at startup in projects with a `SessionStart` hook

## 概要

`SessionStart` フックを設定しているプロジェクトでClaude Codeを起動すると、フックの実行が完了するまでの間、入力欄に表示されるサンプルのプレースホルダーテキスト（使い方のヒントなど）が一瞬表示されてすぐに消えるという視覚的なちらつきが発生していました。今回の修正でこの表示の不安定さが解消され、より滑らかな起動体験になりました。

## 基本的な使い方

ユーザー側の対応は不要です。`SessionStart` フックを設定しているプロジェクトで、通常通りClaude Codeを起動するだけです。

```json
{
  "hooks": {
    "SessionStart": [{ "hooks": [{ "type": "command", "command": "echo ready" }] }]
  }
}
```

## 実践例

### 環境セットアップ用フックを持つプロジェクトでの起動体験向上

`SessionStart` フックでプロジェクト固有のコンテキストを読み込むような構成のプロジェクトでも、起動時の画面がちらつかず快適に作業を始められます。

### デモや画面共有時の見栄え改善

チームメンバーへのデモや画面共有をしながらClaude Codeを起動する場面でも、不要な表示のちらつきがなくなり、洗練された印象を与えられます。

## 注意点

- これは純粋に見た目上の修正であり、`SessionStart` フック自体の動作やタイミングには影響しません
- `SessionStart` フックを設定していないプロジェクトではこの不具合は発生していませんでした
