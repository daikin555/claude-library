## 原文（日本語に翻訳）

Claude Opus 5（`claude-opus-5`）が追加されました。これはデフォルトのOpusモデルとなり、100万トークンのコンテキストウィンドウに対応します。fast mode利用時の価格は、入力100万トークンあたり10ドル、出力100万トークンあたり50ドルです。

## 原文（英語）

Added Claude Opus 5 (`claude-opus-5`), now the default Opus model — 1M context, fast mode at $10/$50 per Mtok

## 概要

Claude Opus 5は、Claude Codeにおける新しいデフォルトのOpusモデルです。最大の特徴は100万トークン（1M）まで拡張されたコンテキストウィンドウで、大規模なリポジトリ全体や長い会話履歴を保持したまま作業を続けられます。また、`/fast` によるfast modeを利用すると、入力$10 / 出力$50 per Mtokという価格でより高速な応答が得られます。

## 基本的な使い方

```bash
/model
```

`/model` を実行してモデル選択メニューを開き、`claude-opus-5` を選択するだけで、以降のセッションでOpus 5が使用されます。すでにOpusを選択している場合は、次回起動時から自動的にOpus 5がデフォルトとして使われます。

## 実践例

### モデルをOpus 5に明示的に切り替える

```bash
/model claude-opus-5
```

対話モードで `/model` にモデルIDを直接指定すると、確認プロンプトなしで即座に切り替えられます。CI環境やスクリプトから起動する場合は、環境変数でも指定できます。

```bash
export ANTHROPIC_MODEL=claude-opus-5
claude
```

### 大規模リポジトリ解析でfast modeを併用する

```bash
/model claude-opus-5
/fast
```

1Mコンテキストを活かして、複数モジュールにまたがる大規模なコードベースを一度に読み込ませつつ、`/fast` でfast modeを有効化すると、通常より低いレイテンシで実装提案や差分説明を受け取れます。応答速度を優先したいレビューや、対話的なデバッグセッションに向いています。

```bash
/fast
/code-review
```

### 長時間セッションでのコンテキスト温存

```bash
/model claude-opus-5
```

長時間にわたるペアプログラミングやマイグレーション作業では、会話やファイル読み込みが積み重なってコンテキストが圧迫されがちです。Opus 5の1Mコンテキストウィンドウを使うことで、`/compact` の頻度を減らし、過去のやり取りを保持したまま作業を継続できます。

## 注意点

- fast modeの価格（入力$10 / 出力$50 per Mtok）は通常モードとは異なる料金体系です。大量のトークンを消費するタスクでは、事前にコストを見積もっておくことを推奨します。
- 1Mコンテキストウィンドウはモデル自体の対応範囲であり、実際に利用可能な最大コンテキスト長はプランやAPIの設定によって制限される場合があります。
- 既存のワークフローで特定のOpusバージョンに依存している場合は、`/model` で明示的にモデルIDを指定し、意図しないデフォルト変更の影響を受けないようにしてください。
- fast modeは応答速度を優先するモードのため、非常に複雑な推論タスクでは通常モードの方が精度面で有利な場合があります。用途に応じて使い分けてください。
