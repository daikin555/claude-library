## 原文（日本語訳）

フルスクリーンモードにおいて、Escキーがマウスによるテキスト選択を解除しないように変更しました。Escキーは従来どおり処理の中断・ダイアログの閉じるなどの動作を行い、テキスト選択はハイライトされたまま維持されます

## 原文（英語）

Changed Esc in fullscreen mode to no longer clear a mouse text selection: it interrupts or dismisses as usual and the selection stays highlighted

## 概要

Claude Codeのフルスクリーンモードでは、ターミナル上の出力をマウスでドラッグして選択できます。これまでは、選択中にEscキーを押すと、本来の「処理を中断する」「ダイアログを閉じる」といった動作に加えて、意図せずテキスト選択も解除されてしまっていました。この修正により、Escキーは従来どおりの中断・キャンセル動作のみを行い、マウスで選択した範囲のハイライトはそのまま維持されるようになります。

## 基本的な使い方

特別な操作は不要です。フルスクリーンモードでマウスによりテキストを選択した状態のまま、Escキーで実行中の処理を中断したりダイアログを閉じたりできます。選択範囲は解除されません。

```bash
claude
# フルスクリーンモードで動作中
```

1. 出力されたテキストをマウスでドラッグして選択
2. その状態でEscキーを押して、実行中の処理を中断
3. テキスト選択はハイライトされたまま残る

## 実践例

### エラーメッセージをコピーしつつ処理を止める

```bash
claude
# 長いコマンド実行中にエラーが表示される
```

エラーメッセージをマウスで選択している最中に、別の処理を止めたくてEscを押しても、以前は選択が消えてコピーし直しになっていました。修正後は選択が維持されたまま処理だけが中断されるため、そのままコピーできます。

### ダイアログを閉じつつ選択済みテキストを保持

確認ダイアログが表示された状態で、事前に選択していたログの一部をコピーしたい場合、Escでダイアログを閉じても選択範囲が保持されるため、そのままクリップボードにコピーできます。

### 長い出力からの部分コピー作業中の中断

大量のログ出力をスクロールしながら選択している途中で誤って別の処理が走ってしまった場合も、Escで中断してから選択済み範囲をそのままコピーできます。

## 注意点

- この変更はフルスクリーンモードでの挙動です
- Esc自体の「処理の中断」「ダイアログを閉じる」という機能は変わりません
- 選択範囲を明示的に解除したい場合は、通常どおりターミナル上の別の場所をクリックするなどの操作が必要です
