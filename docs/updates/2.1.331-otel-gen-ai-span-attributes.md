# llm_request トレースに gen_ai.* 属性を追加

## 原文（日本語に翻訳）

`claude_code.llm_request` のトレーススパンに `gen_ai.usage.*`、`gen_ai.response.model`、`gen_ai.operation.name` を追加しました。`gen_ai.usage.input_tokens` にはプロンプトキャッシュのトークンも含まれます。

## 原文（英語）

Added `gen_ai.usage.*`, `gen_ai.response.model` and `gen_ai.operation.name` to `claude_code.llm_request` trace spans; `gen_ai.usage.input_tokens` includes prompt cache tokens

## 概要

OpenTelemetry の GenAI セマンティック規約に沿った属性がスパンに付くため、既存の観測基盤でトークン使用量やモデル別の分析がしやすくなります。

## 基本的な使い方

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
claude
```

## 実践例

### モデル別トークン使用量の集計

トレースバックエンドで `gen_ai.response.model` ごとに `gen_ai.usage.input_tokens` を集計すれば、モデル別のコスト傾向を把握できます。

## 注意点

- `gen_ai.usage.input_tokens` にはキャッシュ分が含まれるため、キャッシュを除いた値と直接比較しないでください。
- トレースのエクスポート設定は公式ドキュメントを参照してください。
