# CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP でループ状のクロス証明書を保持する

## 原文（日本語訳）

- 互いに認証し合ってループを成すシステムのクロス証明書を保持する `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` を追加（プライベート CA がそれを必要とするサーバー向け）

## 原文（英語）

- Added `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` to keep system cross-certificates that certify each other in a loop, for servers whose private CA needs one

## 概要

通常、互いに認証し合ってループになっているシステムのクロス証明書は除外されます。プライベート CA がそのような証明書を必要とするサーバーに接続する場合、この環境変数で除外を無効にできます。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP=1
claude
```

## 実践例

### 社内 CA 環境での TLS エラー解消

通常の設定で証明書エラーになる社内サーバーに接続するときに試します。

## 注意点

- 必要な場合のみ有効にしてください。
- 同じバージョンで SSL 証明書エラーのメッセージも改善され、原因と対処が示されます。
