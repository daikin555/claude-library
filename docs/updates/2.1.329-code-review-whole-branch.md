## 原文（日本語訳）

ほとんどのモデルで、ターゲットなしの `/code-review` がデフォルトブランチに対するブランチ全体をレビューするよう変更し、複数コミットのブランチでdiffが失われる問題も修正しました。

## 原文（英語）

Changed `/code-review` with no target on most models to review the whole branch against the default branch, and fixed it losing the diff on multi-commit branches

## 概要

引数なしの `/code-review` は、デフォルトブランチとの差分全体を対象にレビューします。あわせて、`/code-review <PR番号>` はチェックアウト中のブランチを黙ってレビューせず、`gh pr diff` でPRを読み取るようになりました（取得できない場合はその旨を表示）。`--fix` 付きやPR URL指定で `gh pr diff` が拒否・失敗した場合は、レビューせずに停止します。

## 基本的な使い方

```
/code-review
/code-review 123
/code-review 123 --fix
```

## 実践例

### PR作成前のセルフレビュー

機能ブランチで `/code-review` を実行し、複数コミットを含む変更全体を確認します。

### 他人のPRのレビュー

`/code-review 123` で、手元のブランチに関係なく該当PRを対象にします。

## 注意点

- PR指定には `gh` CLI が必要です。
- 挙動の変更は「ほとんどのモデル」が対象です。
