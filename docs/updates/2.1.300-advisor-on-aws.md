# Claude Platform on AWS で /advisor が使えるように

## 原文（日本語に翻訳）

Claude Platform on AWS で `/advisor` を追加しました。`/advisor`、`advisorModel`、`--advisor` で選ぶまでアドバイザーは動作しません。`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効化できます。

## 原文（英語）

Added `/advisor` on Claude Platform on AWS; no advisor runs until you pick one with `/advisor`, `advisorModel` or `--advisor`, and `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` turns it off

## 概要

AWS 上の Claude Platform でもアドバイザー機能を利用できるようになりました。明示的に選択するまで何も動作せず、環境変数で完全に無効化もできます。

## 基本的な使い方

```bash
# 起動時に指定
claude --advisor <モデル名>

# セッション中は /advisor で選択
```

## 実践例

### 組織で無効化する

```bash
export CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1
```

### 設定ファイルで既定を決める

`advisorModel` を settings.json に指定すると、既定のアドバイザーを決められます。

## 注意点

- 選ぶまでアドバイザーは実行されません。
- 指定できるモデルは公式ドキュメントで確認してください。
