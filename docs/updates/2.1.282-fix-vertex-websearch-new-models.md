## 原文（日本語訳）

Vertex AI: Claude Codeがまだ認識していない新しくリリースされたモデルなどで、Web検索が提供されていなかった不具合を修正しました。

## 原文（英語）

Vertex AI: Fixed web search not being offered for models Claude Code doesn't recognize yet, such as newly released ones

## 概要

Google Cloud Vertex AI（Agent Platform）経由でClaude Codeを利用している場合、新しくリリースされたばかりのモデルはClaude Code側でまだ「既知のモデル」として認識されておらず、その結果Web検索ツールが提供されないという問題がありました。今回の修正で、未認識のモデルであってもVertex AI経由でWeb検索が利用できるようになりました。

## 基本的な使い方

Vertex AI経由でClaude Codeを設定し、新しいモデルを指定して起動します。

```bash
export CLAUDE_CODE_USE_VERTEX=1
claude --model <新しいモデルID>
```

Web検索が必要なタスクでも、通常通りツールが提供されます。

## 実践例

### 新モデルのリリース直後の先行利用

Anthropicが新モデルをリリースした直後、Claude Code側のアップデートを待たずにVertex AI経由でいち早くそのモデルを試す際にも、Web検索を含めたフル機能を利用できます。

### 最新情報の調査タスク

新モデルを使って最新のライブラリ情報やドキュメントを調査するタスクでも、Web検索が使えないことによる機能制限を受けません。

## 注意点

- この修正はVertex AI（Google Cloud Agent Platform）経由の利用に特有のものです
- モデルの認識自体はClaude Codeのアップデートで随時追加されていくため、常に最新版を利用することを推奨します
