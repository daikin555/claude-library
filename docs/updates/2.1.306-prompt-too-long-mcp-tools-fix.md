# MCP ツールが多いセッションで API エラーが「prompt is too long」に置き換わる問題を修正

## 原文（日本語に翻訳）

- MCP ツールが多いセッションで、API エラーが「prompt is too long」に置き換わり、不要なコンパクションが発生する問題を修正

## 原文（英語）

- Fixed an API error being replaced by "prompt is too long", and an unneeded compaction, in sessions with many MCP tools

## 概要

多数の MCP ツールを接続していると、実際の API エラーが「prompt is too long」と誤表示され、不要なコンパクションも走っていました。本来のエラーが表示され、無駄なコンパクションも起きなくなります。

## 基本的な使い方

更新のみで反映されます。

## 実践例

### 多数の MCP サーバーを接続している環境

原因の切り分けが正確になり、不要なコンパクションによる文脈の損失を避けられます。

## 注意点

- ツール定義が実際にコンテキストを圧迫している場合は、使わない MCP サーバーの無効化も検討してください。
