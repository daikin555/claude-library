## 原文（日本語訳）
Bedrock、Vertex、Foundry、およびテレメトリ無効のインストールでも、他のインストールと同様に、デフォルトでダイレクトHTTPサーバーに対してv2 MCPクライアントとMCP 2026-07-28ネゴシエーションを使用するように変更されました（無効化するには `MCP_SDK_GENERATION=v1` または `MCP_PROTOCOL_NEGOTIATION=legacy` を使用）。

## 原文（英語）
Changed Bedrock, Vertex, Foundry and telemetry-disabled installs to use the v2 MCP client and MCP 2026-07-28 negotiation with direct HTTP servers by default, as other installs already do (opt out: `MCP_SDK_GENERATION=v1` or `MCP_PROTOCOL_NEGOTIATION=legacy`)

## 概要
これまでBedrock、Vertex AI、Foundry経由のインストールやテレメトリを無効化した環境では、MCP（Model Context Protocol）のクライアント実装が旧世代のv1のままでした。今回の変更により、これらの環境でも他の通常インストールと同様に、v2 MCPクライアントとMCP 2026-07-28プロトコルネゴシエーションがダイレクトHTTP接続のMCPサーバーに対してデフォルトで有効になります。これにより、企業向けデプロイでもMCPサーバーとの通信の一貫性と新機能の恩恵を受けられるようになります。

## 基本的な使い方
特別な設定は不要です。Bedrock/Vertex/Foundry経由でClaude Codeを使用している場合、ダイレクトHTTP接続のMCPサーバーは自動的にv2クライアントで動作します。

```bash
# 通常通りMCPサーバーを設定するだけでv2クライアントが使われる
claude mcp add my-server https://example.com/mcp
```

## 実践例

### 従来の挙動に戻したい場合
何らかの理由でv1クライアントの挙動が必要な場合は、環境変数でオプトアウトできます。

```bash
export MCP_SDK_GENERATION=v1
claude
```

### プロトコルネゴシエーションのみをレガシーに戻す場合
クライアント自体はv2のままで、ネゴシエーション部分だけ旧仕様にしたい場合は次のようにします。

```bash
export MCP_PROTOCOL_NEGOTIATION=legacy
claude
```

## 注意点
- この変更はBedrock、Vertex、Foundry経由のインストール、およびテレメトリ無効化インストールに限定されており、対象は「ダイレクトHTTPサーバー」接続です。
- オプトアウト用の環境変数は一時的な回避策であり、将来的に廃止される可能性があるため、問題が解決したら通常のデフォルト設定に戻すことが推奨されます。
- エンタープライズ環境でMCPサーバーとの接続に問題が発生した場合は、まずこの変更が影響していないか確認するとよいでしょう。
