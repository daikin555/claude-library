## 原文（日本語に翻訳）

完了したバックグラウンドエージェントを再開（resume）した際に表示されるメッセージを短縮しました。

## 原文（英語）

Shortened the message shown when resuming a completed background agent

## 概要

これはUI表示の改善です。すでに完了しているバックグラウンドエージェント（サブエージェント）を再開しようとした際、Claude Codeはその旨をメッセージとして表示していましたが、従来のメッセージは冗長で会話やパネルのスペースを必要以上に占有していました。今回の変更でこのメッセージが短縮され、必要な情報を保ったまま、より簡潔に表示されるようになりました。

## 基本的な使い方

この変更はメッセージ表示の簡略化であり、ユーザー側の操作は変わりません。完了済みのバックグラウンドエージェントに対して再開の操作を行った際に、短縮されたメッセージが表示されます。

```
/tasks
# 完了済みのタスク一覧から対象を選んで再開を試みる
```

## 実践例

### 完了済みタスクを一覧から誤って再開しようとした場合

`/tasks` で過去に完了したバックグラウンドタスクの一覧を見ている際に、すでに終わっているタスクを再開しようとすると、以前は長い説明文が表示されていましたが、今後は簡潔なメッセージで状況がすぐに把握できます。

```
/tasks
# 完了済みのエージェントを選択して再開を試みる
# → 短縮されたメッセージが表示される
```

### 多数の完了済みバックグラウンドエージェントを扱っている場合

並行して多くのサブエージェントを走らせるワークフローでは、完了済みのものを再開しようとする操作が頻繁に発生することがあります。メッセージが短縮されたことで、会話やパネルの表示がすっきりし、他の情報を確認しやすくなります。

### スクリプトやルーチンから繰り返しバックグラウンドタスクを扱う場合

`/loop` などで定期的にバックグラウンドタスクの状態を確認・操作するようなワークフローでも、表示が簡潔になることでログや履歴を追いやすくなります。

## 注意点

- これは表示メッセージの簡略化のみであり、完了済みバックグラウンドエージェントを再開できない、という基本的な制約自体に変更はありません。
- 完了済みのエージェントの結果を確認したい場合は、引き続き `/tasks` などから内容を参照できます。
