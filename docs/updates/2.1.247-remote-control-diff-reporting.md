## 原文（日本語訳）

`/remote-control` で開始したRemote Controlセッションが、接続先クライアントに作業ツリーの差分を報告していなかった問題を修正しました。

## 原文（英語）

Fixed Remote Control sessions started with `/remote-control` not reporting the working-tree diff to connected clients

## 概要

Remote Controlは、Claude Codeのセッションを別のデバイスやクライアントから確認・操作できる機能です。通常、接続中のクライアントにはセッションが行った変更の差分（working-tree diff）が表示されますが、`/remote-control` コマンドで開始したセッションに限り、この差分が接続先クライアントに報告されないという不具合がありました。今回の修正でこの経路からセッションを開始した場合も、他の起動方法と同様に差分が正しく報告されるようになりました。

## 基本的な使い方

セッション内で以下のコマンドを実行してRemote Controlを有効化します。

```
/remote-control
```

接続したクライアント側で、セッションがファイルを編集した際にその作業ツリーの差分がリアルタイムに表示されます。

## 実践例

### モバイルからの進行状況確認

デスクトップで `/remote-control` を実行してセッションを開始し、モバイルアプリから接続して進捗を確認する場合、コード変更の差分がモバイル側にも正しく表示されるようになり、リモートからレビューしやすくなります。

### チームメンバーとの共同レビュー

同僚に一時的にセッションへの閲覧アクセスを許可する際も、`/remote-control` 経由で開始したセッションであれば、相手側に変更内容の差分が確実に表示されます。

### 長時間タスクの遠隔監視

長時間かかるリファクタリングタスクをリモートコントロール経由で監視する場合、差分が正しく報告されることで、意図しない変更がないかをリアルタイムに確認できます。

## 注意点

- この修正は `/remote-control` コマンドで開始したセッションに特有の問題であり、他の方法で開始したRemote Controlセッションでは元々問題ありませんでした
- 差分の報告はあくまで接続中のクライアントへの表示機能であり、Gitへのコミットや操作そのものには影響しません
