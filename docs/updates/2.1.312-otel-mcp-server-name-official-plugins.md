## 原文（日本語訳）

OpenTelemetryの `mcp_server.name` が、Anthropic公式マーケットプレイスのプラグインが宣言する固定URLのリモートMCPサーバーについて、`custom` ではなく実名を報告するよう変更しました

## 原文（英語）

Changed OpenTelemetry `mcp_server.name` to report the real name of fixed-URL remote MCP servers declared by plugins from the official Anthropic marketplace, instead of `custom`

## 概要

公式プラグイン由来のリモートMCPサーバーが、テレメトリ上で実名で区別できるようになりました。

## 基本的な使い方

OpenTelemetryを有効にしている環境では、追加設定なしで `mcp_server.name` に実名が入ります。

## 実践例

### MCP利用状況の分析

どのMCPサーバーがどれだけ使われているかを名前で集計できます。

## 注意点

- 対象は公式マーケットプレイスのプラグインが宣言する固定URLのサーバーです。ダッシュボードで `custom` を前提にしている場合は見直してください。
