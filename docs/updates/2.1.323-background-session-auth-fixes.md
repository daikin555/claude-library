## 原文（日本語訳）

名前付きAnthropicプロファイルのセッションを `/fork`、左矢印キー、`--bg` でバックグラウンド継続した際に、別のサインインへ移ってしまう問題を修正しました。更新時に開いていたセッションは開き直してください。プロファイルが見つからない、変更された、または上書きされた場合、バックグラウンドセッションは会話を別のサインインで送らず、停止して理由を伝えます。

## 原文（英語）

Fixed a session on a named Anthropic profile moving to another sign-in when `/fork`, the Left arrow or `--bg` continued it in the background; reopen any session that was open during the update

## 概要

複数のアカウントやプロファイルを使い分けている場合に、バックグラウンドで継続されたセッションが意図しないサインインで会話を送信する恐れがありました。2.1.323では、プロファイル、APIキー、認証トークン、workload identityのいずれの場合も、元の認証を維持できなければ停止して理由を表示します。

## 基本的な使い方

特別な操作は不要ですが、更新時に開いていたセッションは開き直してください。

```bash
claude --bg
```

## 実践例

### 複数プロファイルの運用

仕事用と個人用で別プロファイルを使っている場合、`/fork` やバックグラウンド化の後も同じプロファイルが使われます。

### 古いバックグラウンドサービス

名前付きプロファイルのセッションが、サインインを保持できない古いバックグラウンドサービスに渡された場合は、サービスの再起動を促すメッセージが表示されます。

## 注意点

- `/logout` はバックグラウンドセッションでも有効になり、コンピュータ上の全セッションからサインアウトして保存済みのMCPログインとプラグインのシークレットを削除します
- 停止した場合は、メッセージに従って再サインインまたはサービスの再起動を行ってください
