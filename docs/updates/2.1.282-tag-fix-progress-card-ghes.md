## 原文（日本語訳）

以前のClaude in Slackアプリの、GitHub Enterprise Serverリポジトリ上のセッションに対する進捗カードを修正しました。現在はリポジトリ名が表示され、機能するCreate PRボタンが提供されます。

## 原文（英語）

[Claude Tag] Fixed the earlier Claude in Slack app's progress card for sessions on a GitHub Enterprise Server repository: it now names the repository and offers a working Create PR button

## 概要

Slack上でClaudeに作業を依頼すると、その進捗状況を示す「進捗カード」が表示されます。GitHub Enterprise Server（セルフホスト版GitHub）上のリポジトリを対象にセッションを実行した場合、以前のClaude in Slackアプリではこの進捗カードにリポジトリ名が表示されず、また「Create PR」ボタンを押しても正しく機能しないという不具合がありました。今回の修正で、リポジトリ名が正しく表示されるようになり、Create PRボタンも問題なく機能するようになりました。

## 基本的な使い方

Slackで `@Claude` にメンションしてGitHub Enterprise Server上のリポジトリに対する作業を依頼すると、進捗カードにリポジトリ名が表示され、作業完了後は「Create PR」ボタンからプルリクエストを作成できます。

## 実践例

### セルフホストGitHub環境での開発フロー

社内でGitHub Enterprise Serverを運用している企業のチームが、Slack経由でClaudeに開発タスクを依頼し、進捗カードから直接プルリクエストを作成する一連のフローがスムーズになります。

### 複数リポジトリにまたがる作業の進捗管理

複数のGitHub Enterprise Serverリポジトリで並行して作業を依頼している場合でも、進捗カードにリポジトリ名が表示されることで、どのカードがどのリポジトリの作業かを見分けやすくなります。

## 注意点

- この修正は「以前のClaude in Slackアプリ」（現行のClaude Tag以前のバージョン）を対象にしたものです
- GitHub.com（パブリック版GitHub）のリポジトリを使用している場合は影響を受けていませんでした
