## 原文（日本語訳）

`/install-github-app` が「cancelled」と表示した後も、ブランチのpushとAPIキーシークレットの保存が続行されていた不具合を修正しました。現在は途中でやめると残りの手順が停止し、既に完了した内容が報告されるようになりました。

## 原文（英語）

Fixed `/install-github-app` saying "cancelled" and then still pushing the branch and saving the API key secret; leaving now stops the remaining steps and reports what was already done

## 概要

`/install-github-app` コマンドはGitHub Appのセットアップの一環として、ブランチのpushやAPIキーのシークレット保存といった操作を行います。しかし、途中でユーザーが処理をキャンセルしても、画面上は「cancelled」と表示される一方で、実際にはブランチのpushやシークレットの保存といった副作用のある操作がバックグラウンドで続行されてしまう不具合がありました。今回の修正で、キャンセル操作が正しく残りの手順を停止させ、それまでに実際に完了していた内容だけが報告されるようになりました。

## 基本的な使い方

```
/install-github-app
```

セットアップ途中でキャンセルした場合、現在は「どこまで完了していたか」が正確に報告されるようになります。

## 実践例

### セットアップを慎重に進めたい場合

GitHub Appの権限範囲を確認しながら進めたい場合に、途中でキャンセルしても意図しないブランチのpushやシークレットの保存が行われないため、安心して中断・再検討できます。

### 誤操作からのリカバリー

誤って `/install-github-app` を実行してしまい途中でキャンセルした場合でも、リポジトリに意図しないブランチや、保存されるべきでないAPIキーが残る心配が減ります。

## 注意点

- 過去にこの不具合の影響でキャンセルしたにもかかわらずブランチやシークレットが残っている場合は、手動での確認・削除を検討してください
- GitHub App連携のセットアップ手順自体は変更されていません
