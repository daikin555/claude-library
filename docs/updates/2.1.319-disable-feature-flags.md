## 原文（日本語訳）
環境変数 `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` を追加：テレメトリを無効にせずにフィーチャーフラグの取得を停止します。すべてのフラグは組み込みのデフォルト値を使います。

## 原文（英語）
Added the `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` environment variable, which stops feature-flag fetching without turning off telemetry; every flag then uses its built-in default

## 概要
テレメトリは維持したまま、フィーチャーフラグの取得だけを止められる環境変数です。フラグはすべて組み込みのデフォルト値になります。

## 基本的な使い方
```bash
export CLAUDE_CODE_DISABLE_FEATURE_FLAGS=1
claude
```

## 実践例

### 挙動を固定したい環境
サーバー側フラグで挙動が変わらないよう、組み込みデフォルトに固定できます。

### 設定ファイルでの配布
`settings.json` の `env` に入れてチームに適用できます。

## 注意点
- サーバー側フラグに依存する機能はデフォルト挙動になります。
