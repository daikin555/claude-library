## 原文（日本語訳）
新しいメッセージでターンが中断された後に完了したツール呼び出しでも、PostToolUseフックが実行されるようになりました（完了まで最大10秒）。

## 原文（英語）
Changed PostToolUse hooks to run, with up to 10 seconds to finish, on tool calls that finish after a new message interrupts the turn

## 概要
ターン中断後に終わったツール呼び出しでもPostToolUseフックが走り、フォーマッタやログ記録などの後処理が抜けにくくなります。

## 基本的な使い方
`.claude/settings.json` でPostToolUseフックを設定します。

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "./scripts/format.sh" }]
      }
    ]
  }
}
```

## 実践例

### 自動フォーマットの取りこぼし防止
編集中に割り込んでも、完了した編集に対してフォーマットが実行されます。

### 監査ログ
実行されたツール呼び出しの記録が欠けにくくなります。

## 注意点
- フックの実行猶予は最大10秒です。長い処理は避けてください。
