## 原文（日本語訳）

PDFページ読み取りエラーメッセージを修正しました。アクセント記号付きや非ラテン文字を含むパスが読みやすく表示されるようになり、「password」や「invalid」のような名前のフォルダによってエラーが誤った原因を示すことがなくなりました。

## 原文（英語）

Fixed PDF page-read error messages: paths with accented or non-Latin characters now appear readably, and a folder named like "password" or "invalid" can no longer make the error name the wrong cause

## 概要

PDFファイルの読み取りに失敗した際のエラーメッセージに2つの問題がありました。1つは、ファイルパスにアクセント記号付きの文字（é、ñなど）や日本語・中国語などの非ラテン文字が含まれていると、パスが文字化けして表示されること。もう1つは、パスの一部に「password」や「invalid」といった単語がフォルダ名としてたまたま含まれていると、実際の原因とは無関係にそれらの単語に基づいてエラー原因が誤って判定されてしまうことでした。今回の修正で両方の問題が解消されました。

## 基本的な使い方

ユーザー側の対応は不要です。PDFファイルを読み込む通常の操作の中で、パスに特殊文字が含まれていたり、フォルダ名に紛らわしい単語が含まれていたりしても、正確なエラー情報が表示されるようになります。

## 実践例

### 日本語のフォルダ名・ファイル名でのPDF管理

「請求書」「見積書」といった日本語のフォルダ名やファイル名でPDFを管理しているプロジェクトでも、エラー発生時にパスが正しく読める形で表示されます。

### 誤解を招くフォルダ名を持つプロジェクト構成

たとえば `test/invalid-cases/sample.pdf` のようなテスト用フォルダ構成でPDFの読み取りに失敗した場合でも、「invalid」という単語に引きずられず、実際の失敗原因が正しく報告されます。

## 注意点

- この修正はエラーメッセージの正確性を改善するものであり、PDF自体の読み取り機能や対応フォーマットを変更するものではありません
- 依然としてPDFの読み取りに失敗する場合は、表示される具体的なエラー内容を確認してください
