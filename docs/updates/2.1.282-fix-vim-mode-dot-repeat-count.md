## 原文（日本語訳）

`x`、`s`、`p`、`d`、`c` を `.` でリピートする際にその前に付けたカウントが無視される問題、および行全体の `p`/`P`、`o`、`O`、`J`、`>>`、`<<` が、上の行が折り返している場合に誤った行へ作用してしまう問題を修正しました。

## 原文（英語）

Fixed vim mode ignoring a count typed before `.` when repeating `x`, `s`, `p`, `d` or `c`, and whole-line `p`/`P`, `o`, `O`, `J`, `>>` and `<<` acting on the wrong line when a line above wraps

## 概要

vimモードの `.` コマンドは直前の編集操作を繰り返すためのものですが、`3.` のように繰り返し回数のカウントを指定しても、`x`・`s`・`p`・`d`・`c` といった操作ではそのカウントが無視されてしまう不具合がありました。また、ターミナルの表示幅の都合で上の行が折り返して複数行に見えている場合、行全体を対象とする `p`/`P`・`o`・`O`・`J`・`>>`・`<<` といった操作が、見た目上の行と実際の行の対応関係を誤認識し、意図しない行に作用してしまう問題もありました。今回の修正で両方が解消されました。

## 基本的な使い方

```
x       " 1文字削除
3.      " 直前の操作(x)を3回繰り返す → 3文字削除されるようになった
```

## 実践例

### 繰り返し編集の効率化

同じ削除・置換操作を複数回繰り返したい場合に、`3.` のようにカウントを指定するだけで意図した回数だけ操作を繰り返せるようになり、同じキーを何度も押す手間が省けます。

### 長いプロンプトでの折り返し行を跨いだ編集

ターミナル幅の関係で長い行が折り返して表示されているプロンプトでも、`J` での行結合や `o`/`O` での新規行挿入が、見た目ではなく実際の行構造に基づいて正しく動作するようになります。

## 注意点

- ターミナルの幅を変更すると行の折り返し方も変わるため、極端に狭いターミナルでは依然として見た目と実際の行の対応が分かりにくい場合があります
- `.` によるリピートはvimの基本機能であり、vimに慣れたユーザーほどこの修正の恩恵を感じやすくなります
