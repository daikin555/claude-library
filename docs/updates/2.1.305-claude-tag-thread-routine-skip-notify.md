# [Claude Tag] 会話終了後に成功扱いで投稿されないルーティンをスキップし作成者へ通知

## 原文（日本語に翻訳）

- [Claude Tag] Slackスレッドで設定したルーティンが、会話終了後に投稿せず成功と報告する問題を修正。該当の実行はスキップされ、作成者に通知される

## 原文（英語）

- [Claude Tag] Fixed routines set up in a Slack thread reporting success without posting after the conversation ended; those runs are now skipped and the creator is told

## 概要

会話終了後、投稿しないのに成功と報告していたルーティンの実行が、スキップされ作成者に通知されるようになりました。

## 基本的な使い方

自動で動作します。通知を受けたら、ルーティンの宛先を見直します。

## 実践例

### 失敗の見逃し防止

投稿されていないのに成功と見える状態がなくなります。

## 注意点

- 通知を受けた場合は、投稿先のスレッドを更新するか新規設定してください。
