# /tui classic で非フルスクリーンレンダラーを選択

## 原文（日本語に翻訳）

非フルスクリーンレンダラーの名称として `/tui classic` を追加しました。`/tui default` も引き続き使えます。

## 原文（英語）

Added `/tui classic` as the name for the non-fullscreen renderer; `/tui default` still works

## 概要

フルスクリーン表示ではない従来のレンダラーが `classic` という名前で呼べるようになりました。ターミナルのスクロールバックやネイティブな選択操作を使いたい場合に切り替えます。

## 基本的な使い方

```text
/tui classic
```

## 実践例

### tmux や一部ターミナルで表示が乱れる場合

フルスクリーンで表示崩れが起きる環境では `/tui classic` に切り替えて回避できます。

### 元に戻す

```text
/tui fullscreen
```

## 注意点

- `/tui default` は互換のため引き続き動作します。
- 選択できるモードの一覧は `/tui` を引数なしで実行して確認してください。
