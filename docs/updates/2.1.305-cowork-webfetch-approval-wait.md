# スケジュールCoworkでのWebFetch承認待ち5分問題を追加修正

## 原文（日本語に翻訳）

- スケジュール実行されるCoworkクラウドセッションで、WebFetchにURL承認が必要なのに承認者がいないサブエージェントごとに5分待機してしまうケースをさらに修正

## 原文（英語）

- Fixed more cases of scheduled Cowork cloud sessions waiting five minutes for each subagent whose WebFetch needed a URL approval that nobody was there to give

## 概要

無人のスケジュール実行で、WebFetchのURL承認が得られないサブエージェントが1件ごとに5分待つ問題の追加修正です。待機で全体が長引くケースが減ります。

## 基本的な使い方

設定は不要です。事前に許可したいドメインがある場合は権限ルールで許可しておくと、承認待ち自体を避けられます。

```json
{ "permissions": { "allow": ["WebFetch(domain:docs.example.com)"] } }
```

## 実践例

### 定期レポート生成

無人実行のジョブで、承認不能なURLに起因する無駄な待ち時間が短縮されます。

## 注意点

- 無人実行で必要なドメインは事前に許可リストへ追加するのが確実です。
