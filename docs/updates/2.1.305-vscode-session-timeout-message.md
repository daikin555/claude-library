# [VSCode] セッション起動タイムアウト時のメッセージを改善

## 原文（日本語に翻訳）

- [VSCode] セッションが時間内に開始せず、実行中のフックもない場合のメッセージを変更。サインインやネットワークより先に出力ログを案内し、原因の候補を列挙する

## 原文（英語）

- [VSCode] Changed the message shown when a session does not start in time and no hook is running: it now leads with the output logs and lists causes instead of pointing to sign-in and network first

## 概要

起動タイムアウト時のメッセージが、まず出力ログの確認を促し、考えられる原因を並べる形式になりました。

## 基本的な使い方

メッセージが出たら、VS Codeの出力パネルでClaude Codeのログを開いて確認します。

## 実践例

### 起動トラブルの調査

ログから原因を特定してから、サインインやネットワークを確認する流れになります。

## 注意点

- 実行中のフックがある場合は別のメッセージが表示されます。
