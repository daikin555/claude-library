## 原文（日本語に翻訳）

DesktopアプリとVS Codeのバイパス権限モードで、危険な `rm` および `rmdir` のプロンプトを、書き換えのヒント付きで即座に拒否するよう変更しました。無人セッションが止まらず続行できます

## 原文（英語）

Changed the dangerous `rm` and `rmdir` prompt in bypass permissions mode in the Desktop app and VS Code to deny the command at once with a rewrite hint, so unattended sessions keep going

## 概要

バイパス権限モードでも、危険と判定された `rm` / `rmdir` には確認プロンプトが出ていました。DesktopアプリとVS Codeではこれが「即時拒否＋書き換えのヒント」に変わり、人が不在でも承認待ちで止まらず、Claudeがより安全なコマンドへ自力で修正できます。

## 基本的な使い方

特別な設定は不要です。バイパス権限モードのセッションで危険な削除が提案されると、プロンプトなしで拒否され、Claudeにヒントが返ります。

## 実践例

### 無人タスクでのクリーンアップ

```text
ビルド成果物を整理して。削除は対象を明示したパスのみにして
```

広範囲な削除は拒否され、Claudeは対象を絞ったコマンドへ書き換えて再試行します。

### 削除対象を具体的に指示する

```text
dist/ と .cache/ だけを削除して。それ以外には触れないで
```

## 注意点

- 対象はDesktopアプリとVS Code拡張のバイパス権限モードです
- 拒否されるのは危険と判定された `rm` / `rmdir` です
- 削除したいファイルがある場合は、対象パスを具体的に指示してください
