## 原文（日本語に翻訳）

`/config` を改善しました。循環する設定には ‹ › が表示され、←/→ で双方向に切り替えられます。狭いターミナルでは各値がラベルの下に積まれ、PgUp/PgDn で一覧をページ送りできます。

## 原文（英語）

Improved `/config`: settings that cycle show ‹ › and step both ways with ←/→, narrow terminals stack each value under its label, and PgUp/PgDn page the list

## 概要

`/config` 画面の操作性が向上しました。値が循環する設定は ←/→ で前後どちらにも切り替えられ、狭いターミナルでも見やすく、長い設定一覧は PgUp/PgDn で移動できます。

## 基本的な使い方

```
/config
```

- ←/→: 循環する設定の値を前後に切り替える（‹ › で示される）
- PgUp/PgDn: 一覧をページ単位でスクロール

## 実践例

### 設定値をすばやく切り替える

テーマなど循環型の設定は、→ だけでなく ← で戻せるため、行き過ぎても簡単に戻れます。

### 狭いターミナルでの利用

分割ペインなど幅が狭い環境でも、値がラベルの下に表示されるので読み取りやすくなります。

### 関連: /memory

`/memory` でも、←/→ で Auto-memory などのオン/オフを切り替えられるようになりました。

## 注意点

- 切り替え方向が増えただけで、設定の内容自体は変わりません。
