## 原文（日本語訳）

`/update-config` が、ファイル権限チェックと一致しない `Write(path)` 権限ルールを書き込んでいた不具合を修正し、正しく `Edit(path)` ルールを書き込むようにしました。

## 原文（英語）

Fixed `/update-config` writing `Write(path)` permission rules, which file permission checks don't match, instead of `Edit(path)` rules

## 概要

`/update-config` はClaude Codeの設定（`settings.json` など）を対話的に更新するためのコマンドです。ファイルの編集を許可する権限ルールを追加する際、修正前は `Write(path)` という形式のルールを書き込んでいましたが、実際のファイル権限チェックの仕組みは `Edit(path)` という形式のルールを想定しており、両者が一致しないため、せっかく追加した権限ルールが実際の権限確認時に機能しないという不具合がありました。今回の修正により、`/update-config` は正しく `Edit(path)` 形式のルールを書き込むようになりました。

## 基本的な使い方

```
/update-config
```

対話的なプロンプトに従って権限ルールを追加すると、正しい形式で `settings.json` に反映されます。

## 実践例

### 特定パスへの編集を許可するルールを追加する

`/update-config` を使って「特定のディレクトリ配下のファイル編集を常に許可する」ようなルールを追加した場合、修正前は次のような誤ったルールが書き込まれ、実際の編集時に許可が反映されないことがありました。

```json
{
  "permissions": {
    "allow": ["Write(src/**)"]
  }
}
```

修正後は正しく次のように書き込まれ、意図通り編集操作が許可されます。

```json
{
  "permissions": {
    "allow": ["Edit(src/**)"]
  }
}
```

### 既存の設定ファイルを確認・修正する

過去のバージョンの `/update-config` で誤って `Write(path)` 形式のルールが書き込まれた `settings.json` を持っている場合は、手動で `Edit(path)` 形式に書き換えることで、意図した権限設定を反映できます。

## 注意点

- 既存の `settings.json` にすでに誤った `Write(path)` ルールが残っている場合、今回の修正はそれらを自動的に修正するものではありません。必要に応じて手動での見直しを推奨します。
- 権限ルールの形式や書き方の詳細は、Claude Codeの権限設定ドキュメントを参照してください。
