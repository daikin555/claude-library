## 原文（日本語に翻訳）

`/code-review` のhigh、xhigh、maxエフォートも、他のエフォートレベルと同様にバックグラウンドエージェントで実行されるようになりました。

## 原文（英語）

`/code-review` at high, xhigh, and max effort now runs in a background agent like the other levels

## 概要

Claude Code v2.1.218で `/code-review` のデフォルト（low/medium相当）のレビューはバックグラウンドサブエージェントとして実行されるように変更されましたが、それより深いレビューを行う `high`・`xhigh`・`max` エフォートは、これまでメインの会話の中で直接実行されていました。今回のv2.1.232で、これらの高エフォートレベルも他のレベルと同じくバックグラウンドエージェントとして実行されるようになり、深いレビューを回している間もメインの会話を占有せず、他の作業を並行して進められるようになりました。

## 基本的な使い方

```bash
/code-review high
```

エフォートレベルを指定して呼び出す方法自体は変わりませんが、`high`・`xhigh`・`max` を指定した場合も、レビュー処理はバックグラウンドのサブエージェントとして進行するようになります。

```
# 変更前: high/xhigh/maxのレビューはメインの会話内で直接実行され、
#          処理中は会話が占有されていた

# 変更後: high/xhigh/maxも他のレベルと同様にバックグラウンドエージェントで実行され、
#          完了後に結果だけが会話に返される
```

## 実践例

### 大規模な変更をhighエフォートで深くレビューしつつ他の作業を続ける

大きなリファクタリングの差分をhighエフォートで念入りにレビューしたいが、レビューの完了を待たずに別のタスクに着手したい場合です。

```bash
/code-review high
# レビューはバックグラウンドで進行

# レビューの完了を待たずに、別の作業を続行できる
このモジュールのドキュメントを更新して
```

### maxエフォートでの最終チェック

リリース前の最終確認としてmaxエフォートでレビューを回す場合も、会話がレビューの思考過程で埋まらなくなります。

```bash
/code-review max
```

完了すると、レビュー結果のサマリーが会話に返され、詳細な検討過程は会話のトランスクリプトを圧迫しません。

### xhighエフォートで複数回レビューを回す

修正とレビューを繰り返すサイクルでも、各レビューがバックグラウンドで独立して進行するため、会話が長くなりすぎるのを防げます。

```bash
/code-review xhigh
# 修正を加えた後、再度実行
/code-review xhigh
```

## 注意点

- v2.1.218で導入されたデフォルトエフォートのバックグラウンド化に続き、v2.1.232でhigh/xhigh/maxにも同じ挙動が適用されます。
- より広範囲・高信頼度の検証が必要な場合は、クラウド上で実行される `/code-review ultra` の利用も検討してください。
- バックグラウンドで進行中のレビューの状況を確認したい場合は、Agent Viewなどのバックグラウンドタスク管理画面や `/tasks` を利用できます。
