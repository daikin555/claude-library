## 原文（日本語訳）

OpenTelemetryのイベントとメトリクスが有効な状態でもCode Modeをオンにできるようになりました。コードが行う各ツール呼び出しはイベントを送信します。トレーシングが有効な場合は引き続きオフのままです。

## 原文（英語）

Added support for turning on Code Mode while OpenTelemetry events and metrics are enabled; each tool call the code makes sends its events; tracing still keeps it off

## 概要

テレメトリを収集している環境でもCode Modeを使えるようになり、スクリプト内の各ツール呼び出しについてもイベントが送られるため、監視の抜けが生じません。同じバージョンで、テレメトリ・非必須通信・フィーチャーフラグがオフの場合にもCode Modeが起動するよう変更されています（管理設定で無効にすることも可能）。

## 基本的な使い方

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
claude
```

テレメトリ設定の詳細は公式ドキュメントのモニタリングの項を参照してください。

## 実践例

### 監査要件のある組織

Code Modeの自動化もツール単位でイベントが記録されるため、既存の可観測性基盤にそのまま乗せられます。

### トレーシング利用時

トレーシングを有効にしている間はCode Modeはオフのままです。必要なら一時的にトレーシングを外して検証します。

## 注意点

- トレーシング有効時はCode Modeは使えません。
- Code Modeを使わせたくない場合は管理設定で無効にします。
