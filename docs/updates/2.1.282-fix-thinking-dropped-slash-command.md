## 原文（日本語訳）

Claudeが作業中に `/model`、`/rename`、`/artifacts` など他の即時実行系スラッシュコマンドを使用した際、それ以前のextended thinkingが失われていた不具合を修正しました。

## 原文（英語）

Fixed earlier extended thinking being dropped when `/model`, `/rename`, `/artifacts` or another immediate slash command was used while Claude was working

## 概要

Claudeがタスクを実行している最中に、ユーザーが `/model` でモデルを切り替えたり、`/rename` でセッション名を変更したり、`/artifacts` を開いたりといった即時実行系のスラッシュコマンドを使うと、それまでに蓄積されていたextended thinking（拡張思考）の内容が失われてしまう不具合がありました。この修正により、作業中にこれらのコマンドを使っても、Claudeの思考の連続性が維持されるようになりました。

## 基本的な使い方

修正後は特別な操作なく、作業中に以下のようなコマンドを安心して使えます。

```
/model
/rename
/artifacts
```

## 実践例

### 作業途中でのモデル切り替え

複雑なタスクの途中で、より高性能なモデルに切り替えたくなった場合でも、`/model` 実行前までの思考プロセスを引き継いだまま作業を続けられます。

### 長時間タスク中のセッション整理

長時間のリファクタリング作業中に `/rename` でセッション名を分かりやすく変更しても、Claudeの推論の一貫性が損なわれません。

## 注意点

- この不具合は「Claudeが作業中」というタイミングに特有のものです。作業が完了した後にこれらのコマンドを使う場合は元々影響を受けていません
- extended thinkingを利用していないセッションには関係ありません
