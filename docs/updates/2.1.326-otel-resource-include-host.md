# OTEL_RESOURCE_INCLUDE_HOST で OpenTelemetry にホスト情報を含める

## 原文（日本語に翻訳）

OpenTelemetry のリソース属性に `host.name` と `host.id` を含める `OTEL_RESOURCE_INCLUDE_HOST` を追加しました（デフォルトはオフ）。

## 原文（英語）

Added `OTEL_RESOURCE_INCLUDE_HOST` to include `host.name` and `host.id` in OpenTelemetry resource attributes (off by default)

## 概要

Claude Code v2.1.326 で、環境変数 `OTEL_RESOURCE_INCLUDE_HOST` が追加されました。有効にすると、エクスポートされる OpenTelemetry のリソース属性に `host.name` と `host.id` が付与され、どのマシンから届いたテレメトリかを区別できます。デフォルトではオフです。

## 基本的な使い方

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_RESOURCE_INCLUDE_HOST=1
claude
```

## 実践例

### 複数マシンの利用状況を区別する

開発用 PC、CI ランナー、リモートサーバーなど複数の環境から同じコレクターにテレメトリを送る場合、ホスト属性があるとダッシュボード上でマシン別に集計できます。

```bash
# ~/.zshrc などに追加
export OTEL_RESOURCE_INCLUDE_HOST=1
```

### 管理設定で組織全体に配布する

`settings.json` の `env` に設定しておけば、メンバーの環境にも同じ設定を適用できます。

```json
{
  "env": {
    "OTEL_RESOURCE_INCLUDE_HOST": "1"
  }
}
```

## 注意点

- デフォルトはオフです。明示的に有効にしない限りホスト情報は含まれません。
- `host.name` や `host.id` はマシンを特定できる情報です。プライバシーポリシーやテレメトリ送信先の取り扱いを確認してから有効にしてください。
- 値の厳密な書式（`1` / `true` など）は公式ドキュメントで確認してください。
