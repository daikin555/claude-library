## 原文（日本語に翻訳）

`/teleport` と `claude --teleport` を改善し、compact済みのクラウドセッションが最後のcompactionから読み込まれる場合に、要約された過去のメッセージがローカルのコピーに含まれないことを警告するようにしました。

## 原文（英語）

Improved `/teleport` and `claude --teleport` to warn when a compacted cloud session loads from its last compaction, so the messages it summarized aren't in the local copy

## 概要

クラウドセッションをローカルへ引き継ぐ際、そのセッションがcompact済みだと、要約前のメッセージはローカルに含まれません。この点が警告で明示されるようになりました。

## 基本的な使い方

```bash
claude --teleport
```

セッション内では次のように実行します。

```text
/teleport
```

## 実践例

### 長時間のクラウド作業をローカルで続ける

警告が出た場合は、要約前の細部が必要かどうかを確認してから作業を進めます。

### 重要な前提の再提示

失われた可能性のある前提は、ローカルで改めて伝えるか `CLAUDE.md` に記載します。

## 注意点

- 要約前の詳細な履歴は、ローカルコピーでは参照できません。
