## 原文（日本語に翻訳）

`/auto-mode-setup` を追加しました。プロジェクトと最近のセッションを読み取り、auto mode にあなたの環境を教えるガイド付きセットアップです。Bedrock、Vertex、Foundry、Claude apps gateway、およびテレメトリー無効のセッションでも利用できるようになりました。

## 原文（英語）

Added `/auto-mode-setup`: a guided setup that reads your project and recent sessions to teach auto mode about your environment, now also available on Bedrock, Vertex, Foundry, Claude apps gateway and telemetry-disabled sessions

## 概要

`/auto-mode-setup` は、プロジェクトの内容や最近のセッション履歴を読み取り、auto mode が「あなたの環境で何が通常の操作か」を理解するための対話型セットアップです。環境に合わない確認やブロックを減らす助けになります。今回のバージョンから、Bedrock・Vertex・Foundry・Claude apps gateway、テレメトリー無効のセッションでも使えます。

## 基本的な使い方

```text
/auto-mode-setup
```

コマンドを実行すると、ガイドに従ってセットアップが進みます。

## 実践例

### 新しいプロジェクトで auto mode を使い始める

プロジェクトのディレクトリで Claude Code を起動し、auto mode を使う前に一度実行します。プロジェクトの構成が読み取られ、環境に関する情報が auto mode に伝わります。

### クラウドプロバイダー経由の環境で使う

Amazon Bedrock、Google Vertex AI、Microsoft Foundry を利用している場合や、テレメトリーを無効にしている場合でも同じ手順で実行できます。

## 注意点

- 実際に表示される質問や設定内容はバージョンにより異なる可能性があります。画面の指示に従ってください。
- auto mode の挙動自体は組織のポリシーなどの影響を受けることがあります。
