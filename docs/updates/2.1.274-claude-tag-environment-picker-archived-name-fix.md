## 原文（日本語訳）

[Claude Tag] Claude Tag管理設定のEnvironmentピッカーが、アーカイブ済みまたはアプリが作成した環境について、環境名の代わりに生の環境IDを表示していた不具合を修正しました。

## 原文（英語）

[Claude Tag] Fixed the Environment picker in Claude Tag admin settings showing a raw environment ID instead of the environment's name for archived or app-created environments

## 概要

Claude Tagの管理者設定画面には、利用する実行環境（Environment）を選択するためのピッカーがあります。これまで、アーカイブ済みの環境やアプリケーションが自動生成した環境については、人間が読める環境名ではなく内部的な環境IDがそのまま表示されてしまい、管理者がどの環境を選んでいるのか分かりにくいという問題がありました。今回の修正で、こうしたケースでも正しく環境名が表示されるようになり、管理画面の視認性が向上しました。

## 基本的な使い方

Claude Tagの管理者設定画面からEnvironmentピッカーを開くだけで、修正後の表示を確認できます。

```
管理設定 > Claude Tag > Environment picker
```

アーカイブ済みの環境やアプリ作成の環境を選択する際、IDではなく名前が表示されます。

## 実践例

### アーカイブ済み環境を選択する場合

過去に使用していたが現在はアーカイブされた環境をEnvironmentピッカーから確認する際、修正前は `env-3f9a2c1b` のようなIDが表示されていましたが、修正後は `Staging (archived)` のような分かりやすい名前が表示されます。

### アプリが作成した環境を選択する場合

CI/CDパイプラインなど外部アプリが自動生成した環境についても、同様に生のIDではなく設定された環境名が表示されるようになりました。

## 注意点

- この修正は表示上の問題の修正であり、環境の動作自体には影響しません
- 管理者権限を持つユーザーのみがこの設定画面にアクセスできます
