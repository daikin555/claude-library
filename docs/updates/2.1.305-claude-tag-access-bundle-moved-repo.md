# [Claude Tag] 別GitHubアカウントへ移動したリポジトリをアクセスバンドルに再追加可能に

## 原文（日本語に翻訳）

- [Claude Tag] リポジトリが別のGitHubアカウントに移動した場合に、Claude Tagのアクセスバンドルへ再び追加できない問題を修正

## 原文（英語）

- [Claude Tag] Fixed Claude Tag access bundles so a repository that moved to another GitHub account can be added again

## 概要

リポジトリの移管後にアクセスバンドルへ追加できなくなる問題が修正されました。

## 基本的な使い方

管理画面のアクセスバンドルで、移管後のリポジトリを通常どおり追加します。

## 実践例

### リポジトリ移管後の再設定

組織間でリポジトリを移したときも、バンドルに再登録できます。

## 注意点

- 移管先のGitHub Appのアクセス権も確認してください。
