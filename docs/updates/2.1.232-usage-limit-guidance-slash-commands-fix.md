## 原文（日本語に翻訳）

SDKおよびリモートセッションにおいて、使用制限（usage-limit）に関するガイダンスが利用できないスラッシュコマンドを提案してしまう不具合を修正しました

## 原文（英語）

Fixed usage-limit guidance suggesting unavailable slash commands in SDK and remote sessions

## 概要

Claude CodeはAPIの使用制限（レートリミットやプラン上限など）に達すると、対応方法を案内するガイダンスメッセージを表示します。しかし、Claude Agent SDK経由の実行やリモートセッションなど、対話型のスラッシュコマンドが利用できない環境でも、通常のCLIセッション向けのスラッシュコマンド（例: `/upgrade` や `/model` など）を案内してしまうことがありました。v2.1.232では、実行環境に応じて適切なガイダンスが表示されるように修正されています。

## 基本的な使い方

```bash
# SDK経由でClaude Codeを利用中に使用制限に達した場合
# 修正前: 「/upgrade を実行してください」など、対話セッションでしか使えない
#         コマンドが案内として表示されてしまうことがあった
# 修正後: SDKやリモートセッションの文脈に沿った、実行可能な案内が表示される
```

## 実践例

### Claude Agent SDKを利用したアプリケーションでの使用制限到達

```python
# Claude Agent SDKを使ったスクリプト実行中に使用制限に達した場合
from claude_agent_sdk import query

async for message in query(prompt="大規模なリファクタリングを実行して"):
    print(message)

# 修正前: エラーメッセージ内に「/model」などスラッシュコマンドの実行を促す
#         案内が含まれ、SDK利用者が混乱する原因になっていた
# 修正後: SDK利用時に適した、実行可能なガイダンス（例: プラン変更のURLなど）が返される
```

### リモートセッション（クラウド実行環境）での使用制限到達

```bash
# リモート環境で実行中のセッションが使用制限に達した場合
# 修正前: 対話型セッション専用のコマンドを案内され、
#         リモート環境では実行できずガイダンスが機能しなかった
# 修正後: リモートセッションでも意味のある案内が表示される
```

## 注意点

- Claude Code v2.1.232で修正されたバグ修正です。
- 通常の対話型CLIセッションでの使用制限ガイダンスには影響しません。
- SDKやリモートセッションでスラッシュコマンドに関する案内を見かけて実行できず困っていた場合、v2.1.232以降で改善されています。
