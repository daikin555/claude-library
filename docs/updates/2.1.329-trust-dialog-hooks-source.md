## 原文（日本語訳）

フォルダーのフックがどこで宣言されているかを示す警告を、信頼ダイアログに追加しました。

## 原文（英語）

Added a trust dialog warning that says where a folder's hooks are declared

## 概要

初めて開くフォルダーを信頼するかどうかを決める信頼ダイアログに、そのフォルダーのフックがどのファイルで宣言されているかを示す警告が表示されるようになりました。フックは任意のコマンドを実行できるため、出所が分かると判断しやすくなります。

## 基本的な使い方

信頼していないリポジトリで `claude` を起動すると、信頼ダイアログが表示されます。

```bash
git clone https://example.com/some/repo.git
cd repo
claude
```

ダイアログの警告で、フックの宣言場所（例: プロジェクトの `.claude/settings.json`）を確認してから信頼するか決めます。

## 実践例

### 他人のリポジトリを調べる前の確認

クローン直後に警告の宣言場所を見て、想定外のファイルにフックがあれば信頼せずに終了し、中身を先にエディターで確認します。

### チーム設定のレビュー

`.claude/settings.json` にフックを追加したら、メンバーが見る信頼ダイアログの表示も確認しておくと、説明を添えやすくなります。

## 注意点

- 警告は判断材料であり、フックの安全性を保証するものではありません。
- 信頼する前に、フックのコマンド内容自体を必ず確認してください。
