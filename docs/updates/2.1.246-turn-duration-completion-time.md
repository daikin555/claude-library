## 原文（日本語訳）

ターン終了時に表示される経過時間の行の末尾に、そのターンの完了時刻が追加されました。例: `✻ Sautéed for 23s · done 6:05 PM`

## 原文（英語）

Added the turn's completion time to the end-of-turn duration line, e.g. `✻ Sautéed for 23s · done 6:05 PM`

## 概要

Claude Codeでは各ターンの終わりに、処理にかかった時間を示すステータス行（例: `✻ Sautéed for 23s`）が表示されます。これまでは経過時間しか分からず、実際にいつ完了したのかを知るには別途時計を確認する必要がありました。今回のアップデートで、この行の末尾に完了時刻（例: `done 6:05 PM`）が追加され、経過時間と完了時刻を一目で確認できるようになりました。

## 基本的な使い方

特別な設定は不要で、通常通りClaude Codeを使うだけで自動的に表示されます。

```
✻ Sautéed for 23s · done 6:05 PM
```

## 実践例

### 長時間タスクの完了タイミングを記録したい場合

大きなリファクタリングやビルドを実行させた際、単に「23秒かかった」だけでなく「何時何分に完了したか」が表示されるため、作業ログや進捗の記録に役立ちます。

### 複数タスクを並行して進めている場合

複数のターミナルやセッションで作業をしている際、それぞれのターンがいつ完了したかを完了時刻で把握でき、どのセッションが最近動いたかを比較しやすくなります。

### 離席後に再開した場合

離席して戻ってきたときに、経過時間表示だけでは「本当にさっき終わったのか、それともかなり前に終わっていたのか」が分かりにくい場合がありました。完了時刻が併記されることで、そのギャップを把握しやすくなります。

## 注意点

- 表示される時刻はローカルのシステム時計に基づきます
- 表示形式（12時間表記か24時間表記か）はロケール設定などに依存する可能性があります
- この変更は表示上のものであり、動作やパフォーマンスに影響はありません
