## 原文（日本語訳）

新しく接続されたSlackワークスペースが、接続された時点で既定だったモデルを固定的に使い続けるのではなく、現行の既定モデルに追従するように変更しました。

## 原文（英語）

[Claude Tag] Changed newly connected Slack workspaces to follow the current default model instead of keeping whichever model was the default when they were connected

## 概要

これまでは、SlackワークスペースをClaude Tagに新しく接続すると、その接続時点でその組織の既定モデルとして設定されていたモデルが、その後もそのワークスペースに固定的に使われ続けるという挙動になっていました。しかし、既定モデルは時間の経過とともに更新されることがあり、古い接続時点のモデルのまま固定されるのは望ましくないケースが多くありました。今回の変更で、新しく接続されたワークスペースは、常にその時点での現行の既定モデルに追従するようになりました。

## 基本的な使い方

エンドユーザー側の対応は不要です。新しくSlackワークスペースをClaude Tagに接続すると、自動的に組織の現行の既定モデルが使われます。

## 実践例

### 新規ワークスペース接続時の一貫したモデル体験

企業が新しいSlackワークスペースを組織に追加した際、既存のワークスペースと同じ最新の既定モデルが自動的に適用され、モデルのばらつきによる体験差が生じません。

### 既定モデルの更新に追従する運用の簡素化

組織の管理者が既定モデルを新しいモデルに更新した際、新しく接続されるワークスペースについては手動で個別設定をし直す必要がなくなります。

## 注意点

- 既に接続済みの既存ワークスペースの挙動について、この変更が遡って影響するかどうかは組織の設定内容によって異なる場合があります
- 特定のワークスペースだけ異なるモデルを使いたい場合は、個別に設定を上書きする必要があります
