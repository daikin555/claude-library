# 起動時の警告を生テキスト出力からデバッグログと警告行へ変更

## 原文（日本語に翻訳）

- 起動時の警告がロゴの上に生テキストで出力される問題を修正。警告はデバッグログへ出力され、何も制限しない権限ルールはバナー下に警告行として表示される

## 原文（英語）

- Fixed startup warnings printing as raw text above the logo: they now go to the debug log, and permission rules that restrict nothing show as warning rows under the banner

## 概要

起動時の警告でロゴ表示が乱れる問題の修正です。通常の警告はデバッグログへ、何も制限しない権限ルールはバナー下の警告行として表示されます。

## 基本的な使い方

警告の詳細はデバッグログで確認できます。

```bash
claude --debug
```

## 実践例

### 権限ルールの見直し

警告行が出たら、効果のないルールを見直して整理します。

## 注意点

- 警告が見当たらなくなったように見えても、デバッグログに記録されています。
