## 原文（日本語に翻訳）

`/feedback` と `/bug` が、Claudeが応答している最中に呼び出された場合、ターンの終了を待たずに即座に開くようになりました

## 原文（英語）

`/feedback` and `/bug` now open immediately when invoked while Claude is responding, instead of waiting for the turn to finish

## 概要

`/feedback` および `/bug` コマンドは、フィードバックやバグ報告を送信するためのダイアログを開くコマンドです。これまでは、Claudeが応答を生成している最中（ターンの途中）にこれらのコマンドを実行すると、Claudeの応答が完了するまでダイアログが開かず待たされることがありました。v2.1.232では、Claudeの応答中であってもターンの終了を待たず、即座にダイアログが開くように改善されました。

## 基本的な使い方

```bash
claude
> 大きなタスクを実行して（Claudeが応答中）

# Claudeがまだ応答・作業している最中に
> /feedback

# 修正前: Claudeのターンが終わるまでダイアログが開かなかった
# 修正後: ターン完了を待たず、即座にフィードバックダイアログが開く
```

```bash
# バグを見つけたその場ですぐに報告したい場合
> /bug
```

## 実践例

### 長時間実行中のタスク中にバグを発見した場合

```bash
claude
> リポジトリ全体を解析してレポートを作成して

# 解析が進行中（Claudeが応答・ツール実行中）に不具合に気づいた
> /bug

# 修正前: 長時間の解析処理が終わるまで /bug ダイアログを開けなかった
# 修正後: 即座にダイアログが開き、気づいた時点ですぐ報告できる
```

### 応答中に思いついたフィードバックをすぐ送りたい場合

```bash
claude
> 新機能を実装して（応答が数分続く）

# 応答の途中で改善案を思いついた
> /feedback

# 修正後: 応答完了を待たずにフィードバック送信フローを開始できる
```

## 注意点

- Claude Code v2.1.232で導入されたUI改善です。
- ダイアログが即座に開いても、進行中のClaudeの処理自体（応答生成やツール実行）はバックグラウンドで継続されます。
- フィードバックやバグ報告の内容は、進行中のタスクとは独立して送信されます。
