## 原文（日本語訳）

ワイドターミナルにおいて、表やコードブロックは全幅を維持したまま、Claudeの文章表示幅を制限する `maxProseWidth` 設定を追加しました。

## 原文（英語）

Added a `maxProseWidth` setting that caps the width of Claude's prose in wide terminals while tables and code blocks keep the full width

## 概要

ウルトラワイドモニターや大きなターミナルウィンドウでClaude Codeを使うと、応答の説明文が画面いっぱいに引き伸ばされ、視線移動が大きくなって読みにくいことがありました。`maxProseWidth` 設定は、Claudeの説明文・Markdown本文の表示幅にだけ上限をかけ、読みやすい行長を保ちます。表やコードブロック、diffは引き続き利用可能な幅をフルに使って表示されます。

## 基本的な使い方

`~/.claude/settings.json`（ユーザー設定）または `.claude/settings.json`（プロジェクト設定）に追加します。

```json
{
  "maxProseWidth": 100
}
```

値は文字数（カラム数）の目安で、この幅を超える説明文は折り返されます。

### ユースケース別の活用

### ウルトラワイドモニターでの可読性向上

34インチ以上のウルトラワイドディスプレイでターミナルを全画面にしている場合、文章だけを100〜120文字程度に制限すると、コードや表は広く、説明文は読みやすく保てます。

### チームでの表示スタイル統一

プロジェクトの `.claude/settings.json` に設定することで、チームメンバー全員が同じ幅でClaudeの応答を読めるようになります。

```json
{
  "maxProseWidth": 90
}
```

## 注意点

- 表・コードブロック・diff表示はこの設定の影響を受けず、常に全幅で表示されます
- 数値はおおよその文字数であり、フォントやターミナルの文字幅設定によって見た目の折り返し位置は変わります
- 狭いターミナルではこの設定より実際の幅が優先されるため、通常のターミナル幅では効果を体感しにくい場合があります
