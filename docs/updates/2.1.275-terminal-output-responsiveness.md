## 原文（日本語訳）
ターミナルの動作が遅い、または一時停止している場合の応答性を改善：ターミナルが追いつくまでの間、出力がさらに遅れて溜まっていくことがなくなりました

## 原文（英語）
Improved responsiveness when the terminal is slow or paused: output no longer falls further behind while the terminal catches up

## 概要
SSH経由の低速な接続や、大量の出力によって描画が追いつかないターミナルを使っていると、Claude Codeの出力がどんどん遅れて溜まってしまい、体感的な応答性が悪化することがありました。今回の改善により、ターミナルの描画が追いつくのを待っている間も出力の遅延が積み重ならないよう調整され、遅いターミナル環境でも操作感が向上します。

## 基本的な使い方
特別な設定は不要です。低速なターミナルや一時的に描画が止まる環境でClaude Codeを使うと、自動的に改善された挙動が適用されます。

```
# 例: SSH越しの低帯域接続でClaude Codeを使用
ssh remote-server
claude
# → 大量の出力があっても、ターミナルの遅れがどんどん蓄積しにくくなる
```

## 実践例

### SSH経由のリモート開発環境での利用
```
ssh -o ServerAliveInterval=30 dev-box
claude
「このログファイル全体を解析して要約して」
# → 大量出力時でもターミナルの遅延蓄積が抑えられ、操作の追従性が向上
```

### ターミナルマルチプレクサ（tmux/screen）併用時
```
tmux new -s claude-session
claude
# バックグラウンドでペインが一時的に描画停止しても、
# 再開時に出力が極端に遅れて表示されることが少なくなる
```

## 注意点
- 根本的なネットワーク遅延やターミナルエミュレータ自体の描画性能限界を解消するものではありません。
- 非常に低速な環境では、依然として体感的な遅延が発生する場合があります。
- 特定の設定変更は不要で、アップデートするだけで適用されます。
