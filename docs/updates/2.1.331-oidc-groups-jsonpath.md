# Claude apps gateway に oidc.groups_jsonpath を追加

## 原文（日本語に翻訳）

Claude apps gateway に `oidc.groups_jsonpath` を追加しました。JSONPath（RFC 9535）の小さなサブセットを使って、オブジェクトのリスト内の一致するエントリからグループを読み取れます。

## 原文（英語）

Added `oidc.groups_jsonpath` to the Claude apps gateway, to read groups from the matching entries of a list of objects with a small subset of JSONPath (RFC 9535)

## 概要

IdP が返すグループ情報が単純な文字列配列ではなく、オブジェクトのリストになっている場合に、JSONPath で必要なグループ名だけを抽出できる設定です。

## 基本的な使い方

```yaml
oidc:
  groups_jsonpath: "$.roles[?(@.type==\"group\")].name"
```

## 実践例

### オブジェクト配列からのグループ抽出

IdP のクレームが `roles: [{type: "group", name: "dev"}, ...]` のような形式のとき、上記の設定で `type` が `group` のエントリの `name` だけをグループとして扱えます。

## 注意点

- サポートされるのは JSONPath のごく一部のサブセットです。
- 式の詳細は RFC 9535 を参照してください。
