## 原文（日本語訳）

フルスクリーンの `claude --resume` セッション選択画面でマウスを使って選択したテキストが、クリップボードにまったく届かない不具合を修正しました。

## 原文（英語）

Fixed text selected with the mouse in the fullscreen `claude --resume` session picker never reaching the clipboard

## 概要

`claude --resume` をフルスクリーンモードで実行すると、過去のセッション一覧から選択するピッカー画面が表示されます。この画面上でマウスを使ってセッション名などのテキストを選択しても、選択したテキストがクリップボードに一切コピーされない不具合がありました。今回の修正により、ピッカー画面上でもマウスによるテキスト選択とクリップボードへのコピーが正しく機能するようになりました。

## 基本的な使い方

```bash
claude --resume
```

セッション選択画面が表示されたら、通常のターミナルと同様にマウスドラッグでテキストを選択し、コピー操作（`Cmd+C` や `Ctrl+Shift+C` など、ターミナルの設定に応じたショートカット）でクリップボードにコピーできます。

## 実践例

### セッションIDやタイトルのコピー

再開したいセッションのIDやタイトルをマウスで選択してコピーし、別のドキュメントやチャットに貼り付けて共有したい場合に、修正前はコピーが機能せず選択したテキストが失われていました。修正後は問題なくコピーできます。

```bash
claude --resume
# セッション選択画面でマウスドラッグ→コピー操作でクリップボードに反映される
```

### 複数セッションのタイトルを見比べて記録する

複数のセッション候補のタイトルをそれぞれコピーしてメモに貼り付けながら比較する、といった使い方も、この修正によって可能になりました。

## 注意点

- クリップボードへのコピー動作は使用しているターミナルエミュレータの設定にも依存します。ターミナル側でマウス選択のパススルー設定が有効になっているか確認してください。
- 通常モード（フルスクリーンでないモード）ではこの問題は発生していませんでした。
