# Readツールがバイナリファイルをテキストとして読む問題を修正

## 原文（日本語に翻訳）

Read ツールが .xlsm、.parquet、.epub、.heic などのバイナリファイルをテキストとして読み込む問題を修正しました。

## 原文（英語）

Fixed the Read tool reading binary files such as .xlsm, .parquet, .epub and .heic as text

## 概要

これらの形式のバイナリがテキストとして読み込まれると、意味のない文字列でコンテキストを消費していました。修正後は、バイナリとして適切に扱われます。

## 基本的な使い方

通常どおりファイルパスを指定します。

```text
data/sales.parquet の内容を確認して
```

## 実践例

### データファイルの扱い

Parquetなどのデータファイルは、専用のツールやスクリプト経由で中身を確認する方針が適切です。

### コンテキスト消費の抑制

不要なバイナリ文字列がコンテキストに流れ込むことを避けられます。

## 注意点

- 対象拡張子の例は .xlsm、.parquet、.epub、.heic です。
- 中身を分析したい場合は、`pandas` などで変換してから読ませてください。
