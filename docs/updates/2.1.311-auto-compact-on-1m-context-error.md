## 原文（日本語に翻訳）

標準コンテキストのセッションで、リクエストが200Kトークンを超えた際に「Usage credits required for 1M context」で停止する問題を修正。Claude Codeは会話をcompactして続行するようになりました。

## 原文（英語）

Fixed standard-context sessions stopping with "Usage credits required for 1M context" when a request ran over 200K tokens; Claude Code now compacts the conversation and continues

## 概要

1Mコンテキストを使えない標準コンテキストのセッションで、リクエストが200Kトークンを超えるとエラーで停止していました。今回の修正により、Claude Codeは会話を自動的にcompact（要約）してから処理を続行します。長時間の作業が途中で止まりにくくなります。

## 基本的な使い方

特別な操作は不要です。必要に応じて手動でも実行できます。

```text
/compact
/context
```

`/context` で現在のコンテキスト使用量を確認し、大きくなってきたら `/compact` で先に整理しておくと安心です。

## 実践例

### 大規模リポジトリの調査

多数のファイルを読み込む調査タスクで200Kを超えても、エラーで中断せず自動compactして作業が続きます。

### 重要な指示を維持する

compactで失われてほしくない前提は `CLAUDE.md` に書いておくと、会話が要約されても参照され続けます。

## 注意点

- compactにより、細かな会話内容は要約されます。
- 同リリースでは、compactの返答に要約が含まれない場合に一度だけ再要求する改善も入っています。
- `DISABLE_COMPACT` を設定している場合は自動compactは無効です。
