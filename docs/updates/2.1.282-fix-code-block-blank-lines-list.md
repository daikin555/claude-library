## 原文（日本語訳）

スクリーンリーダーモード、引用（quote）内のリスト、非常に長いリストで、リスト項目内で始まるコードブロック（直接、または引用内）冒頭の空行が失われる不具合を修正しました。

## 原文（英語）

Fixed screen-reader mode, quoted lists and very long lists dropping the blank lines at the top of a code block that opens a list item, directly or inside a quote

## 概要

Markdownのリスト項目の中でコードブロックが始まる場合、通常はコードブロックの前に空行が入りますが、スクリーンリーダーモード、引用（`>`）内にあるリスト、あるいは非常に長いリストといった特定の表示条件下では、その冒頭の空行が失われて表示されてしまう不具合がありました。これにより、コードブロックの境界が視覚的・音声的に分かりにくくなっていました。今回の修正でこの空行が正しく保持されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。リスト項目内にコードブロックを含むMarkdownコンテンツを表示する通常の操作の中で、この修正が自動的に適用されます。

## 実践例

### スクリーンリーダー利用者への対応改善

視覚障害のあるユーザーがスクリーンリーダーでClaude Codeを利用する際、リスト内のコードブロックの区切りがより正確に読み上げられるようになります。

### 引用付きの手順書やレビューコメントの表示

Slackのスレッドや引用形式でコードを含む手順を共有する場面でも、リスト構造とコードブロックの境界が崩れずに表示されます。

## 注意点

- 通常の（引用やスクリーンリーダーモードではない）短いリストではこの不具合は目立ちにくいものでした
- これは表示上の修正であり、Markdownコンテンツ自体の内容には影響しません
