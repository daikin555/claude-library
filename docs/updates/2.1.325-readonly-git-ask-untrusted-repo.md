# 信頼外リポジトリでの読み取り専用gitコマンドは確認を求める

## 原文（日本語に翻訳）

プロジェクト自身のものでも、信頼したものでもないリポジトリでは、読み取り専用のgitコマンドも先に確認を求めるようになりました。プロンプトなしで実行するには、`additionalDirectories` 設定ではなく `--add-dir` で指定してください。

## 原文（英語）

Changed read-only git commands to ask first in a repository that isn't the project's or one you trusted; name it with `--add-dir`, not the `additionalDirectories` setting, to run them without prompts

## 概要

`git status` や `git log` のような読み取り専用コマンドでも、リポジトリ内の設定次第では想定外の動作につながり得ます。そのため、プロジェクト外かつ未信頼のリポジトリでは先に確認が入ります。

## 基本的な使い方

```bash
claude --add-dir ../other-repo
```

## 実践例

### 複数リポジトリを横断して調査する

```bash
cd ~/work/main-app
claude --add-dir ~/work/shared-lib
```

`shared-lib` が明示的に追加されるため、読み取り専用gitコマンドが確認なしで実行できます。

### additionalDirectories 設定を使っている場合

設定ファイルの `additionalDirectories` に書いたディレクトリでは、この目的では確認が省略されません。プロンプトなしで使いたい場合は `--add-dir` に切り替えてください。

## 注意点

- 未知のリポジトリを `--add-dir` で追加するのは、内容を信頼できる場合に限ってください。
