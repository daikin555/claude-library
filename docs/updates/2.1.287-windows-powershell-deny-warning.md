## 原文（日本語に翻訳）

Windows: Bash ツールを拒否すると PowerShell ツールも無効になる場合に、起動時の警告を追加しました。これにより Claude にシェルツールがない状態になることがわかります。

## 原文（英語）

Windows: Added a startup warning when denying the Bash tool also turns off the PowerShell tool, so Claude has no shell tool

## 概要

Windows で Bash ツールを拒否した結果、PowerShell ツールまで無効になり、Claude がシェルを一切使えなくなる場合に、起動時に警告が表示されます。意図せずシェルが使えない状態を早期に気付けます。

## 基本的な使い方

`settings.json` の権限で Bash を拒否しているとします。

```json
{
  "permissions": {
    "deny": ["Bash"]
  }
}
```

この設定により PowerShell ツールも無効になる場合、起動時に警告が表示されます。

## 実践例

### 意図しないシェル無効化の確認

警告が出たら、本当にシェルを禁止したいのかを確認します。

### 特定コマンドだけを拒否したい場合

ツール全体ではなく、コマンド単位で拒否するルールにすることを検討してください。

```json
{
  "permissions": {
    "deny": ["Bash(rm:*)"]
  }
}
```

## 注意点

- 警告は起動時に表示されるもので、設定自体は変更されません。
- シェルツールがないと、ビルドやテストの実行など多くの作業ができなくなります。
