## 原文（日本語訳）

VSCode拡張について、複数のClaudeパネルを開いた状態のウィンドウが復元・再読み込みされた際に、開いているClaudeタブ間でフォーカスが勝手に移動してしまう不具合を修正しました。

## 原文（英語）

[VSCode] Fixed focus jumping between open Claude tabs on its own when a window with several Claude panels is restored or reloaded

## 概要

Claude CodeのVS Code拡張機能では、「Open in New Tab」や「Open in New Window」などを使って複数のClaudeパネル（会話タブ）を同時に開いておくことができます。これまでは、複数のClaudeパネルを開いた状態のVS Codeウィンドウをそのまま閉じて後で復元したり、ウィンドウをリロードしたりすると、どのタブにも入力していないのにフォーカスが別のClaudeタブへ勝手に移ってしまうことがありました。今回の修正でウィンドウ復元・再読み込み時のフォーカス管理が改善され、意図しないタブ間のフォーカス移動が起きなくなりました。

## 基本的な使い方

この修正もユーザー側で有効化する操作は不要で、拡張機能を最新版に更新するだけで適用されます。VS Codeで複数のClaudeパネルを開いた状態を保存し、ウィンドウを再起動・リロードする、といった通常の使い方の中で自然に修正の効果を確認できます。

```
1. VS CodeでClaude Codeパネルを複数タブ開く（Open in New Tabなど）
2. ウィンドウを閉じてVS Codeを再起動する、または「Reload Window」を実行する
3. 修正前: 開いていたタブのどこかへフォーカスが勝手に移動することがあった
4. 修正後: 復元時のフォーカスが意図しないタブへ飛ばなくなる
```

## 実践例

### 複数プロジェクトの会話を並行して開いている場合

フロントエンド用とバックエンド用など、複数のClaudeタブを別々のタスクのために開いているときにVS Codeを再起動しても、直前まで作業していたタブとは違うタブに勝手にフォーカスが移って入力を続けてしまう、という事故がなくなります。

### 「Reload Window」でVS Codeを再読み込みする場合

拡張機能の設定変更後などに `Developer: Reload Window` コマンドでウィンドウを再読み込みした際も、複数のClaudeパネルが開いていた状態が正しく復元され、フォーカスが意図せず切り替わらなくなります。

### エディタ領域にClaudeタブを複数配置している場合

Claudeパネルをサイドバーではなくエディタ領域にタブとして複数開いているレイアウトでも、同様にウィンドウ復元時のフォーカスの安定性が向上しています。

## 注意点

- この修正はVS Code拡張機能（Claude Code for VS Code）に固有のものです。ターミナル上のCLIやJetBrains向け拡張には直接関係しません
- 修正の適用にはVS Code拡張機能自体の更新が必要です。拡張機能のマーケットプレイスから最新版を取得してください
- 単一のClaudeパネルしか開いていない場合はもともと影響のなかった不具合です
