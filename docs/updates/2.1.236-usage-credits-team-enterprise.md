## 原文（日本語訳）

`/usage` にTeamおよびEnterpriseメンバー向けの使用クレジット（usage-credits）支出行が表示されるようになりました。また、まだ何も消費していない場合は0%で頭打ちになった行が表示されます。

## 原文（英語）

`/usage` now shows the usage-credits spend row for Team and Enterprise members, and shows a capped row at 0% before anything is spent

## 概要

Claude Codeの `/usage` コマンドは、セッション内から自分の利用状況を確認できるセルフサービスのビューです。TeamプランやEnterpriseプランで「使用クレジット（usage-credits）」機能が有効になっている組織では、含まれる利用枠を使い切った後もクレジットを消費して作業を続けられますが、これまで `/usage` にはそのクレジット消費状況が表示されていませんでした。今回の変更で、TeamおよびEnterpriseメンバーに対して使用クレジットの支出行が追加表示されるようになり、さらにまだ何もクレジットを消費していない場合でも0%表示の行が出るようになったことで、クレジットが有効になっていること自体を確認できるようになりました。

## 基本的な使い方

TeamまたはEnterpriseプランのメンバーがセッション内で `/usage` を実行するだけで、通常の利用状況に加えて使用クレジットの支出状況が表示されます。

```
/usage
```

使用クレジットをまだ消費していない場合は、0%で頭打ちになった行が表示され、クレジットの残量を消費し始めるとその割合が更新されていきます。

## 実践例

### Team管理者がメンバーのクレジット消費状況を把握する

組織で使用クレジットを有効にしているTeamプランの管理者は、メンバーに `/usage` を実行してもらうことで、含まれる利用枠に加えてクレジットがどの程度消費されているかをセッション内から素早く確認できます。ダッシュボードを別途開かなくても、ターミナル上で状況を把握できるのが利点です。

```
/usage
# 使用クレジットの支出行が表示される（例: Usage credits: 12% spent）
```

### Enterpriseメンバーがクレジットの有効化を確認する

Enterpriseプランでシート単位の課金を利用しており、使用クレジットが有効化されているかどうか不明な場合、`/usage` を実行すれば、まだ消費がなくても0%表示の行が現れることでクレジット機能自体が有効であることを確認できます。

```
/usage
# Usage credits: 0% spent （まだ消費なし、ただし機能は有効）
```

### 含まれる利用枠とクレジット消費の切り替わりを監視する

含まれる利用枠を使い切るタイミングが近いユーザーは、`/usage` を定期的に確認することで、いつからクレジットの消費に切り替わるのかを把握し、想定外のコスト増加を早期に察知できます。

## 注意点

- この支出行はTeamおよびEnterpriseプランで使用クレジットが有効になっているメンバーにのみ表示されます
- クレジットをまだ消費していない場合でも、機能が有効であれば0%の行が表示されます（機能が無効な組織では行自体が表示されません）
- 組織全体の集計や課金管理はAnthropic Consoleなど管理者向けの画面で行う必要があり、`/usage` はあくまで個人のセルフサービスビューです
