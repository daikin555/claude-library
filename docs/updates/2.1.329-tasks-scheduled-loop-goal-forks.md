## 原文（日本語訳）

このセッションのスケジュール済みタスク、`/loop` のウェイクアップ、goal、この会話のforkを `/tasks` に追加しました。`x` を押すと確認の後で停止します。

## 原文（英語）

Added this session's scheduled tasks, `/loop` wakeups, the goal and this conversation's forks to `/tasks`; x stops one after asking

## 概要

`/tasks` が、バックグラウンドシェルなどに加えて、現在のセッションのスケジュール済みタスク、`/loop` の次回実行、goal、forkした会話も一覧表示するようになりました。不要なものは `x` キーで、確認を挟んで停止できます。同じバージョンでヘッダーとフッターの件数も、シェル・モニター・MCP呼び出し・エージェント・ワークフロー・スケジュール済みタスクを合算した1つの数字になりました。

## 基本的な使い方

```
/tasks
```

一覧で対象を選び、`x` を押すと停止の確認が表示されます。

## 実践例

### /loop の状況確認

```
/loop 5m /babysit-prs
/tasks
```

`/tasks` で次回ウェイクアップを確認し、不要になれば `x` で止めます。

### 並行作業の整理

forkやバックグラウンドエージェントが増えたとき、`/tasks` で全体像を確認してから不要なものを停止します。

## 注意点

- 停止の前には必ず確認が入ります。
- 「Exit and stop tasks」を選ぶとこのセッションのスケジュール済みタスクも終了し、再開時に再実行されなくなります（応答中に終了した場合を除く）。
