# deniedMcpServers のURL指定がAnthropic提供サーバーとコネクタにも適用

## 原文（日本語訳）

`deniedMcpServers` のURLエントリが、上流URLが一致するAnthropic提供サーバーや、クラウドセッション・セルフホストランナーでセッションにコネクタ自身のURLが与えられるコネクタもブロックするようになりました。それ以外の場合は、コネクタを名前で拒否してください。

## 原文（英語）

Changed `deniedMcpServers` URL entries to also block Anthropic-provided servers whose upstream URL matches, and connectors in cloud sessions and on self-hosted runners, where the session is given the connector's own URL; otherwise deny a connector by name

## 概要

MCPサーバーの拒否リストがURLベースでより広く効くようになりました。組織のポリシーで特定のエンドポイントを禁止している場合、Anthropic提供サーバー経由でも到達できなくなります。

## 基本的な使い方

`settings.json`（管理設定）に拒否エントリを追加します。下記は例示で、正確な書式は公式ドキュメントで確認してください。

```json
{
  "deniedMcpServers": [
    { "serverUrl": "https://example.com/mcp" }
  ]
}
```

## 実践例

### 組織全体でのエンドポイント禁止

管理設定にURLを登録すると、同じ上流URLを持つAnthropic提供サーバーやクラウドセッションのコネクタも対象になります。

### 名前での拒否

URLが一致しないコネクタは、名前での拒否エントリを追加します。

## 注意点

- 既存のURL拒否設定の影響範囲が広がるため、意図せず使えなくなったコネクタがないか確認してください。
