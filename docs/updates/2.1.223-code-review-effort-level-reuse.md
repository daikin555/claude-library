## 原文（日本語に翻訳）

effortレベルを指定せずに `/code-review` を実行した場合、前回入力したレベルを再利用するように変更した。レベルを変更するには `/code-review high` のようにレベルを入力する。

## 原文（英語）

Changed `/code-review` with no effort level to reuse the level you typed last; type a level like `/code-review high` to change it

## 概要

`/code-review` はeffortレベル（`low`・`medium`・`high`・`xhigh` など）を指定してレビューの精度と網羅性を調整できます。v2.1.223より前は、effortレベルを指定せずに `/code-review` を実行すると、常にそのセッションの現在のeffort設定が使われていました。今回の変更により、effortレベルを省略した場合には、過去に自分が明示的に入力した最後のレベルが再利用されるようになりました。これは同一セッション内だけでなく、別のセッションをまたいでも有効です。レベルを指定して実行すると、`Reusing high effort, the level you typed last time` のような通知が表示され、どのレベルが使われているかが分かります。

## 基本的な使い方

effortレベルを指定せずに実行すると、前回明示的に入力したレベルが再利用されます。

```text
/code-review
```

再利用されるレベルを変更したい場合は、明示的にレベルを入力します。

```text
/code-review high
```

## 実践例

### 毎回同じeffortレベルで手早くレビューしたい場合

一度 `high` を指定してレビューを実行しておけば、以降は `/code-review` とだけ入力しても `high` が再利用されます。

```text
/code-review high
```

```text
# 別のセッションでも high が再利用される
/code-review
```

### クリティカルな変更だけeffortレベルを引き上げたい場合

普段は `medium` で運用しつつ、重要な変更のときだけ `xhigh` を明示的に指定します。以降の `/code-review`（レベル省略）は `xhigh` を再利用するようになるため、通常運用に戻す際は再度 `medium` を明示的に入力する必要があります。

```text
/code-review xhigh
```

```text
# 通常運用に戻す
/code-review medium
```

### CI・スクリプトなど非対話的な実行での注意

`-p` を使った非対話的な実行でレベルを指定しても、次回以降に再利用される「最後に入力したレベル」としては保存されません。CIパイプラインなどでは、実行のたびに明示的にレベルを指定するのが安全です。

```bash
claude -p '/code-review high'
```

## 注意点

- 再利用されるのは「自分が明示的にレベルを入力して実行した」場合のみです。一度もレベルを入力したことがない場合は、セッションの現在のeffort設定が使われます。
- `-p` フラグを使った非対話的な実行でレベルを指定しても、次回以降に再利用される値としては更新されません。
- v2.1.223より前のバージョンでは、レベルを省略した `/code-review` は常にセッションの現在のeffort設定を使用していました。過去のスクリプトや手順書がこの前提に依存している場合は見直しが必要です。
- effortレベルはモデルによって対応状況が異なり、対応していないレベルを指定した場合は、そのモデルがサポートする範囲内で最も近いレベルにフォールバックします。
