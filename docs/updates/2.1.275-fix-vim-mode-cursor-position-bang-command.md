## 原文（日本語に翻訳）

vimモードにおいて、ドットリピートされた「!」、または空でないプロンプトをシェルモードに切り替える高速入力の「i!」の後に、カーソルが1文字右にずれて配置されてしまっていた問題を修正

## 原文（英語）

Fixed vim mode placing the cursor one character right after a dot-repeated "!" or a fast-typed "i!" switched a non-empty prompt into shell mode

## 概要

Claude Codeのvimモードでは、`!` を使ってシェルモードに切り替えることができます。これまで、ドットリピート（`.`）によって `!` コマンドを繰り返した場合や、空ではないプロンプトの状態で素早く `i!` と入力してシェルモードに切り替えた場合に、カーソル位置が本来より1文字右にずれてしまう不具合がありました。今回の修正でカーソル位置が正しく揃うようになりました。

## 基本的な使い方

vimモードを有効にしている場合、`!` でシェルモードに切り替えられます。

```
# vimモードのノーマルモードで
!
# → シェルモードに切り替わる
```

## 実践例

### ドットリピートで「!」を繰り返す場合

一度 `!` によるシェルモード切り替えを行った後、`.` でその操作を繰り返した際にカーソル位置がずれていましたが、修正後は正しい位置に表示されます。

```
# 1回目: ! でシェルモードに切り替え
!
# ノーマルモードに戻った後
. 
# → ドットリピートでも正しいカーソル位置になる
```

### 空でないプロンプトで素早く「i!」と入力した場合

既に何か文字を入力した状態のプロンプトで、素早く `i!` と入力してシェルモードに切り替えた際もカーソル位置のずれが解消されます。

```
# プロンプトに何か入力済みの状態で
some text i!
# → シェルモードへの切り替え後、カーソルが正しい位置に表示される
```

## 注意点

- この不具合はvimモードを有効にしている場合にのみ発生していました
- 通常の入力速度で1文字ずつ `i` と `!` を入力した場合は影響を受けない場合があります
- vimモードの設定は `/vim` コマンドやsettings.jsonの `editorMode` などで管理されています
