## 原文（日本語訳）

キューに入れた `!` シェルコマンドを上矢印キーで呼び出して編集した際、そのコマンドが平文としてそのままモデルに送信されてしまう問題を修正しました。

## 原文（英語）

Fixed a queued `!` shell command being sent to the model as plain text after pressing up-arrow to edit the queued input

## 概要

`!` プレフィックス付きのシェルコマンドをキューに入れた後、上矢印キーで入力履歴からそのコマンドを呼び出して編集すると、`!` によるシェルコマンドとしての扱いが失われ、通常のテキストメッセージとしてそのままモデルに渡されてしまう不具合がありました。今回の修正により、キュー済みの `!` コマンドを編集した場合でも、正しくシェルコマンドとして再送されるようになりました。

## 基本的な使い方

`!` で始まるコマンドをキューに追加した後、上矢印キーで呼び出して内容を修正しても、`!` コマンドとしての実行モードが維持されます。

```
> !git status
[Enterでキューに追加、その後Claudeがまだ処理中]
> [上矢印キーでキュー済みコマンドを呼び出す]
> !git status --short
[Enterで再度キューに追加 → 正しくシェルコマンドとして実行される]
```

## 実践例

### タイプミスに気づいて修正する

```
> !gti status
# 入力ミスに気づく
[上矢印キーで呼び出し]
> !git status
[Enter]
```

修正前: 編集後のコマンドが `!` シェルコマンドとして認識されず、モデルへの通常メッセージとして送られてしまい、期待した実行結果が得られませんでした
修正後: 編集後も `!` コマンドとして正しく認識され、シェル上でコマンドが実行されます

### 引数を追加して再実行する

```
> !npm test
[上矢印で呼び出し]
> !npm test -- --watch
[Enter]
```

キュー済みのコマンドにオプションを追加するような編集操作でも、意図通りシェルコマンドとして実行されます。

## 注意点

- この不具合はキュー済みの入力を上矢印キーで呼び出して編集する操作に限定されていました
- 通常の（キューに入っていない）`!` コマンド入力では問題は発生していませんでした
