## 原文（日本語に翻訳）

フルスクリーンのストリーミング表示を改善しました。更新のたびに会話全体を再正規化しなくなったことで、長時間セッションでも応答性が保たれるようになりました

## 原文（英語）

Improved fullscreen streaming: long sessions stay responsive because the whole conversation is no longer re-normalized on every update

## 概要

Claude Codeのフルスクリーン表示モードでは、Claudeの応答がストリーミング（逐次表示）される際に、これまで更新のたびに会話全体を「再正規化」する処理が行われていました。会話が長くなるほどこの処理のコストが増大し、長時間のセッションではUIの応答性が低下する原因となっていました。v2.1.232では、更新のたびに会話全体を再正規化する必要がなくなり、長時間セッションでもストリーミング表示がスムーズかつ軽快になりました。

## 基本的な使い方

この改善は内部的なレンダリング処理の最適化であり、特別な操作は不要です。フルスクリーンモードで長時間セッションを使い続けるほど、その恩恵を実感しやすくなります。

```bash
# フルスクリーンモードでClaude Codeを起動
claude

# 長時間にわたって多数のメッセージをやり取りする場合でも、
# ストリーミング表示のもたつきが軽減される
```

## 実践例

### 長時間の大規模リファクタリングセッション

```bash
claude
> プロジェクト全体のリファクタリングを段階的に進めてほしい

# 会話が数十〜数百ターンに及ぶ長時間セッションでも、
# 修正前: 応答のたびに会話全体が再正規化され、表示がもたつくことがあった
# 修正後: 差分のみが処理されるため、セッションが長くなっても操作感が軽快
```

### 大量のツール実行ログを含むセッション

```bash
claude
> テストを実行して、失敗したものを一つずつ修正して

# ツール実行結果が大量に蓄積するセッションでも
# ストリーミング表示の更新が引き続き高速に行われる
```

### 長時間のペアプログラミング的な対話

```bash
claude
# 1日を通して同じセッションで複数の機能実装を依頼し続けるケース

# 会話履歴が積み上がっても、応答のストリーミング表示が
# 遅延しにくくなっている
```

## 注意点

- Claude Code v2.1.232で導入されたパフォーマンス改善です。
- フルスクリーン表示モードに関する改善であり、通常のインラインCLI表示モードへの影響については明記されていません。
- 体感できる効果は、会話の長さやセッション時間が長いほど大きくなります。
