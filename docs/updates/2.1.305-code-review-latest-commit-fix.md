# [Code Review] 複数プッシュ時に最新コミットがレビューされないことがある問題を修正

## 原文（日本語に翻訳）

- [Code Review] レビュー中に複数のプッシュがPRに入った際、最新コミットがレビューされないことがある問題を修正

## 原文（英語）

- [Code Review] Fixed Code Review sometimes not reviewing the newest commit when several pushes landed on a pull request during a review

## 概要

レビュー実行中に連続でプッシュした場合でも、最新コミットが対象になるよう修正されました。

## 基本的な使い方

設定不要です。PRに追加プッシュしても、最新の状態がレビューされます。

## 実践例

### 連続プッシュの多いPR

fixupコミットを続けて積んでも、レビューが古いコミットのままになりません。

## 注意点

- レビュー結果がどのコミットを対象にしたかは、PR上で確認できます。
