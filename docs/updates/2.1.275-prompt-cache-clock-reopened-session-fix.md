## 原文（日本語訳）

[VSCode] Claudeが作業中に送信されたメッセージを含むセッションを再度開いた際、プロンプトキャッシュの残り時間表示（clock）が実際より少ない分数で表示される問題を修正しました。

## 原文（英語）

[VSCode] Fixed the prompt cache clock showing too few minutes after reopening a session with a message sent while Claude was working

## 概要

Claude Codeはプロンプトキャッシュの有効期限をUI上の「clock（時計）」表示で確認できます。しかし、Claudeが作業中に送信されたメッセージを含むセッションを再度開くと、この残り時間の計算が誤り、実際よりも短い時間しか残っていないかのように表示されてしまう不具合がありました。今回の修正でこの計算ロジックが是正され、正確な残り時間が表示されるようになりました。

## 基本的な使い方

セッション内でメッセージのやり取りを行うと、プロンプトキャッシュの残り有効時間がUI上に自動的に表示されます。

```
プロンプトキャッシュ: 残り 4分
```

## 実践例

### 作業中に送信したメッセージを含むセッションを再度開く場合

Claudeがツールを実行している最中に別のメッセージを送信し、そのセッションを一度閉じてから再度開いた際の残り時間表示を確認するケースです。

```
修正前: 実際の残り時間は8分 → 再オープン後の表示は「残り2分」（誤り）
修正後: 実際の残り時間は8分 → 再オープン後の表示は「残り8分」（正しい）
```

### キャッシュ有効期限が切れる直前の作業再開

表示される残り時間を頼りに作業タイミングを調整しているユーザーにとって、正確な時間表示は無駄なキャッシュの再生成を避ける判断材料になります。

## 注意点

- この修正は表示上の計算ロジックに関するものであり、プロンプトキャッシュ自体の実際の有効期限やキャッシュ機構を変更するものではありません。
- プロンプトキャッシュの仕組みについては公式ドキュメントも参照してください。
