## 原文（日本語訳）

補完対象のトークンや作業ディレクトリのパスにNULL文字が含まれている場合に、パス補完が失敗する不具合を修正しました。

## 原文（英語）

Fixed path completion failing when the completion token or working directory contained a null byte

## 概要

Claude Codeでは、ファイルパスを入力する際にTabキーなどによる補完機能が利用できます。しかし、補完中の入力文字列や現在の作業ディレクトリのパスにNULL文字（`\0`）が含まれる場合、内部処理でエラーが発生しパス補完全体が失敗するという不具合がありました。今回の修正により、NULL文字が含まれる状況でもパス補完が正しく動作するようになりました。

## 基本的な使い方

通常のファイルパス補完は変わらず利用できます。

```
@src/components/App.t<Tab>
```

修正前は入力文字列や作業ディレクトリのパスにNULL文字が紛れ込むケース（クリップボード経由の貼り付けや特定のツール連携など）で補完が機能しませんでしたが、修正後はそのような場合でも補完が正しく動作します。

## 実践例

### クリップボードからパスを貼り付けて補完する

他のアプリケーションからコピーしたパス文字列に不可視のNULL文字が混入していた場合でも、補完機能が中断せずに動作します。

### 特殊なファイルシステムやツール連携環境での作業

一部のツールや自動生成されたスクリプトが、パス文字列にNULL文字を含めて渡してくることがある環境でも、Claude Codeのパス補完が安定して機能します。

### 作業ディレクトリのパスが特殊な文字を含む場合

シンボリックリンクや特殊なマウント構成により、作業ディレクトリのパス自体に問題のある文字が含まれてしまうケースでも、補完機能全体が停止しないようになりました。

## 注意点

- NULL文字はファイルパスとして通常は無効な文字であるため、実際のファイル操作結果には影響しません。この修正は補完処理がエラーで完全に止まってしまう問題への対処です
- 特殊な入力経路（貼り付けや外部ツール連携）で発生しやすい問題であり、通常のキーボード入力のみでは遭遇しにくい不具合でした
