# Claude apps gateway のアップストリームごとの models リスト

## 原文（日本語に翻訳）

Claude apps gateway のすべてのアップストリームに、任意の `models` リストを追加しました。リストにあるモデルだけがそこへ送られ、フェイルオーバー時も同様です。エントリ内の `*` 1つはワイルドカードとして使えます。

## 原文（英語）

Added an optional `models` list to every Claude apps gateway upstream: only the listed models are sent there, on failover too, and one `*` in an entry is a wildcard

## 概要

Bedrock や Vertex など複数のアップストリームを持つゲートウェイで、どのモデルをどのアップストリームへ送るかを制御できます。フェイルオーバー先にも同じ制限が適用されるため、意図しないモデルが流れ込みません。

## 基本的な使い方

```yaml
upstreams:
  - name: bedrock-us
    models:
      - "claude-sonnet-*"
      - "claude-haiku-4-5"
```

上記は設定イメージです。正確なスキーマは公式のゲートウェイドキュメントで確認してください。

## 実践例

### モデルごとにリージョンや契約を分ける

特定モデルだけを特定のアップストリームに向け、フェイルオーバー時にも対象外のモデルが送られないようにします。

### ワイルドカードでシリーズをまとめて指定

`claude-sonnet-*` のように 1 つの `*` を使って、同系列のモデルをまとめて許可できます。

## 注意点

- ワイルドカードの `*` はエントリ内に 1 つだけ使えます。
- 同バージョンでは、`models:` に載っていないモデルの Bedrock（米国外リージョン）での扱いも改善されています。
