## 原文（日本語に翻訳）

agents ビューに、セッション名とタスクにマッチする `n:<text>` フィルターを追加しました。フィルター使用時は折りたたまれたセクション内のマッチも表示され、Enter で最初のマッチを開きます。

## 原文（英語）

Added an `n:<text>` filter to the agents view that matches session names and tasks; a filter now shows matches in collapsed sections and Enter opens the first match

## 概要

`claude agents` のビューで、`n:<text>` と入力するとセッション名とタスクを対象に絞り込めるようになりました。折りたたまれたセクションの中にあるセッションもヒットし、Enter で先頭のマッチを直接開けます。多数のバックグラウンドセッションを管理するときに便利です。

## 基本的な使い方

```
claude agents
```

ビューを開いた後、フィルター入力欄に次のように入力します。

```
n:login
```

## 実践例

### 特定のタスクのセッションを素早く開く

`n:migration` と入力して Enter を押すと、名前やタスクに "migration" を含む最初のセッションが開きます。

### 折りたたまれたセクションの検索

完了済みなどで折りたたまれたセクションにあるセッションも、フィルター中は表示されます。

## 注意点

- `n:` はセッション名とタスクが対象です。
- Enter は最初のマッチを開くため、複数ヒットする場合はより具体的な文字列で絞り込んでください。
