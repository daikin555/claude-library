## 原文（日本語訳）

[VSCode] メッセージ送信時の一番下へのスクロールが、スクロール中に返信が届き始めた場合に返信の手前で止まってしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed the scroll to the bottom on send stopping short of the reply when the reply starts arriving during the scroll

## 概要

Claude Codeにメッセージを送信すると、会話ビューは自動的に一番下までスクロールします。しかし、スクロールアニメーションの最中にClaudeからの返信が届き始めると、スクロールが返信の手前で止まってしまい、最新の内容が見えない状態になる不具合がありました。この修正により、返信が届くタイミングに関わらず、確実に一番下まで到達するようになりました。

## 基本的な使い方

通常通りメッセージを送信するだけで、会話ビューが自動的に最新のメッセージまでスクロールされます。

```
1. 入力欄にメッセージを入力
2. 送信（Enter または送信ボタン）
3. 会話が自動的に一番下までスクロールする
```

## 実践例

### 応答が速いモデルでのスクロール挙動確認

応答速度が速いケースでは、スクロールアニメーションが完了する前に返信のストリーミングが始まりやすく、この不具合が発生しやすい状況でした。

```
修正前: 送信 → スクロール開始 → 返信到着（スクロール中）→ 返信の手前で停止
修正後: 送信 → スクロール開始 → 返信到着（スクロール中）→ 返信を含めて最下部まで到達
```

### 長い会話履歴での送信直後の挙動

会話が長くスクロール距離が大きい場合でも、返信の到着とスクロール完了のタイミングのずれによる表示崩れが解消されます。

## 注意点

- この修正は自動スクロールのタイミング制御に関するものです。
- 関連機能として、送信時のスクロールをユーザーが制御できる `claudeCode.scrollToBottomOnSend` 設定も同時期に追加されています。
