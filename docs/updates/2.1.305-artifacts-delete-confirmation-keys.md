# /artifacts の削除確認キー操作を変更

## 原文（日本語に翻訳）

- `/artifacts` の削除確認を、1またはEnterで保持、2で削除、Escでキャンセルに変更。`y` と `n` では応答できなくなった

## 原文（英語）

- Changed the `/artifacts` delete confirmation to take 1 or Enter to keep, 2 to delete, and Esc to cancel; `y` and `n` no longer answer it

## 概要

削除確認の操作が変わりました。1／Enterで保持、2で削除、Escでキャンセルです。`y`／`n` は使えません。既定が「保持」側なので誤削除しにくくなっています。

## 基本的な使い方

```
/artifacts
```

削除を選ぶと確認が表示されるので、2で削除、1またはEnterで保持します。

## 実践例

### 誤削除の防止

Enterを押しても保持されるため、うっかり削除を避けられます。

## 注意点

- 以前の `y` の習慣で押しても削除されません。
