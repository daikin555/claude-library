## 原文（日本語に翻訳）

対話型の `--advisor fable` 起動時の同意メッセージが、すでに終了した対話セッションで `/model fable` を実行するよう案内していた不具合を修正しました

## 原文（英語）

Fixed the consent message for interactive `--advisor fable` launches, which told you to run `/model fable` in an interactive session that had just exited

## 概要

`--advisor fable` フラグを使ってClaude Codeを対話モードで起動する際、利用にあたっての同意（コンセント）メッセージが表示されます。これまで、このメッセージの文言が矛盾しており、「対話セッション内で `/model fable` を実行してください」と案内しているにもかかわらず、実際にはその対話セッションはすでに終了しているという状況でした。v2.1.232では、この案内文が正しい手順（起動時のフラグ指定など）を示すように修正されています。

## 基本的な使い方

```bash
# fableアドバイザーモードで対話的に起動
claude --advisor fable

# 修正前: 同意メッセージが「/model fable を実行してください」と案内するが、
#         そのセッションはすでに終了しており、案内通りに実行できなかった
# 修正後: 正しい起動方法・手順が同意メッセージに表示される
```

## 実践例

### fableモードを初めて有効化する場合

```bash
claude --advisor fable

# 同意メッセージが表示される
# 修正後は、メッセージの指示に従うだけで正しくfableモードを開始できる
```

### 同意メッセージの内容を確認してから再起動する場合

```bash
claude --advisor fable
# 同意内容を確認

# 修正前: メッセージ通りに /model fable を打とうとしても
#         セッションがすでに終了しており実行不可能だった
# 修正後: 案内に従って新しいセッションを正しく起動できる
claude --advisor fable
```

## 注意点

- Claude Code v2.1.232で修正されたバグ修正です。
- `--advisor fable` はまだ実験的・限定的な機能である可能性があるため、詳細な利用条件は公式ドキュメントを参照してください。
- メッセージ文言のみの修正であり、fableモード自体の機能や挙動には変更はありません。
