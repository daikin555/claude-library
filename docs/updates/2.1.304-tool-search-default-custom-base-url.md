## 原文（日本語に翻訳）

カスタム `ANTHROPIC_BASE_URL` の背後でも、ツール検索をデフォルトで有効にするよう変更しました。ゲートウェイが 400 または 422 を返した場合は、ツール検索なしで再試行されます。

## 原文（英語）

Changed tool search to be on by default behind a custom `ANTHROPIC_BASE_URL`; a 400 or 422 from the gateway is retried without it

## 概要

LLM ゲートウェイ経由で Claude Code を使う場合でも、ツール検索がデフォルトで有効になります。ゲートウェイが対応しておらず 400 / 422 エラーを返したときは、自動的にツール検索なしで再送されるため、手動の設定変更は通常不要です。

同バージョンでは、`context_management: Extra inputs are not permitted` エラーもゲートウェイ配下で修正されており、そのフィールドを除いてリクエストが再送されます。

## 基本的な使い方

```bash
export ANTHROPIC_BASE_URL="https://gateway.example.com"
claude
```

## 実践例

### 社内ゲートウェイ経由で多数の MCP ツールを使う

ツール検索が有効なため、多数のツールがあっても必要なものだけを検索して使えます。

### 非対応ゲートウェイでのフォールバック

ゲートウェイが拒否しても自動で再試行されるので、動作が止まりません。

## 注意点

- 再試行の対象は 400 または 422 の応答です。
- 明示的に無効化したい場合の設定方法は公式ドキュメントを参照してください。
