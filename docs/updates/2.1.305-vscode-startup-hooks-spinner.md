# [VSCode] SessionStart／Setupフック実行中のスピナー表示を追加

## 原文（日本語に翻訳）

- [VSCode] SessionStartまたはSetupフックの実行中に「Running start-up hooks」スピナーを表示し、スクリーンリーダー向けのアナウンスも追加

## 原文（英語）

- [VSCode] Added a "Running start-up hooks" spinner status, with a screen reader announcement, while SessionStart or Setup hooks run

## 概要

セッション開始時のフックが動いている間、VS Code拡張が「Running start-up hooks」と表示します。スクリーンリーダー向けアナウンスにも対応しています。

## 基本的な使い方

フックの例:

```json
{
  "hooks": {
    "SessionStart": [
      { "hooks": [{ "type": "command", "command": "./scripts/setup.sh" }] }
    ]
  }
}
```

## 実践例

### 重い起動フックの可視化

起動に時間がかかる理由がフックだと分かります。

## 注意点

- 起動が遅い場合は、フックの処理時間を確認してください。
