## 原文（日本語訳）
ネットワークアクセスが有効なCoworkおよびclaude.aiのクラウドセッションが、チームメイトのアーティファクトの読み取りを、あたかもネットワークアクセスが無効であるかのように扱ってしまう問題を修正しました。

## 原文（英語）
Fixed Cowork and claude.ai cloud sessions with network access on treating reads of a teammate's artifact as if network access were off

## 概要
Coworkやclaude.aiのクラウドセッションでは、ネットワークアクセスを有効にすることで外部リソースへのアクセスなどが可能になります。しかし、チームメイトが作成したアーティファクトを読み取る操作に限り、ネットワークアクセスが実際には有効であるにもかかわらず、無効であるかのように扱われてしまう不具合がありました。これにより、本来利用できるはずの機能が制限されてしまうケースがありました。今回の修正で、ネットワークアクセス設定がチームメイトのアーティファクト読み取り時にも正しく反映されるようになりました。

## 基本的な使い方
ネットワークアクセスを有効にしたCoworkまたはclaude.aiのクラウドセッションで、チームメイトが共有したアーティファクトを開きます。

```
セッション設定: ネットワークアクセス = オン
→ チームメイトのアーティファクトを読み取り
```

## 実践例

### 修正前の挙動
ネットワークアクセスをオンにしたセッションでチームメイトのアーティファクトを読み取ると、ネットワークが必要な処理が無効化されているかのような制限を受けることがありました。

### 修正後の挙動
同じ設定で読み取りを行うと、ネットワークアクセスが有効な状態として正しく扱われ、意図した機能が利用できるようになりました。

## 注意点
- この修正はCoworkおよびclaude.aiのクラウドセッションに限定されるものです。
- ネットワークアクセスの設定自体は組織や管理者のポリシーによって制限される場合があります。
