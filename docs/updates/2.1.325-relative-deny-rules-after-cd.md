# 相対パスのdeny/askルールが cd 後もプロジェクトを保護

## 原文（日本語に翻訳）

`Read(./.env)` のような相対パスのdenyおよびaskの権限ルールが、`cd` の後にプロジェクトを対象としなくなる問題を修正しました。これらは追加ディレクトリにも適用されます。

## 原文（英語）

Fixed relative deny and ask permission rules (e.g. `Read(./.env)`) no longer covering the project after a `cd`; they now also apply in added directories

## 概要

相対パスで書いたルールは、作業ディレクトリが変わると保護対象がずれる問題がありました。今回の修正で、`cd` 後もプロジェクトを保護し、追加ディレクトリにも適用されます。

## 基本的な使い方

```json
{
  "permissions": {
    "deny": ["Read(./.env)"]
  }
}
```

## 実践例

### サブディレクトリへ移動した後

```bash
cd packages/api
```

移動後も、プロジェクトの `.env` への読み取りが引き続き拒否されます。

### --add-dir で追加したディレクトリ

```bash
claude --add-dir ../shared
```

追加ディレクトリでも `./.env` のようなルールが適用されます。

## 注意点

- 同バージョンでは、一部のdeny/askルールがBashコマンドに適用されない問題や、一部の複合コマンドが確認なしで実行され得る問題も修正されています。
- 機密ファイルの保護は、サンドボックス設定と併用するとより確実です。
