## 原文（日本語に翻訳）

claude.aiアカウントで有効化されているスキルとプラグインを、そのアカウントでサインインしたターミナルセッションに同期する機能を追加。`syncClaudeAiSkills: false` または `syncClaudeAiPlugins: false` を設定することでオプトアウトできます

## 原文（英語）

Added syncing of the skills and plugins enabled on your claude.ai account to terminal sessions signed in with it; opt out with `syncClaudeAiSkills: false` or `syncClaudeAiPlugins: false`

## 概要

claude.ai（Web版）で有効化しているスキルやプラグインが、同じアカウントでサインインしたターミナルのClaude Codeセッションにも自動的に同期されるようになりました。これにより、Webとターミナルの両方で同じスキル・プラグイン構成を維持でき、セットアップの二度手間がなくなります。同期を望まない場合は、設定でスキルとプラグインそれぞれ個別にオプトアウトできます。

## 基本的な使い方

claude.aiアカウントでサインインしていれば、特別な操作なしに自動的にスキルとプラグインが同期されます。同期を無効化したい場合は設定ファイルに以下を追加します。

```json
{
  "syncClaudeAiSkills": false,
  "syncClaudeAiPlugins": false
}
```

## 実践例

### Web版で有効化したスキルをターミナルでもそのまま使う

claude.aiで有効化しておいたスキルが、ターミナルのセッション開始時に自動的に利用可能になります。

```bash
# claude.aiでスキルを有効化しておく
# 同じアカウントでターミナルからサインイン
claude
# → claude.aiで有効化済みのスキルが自動的に同期され利用可能になる
```

### 特定のマシンでは同期を止めたい場合

社内共有マシンや特定のプロジェクト専用環境など、アカウント側の設定をそのまま反映したくない場合はオプトアウトできます。

```json
// ~/.claude/settings.json などに設定
{
  "syncClaudeAiSkills": false,
  "syncClaudeAiPlugins": false
}
```

## 注意点

- API keyでの認証やBedrock経由など、認証方式によっては同期が行われない場合があります
- 同期をオフにすると、既に同期済みのスキル・プラグインは次回起動時にトラッシュへ移動され読み込まれなくなります
- スキルとプラグインは個別に設定でオプトアウトできるため、片方だけ同期させることも可能です
- 組織のポリシー（管理者による制限設定）によっては同期が制御される場合があります
