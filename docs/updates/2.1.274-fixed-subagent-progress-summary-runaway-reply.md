## 原文（日本語訳）
サブエージェントの進捗サマリーが、暴走した複数段落にわたる長文の返信によって置き換えられてしまっていた問題を修正。

## 原文（英語）
Fixed a sub-agent's progress summary being replaced by a runaway multi-paragraph reply

## 概要
Claude Codeでは、サブエージェント（Agentツールで起動した子エージェント）が作業を進めている間、その進捗状況を簡潔なサマリーとしてメインセッションに表示します。しかし、まれにサブエージェントが本来簡潔であるべき進捗報告の代わりに、制御が効かなくなったかのような複数段落にわたる長文の返信を生成し、これが進捗サマリー表示を占拠してしまう不具合がありました。今回の修正により、このような暴走した長文がサマリー表示を乗っ取ることがなくなりました。

## 基本的な使い方
特別な操作は不要です。サブエージェントを使ったタスク実行中、進捗表示が常に簡潔なサマリーとして保たれるようになります。

```bash
# サブエージェントを使うタスクの例
"複数のディレクトリを並行して調査してAgentツールで報告して"
```

## 実践例

### 大規模な調査タスクをサブエージェントに任せる場合
コードベース全体の調査など、時間のかかるタスクをサブエージェントに委任している間、以前はサブエージェントの応答が長文化すると進捗表示が読みにくい状態になることがありました。修正後は、進捗サマリーが簡潔に保たれ、メインセッションから実行状況を把握しやすくなります。

### 複数のサブエージェントを並行実行する場合
複数のサブエージェントを同時に走らせているとき、それぞれの進捗表示が暴走した長文に置き換わらなくなったことで、全体の状況を一目で確認しやすくなります。

## 注意点
- これは表示上の不具合修正であり、サブエージェントが最終的に返す成果物（レポート内容）そのものの品質を保証するものではありません。
- 長文の応答自体が発生しにくくなるわけではなく、進捗表示への悪影響が解消される点に注意してください。
