## 原文（日本語訳）

スピナー、OpenTelemetryの `effort` 値、トランスクリプトが、モデルが適用する前の段階で新しく選んだ努力レベルを表示していた問題を修正。現在有効なレベルが表示されます

## 原文（英語）

Fixed the spinner, OpenTelemetry `effort` values and transcripts naming a newly picked effort level during a task before the model applied it; they now show the level in force

## 概要

タスク中に `/effort` で変更しても、実際に反映されるまでは古いレベルで動いています。表示とテレメトリが実際に有効なレベルを示すよう修正されました。

## 基本的な使い方

```
/effort
```

変更後も、反映されるまでは従来のレベルが表示されます。

## 実践例

### テレメトリの正確な集計

OpenTelemetryの `effort` 属性が実態と一致するため、利用分析の信頼性が上がります。

## 注意点

- 変更を選んだ直後の表示は、適用されるまで前のレベルのままです。
