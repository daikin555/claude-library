## 原文（日本語に翻訳）

組み込み Mod「You should know」を追加: サイドエージェントがあなたをサポートし、あなたや Claude が見落としそうな点を指摘します。`/plugin enable cc-plugin-you-should-know@builtin` で有効化できます（テレメトリが有効なファーストパーティのセッション向け）。

## 原文（英語）

Added You should know, a built-in mod where a side agent watches your back and flags things you or Claude might miss. Turn it on with `/plugin enable cc-plugin-you-should-know@builtin` (for first-party sessions with telemetry on)

## 概要

「You should know」は、作業中のセッションを横で見守るサイドエージェントが、あなたや Claude が見落としているかもしれない点を指摘する組み込み Mod です。メインの会話とは別のエージェントが動くため、作業の流れを止めずに第二の視点を得られます。

## 基本的な使い方

```
/plugin enable cc-plugin-you-should-know@builtin
```

有効化後は通常どおり Claude Code を使うだけで、サイドエージェントが必要に応じて指摘を表示します。

## 実践例

### 大きなリファクタリング中の見落とし防止

複数ファイルにまたがる変更中に、修正漏れや影響範囲の確認不足を第三者の視点で指摘してもらう用途に向いています。

### 設定の確認

有効化できない場合は、利用条件（ファーストパーティのセッションで、テレメトリが有効であること）を満たしているか確認してください。

## 注意点

- 対象は**テレメトリが有効なファーストパーティのセッション**です。
- サイドエージェントが動くため、追加のトークン消費が発生する可能性があります。
