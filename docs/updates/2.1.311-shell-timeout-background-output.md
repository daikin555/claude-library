## 原文（日本語に翻訳）

タイムアウトに達したシェルコマンドの結果を改善しました。ここまでの出力を表示し、コマンドがバックグラウンドで実行され続けていることを伝えます。

## 原文（英語）

Improved shell commands that reach their timeout: the result now shows the output so far and says the command is still running in the background

## 概要

Bashツールのコマンドがタイムアウトした際、以前は状況が分かりにくいことがありました。今後はそこまでの出力が返り、コマンドがバックグラウンドで動き続けていることが明示されます。Claudeが状況を誤解して同じコマンドを再実行するのを防げます。

## 基本的な使い方

```text
ビルドを実行して、完了したら結果を教えて
```

長時間コマンドがタイムアウトしても、途中経過の出力とバックグラウンド実行中である旨が返ります。

## 実践例

### 長いテストスイート

テストが長引いてタイムアウトしても、途中までのログから進捗を判断できます。

### タイムアウトの調整

環境変数で既定のタイムアウトを調整できます。

```bash
BASH_DEFAULT_TIMEOUT_MS=300000 claude
```

## 注意点

- コマンドは止まっていないため、不要なら明示的に停止してください。
- 同じコマンドの二重起動に注意してください。
