## 原文（日本語に翻訳）

Bedrock、Vertex、Foundry、Claude apps ゲートウェイで、Opus 4.7 以降と Fable が `[1m]` サフィックスなしで既定の 1M コンテキストウィンドウを使うように変更しました（`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K を維持できます）。

## 原文（英語）

Changed Opus 4.7+ and Fable to use a 1M context window by default on Bedrock, Vertex, Foundry and the Claude apps gateway, with no `[1m]` suffix (`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` keeps 200K)

## 概要

Bedrock、Vertex、Foundry、Claude apps ゲートウェイを利用している場合、Opus 4.7 以降と Fable のモデルが、モデル ID に `[1m]` を付けなくても 1M トークンのコンテキストウィンドウを既定で使うようになりました。従来の 200K に戻したい場合は環境変数で指定します。

## 基本的な使い方

追加の設定は不要です。200K を維持したい場合のみ次を設定します。

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

## 実践例

### 大規模コードベースの調査

長い会話や大量のファイル読み込みでも、圧縮（compaction）が起きにくくなります。

### コストや挙動を従来どおりにしたい場合

```bash
CLAUDE_CODE_DISABLE_1M_CONTEXT=1 claude
```

## 注意点

- 対象は Bedrock、Vertex、Foundry、Claude apps ゲートウェイです。
- コンテキストが大きくなると、利用するトークン量や料金に影響する可能性があります。料金体系はプロバイダーの情報を確認してください。
- 従来の `[1m]` サフィックス付き指定は不要になりました。
