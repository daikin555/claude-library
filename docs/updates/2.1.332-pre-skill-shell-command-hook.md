# PreSkillShellCommand フックでスキルのインラインシェル実行を制御

## 原文（日本語に翻訳）

スキルやコマンドの読み込み時に、そのインラインシェルコマンドを拒否できる `PreSkillShellCommand` フックイベントを追加しました。2.1.331 以前では、このイベント名を含む設定ファイルがあると起動時にダイアログが開きます。

## 原文（英語）

Added a `PreSkillShellCommand` hook event that can refuse a skill or command's inline shell commands as it loads; on 2.1.331 and older, a settings file naming it opens a dialog at start

## 概要

`PreSkillShellCommand` は、スキルやスラッシュコマンドが読み込まれる際に含まれるインラインシェルコマンドを実行前に検査し、拒否できるフックイベントです。組織のポリシーに反するシェル実行を事前に止めたい場合に役立ちます。

## 基本的な使い方

`.claude/settings.json` にフックを登録します。

```json
{
  "hooks": {
    "PreSkillShellCommand": [
      {
        "hooks": [
          { "type": "command", "command": "~/.claude/hooks/check-skill-shell.sh" }
        ]
      }
    ]
  }
}
```

## 実践例

### 危険なコマンドを含むスキルを拒否する

フックのスクリプトで、`curl | sh` などのパターンを検出したら拒否の結果を返します。入力・出力の具体的な形式は公式のフックリファレンスを確認してください。

### チーム共有設定として配布する

管理設定やプロジェクト設定にフックを入れておけば、他人が作ったスキルを読み込む際の安全網になります。

## 注意点

- 2.1.331 以前のバージョンでこのイベント名を設定に書くと、起動時にダイアログが表示されます。バージョンを揃えてください。
- フックの入出力仕様は公式ドキュメントで確認してください。
