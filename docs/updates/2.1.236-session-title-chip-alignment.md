## 原文（日本語訳）

プロンプト枠の境界線上に表示されるセッションタイトルのチップを、フッターの右端と揃うように配置を修正しました。

## 原文（英語）

Aligned the session title chip on the prompt border with the footer's right edge

## 概要

Claude Codeのターミナル画面では、入力欄（プロンプト）の枠線上にセッションタイトルを示す小さなチップ（ラベル）が表示され、その下のフッターにはモデル名やディレクトリなどの情報が並びます。これまではこのタイトルチップの右端の位置が、フッター側の右端とわずかにずれていました。今回の修正で両者の右端が揃うようになり、画面全体の見た目がより整った印象になります。

## 基本的な使い方

これは見た目のみの調整であり、ユーザー側で行う操作は特にありません。通常どおりClaude Codeを起動すると、プロンプト枠上部のセッションタイトルチップの右端が、フッターの右端と同じ位置に揃って表示されます。

```
claude
```

## 実践例

### 通常のインタラクティブセッションを開始したとき

セッションを開始すると、プロンプト枠の上辺にタイトルチップが表示されます。修正後はこのチップの右端が、フッターに表示されるモデル名やコンテキスト使用量などの右端と一直線に揃って見えるようになります。

### ウィンドウ幅を変えながら作業するとき

ターミナルの幅を変更した場合でも、タイトルチップとフッターの右端が同じ基準で揃うため、画面のどのサイズでもレイアウトの統一感が保たれます。

## 注意点

- 機能面での変更はなく、純粋に表示位置を整えるだけの修正です
- チップに表示される内容（セッションタイトルそのもの）は変わりません
