# OpenTelemetry に claude_code.safety_event イベントを追加

## 原文（日本語に翻訳）

- 権限ルール、auto mode、セーフティチェック、フック、またはサンドボックスがツール呼び出しを停止・確認要求・差し戻しするたびに発行される OpenTelemetry イベント `claude_code.safety_event` を追加

## 原文（英語）

- Added the `claude_code.safety_event` OpenTelemetry event for each tool call a permission rule, auto mode, a safety check, a hook or the sandbox stopped, prompted or sent back

## 概要

ツール呼び出しが安全機構によって止められた、確認を求められた、または差し戻された場合に、`claude_code.safety_event` が OpenTelemetry イベントとして出力されます。組織全体で「どの安全機構がどれだけ介入したか」を集計できます。

## 基本的な使い方

既存の OpenTelemetry 設定をそのまま使います。

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_LOGS_EXPORTER=otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
claude
```

## 実践例

### 権限ルールの見直し

safety_event を集計し、頻繁に確認が出るルールを allow リストへ移すか検討します。

### フックやサンドボックスの監査

フックやサンドボックスによる拒否の頻度を監視し、想定外のブロックを検知します。

## 注意点

- イベントの属性の詳細は公式の monitoring ドキュメントで確認してください。
- テレメトリの収集先と保持ポリシーは組織の規定に従ってください。
