## 原文（日本語訳）

自動生成されるセッションタイトルを改善し、依頼内容をそのまま言い換えた文章（例：「Fix the login button on mobile」）ではなく、短く具体的な名前（例：「Login button bug」）として読めるようにしました。

## 原文（英語）

Improved auto-generated session titles to read as short, specific names (e.g. "Login button bug") rather than sentences restating your request (e.g. "Fix the login button on mobile")

## 概要

Claude Codeはセッション一覧やRemote Controlなどで見分けやすいように、会話内容から自動的にセッションタイトルを生成しています。従来はユーザーの依頼文をほぼそのまま言い換えた「文章形式」のタイトルになりがちで、一覧で見たときに冗長で見分けづらいことがありました。今回の改善で、タイトルは「Login button bug」のような短く具体的な名詞句として生成されるようになり、セッション一覧の視認性が向上しました。

## 基本的な使い方

タイトルは会話開始時にClaude Codeが自動生成するため、ユーザー側の操作は不要です。より短く、内容を的確に表す名前が自動的に付けられます。

改善前のタイトル例:
```
Fix the login button on mobile
```

改善後のタイトル例:
```
Login button bug
```

## 実践例

### 複数セッションを並行管理する場合

Remote Controlやセッション一覧で複数のタスクを同時に進めている場合、短く具体的なタイトルが並ぶことで、どのセッションが何のタスクかを一目で把握しやすくなります。

```
セッション一覧の例:
- Login button bug
- CSV export timeout
- Dark mode contrast
- API rate limit retry
```

### 長い依頼文を投げた場合

「モバイル版のログインボタンが小さすぎてタップしづらいので、パディングを増やして、かつダークモード時のコントラストも確認してほしい」のような長い依頼をしても、タイトルは要点を抽出した短い名前（例：「Login button padding & contrast」）にまとめられます。

### 検索・振り返り時の効率化

過去のセッションを名前で検索したり、あとから見返したりする際、文章的なタイトルより名詞句のタイトルの方が一覧をスキャンしやすく、目的のセッションを素早く見つけられます。

## 注意点

- タイトルはあくまで自動生成であり、必ずしも意図通りの表現になるとは限りません
- 既存セッションのタイトルが自動的に付け替えられるわけではなく、この改善は新規に生成されるタイトルに適用されます
- タイトルの精度は会話の内容量や明確さに依存します
