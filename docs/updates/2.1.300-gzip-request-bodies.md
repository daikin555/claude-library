# 大きなリクエストの gzip 圧縮が常時有効に（無効化は環境変数で）

## 原文（日本語に翻訳）

api.anthropic.com への大きなリクエストで、テレメトリが無効でも gzip 圧縮を使うように変更しました。無効にするには `CLAUDE_CODE_GZIP_REQUEST_BODIES=0` を設定します。

## 原文（英語）

Changed large requests to api.anthropic.com to use gzip compression even when telemetry is disabled; set `CLAUDE_CODE_GZIP_REQUEST_BODIES=0` to turn it off

## 概要

大きなリクエストボディは、テレメトリ設定に関係なく gzip 圧縮して送信されます。長い会話では送信量が減ります。プロキシなどが圧縮ボディを扱えない環境では、環境変数で無効化できます。

## 基本的な使い方

```bash
# 圧縮を無効にする
CLAUDE_CODE_GZIP_REQUEST_BODIES=0 claude
```

## 実践例

### 社内プロキシが圧縮ボディを拒否する場合

リクエストが拒否される、または検査できない場合は、上記の環境変数で圧縮を止めて切り分けます。

### settings.json の env に固定する

```json
{
  "env": {
    "CLAUDE_CODE_GZIP_REQUEST_BODIES": "0"
  }
}
```

## 注意点

- 対象は api.anthropic.com への大きなリクエストです。
- 通常は変更不要で、問題が出た場合のみ無効化してください。
