## 原文（日本語訳）

`/autocompact` が自動compactウィンドウをモデルごとに保存するよう変更した。モデルを切り替えても、それぞれが自分の設定を保持する。

## 原文（英語）

Changed `/autocompact` to save the auto-compact window per model, so each model keeps its own setting when you switch

## 概要

自動compactが働くコンテキストウィンドウの設定が、モデル単位で保存されます。モデルごとにコンテキスト長や使い方が違うため、切り替えのたびに設定し直す必要がなくなります。

## 基本的な使い方

```text
/autocompact
```

現在のモデルを選んだ状態で設定すると、その値はそのモデルにのみ適用されます。

## 実践例

### 長いコンテキストのモデルだけ大きく設定する

```text
/model
/autocompact
```

### 作業内容でモデルを切り替える

調査用と実装用でモデルを使い分けても、それぞれの設定が保たれます。

## 注意点

- 設定は現在選択中のモデルに紐づくため、設定前に `/model` で対象を確認してください。
- 以前の全モデル共通の値は、モデルごとの値で置き換わる可能性があります。
