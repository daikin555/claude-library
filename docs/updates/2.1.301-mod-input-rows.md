# modのInputに rows を追加して複数行入力に対応

## 原文（日本語に翻訳）

mod の `Input` に `rows` を追加しました。ターミナルで複数行のテキストフィールドになり、Enter で送信、Shift+Enter または Enter の前のバックスラッシュで改行できます。

## 原文（英語）

Added `rows` to a mod's `Input`: a text field of several lines in the terminal, where Enter submits and Shift+Enter or a backslash before Enter starts a new line

## 概要

modが表示する `Input` コンポーネントに `rows` を指定すると、複数行のテキストフィールドを作れます。長めのメモや説明文の入力を伴うmodで便利です。

## 基本的な使い方

```tsx
<Input rows={4} placeholder="詳細を入力" />
```

操作方法:

- Enter: 送信
- Shift+Enter、または行末のバックスラッシュ + Enter: 改行

## 実践例

### コミットメッセージ入力

本文を複数行で入力するmodのフォームに利用できます。

### レビューコメントの記入

複数行の文章を入力させ、Enterで確定する流れを作れます。

## 注意点

- 上記のキー操作はターミナル上のものです。
- 詳細なAPIは [plugin-authoring](https://code.claude.com/docs) 関連のドキュメントで確認してください。
