# ルートやホーム等を対象とする rm コマンドの承認を強化

## 原文（日本語に翻訳）

ルート、ホーム、トップレベルのフォルダー、作業フォルダーを対象とする `rm` コマンドの多くで承認を求めるようになりました。誰も応答できない環境では拒否されます。

## 原文（英語）

Changed more `rm` commands aimed at the root, home, a top-level folder or the working folder to ask for approval; where nobody can answer, they're refused

## 概要

危険度の高い `rm` を誤って実行しないよう、承認が必要になるコマンドの範囲が広がりました。

## 基本的な使い方

特別な設定は不要です。該当コマンドで承認プロンプトが表示されます。

## 実践例

### 対話セッション

`rm -rf ~/something` のようなコマンドの前に確認が表示されます。

### 非対話（`claude -p` など）

承認できる相手がいないため、該当コマンドは拒否されます。

## 注意点

- 自動化スクリプトで該当する `rm` を使っていた場合は、対象を狭めるなど見直してください
