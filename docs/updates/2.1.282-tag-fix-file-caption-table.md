## 原文（日本語訳）

Claudeがアップロードするファイルが、表を含むキャプションを正しく持てなかった不具合を修正しました。キャプションは現在、返信と同じ書式でレンダリングされるようになりました。

## 原文（英語）

[Claude Tag] Fixed files Claude uploads to Slack not being able to carry a caption containing a table with the same formatting as replies

## 概要

Slack上でClaudeがファイルをアップロードする際、そのファイルに付けられるキャプション（説明文）にMarkdownの表が含まれていると、通常の返信メッセージと同じようには表として整形されず、崩れた形で表示されてしまう不具合がありました。今回の修正で、ファイルのキャプションも通常の返信と同じ書式（表を含む）で正しくレンダリングされるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。Claudeが表を含む説明とともにファイルをアップロードする場面で、この修正が自動的に適用されます。

## 実践例

### データ集計結果をファイルとキャプションで共有

CSVやレポートファイルをアップロードする際、そのファイルの要約データを表形式のキャプションとして添えても、正しく整形されて表示されます。

### 比較表を伴うドキュメント生成タスク

複数の選択肢を比較する表を含んだキャプション付きでドキュメントファイルを共有する場合にも、読みやすい表形式で表示されるようになります。

## 注意点

- この修正はSlackへのファイルアップロード時のキャプション表示に関するものです
- 表以外の通常のテキストキャプションには元々大きな問題はありませんでした
