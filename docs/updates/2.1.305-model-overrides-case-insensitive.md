# modelOverrides の大文字小文字・[1m]タグ差異で /effort と /autocompact が効かない問題を修正

## 原文（日本語に翻訳）

- モデル名が `modelOverrides` の値と大文字小文字や `[1m]` タグだけ異なる場合に、`/effort` と `/autocompact` の設定が適用されない問題を修正

## 原文（英語）

- Fixed `/effort` and `/autocompact` settings not applying when the model name differed from a `modelOverrides` value by letter case or a `[1m]` tag

## 概要

`modelOverrides` でモデル名を別名に割り当てている場合、表記が大文字小文字や `[1m]` タグだけ違うと `/effort`・`/autocompact` が反映されませんでした。この差異が吸収され、設定が正しく適用されます。

## 基本的な使い方

```json
{
  "modelOverrides": {
    "claude-sonnet-5-5": "my-gateway-sonnet"
  }
}
```

その上で `/effort` や `/autocompact` を実行します。

## 実践例

### 1Mコンテキスト指定のモデルを使う場合

`[1m]` の有無に関わらず、effortや自動コンパクト設定が一貫して適用されます。

### ゲートウェイ固有のモデル名を使う場合

大文字小文字の揺れによる設定漏れを気にする必要が減ります。

## 注意点

- 設定は `/effort`・`/autocompact` 実行後に反映されているか確認すると安心です。
