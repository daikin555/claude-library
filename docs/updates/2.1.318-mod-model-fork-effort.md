# mod の $.model.fork に effort オプションを追加

## 原文（日本語訳）

mod の `$.model.fork` に `effort` オプションを追加しました。セッションのeffortに関わらず、簡単なサブ作業を `low` で実行できます。結果には送信されたeffortが報告されます。

## 原文（英語）

Added an `effort` option to a mod's `$.model.fork`, so a quick side job can run at `low` whatever effort the session uses; the result reports the effort sent

## 概要

modから呼び出す補助的なモデル呼び出し（fork）で、effortを個別に指定できるようになりました。セッションが高effortでも、分類や要約などの軽い処理は低コスト・低遅延で実行できます。

## 基本的な使い方

次のコードは説明用の例です。引数の正確な形はmodのドキュメントで確認してください。

```js
const result = await $.model.fork({
  prompt: "この差分を一行で要約して",
  effort: "low",
});
console.log(result.effort); // 送信されたeffort
```

## 実践例

### 軽量な副次タスク

コミットメッセージ案やラベル分類など、深い推論が不要な処理を `low` で実行して待ち時間を減らします。

### 実際のeffortの確認

結果に送信されたeffortが含まれるため、ログに記録して意図通りに動作したか検証できます。

## 注意点

- effortを下げると推論も浅くなるため、複雑な処理には向きません。
