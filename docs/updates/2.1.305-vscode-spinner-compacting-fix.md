# [VSCode] spinnerVerbs が短い場合に「Compacting...」が切れる問題を修正

## 原文（日本語に翻訳）

- [VSCode] `spinnerVerbs` 設定が組み込みの動詞を短いものに置き換えた場合に、スピナーが「Compacting...」を切ってしまう問題を修正

## 原文（英語）

- [VSCode] Fixed the spinner cutting off "Compacting..." when your `spinnerVerbs` setting replaces the built-in verbs with short ones

## 概要

`spinnerVerbs` で短い動詞に置き換えている場合に、コンパクション中の表示が途切れる問題が修正されました。

## 基本的な使い方

```json
{ "spinnerVerbs": { "mode": "replace", "verbs": ["Go"] } }
```

## 実践例

### スピナーのカスタマイズ

短い動詞を使っても「Compacting...」が完全に表示されます。

## 注意点

- `spinnerVerbs` の書式は公式ドキュメントで確認してください。
