## 原文（日本語訳）

`claude plugin validate` に、プラグインのTypeScript hooksモジュールの型チェックを追加しました。各検出結果は警告として扱われ、`--strict` を付けると失敗になります。

## 原文（英語）

Added type checking of a plugin's TypeScript hooks module to `claude plugin validate`; each finding is a warning, and `--strict` fails on it

## 概要

`claude plugin validate` が、プラグインに含まれるTypeScript製のhooksモジュールを型チェックするようになりました。型エラーは通常は警告として表示され、`--strict` を指定した場合は検証失敗（非ゼロ終了）になります。

## 基本的な使い方

```bash
# 警告として表示
claude plugin validate ./my-plugin

# 警告もエラー扱いにする
claude plugin validate ./my-plugin --strict
```

## 実践例

### CIでの利用

```yaml
- name: Validate plugin
  run: claude plugin validate . --strict
```

### 公開前チェック

マーケットプレイスへ公開する前にローカルで実行し、型の不整合を早期に発見できます。

## 注意点

- 既定では警告のみで、終了コードには影響しません
- 同バージョンでは、modの `engine.create` hookが追加・除外・置換する `$` 名詞も検証対象に追加されています
- `engine.create` hookが受け付けられる形式で書かれていないmodは検証に失敗します（インストール済みのmodは引き続き読み込まれます）
