## 原文（日本語訳）
Claude apps ゲートウェイ経由でサインインしている場合の `/logout` を更新し、トークン失効に対応していると通知しているゲートウェイ上のセッションも終了するようにしました

## 原文（英語）
Updated `/logout` for Claude apps gateway sign-ins to also end the session on gateways that advertise token revocation

## 概要
企業などでClaude appsのゲートウェイ経由でサインインしている場合、これまで `/logout` を実行してもローカルのセッション情報が消えるだけで、ゲートウェイ側のセッションが有効なまま残ることがありました。今回の更新により、トークン失効（revocation）に対応していると通知するゲートウェイに対しては、`/logout` 実行時にゲートウェイ側のセッションも合わせて終了させるようになり、よりセキュアなサインアウトが可能になります。

## 基本的な使い方
通常どおり `/logout` を実行するだけです。

```
/logout
# → ローカルのセッションに加え、対応しているゲートウェイ側のセッションも終了する
```

## 実践例

### 企業のSSOゲートウェイ経由で利用している場合
```
claude
> /logout
# ゲートウェイがトークン失効に対応していれば、
# サーバー側のトークンも無効化され、盗まれたトークンの再利用リスクが下がる
```

### 共有端末での作業終了時
```
# 作業終了時に必ず/logoutを実行する運用にすることで、
# 端末に残ったトークンが後から悪用されるリスクを減らせる
> /logout
```

## 注意点
- ゲートウェイがトークン失効を通知（advertise）していない場合、この動作は従来どおりローカルセッションの終了のみになります。
- 通常のAnthropicアカウントでの直接サインインには影響しません。
- 組織の管理者はゲートウェイ側の対応状況を確認してください。
