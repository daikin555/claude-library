## 原文（日本語訳）

`/permissions` にAuto modeタブが追加され、Auto mode（自動判定）分類ルールの表示と編集ができるようになりました。

## 原文（英語）

Added an Auto mode tab to `/permissions` for viewing and editing auto mode classifier rules

## 概要

Claude CodeのAuto modeは、コマンドやツール呼び出しが安全かどうかを自動的に判定して実行を許可・拒否する仕組みです。これまでその判定に使われる分類ルールは可視化されておらず、どのような基準で自動許可・拒否が行われているかを確認するのが難しい状態でした。今回のアップデートで `/permissions` コマンドにAuto mode専用のタブが追加され、分類ルールを一覧表示したり、必要に応じて編集したりできるようになりました。

## 基本的な使い方

`/permissions` を実行し、表示されたタブの中からAuto modeタブを選択します。

```
/permissions
```

タブを切り替えると、現在Auto modeで使われている分類ルールの一覧が表示され、その場で内容を確認・編集できます。

## 実践例

### Auto modeの挙動を把握したい場合

チームで導入したAuto modeが具体的にどのコマンドを自動許可しているのか分からないとき、`/permissions` のAuto modeタブを開くことで、適用されているルールを一目で確認できます。

### 誤った自動許可を修正したい場合

意図せず広い範囲のコマンドが自動許可されていることに気づいた場合、Auto modeタブから該当ルールを直接編集し、より安全な範囲に絞り込むことができます。

### 新しいプロジェクトでAuto modeを調整する場合

新しいプロジェクトに参加した際、既存のAuto mode設定がどうなっているかをまず確認し、そのプロジェクトの運用方針に合わせてルールを調整する、といった使い方ができます。

## 注意点

- Auto mode自体を有効化しているかどうかは別の設定に依存します。まずAuto modeが有効になっている必要があります
- 分類ルールの編集は権限設定そのものに影響するため、変更内容は慎重に確認することが推奨されます
- タブのUIはターミナル環境によって表示崩れが起きる場合があるため、対応していないターミナルでは従来の表示にフォールバックする可能性があります
