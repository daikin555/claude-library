## 原文（日本語訳）
AskUserQuestionのプレビューモードで、Enterキーでメモを送信するとハイライトされていた選択肢が失われてしまう問題を修正しました。

## 原文（英語）
Fixed AskUserQuestion preview mode dropping the highlighted option when submitting a note with Enter

## 概要
AskUserQuestionのプレビューモードでは、選択肢をハイライトしながらメモを入力し、Enterキーで送信できます。しかし、この送信操作を行うと、それまでハイライトされていた選択肢の情報が失われてしまう不具合がありました。今回の修正により、Enterでメモを送信してもハイライト中の選択肢が正しく保持されるようになりました。

## 基本的な使い方
選択肢をハイライトした状態でメモ欄に入力し、Enterキーを押して送信します。

```
選択肢2: このファイルをリネームする  ← ハイライト中
メモ入力 → Enter
```

## 実践例

### 修正前の挙動
選択肢をハイライトした状態でメモを入力してEnterを押すと、選択されていたはずの選択肢情報が消えてしまい、意図した選択が反映されないことがありました。

### 修正後の挙動
Enterで送信した後も、ハイライトしていた選択肢が正しく維持され、メモとともに意図通りClaudeに伝わるようになりました。

## 注意点
- この修正はプレビューモードでメモを併用する場合に特に影響します。メモを使わないシンプルな選択操作には直接関係しません。
- 重要な選択を行う際は、送信後に選択内容が意図通り反映されているか確認すると安心です。
