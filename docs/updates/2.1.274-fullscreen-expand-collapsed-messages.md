## 原文（日本語訳）

フルスクリーンモードにおいて、折りたたまれたチームメイトおよびエージェントのメッセージをクリックして展開できるようになりました。

## 原文（英語）

Added click-to-expand for collapsed teammate and agent messages in fullscreen mode

## 概要

複数のチームメイトやサブエージェントが並行して動くセッションをフルスクリーンモードで閲覧していると、メッセージが折りたたまれて要約表示されることがあります。今回の変更により、そうした折りたたまれたメッセージをクリック一つで展開し、詳細な内容をその場で確認できるようになりました。これにより、長い会話履歴の中から必要な情報を探す手間が軽減されます。

## 基本的な使い方

フルスクリーンモードでチームメイトやエージェントのメッセージが折りたたまれて表示されている箇所をクリックするだけで、内容が展開されます。

```
[折りたたまれたメッセージ] ▶ クリックして詳細を表示
```

## 実践例

### 複数エージェントの並行作業を確認するとき

複数のサブエージェントが並行してタスクを進めている際、フルスクリーンモードで一覧表示された折りたたみメッセージの中から、気になるエージェントの出力だけをクリックして詳細を確認できます。

### チームメイトとのやり取りを振り返るとき

チームメイトからの長い応答が要約表示されている場合でも、クリックすることで元の全文をその場で展開して確認でき、別画面に切り替える必要がありません。

## 注意点

- この機能はフルスクリーンモードでの表示に関するUI改善であり、通常のインラインビューでの挙動には影響しません。
- 展開状態はメッセージごとに個別に切り替わります。
