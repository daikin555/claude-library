# Enterprise Admin Console で管理される組織へのサインイン

## 原文（日本語に翻訳）

Anthropic の Enterprise Admin Console で管理される組織へのサインインを追加しました。`claude auth login` の後、Claude Code は組織の設定を適用し、組織のクラウドプロバイダーまたはゲートウェイを使用します。

## 原文（英語）

Added sign-in to organizations managed in Anthropic's Enterprise Admin Console: after `claude auth login`, Claude Code applies the organization's settings and uses its cloud provider or gateway

## 概要

Enterprise Admin Console で管理されている組織のアカウントでサインインできるようになりました。サインイン後、管理者が定めた設定が自動的に適用され、組織指定のクラウドプロバイダーやゲートウェイ経由で接続されます。

## 基本的な使い方

```bash
claude auth login
```

画面の案内に従って組織アカウントでサインインします。

## 実践例

### 組織ポリシーの一括適用

管理者はコンソール側で設定を配布し、メンバーはサインインするだけで同じ設定・接続先を利用できます。

### サインイン後の確認

```bash
claude
# /status などで現在のアカウントと接続先を確認
```

## 注意点

- 利用できる設定項目や対象プランは組織の管理者設定に依存します
- 組織側の設定が個人設定より優先される場合があります
