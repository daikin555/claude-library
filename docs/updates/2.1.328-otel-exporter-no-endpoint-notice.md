# OpenTelemetry エクスポーターのエンドポイント未設定を /status と claude doctor で通知

## 原文（日本語に翻訳）

OpenTelemetry エクスポーターにエンドポイントがなく、データが失われそうな場合に、`/status` と `claude doctor` で通知するようにしました。

## 原文（英語）

Added a notice in `/status` and `claude doctor` when an OpenTelemetry exporter has no endpoint and its data would likely be lost

## 概要

テレメトリーのエクスポーターを有効にしたのにエンドポイントが未設定だと、データが送信先なく捨てられてしまいます。この設定ミスに気付けるよう、診断コマンドが警告を出すようになりました。

## 基本的な使い方

```bash
claude doctor
```

セッション内では `/status` でも確認できます。

## 実践例

### 監視基盤の導入時チェック

OTel 関連の環境変数を配布した後、`claude doctor` を実行して通知が出ていないか確認すると、設定漏れを早期に発見できます。

## 注意点

- 通知は設定ミスの検出が目的で、設定自体は自動修正されません
- 同バージョンでは、不正な `OTEL_RESOURCE_ATTRIBUTES` エントリが他のラベルまで消してしまう問題も修正されています
