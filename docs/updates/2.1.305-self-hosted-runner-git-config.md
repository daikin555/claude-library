# セルフホストランナーで GIT_CONFIG を使う認証ヘルパーのリポジトリアクセス失敗を修正

## 原文（日本語に翻訳）

- セルフホストランナー: gitの認証ヘルパーやaskpassプログラムが `GIT_CONFIG` 経由で設定を読む場合に、2.1.296以降リポジトリアクセスが失敗する問題を修正

## 原文（英語）

- Self-hosted runner: Fixed repository access failing since 2.1.296 when a git credential helper or askpass program reads its settings through `GIT_CONFIG`

## 概要

2.1.296以降、`GIT_CONFIG` で設定を読む認証ヘルパー／askpassを使う環境でリポジトリアクセスが失敗していた問題の修正です。

## 基本的な使い方

更新のみで解消します。`GIT_CONFIG` を使った独自認証構成は従来どおり利用できます。

## 実践例

### 社内の独自認証ヘルパー

専用の `GIT_CONFIG` を指す構成のランナーでも、clone／fetchが再び動作します。

## 注意点

- 2.1.296〜2.1.304の間に症状が出ていた環境が対象です。
