## 原文（日本語に翻訳）

プラグインのメッセージ、ログ、およびVS Codeのプラグインダイアログが、一部のgitアドレスに対して誤ったサーバーを表示してしまっていた問題を修正

## 原文（英語）

Fixed plugin messages, logs and the VS Code plugin dialog showing the wrong server for some git addresses

## 概要

プラグインをgitリポジトリのアドレスから追加・管理する際、Claude Codeはメッセージやログ、そしてVS Code拡張のプラグインダイアログ上にそのサーバー（ホスト名）を表示します。これまで、特定の形式のgitアドレスに対して、実際とは異なるサーバー名が表示されてしまう不具合がありました。今回の修正により、gitアドレスの解析が改善され、正しいサーバー名が表示されるようになりました。

## 基本的な使い方

プラグインをgitアドレスから追加する際、表示されるサーバー名は正しいホストと一致するようになりました。

```bash
claude plugin marketplace add git@example.com:org/plugins.git
# → メッセージやログに正しいサーバー名（example.com）が表示される
```

## 実践例

### VS Codeのプラグインダイアログでの表示

VS Code拡張からプラグインを管理する際、ダイアログに表示されるサーバー名が特定のgitアドレス形式で誤っていましたが、修正後は正しく表示されます。

```
# VS Codeのプラグイン管理ダイアログを開く
# → gitアドレスに対応する正しいサーバー名が表示される
```

### CLIのログ出力での確認

CLIでプラグインを操作した際のログにも、正しいサーバー名が記録されるようになりました。

```bash
claude plugin marketplace list
# → 各マーケットプレイスのサーバー名が正確に表示される
```

## 注意点

- この不具合は特定の形式のgitアドレス（sshやカスタムポート指定など）で発生しやすい傾向がありました
- 表示上の問題であり、実際の接続先やインストール処理自体には影響していませんでした
- VS Code拡張を利用している場合は、拡張機能のアップデートも併せて確認してください
