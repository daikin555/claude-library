# Amazon Bedrock などのサードパーティ環境で Opus 4.6 / Sonnet 4.6 の auto モードを利用可能に

## 原文（日本語に翻訳）

Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude apps gateway 上の Claude Opus 4.6 と Sonnet 4.6 向けに auto モードを追加しました。権限モードを指定しないインタラクティブセッションは auto モードで開始します。

## 原文（英語）

Added auto mode for Claude Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude apps gateway; interactive sessions with no permission mode start in it

## 概要

v2.1.328 では、サードパーティプロバイダー経由で Claude Code を利用している環境でも、Opus 4.6 / Sonnet 4.6 で auto モードが使えるようになりました。権限モードを明示しないインタラクティブセッションは auto モードで始まります。あわせて plan モードや Bash の権限プロンプトも auto モードを使う／案内する形に変わり、`disableAutoMode` で両方を無効化できます。

## 基本的な使い方

```bash
# 権限モードを指定せずに起動すると auto モードで開始する
claude

# 明示的に指定する場合
claude --permission-mode default
```

## 実践例

### auto モードを無効化したい組織設定

```json
{
  "disableAutoMode": true
}
```

この設定を managed settings などに入れると、plan モードや Bash プロンプトでの auto モードの利用・案内も止まります。

### ゲートウェイ越しでの利用

`CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` を設定し、betas を拒否するゲートウェイ配下の Bedrock / Agent Platform / Foundry / Claude apps gateway で、毎ターン auto モードが失敗する不具合も同バージョンで修正されています（Claude Desktop 以外）。

## 注意点

- 対象はOpus 4.6 と Sonnet 4.6 のサードパーティプロバイダー利用時です
- 権限モードを指定しない起動の既定動作が変わるため、運用ルールがある場合は `disableAutoMode` や権限設定を確認してください
