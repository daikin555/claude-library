## 原文（日本語訳）

サーバー管理設定を利用している一部のTeam/Enterpriseユーザーで、`curl -fsSL https://claude.ai/install.sh | bash` が「Raw mode is not supported」というエラーで失敗する問題を修正しました。

## 原文（英語）

Fixed `curl -fsSL https://claude.ai/install.sh | bash` failing with "Raw mode is not supported" for some Team/Enterprise users with server-managed settings

## 概要

Claude Codeの公式インストールスクリプトは、`curl | bash` の形でパイプ経由で実行されることがあります。この実行方式では標準入力が対話的なターミナルとして扱われないため、インストーラーが端末のRaw modeを要求する処理を内部的に行おうとすると失敗することがありました。特にサーバー管理設定（Team/Enterpriseプランで管理者がポリシーを一括管理する設定）を利用している環境でこの問題が発生しやすく、インストール自体ができないという状況につながっていました。今回の修正でこの依存が解消され、対象のユーザーでもインストールスクリプトが正常に完了するようになりました。

## 基本的な使い方

修正後は、通常のインストールコマンドをそのまま実行すれば問題なく完了します。

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## 実践例

### Enterprise管理下の開発マシンでの初回セットアップ

サーバー管理設定が適用された会社のマシンで新しく開発環境をセットアップする際、以前は上記コマンドがエラーで止まってしまうことがありました。修正後はそのまま実行してインストールを完了できます。

### CI/コンテナ環境での非対話インストール

パイプ経由でのインストールはCIやDockerビルドなど非対話的な環境でもよく使われます。Raw mode関連のエラーによってビルドが失敗するケースがなくなり、自動化されたセットアップフローが安定します。

### 複数拠点のチームへの展開

Team/Enterpriseプランで組織全体にClaude Codeを展開する際、一部のユーザー環境だけでインストールが失敗するというばらつきがなくなり、展開作業の手間が減ります。

## 注意点

- この問題はサーバー管理設定を持つ一部のTeam/Enterpriseユーザーに限定して発生していました。すべてのユーザーが影響を受けていたわけではありません
- インストールスクリプトが依然として失敗する場合は、ネットワーク環境やプロキシ設定など別要因の可能性があるため、公式ドキュメントの手動インストール手順も確認してください
