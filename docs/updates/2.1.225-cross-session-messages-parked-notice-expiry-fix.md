## 原文（日本語訳）

クロスセッションメッセージがヘッドレスセッションと起動時に通知や有効期限なしで待機状態のまま留まる問題を修正しました

## 原文（英語）

Fixed cross-session messages staying parked without a notice or expiry in headless sessions and during startup

## 概要

クロスセッションメッセージング機能で、ヘッドレスセッション（`claude -p`で実行する非対話的なセッション）や起動中のセッションに到着したメッセージが、通知なく無期限に「待機状態」のまま留まる問題が修正されました。これまでメッセージが失われたり停滞したりする可能性がありましたが、この修正により、メッセージは適切な通知を受け取るか、または設定に従って適切に有効期限が切れるようになりました。

## 基本的な使い方

クロスセッションメッセージングでは、複数のセッション間でテキストメッセージを送受信できます。ヘッドレスセッション（`-p`フラグで実行）は従来、メッセージ受信用のインボックスソケットをバインドする一方で、メッセージの処理が不完全でした。

この修正により：

- **ヘッドレスセッションがメッセージを受け取るとき**：`crossSessionInbound`設定に従って動作が決まります
  - `accept`に設定：メッセージがClaudeに配信されます
  - `hold`に設定：メッセージが保留され、`dialogExpiry`（デフォルト5分）時間内に承認される必要があります。期限切れの場合は自動的に削除されます
  - `refuse`に設定：メッセージが即座に拒否されます

- **起動中のセッション**：メッセージが到着した際に、セッションが起動完了するまで適切に処理されるようになり、メッセージの損失や無限待機が防止されます

## 実践例

### CI環境のヘッドレスセッションがメッセージを受け取る場合

```bash
# CI内でヘッドレスセッションを実行
claude -p "Run the build and deploy" \
  --settings '{"crossSessionInbound":"accept"}' \
  --allowedTools "Bash,Read"
```

別のセッションから以下のようにメッセージを送信：

```text
Build completed successfully on main branch. Deploy is safe to proceed.
```

修正前：メッセージがCI環境で無通知のまま待機状態に留まり、完全に失われる可能性がありました

修正後：`crossSessionInbound`設定に基づいて：
- `accept`に設定されている場合、メッセージはClaudeに配信されてプロンプト内で確認できます
- `hold`に設定されている場合、メッセージは保留され、タイムアウト（デフォルト5分）に達すると自動削除されます

### セッション起動中に別のセッションからメッセージが到着する場合

```bash
# セッション A: 起動中に別セッションからメッセージを受け取る
claude --name session-a --settings '{"crossSessionInbound":"hold"}'
```

```bash
# セッション B: セッション A の起動中にメッセージを送信
claude -p "Alert session-a: the database migration was reverted on main"
```

修正前：セッションAが起動完了前にメッセージが到着した場合、そのメッセージは無限に待機状態のままになり、セッションA起動後も配信されませんでした

修正後：
- セッション A が起動完了すると、待機中のメッセージが適切に処理されます
- `hold`設定の場合、ユーザーに承認ダイアログが表示されます
- 有効期限（`dialogExpiry`）に達するとメッセージは自動削除されます

## 注意点

- **設定の確認**：ヘッドレスセッションでメッセージを確実に受け取るには、`--settings`フラグで`crossSessionInbound`を`accept`に明示的に設定してください。デフォルトは`hold`なため、ヘッドレスセッションでは承認ダイアログが表示されません
- **有効期限**：`hold`モードでは`dialogExpiry`（デフォルト5分）内に承認する必要があります。期限切れ後は自動削除されます
- **適用範囲**：この修正はヘッドレスセッション（`claude -p`）、非表示セッション（`claude --bg`）、および起動中のセッションの起動ウィンドウに適用されます
- **クロスマシン通信**：他のマシンやRemote Control経由での動作も同様に改善されています
