# VS Code: ノートブックセルを「Add Cell to Chat」で添付

## 原文（日本語に翻訳）

[VSCode] ノートブックのセルメニューに「Add Cell to Chat」を追加しました。出力やエラーを含めてセルを添付できます。

## 原文（英語）

[VSCode] Added "Add Cell to Chat" to the notebook cell menu, which attaches a cell with its outputs or error

## 概要

セルのコードと出力・エラーをまとめて Claude Code に渡せます。

## 基本的な使い方

セルのメニューから「Add Cell to Chat」を選びます。

## 実践例

### エラーセルのデバッグ

エラー出力のあるセルを添付して、原因と修正を尋ねます。同バージョンでは null 出力やトレースバックなしのエラー出力を持つノートブックの読み込み失敗も修正されています。

## 注意点

- 出力が大きい場合はコンテキスト消費に注意してください。
