## 原文（日本語に翻訳）

セッション途中で `/cd` を実行した後、そのセッションをresumeすると内容が空になってしまう不具合を修正しました。

## 原文（英語）

Fixed resuming a session after a mid-session `/cd` coming back empty

## 概要

`/cd` はセッションを再起動せずに作業ディレクトリを移動できるコマンドです。セッションのトランスクリプトは `~/.claude/projects/<project>/<session-id>.jsonl` のように、作業ディレクトリのパスをエンコードしたディレクトリ配下に保存されており、`/cd` でディレクトリを移動すると、そのセッションは移動先ディレクトリのプロジェクトストレージに再配置されます。今回の修正以前は、セッションIDを指定して `claude --resume <session-id>` を実行した際の検索範囲が「現在のプロジェクトディレクトリとそのgit worktree」に限られていたため、`/cd` で移動した後のセッションを、移動前のディレクトリ（またはそれ以外のディレクトリ）から `--resume` しようとすると、セッションが見つからず内容が空として返ってくることがありました。v2.1.223では、セッションIDによる検索が現在のプロジェクト・worktreeで見つからない場合、マシン上の他の全プロジェクトにもフォールバックして探すように改善され、`/cd` で移動したセッションでも正しくresumeできるようになりました。

## 基本的な使い方

セッション内で作業ディレクトリを移動するには `/cd` を使います。

```text
/cd ../another-repo
```

セッションを終了した後、同じセッションを再開するには `--resume` にセッションIDを指定します。

```bash
claude --resume <session-id>
```

セッションIDが分からない場合は、引数なしでピッカーを開いて選択することもできます。

```bash
claude --resume
```

## 実践例

### 複数リポジトリを横断する調査セッションの再開

モノレポや複数リポジトリを `/cd` で行き来しながら作業したセッションを、後日別のディレクトリから再開したい場合です。

```bash
# 別ディレクトリから、/cdで最終的に移動した先とは無関係な場所でも
# セッションIDを指定すればresumeできる
claude --resume abc123-session-id
```

v2.1.223以降では、このセッションIDがカレントプロジェクトになくても、マシン上の他プロジェクトを横断して検索されるため、空の会話として復元される心配がありません。

### git worktree間を移動しながらの長時間セッション

複数のworktreeを `/cd` で切り替えながら作業を続けた場合、そのセッションは最後に `/cd` した worktree のプロジェクトストレージに保存されます。

```bash
# 作業していたworktreeとは別の場所からでも
cd ~/repos/main-worktree
claude --resume <session-id>
```

### `--continue` との使い分け

`--continue` はあくまで「現在の作業ディレクトリ」の最新セッションを再開するコマンドです。`/cd` で移動した先のディレクトリのセッションを再開したい場合は、移動後のディレクトリに `cd` してから `--continue` を使うか、`--resume <session-id>` でIDを直接指定します。

```bash
cd ~/repos/moved-to-here
claude --continue
```

## 注意点

- 本修正はClaude Code v2.1.223以降で有効です。それより前のバージョンでは、`/cd` で移動したセッションを移動前のディレクトリから `--resume` すると、正しく復元されない場合があります。
- セッションIDによるクロスプロジェクト検索は、該当IDのトランスクリプトを保持しているプロジェクトが1つだけの場合にのみ解決されます。複数プロジェクトに同じIDのコピーが存在する場合は「not found」として扱われ、任意のコピーが誤って復元されることはありません。
- `/resume` のセッションピッカーは既定でカレントworktreeのセッションのみを表示します。他のworktreeやプロジェクト全体を見るには `Ctrl+W`（全worktree）や `Ctrl+A`（全プロジェクト）を使用してください。
- `--mcp-config` や `--settings`、`--add-dir` など、起動時に指定した一部のオプションはresume時に自動復元されないため、必要に応じて再指定してください。
