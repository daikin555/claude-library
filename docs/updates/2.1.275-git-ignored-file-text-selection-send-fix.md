## 原文（日本語訳）

[VSCode] 拡張機能が数秒間応答しなくなった後、git-ignoreされているファイル内で選択したテキストがClaudeに送信されてしまう稀なケースを修正しました。

## 原文（英語）

[VSCode] Fixed a rare case where text selected in a git-ignored file could be sent to Claude after the extension was unresponsive for several seconds

## 概要

通常、`.gitignore`で除外されているファイル（機密情報や生成物などを含むことが多い）は、Claude Codeによる自動的な参照から保護されています。しかし、拡張機能が数秒間応答しなくなった直後という稀な状況において、この保護が正しく機能せず、git-ignoreされたファイル内で選択されたテキストがClaudeに送信されてしまう不具合がありました。今回の修正により、このような状況でもgit-ignoreされたファイルの内容が誤って送信されることがなくなりました。

## 基本的な使い方

通常通りエディタでテキストを選択し、Claude Codeに送信する操作（右クリックメニューや「Add to Claude Code」など）を行うだけです。git-ignoreされたファイルは自動的に送信対象から除外されます。

## 実践例

### 拡張機能が一時的に応答しなくなった直後の操作

大きなファイルの読み込みなどで拡張機能の応答が数秒間遅延した直後、git-ignoreされた設定ファイルや機密情報を含むファイルでテキストを選択・送信しようとした場合のケースです。

```
修正前: 拡張機能が応答しない → 復帰直後にgit-ignore対象ファイルのテキストを選択・送信操作
  → 保護が効かずテキストがClaudeに送信されてしまう（稀なケース）

修正後: 同じ状況でも保護が正しく機能し、git-ignore対象ファイルのテキストは送信されない
```

### .envファイルなど機密情報を含むファイルの保護

APIキーや認証情報を含む`.env`ファイルなど、`.gitignore`で管理されているファイルの内容が、意図せずモデルに渡ってしまうリスクを防ぎます。

## 注意点

- これはセキュリティ・プライバシーに関わる修正であり、拡張機能を最新版に更新することを強く推奨します。
- `.gitignore`の設定内容が正しく機能していることを前提とした保護のため、`.gitignore`自体の設定も適切に管理してください。
