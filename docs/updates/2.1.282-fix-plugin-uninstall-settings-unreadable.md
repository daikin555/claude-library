## 原文（日本語訳）

プラグインの設定ファイルがそのプラグインを引き続き有効にしていた、または読み込めなかった場合に、プラグインのアンインストールが成功したと報告しつつ保存済みのオプションを削除してしまっていた不具合を修正しました。現在は処理を停止し、該当ファイルを名指しするようになりました。

## 原文（英語）

Fixed plugin uninstall reporting success and deleting the plugin's saved options when its settings file still enabled it or could not be read; it now stops and names the file

## 概要

プラグインをアンインストールする際、そのプラグインの設定ファイルが依然としてそのプラグインを有効にしたままだったり、何らかの理由でファイル自体が読み込めなかったりする場合がありました。これまでは、こうした状況でもアンインストールが「成功した」と報告され、さらにプラグインの保存済みオプション（設定値）まで削除されてしまうという、実態と異なる不整合な動作をしていました。今回の修正で、こうした場合には処理を安全に停止し、問題のあるファイルを名指しして知らせるようになりました。

## 基本的な使い方

プラグインをアンインストールする際に、設定ファイルに問題がある場合はエラーメッセージで該当ファイルが示されるようになります。まずそのファイルの内容を確認・修正してから、再度アンインストールを試みてください。

## 実践例

### プラグイン設定の不整合の早期発見

チームで共有しているプラグイン設定ファイルに矛盾がある場合、アンインストール時のエラーメッセージからその不整合に気づき、正しく修正できます。

### 誤ったオプション削除の防止

設定ファイルが読めないという理由だけで、意図せずプラグインの保存済みオプションが失われてしまう事態を避けられ、安心してアンインストール操作を行えます。

## 注意点

- エラーが表示された場合は、名指しされた設定ファイルの内容やアクセス権限を確認してください
- この修正により、以前は「成功」と表示されていた一部のケースが、今後はエラーとして扱われるようになります
