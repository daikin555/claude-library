# /status で壊れた設定ファイルや無効な設定を一覧表示

## 原文（日本語に翻訳）

`/status` に、壊れたエージェント・スキル・コマンド・出力スタイルのファイル、キーバインドのエラー、利用できないサンドボックス、無視されたパーミッション設定、一致しないフックマッチャーの一覧を追加しました。

## 原文（英語）

Added a list in `/status` of broken agent, skill, command and output style files, keybinding errors, an unavailable sandbox, ignored permission settings and hook matchers that never match

## 概要

`/status` を実行すると、設定の問題点がまとめて表示されるようになりました。「スキルが読み込まれない」「フックが動かない」といった原因不明の不具合を、ファイルを一つずつ調べずに特定できます。

## 基本的な使い方

```text
/status
```

表示される項目:

- 壊れたエージェント / スキル / コマンド / 出力スタイルのファイル
- キーバインドのエラー
- 利用できないサンドボックス
- 無視されたパーミッション設定
- どのツールにも一致しないフックマッチャー

## 実践例

### フックが動かない原因を調べる

```json
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bsh", "hooks": [{ "type": "command", "command": "./check.sh" }] }
    ]
  }
}
```

`Bsh` のような誤記のマッチャーは永久に一致しません。`/status` で指摘されるので `Bash` に修正できます。

### スキルが一覧に出ない場合

frontmatter の YAML 構文エラーなどでスキルが読み込めない場合、`/status` に該当ファイルが表示されます。

## 注意点

- 同じ更新で `/config` にも、他の設定で上書きされている行へ注記が表示されるようになりました。
- 設定変更の保存に失敗した場合も、プロンプト下に警告が出ます。
