## 原文（日本語訳）

レンダリングされたMarkdown内の水平線（`---`）が、次の行にめり込んで表示される問題を修正しました。

## 原文（英語）

Fixed a `---` horizontal rule in rendered markdown running into the line after it

## 概要

Claudeの応答内でMarkdownの水平線（`---`）を使用した際、レンダリング後の表示でその直後の行とスペースが詰まりすぎてしまい、水平線と後続テキストが重なって見づらくなる不具合がありました。今回の修正で、水平線の下に適切な余白が確保されるようになりました。

## 基本的な使い方

Claudeが応答の中でセクション区切りとして `---` を使用する場合、特別な操作は不要です。通常どおりMarkdown形式で応答が返され、水平線の下に適切な余白を伴って表示されます。

```markdown
## セクションA
内容...

---

## セクションB
内容...
```

## 実践例

### 長い応答をセクションごとに区切る

Claudeが複数の話題にまたがる長い回答を返す際、`---` で視覚的に区切ることがあります。修正前はこの区切り線の直下の見出しやテキストが線に重なって読みにくくなっていましたが、修正後は自然な余白を持って表示されます。

```markdown
### 調査結果
...詳細...

---

### 次のステップ
...詳細...
```

### コード変更のサマリー表示

ファイル変更の要約と注意事項の間に水平線を挟むような応答でも、視認性が向上しています。

## 注意点

- ターミナルの種類やフォント設定によっては、依然として余白の見え方に差が出る場合があります
- 本修正はレンダリング表示のみに関わるもので、Markdownの内容自体には影響しません
