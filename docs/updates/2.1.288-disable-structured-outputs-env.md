## 原文（日本語訳）

構造化出力を拒否するMantleやゲートウェイ経由で、セッションタイトル、メモリ想起、プロンプトフックが失敗する問題を修正した。構造化出力を無効にする `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` を追加した。

## 原文（英語）

Fixed session titles, memory recall and prompt hooks failing on Mantle or behind gateways that reject structured outputs; added `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` to turn structured outputs off

## 概要

セッションタイトル生成、メモリ想起、プロンプトフックは内部で構造化出力を使います。構造化出力に対応しないゲートウェイ等ではこれらが失敗していましたが、今回修正されました。さらに、環境変数で構造化出力を明示的に無効化できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS=1
claude
```

## 実践例

### 社内ゲートウェイ経由で利用する

```bash
export ANTHROPIC_BASE_URL=https://gateway.example.com
export CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS=1
claude
```

### settings.jsonで固定する

```json
{
  "env": {
    "CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS": "1"
  }
}
```

## 注意点

- 値の書式はchangelogに明記がないため、`1` を例として記載しています。
- 通常の環境では設定不要です。問題が起きた場合のみ使ってください。
