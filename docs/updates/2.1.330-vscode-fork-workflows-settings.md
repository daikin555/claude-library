# VS Code 拡張に /fork・/workflows と新設定を追加

## 原文（日本語に翻訳）

VS Code 拡張に、最後の返信以降で会話を分岐する `/fork`、実行中のワークフローを含むエージェントマップを開く `/workflows`、および `claudeCode.escapeStopsClaude`、`claudeCode.pinPrompt`、`claudeCode.contextUsageThreshold` の各設定を追加しました。

## 原文（英語）

[VSCode] Added `/fork` to fork a conversation after its last reply (anthropics/claude-code#69272)
[VSCode] Added `/workflows`, which opens the agent map with running workflows
[VSCode] Added the `claudeCode.escapeStopsClaude` setting; turn it off so Escape does not stop Claude (anthropics/claude-code#91536)
[VSCode] Added the `claudeCode.pinPrompt` setting to let your message scroll away instead of staying pinned
[VSCode] Added the `claudeCode.contextUsageThreshold` setting for when the context indicator shows (anthropics/claude-code#93036)

## 概要

VS Code 拡張での会話分岐、ワークフロー確認、操作性の調整がしやすくなります。

## 基本的な使い方

チャット入力欄で `/fork` または `/workflows` を実行します。設定は VS Code の settings.json に記述します。

```json
{
  "claudeCode.escapeStopsClaude": false,
  "claudeCode.pinPrompt": false,
  "claudeCode.contextUsageThreshold": 50
}
```

## 実践例

### 別案の試行

`/fork` で現在の会話を保ったまま別のアプローチを試せます。

### Escape の誤爆防止

`claudeCode.escapeStopsClaude` をオフにすると Escape で Claude が停止しなくなります。

## 注意点

- `contextUsageThreshold` の値の意味（単位）は拡張の設定説明で確認してください（上の値は例です）
