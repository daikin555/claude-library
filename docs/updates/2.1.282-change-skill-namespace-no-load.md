## 原文（日本語訳）

`anthropic-skills` または `claude-ai` の名前空間にあるスキルフォルダ、コマンドファイル、ワークフローコマンドが読み込まれなくなるように変更しました。同名のプラグインは引き続き読み込まれますが、同期されたスキルとの名前の衝突が生じます。

## 原文（英語）

Changed skill folders, command files and workflow commands in the `anthropic-skills` or `claude-ai` namespace to no longer load; a plugin so named still loads but yields name ties to synced skills

## 概要

これはセキュリティに関わる変更です。`anthropic-skills` や `claude-ai` という名前は、claude.aiから同期される正規のスキル群のために予約された名前空間です。これまでは、リポジトリ内に同じ名前のスキルフォルダやコマンドファイル、ワークフローコマンドを配置することで、正規のスキルになりすます、あるいは競合させることが可能でした。今回の変更で、これらの名前空間にあるスキルフォルダ・コマンドファイル・ワークフローコマンドは読み込まれなくなりました。ただし、同じ名前を持つプラグイン自体は引き続き読み込まれ、名前が衝突した場合は同期されたスキル側が優先されます。

## 基本的な使い方

エンドユーザー側の対応は不要です。`anthropic-skills` や `claude-ai` という名前を独自のスキルフォルダやコマンドに使っていた場合は、別の名前に変更することを推奨します。

## 実践例

### なりすましスキルからの保護

リポジトリに紛れ込んだ悪意のあるスキルが `anthropic-skills` や `claude-ai` という名前を騙って正規のスキルのように振る舞おうとしても、読み込まれなくなり、ユーザーが意図せず実行してしまうリスクが減ります。

### 独自スキル・コマンドの命名規則の見直し

社内で独自にスキルやコマンドを開発している場合、予約された名前空間との衝突を避けるため、命名規則を確認・見直す良い機会になります。

## 注意点

- 既存のプロジェクトで `anthropic-skills` や `claude-ai` という名前のスキルフォルダやコマンドファイルを使っていた場合、この変更以降は読み込まれなくなるため、名前の変更が必要です
- プラグインとしてこれらの名前を使っている場合はプラグイン自体は読み込まれますが、同期されたスキルとの名前の衝突には注意が必要です
