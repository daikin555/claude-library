# ディスクフル時のBashエラーメッセージを分かりやすく改善

## 原文（日本語に翻訳）

- ディスクが満杯のときにBashコマンドが生の `ENOSPC` ファイルパスで失敗する問題を修正。ディスクが満杯であることと、何も実行されていないことを伝えるエラーになった

## 原文（英語）

- Fixed Bash commands on a full disk failing with a raw `ENOSPC` file path: the error now says the disk is full and that nothing ran

## 概要

ディスク容量不足でBashコマンドを実行できない場合、これまでは内部ファイルパス付きの `ENOSPC` が表示されて原因が分かりにくい状態でした。今後は「ディスクが満杯である」「コマンドは実行されていない」ことが明示されます。

## 基本的な使い方

エラーが出たら、まず容量を確認します。

```bash
df -h
du -sh ~/.claude 2>/dev/null
```

## 実践例

### 原因の切り分け

コマンドが未実行と明示されるため、副作用を気にせず容量確保後に再実行できます。

## 注意点

- 容量を空けるまでは同じエラーが続きます。
