## 原文（日本語訳）

Amazon BedrockおよびBedrock MantleでのセーフガードブロックメッセージにリクエストIDが表示されていなかった不具合を修正しました。ブロックメッセージには現在メッセージIDも表示されます。

## 原文（英語）

Fixed safeguard block messages on Amazon Bedrock and Bedrock Mantle not showing a request ID; block messages now also show the message ID

## 概要

Amazon Bedrock経由でClaude Codeを利用している際、安全性のガードレールによってリクエストがブロックされることがあります。これまでは、このブロックメッセージにリクエストIDが含まれておらず、AWSサポートやAnthropicへの問い合わせ時に該当リクエストを特定するのが難しいという問題がありました。今回の修正で、ブロックメッセージにリクエストIDとメッセージIDの両方が表示されるようになり、トラブルシューティングが容易になりました。

## 基本的な使い方

Bedrock経由でセーフガードによりリクエストがブロックされた場合、表示されるメッセージ内のリクエストID・メッセージIDをそのまま記録しておきます。

## 実践例

### AWSサポートへの問い合わせ

意図しないブロックが頻発する場合、表示されたリクエストIDをAWSサポートチケットに添付することで、原因調査を迅速に進められます。

### 社内での問題追跡

複数チームでBedrock経由のClaude Codeを利用している組織で、特定のブロック事象を社内チケットに記録・共有する際に、リクエストID・メッセージIDが正確な参照キーとして使えます。

## 注意点

- このIDはブロックされたリクエストを特定するための識別子であり、ブロック自体を回避するものではありません
- Bedrock Mantle環境でも同様にIDが表示されるようになりました
