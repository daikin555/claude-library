# claude remote-control に --settings オプションを追加

## 原文（日本語に翻訳）

- `claude remote-control` に `--settings <file>` を追加。起動するすべてのセッションに設定ファイルを適用する。ファイルが変更された場合、`claude remote-control` を再起動するまで新しいセッションは開始されない

## 原文（英語）

- Added `--settings <file>` to `claude remote-control`, which applies a settings file to every session it starts; if the file changes, no new session starts until you restart `claude remote-control`

## 概要

`claude remote-control` が起動するすべてのセッションに、指定した設定ファイルを一括適用できるようになりました。リモートから開始されるセッションの権限やモデルなどを統一できます。

## 基本的な使い方

```bash
claude remote-control --settings ./remote-settings.json
```

## 実践例

### リモートセッションの権限を固定する

```json
{
  "permissions": {
    "deny": ["Bash(rm:*)"]
  }
}
```

```bash
claude remote-control --settings ./remote-settings.json
```

### 設定を更新する

ファイルを編集した後は、`claude remote-control` を再起動して反映させます。

## 注意点

- 実行中にファイルが変更されると、再起動するまで新しいセッションは開始されません。意図しない設定でセッションが始まることを防ぐための挙動です。
- 設定変更後は必ず再起動してください。
