## 原文（日本語訳）

Bashの権限確認プロンプトに、auto modeを案内するTipsが追加されました。「Yes, and switch to auto mode」というワンキーで選べる選択肢が用意され、その場でauto modeに切り替えられます。

## 原文（英語）

Added a tip on Bash permission prompts pointing to auto mode, with a one-keystroke "Yes, and switch to auto mode" option

## 概要

Bashコマンド実行時の権限確認プロンプトは、許可のたびに都度応答が必要で、繰り返し同じような確認を求められることがあります。今回、このプロンプトにauto mode（自動承認モード）への案内Tipsが追加され、「今回は許可し、かつ以後はauto modeに切り替える」という操作をワンキーで行えるようになりました。頻繁にコマンド実行の確認を求められる場面で、モード切り替えの手間を大幅に減らせます。

## 基本的な使い方

Bashコマンドの権限確認プロンプトが表示された際、通常の「Yes」「No」の選択肢に加えて「Yes, and switch to auto mode」という選択肢が表示されます。これを選ぶと、今回のコマンドを許可しつつ、以降はauto modeで動作するようになります。

```
Bash command permission required:
  npm run build

> Yes
  Yes, and switch to auto mode
  No
```

## 実践例

### 同じようなコマンドで何度も確認を求められる場面

ビルドやテストなど、繰り返し似たようなBashコマンドを実行するワークフローで、毎回確認するのが煩わしいと感じたら、その場で「Yes, and switch to auto mode」を選んでauto modeに切り替えられます。

### 長時間の自動化タスクを開始する前

これから長いタスクを自動的に進めてほしい場面で、最初のBashコマンド確認時にauto modeへ切り替えておくことで、以降のコマンド実行を都度確認する必要がなくなります。

### auto modeの存在を知らないユーザーへの導線

auto modeという機能自体を知らないユーザーにとって、権限確認プロンプトの中でTipsとして案内されることで、機能の発見と利用が促進されます。

## 注意点

- auto modeに切り替えると、以降のBashコマンドは確認なしで実行されるようになるため、実行内容には注意が必要です
- auto modeの範囲や挙動は既存の権限設定（`permissions` 設定や `allow`/`deny` リスト）と組み合わさって決まります
- この選択肢は案内として表示されるものであり、必ず選ぶ必要はなく、通常通り「Yes」や「No」を選ぶこともできます
