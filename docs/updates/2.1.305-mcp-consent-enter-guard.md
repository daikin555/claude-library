# MCP同意ダイアログでEnterの誤承認を起きにくく改善

## 原文（日本語に翻訳）

- MCP同意ダイアログを改善し、プロンプト向けのEnterが「承認」として扱われにくくした

## 原文（英語）

- Improved MCP consent dialogs so an Enter meant for the prompt is less likely to be taken as Accept

## 概要

プロンプト入力中のEnterが、直後に表示されたMCP同意ダイアログへの承認として誤入力されにくくなりました。意図しないMCPサーバーの承認を防ぎます。

## 基本的な使い方

特別な操作は不要です。同意ダイアログが表示されたら、内容を確認してから明示的に選択してください。

## 実践例

### 入力中にダイアログが割り込む場合

素早くEnterを押した際の誤承認リスクが下がります。

## 注意点

- 誤操作の可能性が完全になくなるわけではありません。承認前にサーバー内容を確認してください。
