# Remote Controlで /resume 後に空の「(session)」が残る問題を修正

## 原文（日本語に翻訳）

- `/resume` で会話を切り替えた後、Remote Controlが `/resume` に空の「(session)」エントリを残す問題を修正

## 原文（英語）

- Fixed Remote Control leaving empty "(session)" entries in `/resume` after switching conversations with `/resume`

## 概要

Remote Control利用中に会話を切り替えると、`/resume` の一覧に中身のない「(session)」が増えていく問題が修正されました。

## 基本的な使い方

```
/resume
```

一覧が過去の会話だけで整理されて表示されます。

## 実践例

### 会話の頻繁な切替

目的の会話を探しやすくなります。

## 注意点

- すでに作られた空エントリが残っている場合があります。
