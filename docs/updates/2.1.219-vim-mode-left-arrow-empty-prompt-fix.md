## 原文（日本語に翻訳）

Vim modeを修正：空のプロンプトで←キーを押したときに、INSERTモードだけでなくNORMALモードからもエージェントビューに戻れるようになりました。

## 原文（英語）

Fixed Vim mode: pressing ← on an empty prompt now returns to the agent view from NORMAL mode, not just INSERT

## 概要

Claude CodeにはVim風のキーバインドで入力欄を操作できる「Vim mode」があります。この機能では、入力プロンプトが空の状態で左矢印キー（←）を押すと、入力欄からエージェントのビュー（会話・応答が表示される側）にフォーカスを移動できます。これまではこの挙動がINSERTモードのときにしか動作せず、NORMALモードでは反応しませんでしたが、今回の修正でNORMALモードでも同様に機能するようになりました。

## 基本的な使い方

Vim modeは以下のいずれかの方法で有効化できます。

```
/vim
```

または `/config` を開き、Editor modeの項目を「vim」に切り替えることでも有効化できます。セッションをまたいで常にVim modeを使いたい場合は、`~/.claude/settings.json` に以下のように設定します。

```json
{
  "editorMode": "vim"
}
```

Vim modeが有効な状態では、入力欄はデフォルトでINSERTモードから始まります。`Esc` キーでNORMALモードに切り替え、`i` / `I` / `a` / `A` / `o` / `O` などのキーで再びINSERTモードに戻れます。現在のモードは入力欄の左下にあるインジケーターで確認できます。

プロンプトが空の状態で、カーソルが入力欄の先頭にあるときに `←` を押すと、入力欄からエージェントビュー（上部の会話履歴・応答表示エリア）へフォーカスが移動します。今回の修正により、この挙動がNORMALモードでも正しく機能するようになりました。

## 実践例

### NORMALモードのままエージェントビューへ移動する

修正前は、NORMALモードで空のプロンプトの状態で `←` を押しても何も起こりませんでした。移動するにはわざわざINSERTモードに戻す必要がありました。修正後は次のように操作できます。

```
1. プロンプトが空の状態で Esc を押してNORMALモードにする
2. その状態のまま ← を押す
   → 入力欄からエージェントビューにフォーカスが移動する
```

これにより、テキストを編集した直後にNORMALモードのままカーソルキーで画面を移動する、というVimライクな操作フローが自然につながるようになります。

### 直前の応答をスクロールして確認してからプロンプトに戻る

```
1. 何か入力しようとしたが送信前に消去し、プロンプトを空にする
2. Esc でNORMALモードに切り替える
3. ← でエージェントビューにフォーカスを移す
4. j / k（またはスクロール操作）で過去の応答を確認する
5. 再度入力欄をクリック、もしくは対応するキー操作でプロンプトに戻り、
   i でINSERTモードにして入力を再開する
```

INSERTモードに戻す手間が減り、直前の出力を見返す→続きを入力する、というサイクルがスムーズになります。

### キーボードだけで画面遷移を完結させる

マウスを使わずにキーボードだけで操作したいユーザーにとって、モードを問わず `←` でエージェントビューに戻れることは、Vim modeの一貫性を高めるポイントです。NORMALモードで文章の編集や削除（`dd` や `dw` など）を行った後、プロンプトが空になった時点でそのまま `←` を押せば、フォーカス移動のためだけにモード切り替えを挟む必要がなくなります。

## 注意点

- この挙動が発動するのは、あくまで**プロンプトが空**の場合です。文字が入力されている状態で `←` を押した場合は、通常どおりカーソル移動として扱われます。
- Vim modeの対応キーバインドはNORMAL/VISUALモードの一部の動作（`hjkl` によるナビゲーション、`w`/`e`/`b`、`0`/`$`/`^`、`gg`/`G`、`dw`/`dd`/`cw`/`cc` などの編集操作）に限定されています。すべてのVimキーバインドが網羅されているわけではありません。
- Vim modeを有効にしていない場合（デフォルトのeditor mode）は、この修正内容は影響しません。
- 設定は `/config` からその場で切り替えるか、`~/.claude/settings.json` の `editorMode` で永続化するかを選べます。
