## 原文（日本語訳）

シェルがワイルドカードとして展開してしまう引数を持つ読み取り専用コマンド（`rg` や `git grep` など）が自動承認されていた問題を修正した。今後は承認を求める。

## 原文（英語）

Fixed Bash permission checks auto-approving some read-only commands (such as `rg` or `git grep`) whose arguments the shell would still expand as wildcards; these now prompt for approval

## 概要

読み取り専用として自動許可されるコマンドでも、引数のワイルドカードがシェルで展開されると想定外のファイルに作用し得ます。この修正により、そのようなケースでは確認プロンプトが表示されます。

## 基本的な使い方

特別な操作は不要です。次のようなコマンドで承認を求められるようになります。

```bash
rg "pattern" *.env
```

## 実践例

### 想定外のファイル参照の防止

ワイルドカード付きの検索は承認が必要になり、Readの拒否ルールを意図せず回避する事態を防ぎます。

### 関連する権限修正

同バージョンでは、zshで変数名の解釈が異なるコマンドや、`declare` / `export` などのプレフィックス経由でdeny・askルールをすり抜ける問題も修正されています。

## 注意点

- 以前は黙って通っていたコマンドで承認を求められることがあります。
- 頻繁に使うコマンドは、permissionsに明示的な許可ルールを追加してください。
