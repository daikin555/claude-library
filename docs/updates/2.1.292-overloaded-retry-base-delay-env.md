## 原文（日本語訳）

過負荷（529）リクエストを再試行する際のバックオフの基本待機時間を長く設定するための環境変数 `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` を追加した。

## 原文（英語）

Added `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` environment variable to set a longer base delay for the backoff when retrying an overloaded (529) request

## 概要

APIが過負荷（529）を返したときの再試行バックオフの基本待機時間をミリ秒で指定できます。混雑時に再試行の間隔を長くしたい場合に有効です。

## 基本的な使い方

```bash
export CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS=5000
claude
```

## 実践例

### 並列実行が多いCI環境

```bash
export CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS=10000
claude -p "テストの失敗原因を要約して"
```

複数ジョブが同時に再試行して負荷を悪化させるのを緩和できます。

## 注意点

- 「より長い基本待機時間」を設定するための変数です。長くしすぎると応答が遅く感じられる場合があります。
- 値の単位はミリ秒です。
