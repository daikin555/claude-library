## 原文（日本語訳）
Artifactツールのエラーを改善：claude.aiにサインインしていない場合、ターミナルが最初の試行時点でその旨を表示するようになった。また、拒否された呼び出しに対してClaudeがより早くリトライを止めるように指示されるようになった。

## 原文（英語）
Improved Artifact tool errors: when you are not signed in to claude.ai the terminal now says so on the first attempt, and Claude is told to stop retrying a rejected call sooner

## 概要
ClaudeがArtifactツールを使ってclaude.ai上に成果物を公開・更新しようとする際、claude.aiにサインインしていないと操作が失敗します。これまでは、サインインしていないことが原因のエラーでも、その理由が分かりにくく、Claudeが何度も無駄にリトライを繰り返すことがありました。今回の改善により、サインインしていない場合は最初の試行時点でターミナルにその旨が明示され、さらにClaude自身も拒否された呼び出しをより早く諦めるよう指示されるようになりました。

## 基本的な使い方
Artifactツールを使う前にclaude.aiへのサインインが必要です。サインインしていない状態でArtifact関連の操作を行うと、その場でエラー内容が分かりやすく表示されます。

```bash
# claude.aiへのサインイン状態を確認・実施する
claude /login
```

## 実践例

### サインインせずにArtifactツールを使おうとした場合
以前は、claude.aiにサインインしていない状態でArtifactツールを使おうとすると、原因が分かりにくいエラーが出たり、Claudeが何度もリトライを試みて時間を浪費することがありました。改善後は最初の試行で「サインインしていません」という明確なメッセージが表示され、無駄なリトライも抑制されます。

```bash
# サインインしていない状態でのArtifact操作
"このHTMLをArtifactとして公開して"
# 修正後: 最初の試行で「claude.aiにサインインしてください」と明示される
```

### CI環境など非対話的な環境でArtifactツールを使う場合
サインイン状態を維持できないCI環境などでArtifactツールを誤って呼び出してしまった場合も、早い段階でエラー原因が判明し、リトライによる時間の浪費が防げます。

## 注意点
- Artifactツールを利用するにはclaude.aiへのサインインが前提条件です。サインインしていない環境では引き続き利用できません。
- サインイン後もエラーが続く場合は、ネットワーク接続やアカウント権限など別の原因を確認する必要があります。
