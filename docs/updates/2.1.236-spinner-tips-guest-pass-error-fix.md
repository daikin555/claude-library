## 原文（日本語訳）

`~/.claude.json` にキャッシュされたguest-pass報酬情報が不正な形式だった場合に、バックグラウンドエラーが繰り返し発生してスピナーのヒントが一切表示されなくなる問題を修正しました。

## 原文（英語）

Fixed spinner tips never appearing, with a repeated background error, when the cached guest-pass reward in `~/.claude.json` was malformed

## 概要

Claude Codeは処理中に表示されるスピナーの下に、便利な使い方や小ネタなどのヒントをランダムに表示する機能を持っています。このヒント表示の仕組みは、`~/.claude.json` にキャッシュされているguest-pass（招待・お試し利用の報酬）関連の情報を参照する処理と関わっており、このキャッシュデータが何らかの理由で不正な形式になっていると、ヒントを取得しようとするたびにバックグラウンドでエラーが発生し、結果としてスピナーのヒントが一切表示されなくなっていました。今回の修正により、このデータが壊れていてもエラーが発生し続けることなく、ヒントが正常に表示されるようになりました。

## 基本的な使い方

この修正は内部的なエラーハンドリングの改善であり、ユーザーが明示的に操作する必要はありません。通常どおりClaude Codeを起動し、処理を実行するだけです。

```
claude
```

修正前は、`~/.claude.json` 内のguest-pass報酬に関するキャッシュ情報が壊れていると、スピナー表示中にヒントの取得処理が裏側で失敗し続け、ヒントメッセージが二度と表示されなくなることがありました。修正後は、こうした不正なキャッシュデータがあってもエラーが解消され、通常どおりヒントが表示されます。

## 実践例

### guest-pass経由でClaude Codeを試したことがある環境

招待リンクやguest-passを通じてClaude Codeを試用したことがあるユーザーの環境では、`~/.claude.json` にguest-pass報酬に関する情報がキャッシュされます。何らかの理由でこのキャッシュが破損していた場合、修正前はスピナーのヒントがまったく出なくなっていましたが、修正後は正しく表示されるようになります。

### 設定ファイルを手動で編集・移行した環境

`~/.claude.json` を別の端末からコピーしたり手動で編集したりした際に、意図せずguest-pass関連のフィールドが不完全な状態になってしまうことがあります。このような状況でも、修正後はバックグラウンドエラーが繰り返されることなく、スピナーのヒント表示機能が正常に動作し続けます。

## 注意点

- この修正はスピナーのヒント表示に関するものであり、guest-pass自体の報酬付与ロジックを変更するものではありません。
- `~/.claude.json` はClaude Codeの各種設定やキャッシュを保持するファイルです。手動編集する場合は、他のフィールドを壊さないよう注意してください。
