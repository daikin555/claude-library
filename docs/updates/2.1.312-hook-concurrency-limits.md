## 原文（日本語訳）

プロンプトフックとエージェントフックを、サブエージェントを含め1セッションあたり同時最大24件に制限し、さらにイベントのタイムアウトより長く待機したものは最大12件までとしました。1秒未満の `timeout` は1秒として扱われます

## 原文（英語）

Changed prompt and agent hooks to run at most 24 at a time per session, sub-agents included, plus at most 12 that have waited longer than their event's timeout; a `timeout` under 1 second now counts as 1 second

## 概要

プロンプト/エージェントフックの同時実行数に上限が設けられ、大量のフックによる過負荷を抑えます。

## 基本的な使い方

```json
{
  "hooks": {
    "PostToolUse": [
      { "matcher": "Edit", "hooks": [ { "type": "prompt", "prompt": "...", "timeout": 30 } ] }
    ]
  }
}
```

（例示です。正確な書式は公式のフックドキュメントを参照してください）

## 実践例

### 多数のフックを使う構成

同時実行が24件を超える設計では待機が発生する点を考慮します。

### 短いtimeout

`timeout: 0.5` は1秒として扱われます。

## 注意点

- 上限はサブエージェントも含めたセッション単位です。
