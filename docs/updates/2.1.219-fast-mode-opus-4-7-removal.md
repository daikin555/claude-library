## 原文（日本語に翻訳）

fast modeからOpus 4.7を削除。`/fast` はOpus 5とOpus 4.8に適用されるようになりました。

## 原文（英語）

Removed Opus 4.7 from fast mode; `/fast` now applies to Opus 5 and Opus 4.8

## 概要

Claude Codeの `/fast`（fast mode）は、対応モデルに対して高速な応答を得られるモードです。今回のリリースでは、fast modeの対象モデルからOpus 4.7が外れ、以降 `/fast` はOpus 5とOpus 4.8にのみ適用されるようになりました。Opus 4.7自体は引き続きモデルとして選択・利用できますが、fast modeによる高速応答の恩恵は受けられなくなります。これはOpus 5の登場に伴うモデルラインナップ整理の一環と考えられます。

## 基本的な使い方

fast modeは、Claude Codeのセッション内で `/fast` コマンドを実行することで有効化・切り替えができます。

```
/fast
```

fast modeが有効な状態で、現在使用中のモデルがOpus 5またはOpus 4.8であれば、高速化された応答が適用されます。Opus 4.7を使用している場合は、`/fast` を実行してもfast modeによる高速化は適用されません。

## 実践例

### Opus 4.7でfast modeを使っていた場合の影響を確認する

これまでOpus 4.7 + `/fast` の組み合わせで高速応答を利用していたユーザーは、このリリース以降、同じ組み合わせでは高速化が適用されなくなります。現在のモデルとfast modeの状態は `/model` と `/fast` で確認できます。

```
/model
# 現在選択中のモデルが表示される（例: Opus 4.7）

/fast
# fast modeの有効/無効状態が表示される
```

Opus 4.7のまま作業を続けたい場合、通常モードでの応答速度・挙動に変わりはありませんが、fast modeによる高速化のメリットは得られません。

### Opus 5へ移行して高速応答を維持する

fast modeの恩恵を引き続き受けたい場合は、Opus 5へモデルを切り替えます。

```
/model claude-opus-5
/fast
```

Opus 5はfast modeに正式対応しているため、これまでOpus 4.7で得ていたのと同様の高速応答が期待できます。加えてOpus 5はモデル自体の改善も含むため、単なる置き換え以上の品質向上が見込めます。

### Opus 4.8へ移行する（Opus 5への移行が難しい場合）

環境やプロジェクトの都合でOpus 5へすぐに切り替えられない場合は、Opus 4.8を選択することでもfast modeを利用できます。

```
/model claude-opus-4-8
/fast
```

Opus 4.8はOpus 4.7の後継的な位置づけのモデルであり、fast modeの対象に含まれているため、比較的小さな変更でfast modeによる高速応答を維持できます。

## 注意点

- Opus 4.7自体はモデルとしては引き続き利用可能ですが、`/fast` を実行してもfast modeの高速化は適用されません。
- fast modeの対象モデルは今後のリリースでも変更される可能性があるため、`/fast` 実行時の挙動やドキュメントを都度確認することをおすすめします。
- モデルを切り替える際は、プロジェクトやチームで使用しているモデルのバージョンをそろえておくと、挙動の差異によるトラブルを避けやすくなります。
- fast modeの対象外モデルで `/fast` を実行した場合にエラーになるか、単に無効化されるだけかは環境によって異なる可能性があるため、実際の出力メッセージを確認してください。
