## 原文（日本語に翻訳）

OpenTelemetry の `user_prompt` イベントに `prompt_text` を追加しました。ドット区切りのキーをネストするバックエンド向けに `prompt` の複製を提供します。`prompt` を削除またはマスクしている場合は、`prompt_text` も同じ箇所で削除またはマスクしてください（anthropics/claude-code#70763）。

## 原文（英語）

Added `prompt_text` to the OpenTelemetry `user_prompt` event, a copy of `prompt` for backends that nest dotted keys; drop or mask it wherever you drop or mask `prompt` (anthropics/claude-code#70763)

## 概要

`user_prompt` イベントに、`prompt` と同じ内容を持つ `prompt_text` 属性が追加されました。`prompt` のようにドットを含むキーをネストして扱うバックエンドでは、`prompt` が正しく保存・検索できない場合があり、その回避策として使えます。

## 基本的な使い方

テレメトリは通常どおり有効化します。

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_LOGS_EXPORTER=otlp
```

イベントには `prompt` と `prompt_text` の両方が含まれます。

## 実践例

### プロンプト内容をマスクしている場合

OpenTelemetry Collector などで `prompt` を削除またはマスクしている場合は、`prompt_text` にも同じ処理を追加してください。

```yaml
processors:
  attributes/drop_prompt:
    actions:
      - key: prompt
        action: delete
      - key: prompt_text
        action: delete
```

### ネストされるバックエンドでの参照

`prompt` が階層構造として扱われてしまうバックエンドでは、`prompt_text` を参照してください。

## 注意点

- **機密情報の漏えいに注意**: `prompt` だけを除外していると、`prompt_text` 経由でプロンプトが送信され続けます。
- 既存のマスキング設定の見直しを推奨します。
