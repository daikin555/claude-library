# claude mcp add/remove が .mcp.json の他のキーを消さないように修正

## 原文（日本語に翻訳）

プロジェクトスコープの `claude mcp add` と `claude mcp remove` が、`.mcp.json` の `$schema` や他ツールの `servers` など、他のトップレベルキーを削除してしまう問題を修正しました。

## 原文（英語）

Fixed `claude mcp add` and `claude mcp remove` with project scope deleting other top-level keys from `.mcp.json`, such as `$schema` or another tool's `servers`

## 概要

`.mcp.json` を編集するコマンドが `mcpServers` 以外のキーを失わせていた問題の修正です。エディタ補完用の `$schema` や、他ツールと共有している設定が保持されます。

## 基本的な使い方

```bash
claude mcp add --scope project my-server -- npx my-mcp-server
claude mcp remove --scope project my-server
```

## 実践例

### `$schema` を持つ .mcp.json

```json
{
  "$schema": "https://example.com/mcp.schema.json",
  "mcpServers": {}
}
```

add / remove 後も `$schema` が残ります。

### トップレベルに servers がある場合

同じ更新で、`mcpServers` キーが無く、サーバーがトップレベルに並ぶ形式の `.mcp.json` に対して `claude mcp add --scope project` を実行すると、上書きせずに停止するよう変更されました。

## 注意点

- 以前のバージョンで既にキーが消えた場合、Git 履歴から復元してください。
- 停止した場合は、`mcpServers` キー配下へ手動で構造を整えてから再実行します。
