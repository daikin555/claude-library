## 原文（日本語に翻訳）

非常に大きなネストされたCLAUDE.md配下のファイルを読んだ後、セッションが繰り返しcompactされる問題を修正しました。サイズ上限を超えるネストCLAUDE.mdは先頭部分のみ読み込まれます

## 原文（英語）

Fixed sessions compacting repeatedly after reading files under a very large nested CLAUDE.md; a nested CLAUDE.md over the size limit now loads only its start

## 概要

サブディレクトリのファイルを読むと、そのディレクトリのCLAUDE.mdが読み込まれます。このファイルが極端に大きいとコンテキストを圧迫し、compactが繰り返し発生していました。v2.1.309では、サイズ上限を超えたネストCLAUDE.mdは先頭部分のみが読み込まれます。

## 基本的な使い方

対応は自動です。ただし重要な指示はファイルの**先頭**に置くのが確実です。

## 実践例

### 先頭に要点を集約する

```markdown
# packages/api/CLAUDE.md
## 必須ルール（先頭に配置）
- テストは `pnpm test` で実行
- DBマイグレーションは手動実行しない

## 詳細リファレンス（後ろに配置）
...
```

### 長大な資料は別ファイルへ分離

```markdown
詳細なAPI仕様は @docs/api-spec.md を参照
```

## 注意点

- 上限超過時は先頭のみ読み込まれ、後半の指示は効かない可能性があります
- 上限の具体的な数値は本changelogには記載がありません
- CLAUDE.mdは簡潔に保つのが基本です
