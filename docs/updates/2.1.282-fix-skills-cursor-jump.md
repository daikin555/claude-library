## 原文（日本語訳）

`/skills` の検索ボックスで入力している最中に、ターミナルのカーソルが検索ボックスからスキル一覧へジャンプしてしまい、キャレットが隠れたりIME入力が誤った位置に表示されたりする不具合を修正しました。

## 原文（英語）

Fixed the terminal cursor jumping from the `/skills` search box to the skill list while typing, which could hide the caret and put IME input in the wrong place

## 概要

`/skills` の検索ボックスに文字を入力している最中、ターミナルのカーソル（キャレット）が検索ボックスから離れてスキル一覧側にジャンプしてしまう不具合がありました。これにより、通常の入力ではキャレットの位置が分かりにくくなるだけでなく、日本語などのIME（インプットメソッド）を使った変換中の入力位置がずれて表示されるという、特に日本語ユーザーにとって影響の大きい問題を引き起こしていました。今回の修正でカーソルが正しく検索ボックスに留まるようになりました。

## 基本的な使い方

```
/skills
```

検索ボックスに日本語・英語を問わず入力する際、カーソルは正しく検索ボックス内に留まります。

## 実践例

### 日本語IMEでのスキル検索

日本語入力中に変換候補を選ぶ操作をしても、キャレットの位置がずれず、どこに何が入力されているかを正確に把握できます。

### 長いキーワードでの絞り込み検索

長めのキーワードを入力してスキルを絞り込む際も、入力中にカーソルが迷子にならず、スムーズにタイピングを続けられます。

## 注意点

- 特にIME（日本語・中国語・韓国語など）を使用するユーザーに影響が大きかった不具合です
- 関連する `/skills` 検索ボックスのフォーカスに関する不具合修正も参照してください（[/の直後の入力に関する修正](./2.1.282-fix-skills-search-box-focus.md)）
