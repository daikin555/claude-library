# claude-api スキルにOpenTelemetryトレーシングの案内を追加

## 原文（日本語に翻訳）

`claude-api` スキルに OpenTelemetry トレーシングのガイダンスを追加しました。`ant` CLI を使ったトレース送信先の設定も含まれます。

## 原文（英語）

Added OpenTelemetry tracing guidance to the `claude-api` skill, including setting up trace destinations with the `ant` CLI

## 概要

Claude API を使うアプリケーションを開発する際、`claude-api` スキルがOpenTelemetryによるトレーシングの設定方法を案内してくれるようになりました。`ant` CLI でトレースの送信先を設定する手順も対象です。

## 基本的な使い方

```text
/claude-api このアプリにOpenTelemetryトレーシングを追加したい
```

## 実践例

### 既存アプリへのトレース導入

Claude APIを呼び出している既存コードに対し、スキルの案内に沿ってトレースの計測を追加できます。

### トレース送信先の設定

`ant` CLI を使った送信先のセットアップ手順を、スキル経由で確認しながら進められます。

## 注意点

- 具体的なコマンドや設定値はスキルの出力と公式ドキュメントで確認してください。
- アプリ側のトレーシングと、Claude Code自体のテレメトリは別の仕組みです。
