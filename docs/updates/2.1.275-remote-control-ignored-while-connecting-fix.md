## 原文（日本語訳）

[VSCode] Remote Controlが接続処理中の間、`/remote-control`コマンドが無視されてしまう問題を修正しました。接続中に再度実行すると、Remote Controlが即座にオフになるようになりました。

## 原文（英語）

[VSCode] Fixed `/remote-control` being ignored while Remote Control is still connecting: running it again now turns Remote Control off immediately

## 概要

`/remote-control`コマンドはRemote Control機能のオン・オフを切り替えるためのコマンドです。これまで、Remote Controlが接続処理中（オンになろうとしている最中）にこのコマンドを実行しても無視されてしまい、ユーザーが意図したタイミングでオフにできない不具合がありました。今回の修正により、接続中であっても`/remote-control`を再度実行すれば、即座にRemote Controlがオフになるようになりました。

## 基本的な使い方

```
/remote-control
```
を実行することでRemote Controlのオン・オフを切り替えられます。

## 実践例

### Remote Controlの接続処理中に誤って有効化してしまった場合

`/remote-control`を実行してオンにした直後、やはりオフにしたいと考え、接続処理が完了する前に再度コマンドを実行するケースです。

```
修正前:
  1. /remote-control 実行 → 接続処理開始
  2. 接続中に /remote-control を再実行 → 無視される（オフにならない）

修正後:
  1. /remote-control 実行 → 接続処理開始
  2. 接続中に /remote-control を再実行 → 即座にオフになる
```

### 誤操作からすばやく復旧したい場合

Remote Controlを誤って有効化してしまった際、接続完了を待たずにすぐキャンセルできるようになり、セキュリティ・プライバシーの観点でも安心して利用できます。

## 注意点

- 接続完了後の通常のオン・オフ切り替えの挙動には変更はありません。
- Remote Controlの状態はUI上のステータス表示でも確認できます。
