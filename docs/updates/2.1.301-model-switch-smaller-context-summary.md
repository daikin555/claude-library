# コンテキストの小さいモデルへ切り替える際に前のモデルで要約する

## 原文（日本語に翻訳）

コンテキストウィンドウの小さいモデルへの切り替えを改善しました。新しいモデルには長すぎる会話は、先に前のモデルで要約されます。

## 原文（英語）

Improved switching to a model with a smaller context window: a conversation too long for the new model is now summarized by the previous model first

## 概要

大きなコンテキストのモデルで長く作業した後、小さいコンテキストのモデルへ切り替えると、会話が収まらないことがあります。この場合、切り替え前のモデルが先に会話を要約してから移行します。

## 基本的な使い方

```text
/model
```

でモデルを切り替えると、必要な場合のみ自動で要約が行われます。

## 実践例

### 長い調査の後に軽量モデルへ移る

大きなコンテキストで調査した後、小さいモデルで実装に移る際に、要約を引き継いで作業を続けられます。

### 関連する修正

同じバージョンで、要約に使用量クレジットを消費する場合に確認なしで実行されていた問題も修正されています。

## 注意点

- 要約によって細かい情報が失われる可能性があります。重要な内容は事前にファイルへ保存しておくと安心です。
- 切り替え前に `/context` で使用量を確認できます。
