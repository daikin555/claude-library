# /claude-api api-version で Claude API コードを API バージョン 2026-10-21 へ移行

## 原文（日本語に翻訳）

- Claude APIのコードをAPIバージョン `2026-10-21` に移行する `/claude-api api-version` を追加

## 原文（英語）

- Added `/claude-api api-version` to move Claude API code to API version `2026-10-21`

## 概要

同梱スキル `/claude-api` にサブコマンド `api-version` が追加されました。プロジェクト内の Claude API 呼び出しコードを、API バージョン `2026-10-21` に合わせて更新する作業を Claude に任せられます。

## 基本的な使い方

```
/claude-api api-version
```

実行すると、Claude がコードベース内の API 利用箇所を調べ、新バージョンに向けた修正を提案・適用します。

## 実践例

### 既存アプリの API バージョンを更新する

```
/claude-api api-version
```

実行前にブランチを切り、差分を確認してから取り込むと安全です。

### 移行後の動作確認

```
/claude-api api-version
テストを実行して、失敗した箇所を修正して
```

## 注意点

- 変更内容は必ず差分レビューとテストで確認してください。
- 具体的な破壊的変更の内容は公式のAPIドキュメントを参照してください。
