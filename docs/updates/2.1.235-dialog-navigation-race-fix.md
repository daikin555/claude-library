## 原文（日本語訳）

ダイアログ内で矢印キーとEnterキーをほぼ同時に連続して押した場合、これまでは移動前にハイライトされていた選択肢が確定されてしまうことがありました。今回の修正により、実際に矢印キーで移動した先の選択肢が正しく選択されるようになりました。

## 原文（英語）

Dialogs: arrow keys and Enter pressed in quick succession now select the option you navigated to instead of the previously highlighted one

## 概要

Claude CodeのCLIでは、モデル選択やパーミッション確認、設定変更など様々な場面でターミナル上のダイアログ（選択式UI）が表示されます。タイピングが速いユーザーが矢印キーで選択肢を移動した直後にEnterキーを押すと、画面の再描画やハイライト状態の更新がキー入力の処理に追いつかず、移動前の選択肢が確定されてしまう競合状態（レースコンディション）が発生することがありました。今回の修正でキー入力の処理順序が保証されるようになり、常に実際に移動した先の選択肢がEnterで確定されるようになりました。

## 基本的な使い方

この修正はCLIの内部動作の改善であり、ユーザー側で有効化する設定はありません。Claude Codeを2.1.235以降に更新するだけで、自動的に修正後の挙動になります。

```bash
claude update
claude --version
```

修正前は、たとえば `/model` コマンドでモデル一覧ダイアログを開き、下矢印キーを2回押した直後にEnterキーを押すと、意図した3番目の選択肢ではなく2番目や1番目の選択肢が選ばれてしまうことがありました。修正後はキー入力を素早く連打しても、常にカーソルが実際に止まっている選択肢が選択されます。

## 実践例

### モデル選択ダイアログでの選択

`/model` コマンドでモデル切り替えダイアログを開き、矢印キーで目的のモデルまで素早く移動してEnterを押しても、修正後は移動先のモデルが確実に選択されます。

```bash
/model
```

### パーミッション確認ダイアログでの承認操作

ツール実行の許可を求めるダイアログで「Yes」「Yes, and don't ask again」「No」などの選択肢を矢印キーで切り替えている最中に急いでEnterを押しても、直前に選んでいた項目ではなく、カーソルが実際にある項目が確定します。

### 設定メニューでの項目選択

`/config` や `/permissions` などの設定系ダイアログで複数の項目を素早くスクロールして選ぶ場合も、同様にカーソル位置と確定される選択肢のずれが解消されています。

## 注意点

- この修正は表示や操作方法自体を変えるものではなく、キー入力処理のタイミングに関するバグ修正です
- 修正の恩恵を受けるには、Claude Codeを2.1.235以降のバージョンに更新する必要があります
- 非常に高速なキー入力を行う環境（マクロ入力やリモート接続など）では、ターミナル側の遅延によって体感が変わる場合があります
