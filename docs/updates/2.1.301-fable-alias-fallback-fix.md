# fable / best エイリアスが最新Fableを使えない組織でエラーになる問題を修正

## 原文（日本語に翻訳）

最新の Fable モデルが組織で利用できない場合に、`fable`（および `best`）モデルエイリアスが Anthropic API でエラーになる問題を修正しました。Claude Code は一つ前の Fable モデルで一度だけ再試行します。

## 原文（英語）

Fixed the `fable` (and `best`) model alias erroring on the Anthropic API when the newest Fable model is not available to your organization: Claude Code now retries once on the previous Fable model

## 概要

エイリアスが最新のFableを指していても、組織に提供されていないとエラーになっていました。修正後は、前のFableモデルへ自動的に1回フォールバックします。

## 基本的な使い方

```bash
claude --model fable
```

または対話中に `/model fable` を実行します。

## 実践例

### 組織全体でエイリアスを標準化する

チームの設定に `fable` や `best` を使っていても、モデルの提供状況の差でエラーになりにくくなります。

### 段階的に提供される新モデルへの対応

新モデルの提供開始直後で組織にまだ反映されていない期間も、前のFableで作業を続けられます。

## 注意点

- 再試行は1回のみです。
- 特定のモデルを厳密に使いたい場合は、エイリアスではなくモデルIDを指定してください。
