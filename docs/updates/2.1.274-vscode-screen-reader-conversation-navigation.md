## 原文（日本語訳）
[VSCode] 会話のスクリーンリーダーによるナビゲーションを改善しました。各メッセージは「You（あなた）」または「Claude」として読み上げられ、ツール実行ステップではツール名も読み上げられるようになります。

## 原文（英語）
[VSCode] Improved screen reader navigation of the conversation: each message is announced as "You" or "Claude", with the tool name for tool steps

## 概要
VSCode拡張機能でスクリーンリーダーを使ってClaude Codeとの会話を追う際、これまでは発言者やツール実行内容が明確にアナウンスされず、会話の流れを把握しにくいという課題がありました。今回の改善で、各メッセージが「You」または「Claude」の発言として読み上げられるようになり、ツールを実行しているステップではそのツール名も併せて読み上げられます。視覚に障害のあるユーザーや、スクリーンリーダーを利用する開発者にとって大きなアクセシビリティ向上です。

## 基本的な使い方
特別な設定は不要です。VSCodeでスクリーンリーダー（NVDA、JAWS、VoiceOverなど）を有効にした状態でClaude Code拡張機能を使用すると、自動的に改善されたアナウンスが読み上げられます。

1. OSまたはVSCodeでスクリーンリーダーを有効化
2. Claude Code拡張機能でチャットを開始
3. メッセージやツール実行のたびに、話者名やツール名が読み上げられることを確認

## 実践例

### 会話メッセージの読み上げ
ユーザーが質問を送信すると「You: （質問内容）」、Claudeが返信すると「Claude: （返信内容）」というように、発言者が明確に区別されてアナウンスされます。

### ツール実行ステップの読み上げ
Claudeがファイル編集やコマンド実行などのツールを使う場面では、「Claude used Edit」のようにツール名が読み上げられ、いま何が実行されているのかをスクリーンリーダー利用者が把握しやすくなります。

## 注意点
- 効果を得るにはVSCode拡張機能を最新版に更新する必要があります。
- 対応状況は使用しているスクリーンリーダーソフトウェアやOSの設定によって多少異なる場合があります。
