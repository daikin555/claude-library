# [Claude Tag] Slack DMスレッドのルーティンが他のルーティン再開後に投稿されなくなる問題を修正

## 原文（日本語に翻訳）

- [Claude Tag] Slack DMスレッドで設定したルーティンが、同スレッドの別ルーティンが会話を再開した後に投稿しなくなる問題を修正。両方がそこへ投稿し続ける

## 原文（英語）

- [Claude Tag] Fixed a routine set up in a Slack DM thread no longer posting after another routine in that thread restarted the conversation; both now keep posting there

## 概要

同じDMスレッド内の複数ルーティンが、互いの会話再開によって投稿不能にならなくなりました。

## 基本的な使い方

特別な操作は不要です。DMスレッドで複数のルーティンを設定しても、すべてが投稿を続けます。

## 実践例

### 1スレッドでの複数ルーティン

日次レポートと監視通知を同じDMスレッドで受け取る運用ができます。

## 注意点

- 既に停止しているルーティンは設定し直しが必要な場合があります。
