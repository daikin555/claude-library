# axScreenReader 設定の適用範囲をユーザー・管理・--settings に限定

## 原文（日本語に翻訳）

- `axScreenReader` 設定、および settings の `env` ブロック内の `CLAUDE_AX_SCREEN_READER` を、ユーザー設定、管理設定、`--settings` からのみ適用されるように変更（2.1.305 以降）

## 原文（英語）

- Changed the `axScreenReader` setting and `CLAUDE_AX_SCREEN_READER` in a settings `env` block to apply only from user, managed or `--settings` settings (since 2.1.305)

## 概要

スクリーンリーダー向けの設定は、信頼できる設定ソースからのみ有効になります。リポジトリ内のプロジェクト設定などでは適用されません。

## 基本的な使い方

`~/.claude/settings.json`（ユーザー設定）に記述します。

```json
{
  "axScreenReader": true
}
```

## 実践例

### 環境変数で有効にする

```json
{
  "env": {
    "CLAUDE_AX_SCREEN_READER": "1"
  }
}
```

これもユーザー設定、管理設定、`--settings` のいずれかに置いたときのみ有効です。

### プロジェクト設定に書いていた場合

`.claude/settings.json` に書いていた設定は無効になるため、ユーザー設定へ移してください。

## 注意点

- 変更は 2.1.305 以降のバージョンに適用されるとされています。
