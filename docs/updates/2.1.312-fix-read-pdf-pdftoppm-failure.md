## 原文（日本語訳）

古いセッションファイルのクリーンアップが同時に実行された際、ReadツールがPDFページで「pdftoppm failed: Could not write image」と失敗することがある問題を修正しました

## 原文（英語）

Fixed the Read tool sometimes failing on PDF pages with "pdftoppm failed: Could not write image" when the clean-up of old session files ran at the same time

## 概要

PDFをページ画像に変換する際、クリーンアップ処理と競合して書き込みに失敗することがありました。この競合が解消されています。

## 基本的な使い方

```
@report.pdf の3〜5ページを読んで要点をまとめて
```

## 実践例

### 仕様書PDFの確認

長いPDFをページ指定で読み込む作業が安定します。

## 注意点

- PDF読み取りには `pdftoppm` が必要です。環境に導入されているか確認してください。
