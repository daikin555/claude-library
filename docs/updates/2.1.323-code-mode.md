## 原文（日本語訳）

Code Modeを追加しました。これはClaudeがツールを呼び出すためにJavaScriptを書く、実験的なオプトイン機能です。有効化する方法、または組織全体で無効化する方法は https://code.claude.com/docs/en/code-mode を参照してください。

## 原文（英語）

Added Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools; see https://code.claude.com/docs/en/code-mode to turn it on, or to turn it off for an organization

## 概要

Code Modeは、Claudeが個々のツール呼び出しを1つずつ発行する代わりに、JavaScriptコードを書いてツールを呼び出す実験的機能です。デフォルトでは無効で、利用者が明示的にオプトインする必要があります。組織管理者は組織単位で無効化することもできます。

## 基本的な使い方

有効化・無効化の具体的な手順は公式ドキュメントで案内されています。実験的機能のため、設定方法は今後変更される可能性があります。

```bash
# 公式ドキュメントの手順に従って有効化する
# https://code.claude.com/docs/en/code-mode
claude
```

## 実践例

### 複数ファイルにまたがる繰り返し処理

多数のファイルに同じ調査を行う場合、ツール呼び出しをループとしてコードにまとめられるため、往復の回数を減らせる可能性があります。

```text
src/ 配下のすべてのTypeScriptファイルから、非推奨APIの使用箇所を一覧にして
```

### 組織での無効化

組織として実験的機能を許可しない場合は、公式ドキュメントに記載された管理者向けの手順でCode Modeをオフにできます。

## 注意点

- 実験的機能であり、挙動や設定方法が変わる可能性があります
- オプトイン方式のため、有効にしない限り従来どおりの動作です
- コードによるツール呼び出しでも、権限設定（permissions）は引き続き確認してください
