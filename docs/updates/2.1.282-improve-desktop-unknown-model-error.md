## 原文（日本語訳）

Claude Desktopの不明なモデルに関するエラーを改善し、別のモデルへの切り替えを提案するようにしました。

## 原文（英語）

Improved the Claude Desktop unknown-model error to suggest switching to a different model

## 概要

Claude Desktopで、指定されたモデルが認識されない（廃止された、または利用できないモデルIDが指定された等の）場合に表示されるエラーメッセージが改善されました。従来はエラーが発生した旨だけが表示されていましたが、今回の改善によって、別の利用可能なモデルへ切り替えるよう具体的に提案されるようになり、ユーザーが次に取るべき行動が明確になりました。

## 基本的な使い方

不明なモデルIDを指定してしまった場合、表示されるエラーメッセージの提案に従って `/model` で別のモデルに切り替えます。

```
/model
```

## 実践例

### 廃止されたモデルIDを使い続けていた場合の移行

古いドキュメントやスクリプトに記載された廃止済みのモデルIDを使っていた場合でも、エラーメッセージの提案に従ってスムーズに現行モデルへ移行できます。

### 新規ユーザーの初回セットアップ時の混乱防止

Fableモデルなど複数のモデルファミリーがある中で、誤ったモデルIDを入力してしまった初心者ユーザーでも、次に何をすべきかが分かりやすくなります。

## 注意点

- 提案されるモデルは利用可能なプランやアカウントの状態によって異なります
- Claude Desktop以外のクライアント（CLIなど）での不明モデルエラー表示は対象外です
