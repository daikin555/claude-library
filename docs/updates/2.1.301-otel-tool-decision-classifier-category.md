# OpenTelemetry tool_decision イベントにclassifier_categoryを追加

## 原文（日本語に翻訳）

OpenTelemetry の `tool_decision` イベントに `classifier_category` を追加しました。`OTEL_LOG_TOOL_DETAILS=1` のとき、分類器のブロックに該当した組み込みルールの名前が入ります。

## 原文（英語）

Added `classifier_category` to OpenTelemetry `tool_decision` events, naming the built-in rule a classifier block matched, when `OTEL_LOG_TOOL_DETAILS=1`

## 概要

autoモードの分類器がツール呼び出しをブロックした際、どの組み込みルールに該当したかを `classifier_category` で確認できます。ブロックの原因調査に役立ちます。

## 基本的な使い方

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_LOGS_EXPORTER=otlp
export OTEL_LOG_TOOL_DETAILS=1
claude
```

## 実践例

### ブロック理由の傾向分析

`classifier_category` ごとにブロック件数を集計し、頻出するルールを把握できます。

### 運用ルールの見直し

特定のカテゴリで誤ブロックが多い場合、権限設定やプロンプトの改善材料になります。

## 注意点

- `OTEL_LOG_TOOL_DETAILS=1` を設定した場合のみ出力されます。
- ツールの詳細がログに含まれるため、機密情報の取り扱いに注意してください。
