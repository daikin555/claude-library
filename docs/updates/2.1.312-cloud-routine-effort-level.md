## 原文（日本語訳）

[クラウドセッション] クラウドで実行するルーチンの作成・編集時に、モデルピッカーへ努力レベルを追加しました

## 原文（英語）

[Cloud sessions] Added an effort level to the model picker when you create or edit a routine that runs in the cloud

## 概要

クラウドで動くルーチンに、モデルと併せて努力レベルを指定できるようになりました。

## 基本的な使い方

ルーチンの作成・編集ダイアログでモデルを選び、努力レベルを指定します。

## 実践例

### 定型タスクは低め

単純な定期処理は努力レベルを抑えてコストと時間を節約します。

### 複雑な分析は高め

重い分析ルーチンでは高い努力レベルを選びます。

## 注意点

- 選べるレベルはモデルによって異なる場合があります。
