# VSCode 拡張で ultrathink が xhigh effort で実行される

## 原文（日本語訳）

- [VSCode] `ultrathink` のターンを `xhigh` effort で実行するよう変更し、ターミナルと同様にチャットボックスで虹色表示する

## 原文（英語）

- [VSCode] Changed `ultrathink` to run its turn at `xhigh` effort and show in a rainbow in the chat box, as in the terminal

## 概要

VSCode 拡張でも、プロンプトに `ultrathink` を含めるとそのターンが `xhigh` effort で実行され、チャットボックスで虹色に表示されます。

## 基本的な使い方

```text
ultrathink この設計の問題点を洗い出して
```

## 実践例

### 難しい設計レビュー

特定のターンだけ深く考えさせたいときに、キーワードを付けるだけで切り替えられます。

## 注意点

- 無効化したい場合は `CLAUDE_CODE_DISABLE_ULTRATHINK` を使用します。
