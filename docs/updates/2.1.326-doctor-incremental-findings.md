# /doctor が調査結果を順次共有

## 原文（日本語に翻訳）

`/doctor` が、完全なレポートまで黙っているのではなく、作業しながら結果を共有するようになりました。

## 原文（英語）

Improved `/doctor` to share findings as it works instead of staying silent until the full report

## 概要

`/doctor` の診断に時間がかかる環境でも、途中経過が表示されるため、フリーズしたのか判断しやすくなりました。

## 基本的な使い方

```text
/doctor
```

## 実践例

### 環境の不具合を調べる

インストール、設定、MCP などの問題を調べるときに `/doctor` を実行すると、見つかった項目が順次表示されます。

## 注意点

- 同バージョンでは、設定や `.mcp.json` の JSON エラーに行・列が表示されるようにもなっています。
