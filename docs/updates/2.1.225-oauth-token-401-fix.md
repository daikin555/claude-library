## 原文（日本語訳）

一時的な401エラーで、長期間有効な`CLAUDE_CODE_OAUTH_TOKEN`がローカルに保存されたログインの短期間有効なトークンに置き換わり、再起動するまでヘッドレスセッションが破損する問題を修正しました

## 原文（英語）

Fixed a transient 401 replacing a long-lived `CLAUDE_CODE_OAUTH_TOKEN` with a stored login's short-lived token, breaking headless sessions until restart

## 概要

Claude CodeのヘッドレスセッションやCI/CDパイプラインで使用される長期間有効な`CLAUDE_CODE_OAUTH_TOKEN`が、一時的なAPI 401エラーによって誤ってローカルの短期間有効なトークンに置き換わる問題が発生していました。この修正により、認証トークンの不正な置換が防止され、ヘッドレスセッションの信頼性が向上します。

## 基本的な使い方

ヘッドレス環境やCI/CDパイプラインで`CLAUDE_CODE_OAUTH_TOKEN`を設定するには、まず`claude setup-token`コマンドでトークンを生成し、環境変数として設定します。

```bash
# トークンを生成（ブラウザで認可フローが開きます）
claude setup-token

# 返されたトークンを環境変数として設定
export CLAUDE_CODE_OAUTH_TOKEN=your-long-lived-token
```

その後、ヘッドレスモードでClaudeを実行できます。

```bash
# ヘッドレスモードで実行（対話形式ではない）
claude --headless -p "Your prompt here"
```

## 実践例

### GitHub Actionsでのトークン使用

GitHub Actionsでヘッドレスセッションを実行する場合、生成したトークンをシークレットとして保存し、ワークフローで使用します。

```yaml
name: Claude Code Automation

on: [push]

jobs:
  claude-task:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Run Claude Code
        env:
          CLAUDE_CODE_OAUTH_TOKEN: ${{ secrets.CLAUDE_TOKEN }}
        run: |
          claude --headless --auto-approve -p "Analyze this codebase" > analysis.txt

      - name: Upload results
        uses: actions/upload-artifact@v3
        with:
          name: analysis
          path: analysis.txt
```

### 長時間実行されるヘッドレスプロセス

サーバーやバックグラウンドプロセスで継続的にClaudeを実行する場合、環境変数を設定してから起動します。

```bash
#!/bin/bash

# 環境変数を設定
export CLAUDE_CODE_OAUTH_TOKEN=$(cat /secure/token.txt)

# 長時間実行されるタスク
while true; do
  claude --headless --bare -p "Process queue" 2>&1 | logger
  sleep 60
done
```

### ビルドスクリプトへの統合

プロジェクトのビルドまたはテストプロセス中にClaudeを実行する場合。

```bash
#!/bin/bash

set -e

export CLAUDE_CODE_OAUTH_TOKEN=$CLAUDE_TOKEN

# テストを実行
npm test

# テスト結果を分析
claude --headless --bare -p \
  "Analyze the test failures in the previous output and suggest fixes" \
  --allowedTools "Read,Bash(git *)" > suggestions.md
```

## 注意点

- **一時的なエラーの影響**: この修正前は、API 401エラーが一度発生するだけで、環境変数のトークンが上書きされる可能性がありました
- **短期トークンの寿命**: ローカルに保存されたログインのトークンは短期間有効ですが、`CLAUDE_CODE_OAUTH_TOKEN`は1年間有効です
- **認証優先度**: 複数の認証方法が設定されている場合、Claude Codeは特定の優先順位に従って認証を選択します。`CLAUDE_CODE_OAUTH_TOKEN`は`apiKeyHelper`の次に評価されます
- **再起動が不要に**: この修正により、一時的な401エラーが発生してもセッションの再起動が不要になりました
- **ベアモードでは未対応**: `--bare`フラグを使用する場合、`CLAUDE_CODE_OAUTH_TOKEN`は読み込まれません。代わりに`ANTHROPIC_API_KEY`を使用するか、`apiKeyHelper`を設定してください
