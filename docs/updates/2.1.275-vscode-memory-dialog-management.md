## 原文（日本語訳）
[VSCode] Memoryダイアログ内で、保存済みメモリの閲覧・編集・削除ができるようになりました

## 原文（英語）
[VSCode] Added viewing, editing and deleting a saved memory inside the Memory dialog

## 概要
VS Code拡張機能のMemoryダイアログが強化され、これまでは確認しづらかった保存済みメモリの内容を、ダイアログ内で直接閲覧・編集・削除できるようになりました。メモリファイルを別途開いてテキストを編集する手間が減り、記憶させた内容の管理がその場で完結します。

## 基本的な使い方
VS Code上でMemoryダイアログを開き、保存済みのメモリ項目を選択して編集・削除します。

```
# VS CodeのClaude Codeパネルから Memory ダイアログを開く
# → 保存済みメモリの一覧が表示される
# → 各項目を選んで内容を編集、または削除ボタンで削除できる
```

## 実践例

### 古くなったメモリ内容を修正する
```
# Memoryダイアログを開く
# 「プロジェクトのAPIエンドポイントは v1」というメモリを選択
# → ダイアログ内でテキストを直接 v2 に修正して保存
```

### 不要になったメモリを削除する
```
# Memoryダイアログで一覧を確認
# 使われなくなった古いメモを選び、削除ボタンで削除
# → CLAUDE.mdやメモリファイルを手動で開かずに整理できる
```

## 注意点
- この機能はVS Code拡張機能限定です。CLIやDesktopアプリでの挙動は別途確認が必要です。
- 削除は元に戻せない場合があるため、重要なメモリを削除する際は内容を確認してから操作してください。
- メモリの保存場所（プロジェクト単位かユーザー単位か）によって、影響範囲が異なります。
