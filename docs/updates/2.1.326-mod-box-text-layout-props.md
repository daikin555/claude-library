# モッドの Box と Text にスクロール・行数制限・クリップ指定を追加

## 原文（日本語に翻訳）

モッドの `Box` に `overflowX="scroll"` を、`Text` に `maxLines` と `wrap="clip"` を追加しました。

## 原文（英語）

Added `overflowX="scroll"` on a mod's `Box`, and `maxLines` and `wrap="clip"` on its `Text`

## 概要

モッドの UI 部品でレイアウトの選択肢が増えました。横スクロール、表示行数の上限、はみ出し部分のクリップを指定できます。

## 基本的な使い方

```jsx
<Box overflowX="scroll">
  <Text maxLines={3} wrap="clip">{longText}</Text>
</Box>
```

## 実践例

### 長いログ表示を制限する

`maxLines` でパネル内の表示行数を抑え、画面を占有しないようにできます。

### 幅の広い表示を横スクロールさせる

`overflowX="scroll"` で、幅が広いテーブルなどを折り返さずに表示できます。

## 注意点

- 上記コードは使い方のイメージです。正確な API は plugin-authoring の資料を確認してください。
