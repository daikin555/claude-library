# Opus 4.8 の fast mode が非推奨に（Opus 5.5 への移行）

## 原文（日本語訳）

- Opus 4.8 の fast mode を 2026年10月30日付で非推奨化。2026年11月30日に削除される。削除後、Opus 4.8 の fast mode リクエストはエラーを返し、標準の Opus 4.8 にはフォールバックしない。高速化を維持するには Opus 5.5 に移行すること

## 原文（英語）

- Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. Migrate to Opus 5.5 to keep the speedup

## 概要

Opus 4.8 の fast mode は 2026年11月30日に削除されます。以降、Opus 4.8 での fast mode リクエストはエラーになります。高速出力が必要な場合は Opus 5.5 へ移行してください。

## 基本的な使い方

```text
/model opus
/fast
```

## 実践例

### 移行手順

1. 設定やスクリプトで固定している Opus 4.8 のモデル指定を確認する
2. モデルを Opus 5.5（`claude-opus-5-5`）に切り替える
3. `/fast` で fast mode が有効なことを確認する

```bash
claude --model claude-opus-5-5
```

## 注意点

- 削除後は標準モデルへ自動フォールバックしないため、スクリプトや CI が失敗する可能性があります。
- 11月30日までに移行を完了してください。
