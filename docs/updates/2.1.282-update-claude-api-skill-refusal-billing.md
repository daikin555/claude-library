## 原文（日本語訳）

`claude-api` スキルを更新しました。出力前の拒否に関する課金は「拒否がどのように課金されるか」のドキュメントにリンクされ、ストリーミング途中の拒否は通常料金で課金され、出力前の拒否はレート制限に対してもカウントされるようになりました。

## 原文（英語）

Updated the `claude-api` skill: pre-output refusal billing now links to the How refusals are billed docs, mid-stream refusals bill at normal rates, and pre-output refusals count against rate limits

## 概要

Claude APIがリクエストを「拒否（refusal）」した場合の課金ルールは複雑で、出力前の拒否とストリーミング途中の拒否とで扱いが異なります。今回、Claude Codeに組み込まれている `claude-api` スキル（Claude API・Agent SDKに関する開発支援用スキル）が更新され、出力前の拒否については公式の「拒否がどのように課金されるか」のドキュメントに直接リンクするようになり、ストリーミング途中の拒否は通常のトークン課金と同様に扱われること、そして出力前の拒否であってもレート制限にはカウントされることが明記されました。

## 基本的な使い方

Claude Codeの `claude-api` スキルは、Claude API・Anthropic SDKに関する質問をした際に自動的に参照されます。特別なコマンドは不要です。

```
Claude APIの拒否はどのように課金されますか？
```

のように質問すると、スキルが最新の課金ルールを踏まえて回答します。

## 実践例

### API利用コストの見積もり

自社サービスにClaude APIを組み込む際、拒否が発生した場合のコスト影響をあらかじめ正確に見積もることができます。

### レート制限の設計・監視

拒否されたリクエストであってもレート制限にカウントされることを踏まえ、リトライロジックやレート制限の監視設計を行う際の判断材料になります。

## 注意点

- 実際の課金・レート制限の詳細な仕様は変更される可能性があるため、重要な意思決定の前には公式ドキュメントの最新版を確認してください
- この更新はスキルの参照情報の正確性向上であり、Claude API自体の課金仕様を変更するものではありません
