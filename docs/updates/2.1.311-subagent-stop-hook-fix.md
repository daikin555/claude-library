## 原文（日本語に翻訳）

`SubagentStop` フックが、サブエージェントの終了時に1回だけではなく、実行中のサブエージェントごとに毎分約2回実行されていた問題を修正しました。

## 原文（英語）

Fixed `SubagentStop` hooks running about twice a minute for each running subagent instead of once when it finishes

## 概要

`SubagentStop` フックは、サブエージェントの完了時に1回だけ動く想定でした。しかし実際には、実行中のサブエージェントに対して毎分約2回起動していました。この修正で、終了時に1回だけ実行されます。

## 基本的な使い方

`.claude/settings.json` の例です。

```json
{
  "hooks": {
    "SubagentStop": [
      {
        "hooks": [
          { "type": "command", "command": "echo \"subagent finished\" >> ~/.claude/subagent.log" }
        ]
      }
    ]
  }
}
```

## 実践例

### 完了通知

```json
{
  "hooks": {
    "SubagentStop": [
      { "hooks": [{ "type": "command", "command": "notify-send 'Subagent done'" }] }
    ]
  }
}
```

### 後処理の実行

サブエージェントが生成した成果物を、完了時に1回だけ集計・検証するスクリプトを安全に呼べるようになります。

## 注意点

- 回避策として重複排除を入れていた場合は、不要になる可能性があります。
- 冪等な処理にしておくと、より安全です。
