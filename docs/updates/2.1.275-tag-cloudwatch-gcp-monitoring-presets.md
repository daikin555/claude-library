## 原文（日本語訳）
[Claude Tag] Claude Tag管理設定のアクセスバンドルの「Credentials」タブに、Amazon CloudWatch、CloudWatch Logs、Amazon SNS、Google Cloud Monitoring、Cloud Loggingのプリセットを追加。

## 原文（英語）
[Claude Tag] Added Amazon CloudWatch, CloudWatch Logs, Amazon SNS, Google Cloud Monitoring and Cloud Logging presets to an access bundle's Credentials tab in Claude Tag admin settings

## 概要
Claude Tagの管理者は、アクセスバンドルの「Credentials」タブから外部サービスとの接続情報をプリセットとして登録できます。今回のアップデートで、AWSのモニタリング・通知系サービスであるAmazon CloudWatch、CloudWatch Logs、Amazon SNSと、Google CloudのGoogle Cloud Monitoring、Cloud Loggingがプリセットとして追加されました。これにより、これらの監視・ログサービスとの接続設定をゼロから作成する必要がなくなり、Slack上のClaudeからインフラの監視情報やログを扱うタスクを素早く設定できるようになります。

## 基本的な使い方
Claude Tag管理設定でアクセスバンドルを開き、「Credentials」タブから該当するプリセット（例: CloudWatch Logs）を選択し、必要な認証情報を入力して保存します。

```
Claude Tag 管理設定 > アクセスバンドル > Credentials タブ
> プリセットを選択: "Amazon CloudWatch Logs"
> 認証情報（IAMロール/APIキー等）を入力 > 保存
```

## 実践例

### AWS CloudWatchのアラーム状況をSlackから確認する
CloudWatchプリセットを設定したアクセスバンドルをチャンネルにアタッチすることで、Slack上でClaudeに「本番環境のCPUアラームの状況を教えて」のように依頼し、CloudWatchのメトリクスやアラーム情報を取得させることができます。

### Google Cloud Loggingのエラーログを調査する
Cloud Loggingプリセットを利用すれば、GCP上のアプリケーションログをClaude経由でSlackから検索・要約させ、障害調査のスピードを上げられます。

```
ユーザー: 「昨夜のCloud Loggingでエラーレベルのログを教えて」
Claude: （Cloud Logging接続を使ってログを検索し要約）
```

### Amazon SNSの通知設定を確認する
SNSプリセットを使えば、トピックの購読状況や通知履歴の確認といったタスクをSlack上のClaudeに依頼できます。

## 注意点
- 各プリセットを利用するには、対応するAWS/GCPアカウント側での認証情報（IAMロールやサービスアカウントキーなど）の発行が別途必要です。
- プリセットはあくまで接続設定のひな形であり、実際のアクセス範囲は付与した権限に依存します。最小権限の原則に従って設定することを推奨します。
