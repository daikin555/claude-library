## 原文（日本語訳）

Remote Controlの適格性エラー自体は `--debug` を付けて実行するよう案内していたにもかかわらず、`claude remote-control --debug` が「Unknown argument: --debug」で失敗していた不具合を修正しました。

## 原文（英語）

Fixed `claude remote-control --debug` failing with "Unknown argument: --debug", although Remote Control's own eligibility error says to run with `--debug`

## 概要

Remote Controlが利用できない場合に表示される適格性エラーメッセージでは、詳細を確認するために `--debug` フラグを付けて再実行するよう案内されていました。しかし実際には `claude remote-control --debug` を実行すると「Unknown argument: --debug」というエラーになり、案内通りに操作してもデバッグ情報を確認できないという矛盾した状態でした。今回の修正でこのフラグが正しく認識されるようになりました。

## 基本的な使い方

Remote Controlの利用条件を満たしていない場合のトラブルシューティングに使います。

```bash
claude remote-control --debug
```

## 実践例

### Remote Controlが使えない原因の調査

`/rc` コマンドやRemote Control機能が期待通り動作しない場合、`--debug` フラグ付きで実行することで、適格性チェックの詳細なログを確認し、原因（アカウントの設定、ネットワーク制限など）を特定できます。

### サポートへの問い合わせ時の情報収集

Anthropicのサポートに問い合わせる際、`--debug` の出力をそのまま共有することで、より迅速な調査につなげられます。

## 注意点

- この修正はエラーメッセージ通りにコマンドが動作するようにするものであり、Remote Control自体の利用条件を変更するものではありません
- Remote Controlの基本的な使い方については公式ドキュメントを参照してください
