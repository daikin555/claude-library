## 原文（日本語に翻訳）

Claude Mods を追加: プラグインがより深い挙動を変更できるようになりました。

## 原文（英語）

Added Claude Mods: plugins may now modify deeper behavior

## 概要

Claude Mods は、プラグインが Claude Code のより深い挙動を変更できるようにする仕組みです。従来のプラグインはコマンドやスキル、フックなどの追加が中心でしたが、Mods によって拡張できる範囲が広がります。具体的な API の詳細は公式ドキュメントを確認してください。

## 基本的な使い方

プラグインの管理は従来どおり `/plugin` コマンドから行います。

```
/plugin
/plugin enable <plugin-name>@<marketplace>
```

Mods として提供されるプラグイン（例: [You should know](./2.1.287-you-should-know-mod.md)）も同じ方法で有効化できます。

## 実践例

### 組み込み Mod を有効にする

組み込みの Mod は `@builtin` マーケットプレイスから有効化します。

```
/plugin enable cc-plugin-you-should-know@builtin
```

### 自作 Mod の開発

Mod を自作する場合は、Claude Code に同梱されている `plugin-authoring` スキルを利用すると、ターミナルやデスクトップの Code タブ内で動作するペインやステータスラインなどをホットリロードしながら開発できます。

## 注意点

- Mods はより深い挙動に触れるため、信頼できる提供元のプラグインだけを有効にしてください。
- 提供される機能や対象環境はバージョンによって異なる可能性があります。
