## 原文（日本語に翻訳）

応答に `</ccmemory>` のような形式の不要な閉じタグがまれに現れてしまう問題を修正

## 原文（英語）

Fixed a stray `</ccmemory>`-style closing tag occasionally appearing in responses

## 概要

Claude Codeは内部的にメモリ情報を扱う際に `<ccmemory>` のようなタグ形式を利用することがあります。これまで、ごくまれにこの内部処理用のタグの閉じタグ（`</ccmemory>` のような形式）が、そのままユーザーに表示される応答テキストに混入してしまう不具合がありました。今回の修正により、応答からこのような内部タグが正しく除去されるようになりました。

## 基本的な使い方

この修正は内部処理の改善であり、ユーザー側での操作は不要です。通常通りClaude Codeを利用するだけで改善が適用されます。

```bash
claude
```

## 実践例

### 修正前の挙動

メモリ機能に関連する処理が行われた際、まれに応答テキストの末尾や途中に `</ccmemory>` のような不要な文字列が混入し、応答の見た目が乱れることがありました。

### 修正後の挙動

内部タグが応答テキストから正しく除去され、余計な文字列が表示されなくなりました。

```
# 修正前: 応答末尾に </ccmemory> のような文字列が混入することがあった
# 修正後: そのような内部タグは表示されない
```

## 注意点

- この不具合はまれに発生するものであり、常に再現するものではありませんでした
- メモリ機能（CLAUDE.mdや記憶ファイルなど）を積極的に利用しているセッションで発生しやすい傾向がありました
- 応答品質に関する内部的な修正のため、ユーザー側で設定変更などは不要です
