# CLAUDE_CODE_SUBAGENT_EFFORT でサブエージェントの effort を指定する

## 原文（日本語訳）

- 他に指定がない場合にサブエージェントが実行される effort レベルを、セッションのものを継承する代わりに設定する `CLAUDE_CODE_SUBAGENT_EFFORT` を追加

## 原文（英語）

- Added `CLAUDE_CODE_SUBAGENT_EFFORT` to set the effort level subagents run at when nothing else names one, instead of inheriting the session's

## 概要

サブエージェントはこれまでセッションの effort レベルを継承していました。`CLAUDE_CODE_SUBAGENT_EFFORT` を設定すると、他に指定がない場合のサブエージェントの既定 effort を独立して決められます。

## 基本的な使い方

```bash
export CLAUDE_CODE_SUBAGENT_EFFORT=low
claude
```

## 実践例

### メインは高 effort、探索用サブエージェントは低 effort

メインセッションでは深く考えさせつつ、多数起動されるサブエージェントのコストと時間を抑えられます。

```bash
CLAUDE_CODE_SUBAGENT_EFFORT=low claude
```

## 注意点

- effort が明示されている場合はそちらが優先されます（「他に指定がない場合」の既定値）。
- 指定可能な値は公式ドキュメントで確認してください。
