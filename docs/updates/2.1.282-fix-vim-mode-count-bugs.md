## 原文（日本語訳）

vimモードにおいて、`>>` が空行をインデントしてしまう問題、カウント付きの `r` が行より長く変更してしまう問題、`2J` が1行多く結合してしまう問題、最終行に対するカウント（`2dd`、`2>>`）が行をずらしたり削除したりしてしまう問題を修正しました。

## 原文（英語）

Fixed vim mode `>>` indenting empty lines, `r` with a count longer than the line changing text, `2J` joining one line too many, and a count on the last line (`2dd`, `2>>`) shifting or deleting it

## 概要

Claude Codeのvimモードには、プロンプト入力欄でvimライクな編集操作を行える機能がありますが、いくつかの操作にカウント（数値プレフィックス）を組み合わせた際の細かい不具合が複数存在していました。空行への `>>` によるインデント、行の長さを超えるカウント付き `r` による置換、`2J` での結合対象行数のずれ、最終行に対するカウント付き削除・インデントでの範囲の誤りなどです。今回の修正でこれらがまとめて解消され、vimの標準的な挙動によりまで近づきました。

## 基本的な使い方

```
/vim
```

でvimモードを有効化した上で、通常のvimと同様の操作を行います。

```
>>      " 現在行をインデント
3r x    " カーソル位置から3文字をxに置換
2J      " 現在行と次の1行を結合
2dd     " 現在行から2行削除
```

## 実践例

### vim使い慣れたユーザーの違和感解消

普段からvimやNeovimを使っている開発者が、Claude Codeのプロンプト入力でも同じ感覚でカウント付き操作を行えるようになり、誤操作によるテキストの意図しない変更が減ります。

### 複数行プロンプトの編集効率化

長い複数行のプロンプトを編集する際、`2dd` で不要な2行をまとめて削除したり、`2J` で行を結合したりする操作が正確に機能するようになり、編集効率が向上します。

## 注意点

- vimモードはプロンプト入力欄にのみ適用され、会話出力には影響しません
- vimモードは `/vim` またはユーザー設定ファイルへの記載で有効化できます
