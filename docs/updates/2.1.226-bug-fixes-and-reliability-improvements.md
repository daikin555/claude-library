## 原文（日本語に翻訳）

バグ修正と安定性向上

## 原文（英語）

Bug fixes and reliability improvements

## 概要

v2.1.226は、Claude Codeの安定性と信頼性を向上させるためのメンテナンスリリースです。このリリースでは、ユーザーが遭遇していた様々なバグを修正し、エッジケースへの対応を強化しています。定期的な更新により、より安定した操作環境を実現し、開発ワークフローの中断を減らすことができます。このリリースへの更新を通じて、Claude Codeをより快適にご利用いただけるようになります。

## 基本的な使い方

### インストール済みのClaude Codeを更新する

Claude Codeをインストール済みの場合、以下の方法で最新バージョンに更新できます。

**推奨：自動更新の確認**
```bash
claude --version
```

**手動で更新する**
```bash
claude update
```

**npm経由でのインストール**
```bash
npm install -g @anthropic-ai/claude-code@latest
```

**Homebrew経由での更新（macOS）**
```bash
brew upgrade claude-code
```

### 更新後にバージョンを確認する

```bash
claude --version
```

## 実践例

### インストール後の動作確認

新しいバージョンにアップデートしたら、診断コマンドで正常にインストールされているか確認しましょう。

```bash
claude doctor
```

このコマンドは以下を検証します：
- ネットワーク接続状態
- PATH設定
- バイナリの動作確認
- ディレクトリのアクセス権限
- インストール整合性

### 自動更新の設定確認と変更

Claude Codeはデフォルトで毎日自動的に更新をチェックし、バックグラウンドでインストールします。自動更新の設定を確認または変更する場合：

```bash
# 自動更新を無効にする場合
claude settings set autoUpdate false

# 安定版チャネルを指定する場合
claude settings set releaseChannel stable

# 最小バージョンを指定する場合
claude settings set minimumVersion "2.1.226"
```

### トラブルシューティング：ログインの再設定

更新後にログイン関連の問題が発生した場合は、ログアウトして再度ログインすることで解決することがあります。

```bash
claude logout
claude login
```

## 注意点

- **自動更新の確認**: Claude Codeはデフォルトで自動更新が有効になっています。自動更新を無効化している場合は、定期的に `claude update` コマンドで手動更新してください。

- **複数のインストール方法**: npm、Homebrew、WinGetなど複数の方法でインストールしている場合、各パッケージマネージャーの更新方法に従ってください。

- **バージョン確認**: 重要なバグ修正が含まれている場合があるため、リリースノートで具体的な修正内容を確認することをお勧めします。

- **既存セッションへの影響**: 既存のClaude Codeセッションは新しいバージョンで自動的に再起動される可能性があります。重要な作業中の場合は適切なタイミングで更新してください。

- **PATH設定**: アップデート後に `command not found: claude` エラーが表示される場合は、ターミナルを再起動してPATH設定を反映させてください。
