# Claude apps gateway に CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME を追加

## 原文（日本語に翻訳）

Claude apps gateway 向けに `CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1` を追加しました。`oidc.use_proxy: true` のとき、`NO_PROXY` が設定されていても、サインイン要求は `https` の IdP のホスト名をプロキシに渡します。

## 原文（英語）

Added `CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1` for Claude apps gateways: with `oidc.use_proxy: true`, sign-in requests hand the proxy an `https` IdP's hostname even with `NO_PROXY` set

## 概要

プロキシ経由で IdP に接続する構成で、ホスト名ベースの接続を強制するための設定です。

## 基本的な使い方

```bash
export CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1
```

## 実践例

### プロキシ必須の IdP 接続

```yaml
oidc:
  use_proxy: true
```
と併用すると、`NO_PROXY` に IdP が含まれていてもホスト名がプロキシへ渡されます。

## 注意点

- 対象は `https` の IdP です。
- `oidc.use_proxy: true` との組み合わせで効果があります。
