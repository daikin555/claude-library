## 原文（日本語訳）

このコンピュータで開始されたRemote Controlセッションが、セッション一覧のWebエントリから開けなかった不具合を修正しました。現在は、そのセッションが他の場所で実行中でない限り、ローカルの会話が開くようになりました。

## 原文（英語）

[VSCode] Fixed Remote Control sessions started on this computer not opening from their Web entry in the session list; they now open the local conversation unless it's running elsewhere

## 概要

Remote Controlは、あるマシンで開始したセッションをスマートフォンや別のブラウザから引き継いで操作できる機能ですが、VS Code拡張機能でセッション一覧にWeb版のエントリとして表示されているセッションを開こうとした際、それが元々自分のコンピュータで開始されたセッションであっても正しく開けない不具合がありました。今回の修正で、そのセッションが他の場所で実行中でない限り、ローカルの会話がそのまま開かれるようになりました。

## 基本的な使い方

VS Code拡張機能のセッション一覧から、Web版のエントリとして表示されているセッションをクリックして開きます。自分のマシンで開始したセッションであれば、ローカルの会話がそのまま開きます。

## 実践例

### 同じマシン上での作業の継続

外出先でRemote Controlを使ってスマートフォンからセッションを確認した後、オフィスに戻って同じマシンのVS Codeからそのセッションを開き直す際にも、スムーズにローカルの会話へアクセスできます。

### セッション管理の一貫性向上

複数のセッションを行き来する開発者にとって、Web版の一覧とローカルのVS Code拡張機能とで表示・アクセスの一貫性が保たれるようになります。

## 注意点

- 該当セッションが別の場所（別のデバイスなど）で現在実行中の場合は、引き続きリモートセッションとして扱われます
- VS Code拡張機能に特有の修正であり、CLI単体での利用には直接関係しません
