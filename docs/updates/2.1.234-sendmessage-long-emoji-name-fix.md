## 原文（日本語訳）

`ListAgents` からコピーした宛先の名前が200文字の上限に達している場合や絵文字を多く含む場合に、`SendMessage` がその宛先を拒否してしまう不具合を修正しました。

## 原文（英語）

Fixed `SendMessage` rejecting a recipient copied from `ListAgents` when the session name is at the 200-character cap or emoji-heavy

## 概要

複数のClaude Codeエージェント間でメッセージをやり取りする際、`ListAgents` で取得したセッション名を宛先として `SendMessage` に指定します。しかし、セッション名が最大文字数（200文字）ちょうどであったり、絵文字を多く含んでいたりする場合、`SendMessage` がその名前を正しい宛先として認識できずに拒否してしまう不具合がありました。今回の修正により、こうした長いセッション名や絵文字を多く含むセッション名でも、`ListAgents` の出力からそのままコピーして `SendMessage` の宛先に指定できるようになりました。

## 基本的な使い方

`ListAgents` でエージェント一覧を確認し、表示された名前をそのまま `SendMessage` の `to` パラメータに渡します。

```
ListAgents() で一覧を取得
→ 表示された名前（絵文字を含む長い名前でも）をそのままコピー
→ SendMessage({ to: "<コピーした名前>", message: "..." })
```

## 実践例

### 絵文字入りのセッション名を持つエージェントにメッセージを送る

```
# ListAgentsの出力例
- 🚀デプロイ監視エージェント🔥 [ref]

# 修正前: この名前を to に指定すると拒否されることがあった
SendMessage({ to: "🚀デプロイ監視エージェント🔥 [ref]", message: "進捗を教えて" })

# 修正後: 正しく宛先として認識され、メッセージが届く
```

### 200文字ぎりぎりの長いセッション名への送信

自動生成された長い説明的なセッション名（ちょうど上限の200文字）を持つバックグラウンドエージェントに対しても、`ListAgents` の出力をそのまま貼り付けて `SendMessage` できるようになりました。

## 注意点

- 宛先名が一覧上で他の行と重複している場合は、`[ref]` 付きの表記を含めて正確にコピーする必要があります
- この修正はあくまで「境界値（200文字ちょうど）」や「絵文字を多く含む」ケースでの拒否を解消するものです。名前自体を変更する機能ではありません
