## 原文（日本語訳）

[Code Review] GitHubのプッシュイベントが遅れて届いた場合に、古いコミットをレビューしたりレビューされなかったりする問題を修正。プルリクエストの現在のコミットをレビューします

## 原文（英語）

[Code Review] Fixed Code Review reviewing an outdated commit, or none at all, when GitHub delivered a push event late; it now reviews the pull request's current commit

## 概要

イベント到着が遅れても、PRの最新コミットがレビュー対象になります。

## 基本的な使い方

追加操作は不要です。PRにプッシュすると最新コミットがレビューされます。

## 実践例

### 連続プッシュ

短時間に何度もプッシュしても、最新の状態がレビューされます。

## 注意点

- レビュー結果がどのコミットに対するものか、コメント内で確認する習慣が役立ちます。
