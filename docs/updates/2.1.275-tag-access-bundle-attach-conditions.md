## 原文（日本語訳）
[Claude Tag] Claude Tag設定のアクセスバンドルにアタッチ条件を追加。Ownerはバンドルをメンバー限定チャンネルだけでなく、ゲストがいるチャンネルやSlack Connectチャンネルにも適用できるようになった。

## 原文（英語）
[Claude Tag] Added attach conditions for access bundles in Claude Tag settings: an Owner can let a bundle also apply in channels with guests or Slack Connect channels, not just member-only

## 概要
Claude Tag（Slack上のClaude）の管理設定では、権限や認証情報をまとめた「アクセスバンドル」をチャンネルに適用できますが、これまではメンバー限定チャンネルにしか適用できませんでした。今回のアップデートで「アタッチ条件」という設定項目が追加され、Ownerがアクセスバンドルをゲストが参加しているチャンネルやSlack Connect（社外連携）チャンネルにも適用できるようになりました。これにより、社外パートナーとのやり取りが発生するチャンネルでも、統制された形でClaudeに権限を付与できます。

## 基本的な使い方
Claude Tagの管理設定画面でアクセスバンドルを開き、「アタッチ条件」からチャンネルの種類（メンバー限定、ゲストを含む、Slack Connect）を選択して保存します。

```
Claude Tag 管理設定 > アクセスバンドル > 対象バンドルを選択
> アタッチ条件 > 「ゲストがいるチャンネルにも適用」をチェック
> 保存
```

## 実践例

### 社外パートナーが参加するSlack Connectチャンネルでの利用
社外との共同プロジェクト用にSlack Connectチャンネルを使っている場合、必要な認証情報バンドルのアタッチ条件を有効にすることで、そのチャンネルでもClaudeに同じ権限セットを付与できます。

```
アクセスバンドル「開発チーム標準」
> アタッチ条件: Slack Connectチャンネルを許可
> 適用先: #partner-integration
```

### ゲストユーザーが参加する社内チャンネルでの利用
ベンダーなどのゲストアカウントが参加しているチャンネルでも、Ownerが明示的に許可すればアクセスバンドルを適用できます。デフォルトでは適用されないため、意図せず外部に権限が漏れることを防げます。

## 注意点
- デフォルトではアクセスバンドルはメンバー限定チャンネルにのみ適用されます。ゲストやSlack Connectチャンネルへの適用はOwnerが明示的に許可する必要があります。
- 機密性の高い認証情報を含むバンドルをゲストが参加するチャンネルに適用する場合は、権限の範囲を十分に確認してください。
