## 原文（日本語訳）

[VSCode] Claude CodeがオフにできなかったとReportした場合でも、Remote Controlが「接続中」と表示され続けてしまう問題を修正しました。現在は正しくオフとして表示されます。

## 原文（英語）

[VSCode] Fixed Remote Control staying shown as connected after a turn-off that Claude Code reported as failed; it now shows as off

## 概要

Remote Controlは、Claude Codeをリモートから操作・監視するための機能です。これまで、Remote Controlをオフにしようとした際にClaude Code側が失敗を報告したケースで、UI上は「接続中」のまま表示され続けてしまうという不整合がありました。今回の修正により、オフ操作が失敗として報告された場合でも、UIの表示状態が正しく「オフ」に更新されるようになりました。

## 基本的な使い方

VSCode拡張機能のコマンドパレットやステータスバーからRemote Controlの状態を確認・切り替えできます。

```
> Claude Code: Toggle Remote Control
```

## 実践例

### Remote Controlをオフにしようとして失敗した場合の表示確認

修正前は、バックエンド側でオフ処理が失敗として報告されても、UI上は「接続中」のまま残ってしまい、ユーザーが実際の状態を誤認する可能性がありました。

```
修正前:
  1. Remote Controlのオフを実行 → バックエンドがエラーを報告
  2. UI表示: 「接続中」のまま（実態と不一致）

修正後:
  1. Remote Controlのオフを実行 → バックエンドがエラーを報告
  2. UI表示: 「オフ」に正しく更新される
```

### ネットワーク不安定時のRemote Control状態管理

ネットワークが不安定な環境でRemote Controlの接続・切断を繰り返す場合でも、表示される状態が実際の接続状況と一致するようになり、誤解を招く操作を防げます。

## 注意点

- この修正はUIの表示ロジックに関するものであり、Remote Control自体の接続処理ロジックを変更するものではありません。
- 表示が「オフ」になっていても、必要に応じて再度Remote Controlの状態を確認することを推奨します。
