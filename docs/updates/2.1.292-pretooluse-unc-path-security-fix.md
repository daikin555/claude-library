## 原文（日本語訳）

セキュリティ: PreToolUseフックの承認と自動モードが、ネットワーク（UNC）パスからのファイル読み取りで許可プロンプトを回避していた問題を修正した。

## 原文（英語）

Security: Fixed PreToolUse hook approvals and auto mode bypassing the permission prompt for file reads from network (UNC) paths

## 概要

UNCパス（例: `\\server\share\file`）の読み取りで、フック承認や自動モードがあっても許可プロンプトが表示されるようになりました。ネットワーク上のファイルへ意図せずアクセスするリスクを下げる修正です。

## 基本的な使い方

特別な操作は不要です。アップデートすると自動的に適用されます。

```bash
claude update
```

## 実践例

### Windows環境での運用

PreToolUseフックで読み取りを自動承認している場合でも、UNCパスへのアクセスは確認が求められます。

## 注意点

- 該当環境（特にWindowsやネットワーク共有を使う環境）では早めの更新を推奨します。
