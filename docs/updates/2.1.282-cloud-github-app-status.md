## 原文（日本語訳）

Settings › Connectors › GitHubに、Claude GitHub Appのステータス（アプリがインストールされていてアカウントから到達可能かどうか）と、接続・インストール・再接続の手順を追加しました。

## 原文（英語）

[Cloud sessions] Added Claude GitHub App status to Settings › Connectors › GitHub: whether the app is installed and reachable for your account, plus steps to connect, install or reconnect

## 概要

クラウドセッション（Claude Codeのクラウド実行環境）でGitHubリポジトリを扱う際には、Claude GitHub Appがインストールされ、正しくアカウントからアクセスできる状態である必要があります。これまでは、この連携状態が分かりにくく、問題が起きた際の原因究明が難しいことがありました。今回の変更で、Settings › Connectors › GitHub画面にGitHub Appのインストール状況と到達可能性が明示され、接続・インストール・再接続それぞれの具体的な手順も案内されるようになりました。

## 基本的な使い方

Webブラウザで設定画面を開きます。

```
Settings › Connectors › GitHub
```

GitHub Appのステータスを確認し、必要に応じて画面の案内に従って接続・インストール・再接続を行います。

## 実践例

### クラウドセッションが特定リポジトリにアクセスできない場合の原因切り分け

クラウドセッションがGitHubリポジトリを操作できないというトラブルが発生した際、まずこの画面でGitHub Appの状態を確認することで、権限設定の問題なのか、アプリ未インストールの問題なのかを素早く切り分けられます。

### 新しいGitHub組織との連携セットアップ

新たにGitHub組織のリポジトリをクラウドセッションで使いたい場合、この画面から必要なインストール手順に沿って設定を進められます。

## 注意点

- GitHub組織側の管理者権限が必要な操作（アプリのインストールなど）は、組織の管理者に依頼する必要がある場合があります
- この機能はクラウドセッションに関するものであり、ローカルのCLI利用には直接関係しません
