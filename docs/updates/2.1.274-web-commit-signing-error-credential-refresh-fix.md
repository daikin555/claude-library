## 原文（日本語訳）
[Claude Code on the web] クラウドセッションの認証情報（credentials）が更新された直後の数分間、コミットが署名エラーで失敗することがあった問題を修正しました。

## 原文（英語）
[Claude Code on the web] Fixed commits in cloud sessions occasionally failing with a signing error for a few minutes after the session's credentials refreshed

## 概要
Claude Code on the webのクラウドセッションでは、セキュリティのためセッションの認証情報が定期的に自動更新（リフレッシュ）されます。この更新直後のタイミングでコミットを作成しようとすると、内部的な署名処理と新しい認証情報の反映との間にタイミングのずれがあり、コミットが署名エラーで失敗することがありました。今回の修正により、認証情報が更新された直後でもコミット処理が正しく成功するようになりました。

## 基本的な使い方
特別な操作は不要です。通常通りクラウドセッション内でファイルを変更しコミットを行うだけで、認証情報の更新タイミングに関わらず正しく処理されます。

## 実践例

### 長時間セッションでのコミット
数時間にわたって稼働するクラウドセッションの中で、認証情報が自動更新された直後にClaudeがコミットを作成しようとしても、以前のように署名エラーで失敗することはなくなりました。

### 連続した複数回のコミット
1つのセッション内で複数回コミットを重ねる場合でも、認証情報更新タイミングに関係なく安定してコミットが成功するようになっています。

## 注意点
- この修正はクラウドセッション（Claude Code on the web）特有の問題に対するものです。
- ローカル環境でのコミット署名設定（GPGなど）には影響しません。
