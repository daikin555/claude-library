# /claude-api スキルが Managed Agents を既定に

## 原文（日本語に翻訳）

`/claude-api` スキルは、エージェントループを自分でホストしたい場合を除き、既定で Managed Agents 上にエージェントを構築するようになりました。

## 原文（英語）

Changed the `/claude-api` skill to build agents on Managed Agents by default, unless you want to host the agent loop yourself

## 概要

v2.1.326 で `/claude-api` スキルの既定のエージェント構築方針が変わり、Managed Agents を使うようになりました。自前でループを管理したい場合は、その旨を伝えれば従来型の構成になります。

## 基本的な使い方

```text
/claude-api Slack の問い合わせに答えるエージェントを作りたい
```

## 実践例

### Managed Agents で構築する

特に指定しなければ Managed Agents ベースのコードが提案されます。

### 自前でエージェントループをホストする

```text
/claude-api エージェントループは自分でホストしたい。Tool Runner を使って実装して
```

## 注意点

- 既存プロジェクトの構成方針と合うか、提案内容を確認してください。
