## 原文（日本語訳）
スケジュール実行および「Run now」で実行されたルーチンの挙動を変更：編集可能なArtifactについては、確認を求めずにデータを保存し、そのページを再公開するようになりました。ただし、公開範囲が公開（public）のArtifact、初回公開、削除については引き続き確認を求めます

## 原文（英語）
Changed scheduled and Run now routine runs to save data to, and republish the page of, an artifact you can edit without asking; public artifacts, first publishes and deletes still ask

## 概要
スケジュール実行や「Run now」で自動実行されるルーチンが、編集権限のあるArtifactを更新する場面がありますが、これまでは毎回確認プロンプトが表示され、自動実行の妨げになることがありました。今回の変更で、編集可能なArtifactへのデータ保存とページの再公開については確認なしで自動的に行われるようになります。一方で、公開範囲がpublicのArtifact、初回の公開、削除操作については、引き続き安全のため確認が求められます。

## 基本的な使い方
編集権限のあるArtifactを更新するスケジュールタスクやルーチンを設定するだけで、以降の自動実行時は確認なしで更新されます。

```
# スケジュール設定例（毎朝データを更新するルーチン）
「毎朝9時に最新の売上データを取得して、このダッシュボードArtifactを更新して」
# → 2回目以降の自動実行では、確認プロンプトなしでArtifactが更新・再公開される
```

## 実践例

### 毎日自動更新されるレポートダッシュボード
```
# スケジュールルーチンが日次で実行され、
# 既存の（編集可能な）ダッシュボードArtifactにデータを反映
# → 確認なしで自動的に保存・再公開される
```

### Run nowで手動トリガーした更新
```
# ルーチンを「Run now」で即時実行
# → 編集可能なArtifactの更新は確認なしで行われるが、
#   新規Artifactの初回公開や削除操作は引き続き確認が求められる
```

## 注意点
- 公開範囲がpublicのArtifactについては、引き続き確認が必要です。
- 新規にArtifactを初めて公開する場合や、Artifactを削除する場合も確認が求められます。
- 自動化フローを組む際は、意図しない上書きが起きないよう、対象のArtifactの編集権限・公開範囲を確認しておくことをおすすめします。
