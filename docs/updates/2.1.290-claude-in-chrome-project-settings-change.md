## 原文（日本語訳）

Claude in Chromeを、プロジェクトの設定ファイルから有効にできなくなった。`--chrome`、`/chrome`、またはユーザー設定を使う。

## 原文（英語）

Changed Claude in Chrome so that a project's settings files can no longer turn it on; use `--chrome`, `/chrome` or your user settings

## 概要

リポジトリに含まれる設定でブラウザ連携が勝手に有効になることを防ぐ、セキュリティ上の変更です。

## 基本的な使い方

```bash
claude --chrome
```

## 実践例

### 一時的に使う

起動時に `--chrome` を付けるか、セッション内で `/chrome` を実行します。

### 常時使う

ユーザー設定（`~/.claude/settings.json`）で有効化します。

## 注意点

- チーム共有の `.claude/settings.json` に書いていた場合は、ユーザー設定へ移してください。
