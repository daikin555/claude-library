# フォールバックモデル切替後のサブエージェントのモデル名誤認を修正

## 原文（日本語に翻訳）

- サブエージェントがフォールバックモデルに切り替わった後、Claudeがそのサブエージェントの作業に対して誤ったモデル名を述べる問題を修正

## 原文（英語）

- Fixed Claude naming the wrong model for a subagent's work after the subagent switched to a fallback model

## 概要

サブエージェントがフォールバックモデルへ切り替わった際、Claudeが元のモデル名で作業を説明してしまう問題の修正です。実際に使われたモデルが正しく伝わります。

## 基本的な使い方

特別な操作は不要です。サブエージェントの結果について「どのモデルが処理したか」を尋ねた際、正確な回答が得られます。

## 実践例

### 結果の監査

どのモデルが処理したかを記録・レポートする運用で、情報の信頼性が上がります。

## 注意点

- フォールバックはモデルの過負荷などで発生します。品質比較をする際は実際のモデルを確認してください。
