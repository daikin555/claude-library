## 原文（日本語訳）
新しい会話の開始直後の数秒間に尋ねられた `/btw` のサイド質問が、別セッションのサイド質問履歴を表示してしまうことがある不具合が修正されました。

## 原文（英語）
[VSCode] Fixed a `/btw` side question asked in a new conversation's first seconds occasionally showing another session's side-question history

## 概要
`/btw` はメインの会話フローを止めずに、ちょっとした質問（サイド質問）をClaudeに尋ねるための機能です。新しい会話を開始した直後の数秒間にこの `/btw` を使うと、まれに別のセッションのサイド質問履歴が誤って表示されてしまう不具合がありました。今回の修正により、新規会話開始直後でも正しく現在のセッションの履歴のみが表示されるようになりました。

## 基本的な使い方
```
/btw このファイルの目的は何ですか？
```

## 実践例

### 修正前の挙動
新しい会話を開始した直後の数秒以内に `/btw` を使ってサイド質問をすると、まれに別セッションで行ったサイド質問のやり取りが履歴として表示されてしまうことがありました。

### 修正後の挙動
同じタイミングで `/btw` を使っても、常に現在の会話に紐づいたサイド質問の履歴のみが正しく表示されるようになりました。

## 注意点
- この不具合は新規会話開始直後の狭いタイミングでのみ発生するものであり、通常の利用ではほとんど気づかれないレアケースでした。
- 修正はVSCode拡張機能に対するものです。
