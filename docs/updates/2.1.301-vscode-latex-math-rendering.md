# VS Code拡張でLaTeX数式のレンダリングに対応

## 原文（日本語に翻訳）

[VSCode] Claude の応答で LaTeX 数式をレンダリングできるようになりました。`$$` や複数行の `\[ … \]` ブロック、インラインの `$…$` と `\(…\)` に対応します。

## 原文（英語）

[VSCode] Added LaTeX math rendering in Claude's responses, including `$$` and multi-line `\[ … \]` blocks and inline `$…$` and `\(…\)` math

## 概要

VS Code拡張のチャットで、Claudeが出力した数式が整形されて表示されます。ブロック数式とインライン数式の両方に対応しています。

## 基本的な使い方

Claudeに数式を含む説明を依頼します。

```text
ソフトマックス関数の定義を数式で説明して
```

対応する記法:

- ブロック: `$$ ... $$`、`\[ ... \]`（複数行可）
- インライン: `$...$`、`\( ... \)`

## 実践例

### アルゴリズムの解説

```latex
$$
\sigma(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$
```

### 計算量の説明

インラインで $O(n \log n)$ のように書かれた計算量が読みやすく表示されます。

## 注意点

- 対象はVS Code拡張のチャット表示です。
- 通貨表記の `$` と数式の `$…$` の区別はレンダラーの判断に依存します。
