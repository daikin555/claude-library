# CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS で使用上限の解除を検知する

## 原文（日本語に翻訳）

- 無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が、リセット前に解除された使用上限に気付けるよう `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加

## 原文（英語）

- Added `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` so unattended retry mode (`CLAUDE_CODE_RETRY_WATCHDOG`) notices a usage limit that was lifted before its reset

## 概要

無人リトライモードでは使用上限に達するとリセットまで待機します。新しい環境変数 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を設定すると、ミリ秒間隔で上限を再確認し、リセット時刻より前に上限が解除された場合も再開できます。

## 基本的な使い方

```bash
export CLAUDE_CODE_RETRY_WATCHDOG=1
export CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS=300000  # 5分ごとに再確認
claude -p "長時間のタスク"
```

## 実践例

### 夜間バッチでの利用

上限の追加付与やプラン変更で上限が解除された場合に、リセット時刻を待たず処理を再開できます。

### CI／自動化ジョブ

短めの間隔にすると復帰が早くなりますが、再確認の頻度が増える点に留意してください。

## 注意点

- 値の単位はミリ秒です。
- `CLAUDE_CODE_RETRY_WATCHDOG` が有効な無人リトライモードでの動作に関する設定です。
