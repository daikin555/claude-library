# [Claude Tag] 管理画面の検索でClaude未参加の公開Slackチャンネルを表示

## 原文（日本語に翻訳）

- [Claude Tag] Claude Tag管理のAdd place検索に、Claudeが未参加の公開Slackチャンネルが含まれるようになり、管理者がそこから設定できる

## 原文（英語）

- [Claude Tag] Added public Slack channels Claude hasn't joined to the Claude Tag admin Add place search, so admins can set one up from there

## 概要

Claude Tag管理画面のAdd place検索で、Claudeがまだ参加していない公開チャンネルも候補に出るようになりました。

## 基本的な使い方

管理画面のAdd placeで、チャンネル名を検索して選択し設定します。

## 実践例

### 新チャンネルへの展開

Claudeを先にチャンネルへ招待しなくても、管理画面から設定を始められます。

## 注意点

- 対象は公開チャンネルです。
