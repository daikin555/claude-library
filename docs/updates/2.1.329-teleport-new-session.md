## 原文（日本語訳）

`/teleport` でクラウドセッションを選ぶと、開いている会話を置き換えず、`/clear` と同様に新しいセッションを開始するよう修正しました。元の会話は `/resume` で戻れます。

## 原文（英語）

Fixed picking a cloud session in `/teleport` replacing your open conversation: the pick now starts a new session, as `/clear` does, and `/resume` brings the old one back

## 概要

クラウドセッションを引き継ぐ際、手元の会話が上書きされて失われることがなくなりました。

## 基本的な使い方

```
/teleport
/resume
```

## 実践例

### 作業の持ち替え

ローカルの会話を保持したままクラウドセッションを引き継ぎ、必要なら `/resume` で元に戻します。

## 注意点

- 選択後は新しいセッションになるため、元の会話の文脈は引き継がれません。
