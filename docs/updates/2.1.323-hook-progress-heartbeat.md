## 原文（日本語訳）

`claude -p` とSDKセッションで、hookが長時間実行されている間、30秒ごとに進捗ハートビートを送るようにしました。Claude Desktopなどのホストがターンを停止と見なして終了させることがなくなります（該当ホストがこのバージョンを含んだ後）。

## 原文（英語）

Added a progress heartbeat every 30 seconds while hooks run long in `claude -p` and SDK sessions, so a host such as Claude Desktop won't end the turn as hung (once it includes this version)

## 概要

時間のかかるhookを実行している間、ホスト側からは出力がなく停止しているように見えることがありました。30秒ごとの進捗ハートビートにより、ホストは処理が続いていることを判断できます。

## 基本的な使い方

利用者側の設定は不要です。

```bash
claude -p "テストを実行して結果を要約して"
```

## 実践例

### 重い検証hook

`PreToolUse` や `Stop` で、ビルドやテストを走らせるhookを使っていても、ホストにタイムアウト扱いされにくくなります。

```json
{
  "hooks": {
    "Stop": [
      { "hooks": [{ "type": "command", "command": "npm test" }] }
    ]
  }
}
```

## 注意点

- Claude Desktopなどのホスト側が、このバージョンを取り込んでから効果が出ます
- hook自体のタイムアウト設定は別途有効です
