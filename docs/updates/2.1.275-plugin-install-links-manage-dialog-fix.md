## 原文（日本語訳）

[VSCode] リンクとして使用できないプラグイン名やマーケットプレイスアドレスに対して、プラグインインストールリンクが「Manage plugins」ダイアログを開いてしまう問題を修正しました。

## 原文（英語）

[VSCode] Fixed plugin install links opening the Manage plugins dialog for plugin names and marketplace addresses that can't be used in a link

## 概要

Claude Code拡張機能では、プラグイン名やマーケットプレイスのアドレスをクリックすることでインストールを開始できるリンク機能があります。しかし、リンクとして扱えない特殊な文字列（記号やフォーマットが不正なアドレスなど）が含まれる場合、期待したインストール処理ではなく「Manage plugins」ダイアログが誤って開いてしまう不具合がありました。今回の修正でこの挙動が是正され、該当するプラグイン名・アドレスでも正しく処理されるようになりました。

## 基本的な使い方

VSCode拡張のClaude Codeパネルで、プラグインのインストールリンク（例: `claude-code://plugins/install?name=...`のような内部リンク）をクリックするだけで、通常通りインストールフローが開始されます。

```
# コマンドパレットからも同様にプラグイン管理画面を開けます
> Claude Code: Manage Plugins
```

## 実践例

### 特殊文字を含むプラグイン名を扱うマーケットプレイスからのインストール

修正前は、プラグイン名に記号やスペースなどリンクとして解釈しづらい文字が含まれていると、意図したインストール処理が行われず「Manage plugins」ダイアログが代わりに開いてしまうことがありました。

```
修正前: プラグイン名 "my-plugin@v1.0" のリンクをクリック
  → Manage plugins ダイアログが開くだけでインストールされない

修正後: 同じリンクをクリック
  → 正しくインストールフローが開始される
```

### カスタムマーケットプレイスのアドレス形式への対応

社内やチーム独自のマーケットプレイスなど、標準的でないアドレス形式を使っている場合でも、リンクが正しく機能するようになりました。

## 注意点

- この修正はVSCode拡張機能限定の不具合対応です。
- 特殊文字を含むプラグイン名は引き続き避けることが推奨されます（可読性・互換性のため）。
- 拡張機能を最新版に更新することで修正が反映されます。
