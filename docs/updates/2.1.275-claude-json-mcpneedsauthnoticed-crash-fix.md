## 原文（日本語訳）

`~/.claude.json` に不正な形式の `mcpNeedsAuthNoticed` の値が保存されている場合に、起動時にクラッシュする不具合を修正しました。

## 原文（英語）

Fixed a crash at launch when `~/.claude.json` holds a malformed `mcpNeedsAuthNoticed` value

## 概要

`~/.claude.json` はClaude Codeのユーザー設定を保存するファイルで、MCP（Model Context Protocol）サーバーの認証通知状態を記録する `mcpNeedsAuthNoticed` というフィールドを含みます。何らかの理由でこの値が不正な形式になっている場合、Claude Codeの起動処理自体がクラッシュしてしまう不具合がありました。今回の修正により、この値が壊れていても正常に起動できるようになりました。

## 基本的な使い方

特別な操作は不要です。通常どおり `claude` コマンドで起動できます。

```bash
claude
```

## 実践例

### 設定ファイルが手動編集や外部ツールで壊れた場合

`~/.claude.json` を手動で編集したり、別のツールが誤ってこのファイルを書き換えたりした結果、`mcpNeedsAuthNoticed` の値が期待される形式（オブジェクトや配列など）と異なる状態になることがあります。修正前はこの状態でClaude Codeを起動しようとするとクラッシュしていましたが、修正後は不正な値を無視して正常に起動します。

```bash
# 修正前: 不正な mcpNeedsAuthNoticed があると起動時にクラッシュ
claude

# 修正後: 不正な値があっても正常に起動する
claude
```

## 注意点

- この修正は起動時のクラッシュを防ぐものであり、不正な値自体を自動的に修復するわけではありません。MCPサーバーの認証通知が期待通りに表示されない場合は、`~/.claude.json` の該当フィールドを確認・削除することも検討してください。
- 設定ファイルを直接編集する場合は、事前にバックアップを取ることを推奨します。
