## 原文（日本語訳）

[VSCode] セッション一覧に表示される日時が、ウィンドウのリロードなどでセッションを最後に再度開いた時刻を表示してしまい、最後にメッセージが送信された時刻ではなかった問題を修正しました。

## 原文（英語）

[VSCode] Fixed the session list showing when a session was last reopened, such as after a window reload, instead of when its last message was sent

## 概要

セッション一覧では、各セッションの最終更新時刻を確認して作業の履歴を追うことができます。しかし、ウィンドウのリロードなどでセッションを開き直しただけの場合でも、その「開いた時刻」が表示されてしまい、実際に最後にメッセージをやり取りした時刻とは異なる誤った情報が表示される不具合がありました。今回の修正により、セッション一覧には常に最後にメッセージが送信された時刻が正しく表示されるようになります。

## 基本的な使い方

Claude Codeパネルのセッション一覧を開くと、各セッションの最終更新日時が自動的に表示されます。

```
> Claude Code: Show Session History
```

## 実践例

### ウィンドウをリロードしただけのセッションの表示確認

VSCodeを一度閉じて再度開いた際、そのセッションで何もメッセージを送っていないにもかかわらず、一覧上の時刻が更新されてしまうケースです。

```
修正前: 最後のメッセージは昨日 → ウィンドウをリロード → 一覧表示は「たった今」（誤り）
修正後: 最後のメッセージは昨日 → ウィンドウをリロード → 一覧表示は「昨日」のまま（正しい）
```

### 複数セッションを時系列順に整理する場合

多数のセッションを最終更新時刻順に並べて管理している場合、この修正により実際の作業履歴に基づいた正確な並び順が維持されます。

## 注意点

- この修正は表示ロジックのみに関するものです。
- 過去に誤って記録された表示時刻は、修正版へのアップデート後、次回のメッセージ送信以降で正しい値に更新されます。
