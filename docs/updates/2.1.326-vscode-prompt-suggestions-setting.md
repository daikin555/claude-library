# VS Code 拡張にプロンプト提案をオフにする設定を追加

## 原文（日本語に翻訳）

[VSCode] プロンプト提案をオフにする `claudeCode.promptSuggestions` 設定を追加しました。

## 原文（英語）

[VSCode] Added a `claudeCode.promptSuggestions` setting that turns prompt suggestions off

## 概要

VS Code 拡張で表示される次のプロンプトの提案を、設定でオフにできるようになりました。

## 基本的な使い方

```json
{
  "claudeCode.promptSuggestions": false
}
```

## 実践例

### 提案が邪魔なときにオフにする

`settings.json` に上記を追加すると、提案が表示されなくなります。

### ワークスペース単位で切り替える

`.vscode/settings.json` に書くことで、プロジェクトごとに設定できます。

## 注意点

- 設定の型や既定値は拡張機能の設定画面で確認してください。
