## 原文（日本語訳）
- claude.aiのログインが終了し、`ant auth login` のサインインでClaude Codeが継続する場合に、警告を追加しました。使用量はClaude Consoleの組織に請求されます。
- `ant auth login` のサインインを使う場合、起動時に課金対象のClaude Console組織名を表示する行を追加しました。

## 原文（英語）
- Added a warning when your claude.ai login ends and Claude Code continues on the sign-in from `ant auth login`, which bills usage to your Claude Console organization
- Added a line at startup naming the Claude Console organization that is billed in a case where Claude Code uses the sign-in from `ant auth login`

## 概要
意図せずConsole組織のAPI課金で動いてしまう事態を防ぐため、課金先を明示する警告と起動時表示が追加されました。

## 基本的な使い方
特別な操作は不要です。該当状況で起動すると、課金先の組織名が表示されます。

## 実践例

### 課金先の切り替わりに気づく
claude.aiのログインが切れて警告が出たら、再ログインして意図した課金先に戻せます。

### 複数組織の利用者
起動時の組織名で、どの組織に請求されるかを毎回確認できます。

## 注意点
- 警告が出たら、必要に応じて `/login` で再認証してください。
