## 原文（日本語訳）

tmux内（iTermのtmux統合）でターミナルのタブタイトルがちらついてジャンプする問題を修正しました。960ミリ秒ごとにアニメーションのようにタイトルを書き換えるのではなく、テキストが変化したときだけ書き込むようになりました。

## 原文（英語）

Fixed terminal tab titles jumping in tmux (iTerm tmux integration): the title is now written only when its text changes instead of animating every 960ms

## 概要

Claude Codeは実行中の状態（スピナーのアニメーションなど）に合わせて、ターミナルのタブタイトルを定期的に更新する仕組みを持っています。これまではiTermのtmux統合を使っている環境で、タイトルの中身が変わっていなくても960ミリ秒ごとに書き込みが発生しており、その結果タブのタイトルが不必要にちらついたり、位置がジャンプしたりして見えることがありました。今回の修正により、タイトルのテキストが実際に変化したときだけ書き込みが行われるようになり、無用な再描画がなくなりました。

## 基本的な使い方

この修正はユーザーが操作を変える必要のない、表示挙動の内部的な改善です。iTerm2でtmuxを使ってClaude Codeを実行している場合、特別な設定をしなくても自動的に恩恵を受けられます。

```
tmux new -s claude
claude
```

修正前は、上記のようにtmux内でClaude Codeを起動していると、処理中に表示されるタブタイトルが960ミリ秒間隔で常に書き換えられ、タイトルテキストが変わっていなくてもちらつきやジャンプが発生していました。修正後は、タイトルの内容が実際に変わったタイミングでのみ書き込まれるため、余計な視覚的なノイズがなくなります。

## 実践例

### iTerm2 + tmuxで複数セッションを並行して開いている場合

複数のペインやウィンドウでClaude Codeのtmuxセッションを並行して開いている開発者は、これまでタブバー上の複数のタイトルが同時にちらついて視認性が落ちることがありました。修正後は、実際に状態が変わったタブだけが更新されるため、タブバー全体が落ち着いて見えるようになります。

### 長時間の処理中にタブを目印として使う場合

Claude Codeが長時間の処理を実行している間、タブタイトルを見て進行状況や完了を確認する運用をしている場合、修正前はタイトルが絶えず微妙に動いて見え、変化を目で追いにくいことがありました。修正後はテキストが変わった瞬間だけタイトルが更新されるため、状態の変化に気づきやすくなります。

## 注意点

- この修正はiTermのtmux統合を利用している場合の挙動に関するものです。tmuxを使わない通常のターミナルタブの挙動には影響しません。
- タイトルが更新されるタイミング自体（スピナー状態や処理完了時など）は変わらず、書き込みの頻度が最適化されただけです。
