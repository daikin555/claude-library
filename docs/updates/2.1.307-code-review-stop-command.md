# Code Review に @claude review stop を追加

## 原文（日本語に翻訳）

- [Code Review] Code Review に `@claude review stop`（`off`、`pause` も可）を追加。新しいレビューを開始せずに、プルリクエストでの `@claude review always` の購読を終了できます

## 原文（英語）

- [Code Review] Added `@claude review stop` (also `off` and `pause`) to Code Review, ending an `@claude review always` subscription on a pull request without starting a new review

## 概要

`@claude review always` を設定したプルリクエストでは、プッシュのたびに自動レビューが走ります。新コマンドを使うと、新たなレビューを走らせることなくこの購読だけを解除できます。

## 基本的な使い方

プルリクエストのコメントに次のいずれかを投稿します。

```
@claude review stop
```

`@claude review off` や `@claude review pause` でも同じ動作です。

## 実践例

### レビュー完了後に自動レビューを止める

指摘への対応が終わったら `@claude review stop` で、以降のプッシュでの自動レビューを止めます。

### 大量のコミットを整理するとき

リベースや整形で何度もプッシュする前に停止しておくと、不要なレビューを避けられます。

## 注意点

- 再開したい場合は、あらためて `@claude review always` を投稿します。
