# [VSCode] ターミナルと同様のプロンプト提案を追加

## 原文（日本語に翻訳）

[VSCode] ターミナルが表示する場面と同じ場所で、プロンプト提案を追加しました。Tab で提案された次のプロンプトを受け入れられます。Claude Code の settings.json で `promptSuggestionEnabled: false` を設定するとオフにできます。

## 原文（英語）

[VSCode] Added prompt suggestions wherever the terminal shows them: Tab accepts the suggested next prompt; `promptSuggestionEnabled: false` in Claude Code's settings.json turns them off

## 概要

VS Code 拡張でも、次に入力しそうなプロンプトが提案され、Tab で採用できるようになりました。

## 基本的な使い方

Claude の応答後に提案が表示されたら、Tab を押して採用し、Enter で送信します。

## 実践例

### 提案を無効にする

```json
{
  "promptSuggestionEnabled": false
}
```

### 繰り返し作業の効率化

「テストを実行して」「コミットして」など、定型の次の操作を Tab で素早く入力できます。

## 注意点

- 自動実行はされません。Tab で採用して送信するまで何も起きません。
- 同バージョンでは、バックグラウンド／スケジュールタスクが8ターン連続した後、提案の更新頻度が下がります。
