# Windows: レジストリの管理設定による起動への影響に関する注意

## 原文（日本語に翻訳）

Windows: レジストリの管理設定での起動について変更しました。アップグレード前に確認してください。`HKLM` のポリシーは `managed-settings.json` より優先され、壊れた値があると起動できなくなることがあります。

## 原文（英語）

Windows: Changed start-up with managed settings in the registry: check them before upgrading, as an `HKLM` policy outranks `managed-settings.json` and a broken value can stop the start

## 概要

レジストリ経由の管理設定が優先され、不正な値は起動失敗の原因になります。なお同バージョンで、日本語などの非 ASCII 文字を含むレジストリ設定で起動できない問題（#93280）も修正されています。

## 基本的な使い方

```powershell
Get-ItemProperty "HKLM:\SOFTWARE\Policies\ClaudeCode"
```

## 実践例

### アップグレード前の確認

レジストリの値が有効な JSON かを確認し、`managed-settings.json` との優先関係を把握してからアップグレードします。

## 注意点

- レジストリのキー名やパスは環境により異なる場合があるため、公式ドキュメントで確認してください。
- `HKLM` が `managed-settings.json` より優先されます。
