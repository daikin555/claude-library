## 原文（日本語訳）

キューに入れたメッセージがまだキュー中であるにもかかわらずプロンプト履歴に再表示されてしまう問題、キュー済みメッセージ選択中にEscキーを押すとターン処理が中断されてしまう問題、そしてターンの途中で送信した際に `!` モードが解除されずに残り続けてしまう問題をそれぞれ修正しました。

## 原文（英語）

Fixed queued messages reappearing in the prompt history while still queued, Esc while selecting a queued message no longer interrupts the turn, and `!` mode no longer sticks after a mid-turn submit

## 概要

メッセージキュー機能とプロンプト履歴、`!` シェルモードに関連する3つの不具合をまとめて修正したものです。キュー中のメッセージが履歴に誤って現れる、キュー済みメッセージ選択中のEscキーが意図せずターンを中断させる、ターンの途中で送信した後に `!` モードが解除されないまま残ってしまう、といった問題がそれぞれ解消されています。

## 基本的な使い方

Claudeの応答処理中に複数のメッセージをキューに入れて、あとから編集・選択・送信するといった通常のワークフローが、より安定して動作するようになりました。

```
> [Claudeが応答処理中]
> こちらもお願いします  [Enterでキューに追加]
> こちらも  [Enterでキューに追加]
```

## 実践例

### キュー中のメッセージが履歴に混ざらない

修正前は、キューに入れてまだ送信されていないメッセージが、上矢印キーでたどれる入力履歴に重複して表示されてしまうことがありました。修正後はキュー中のメッセージは履歴に混在せず、送信済みのものだけが正しく履歴に残ります。

### キュー済みメッセージ選択中のEscでターンを中断しない

```
> [Claudeが処理中、キューにメッセージが複数ある]
> [矢印キーでキュー済みメッセージを選択中にEscを押す]
```

修正前: Escキーによって実行中のターンそのものが中断されてしまうことがありました
修正後: キュー済みメッセージの選択操作中のEscは選択解除のみに留まり、実行中のターンには影響しません（ターンを中断したい場合は改めてEsc操作を行う必要があります）

### ターン途中の送信後も`!`モードが残り続けない

```
> !ls
[Enterでシェルコマンドを実行、まだ処理中に別の内容を送信]
```

修正前: ターンの途中でメッセージを送信すると、`!` モードの状態が解除されずにその後の入力にも影響を及ぼすことがありました
修正後: ターン途中の送信後は `!` モードが正しくリセットされ、次の入力は通常のメッセージとして扱われます

## 注意点

- これらは主に入力操作の状態管理に関する修正で、メッセージの内容自体やモデルへの送信結果には影響しません
- Escキーの挙動が変わったため、「キュー選択解除」と「ターン中断」を区別して操作する必要があります
