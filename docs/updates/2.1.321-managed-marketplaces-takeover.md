# 管理対象 extraKnownMarketplaces の乗っ取り防止と復元コマンド

## 原文（日本語に翻訳）

- 管理対象の `extraKnownMarketplaces` の挙動を変更：宣言された名前は別のソースから追加できず、別の場所からのエントリは非表示になり、宣言されたマーケットプレイスが一覧に含むプラグインはそこから再インストールされる
- 宣言されていないソースによる管理対象 `extraKnownMarketplaces` の乗っ取り時、保存済みデータは `cleanupPeriodDays` の間、オプションとシークレットは `claude plugin restore-set-aside` を実行するまで退避される

## 原文（英語）

- Changed managed `extraKnownMarketplaces`: a declared name can't be added from another source, an entry from elsewhere is hidden, and plugins the declared marketplace lists are reinstalled from it
- Changed managed `extraKnownMarketplaces` take-overs from an undeclared source: saved data is set aside for `cleanupPeriodDays`, and options and secrets until `claude plugin restore-set-aside`

## 概要

組織が管理設定で宣言したマーケットプレイス名を、別のソースが名乗って差し替えることを防ぎます。乗っ取られたデータは削除されずに退避され、必要なら復元できます。

## 基本的な使い方

```bash
claude plugin restore-set-aside
```

## 実践例

### 管理設定での宣言

```json
{
  "extraKnownMarketplaces": {
    "company-tools": {
      "source": { "source": "github", "repo": "example-org/claude-plugins" }
    }
  }
}
```

宣言済みの `company-tools` と同名のマーケットプレイスを、個人が別ソースから追加することはできません。

### 退避されたデータの復元

退避されたオプションやシークレットを戻したい場合に `claude plugin restore-set-aside` を使います。

## 注意点

- 保存済みデータの退避期間は `cleanupPeriodDays` に従います。
- オプションとシークレットは、復元コマンドを実行するまで保持されます。
- 宣言されたマーケットプレイスのプラグインは、そこから再インストールされます。
