# GrepとGlobが検索失敗を「該当なし」と誤報する問題を修正

## 原文（日本語に翻訳）

検索プログラムが結果を返す前に予期せず失敗した場合に、Grep と Glob が「一致なし」と報告する問題を修正しました。検索に失敗した旨のエラーを返すようになります。

## 原文（英語）

Fixed Grep and Glob reporting no matches when the search program failed unexpectedly before returning any results; they now return an error saying the search failed

## 概要

検索の実行自体が失敗した場合でも「一致なし」と表示され、Claudeが「該当コードは存在しない」と誤判断する恐れがありました。修正後は失敗がエラーとして明示されます。

## 基本的な使い方

特別な操作は不要です。検索が失敗するとエラーメッセージが返ります。

## 実践例

### 誤った結論の防止

「見つからない」と「検索できなかった」が区別されるため、Claudeが誤って「存在しない」と判断することを避けられます。

### 原因の切り分け

エラーが出たら、検索ツールの導入状況や権限、環境を確認できます。

## 注意点

- 本当に一致がない場合は、従来どおり「一致なし」となります。
- エラーが続く場合は `claude doctor` などで環境を確認してください。
