## 原文（日本語に翻訳）

オートコンパクトを変更し、未認識のモデルIDのセッションでは、想定されたコンテキストウィンドウを超えて伸び続けるのではなく、その範囲内に収まるようにした。以前の挙動に戻すには `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` を設定する。

## 原文（英語）

Changed auto-compact to keep sessions on unrecognized model IDs within the assumed context window instead of letting them grow past it; set `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` to restore the previous behavior

## 概要

Claude Codeは、Amazon Bedrock・Google Cloud's Agent Platform・Microsoft Foundryなどのサードパーティプロバイダーや、独自のLLMゲートウェイ（`ANTHROPIC_BASE_URL`）を利用する構成において、モデルIDがClaude Codeにとって未知（未認識）のものになるケースがあります。これまでは、そうした未認識のモデルIDのセッションでは、オートコンパクト（自動要約）が想定コンテキストウィンドウを超えてもそのまま会話を伸ばし続けてしまうことがありました。今回の変更により、未認識のモデルIDであっても、Claude Codeが想定するコンテキストウィンドウの範囲内に収まるようオートコンパクトが働くようになり、想定外の肥大化や、それに伴うエラー・品質劣化のリスクが抑えられます。以前の挙動（強制なし）に戻したい場合は、`CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` を設定します。

## 基本的な使い方

通常はこの変更を意識する必要はなく、未知のモデルIDで動かしていても自動的に想定ウィンドウ内へ収まるようにオートコンパクトが働きます。

```bash
# カスタムのモデルIDでセッションを開始（例）
export ANTHROPIC_MODEL="my-custom-claude-deployment"
claude
```

以前の挙動（ウィンドウ超過を許容する）に戻したい場合は、以下の環境変数を設定します。

```bash
export CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1
claude
```

## 実践例

### サードパーティプロバイダーでカスタムモデルIDを使う場合

Amazon BedrockやGoogle Cloud's Agent Platformなどで、`modelOverrides` や独自のデプロイ名を使ってモデルを指定していると、Claude CodeがそのモデルIDを認識できないことがあります。この変更により、そうした構成でも想定コンテキストウィンドウを超えないようオートコンパクトが自動的に働きます。

```json
{
  "modelOverrides": {
    "claude-opus-4-7": "arn:aws:bedrock:us-east-2:123456789012:application-inference-profile/opus-prod"
  }
}
```

### LLMゲートウェイ経由での利用

`ANTHROPIC_BASE_URL` で独自のLLMゲートウェイを指している場合、Claude Codeがモデルの正式なコンテキストウィンドウを検証できないことがあります。今回の変更により、そうした未認識モデルのセッションでも、想定ウィンドウを超えて肥大化する前にオートコンパクトが機能するため、長時間のセッションでも安定して動作しやすくなります。

```bash
export ANTHROPIC_BASE_URL="https://your-llm-gateway.example.com"
claude
```

### 意図的に強制を無効化したい場合

自社の運用でモデルの実際のコンテキストウィンドウがClaude Codeの想定より大きいことが分かっている、あるいは以前の挙動に依存した運用をしている場合は、強制を無効化できます。

```bash
export CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1
claude
```

無効化すると、未認識のモデルIDのセッションはオートコンパクトによる強制を受けず、コンテキストが想定ウィンドウを超えて伸び続ける可能性がある点に注意してください。

## 注意点

- 「想定コンテキストウィンドウ」は、Claude Codeがモデルの種別やIDのパターンから推測する値であり、実際のモデルの上限と一致しない場合があります。
- `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` を設定すると、未認識モデルでのウィンドウ超過を許容する以前の挙動に戻り、コンテキスト超過によるエラーのリスクが再び生じます。
- モデルの機能（effortレベルや拡張思考など）を正しく認識させたい場合は、`ANTHROPIC_DEFAULT_OPUS_MODEL_SUPPORTED_CAPABILITIES` のような capabilities 系の環境変数もあわせて設定すると、コンテキストウィンドウ以外の挙動も安定します。
- 本記事作成時点で、「想定コンテキストウィンドウ」の具体的なデフォルト値や判定ロジックについての詳細な公式ドキュメントの記載は見当たらなかったため、changelogの記述内容をもとに推測を交えて記述しています。
