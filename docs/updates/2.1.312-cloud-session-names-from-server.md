## 原文（日本語訳）

CLIから開始したクラウドセッションの名前とブランチ名を、サーバー側から取得するよう変更しました

## 原文（英語）

Changed cloud sessions started from the CLI to get their names and branch names from the server

## 概要

CLIから作成したクラウドセッションの名前とブランチ名がサーバー側で決まるようになりました。

## 基本的な使い方

CLIからクラウドセッションを開始するだけで、名前とブランチ名が付きます。

## 実践例

### ブランチの確認

作成されたブランチ名はGit側で確認してからマージ作業を行います。

## 注意点

- 名前やブランチ名の形式はサーバー側に依存するため、自動化で固定の形式を前提にしないでください。
