## 原文（日本語訳）

frontmatterの `name` に既に `<plugin>:` プレフィックスが含まれているプラグインスキルが、スラッシュメニューで名前が二重に表示される不具合（例: `/plugin:plugin:skill`）を修正しました。

## 原文（英語）

Fixed plugin skills whose frontmatter `name` already includes the `<plugin>:` prefix showing it doubled in the slash menu (e.g. `/plugin:plugin:skill`)

## 概要

プラグインが提供するスキルは、スラッシュメニュー上で `<plugin-name>:<skill-name>` の形式で表示されます。この際、スキルのSKILL.mdのfrontmatterの `name` フィールドに既に `<plugin>:` というプレフィックスが書かれていた場合、Claude Codeが表示用のプレフィックスをさらに付け足してしまい、`/plugin:plugin:skill` のように名前が重複して表示される不具合がありました。今回の修正で、`name` に既にプレフィックスが含まれている場合はそれを検知し、二重に付与しないようになりました。

## 基本的な使い方

この修正はプラグイン開発者・利用者の双方に自動的に適用され、特別な操作は不要です。以下のようなSKILL.mdを持つプラグインスキルがあった場合の挙動が変わります。

```yaml
---
name: my-plugin:my-skill
description: サンプルスキル
---
```

修正前は `/my-plugin:my-plugin:my-skill` のように表示されていましたが、修正後は正しく `/my-plugin:my-skill` と表示されます。

## 実践例

### プラグイン開発時のスキル命名を気にせず済む

プラグイン開発者がSKILL.mdのfrontmatterに `name: <plugin>:<skill>` の形式で書いていても、書いていなくても、スラッシュメニューには常に正しい形式で1回だけプレフィックスが表示されるようになりました。既存のプラグインの命名規則を書き換える必要はありません。

### 複数プラグインを導入している環境での視認性向上

多数のプラグインをインストールしている場合、スラッシュメニューの一覧がすっきりと見やすくなり、目的のスキルを探しやすくなります。

### `/plugin` コマンドでのスキル確認

`/plugin` でインストール済みプラグインの詳細を確認する際にも、スキル名が正しい形式で表示されるようになります。

## 注意点

- この修正はプラグインが提供するスキルの表示のみに関するもので、スキルの動作自体には影響しません
- 古いバージョンで作成されたプラグインスキルであっても、SKILL.mdを変更せずにこの修正の恩恵を受けられます
