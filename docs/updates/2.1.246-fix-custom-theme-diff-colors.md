## 原文（日本語訳）

カスタムテーマで定義した diff の色（`diffAdded` / `diffRemoved` およびそれらの薄い（dimmed）バリアント）が、実際の diff 表示や `/theme` のプレビューで無視されてしまう不具合を修正しました。

## 原文（英語）

Fixed custom theme diff colors (`diffAdded`/`diffRemoved` and their dimmed variants) being ignored in diffs and the `/theme` preview

## 概要

Claude Codeのカスタムテーマでは、追加行・削除行の色を `diffAdded` / `diffRemoved`、およびそれぞれの薄い表示用バリアントとして個別に指定できます。しかし、これまではこれらの設定値が実際のファイル差分表示や `/theme` コマンドのプレビュー画面で反映されず、常にデフォルトの色が使われてしまう不具合がありました。今回の修正で、カスタムテーマに指定した diff の色が実際の表示にもプレビューにも正しく反映されるようになりました。

## 基本的な使い方

カスタムテーマの設定ファイルで diff の色を指定すると、それが実際の差分表示に反映されます。

```json
{
  "diffAdded": "#3fb950",
  "diffRemoved": "#f85149",
  "diffAddedDimmed": "#2ea043",
  "diffRemovedDimmed": "#da3633"
}
```

修正前はこれらの値を設定してもデフォルトの緑・赤が使われていましたが、修正後は指定した色でdiffが表示されます。

## 実践例

### 独自のカラースキームでdiffを見やすくする

コントラストや色覚特性に配慮した独自のdiff配色を設定しているユーザーが、実際にその配色でファイル差分を確認できるようになります。

### `/theme` プレビューでの事前確認

`/theme` コマンドでテーマを切り替える際のプレビュー画面でも、diffの色が正しく反映されるようになったため、実際の見た目を切り替え前に確認できます。

```
/theme
```

### チームで統一したカスタムテーマを配布する場合

チーム共通のカスタムテーマ設定を配布している場合、diffの配色も含めて意図した通りに全メンバーの環境で表示されるようになります。

## 注意点

- この修正は `diffAdded` / `diffRemoved` とその薄いバリアントに関するものです。他のカスタムテーマ項目（構文ハイライトなど）は別の設定項目で管理されています
- テーマ設定ファイルの形式やキー名に誤りがある場合、値が反映されないことがあるため、設定後は `/theme` プレビューで確認することを推奨します
