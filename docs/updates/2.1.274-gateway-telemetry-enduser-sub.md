## 原文（日本語訳）

Claude DesktopやCoworkがClaude appsゲートウェイ経由で送信するテレメトリに、IdP（アイデンティティプロバイダー）のサブジェクトである `enduser.sub` を追加しました。

## 原文（英語）

Added `enduser.sub`, the IdP subject, to the telemetry Claude Desktop and Cowork send through a Claude apps gateway

## 概要

企業環境ではClaude DesktopやCoworkがClaude appsゲートウェイを経由してテレメトリを送信しますが、これまではどのユーザーによる利用かをIdP側の識別子と紐づけて追跡することが困難でした。今回の変更で、テレメトリに `enduser.sub`（IdPのサブジェクトクレーム）が含まれるようになり、組織はSSO/IdPのユーザー識別子ベースで利用状況を分析・監査できるようになりました。

## 基本的な使い方

Claude appsゲートウェイを経由してClaude DesktopやCoworkを利用している環境では、追加の設定なしに、送信されるテレメトリイベントへ自動的に `enduser.sub` 属性が付与されます。

```
enduser.sub = "user-idp-subject-id"
```

## 実践例

### ユーザー単位の利用状況分析

IT部門は、収集したテレメトリを `enduser.sub` でグルーピングすることで、IdP上のユーザーアカウントごとにClaude DesktopやCoworkの利用状況（リクエスト数、モデル使用量など）を分析できます。

### 監査ログとの突合

セキュリティチームは、`enduser.sub` をキーにしてテレメトリログと社内のIdP監査ログを突合し、特定ユーザーの利用履歴をより正確にトレースできます。

## 注意点

- この属性はClaude appsゲートウェイを経由する構成（Claude Desktop / Cowork）に限定された機能で、通常のCLI利用のテレメトリには適用されません。
- `enduser.sub` にはユーザーを一意に識別する情報が含まれるため、収集・保管にあたっては社内のプライバシーポリシーに従う必要があります。
