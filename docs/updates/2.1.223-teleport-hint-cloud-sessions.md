## 原文（日本語に翻訳）

クラウドセッション内に `/teleport` のヒントが追加され、`claude --teleport <session id>` でローカルに作業を続ける方法が表示されるようになった。

## 原文（英語）

Added a `/teleport` hint in cloud sessions showing how to continue locally with `claude --teleport <session id>`

## 概要

Claude Code on the web（claude.ai/code）で動くクラウドセッションと、手元のターミナルは `--teleport` によって行き来できます。ターミナル側から `claude --teleport` または `claude --teleport <session-id>` を実行する、あるいはターミナルセッション内で `/teleport`（エイリアス `/tp`）を実行することで、クラウドセッションの会話履歴とブランチをローカルに引き込んで作業を継続できます。今回のアップデートでは、クラウドセッション（Webやモバイルアプリ）の側に、そのセッションをローカルで続けるための `claude --teleport <session id>` コマンドを示すヒントが表示されるようになり、ユーザーがクラウドで開始した作業をターミナルに移す方法を発見しやすくなりました。

## 基本的な使い方

クラウドセッションを開くと、そのセッションIDを使ってローカルに引き込む方法がヒントとして表示されます。表示されたコマンドをそのままターミナルにコピー&ペーストすれば、ローカルでの作業再開が始まります。

```bash
claude --teleport <session id>
```

セッションIDを指定せずに `claude --teleport` だけを実行すると、インタラクティブなセッションピッカーが開き、一覧から選択できます。

```bash
claude --teleport
```

すでにターミナルでClaude Codeを起動している場合は、コマンドを再起動せずに `/teleport`（または `/tp`）を使うこともできます。

```text
/teleport
```

## 実践例

### 外出先でモバイルアプリから作業を始め、帰社後にPCで続ける

移動中にモバイルアプリやWebでクラウドセッションを開始してタスクを進めておき、オフィスに戻ってから今回追加されたヒントに表示されている `claude --teleport <session id>` をターミナルにコピー&ペーストして続きの作業をローカルで行います。

```bash
claude --teleport 1234abcd-session-id
```

### 「ローカルで計画、クラウドで実行」を経てクラウド側の成果をローカルに戻す

まずローカルでplanモードを使って方針を固め、`claude --cloud` でクラウドセッションに作業を投げて自動実行させます。

```bash
claude --permission-mode plan
```

```bash
claude --cloud "docs/migration-plan.mdに書かれたマイグレーションを実行して"
```

クラウド側の実行が完了したら、Web/モバイルに表示されるteleportヒントのコマンドをコピーしてターミナルで実行し、diffの確認やコミット・PR作成などの仕上げをローカルで行います。

```bash
claude --teleport <session id>
```

### `/tasks` やWeb側のセッション一覧から続きをローカルで行う

複数のクラウドセッションを並行して走らせている場合、`/tasks` でバックグラウンドセッションの一覧を確認し、対象を選んで `t` キーでteleportすることもできますが、Webのセッション画面に表示される `claude --teleport <session id>` のヒントをそのままコピーする方が、セッションIDを手動で調べる手間がなく簡単です。

## 注意点

- teleportは「クラウド→ローカル」の一方向の機能です。すでに進めたローカルセッションをそのままクラウドへ送ることはできません（ローカルの作業をクラウドに送りたい場合は `claude --cloud` で新規クラウドセッションを作成します）。
- teleportを実行するには、作業ディレクトリがuncommittedな変更のないクリーンなgit状態であること、クラウドセッションと同じリポジトリのチェックアウトであること、クラウドセッションのブランチがリモートにpushされていること、クラウドセッションと同じclaude.aiアカウントで認証されていることが必要です。条件を満たさない場合はエラーになるか、変更のstashを促されます。
- `--teleport` はclaude.aiのサブスクリプション認証が必要です。APIキー認証の場合は利用できず、`/login` でclaude.aiアカウントにログインし直す必要があります。Amazon Bedrock・Google CloudのAgent Platform・Microsoft Foundry経由の場合はクラウドセッション自体が利用できません。
- teleport後、ターミナル側のセッションはクラウドセッションとは独立したコピーになります。ターミナルで行った新しい作業はローカルにとどまり、Web/モバイルのクラウドセッションには反映されません。
