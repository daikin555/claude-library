## 原文（日本語訳）

`/artifacts` を改善しました。タイトルが1列に整列し、詳細が単語の途中で切れることなく丸ごと省略されるようになり、一覧はPgUp/PgDn、Home/End、マウスホイール、クリックに対応しました。

## 原文（英語）

Improved `/artifacts`: titles line up in one column, details are dropped whole instead of cut mid-word, and the list supports PgUp/PgDn, Home/End, the mouse wheel and clicks

## 概要

`/artifacts` コマンドで表示されるアーティファクト一覧のUIが複数の点で改善されました。各アーティファクトのタイトルがきれいに1列に整列して読みやすくなり、表示しきれない詳細情報は単語の途中で不自然に切れるのではなく、単語単位で丸ごと省略されるようになりました。さらに、PgUp/PgDnキーやHome/Endキーによるナビゲーション、マウスホイールでのスクロール、クリックによる選択にも対応し、キーボード操作・マウス操作の両方で快適に一覧を扱えるようになりました。

## 基本的な使い方

```
/artifacts
```

一覧が表示されたら、キーボードの矢印キーに加えて以下の操作が可能です。

- `PgUp` / `PgDn`: ページ単位でのスクロール
- `Home` / `End`: 一覧の先頭・末尾へ移動
- マウスホイール: スクロール
- クリック: 項目の選択

## 実践例

### 大量のアーティファクトを管理するプロジェクト

多数のダッシュボードやレポートをアーティファクトとして公開・管理しているプロジェクトで、`Home`/`End` や `PgUp`/`PgDn` を使って目的のアーティファクトに素早くアクセスできます。

### マウス操作を好むユーザーの操作性向上

キーボードショートカットを覚えなくても、マウスホイールでのスクロールやクリックでの選択だけで一覧を直感的に操作できるようになりました。

## 注意点

- これはUI・操作性の改善であり、アーティファクトの公開・共有機能自体に変更はありません
- ターミナル環境によってはマウスイベントのサポート状況が異なる場合があります
