## 原文（日本語訳）
自己ペースの `/loop` は、再スケジュールせずにターンが終わった場合、フォールバックの起床を設定せずに終了するようになりました。従来の動作を維持するには `CLAUDE_CODE_LOOP_KEEPALIVE=1` を設定します。

## 原文（英語）
Changed self-paced `/loop` to end when a turn finishes without rescheduling, instead of scheduling a fallback wakeup; set `CLAUDE_CODE_LOOP_KEEPALIVE=1` to keep the old behavior

## 概要
間隔を指定しない `/loop` では、Claudeが次の実行を予約しないままターンを終えると、ループがそのまま終了します。以前は保険の起床が自動で入っていました。

## 基本的な使い方
```
/loop デプロイ状況を確認して
```
従来動作に戻す場合：
```bash
export CLAUDE_CODE_LOOP_KEEPALIVE=1
```

## 実践例

### 完了したら自然に終わる監視
目的達成後に不要な起床が続かず、ループが終了します。

### 常に見張り続けたい場合
`CLAUDE_CODE_LOOP_KEEPALIVE=1` を設定して従来どおり動かします。

## 注意点
- クラウドセッションの `/loop` 確認には、タイマーがコンテナとともに停止する旨の注記も追加されました。
