# 使用制限バナーに「Get more usage」リンクを追加（VS Code/JetBrains）

## 原文（日本語に翻訳）

[VSCode] VS Code と JetBrains のパネルで、Pro および Max プランの使用制限バナーに「Get more usage」リンクを追加しました。

## 原文（英語）

[VSCode] Added a "Get more usage" link to the usage-limit banner for Pro and Max plans in the VS Code and JetBrains panels

## 概要

使用制限に達したときのバナーから、追加の利用枠を得る手続きへ直接進めるようになりました。対象はProおよびMaxプランです。

## 基本的な使い方

使用制限に達するとパネルにバナーが表示されます。そこにある「Get more usage」リンクをクリックします。

## 実践例

### 作業中に制限へ達した場合

エディタを離れて設定ページを探す手間なく、リンクから対応を選べます。

### チームでの案内

制限到達時にどこから対応するかを共有する際、バナーのリンクを案内できます。

## 注意点

- Pro / Maxプランのみで表示されます。
- 無人実行での待機制御には `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` も利用できます。
