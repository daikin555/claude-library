# Bedrock ガードレール向け guardrail.input_tagging

## 原文（日本語訳）

- Claude apps gateway の Bedrock アップストリームに `guardrail.input_tagging` を追加：Amazon Bedrock ガードレールのプロンプト攻撃フィルターが必要とする入力タグでプロンプトをラップする。`all_messages_and_system` ではシステムプロンプトもタグ付けする

## 原文（英語）

- Added `guardrail.input_tagging` on Claude apps gateway Bedrock upstreams, which wraps prompts in the input tags that an Amazon Bedrock guardrail's prompt attacks filter needs; `all_messages_and_system` also tags the system prompt

## 概要

Bedrock ガードレールのプロンプト攻撃フィルターは入力タグを必要とします。この設定により、gateway がプロンプトを自動的にタグで囲みます。

## 基本的な使い方

```yaml
guardrail:
  input_tagging: all_messages_and_system
```

## 実践例

### プロンプト攻撃フィルターを有効にする

ガードレール側でフィルターを有効にした Bedrock アップストリームで、システムプロンプトまでタグ付けしたい場合に `all_messages_and_system` を使います。

## 注意点

- 他に指定可能な値は公式ドキュメントで確認してください。
