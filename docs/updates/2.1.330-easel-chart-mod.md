# 組み込み mod「easel」でチャートを自動描画

## 原文（日本語に翻訳）

依頼に応じてチャートを描画し、MCP のメトリクス結果の下にも表示する組み込み mod「easel」を追加しました。macOS と Linux の Pro、Max、および利用可能な場合は Team と Enterprise で使えます。自動チャートは `/config` でオフにできます。

## 原文（英語）

Added easel, a built-in mod that draws charts when asked and under MCP metrics results, on Pro, Max and, where available, Team and Enterprise on macOS and Linux; turn automatic charts off in `/config`

## 概要

easel は Claude Code に組み込まれた mod で、チャートを頼むとグラフを描画します。MCP ツールがメトリクスを返した場合も、その結果の下にチャートを表示します。

## 基本的な使い方

```text
> 直近 7 日のエラー率を折れ線グラフにして
```

## 実践例

### MCP メトリクスの可視化

監視系 MCP サーバーの結果が返ると、その下に自動でチャートが表示されます。

### 自動チャートの無効化

`/config` を開き、自動チャートの設定をオフにします。

## 注意点

- macOS と Linux のみ、対象プランは Pro / Max、および提供されている場合の Team / Enterprise です
- MCP の許可・拒否リストで easel を除外している場合、チャートツールはブロックされたままです（2.1.330 で毎回の起動時警告は修正）
- Code Mode で呼び出した際に失敗する問題も修正されています
