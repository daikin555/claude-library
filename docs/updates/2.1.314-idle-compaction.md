# アイドル時の自動コンパクション（Idle compaction）

## 原文（日本語訳）

VS Code と Claude Desktop の Code タブにアイドルコンパクションを追加しました。200K トークン以上の会話が放置されると要約され、プロンプトキャッシュが期限切れの場合は次のメッセージでその要約が使われます。

アイドルコンパクションは、テレメトリーを無効にしている購読者や、1 時間プロンプトキャッシュが有効な Bedrock・Vertex・Foundry・LLM ゲートウェイでも実行されるよう変更しました。

## 原文（英語）

Added idle compaction to VS Code and Claude Desktop's Code tab: a 200K+ token conversation left idle is summarized, and the summary is used on your next message if the prompt cache has expired

Changed idle compaction to also run for subscribers with telemetry turned off, and on Bedrock, Vertex, Foundry and LLM gateways once the one-hour prompt cache is on

## 概要

長い会話を放置してプロンプトキャッシュが切れると、再開時に巨大なコンテキスト全体を再処理するためコストと遅延が増えます。アイドルコンパクションは放置中に会話を要約しておき、キャッシュ切れ後の最初のメッセージでその要約を使うことでこれを軽減します。

## 基本的な使い方

特別な操作は不要です。VS Code 拡張機能または Claude Desktop の Code タブで、200K トークン超の会話をしばらく放置すると自動的に動作します。

## 実践例

### 昼休みを挟む長時間セッション

大規模リファクタリング中に離席して戻っても、要約済みのコンテキストで再開できるため、最初の応答が速くなり、消費トークンも抑えられます。

### Bedrock / Vertex / Foundry 環境

ゲートウェイやクラウドプロバイダー経由でも、1 時間のプロンプトキャッシュを有効にしていれば対象になります。

### 手動コンパクトとの使い分け

重要な区切りで要点を残したい場合は、従来どおり `/compact` に指示を付けて実行します。

## 注意点

- 対象は VS Code と Claude Desktop の Code タブです。
- 要約が使われるのはプロンプトキャッシュが期限切れの場合のみです。
- 要約で細部が省略されるため、重要な情報は CLAUDE.md などに残しておくと安全です。
