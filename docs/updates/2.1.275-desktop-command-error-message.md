## 原文（日本語訳）

Claude Desktopが開かないときの `/desktop` エラーメッセージを改善しました。原因と次に取るべき対処が表示されるようになりました。

## 原文（英語）

Improved the `/desktop` error when Claude Desktop does not open: it now says why and what to do next

## 概要

`/desktop` コマンドは、Claude Codeから連携してClaude Desktopアプリを開くためのコマンドです。従来、Claude Desktopが開かなかった場合に表示されるエラーメッセージは原因がわかりにくいものでした。今回の改善により、エラーメッセージに「なぜ開かなかったのか」という理由と、「次に何をすればよいか」という具体的な対処方法が表示されるようになり、ユーザーが自力で問題を解決しやすくなりました。

## 基本的な使い方

```
/desktop
```

Claude Desktopが正しくインストールされていて起動可能な状態であれば、通常どおりアプリが開きます。

## 実践例

### Claude Desktopがインストールされていない場合

修正前は単に「開けませんでした」のような曖昧なメッセージが表示されるだけでしたが、修正後は「Claude Desktopがインストールされていません。こちらからインストールしてください」といった具体的な案内が表示されるようになります。

```
/desktop
# 改善後: インストールされていない場合、インストール手順への案内が表示される
```

### Claude Desktopが起動できない別の理由がある場合

OS側の権限設定やバージョンの不一致など、インストール以外の理由で起動できない場合にも、エラーメッセージがより具体的な原因を示すようになったため、トラブルシューティングがしやすくなりました。

## 注意点

- この改善はエラーメッセージの分かりやすさに関するものであり、Claude Desktop自体の起動条件や動作要件を変更するものではありません。
- Claude Desktopの入手方法やシステム要件については公式ドキュメントを参照してください。
