---

## 原文（日本語訳）
Artifact ツールのガイダンスを改善し、編集権限が与えられている共有 Artifact をその場で更新するようにしました。別のコピーを新たに公開する代わりに、元の Artifact 自体を更新します。

## 原文（英語）
Improved the Artifact tool's guidance so Claude updates a shared artifact in place when you were given edit access to it, instead of publishing a separate copy

## 概要
これまで、共有された Artifact に対して編集を依頼すると、Claude が元の Artifact とは別に新しいコピーを公開してしまうことがありました。今回の改善により、編集権限が付与されている Artifact については、その場で直接更新されるようになります。これにより、共同作業中に同じ URL やタブを共有し続けられ、重複したコピーが増える混乱を避けられます。

## 基本的な使い方
編集権限を持つ Artifact に対して修正を依頼するだけで、Claude が自動的にその Artifact を直接更新します。

```
（共有されたArtifactのURLを開いた状態で）
「このダッシュボードの色をもう少し落ち着いたトーンに変更して」
# → 新しいArtifactが作られるのではなく、同じArtifactがその場で更新される
```

## 実践例

### チームで共有中のダッシュボードを修正する
```
「編集アクセスをもらっているこのArtifactに、フィルター機能を追加して」
# → 元のArtifactがそのまま更新され、既存のリンクを共有しているメンバー全員に
#   最新版が反映される
```

### 反復的にプロトタイプを改善する
```
「ボタンの配置を右上に変更して」
「次に、ダークモード対応を追加して」
# → 複数回のやり取りでも同じArtifactが継続的に更新され、
#   コピーが乱立しない
```

## 注意点
- 編集権限が与えられていない Artifact（閲覧のみ、または未公開）の場合は、従来どおり新しい Artifact が作成されます。
- 「別のバージョンとして残したい」場合は、その旨を明示的に伝える必要があります。
- 公開設定や共有範囲自体は変更されません。
