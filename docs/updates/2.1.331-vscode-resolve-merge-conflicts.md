# VS Code: 「Resolve Merge Conflicts」アクションを追加

## 原文（日本語に翻訳）

[VSCode] マージコンフリクトのあるファイルのエディタタイトルと、Source Control の Merge Changes グループに「Resolve Merge Conflicts」を追加しました。

## 原文（英語）

[VSCode] Added "Resolve Merge Conflicts" to the editor title of a file with merge conflicts and to the Merge Changes group in Source Control

## 概要

コンフリクト解消を Claude Code に依頼する導線が追加されました。

## 基本的な使い方

コンフリクトのあるファイルを開き、エディタタイトルの「Resolve Merge Conflicts」を押します。

## 実践例

### リベース後のコンフリクト解消

Source Control の Merge Changes グループからまとめて依頼できます。

## 注意点

- 解消結果は差分で確認してからコミットしてください。
