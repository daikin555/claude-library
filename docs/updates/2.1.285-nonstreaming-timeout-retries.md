# CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES で非ストリーミング再送回数を制限する

## 原文（日本語訳）

- タイムアウトした非ストリーミングのフォールバックリクエストの再送回数を上限設定する環境変数 `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` を追加しました

## 原文（英語）

- Added `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` environment variable to cap re-sends of a non-streaming fallback request that timed out

## 概要

ストリーミングが失敗した際のフォールバックである非ストリーミングリクエストがタイムアウトした場合の、再送回数に上限を設けられます。遅いゲートウェイ経由などで長時間待たされるのを防げます。

## 基本的な使い方

```bash
CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES=1 claude
```

## 実践例

### 不安定なネットワークで早く失敗させる

```bash
export CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES=0
claude
```

### 同バージョンのリトライ予算の変更

同バージョンでは、非ストリーミングのフォールバックがリクエスト全体のリトライ予算を共有するようになり、最大21回リトライされる問題も修正されています。

## 注意点

- 値を小さくすると、一時的な遅延でも早めにエラーになります。
- `0` の扱いなど詳細は公式ドキュメントで確認してください。
