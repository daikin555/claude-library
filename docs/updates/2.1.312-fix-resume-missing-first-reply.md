## 原文（日本語訳）

ターミナルでセッションを再開した後の最初の返信が、次にそのセッションを再開したときに欠けていることがある、まれなケースを修正しました

## 原文（英語）

Fixed a rare case where the first reply after resuming a session in the terminal could be missing the next time the session was resumed

## 概要

再開したセッションで、最初の返信が履歴に残らないことがあった不具合が修正されました。

## 基本的な使い方

```bash
claude --resume
```

再開したセッションで作業した後、再度再開しても履歴が正しく復元されます。

## 実践例

### 長期タスクの継続

数日にわたる作業を何度も再開しても、会話の文脈が欠けにくくなります。

## 注意点

- 発生は「まれ」とされており、通常は意識する必要はありません。
