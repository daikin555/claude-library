## 原文（日本語訳）
支出上限のないClaude appsゲートウェイ利用の開発者向けに、`/usage` へ今日・今週・今月の支出を追加しました（ゲートウェイがこのバージョン以降の場合）。

## 原文（英語）
Added spend for today, this week and this month to `/usage` for developers behind a Claude apps gateway who have no spend limit, when the gateway runs this version or later

## 概要
Claude appsゲートウェイ経由で支出上限が設定されていない場合でも、`/usage` で自分の利用額の推移を確認できます。

## 基本的な使い方
```
/usage
```

## 実践例

### 月次の使いすぎチェック
今月の累計を見て、重い作業を控えるかどうかを判断できます。

### 作業ごとのコスト把握
日次の支出を前後で比べて、大きなタスクのコスト感を掴めます。

## 注意点
- ゲートウェイ側もこのバージョン以降である必要があります。
- 支出上限が設定されている場合は従来の表示です。
