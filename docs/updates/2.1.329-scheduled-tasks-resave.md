## 原文（日本語訳）

保存済みのスケジュールタスクについて、新しくサインインしたセッションでは、以前のバージョンで保存されたもののほとんどを再度スケジュールする必要があります。ただし、そのセッション自体を `--resume` した場合は引き続き実行されます。

## 原文（英語）

Changed saved scheduled tasks: in new signed-in sessions, most saved by earlier versions need scheduling again, though `--resume` of their own session still runs them

## 概要

アップデート後、以前のバージョンで保存したスケジュールタスクが新しいセッションで動かなくなる場合があります。

## 基本的な使い方

```bash
claude --resume
```

## 実践例

### アップデート後の点検

定期実行に頼っているタスクは、`/tasks` で確認し、動いていなければ再設定します。

## 注意点

- 自動で移行されない点に注意してください。
