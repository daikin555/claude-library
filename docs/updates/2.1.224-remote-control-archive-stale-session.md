## 原文（日本語訳）

コンパクション（要約）や `/resume` によって新しいセッションが発行された際、古い（デッドな）サーバーセッションを一覧に残したままにするのではなく、アーカイブするように Remote Control の挙動を変更しました。

## 原文（英語）

Changed Remote Control to archive the stale server session instead of leaving a dead one listed when a fresh session is minted after compaction or `/resume`

## 概要

[Remote Control](https://code.claude.com/docs/en/remote-control) は、ローカルマシンで動作しているClaude Codeのセッションを、スマートフォンやブラウザ（claude.ai/code）から操作できるようにする機能です。会話がコンパクション（要約）されたり `/resume` でセッションを再開したりすると、内部的に新しいRemote Controlセッションが発行されることがあります。v2.1.224より前は、このとき古いサーバーセッションがそのまま一覧に残り、実際には応答しない「死んだ」セッションとして claude.ai/code のセッション一覧に表示され続けることがありました。今回の変更により、新しいセッションが発行されたタイミングで古いセッションは自動的にアーカイブされ、一覧に不要なエントリが残らなくなりました。

## 基本的な使い方

Remote Controlの利用方法自体に変更はありません。通常どおりサーバーモードまたはインタラクティブセッションでRemote Controlを開始します。

```bash
# サーバーモードでRemote Controlを開始
claude remote-control

# または既存のセッションから
/remote-control
```

コンパクションが発生したり `/resume` でセッションを再開したりしても、ユーザー側で特別な操作をする必要はありません。古いセッションのアーカイブはバックグラウンドで自動的に行われます。

## 実践例

### 長時間セッションでコンパクションが発生する場合

長時間の作業でコンテキストが圧縮（コンパクション）されると、内部的に会話の状態が引き継がれた新しいセッションが生成されることがあります。

```text
# 長時間の開発セッション中にコンテキストが自動的にコンパクションされる
Context low · Compacting conversation...

# 修正前: claude.ai/code のセッション一覧に、
#         応答しない古いセッションと新しいセッションの両方が表示されてしまう
# 修正後: 古いセッションは自動的にアーカイブされ、
#         一覧には新しい有効なセッションのみが表示される
```

### `--resume` でセッションを再開する場合

```bash
# 過去のセッションをResume Controlごと再開
claude --resume <session-id>
```

`--resume` によってRemote Controlの接続先が新しいサーバーセッションに切り替わった場合も、古いセッションは放置されずアーカイブされるため、claude.ai/code やClaudeアプリのセッション一覧が古い接続不可能なエントリで汚れることがなくなります。

### セッション一覧を整理して使う場合

```text
# claude.ai/code または Claudeモバイルアプリのセッション一覧を開く
# 修正前: 同じマシン・同じプロジェクトの「死んだ」セッションが複数残り、
#         どれが最新か分かりにくい
# 修正後: 古いセッションは自動でアーカイブ済みとして扱われるため、
#         現在アクティブなセッションだけを見分けやすい
```

## 注意点

- アーカイブされたセッションは会話履歴が削除されるわけではなく、一覧上の「有効な接続先」から外れる扱いです。
- この修正はコンパクションや `/resume` によって新しいRemote Controlセッションが発行される場面に限定した挙動改善であり、通常の切断・再接続フローとは別の問題への対応です。
- 関連して、`claude --resume` や `--continue` での再接続に失敗した場合の挙動については、[Remote Controlのトラブルシューティング](https://code.claude.com/docs/en/remote-control#troubleshooting)にある「Couldn't reconnect to your Remote Control session」の項も参照してください。
