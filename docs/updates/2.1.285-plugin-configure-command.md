# claude plugin configure でプラグインのオプションを確認・設定する

## 原文（日本語訳）

- `claude plugin configure <plugin>` を追加しました。プラグインのオプションと未設定のものを表示し、`--values-stdin` を指定すると標準入力から読み取った新しい値を保存します

## 原文（英語）

- Added `claude plugin configure <plugin>` to show a plugin's options and which are unset, or save new values read from stdin with `--values-stdin`

## 概要

プラグインのオプション設定を CLI から確認・保存できるコマンドです。これまで `/plugin` → Configure の対話操作が必要だった設定を、スクリプトや自動化から扱えます。

## 基本的な使い方

```bash
# オプションと未設定項目を表示
claude plugin configure my-plugin
```

## 実践例

### 標準入力から値を保存する

```bash
cat values.txt | claude plugin configure my-plugin --values-stdin
```

入力の具体的な形式はプラグインのオプション定義に依存します。まず引数なしで実行して項目を確認してください。

### セットアップスクリプトでの利用

チーム共通のオンボーディングスクリプトに組み込み、未設定項目が残っていないか確認する用途に使えます。

## 注意点

- 入力形式の詳細は changelog に記載がないため、`claude plugin configure --help` で確認してください。
- 秘密情報はシェル履歴に残らないよう、標準入力経由で渡すのが安全です。
