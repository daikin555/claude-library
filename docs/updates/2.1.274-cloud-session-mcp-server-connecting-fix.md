## 原文（日本語訳）
クラウドセッションの最初のターンが、まだ接続中だったSDKホスト型MCPサーバーのツールを含まずに開始されてしまうことがある問題を修正しました。

## 原文（英語）
Fixed the first turn of a cloud session sometimes starting without the tools of an SDK-hosted MCP server that was still connecting

## 概要
Claude CodeのクラウドセッションはSDKでホストされたMCP（Model Context Protocol）サーバーに接続してツールを利用できます。しかし、セッション開始時にMCPサーバーの接続がまだ完了していない場合、最初のターンがそのサーバーのツールを認識しないまま開始されてしまう競合状態（レースコンディション）がありました。今回の修正により、MCPサーバーの接続完了を適切に待ってからターンが開始されるようになり、初回ターンからツールが確実に利用可能になりました。

## 基本的な使い方
SDKホスト型のMCPサーバーを設定したクラウドセッションを通常通り開始すれば、内部的にこの修正が適用されます。特別な操作は不要です。

```json
{
  "mcpServers": {
    "my-tool-server": {
      "command": "node",
      "args": ["server.js"]
    }
  }
}
```

## 実践例

### 修正前の挙動
セッション開始直後にMCPサーバーのツールを呼び出そうとすると、サーバーの接続がまだ完了しておらず、ツールが見つからない、あるいは無視されるといった挙動が発生することがありました。

### 修正後の挙動
セッションの最初のターンから、SDKホスト型MCPサーバーの接続完了を待ってツールが確実に利用可能な状態で開始されるようになりました。

## 注意点
- 接続に時間のかかるMCPサーバーを使う場合、初回ターンの開始がわずかに待たされる可能性がありますが、これは正確な動作のためのトレードオフです。
- この修正はクラウドセッション（Claude Code on the web等）に特有のものです。
