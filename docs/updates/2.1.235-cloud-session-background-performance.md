## 原文（日本語訳）

`/ultrareview` や `/autofix-pr` のようなクラウドセッションをバックグラウンドで実行している間のメモリとCPU使用量が改善されました。イベントストリームが更新のたびに再スキャン・再描画されることがなくなりました。

## 原文（英語）

Improved memory and CPU usage while cloud sessions such as `/ultrareview` or `/autofix-pr` run in the background — their event streams are no longer re-scanned and re-rendered on every update

## 概要

`/ultrareview` や `/autofix-pr` はセッションの内容をクラウド上のサンドボックスにアップロードし、リモートで処理を行う機能です。処理中は進捗を示すイベントストリームがローカルのターミナルに随時反映されますが、これまでは新しいイベントを受け取るたびにストリーム全体を再スキャンして再描画しており、セッションが長時間・大量のイベントを伴う場合にメモリとCPUの消費が増大していました。今回の改善により、更新のたびに全体を再走査する処理がなくなり、バックグラウンドで動作するクラウドセッションが軽量になりました。

## 基本的な使い方

ユーザー側で特別な操作は不要です。`/ultrareview` や `/autofix-pr` を実行してクラウドセッションをバックグラウンドに回し、ローカルで別の作業を続けている間、以前よりCPUやメモリの消費が抑えられていることを体感できます。

```bash
> /ultrareview

# クラウドにセッションをアップロードし、レビューをバックグラウンドで実行
# ローカルではそのまま別のタスクを続行できる
```

## 実践例

### `/ultrareview` を回しながら別の作業を続ける

大きめのPRに対して `/ultrareview` を実行すると、複数のレビューエージェントがクラウド上で並列に解析を行います。従来はこの間ローカルのターミナルが重くなることがありましたが、イベントストリームの再描画が最適化されたことで、レビューを待つ間も手元のマシンへの負荷が軽くなりました。

### `/autofix-pr` でCI失敗を監視させたまま長時間放置する

`/autofix-pr` はPRに対するCIの失敗やレビューコメントを監視し、必要に応じて自動で修正をプッシュします。これは数十分単位で動き続けることがあるため、バックグラウンド実行時のリソース消費が改善されたことで、長時間起動したままにしておいてもマシンへの影響が小さくなります。

### 複数のクラウドセッションを同時に走らせる

複数のPRに対して `/autofix-pr` を並行して仕掛けている場合など、バックグラウンドのイベントストリーム処理が重いと全体のパフォーマンスに影響しやすくなります。今回の改善は、こうした複数セッションを同時に扱う場面でより顕著に効果を発揮します。

## 注意点

- この改善は内部的なパフォーマンス最適化であり、`/ultrareview` や `/autofix-pr` の挙動やレビュー結果自体には影響しません
- クラウドセッションの実行自体はAnthropicのインフラ上で行われますが、進捗イベントの受信・表示処理はローカルのClaude Codeプロセスが担っているため、ローカルマシンのリソース使用量に直接関係します
