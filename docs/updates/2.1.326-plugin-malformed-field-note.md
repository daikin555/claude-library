# plugin.json の不正なフィールドを無視した際の通知

## 原文（日本語に翻訳）

`author` や `homepage` などの `plugin.json` のフィールドが不正で無視された場合に、`/plugin` と `claude plugin list` で注記が表示されるようになりました。

## 原文（英語）

Added a note in `/plugin` and `claude plugin list` when a malformed `plugin.json` field such as `author` or `homepage` is ignored

## 概要

プラグイン作者や導入者が、不正なメタデータが黙って無視されていることに気づけるようになりました。

## 基本的な使い方

```bash
claude plugin list
```

## 実践例

### 自作プラグインの検証

`author` を文字列にしてしまうなどの誤りがあると、注記が表示されます。公開前に確認しましょう。

## 注意点

- 同バージョンでは、表示用フィールドの不正で拒否されていた有効なプラグインが、フック・MCP サーバー付きで読み込まれるようになりました。管理者は配布中のプラグインを確認してください。
