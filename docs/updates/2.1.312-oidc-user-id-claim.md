## 原文（日本語訳）

Claude appsゲートウェイに `oidc.user_id_claim` を追加。`sub` 以外のid_tokenクレーム（Microsoft Entra IDの `oid` など）でユーザーを識別できるようになりました

## 原文（英語）

Added `oidc.user_id_claim` to the Claude apps gateway, to identify people by an id_token claim other than `sub`, such as Microsoft Entra ID's `oid`

## 概要

Claude appsゲートウェイのOIDC設定に `oidc.user_id_claim` が追加されました。ユーザー識別に使うid_tokenのクレームを、既定の `sub` から別のものへ切り替えられます。Microsoft Entra IDの `oid` のように、組織のIdPで安定した識別子が別クレームにある場合に有効です。

## 基本的な使い方

ゲートウェイのOIDC設定に、識別に使いたいクレーム名を指定します（正確な設定形式はゲートウェイの公式ドキュメントを参照してください）。

```yaml
oidc:
  user_id_claim: oid
```

## 実践例

### Microsoft Entra IDで利用する

Entra IDでは `oid` がユーザーを一意に示すため、`user_id_claim` に `oid` を指定してユーザーを識別します。

### IdP間で識別子を揃える

IdPごとに `sub` の値が異なる場合、組織で一貫して使えるクレームを選ぶことで識別の揺れを避けられます。

## 注意点

- 上記の設定例は説明用の概念例です。実際のキー配置は公式ドキュメントで確認してください。
- 識別クレームを変更すると既存ユーザーとの紐付けに影響する可能性があるため、変更前に確認してください。
