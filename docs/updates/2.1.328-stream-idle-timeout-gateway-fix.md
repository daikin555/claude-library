# CLAUDE_STREAM_IDLE_TIMEOUT_MS がゲートウェイ等で 5 分の接続制限を延長しない問題を修正

## 原文（日本語に翻訳）

`CLAUDE_STREAM_IDLE_TIMEOUT_MS` が、ゲートウェイ、カスタム base URL、クラウドプロバイダー利用時に 5 分の接続制限を延ばさない問題を修正しました。

## 原文（英語）

Fixed `CLAUDE_STREAM_IDLE_TIMEOUT_MS` not lengthening the 5-minute connection limit on gateways, custom base URLs and cloud providers

## 概要

長時間応答のないリクエストを扱う環境で、この環境変数による待機時間の延長が効かなかった問題が解消されました。

## 基本的な使い方

```bash
export CLAUDE_STREAM_IDLE_TIMEOUT_MS=600000
claude
```

## 実践例

### 長時間思考するタスク

ゲートウェイ経由で重いタスクを実行し、5 分で接続が切れていた場合に値を延ばして試せます。

## 注意点

- 値はミリ秒単位です
- 経路上のゲートウェイやプロキシ側にタイムアウトがある場合は、そちらも確認してください
