# スケジュールタスクと /loop でスキルの実行前に確認を求めるように変更

## 原文（日本語に翻訳）

スケジュールタスクと `/loop` は、`allowed-tools` またはフックを宣言したスキルを実行する前に確認を求めるようになりました。無人で実行するには `permissions.allow` に `Skill(name)` を追加してください。

## 原文（英語）

Changed scheduled tasks and `/loop` to ask before running a skill that declares `allowed-tools` or hooks; add `Skill(name)` to `permissions.allow` to run it unattended

## 概要

スキルは `allowed-tools` やフックによって、通常より広い権限やコマンド実行を持てます。無人のスケジュール実行でこれらが意図せず動くのを防ぐため、該当スキルの実行前に確認が入るようになりました。

## 基本的な使い方

無人実行を許可したいスキルを `permissions.allow` に登録します。

```json
{
  "permissions": {
    "allow": ["Skill(daily-report)"]
  }
}
```

## 実践例

### /loop で定期的にスキルを実行する

```text
/loop 30m /daily-report
```

`daily-report` が `allowed-tools` を宣言している場合、`Skill(daily-report)` を許可していないと実行前に確認待ちになります。

### 信頼できるスキルだけ許可する

内容を確認済みのスキルだけを個別に許可し、それ以外は確認を残す運用が安全です。

## 注意点

- 以前は問題なく動いていた夜間の定期実行が、確認待ちで止まる場合があります。
- 許可はスキル名単位です。不明なスキルは許可しないでください。
