# プロンプトフックの model に haiku / sonnet などのエイリアスを使用可能に

## 原文（日本語に翻訳）

プロンプトフックの `model` フィールドで、`haiku` や `sonnet` といったモデルエイリアスを指定できるようになりました。

## 原文（英語）

Changed prompt hooks to accept model aliases such as `haiku` or `sonnet` in their `model` field

## 概要

プロンプトフックで完全なモデル ID を書かなくても、エイリアスで軽量モデルなどを指定できます。

## 基本的な使い方

```json
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          { "type": "prompt", "prompt": "作業が完了しているか判定してください", "model": "haiku" }
        ]
      }
    ]
  }
}
```

## 実践例

### 判定フックを安価なモデルで実行

`haiku` を指定してコストと待ち時間を抑えます。

### 品質重視の判定

`sonnet` を指定してより精度の高い判定を行います。

## 注意点

- 設定のスキーマは公式 hooks ドキュメントで確認してください
