## 原文（日本語訳）

[VSCode] Focus viewが最新のTo-do一覧、ペンディング質問のコンテキスト、解決済み回答を誤って折りたたんでしまう問題を修正。思考のみのセクションは「Thought for Ns」と表示され、そのターンが終了すると自動的に再度折りたたまれるようになった。

## 原文（英語）

[VSCode] Fixed Focus view folding away the latest to-do list, a pending question's context, and settled answers; thinking-only folds show "Thought for Ns" and re-collapse when their turn completes

## 概要

VS Code拡張機能のFocus viewは、セッション中の重要な情報（最新のTo-do一覧、ペンディング質問、解決済み回答など）を強調表示する簡潔なビューです。このアップデートでは、これらの重要なコンテキスト情報が誤って折りたたまれてしまうバグを修正しました。さらに、モデルの思考のみを含むセクションは「Thought for Ns」というラベルで表示され、ターン完了後は自動的に再度折りたたまれるようになりました。

## 基本的な使い方

Focus viewをVS Codeで有効にするには、以下の方法があります：

**コマンドメニューから有効化：**
```
/ キーを押す → Settings → Focus view
```

**キーボードショートカットで切り替え：**
- Mac: `Ctrl+Option+F`
- Windows/Linux: `Ctrl+Alt+F`

**コマンドパレットから実行：**
- `Cmd+Shift+P` (Mac) または `Ctrl+Shift+P` (Windows/Linux)
- 「Claude Code: Toggle Focus view」と入力して実行

Focus viewを有効にすると、現在開いているすべてのセッションに即座に適用され、この設定はセッション間で保持されます。

## 実践例

### 長いTo-do一覧を追跡しながらClaudeが作業を進める場合

複数のタスクを含むプロジェクトでClaudeが複数のファイルを編集しているとき：

```
プロンプト: 「このプロジェクト全体のレファクタリングを行って。以下のタスクをすべて完了させて：
  1. APIエンドポイントの更新
  2. データベーススキーマの修正
  3. テストの追加」
```

Focus viewが有効になっていれば、Claudeが各タスクに取り組む過程で、**最新のTo-do一覧が常に表示され続ける**ため、進捗状況をすぐに確認できます。バグ修正前は、このTo-do一覧が誤って折りたたまれてしまい、何をしなければならないかを見失う可能性がありました。

### ペンディング質問への回答時にコンテキストを保持する場合

Claudeが `AskUserQuestion` で質問を含むコンテキストを必要としているとき：

```
Claude: 「このコンポーネントの実装方法について、2つのアプローチがあります：
  A. クラスベースコンポーネント
  B. 関数型コンポーネント
どちらをお勧めしますか？」
```

Focus viewが有効なら、**この質問とそのコンテキストが折りたたまれず表示され続ける**ため、背景情報を確認しながら回答できます。修正前は、このコンテキストが誤って隠れてしまい、判断材料がなくなることがありました。

### 思考プロセスの自動な表示と折りたたみ

Claudeが拡張思考モードで作業しているとき：

Focus viewでは、**モデルの思考のみを含むセクション**は「Thought for 3s」（例）というコンパクトなラベルで表示され、Claudeのターンが終了すると自動的に再度折りたたまれます。これにより、セッション履歴が読みやすく保たれながら、必要に応じて思考プロセスを展開して確認できます。

## 注意点

- **VS Code拡張機能 v2.1.221以降が必要**です。拡張機能のバージョンを確認し、必要に応じて更新してください
- Focus viewは設定の変更をすべてのセッションに即座に反映します
- Focus viewはツール呼び出し（tool calls）、ツール結果（tool results）、思考プロセス（thinking）をデフォルトで非表示にし、1行ずつ展開可能にします
- 「Thought for Ns」ラベルは、展開するとモデルの思考内容を確認できますが、ターン完了後は自動的に再度折りたたまれます
- ただし、To-do一覧、ペンディング質問、解決済み回答などの重要なコンテキストは**常に表示され続ける**設計です
