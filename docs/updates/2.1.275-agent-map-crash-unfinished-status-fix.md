## 原文（日本語訳）

[VSCode] セッションを再度開いた際に、クラッシュによって未完了のまま残ったエージェントがagent map上で「stopped（停止）」ではなく「failed（失敗）」として正しく表示されるように修正しました。

## 原文（英語）

[VSCode] Fixed the agent map showing agents a crash left unfinished as stopped instead of failed once the session is reopened

## 概要

agent mapは、実行中・完了済みのサブエージェントの状態を可視化する機能です。拡張機能がクラッシュした場合、その時点で未完了だったエージェントの実際の状態は「失敗（failed）」であるべきですが、セッションを再度開いた際に誤って「停止（stopped）」として表示されてしまう不具合がありました。この修正により、クラッシュに起因する未完了エージェントは正しく「failed」として表示されるようになります。

## 基本的な使い方

agent mapはClaude Codeパネル内でサブエージェントの実行状況を確認する際に自動的に表示されます。特別な操作は不要です。

```
> Claude Code: Show Agent Map
```

## 実践例

### 拡張機能クラッシュ後にセッションを再度開く場合

バックグラウンドでサブエージェントが実行中に拡張機能がクラッシュし、その後VSCodeを再起動してセッションを開き直すケースです。

```
修正前: クラッシュで中断したエージェント → agent map上で "stopped" と表示
修正後: クラッシュで中断したエージェント → agent map上で "failed" と表示（実態と一致）
```

### 複数エージェントが並行実行中のクラッシュ

複数のサブエージェントが並行して動いている状態でクラッシュが発生した場合でも、それぞれのエージェントの状態が正しく「failed」として区別され、どのタスクが失敗したのかを正確に把握できます。

## 注意点

- この修正は表示上のステータスに関するものであり、クラッシュ自体を防ぐものではありません。
- 「failed」と表示されたエージェントのタスクは、必要に応じて再実行することを検討してください。
