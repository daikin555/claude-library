# Claude apps gateway の managed.policy_mode: layered

## 原文（日本語訳）

- Claude apps gateway に `managed.policy_mode: layered` を追加：開発者に一致するすべてのポリシーが適用され、それぞれが下に列挙されたものの上にマージされる（最初の 1 つだけではない）

## 原文（英語）

- Added `managed.policy_mode: layered` to the Claude apps gateway: every policy that matches a developer applies, each merged over the ones listed below it, not only the first

## 概要

従来は最初に一致したポリシーのみが適用されていました。`layered` モードでは、一致するすべてのポリシーが重ねて適用されます。

## 基本的な使い方

```yaml
managed:
  policy_mode: layered
```

## 実践例

### 全社ポリシー＋チーム別ポリシー

全社共通の基本ポリシーを下に置き、その上に部門別ポリシーを重ねて差分だけを定義できます。

## 注意点

- 並び順がマージ結果に影響します（上のポリシーが下のものに重ねられます）。
- 既存の挙動を維持したい場合は設定を変更しないでください。
