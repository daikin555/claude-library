## 原文（日本語に翻訳）

`CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k` が黙って 100K のウィンドウを設定してしまう問題を修正しました。この変数は `--autocompact` と同様に `k` と `M` のサフィックスを受け付け、値が範囲外または無視される場合は警告を表示します。

## 原文（英語）

Fixed `CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k` silently setting a 100K window: the variable now accepts `k` and `M` suffixes like `--autocompact`, and warns when a value is out of range or ignored

## 概要

これまで `200k` と指定しても意図と異なる 100K として扱われていました。修正後は `k` / `M` サフィックスが正しく解釈され、不正な値には警告が出ます。

## 基本的な使い方

```bash
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k
claude
```

## 実践例

### 自動コンパクトのしきい値を調整する

```bash
CLAUDE_CODE_AUTO_COMPACT_WINDOW=500k claude
```

### 数値のみで指定する

サフィックスなしの数値指定も引き続き利用できます。

## 注意点

- 範囲外の値は警告の対象になります。
- 以前 `k` 付きで指定していた場合、意図した値になっていたか見直してください。
