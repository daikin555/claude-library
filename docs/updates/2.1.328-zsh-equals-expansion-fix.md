# zsh で = から始まる語が原因の not found エラーを修正

## 原文（日本語に翻訳）

zsh で `echo ====` や `[ a == b ]` のように `=` で始まる語があると "not found" エラーで停止する問題を修正しました。`=cmd` がコマンドのパスに展開されることはなくなりました。

## 原文（英語）

Fixed Bash commands in zsh stopping with a "not found" error at a word that starts with `=`, such as `echo ====` or `[ a == b ]`; `=cmd` no longer expands to a command's path

## 概要

zsh には `=cmd` を `cmd` のフルパスに展開する機能があり、`====` のような区切り線や `==` 比較が誤って展開されエラーになっていました。この修正により、Claude Code の Bash ツールで安全に実行できます。

## 基本的な使い方

```bash
echo ====
[ a == b ] && echo same
```

## 実践例

### 区切り線付きのログ出力

ビルドスクリプトで \`echo "===="\` のような出力を使っても、zsh 環境で失敗しなくなります。

## 注意点

- 修正の結果、Claude Code の Bash ツール内では `=cmd` 形式の展開は行われません
- zsh を使っているユーザーが対象です
