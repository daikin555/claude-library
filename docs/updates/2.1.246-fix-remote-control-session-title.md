## 原文（日本語訳）

Remote Controlセッションが、claude.aiやClaudeアプリ上で2回目のプロンプトまで仮のプレースホルダー名のままになっていた問題を修正しました。これにより、自動生成されたタイトルが1回目のプロンプトの直後に表示されるようになりました。

## 原文（英語）

Fixed Remote Control sessions keeping their placeholder name in claude.ai and the Claude app until the second prompt; the auto-generated title now appears after the first prompt

## 概要

Remote Controlを使ってClaude Codeセッションをclaude.aiやClaudeアプリから操作する際、各セッションには内容を反映した自動生成タイトルが付けられます。これまではこのタイトル更新のタイミングにずれがあり、1回目のプロンプトを送っただけでは仮のプレースホルダー名のままで、2回目のプロンプトを送るまでタイトルが更新されませんでした。今回の修正により、最初のプロンプト送信直後に適切なタイトルが表示されるようになり、複数セッションを一覧から見分けやすくなります。

## 基本的な使い方

Remote Controlでセッションを開始し、最初のプロンプトを送るだけで、送信後すぐにセッション一覧のタイトルが自動的に更新されます。

```
claude.aiまたはClaudeアプリからRemote Controlでセッションを開始し、
「READMEを更新して」のようにプロンプトを送信する
```

## 実践例

### 複数のRemote Controlセッションを並行管理

claude.aiやClaudeアプリから複数のマシン・セッションをRemote Controlで操作している場合、1回目のプロンプト送信直後にタイトルが更新されるため、どのセッションが何をしているかをすぐに区別できます。

### モバイルからのタスク確認

Claudeアプリを使って外出先からセッション一覧を確認する際、プレースホルダー名のままでは内容が分かりませんでしたが、修正後は最初のやり取りの内容を反映したタイトルがすぐに表示され、目的のセッションを見つけやすくなります。

### セッション履歴の整理

複数のセッションを後から振り返る際、タイトルが早期に正しく設定されることで、履歴一覧の可読性が向上します。

## 注意点

- タイトルは内容に基づいて自動生成されるため、プロンプトの内容によって生成されるタイトルの精度は変わります
- この修正はタイトル表示のタイミングに関するものであり、セッションの動作自体には影響しません
