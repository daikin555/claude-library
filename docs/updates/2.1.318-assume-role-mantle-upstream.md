# Claudeアプリゲートウェイの mantle アップストリームに assume_role を追加

## 原文（日本語訳）

Claudeアプリゲートウェイの `mantle` アップストリームに `assume_role` を追加しました。別のAWSアカウントのロールを使用でき、開発者ごとのAWSコスト按分にも役立ちます。

## 原文（英語）

Added `assume_role` on `mantle` upstreams of the Claude apps gateway, for a role in another AWS account and for per-developer AWS cost attribution

## 概要

ゲートウェイが別AWSアカウントのIAMロールをAssumeして推論リクエストを送れるようになりました。アカウントを分離した構成や、開発者単位のコスト管理が可能になります。

## 基本的な使い方

`mantle` アップストリームに `assume_role` を指定します。下記は概念的な例で、正確なキーはゲートウェイのドキュメントを参照してください。

```yaml
upstreams:
  - type: mantle
    assume_role:
      role_arn: arn:aws:iam::123456789012:role/claude-gateway
```

## 実践例

### クロスアカウント運用

利用料を専用アカウントに集約し、アプリ側アカウントと権限を分離できます。

### 開発者別コスト按分

開発者ごとにロールやセッション名を分けると、AWSのコストレポートで利用量を追跡できます。

## 注意点

- ロール側の信頼ポリシーで、ゲートウェイの実行主体を許可しておく必要があります。
