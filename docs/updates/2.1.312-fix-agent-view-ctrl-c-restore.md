## 原文（日本語訳）

終了直前にCtrl+Cで消去した入力テキストが、次回起動時にエージェントビューで復元されてしまう問題を修正しました

## 原文（英語）

Fixed agent view restoring input text on the next launch after it was cleared with Ctrl+C just before exiting

## 概要

入力をCtrl+Cで消したのに、次回起動時に同じ文章が復元される不具合が修正されました。

## 基本的な使い方

入力をCtrl+Cで消去して終了すると、次回起動時に入力欄は空になります。

## 実践例

### 誤って入力した文字列の破棄

消して終了した文字列が、次回起動時に残りません。

## 注意点

- 消去しないまま終了した場合の入力復元は従来どおりです。
