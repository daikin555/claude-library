## 原文（日本語訳）
[Claude Code on the web] ルーティンのオーナーのGitHub連携が失われている場合、これまでは最初の確認失敗ですぐにルーティンをオフにしていましたが、今後は最大72時間、実行をスキップして再試行するように変更しました。

## 原文（英語）
[Claude Code on the web] Changed routines to skip a run and retry for up to 72 hours when the owner's GitHub connection is missing, instead of switching the routine off at the first failed check

## 概要
Claude Code on the webのルーティン機能はGitHubとの連携を前提に動作しますが、オーナーのGitHubアカウント連携が一時的に外れてしまうことがあります。これまではその状態を検知した最初のタイミングでルーティン自体を自動的にオフにしてしまい、連携が復旧してもユーザーが手動で再度有効化する必要がありました。今回の変更により、GitHub連携が見つからない場合はすぐにルーティンをオフにするのではなく、その回の実行をスキップしたうえで最大72時間、連携の回復を待って自動的に再試行するようになりました。

## 基本的な使い方
特別な操作は不要です。GitHub連携が一時的に失われても、72時間以内に連携が復旧すればルーティンは自動的に通常通り動作を再開します。

## 実践例

### GitHubトークンの一時的な失効からの自動復旧
GitHub側のトークンや権限設定の変更などで一時的に連携が切れてしまった場合でも、ユーザーが気づいて再連携するまでの間、ルーティンは無効化されずに実行をスキップしながら待機します。72時間以内に連携を復旧すれば、次回以降のスケジュール通りに実行が再開されます。

### 長期休暇などでの一時的な連携切れ
ユーザーがしばらくGitHubアカウントの状態を確認できない期間があっても、短期間の連携切れであればルーティンの設定自体は保持され、オフになって設定し直す手間を防げます。

## 注意点
- 72時間を超えても連携が復旧しない場合は、引き続きルーティンが無効化される可能性があります。
- GitHub連携の状態は、Claude Code on the webの連携設定画面から随時確認・再設定できます。
