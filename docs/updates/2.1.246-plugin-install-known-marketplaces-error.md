## 原文（日本語訳）

`~/.claude/plugins/known_marketplaces.json` が空または壊れている場合に、`claude plugin install <name>` がエラーを報告せずに黙って終了する（またはターミナルでハングする）問題を修正しました。

## 原文（英語）

Fixed `claude plugin install <name>` exiting silently (or hanging in a terminal) instead of reporting an error when `~/.claude/plugins/known_marketplaces.json` is empty or corrupted

## 概要

`claude plugin install` コマンドは、既知のマーケットプレイス一覧を保持する `~/.claude/plugins/known_marketplaces.json` を参照してプラグインを解決します。このファイルが空になったり、JSONとして壊れた状態になったりしていた場合、以前はコマンドが何のエラーメッセージも出さずに終了、あるいはターミナル上で応答がなくなる（ハング）という挙動になっていました。今回の修正により、こうしたケースでは明確なエラーメッセージが表示されるようになり、ユーザーは問題の原因を特定して対処できます。

## 基本的な使い方

修正後は、ファイルが破損している状態でインストールを試みると、エラーが明示的に表示されます。

```bash
claude plugin install my-plugin
# known_marketplaces.json が壊れている場合、
# エラーメッセージが表示されるようになった（以前は無反応だった）
```

## 実践例

### 破損したキャッシュファイルの検知

何らかの理由で `known_marketplaces.json` が空ファイルになってしまった場合でも、`claude plugin install` を実行した際にすぐエラーとして検知できるようになりました。原因不明のハングでCIパイプラインが止まる、といった事態を避けられます。

### スクリプトやCI内でのプラグインインストール

自動化スクリプトの中で `claude plugin install` を呼び出している場合、以前は不正なJSONによって処理がハングし、タイムアウトまで気づけないことがありました。修正後はエラーで即座に失敗するため、CIのログから原因を追いやすくなります。

### トラブルシューティング時の切り分け

プラグインインストールがうまくいかないときに、まず `known_marketplaces.json` の内容を確認するという切り分け手順が有効になりました。エラーメッセージに従ってファイルを修復・再生成すれば解決します。

## 注意点

- 破損したファイルを修正するには、`~/.claude/plugins/known_marketplaces.json` を削除するか、正しいJSON形式に直す必要があります
- この修正はエラーの可視性を改善するものであり、ファイルの破損自体を防ぐものではありません
