# allowedMcpServers が managed-mcp.json の env のみ ${VAR} のstdioサーバーを除外しなくなった

## 原文（日本語に翻訳）

- `allowedMcpServers` が、`env` のみで `${VAR}` を使う `managed-mcp.json` のstdioサーバーをフィルタしないよう変更。許可リストから漏れていたサーバーはアップグレード時に読み込まれるようになる。無効にしたい場合は `deniedMcpServers` を使う

## 原文（英語）

- Changed `allowedMcpServers` to stop filtering `managed-mcp.json` stdio servers that use `${VAR}` only in `env`: one your allowlist left out now loads on upgrade; use `deniedMcpServers` to keep it off

## 概要

`env` のみで `${VAR}` を使う `managed-mcp.json` のstdioサーバーは、`allowedMcpServers` によるフィルタ対象外になりました。許可リストに無くても、アップグレード後に読み込まれる点が重要な挙動変更です。

## 基本的な使い方

読み込みたくない場合は `deniedMcpServers` で明示的に拒否します。

```json
{
  "deniedMcpServers": [{ "serverName": "internal-tool" }]
}
```

## 実践例

### 管理者によるアップグレード前確認

許可リストで除外していた該当サーバーが、更新後に有効化されないか確認します。必要なら `deniedMcpServers` に追加します。

## 注意点

- セキュリティに関わる挙動変更です。管理者は更新前に `managed-mcp.json` を点検してください。
