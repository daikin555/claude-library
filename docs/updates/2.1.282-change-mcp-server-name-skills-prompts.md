## 原文（日本語訳）

`anthropic-skills` または `claude-ai` という名前で設定されたMCPサーバーが、スキルやプロンプトを一切表示しないように変更しました（ツール自体は引き続き機能します）。これらのスキル・プロンプトを再度表示するには、MCP設定でサーバー名を変更してください。

## 原文（英語）

Changed MCP servers configured under the name `anthropic-skills` or `claude-ai` to list no skills or prompts (their tools still work); rename the server in your MCP configuration to list them again

## 概要

これはセキュリティに関わる変更です。`anthropic-skills` や `claude-ai` はclaude.aiから同期される正規スキル用に予約された名前空間ですが、MCPサーバーの設定名としてこれらの名前を使うと、そのMCPサーバーが提供するスキルやプロンプトが正規の同期スキルであるかのように紛れて表示されてしまう可能性がありました。今回の変更で、`anthropic-skills` または `claude-ai` という名前で設定されたMCPサーバーは、スキルやプロンプトを一覧に表示しなくなりました。なお、MCPサーバーが提供するツール自体は引き続き通常通り機能します。

## 基本的な使い方

MCPサーバーの設定ファイル（例: `.mcp.json`）で、サーバー名を予約名以外に変更します。

```json
{
  "mcpServers": {
    "my-custom-server": {
      "command": "..."
    }
  }
}
```

`anthropic-skills` や `claude-ai`以外の名前にすることで、そのサーバーが提供するスキル・プロンプトが再び一覧表示されるようになります。

## 実践例

### 既存MCPサーバー設定の名前見直し

過去に `anthropic-skills` や `claude-ai` という名前でMCPサーバーを設定していた場合、この変更によりスキル・プロンプトが一覧から消えたように見えるため、設定ファイルでのリネームが必要です。

### なりすましMCPサーバーからのユーザー保護

第三者が意図的に予約名を使ってMCPサーバーを配布し、正規スキルであるかのように見せかけようとしても、スキル・プロンプトが表示されなくなることで誤認を防げます。

## 注意点

- ツール自体は名前に関わらず引き続き機能するため、影響を受けるのはスキル・プロンプトの一覧表示のみです
- 予約名を使ったMCPサーバー設定を持つチームは、名前を変更してから展開し直すことを推奨します
