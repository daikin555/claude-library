# プラグインマニフェストに optionalDependencies を追加

## 原文（日本語に翻訳）

プラグインマニフェストに `optionalDependencies` を追加しました。列挙されたプラグインは、そのプラグインと一緒にインストールされ、個別に無効化・アンインストールもできます。

## 原文（英語）

Added `optionalDependencies` to plugin manifests: plugins that install with the plugin listing them and can be disabled or uninstalled on their own

## 概要

関連プラグインを一緒に導入しつつ、不要なら単独で外せる依存関係を表現できます。

## 基本的な使い方

```json
{
  "name": "my-plugin",
  "optionalDependencies": ["helper-plugin"]
}
```

## 実践例

### 補助プラグインの同梱

メインのプラグインと一緒に補助プラグインが入りますが、補助側だけを無効化して使うことも可能です。自動更新通知では、新たに依存関係として入ったプラグインが更新分と分けて表示されます。

## 注意点

- 必須依存とは異なり、単独で無効化・アンインストールできます。
- 正確なフィールド形式は公式のプラグインドキュメントで確認してください。
