# claude auth status とJSON出力にサインイン有効期限を追加

## 原文（日本語訳）

- 保存されているclaude.aiサインインの終了日を `claude auth status`（`loginExpiresAt`）と `claude -p` のJSON結果（`credential_expires_at`）に追加しました
- 保存されているclaude.aiサインインの終了10日前から、`claude -p` のテキスト出力にstderrへ1行の警告を表示するようにしました

## 原文（英語）

- Added the date a stored claude.ai sign-in ends to `claude auth status` (`loginExpiresAt`) and to `claude -p` JSON results (`credential_expires_at`)
- Added a one-line stderr warning to `claude -p` text output, starting 10 days before a stored claude.ai sign-in ends

## 概要

保存済みのclaude.aiサインインがいつ失効するかを確認できるようになりました。CIやバッチ処理で `claude -p` を使っている場合、突然の認証切れを事前に検知できます。

## 基本的な使い方

```bash
claude auth status
claude -p "hello" --output-format json
```

前者では `loginExpiresAt`、後者では `credential_expires_at` に期限が含まれます。

## 実践例

### 期限切れの監視スクリプト

```bash
claude -p "ping" --output-format json | jq -r '.credential_expires_at'
```

取得した日時を監視ツールに渡し、期限が近づいたら通知する運用が可能です。

### 警告の確認

期限の10日前から `claude -p` のテキスト出力でstderrに警告が出ます。ログ集約ツールで拾えば更新漏れを防げます。

### 期限切れ時の対処

期限が切れたら `claude auth login` か `claude setup-token` で再認証します。長期運用には `setup-token` が向きます。

## 注意点

- 期限が表示されるのは保存済みのclaude.aiサインインの場合です。
- 警告はstderrに出るため、stdoutをパースする処理には影響しません。
