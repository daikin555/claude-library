## 原文（日本語訳）

`/--` で始まるプロンプト（例: Leanのドキュメントコメント）が、Claudeへ送信されずに不明なスラッシュコマンドとして拒否されてしまう不具合を修正しました。

## 原文（英語）

Fixed prompts beginning with `/--` (e.g. Lean doc comments) being rejected as an unknown slash command instead of being sent to Claude

## 概要

Claude Codeでは、入力が `/` で始まると自動的にスラッシュコマンドとして解釈されます。しかし、Lean言語のドキュメントコメント（`/-- ... -/`）のように `/--` で始まる通常のテキストを貼り付けたり入力したりした場合、これがスラッシュコマンドの入力欄で「不明なコマンド」として拒否され、Claudeにメッセージが送信されないという問題がありました。今回の修正により、`/--` で始まる入力は通常のプロンプトとして正しくClaudeに送信されるようになりました。

## 基本的な使い方

Lean言語のコードやドキュメントコメントをそのままプロンプトに貼り付けて質問できます。

```
/-- This function computes the factorial of `n`. -/
def factorial (n : Nat) : Nat :=
  ...
このドキュメントコメントの内容をレビューしてください
```

修正前はこの入力が「不明なスラッシュコマンド」として拒否されていましたが、修正後はそのままClaudeに送信され、通常のプロンプトとして処理されます。

## 実践例

### Lean言語のコードレビューを依頼する

Leanのソースコードをコピー＆ペーストしてレビューを依頼する際、ドキュメントコメント（`/--`）が先頭に含まれていても問題なく送信できます。

### 記号列を含むテキストの引用

`/--` のように区切り線やコメント記号としてハイフンを多用するテキスト（Markdownの区切り線的な表現など）を貼り付けても、誤ってコマンドとして解釈されません。

### コードスニペットの一部だけを貼り付ける

ファイル全体ではなく一部の関数だけを抜き出して貼り付けた際、たまたま先頭がドキュメントコメントになっているケースでも安心して入力できます。

## 注意点

- 本来の意図通りにスラッシュコマンドを実行したい場合は、`/` の後にスペースやハイフン以外の文字（コマンド名）を続ける必要があります
- この修正はスラッシュコマンドのパース処理に関するものであり、既存の正しいスラッシュコマンド（`/fork` や `/help` など）の動作には影響しません
