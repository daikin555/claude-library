## 原文（日本語訳）
[Claude Code on the web] ルーティンのリンクが解決できなくなった場合に表示されるページに「New routine」ボタンを追加。ルーティン一覧に戻るリンクの隣に配置。

## 原文（英語）
[Claude Code on the web] Added a "New routine" button to the page shown when a routine link no longer resolves, next to the link back to your routines list

## 概要
Claude Code on the webでは、削除されたり無効になったりしたルーティンへのリンクを開くと、専用のエラーページが表示されます。今回のアップデートでは、このエラーページに「New routine」ボタンが追加され、ルーティン一覧へ戻るリンクの隣から直接新しいルーティンを作成できるようになりました。これまではリンク切れに遭遇した際、一覧ページに戻ってから改めて新規作成の操作をする必要がありましたが、その手間が省けます。

## 基本的な使い方
特別な設定は不要です。共有されたルーティンのリンクを開いた際にそのルーティンが既に削除・無効化されていると、自動的にこのエラーページが表示されます。

1. 無効なルーティンリンクを開く
2. 表示されたページで「New routine」ボタンをクリック
3. 新しいルーティンの作成画面に遷移する

## 実践例

### チームで共有されたルーティンリンクが切れていた場合
チームメンバーから共有されたSlackメッセージやドキュメント内のルーティンリンクを開いたが、既にそのルーティンが削除されていた場合、リンク切れページから直接「New routine」を押して代替のルーティンを作成できます。

```
1. 共有されたルーティンURLをブラウザで開く
2. 「このルーティンは見つかりませんでした」ページが表示される
3. 「New routine」ボタンをクリックして新規作成へ
```

### 古いブックマークからアクセスした場合
以前ブックマークしていたルーティンが編集や削除により無効になっていても、同じページから新規ルーティン作成にワンクリックで移動できます。

## 注意点
- このボタンはルーティンリンクが無効な場合にのみ表示されます。
- 新規作成したルーティンは、元のルーティンの設定を引き継ぎません。必要な設定は改めて行う必要があります。
- 本機能はClaude Code on the web上でのみ利用可能です。
