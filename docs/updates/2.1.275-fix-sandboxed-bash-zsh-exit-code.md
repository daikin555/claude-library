## 原文（日本語に翻訳）

Linux上のサンドボックス化されたBashコマンドが、シェルがzshの場合に失敗しても終了コード0を報告してしまっていた問題を修正

## 原文（英語）

Fixed sandboxed Bash commands on Linux reporting exit code 0 for failed commands when the shell is zsh

## 概要

Claude CodeのBashツールはサンドボックス環境内でコマンドを実行できます。Linux環境でデフォルトシェルとしてzshを使用している場合、実行したコマンドが実際には失敗している（非ゼロの終了コードを返している）にもかかわらず、サンドボックス機構が誤って終了コード0（成功）として報告してしまう不具合がありました。これにより、Claudeがコマンドの失敗を認識できず、誤った判断で処理を続けてしまう可能性がありました。今回の修正で、zsh環境でも正しい終了コードが報告されるようになりました。

## 基本的な使い方

この修正は内部的な挙動の改善であり、特別な設定は不要です。zshをデフォルトシェルとして使用しているLinux環境でも、通常通りBashツールを利用できます。

```bash
claude
```

## 実践例

### 修正前の挙動

デフォルトシェルがzshに設定されたLinux環境でサンドボックス内のBashコマンドを実行した際、たとえば存在しないコマンドの実行やテストの失敗などで本来は非ゼロの終了コードが返されるべき状況でも、終了コード0が報告され、Claudeが失敗を検知できないことがありました。

### 修正後の挙動

zsh環境でも、コマンドの実際の終了コードが正しく報告されるようになり、Claudeは失敗を正確に検知して適切に対応（エラーの調査や修正）できるようになりました。

```bash
# zshがデフォルトシェルのLinux環境で
false  # 終了コード1を返すコマンド
# → 修正後は正しく終了コード1として報告される
```

## 注意点

- この不具合はLinux上でサンドボックス機能を利用し、かつシェルがzshの場合に限定されていました
- bashをデフォルトシェルとして使う環境では、この問題は発生していませんでした
- サンドボックス機能自体の設定や利用方法に変更はありません
