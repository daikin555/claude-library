## 原文（日本語訳）
Claude Desktopセッションのエラーヒントが、そこでは使用できないCLIフラグではなく、`/usage-credits` のようなスラッシュコマンドを提案するように修正しました。

## 原文（英語）
Fixed error hints in Claude Desktop sessions to suggest slash commands like `/usage-credits` instead of CLI flags that cannot be used there
## 概要
Claude Desktopはターミナルではなくデスクトップアプリのため、CLIフラグ（コマンドライン引数）を直接入力することができません。しかし、エラーメッセージのヒントが従来はCLI向けのフラグを提案してしまい、Claude Desktopのユーザーにとっては実行不可能な案内になっていました。今回の修正で、Claude Desktop環境では代わりに `/usage-credits` のような、そこで実際に使えるスラッシュコマンドが提案されるようになりました。

## 基本的な使い方
Claude Desktopでエラーが発生した場合、表示されるヒントに従ってスラッシュコマンドを入力します。

```
/usage-credits
```

## 実践例

### 修正前の挙動
Claude Desktop上で利用量に関するエラーが発生した際、「`--usage-credits` フラグを使ってください」のようなCLI向けの案内が表示され、実際にはそのフラグを入力する手段がなく混乱を招いていました。

### 修正後の挙動
同じ状況で、Claude Desktopでは `/usage-credits` のようなスラッシュコマンドを使うよう案内され、その場ですぐに実行できるようになりました。

## 注意点
- この修正はエラーメッセージの案内内容に関するものであり、CLIとClaude Desktopでは引き続き利用できる操作方法が異なります。
- CLIで作業している場合は、従来通りコマンドラインフラグの案内が表示されます。
