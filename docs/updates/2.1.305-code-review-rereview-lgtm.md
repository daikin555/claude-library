# [Code Review] 未解決のブロッキング指摘がある再レビューをLGTMで始めないよう変更

## 原文（日本語に翻訳）

- [Code Review] 以前のブロッキング指摘が未解決の間は、再レビューが「LGTM」で始まらないよう変更

## 原文（英語）

- [Code Review] Changed Code Review re-reviews so they no longer open with LGTM while earlier blocking findings are still open

## 概要

未解決のブロッキング指摘があるのに「LGTM」で始まる再レビューは、誤解を招くため変更されました。

## 基本的な使い方

自動で適用されます。再レビューの冒頭で状況を確認できます。

## 実践例

### 再レビューの読み取り

冒頭の文言でマージ可否を誤認する心配が減ります。

## 注意点

- マージ判断は、未解決の指摘の有無を確認した上で行ってください。
