# SSL 証明書エラーメッセージの改善

## 原文（日本語訳）

- SSL 証明書エラーが、考えられる原因（サーバーが中間証明書を省略している場合など）と、それぞれの対処法を示すように改善

## 原文（英語）

- Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each

## 概要

SSL 証明書エラー時に、考えられる原因と対処法が表示されるようになりました。

## 基本的な使い方

特別な操作は不要です。表示された内容に従って対処します。

## 実践例

### 中間証明書の欠落

サーバー側で中間証明書を配信するよう修正するか、必要な CA 証明書を信頼設定に追加します。

## 注意点

- ループ状のクロス証明書が必要な場合は `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` も参照してください。
