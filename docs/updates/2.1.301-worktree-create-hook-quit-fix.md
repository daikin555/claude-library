# WorktreeCreateフックで作ったworktreeが未プッシュのまま終了時に削除される問題を修正

## 原文（日本語に翻訳）

`WorktreeCreate` フックで作成された worktree が、未プッシュのコミットを持つ可能性があるにもかかわらず、終了時に確認なしで削除される問題を修正しました。

## 原文（英語）

Fixed quitting removing a worktree made by a `WorktreeCreate` hook without asking when it may hold unpushed commits

## 概要

`WorktreeCreate` フックで独自に作成したworktreeは、終了時に確認なしで削除されることがあり、未プッシュのコミットを失う恐れがありました。修正後は、その可能性がある場合に確認が行われます。

## 基本的な使い方

```bash
claude --worktree feature-x
```

作業後に終了する際、未プッシュのコミットがあり得る場合は削除前に確認されます。

## 実践例

### カスタムworktreeでの作業

フックで独自のディレクトリ構成や別のVCSラッパーを使っている場合でも、終了時の誤削除を避けられます。

### 終了前の保全

確認が出たら、削除せず残すか、先にプッシュしてから終了できます。

## 注意点

- 重要な作業は、終了前に `git push` しておくのが確実です。
- 確認の表示条件は「未プッシュのコミットを持つ可能性があるとき」です。
