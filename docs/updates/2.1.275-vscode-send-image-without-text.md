## 原文（日本語訳）
[VSCode] テキストを何も入力しなくても、添付した画像を送信できるようになりました

## 原文（英語）
[VSCode] Added sending an attached image without typing any text

## 概要
これまでVS Code拡張機能では、画像を添付しても何かテキストを入力しないと送信できないケースがありました。今回の変更で、テキストを一切入力せずに画像だけを送信できるようになり、「このスクリーンショットを見て」といった簡単な確認をしたいときに、余計な一言を打つ手間が省けます。

## 基本的な使い方
画像を添付した状態で、テキストを何も入力せずにそのまま送信します。

```
# VS Code拡張機能のチャット入力欄に画像をドラッグ&ドロップ、または貼り付け
# テキストは何も入力せず、そのままEnter（または送信ボタン）
# → 画像だけがClaudeに送信される
```

## 実践例

### エラー画面のスクリーンショットだけを素早く共有する
```
# スクリーンショットをコピー
# チャット欄に貼り付けてそのまま送信（テキストなし）
# → Claudeが画像の内容を見て、状況を推測しながら応答する
```

### デザインカンプを見せてフィードバックを求める
```
# デザイン画像をドラッグ&ドロップ
# テキストなしで送信
# → Claudeが画像内容に基づいてコメントや実装提案を行う
```

## 注意点
- テキストなしで送信すると、Claudeは画像の内容のみから意図を推測する必要があるため、具体的な指示をしたい場合は簡単な説明を添えた方が精度の高い応答が得やすいです。
- 複数画像を添付している場合の挙動も同様に、テキストなしで送信できます。
- この機能はVS Code拡張機能限定の変更です。
