## 原文（日本語訳）

オートモードがAgentツール呼び出しのたびに表示していた、冗長な「Allowed by auto mode classifier（オートモード分類器により許可）」という行を削除しました

## 原文（英語）

Removed the redundant "Allowed by auto mode classifier" line that auto mode showed under every Agent tool call

## 概要

オートモード（Auto mode）では、実行される各操作が自動許可の分類器によって承認されたかどうかを表示する仕組みがありますが、Agentツール（サブエージェントの起動）を呼び出すたびに「Allowed by auto mode classifier」という行が毎回表示されており、実際の作業内容よりもこの定型メッセージの方が目立ってしまっていました。今回の変更でこの冗長な行が削除され、Agentツール呼び出し時の出力がすっきりと見やすくなりました。

## 基本的な使い方

特別な操作は不要です。オートモードでAgentツール（サブエージェント）を呼び出す際、これまで表示されていた「Allowed by auto mode classifier」という行が表示されなくなります。

```bash
claude --permission-mode auto
```

サブエージェントを起動するタスクを依頼すると、以前より簡潔な出力でAgentツールの呼び出しが表示されます。

## 実践例

### サブエージェントを多用するタスクでの出力改善

複数のサブエージェントを立て続けに呼び出すようなタスク（大規模なコードベース調査など）では、以前は呼び出しのたびに「Allowed by auto mode classifier」という同じ行が繰り返し表示され、実際にどのサブエージェントが何をしているかが埋もれがちでした。この修正により、各Agentツール呼び出しの本質的な情報（どのエージェントに何を依頼したか）が見やすくなります。

### ログ・スクリーンショットの可読性向上

オートモードでの作業内容を記録・共有する際にも、定型的な許可メッセージが減ることで、実際の作業ログがより簡潔になります。

## 注意点

- この変更は表示のみに関するもので、オートモードの許可・承認ロジック自体は変わりません
- オートモードを使用していないセッション（通常の許可モード）には影響しません
