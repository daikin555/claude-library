## 原文（日本語訳）

`CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`（2.1.318から利用可能）を追加しました。`1` を設定すると、サブエージェントの進捗要約と、それを生成するリクエストが無効になります。

## 原文（英語）

Added `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES` (available since 2.1.318): set it to `1` to turn off subagent progress summaries and the requests that write them (anthropics/claude-code#86879)

## 概要

サブエージェントの実行中には進捗要約が生成されます。この環境変数を `1` にすると要約と、そのためのAPIリクエストが止まります。リクエスト数を減らしたい場合に有効です。

## 基本的な使い方

```bash
export CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1
claude
```

`settings.json` の `env` からも設定できます。

```json
{
  "env": { "CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES": "1" }
}
```

## 実践例

### リクエストを抑えたい場合

多数のサブエージェントを並列で動かすワークフローで、補助リクエストを減らせます。

### CIやヘッドレス実行

進捗表示が不要な自動実行環境で設定しておきます。

## 注意点

- サブエージェントの進捗が要約表示されなくなります
- 同バージョンでは、要約の更新が返答に10〜20秒かかった場合にスキップされる問題も修正されています
