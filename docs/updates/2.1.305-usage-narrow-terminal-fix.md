# /usage の行が狭いターミナルで切れる問題を修正

## 原文（日本語に翻訳）

- 狭いターミナルで `/usage` の行が途中で切れる問題を修正

## 原文（英語）

- Fixed `/usage` rows being cut off in narrow terminals

## 概要

`/usage` の表示が狭いターミナル幅でも切れないよう修正されました。

## 基本的な使い方

```
/usage
```

## 実践例

### 分割ペイン・小さなウィンドウでの確認

tmux分割などの狭い画面でも使用状況を読み取れます。

## 注意点

- 表示は端末幅に応じて調整されます。
