# セルフホストランナーのチェックアウトフックがデフォルトで30分後に停止

## 原文（日本語に翻訳）

- セルフホストランナー: チェックアウトフックをデフォルトで30分後に停止し、セッションのセットアップを失敗させるように変更。より長い時間が必要な場合は `--checkout-hook-timeout-min` を引き上げるか `0` に設定してください

## 原文（英語）

- Self-hosted runner: Changed checkout hooks to be stopped after 30 minutes by default, failing the session's setup; if yours needs longer, raise `--checkout-hook-timeout-min` or set it to `0`

## 概要

チェックアウトフックが無期限に動き続けてランナーのスロットを占有する事態を防ぐため、デフォルトで30分のタイムアウトが設けられました。超過するとフックは停止され、セッションのセットアップは失敗します。

## 基本的な使い方

タイムアウトを60分に延長する例です。

```bash
<runner コマンド> --checkout-hook-timeout-min 60
```

無制限にする場合は `0` を指定します。

```bash
<runner コマンド> --checkout-hook-timeout-min 0
```

## 実践例

### 巨大リポジトリのクローン

初回のチェックアウトに30分以上かかる環境では、値を引き上げます。

### ハング検知

デフォルトのままにしておけば、フックのハングによるスロット占有を自動で解消できます。

## 注意点

- `0` はタイムアウト無効を意味するため、ハング時にスロットが解放されません。
- `<runner コマンド>` はお使いのランナー起動コマンドに置き換えてください。
