## 原文（日本語訳）

iTerm2で特定のフォントサイズを使用した際に、Clawdマスコットの目と足が不揃いに表示される問題を修正しました。

## 原文（英語）

Fixed the Clawd mascot's eyes and feet rendering unevenly in iTerm2 at some font sizes

## 概要

Claude CodeのCLIには「Clawd」と呼ばれるカニのマスコットキャラクターが用意されており、起動時やアイドル時などにUnicodeのブロック要素を組み合わせたピクセルアート風のアニメーションとして表示されます。iTerm2で特定のフォントサイズを使用していると、このマスコットの目や足を構成する文字の幅計算がずれてしまい、パーツがガタついて見える表示崩れが発生していました。今回の修正により、iTerm2でもフォントサイズにかかわらずマスコットが正しい形で表示されるようになりました。

## 基本的な使い方

この修正はレンダリング周りの内部改善であり、ユーザー側で特別な設定や操作を行う必要はありません。Claude Codeをアップデートするだけで、iTerm2上でのマスコット表示が改善されます。

```bash
# バージョンを確認し、最新版であることを確かめる
claude --version
```

## 実践例

### iTerm2でカスタムフォントサイズを使っている場合

Nerd Fontsなど幅の広いグリフを含むフォントを使い、フォントサイズを標準よりも大きく（または小さく）設定していると、以前は目や足の位置が揃わずにマスコットの見た目が崩れることがありました。アップデート後はこうした環境でも表示が安定します。

### 複数ターミナルを使い分けている場合

iTerm2とTerminal.app、VS Code統合ターミナルなどを併用している場合、これまではiTerm2でのみ発生していた表示崩れが今回の修正で解消されるため、どのターミナルでもマスコットの見た目に差異がなくなります。

## 注意点

- 純粋な見た目の問題であり、Claude Codeの機能や動作そのものには影響していませんでした
- iTerm2以外のターミナルエミュレータでは元々この問題は発生していませんでした
- ターミナルやフォントの推奨設定については公式ドキュメントの「ターミナル設定」ページを参照してください
