## 原文（日本語訳）

ターミナルより高い状態を保ったまま画面が短くなった後、非フルスクリーンレンダラーで行が乱れて誤った位置に表示される不具合（例: シェルコマンドが出力をストリーミングしている最中にプロンプトの行を削除した場合など）を修正しました。

## 原文（英語）

Fixed garbled, misplaced rows in the non-fullscreen renderer after the screen got shorter while still taller than the terminal, e.g. deleting a prompt line while a shell command streams output

## 概要

非フルスクリーンモードで、Claude Codeの表示内容の高さがターミナルの高さより大きい状態を保ちながら、何らかの理由で表示内容自体の高さが縮んだ場合（たとえば、シェルコマンドがストリーミング出力している最中にプロンプトの行を削除するなど）に、画面の行が正しくない位置に描画され、内容が乱れて見える不具合がありました。今回の修正でこの再描画のロジックが改善され、こうした状況でも正しく行が配置されるようになりました。

## 基本的な使い方

ユーザー側の対応は不要です。非フルスクリーンモードで長い出力をストリーミングするコマンドを実行する通常の使い方の中で、この修正が自動的に適用されます。

## 実践例

### ビルドログなど長時間ストリーミングするコマンドの実行中の編集

`npm run build` のように長時間出力を続けるコマンドを実行しながら、プロンプト入力欄で文字を編集・削除しても、画面表示が乱れなくなります。

### ターミナルウィンドウのリサイズを伴う作業

作業中にターミナルウィンドウのサイズを変更する場面でも、表示が崩れにくくなり、より安定した見た目を保てます。

## 注意点

- フルスクリーンモードを使用している場合はこの不具合の影響を受けていませんでした
- 表示が乱れた場合は、ターミナルの再描画（画面クリアなど）で一時的に回避できることもありますが、今回の修正で根本的に解消されています
