## 原文（日本語訳）

Code ModeでPreToolUseフックがエラーになっても、スクリプトのツール呼び出しを拒否しなくなりました。Code Mode外と同じ挙動です。拒否が必要なコマンド、HTTP、MCPツールのフックには `"onFailure": "block"` を設定してください。

## 原文（英語）

Changed Code Mode so a PreToolUse hook that errors no longer refuses a script's tool call, as outside Code Mode; set `"onFailure": "block"` on a command, HTTP or MCP tool hook that must refuse

## 概要

フック自体が失敗したとき、Code Modeでもそれ以外と同様にツール呼び出しが通ります。ガードとして失敗時にも止めたいフックは、明示的に `onFailure` を `block` にします。

## 基本的な使い方

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          { "type": "command", "command": "./check.sh", "onFailure": "block" }
        ]
      }
    ]
  }
}
```

## 実践例

### 安全チェックのフェイルクローズ

検査スクリプトが異常終了した場合も実行を止めたいときに `onFailure: block` を使います。

### 補助的なフック

ログ記録など止める必要のないフックは既定のままにします。

## 注意点

- 上の設定例は構造を示す一例です。正確なスキーマは公式のフックドキュメントで確認してください。
- 既存のガード用フックは見直しを推奨します。
