## 原文（日本語訳）

フルスクリーンモードを改善し、複数回のコンパクション（会話履歴の圧縮）が発生した場合でも、直近の区間だけでなく、コンパクション前の履歴全体をスクロールバックに保持するようにしました。

## 原文（英語）

Improved fullscreen mode to keep the full pre-compaction history in scrollback across repeated compactions, instead of only the most recent interval

## 概要

Claude Codeの「フルスクリーンモード」（`/tui fullscreen`）は、`vim`や`htop`と同様にターミナルの代替画面バッファ（alternate screen buffer）に描画するレンダリングモードです。会話が長くなるとコンテキストウィンドウを節約するために自動的に「コンパクション」（過去のやり取りを要約して圧縮する処理）が行われますが、これまではコンパクションを何度も繰り返すと、スクロールバックとして遡って確認できるのは直近1回分のコンパクション区間のみでした。今回の改善により、セッション開始からのコンパクション前の完全な履歴を、複数回のコンパクションをまたいでスクロールバックに保持できるようになりました。

## 基本的な使い方

フルスクリーンモードでは、会話が代替画面バッファに描画されるため、ターミナル本来のスクロールバック（`Cmd+f`やtmuxの検索など）では会話内容を検索できません。代わりに`Ctrl+o`でトランスクリプトモードに入り、`[`キーを押すことでターミナルのネイティブなスクロールバックに会話全文を書き出せます。

```bash
# フルスクリーンモードを有効化
/tui fullscreen

# トランスクリプトモードに入る
Ctrl+o

# 会話全文をターミナルのスクロールバックに書き出す
[
```

## 実践例

### 長時間セッションで複数回コンパクションが起きた後に過去の指示を確認する

大規模なリファクタリングなど長時間にわたるセッションでは、コンテキストウィンドウの上限に達するたびに自動コンパクションが走ります。以前は2回目・3回目のコンパクションが起きると、1回目のコンパクション前のやり取りはスクロールバックから実質的に失われていました。今回の改善で、セッション序盤に与えた指示や制約事項も、後から`[`でスクロールバックに書き出せば確認できます。

```bash
# 長時間のセッション中、何度目かのコンパクション後に
Ctrl+o
[
# ターミナルのネイティブ検索（Cmd+f やtmuxのコピーモード）でキーワード検索
```

### tmux上でセッション全体のログを保存する

`[`でスクロールバックに書き出した内容はターミナルの通常のバッファに入るため、tmuxのコピーモードやログ保存機能と組み合わせて、コンパクションをまたいだ全履歴を記録に残せます。

```bash
# tmux使用時、フルスクリーンモードのセッションで
Ctrl+o
[
# その後 tmux のログ保存機能でファイルに書き出す
```

### エディタで会話全体をレビューする

`v`キーを使うと会話を一時ファイルに書き出して`$VISUAL`や`$EDITOR`で開けます。コンパクションを何度も経たセッションでも、この方法で全体を通しでレビューできます。

```bash
Ctrl+o
v
# $EDITOR（vimなど）で会話全文が開く
```

## 注意点

- フルスクリーンモードは研究プレビュー（research preview）機能です。2026年5月6日以降に初めてClaude Codeを使用した場合はデフォルトで有効、それ以前から使っている場合は`/tui fullscreen`で明示的に切り替える必要があります。
- この改善はスクロールバックへの表示・書き出しに関するものであり、ディスク上のセッショントランスクリプト自体の保持ポリシー（`~/.claude/projects/`配下、既定30日）を変更するものではありません。
- クラシックレンダラー（`/tui default`）では会話は常にターミナルのネイティブなスクロールバックに残るため、そもそもこの問題は発生しません。
- `Ctrl+o` → `[`でスクロールバックに書き出す操作は、セッションが長い場合は一瞬処理が止まることがあります。
