## 原文（日本語訳）

Artifactの公開結果を改善しました。送信されたタブアイコンを表示し、ページにNULバイトが含まれる場合に警告し、古い公開後にマージするための不安定なフェッチをリトライするようになりました。

## 原文（英語）

Improved artifact publish results: they name the tab icon sent, warn when the page contains a NUL byte, and retry a flaky fetch of the newer page to merge after a stale publish

## 概要

Artifactを公開する際、ブラウザタブに表示されるアイコンが設定されている場合、これまではその情報が公開結果に表示されていませんでした。また、ページの内容にNULバイト（不正なバイナリ文字）が含まれていてもそのまま公開処理が進み、後々問題になることがありました。さらに、すでに古いバージョンが公開されている状態から新しいバージョンをマージして公開しようとした際、最新ページの取得（フェッチ）が不安定でまれに失敗することがありました。今回の改善で、公開結果にタブアイコンの情報が明示され、NULバイトが含まれる場合は警告が表示されるようになり、不安定なフェッチも自動的にリトライされるようになりました。

## 基本的な使い方

特別な操作は不要です。通常どおりArtifactを公開すると、改善された結果メッセージが表示されます。

```
# Artifact公開時の結果表示例
公開しました: https://claude.ai/artifacts/xxxxx
タブアイコン: favicon.png を送信しました
```

## 実践例

### タブアイコンを設定したページを公開する

Artifactページにカスタムのfaviconを設定して公開した場合、公開結果にどのアイコンが送信されたかが明記されるようになり、意図したアイコンが正しく反映されているかをすぐに確認できます。

### ページ内容にNULバイトが混入した場合

生成されたHTMLやテキストに誤ってNULバイトが混入してしまうケースでは、修正前は気づかないまま公開されることがありましたが、修正後は公開結果に警告が表示されるため、事前に問題に気づいて修正できます。

```
公開しました: https://claude.ai/artifacts/xxxxx
警告: ページの内容にNULバイトが含まれています。表示が崩れる可能性があります
```

### 古いバージョンが公開された直後に再公開する場合

短時間に連続してArtifactを更新・公開すると、最新ページの取得が一時的に不安定になり、マージに失敗することがありました。修正後はこのフェッチが自動的にリトライされるため、ユーザーが手動で再試行する必要が減りました。

## 注意点

- タブアイコンやNULバイトに関する警告は、あくまで公開結果として表示される情報です。内容の修正自体は手動で行う必要があります。
- フェッチの自動リトライは一時的な不安定さに対する対策であり、恒久的なネットワーク障害がある場合は引き続きエラーになる可能性があります。
