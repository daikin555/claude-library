## 原文（日本語訳）

`/skills` で `/` の直後にキーを入力すると、検索ボックスに入力される代わりにスキル一覧が移動してしまう不具合を修正しました。

## 原文（英語）

Fixed a key typed right after `/` in `/skills` moving the skill list instead of reaching the search box

## 概要

`/skills` コマンドを実行した直後、続けてすぐに文字キーを入力してスキルを検索しようとすると、その入力が検索ボックスに届かず、代わりにスキル一覧のカーソル移動として解釈されてしまう不具合がありました。これにより、素早くタイピングして絞り込み検索を行おうとしたユーザーの入力が意図しない挙動を引き起こしていました。今回の修正でこの問題が解消され、`/skills` の直後の入力も正しく検索ボックスに届くようになりました。

## 基本的な使い方

```
/skills
```

コマンド実行直後にそのまま検索したいキーワードを入力すると、検索ボックスに正しく反映されます。

## 実践例

### 素早いスキル検索

多数のスキルがインストールされている環境で、`/skills` を実行した直後にすぐキーワードを入力して目的のスキルを素早く絞り込めます。

### タイピングの流れを止めない操作感

コマンド実行から検索までを一連の動作として素早くタイピングするユーザーにとって、意図しない一覧移動が発生しなくなり、ストレスのない操作感になります。

## 注意点

- この不具合は `/skills` 実行「直後」の入力に特有のものです。一覧が表示された後にゆっくり入力する場合は元々問題ありませんでした
- 関連して、検索ボックスとリスト間のカーソル移動に関する別の不具合修正もあります（[カーソルジャンプの修正](./2.1.282-fix-skills-cursor-jump.md)を参照）
