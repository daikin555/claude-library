# エージェントチーム有効時に Code Mode を使えるように

## 原文（日本語に翻訳）

エージェントチームが有効な状態で Code Mode をオンにできるようになりました。すでにオンにしている場合、チームが有効なセッションは Code Mode で起動します。

## 原文（英語）

Added support for turning on Code Mode while agent teams are enabled; if you already turned it on, sessions with teams on now start in Code Mode

## 概要

これまでエージェントチームと Code Mode は併用できませんでしたが、v2.1.326 から同時に利用できます。Code Mode をすでに有効化している場合、チーム機能がオンのセッションは自動的に Code Mode で始まります。

## 基本的な使い方

1. エージェントチームを有効にする
2. Code Mode をオンにする
3. セッションを開始する（チームが有効なら Code Mode で起動）

## 実践例

### 並列作業を Code Mode で行う

複数のエージェントが協調するチーム運用でも、Code Mode のワークフローをそのまま利用できます。

### 既存ユーザーの挙動確認

すでに Code Mode をオンにしている場合、チームを有効にしたセッションの開始時の挙動が変わります。起動後に Code Mode になっているか確認してください。

## 注意点

- 有効化の具体的な手順・設定名は公式ドキュメントを確認してください。
- Code Mode でも権限チェックは強化されており（同バージョンで一部のサンドボックスコマンドが確認または拒否の対象になります）、挙動が変わる場合があります。
