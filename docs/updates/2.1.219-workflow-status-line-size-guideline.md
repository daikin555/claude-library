## 原文（日本語に翻訳）

実行中のワークフローのステータスラインに、現在のデフォルトのワークフローサイズを追加し、変更方法として `/config` へのポインタを表示するようにしました。

## 原文（英語）

Added the current default workflow size to the running-workflow status line, with a pointer to `/config` for changing it

## 概要

Claude CodeでDynamic Workflowを実行すると、画面上部または下部のステータスラインに実行中のワークフローの進捗（フェーズやエージェント数など）が表示されます。今回のアップデートで、このステータスラインに現在適用されている「ワークフローサイズ」のガイドライン（例: `small` / `medium` / `unrestricted` など）が新たに表示されるようになりました。あわせて、サイズを変更したい場合は `/config` から変更できる旨のヒントもステータスラインに併記されるため、実行中のワークフローが想定より小さすぎる・大きすぎると感じたときに、すぐに設定変更へ進めます。

## 基本的な使い方

Dynamic Workflowを伴うタスクをClaude Codeに依頼すると、実行中は自動的にステータスラインが表示されます。特別な操作は不要です。

```
> 大規模なリファクタリングを計画して実行して

# ワークフロー実行中、ステータスラインに以下のような表示が出る
Running workflow… (medium) · phase 2/4 · 3 agents active
Change workflow size: /config
```

ステータスライン上の `(medium)` の部分が、現在適用されているデフォルトのワークフローサイズガイドラインです。

## 実践例

### ワークフローが想定より小さく感じたときにサイズを変更する

複雑な依頼をしたにもかかわらず、ステータスラインに `(small)` と表示され、生成されるワークフローのステップ数やエージェント数が少なすぎると感じた場合は、実行中または実行後に `/config` を開いてサイズを調整します。

```
> 認証周りの大規模な設計変更を計画して

Running workflow… (small) · phase 1/2 · 1 agent active
Change workflow size: /config

# サイズが小さすぎると感じたら /config を実行
/config
# → Workflow size の項目を small から medium や unrestricted に変更
```

次回以降、同様の大規模タスクを依頼した際に、より多くのフェーズ・エージェントを含むワークフローが生成されやすくなります。

### 逆にワークフローが大きすぎる・冗長だと感じたときの調整

簡単な修正タスクなのにステータスラインが `(unrestricted)` や `(large)` を示し、必要以上に多くのフェーズやサブエージェントが生成されていると感じる場合も、同様に `/config` からサイズを縮小できます。

```
> READMEのタイポを1箇所直して

Running workflow… (unrestricted) · phase 3/6 · 5 agents active
Change workflow size: /config

/config
# → Workflow size を small に変更し、以降は軽量なタスクに見合った
#   小規模なワークフローが生成されるようにする
```

### チームでの運用時にステータスラインを確認習慣にする

複数人でClaude Codeを使うプロジェクトでは、メンバーごとに好みのワークフローサイズ設定が異なる場合があります。実行を任せきりにせず、ステータスラインの `(medium)` のような表示を都度確認する習慣をつけておくと、意図しないサイズ設定のままタスクを走らせてしまうミスを防げます。設定を統一したい場合はプロジェクトのオンボーディング手順に `/config` でのワークフローサイズ確認を含めるとよいでしょう。

## 注意点

- ステータスラインに表示されるのはあくまで「現在のデフォルトのワークフローサイズガイドライン」であり、個々のタスクの複雑さに応じてClaude Codeが実際に生成するワークフローの規模は多少前後することがあります。
- `/config` での変更は以降に生成されるワークフローに適用されるものであり、既に実行中のワークフローの構造がその場でリアルタイムに再構成されるわけではありません。
- ステータスラインの表示内容やレイアウトは今後のバージョンで変更される可能性があるため、正確な表示形式は都度お使いのバージョンで確認してください。
