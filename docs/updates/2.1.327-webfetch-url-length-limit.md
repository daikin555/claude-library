# WebFetch が 2,000 文字超の URL を事前に拒否

## 原文（日本語に翻訳）

非常に長い WebFetch の URL で発生していた停止を修正しました。WebFetch は、パーミッション確認の前に 2,000 文字を超える URL を拒否します。

## 原文（英語）

Fixed stalls on a compaction reply with thousands of unclosed tags and on some very long WebFetch URLs; WebFetch now refuses a URL over 2,000 characters before any permission prompt

## 概要

極端に長い URL によって処理が停止する問題への対策として、2,000 文字を超える URL はパーミッションの確認より前に拒否されます。不要なプロンプトも表示されません。

## 基本的な使い方

通常の URL なら動作は変わりません。

```text
WebFetch url="https://docs.anthropic.com/en/docs/claude-code/overview"
```

## 実践例

### クエリが長大な URL

データを URL に埋め込んでいるケースでは拒否されます。必要な情報はファイルに保存し、ローカルで読むか短縮した URL を使います。

### 関連修正

同じ更新で、大量の `@` メンションを含むメッセージが停止する問題も修正され、ファイルとして検索されるのは最初の 100 件までになりました。

## 注意点

- 拒否時は、URL を短くして再試行してください。
- 2,000 文字以内でも、権限設定による許可確認は従来どおり行われます。
