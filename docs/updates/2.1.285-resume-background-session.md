# 実行中のバックグラウンドセッションを /resume で開く

## 原文（日本語訳）

- バックグラウンドで実行中のセッションに対する `/resume` と `claude --resume` が、拒否せずそのセッションを開くようになりました。`claude --resume <id> "prompt"` で渡したプロンプトは次のターンとして送信されます

## 原文（英語）

- Improved `/resume` and `claude --resume` on a session that is running in the background: they now open that session instead of refusing, and a prompt given with `claude --resume <id> "prompt"` is sent to it as its next turn

## 概要

バックグラウンドで動いているセッションにも `/resume` で接続できるようになりました。追加の指示をプロンプト付きで送ることもできます。

## 基本的な使い方

```bash
claude --resume <session-id>
```

## 実践例

### 実行中セッションへ追加指示を送る

```bash
claude --resume <session-id> "テストも追加しておいて"
```

### 一覧から再接続する

セッション一覧から実行中のものを選ぶと、そのまま開けます。

## 注意点

- プロンプトは新規セッションではなく、対象セッションの次のターンとして送られます。
