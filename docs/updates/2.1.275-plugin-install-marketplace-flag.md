## 原文（日本語に翻訳）

`/plugin install <plugin> --marketplace <source>` を追加：プラグインをインストールする前に、そのマーケットプレイスをまだ追加していない場合に追加するかどうかを提案します

## 原文（英語）

Added `/plugin install <plugin> --marketplace <source>`, which offers to add the marketplace before installing the plugin

## 概要

これまでプラグインをインストールするには、事前に `/plugin marketplace add` でマーケットプレイスを追加してから `/plugin install` を実行する2段階の操作が必要でした。今回追加された `--marketplace` フラグを使うことで、マーケットプレイスがまだ登録されていない場合に追加を提案しつつ、1つのコマンドでプラグインのインストールまで完了できるようになりました。

## 基本的な使い方

```
/plugin install <plugin-name> --marketplace <source>
```

`<source>` にはGitHubリポジトリなどのマーケットプレイスの参照先を指定します。まだ追加されていないマーケットプレイスの場合、追加するかどうかの確認が表示されます。

## 実践例

### 新しいマーケットプレイスのプラグインを一度に導入する

まだ利用したことのないマーケットプレイスからプラグインをインストールする場合、マーケットプレイスの追加とインストールを1コマンドで行えます。

```
/plugin install formatter --marketplace anthropics/claude-code
# → マーケットプレイスが未登録の場合、追加するか確認が表示される
# 承認するとマーケットプレイス追加とプラグインインストールが続けて実行される
```

### チームの社内マーケットプレイスから素早く導入する

社内Gitリポジトリをマーケットプレイスとして使っている場合も、同様に1コマンドで導入できます。

```
/plugin install deploy-toolkit --marketplace my-org/internal-plugins
```

## 注意点

- 既にマーケットプレイスが追加済みの場合は、追加の確認なしにそのままプラグインがインストールされます
- マーケットプレイスの追加には確認プロンプトが表示されるため、信頼できるソースかどうかを確認してから承認してください
- `--scope` フラグと組み合わせて、インストール先（ユーザー/プロジェクト）を指定することも可能です
