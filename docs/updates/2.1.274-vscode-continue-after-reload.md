## 原文（日本語訳）
ウィンドウのリロードによって中断したステップをチャット内でラベル付きで継続する機能が追加され、これをオフにする「Claude Code: Continue After Reload」設定が追加されました。

## 原文（英語）
[VSCode] Added continuation of the step a window reload interrupted, labeled in the chat, with a Claude Code: Continue After Reload setting to turn it off

## 概要
VSCode拡張機能でウィンドウがリロードされると、それまで実行中だったステップ（ツール実行など)が中断されてしまうことがありました。今回の更新で、リロードによって中断されたステップをチャット内に明示的にラベル付きで表示しつつ自動的に継続する機能が追加されました。この挙動が不要な場合は「Claude Code: Continue After Reload」設定でオフにできます。

## 基本的な使い方
デフォルトで有効になっているため、特別な操作は不要です。VSCodeのウィンドウがリロードされた場合、中断されたステップが自動的にチャット内で継続されます。

```
VSCode設定 (settings.json):
"claudeCode.continueAfterReload": true
```

## 実践例

### 誤ってウィンドウをリロードしてしまった場合
拡張機能が更新されたりOSがスリープから復帰したりしてVSCodeウィンドウがリロードされても、実行中だったステップは中断された箇所からチャット内にラベル付きで表示され、自動的に継続されます。

### この機能をオフにしたい場合
リロード後は手動でやり取りを再開したい場合は、設定でこの挙動を無効化できます。

```json
{
  "claudeCode.continueAfterReload": false
}
```
VSCodeの設定画面から「Claude Code: Continue After Reload」を検索してチェックを外すことでも同様に無効化できます。

## 注意点
- 設定名は「Claude Code: Continue After Reload」です。VSCodeの設定UIまたは `settings.json` から変更できます。
- 長時間かかるツール実行の途中でリロードが発生した場合、継続処理にも一定の制約がある可能性があるため、重要な処理中はリロードを避けるのが安全です。
