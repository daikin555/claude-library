## 原文（日本語に翻訳）

`known_marketplaces.json` への同時書き込みが原因で、プラグインマーケットプレイスが起動時の競合状態によりサイレントに登録解除されてしまう不具合を修正しました

## 原文（英語）

Fixed a startup race that could silently unregister a plugin marketplace due to concurrent writes to `known_marketplaces.json`

## 概要

Claude Codeはプラグインマーケットプレイスの情報を `known_marketplaces.json` というファイルで管理しています。起動時に複数のプロセスやコンポーネントがこのファイルへ同時に書き込みを行うと、競合状態（レースコンディション）が発生し、登録済みのマーケットプレイスがエラーメッセージも表示されないまま静かに登録解除されてしまうことがありました。v2.1.232ではこの競合状態を修正し、`known_marketplaces.json` への書き込みが安全に行われるようになりました。

## 基本的な使い方

この修正は内部的な安定性向上であり、特別な操作は不要です。以下のような場面で影響を受けていました。

```bash
# マーケットプレイスを追加
claude
> /plugin marketplace add my-org/my-marketplace

# 修正前: 起動タイミングによっては known_marketplaces.json への
# 同時書き込みが競合し、登録したはずのマーケットプレイスが
# 何もエラーが出ないまま消えてしまうことがあった

# 修正後: 起動時の書き込み競合が解消され、登録内容が確実に保持される
```

## 実践例

### 複数のClaude Codeセッションを同時に起動する場合

```bash
# 同じマシンで複数のターミナルからほぼ同時にClaude Codeを起動
claude &
claude &

# 修正前: 起動タイミングが重なると known_marketplaces.json への
# 書き込みが競合し、片方のセッションの変更が失われることがあった
# 修正後: 競合が解消され、両方のセッションの状態が正しく反映される
```

### CI/CDやスクリプトから連続してClaude Codeを起動する場合

```bash
# セットアップスクリプトなどで短時間に複数回claudeを起動するケース
for i in 1 2 3; do
  claude --print "plugin marketplace list"
done

# 修正前: 起動のたびに known_marketplaces.json が書き換えられ、
# 稀にマーケットプレイス登録が消えることがあった
# 修正後: 安定して登録内容が維持される
```

### マーケットプレイス登録状態の確認

```bash
> /plugin marketplace list
# 登録済みのマーケットプレイスが期待通り表示されることを確認できる
```

## 注意点

- Claude Code v2.1.232で修正されたバグ修正です。
- 症状はエラーメッセージなしで発生する「サイレントな」登録解除だったため、これまで気づきにくい問題でした。
- もし過去にマーケットプレイスが理由もなく消えていた経験がある場合、v2.1.232への更新で改善が見込めます。念のため `/plugin marketplace list` で登録状況を確認することをおすすめします。
