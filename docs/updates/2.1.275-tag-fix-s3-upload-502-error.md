## 原文（日本語訳）
[Claude Tag] 最近のバージョンのAWS CLIおよびSDKからのS3アップロードが、AWS接続経由で送信された際に502エラーで失敗する不具合を修正。

## 原文（英語）
[Claude Tag] Fixed S3 uploads from recent AWS CLI and SDK versions failing with a 502 error when sent through an AWS connection

## 概要
Claude TagのAWS接続機能を通じてS3にファイルをアップロードする際、比較的新しいバージョンのAWS CLIやAWS SDKを使用していると502エラーで失敗する不具合がありました。これはAWS接続を経由するリクエスト処理側の問題によるもので、今回の修正によりAWS CLI/SDKの最新バージョンからのS3アップロードも正しく成功するようになりました。

## 基本的な使い方
特別な設定変更は不要です。Claude TagのAWS接続を設定した状態で、通常通りAWS CLIやSDKを使ってS3へのアップロード操作を行います。

```bash
aws s3 cp ./report.csv s3://my-bucket/reports/report.csv
```

## 実践例

### 修正前に発生していた問題
最新のAWS CLI（v2の新しいマイナーバージョンなど）やAWS SDKを使ってS3にファイルをアップロードしようとすると、AWS接続を経由した際に502 Bad Gatewayエラーが返され、アップロードが失敗していました。

```
Before:
$ aws s3 cp ./data.zip s3://my-bucket/data.zip
upload failed: 502 Bad Gateway
```

### 修正後の挙動
同じ操作を行っても502エラーは発生せず、S3へのアップロードが正常に完了するようになりました。

```
After:
$ aws s3 cp ./data.zip s3://my-bucket/data.zip
upload: ./data.zip to s3://my-bucket/data.zip
```

## 注意点
- 本修正はClaude Tag経由のAWS接続を利用してS3操作を行う場合に関係します。AWS接続を利用していない通常のAWS CLI利用には影響しません。
- 依然として502エラーが発生する場合は、AWS接続の認証情報や権限設定を確認してください。
