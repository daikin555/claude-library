# Code Mode が Bedrock・Vertex・Foundry などのターミナルセッションに対応

## 原文（日本語に翻訳）

Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude Platform on AWS 上のターミナルセッションで Code Mode をサポートしました。

## 原文（英語）

Added Code Mode support in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS

## 概要

v2.1.331 から、サードパーティクラウド経由で Claude Code を利用しているターミナルセッションでも Code Mode が使えるようになりました。企業で Bedrock や Foundry などを経由している環境でも、スクリプトによるツール呼び出しの恩恵を受けられます。

## 基本的な使い方

```bash
# Bedrock 経由で起動している既存の環境でそのまま利用可能
export CLAUDE_CODE_USE_BEDROCK=1
claude
```

## 実践例

### クラウドプロバイダー経由でのスクリプト実行

```bash
export CLAUDE_CODE_USE_BEDROCK=1
claude --resume   # 再開時も Code Mode を継続して利用
```

## 注意点

- 利用できるかどうかはプロバイダーやモデルの対応状況にも依存します。
- `--resume` / `--continue` で別の権限モードに切り替えると、以前は思考やプロンプトキャッシュが失われる問題がありましたが、本バージョンで修正されています。
