## 原文（日本語訳）
[VSCode] MCPサーバー一覧の読み込みに失敗した場合に、MCPサーバーダイアログにRetryリンクを追加しました

## 原文（英語）
[VSCode] Added a Retry link to the MCP servers dialog when the server list fails to load

## 概要
VS Code拡張機能のMCPサーバーダイアログで、サーバー一覧の読み込みに失敗した場合、これまでは拡張機能自体を再起動するなど手間のかかる対処が必要になることがありました。今回の変更で、読み込み失敗時にダイアログ内に「Retry」リンクが表示されるようになり、その場でワンクリックで再読み込みを試せるようになります。

## 基本的な使い方
MCPサーバー一覧の読み込みに失敗すると、ダイアログにRetryリンクが表示されるので、それをクリックします。

```
# VS CodeでMCPサーバーダイアログを開く
# ネットワーク不調などで一覧の読み込みに失敗
# → ダイアログに「Retry」リンクが表示される
# → クリックすると再度読み込みを試みる
```

## 実践例

### 一時的なネットワーク不調からの復帰
```
# MCPサーバーダイアログを開いたが、
# サーバーの起動が間に合わず一覧取得に失敗
# → Retryリンクをクリックして再取得
```

### MCPサーバー設定を修正した直後の再確認
```
# .mcp.jsonの設定を修正した直後にダイアログを開いたが
# 一時的に読み込みエラーになった
# → 拡張機能を再起動せずにRetryリンクで再試行できる
```

## 注意点
- Retryで解消しない場合は、MCPサーバー自体の設定やプロセスの起動状況を確認する必要があります。
- この機能はVS Code拡張機能のMCPサーバーダイアログに限定されます。
- 根本原因（サーバー設定ミスやプロセスクラッシュなど）を解消しないと、再試行しても同じエラーになることがあります。
