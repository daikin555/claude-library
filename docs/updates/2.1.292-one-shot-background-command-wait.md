## 原文（日本語訳）

ワンショットの `claude -p` とAgent SDKの実行が、最終結果の5秒後にバックグラウンドコマンドを停止していた問題を修正した。また、ワンショットの `claude -p` が予約された起床（scheduled wakeup）を破棄していた問題も修正した。どちらも待機されるようになった。

## 原文（英語）

Fixed one-shot `claude -p` and Agent SDK runs stopping a background command 5 seconds after the final result, and one-shot `claude -p` runs dropping a scheduled wakeup; both are now waited for

## 概要

非対話実行で、バックグラウンドコマンドや予約された起床が途中で打ち切られなくなりました。

## 基本的な使い方

```bash
claude -p "開発サーバーをバックグラウンドで起動し、疎通確認して"
```

## 実践例

### バックグラウンド処理を伴う自動化

長時間のビルドやテストをバックグラウンドで走らせるスクリプトでも、完了まで待機されます。

## 注意点

- 待機する分、プロセスの終了が従来より遅くなる場合があります。
