## 原文（日本語訳）

[Code Review] GitHubや内部サービスが起動時に一時的に失敗した際、まれに「Code review encountered an error」というメッセージでレビューが終了してしまう不具合を修正しました。現在は待機してリトライするようになっています。

## 原文（英語）

[Code Review] Fixed rare reviews ending with "Code review encountered an error" when GitHub or an internal service failed transiently at launch; they now wait and retry

## 概要

Code Reviewを起動する際、GitHub APIや内部サービスへの呼び出しが発生しますが、これらが一時的な障害（ネットワークの瞬断やサービス側の一時的な不調など）で失敗すると、これまではレビュー全体が「Code review encountered an error」というエラーメッセージとともに即座に終了してしまうことがありました。今回の修正により、こうした一時的な失敗を検知した場合は即座に諦めるのではなく、しばらく待ってから自動的にリトライするようになり、レビューの成功率が向上しました。

## 基本的な使い方

利用者側での操作は不要です。Code Reviewを通常どおり実行すれば、起動時に一時的な障害が発生しても内部で自動的にリトライされます。

```
# PRを作成またはレビューをトリガーするだけ
gh pr create --title "..." --body "..."
```

## 実践例

### GitHub API の一時的な不調時

GitHub側で瞬間的なレート制限や遅延が発生した場合、修正前はレビューがすぐに失敗していましたが、修正後は自動的に待機してからリトライされ、ユーザーが再実行する手間がなくなります。

### 内部サービスの一時的な障害時

Code Reviewの起動処理に関わる内部サービスが一時的に応答しない場合も同様に、修正後はリトライ処理によって多くのケースで正常にレビューが完了するようになります。

## 注意点

- リトライはあくまで「起動時の一時的な失敗」に対するものであり、恒常的な障害や権限不足によるエラーは引き続き失敗として報告されます
- リトライにより、エラーが発生した場合のレビュー完了までの時間がわずかに長くなることがあります
