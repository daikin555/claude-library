# [クラウドセッション] 既存環境の保存が誤って拒否される問題を修正

## 原文（日本語に翻訳）

- [Cloud sessions] Cloud environments管理ページが、既存の環境の保存を「installs packages」エラーで誤って拒否する問題を修正

## 原文（英語）

- [Cloud sessions] Fixed the Cloud environments admin page wrongly refusing to save an existing environment with an "installs packages" error

## 概要

Cloud environments管理ページで、既存環境を保存すると誤って「installs packages」エラーになる問題が修正されました。

## 基本的な使い方

管理ページで既存環境を編集し、通常どおり保存できます。

## 実践例

### 環境設定の更新

パッケージ導入を含む既存環境の設定変更が保存できます。

## 注意点

- 管理者向けの修正です。
