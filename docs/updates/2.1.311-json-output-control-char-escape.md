## 原文（日本語に翻訳）

`--output-format json` と `stream-json` の出力で、文字列内のDEL、C1制御文字、Unicode書式文字を `\uXXXX` エスケープとして書き出すように変更しました。パース後の値は変わりません。

## 原文（英語）

Changed `--output-format json` and `stream-json` output to write DEL, C1 control and Unicode format characters inside strings as `\uXXXX` escapes; parsed values are unchanged

## 概要

JSON出力に含まれる見えない制御文字などが、`\uXXXX` 形式でエスケープされるようになりました。ログや端末への出力時に問題を起こしにくくなります。JSONとしてパースした値は同じです。

## 基本的な使い方

```bash
claude -p "要約して" --output-format json | jq -r '.result'
```

## 実践例

### stream-jsonの処理

```bash
claude -p "調査して" --output-format stream-json --verbose | jq -c .
```

### 文字列照合のスクリプト

正規のJSONパーサーを使う限り影響はありません。生テキストに対する `grep` などで制御文字を直接照合している場合のみ確認が必要です。

## 注意点

- 生の文字列マッチングに頼る処理は見直してください。
- パース後の値は変わりません。
