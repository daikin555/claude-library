## 原文（日本語訳）

`/effort` およびプロンプト入力欄における `ultracode` の視覚表現を、リップルエフェクト・枠の装飾・キーワードの輝きのないプレーンなスタイルに変更し、動的ワークフローのスピナー用ヒントも削除しました。

## 原文（英語）

Changed the `ultracode` visuals in `/effort` and the prompt input to plain styling (no ripple, border flourish or keyword glimmer) and removed the dynamic-workflows spinner tip

## 概要

`ultracode`（マルチエージェント・ワークフロー機能）が有効な際、`/effort` メニューやプロンプト入力欄には波紋のようなリップルエフェクトや枠の装飾、キーワードの輝きといった視覚的な演出が施されていましたが、今回の変更でこれらの派手な演出が削除され、よりシンプルでプレーンな表示スタイルに変更されました。あわせて、動的ワークフローに関するスピナー表示時のヒントメッセージも削除されました。

## 基本的な使い方

ユーザー側の対応は不要です。`ultracode` を利用する際の表示が、より落ち着いたスタイルに自動的に変わります。

```
/effort
```

## 実践例

### 集中を妨げない、落ち着いたUI体験

派手な視覚エフェクトに気を取られることなく、`ultracode` によるマルチエージェント・ワークフローの実行状況に集中できるようになります。

### 低スペック端末やリモート接続でのパフォーマンス向上

装飾的なアニメーションが減ることで、ターミナルの描画負荷が下がり、リモート接続や非力な端末でもよりスムーズな表示が期待できます。

## 注意点

- これは見た目のスタイル変更であり、`ultracode` やワークフロー機能自体の動作には影響しません
- スピナーのヒントメッセージが削除されたため、動的ワークフローに関する情報は別の手段（ドキュメントなど）で確認する必要があります
