# OpenTelemetry tool_decision イベントにclassifierとpermission_modeを追加

## 原文（日本語に翻訳）

OpenTelemetry の `tool_decision` イベントに `classifier_verdict` と `permission_mode` を追加しました。autoモードの分類器による判断を、権限ルールによる判断と区別できます。

## 原文（英語）

Added `classifier_verdict` and `permission_mode` to OpenTelemetry `tool_decision` events, so auto mode classifier decisions can be told apart from permission rules

## 概要

ツール実行の許可・拒否を記録する `tool_decision` イベントに、分類器の判定結果（`classifier_verdict`）と、そのときの権限モード（`permission_mode`）が加わりました。判断がautoモードの分類器によるものか、権限ルールによるものかを集計で見分けられます。

## 基本的な使い方

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_LOGS_EXPORTER=otlp
claude
```

## 実践例

### 分類器による判断の割合を把握する

`classifier_verdict` の有無で絞り込み、autoモードの判断がどの程度を占めるかを確認できます。

### 権限モード別にツール判断を比較する

`permission_mode` ごとに集計し、モード間の許可・拒否の傾向を比べられます。

## 注意点

- テレメトリを有効にした場合のみ出力されます。
