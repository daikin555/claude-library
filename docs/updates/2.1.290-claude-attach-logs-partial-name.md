## 原文（日本語訳）

`claude attach <name>` と `claude logs <name>` を追加した。IDの代わりにセッション名の一部を指定できる。

## 原文（英語）

Added `claude attach <name>` and `claude logs <name>`: part of a session name works in place of the id

## 概要

バックグラウンドセッションに接続する `claude attach` と、ログを表示する `claude logs` で、長いセッションIDではなくセッション名の一部を指定できるようになりました。名前を付けておけば、IDを調べ直す手間が省けます。

## 基本的な使い方

```bash
claude attach my-refactor
claude logs my-refactor
```

## 実践例

### 実行中のバックグラウンドセッションに戻る

```bash
claude attach refactor
```

名前に「refactor」を含むセッションに接続します。

### 止まったセッションの原因を調べる

```bash
claude logs refactor
```

## 注意点

- 部分一致が複数のセッションに該当する場合の挙動は、実際の出力で確認してください。
- `/rename` などで分かりやすい名前を付けておくと効果的です。
