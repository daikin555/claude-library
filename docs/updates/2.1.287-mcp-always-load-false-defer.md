## 原文（日本語に翻訳）

MCP サーバーの `alwaysLoad: false` が、そのサーバーのすべてのツールをツール検索の背後に遅延させるように変更しました。

## 原文（英語）

Changed MCP server `alwaysLoad: false` to defer all of that server's tools behind tool search

## 概要

MCP サーバーの設定で `alwaysLoad: false` を指定すると、そのサーバーのすべてのツールがツール検索（tool search）の背後に回り、必要になるまでコンテキストに読み込まれません。ツール数の多いサーバーでコンテキストを節約できます。

## 基本的な使い方

```json
{
  "mcpServers": {
    "big-server": {
      "type": "http",
      "url": "https://example.com/mcp",
      "alwaysLoad": false
    }
  }
}
```

## 実践例

### ツール数の多いサーバー

使用頻度の低い大規模な MCP サーバーに `alwaysLoad: false` を指定し、初期コンテキストの消費を抑えます。

### 常時使うサーバー

よく使うサーバーは `alwaysLoad: true` にしておくと、ツールが常に利用可能になります。

## 注意点

- 遅延されたツールは、Claude がツール検索で見つけて初めて使えるようになります。
- 既に `alwaysLoad: false` を設定している場合、今回の更新でサーバー全体のツールが遅延対象になる点に注意してください。
