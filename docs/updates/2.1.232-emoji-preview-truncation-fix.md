## 原文（日本語に翻訳）

長いシェルコマンドやエージェントの説明のプレビューが絵文字の途中で切り取られることで発生していた、意図しない文字化けを修正しました

## 原文（英語）

Fixed a stray garbled character where a long shell-command or agent-description preview was cut off mid-emoji

## 概要

Claude Codeでは、実行しようとしているシェルコマンドやサブエージェントの説明文が長い場合、UI上でプレビュー表示として一部が省略（truncate）されます。この省略処理が、絵文字（サロゲートペアなど複数バイト・複数コードポイントで構成される文字）の途中で行われてしまうと、不完全な文字コードが残り、画面上に意味不明な文字化けとして表示される不具合がありました。v2.1.232ではこの切り詰め処理が文字境界を正しく認識するように修正され、絵文字を含むプレビューが正常に表示されるようになりました。

## 基本的な使い方

この修正はユーザーが明示的に操作するものではなく、内部的な表示処理の改善です。以下のような場面で自然に恩恵を受けます。

```bash
# 絵文字を含む長いシェルコマンドを実行しようとする場合
claude "🚀 デプロイスクリプトを実行して、ビルド結果を確認してから通知してほしい 📦✅"

# 修正前: プレビュー表示の末尾で絵文字が途中で切れ、文字化けした記号が表示されることがあった
# 修正後: 絵文字の境界を考慮して正しく省略され、文字化けが発生しない
```

## 実践例

### 絵文字入りのエージェント説明を持つサブエージェント

```markdown
---
name: deploy-helper
description: "🚀 デプロイ作業を自動化し、失敗時は🔥アラートを出すエージェント"
---
```

このようなdescriptionが長く、UI上でプレビューのために切り詰められる際も、v2.1.232以降は絵文字部分が壊れずに表示されます。

### 長いBashコマンドの確認ダイアログ

```bash
# 非常に長いワンライナーを実行させる場合
claude "以下のコマンドを実行して: find . -name '*.log' -exec grep -l 'ERROR ✅❌🔴' {} \; | xargs rm -f"
```

パーミッション確認ダイアログに表示されるコマンドプレビューが長すぎて省略される際、絵文字を含んでいても文字化けせずに正しく表示されます。

## 注意点

- Claude Code v2.1.232で修正されたバグ修正です。
- 表示上の問題のみであり、実際のコマンド実行内容やエージェントの動作自体には影響がありません。
- サロゲートペアや結合文字など、複数コードユニットで構成される文字全般に関わる修正のため、絵文字以外の特殊文字でも同様の改善が期待されます。
