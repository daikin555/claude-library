## 原文（日本語訳）
[Claude Tag] トップレベルのチャンネルメッセージで他のアプリやボットが同時に@メンションした際、Claudeが時々2回返信してしまう不具合を修正。

## 原文（英語）
[Claude Tag] Fixed Claude sometimes replying twice when another app or bot @mentioned it in a top-level channel message

## 概要
Slack上では複数のアプリやボットが同じメッセージ内で同時に@メンションされることがあります。Claude Tagにはこのようなケースで、Claudeが同じメッセージに対して2回返信してしまうという不具合がありました。これはチャンネルのトップレベルメッセージ（スレッドの返信ではなく最初の投稿）で他のボットと同時にメンションされた際に発生しやすいものでした。今回の修正でこの重複返信が解消され、1つのメッセージに対して1回だけ正しく応答するようになりました。

## 基本的な使い方
特別な操作は不要です。他のアプリやボットと同じメッセージで@Claudeとメンションしても、Claudeは1回だけ応答するようになります。

```
チャンネル投稿: "@Claude @OtherBot この件を確認して"
→ 修正前: Claudeが2回返信することがあった
→ 修正後: Claudeは1回だけ返信する
```

## 実践例

### 複数のボットを同時に運用しているチャンネル
デプロイ通知ボットや監視ボットなど複数のSlackアプリが動いているチャンネルで、あるメッセージ内で複数のボットとClaudeを同時にメンションしても、Claudeからの返信が重複することがなくなり、チャンネルが読みやすくなります。

### インシデント対応チャンネルでの一斉メンション
インシデント発生時に複数の担当ボットとClaudeを同時にメンションして状況確認を依頼するようなケースでも、Claudeの応答が1回に統一され、混乱を避けられます。

```
"@Claude @IncidentBot @OnCallBot 現在の障害状況をまとめて"
→ Claudeからの返信は1件のみ
```

## 注意点
- 本修正はトップレベルのチャンネルメッセージで他のボットと同時にメンションされた場合の重複返信に関するものです。
- スレッド内での挙動や、Claude単独でメンションされた場合の挙動には影響しません。
